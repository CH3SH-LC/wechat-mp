# 排版演示

[下载智序 1.0.0 与使用手册](https://github.com/CH3SH-LC/wechat-mp/releases/tag/v1.0.0)

六份虚构校园稿件的桌面排版示例，涵盖活动、资讯和实践报道。同类示例使用相同正文和简短排版要求，展示不同生成结果。

这些示例由完整正文开始排版。学校、社区、活动及组织均为虚构测试素材；图中插画是示意性创作，不是现场照片。

以下图片均为原始 **750 像素宽 PNG 长图**，没有裁切、缩放或重绘。点击图片可查看原图。
