# 写作方法索引

这组方法帮助作者把材料写成对读者有用的文章。先理解需求、选择材料、写清内容，再决定如何排版。结构、篇幅和语气随任务变化；这里没有要求逐项填满的成稿模板。

| 条目 | 解决的问题 |
|---|---|
| writing-purpose.md | 读者为什么需要这篇文章，材料支持讲什么 |
| writing-structure.md | 怎样组织材料，让标题与开头得到兑现 |
| writing-language.md | 怎样把意思写成完整句子和连贯段落，避免碎句与拟人口语 |
| writing-campus.md | 校园活动、通知与报道怎样服务学生的具体需求 |
| writing-product.md | 怎样说清产品用途、实际能力与适用条件 |
| writing-explain.md | 怎样解释问题、讲清步骤或帮助读者比较选择 |
| writing-story.md | 怎样从真实经历中写出人物、事件与感受 |
| writing-review.md | 怎样通过删、补、移、重写完成实质编辑 |

按当前任务选择相关条目，不必先归入某个固定体裁。方法是内部编辑依据：用户给出主题或材料后，由作者完成选材与写作；只在缺失事实会妨碍准确成稿时提出必要问题，不把策划工作交回用户。

材料中的事实和作者的解释要能分清。知识条目、旧稿、示例或排版素材都不能自动成为本稿事实。方法的来源、迁移理由与验证边界见仓库研究记录 `docs/design/writing-method-2026-10-12.md`。
