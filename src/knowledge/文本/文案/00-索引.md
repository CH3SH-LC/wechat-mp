# 文案方向索引（文本 / 文案）

> 定位：解决「这篇推文的文字怎么写」——**不同位置的文案**（标题/开头/分点/小标题/结尾/金句…）各怎么写，外加文风润色、内容类型模板与跨条目方法论。
> 用法：先定类型（见 内容类型 方向）与风格（见 视觉/风格），再按「写作顺序」取条目：标题 → 摘要 → 开头 → 分点 → 小标题 → 结尾 → 文风润色 → 红线自查。
> 交叉：文案结构对应模块（copy-layout）；标题红线见 copy-redline；摘要另见 其它/封面 的 cover-summary.md。

## 一、写作顺序速查

| 步骤 | 条目 | 一句话要点 |
|---|---|---|
| 1 拟标题 | copy-title.md | 给 2-3 个方案再定稿；数字/悬念/利益/情绪等公式 |
| 2 写摘要 | cover-summary.md（封面方向） | 摘要=第二标题，≤120 字，承接标题制造点开冲动 |
| 3 写开头 | copy-open.md | 首段 ≤3 行，钩子 8 选 1：结论/痛点/悬念/场景/故事/数据/反常识/引用 |
| 4 写分点 | copy-points.md | 9 种结构：并列/步骤/时间线/对比/因果/递进/问题解决/案例/问答 |
| 5 写小标题 | copy-subheading.md | 小标题=文中路标：10 类型 + "短准钩统"四字诀 + 8 坑 |
| 6 写结尾 | copy-end.md | 收束 + 行动号召，6 式收尾：总结/金句/悬念/互动/福利/号召 |
| 7 润色文风 | copy-style-basics.md + 其余文风条目 | 去 AI 味 + 节奏/画面感/具体化 |
| 8 红线自查 | copy-redline.md + copy-guide-checklist.md | 标题党/违禁词/字数/重点密度 |

## 二、条目清单

### 位置写法（10 个——标题到结尾每个位置一个点）

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| copy-title.md | 标题写法：公式大全、字数上限、截断规则、方案对比 | 每篇开头必读 |
| copy-open.md | 开头钩子：8 种钩子 + 首段长度/呼应标题/禁忌 | 写首段时 |
| copy-points.md | 分点结构：9 种结构 + 每条 40-120 字公式 | 写正文主体时 |
| copy-subheading.md | 小标题写法：10 类型 + "短准钩统"四字诀 + 8 坑 + 正反案例 | 写分节小标题时 |
| copy-end.md | 结尾：收束句 + 6 式收尾 + 行动号召 | 写结尾时 |
| copy-quote.md | 金句写法：可单拎转发的一句话 | 观点/情感/干货文 |
| copy-transition.md | 段落过渡：小标题间承上启下话术 | 多分点、长文 |
| copy-redline.md | 标题党红线：夸张词/诱导点击/文题不符 | 每个标题定稿前 |
| copy-tags.md | 话题标签与关键词：标签布局、搜索优化 | 垂类账号日常发文 |
| copy-layout.md | 文案与排版配合：文案预留排版位 | 文案完稿转排版时 |

### 文风条目（4 个）

|---|---|---|
| copy-style-basics.md | 文风总则与去 AI 味：口语化/数字具体/避 AI 高频词 | 每篇润色时 |
| copy-style-rhythm.md | 句式节奏：长短句/段落长度/情绪梯度 | 文章读起来"平"时 |

## 三、文案条目统一结构

核心规则（详细展开）→ 公式/模板骨架 → 示例（可用可改）→ 常见错误 → 自查要点 → 个性化留白（按账号调性自定的部分）
