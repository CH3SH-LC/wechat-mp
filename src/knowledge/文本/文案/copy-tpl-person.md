# 人物故事模板（copy-tpl-person）

> **定位**：
> 把一个真实人物写「活」——用一个画面让他登场，
> 用转折让他有起伏，用细节对话动作让他立在读者面前，
> 最后带出这个人给读者的启示。读者记住的不是「他多厉害」，而是「他这个人」。
>
> **调用时机**：
> 写「一个人 / 一群人的经历」时用。
> 典型场景——专访一位创业的姐姐、写一位教书三十年的老师、
> 记录小区里修自行车的老师傅、写一名考上理想学校的学生。
> 它区别于「品牌故事」聚焦一群人 / 理念——这里聚焦一个具体的人；
> 也区别于「情感随笔」重感受——这里重这个「人」。
> 判断依据见「内容类型」维度判断流程。

## 一、结构与写法

人物故事成功与否，在于读者能不能「看见」这个人。
而「看见」只能靠具体的文字画面——对话、动作、细节，
靠形容词是看不见的。结构：人物引入 → 背景交代 → 转折事件 → 细节刻画 → 人物启示。

### 阶段一：人物引入（一个画面 / 细节，约占 15%）

**写作目标**：
用一个具体的画面或细节让这个人在第一段就「立起来」，
让读者记住一个画面。

**写法要点**：
- 从「一个动作 / 一个场面 / 一个物件 / 一句口头禅」切入，不介绍履历。
  例：「修车的老王，蹲在路边，左手捏着辐条，
  右手指肚在轮圈上慢慢摸过去，像医生在摸脉。」画面感立刻有。
- 这个细节最好能体现这个人的性格或处境，后面有机会呼应。
- 避免「他是一位很优秀的人」这类概括性开场，
  一上来就定性，读者反而没有画面。

**判断引入好不好**：
读第一段，眼前有没有出现这个人的画面。
如果只是「他是一位乐于助人的老师」，换成能看见的动作再说。

**时长/篇幅建议**：
首段 ≤3 行，约 100 字。一个画面就够，把人先放出来。

### 阶段二：背景交代（约占 15%）

**写作目标**：
交代这个人的基本情况、身世处境、性格底色，
帮助读者理解他后来的选择。

**写法要点**：
- 简短交代：他是谁、做什么、从哪来、什么性格。
  点到为止，不写履历流水账。
- 背景要为后文的转折与启示服务，
  能解释「他为什么这么选」的信息才值得写。
- 和引入画面衔接自然，别生硬地「介绍一下，他……」。
- 用一两件事或几句对话交代性格，别只贴形容词标签。

**背景别写成简历**：
写背景是为了理解这个人，不是为了列档案。
能推动理解的才留，与转折无关的删掉。

**时长/篇幅建议**：
100-200 字。背景是理解人物后半程的铺垫，别占用太多篇幅。

### 阶段三：转折事件（约占 30%）

**写作目标**：
讲一个让这个人「变」起来的事件——
他的选择、困境、转折、或一个决定性的时刻，让故事有起伏。

**写法要点**：
- 这是人物故事的心跳，必须有转折：
  遇到了什么困难、做了什么艰难的选择、发生了怎样的转变。
  没有转折，人物故事就只剩描述，没有叙事。
- 转折要具体到「当时发生了什么、他怎么想、怎么做的」。
  例：老厂长当机立断砍掉畅销但劣质的产品线，宁可赔钱。
- 转折处最能显露人物性格与价值观，也是后面「启示」的依据。
- 把转折的纠结、犹豫、决定写透，别一句带过。

**转折的三问**：
他面对什么、凭什么做决定、决定带来了什么。
三样写满，转折才立得住。

**时长/篇幅建议**：
这是叙事重心，约 30%，250-400 字。

### 阶段四：细节刻画（贯穿转折前后，约占 25%）

**写作目标**：
用对话、动作、细节（而不是形容词）把这个人的性格「演」出来。

**写法要点**：
- 写对话，让情绪和性格从人物嘴里说出来，不靠作者旁白解释。
  例：学生劝老师快退休歇着，
  老师只回一句「这孩子我带完这一届。」性格都在话里。
- 写动作：紧张时转杯子、着急时抓头发、坚决时攥紧拳头。
  动作比「他很执着」可信。
- 写细节：一个习惯、一个签名、一双手的茧。
  细节是让人物区别于任何别人的关键。
- 原则：能用画面说的，不用评价词。
  删掉「他很善良」「他特别努力」，换成能证明这两句的具体事情。

**写活人的三件套**：
一句有个性的对话、一个标志性动作、一个具体物件的细节。
三样里有一样，人物就有了味道。

**时长/篇幅建议**：
穿插在转折与背景之间，约 200-300 字。
关键是「时时用画面说明」，不必单独一大块。

### 阶段五：人物启示（约占 15%）

**写作目标**：
收束全文，说出「这个人的故事对读者意味着什么」，
但克制、不拔高说教。

**写法要点**：
- 启示要从人物真实的经历里「长出来」，不是硬扣概念。
  他的选择本身已经说明了一切，你只需轻轻点出。
- 常与某句对话 / 某个细节呼应收尾，形成闭环。
  例：结尾呼应开头那个「摸轮圈」的画面。
- 避免「他教会我们人要坚强」这种空洞口号——
  把启示落在「具体的人做出了具体的坚持」，读者自然有收获。

**启示的分寸**：
多数时候话不必说满，留白反而动人。
你越用力总结大道理，读者越觉得被上课。

**时长/篇幅建议**：
100-150 字。启示要克制，收在一个人、一件事上。

## 二、完整骨架（可套用，标出的地方是替换处）

```
【标题】
〔标题走「人物 + 转折/状态」路，点出人物的特殊性或命运感。
  例「修了四十年车，老王说他还不想退休」；
  避免空洞的「致敬最可爱的人」〕

【引入 · 一个画面/细节】
〔一个动作/场面/物件/口头禅，1 个画面摆出来〕
〔画面能体现性格或处境更好〕

【背景 · 交代】
〔他是谁/做什么/从哪来/什么性格，简短〕
〔只写能解释他后来选择的信息〕

【转折 · 关键事件】
〔一个困难/选择/转变，写出当时的纠结与决定〕
〔这是故事起伏与性格显露的地方〕

【细节刻画】（可穿插于转折前后）
〔一段对话：性格从话里出来〕
〔一个动作/习惯/细节：证明性格而非形容〕

【启示 · 收尾】
〔从他真实的经历提炼，不硬扣概念〕
〔可呼应开头的画面/细节，形成闭环〕
〔克制，话不说满〕

〔可选：行动号召，如关注/留言/转发〕
```

### 骨架用法说明

- 骨架是「填空题」，〔方括号〕处换成你要写的人的真实素材。
- 转折与细节是最吃功夫的地方，别用履历凑。
- 启示收尾要克制，宁可留白，别上成道理课。

## 三、示例（教育 / 人物场景，标注结构）

> 主题：一位代课十多年的乡村小学语文老师

**【引入 · 一个画面】**
开学第一天，教室里最后一排坐着个半头白发的女老师，
驼着背，正用笔尖一下下戳着本子角。
校长让她上台做个自我介绍，她站起来，憋了半天，只说了句：「我姓陈，教语文。」

**【背景交代】**
陈老师今年五十二，在镇里这所小学代课已经十四年。
没有编制，工资比在编老师少一半，却年年接手没人愿意带的毕业班。
镇上的年轻老师来了又走，她一直在这儿，
家长都认得她，孩子见了她老远就喊「陈老师」。

**【转折事件】**
前年县里招特岗教师，机会难得，校长劝她去考，说考上了就有编制。
她犹豫了整整一个暑假，教案改了又改。
可到报名那天早上，她在校门口站了很久，
最后转身走进了教室——因为班上有两个孩子，父母去外地打工了，
一周打一次电话，她怕自己走了，就没人每天早上盯着他们背书了。

那个学期，她右手旧伤复发，握粉笔写得久了手就抖。
可她没请假，用左手按住右手，一个字一个字把板书写完。
有别的老师劝她「你都这岁数了，别硬撑」，
她只回了一句：「这个班，我带完这一届。」
她说话时，眼睛还是看着讲台下的那帮孩子。

**【细节刻画】**
学生作文里写过她：陈老师批改本子，红笔总是写得很满，
旁边还画一朵小花，鼓励写得好的人。
有回一个孩子英语考砸大哭，她没讲大道理，就坐在旁边，
把自己常年握粉笔磨出的、裂着口子的手摊开给他看：
「老师这双手，写字写了三十年，没一天是容易的，可也没停过。你也一样。」

**【启示收尾】**
去年九月，那位曾担心她走的校长又站在教室门口，
远处陈老师正扶着门框，喊班里孩子排队。
她没走成，也没打算再走。你看，有些人一辈子没站上多大的舞台，
可就是这一个人，在一间教室里，守住了几百个孩子的清晨。
很多时候，了不起不是做了什么惊天动地的事，
而是把一件平常的事，做了十四年，还没打算停下来。

## 四、语气与禁忌

**语气要求**：
尊重、克制、善意。
第一或第三人称皆可（第三人称更常见，第一人称适合作者亲历）。
客观呈现这个人的选择和坚持，不拔高、不神化，
把「他是怎样的」交给读者自己感受。温度来自细节，不来自用力赞美。

**具体落地**：
- 用事实和对话呈现性格，不用「伟大、善良、坚强」贴标签。
- 转折处写「他怎么想、怎么做」，不替他总结「这很伟大」。
- 语气平淡客观，人物的动人之处让细节自己说话。

**禁忌**：
1. 只用形容词，没有画面。
   通篇「他非常努力、特别善良、很有毅力」，
   却没有一件事能证明——人物是「介绍」出来的，不是「立」起来的。
2. 没有转折、写成履历流水账。
   「他从小 → 上学 → 工作 → 退休」平铺直叙，
   没有关键的困境、选择、转变，就没有故事。
3. 神化、道德绑架式拔高。
   把普通人吹成圣人、或暗示「你不像他这样就不够好」，
   既失真也让人不适。
4. 偷懒用刻板印象。
   用「伟大母亲」「奉献一生的好人」这类标签抹平人物真实的多面性，
   把活人写成了符号。
5. 编造对话和细节。
   真人真事的对话动作必须真实可据，虚构要标注为创作。
   编造细节一旦被本人或身边人发现，既伤害当事人也失信读者。

## 五、与排版配合

人物故事的排版要「叙事有节奏、画面有重量、启示有回响」。
- **开篇**：
  用「开头页眉」做简洁首屏；
  引入画面那段保持清爽，可配一张「图片」增强人物现场感。
- **叙事**：
  转折与细节段落用「分割线」或「章节标题」自然过渡；
  若人物经历时间跨度大，可用「时间线」呈现关键节点。
- **对话 / 金句**：
  人物点睛的一句话（如「这个班，我带完这一届」）
  用「重点气泡」或「金句 / 大字号引用」立起来，方便转发。
- **结尾**：
  用「结尾行动号召」；连载 / 栏目号可加「往期回顾 / 下期预告」，
  把人物故事做成可持续的栏目。

> 具体模块语法与样式见「模块」维度各条目，这里只给组合建议。

## 六、个性化空间

模板是起点不是终点，以下环节需**结合账号调性与读者改写**。
- **视角的选择**：
  写「他」还是写「我」，取决于你与人物是否亲历。
  专访 / 旁观用第三人称；写自己身边的亲友可用第一人称增加亲切感。
  看账号的叙事习惯与可信度需求。
- **人物的取舍**：
  不谈「越厉害越值得写」，写「越能触动你的读者」的人。
  同一篇受众，教育号读者爱看师生，职场号爱看创业者。
  选你这个账号的读者会关心、会共情的那类人。
- **转折的选择**：
  每个人物都有不止一次转折，
  选「最能让读者看清他性格那次」，
  以及「最贴近账号想传达的价值观那次」。别把所有转折都塞进去。
- **细节的浓度**：
  人物本身够传奇，细节可以少、转折可以重；
  人物平淡但可爱，就多用生活化的对话和习惯细节撑起鲜活感。
  判断依据：人物的戏剧性来自哪里，就厚写哪里。
- **启示的分量**：
  人物故事可以停在「这个人」让人回味，
  也可以轻点一句「对读者的意义」。
  教育 / 励志导向的账号启示可以多一分，纯纪实 / 文学调性的账号宁可留白。
  别把每个故事都上成一堂道理课。
