# copy-style-basics · 文风总则与去 AI 味

> 定位：一篇推文"像不像真人写的"总开关——把机器腔改成人话，是所有类型文案的底色。
> 调用时机：每篇初稿写完、润色阶段必读；尤其是一读起来就"假、平、端着"的时候。读完仍嫌"干"看文风节奏（copy-style-rhythm.md）；嫌"虚"看表达生动化（copy-style-vivid.md）。三者是文案润色第三步，排在标题、开头、分点、结尾之后。

### 规则速查（改稿时照着扫）

| 规则 | 一句话 | 最省力的检查法 |
|------|--------|---------------|
| 1 短句 | 单句 ≤30 字，多用逗号 | 读出来能不能"一口气说利索" |
| 2 数字 | 虚词后面补具体数字 | "省时间"这类词后有没有数字 |
| 3 去腔 | 高频词、连接词、排比、夸大全删 | 全篇搜那串 AI 词 + 朗读 |
| 4 人称 | 你/我们定一套 | 搜"你/你们/大家/我们" |
| 5 标记 | 加粗 ≤2、高亮 ≤1、不整段 | 数一屏加粗处 |
| 6 人味 | 留一处带细节/情感的话 | 有没有"我 / 我妈 / 我自己"这类落点 |
| 7 克制 | 别改过头变另一种腔 | 朗读一遍，自然就行 |
| 8 分流 | 写时顺写、改时细扫 | 别一边写一边抠字 |

> 谁在读谁定主规则：急于扫读的 → 短句+去连接词；有专业背景愿细读的 → 数字+去夸大；年轻爱共情的 → 人味+对话感。一篇挑最对症的三条用力即可。

## 一、核心规则

### 规则 1：口语化短句，多用逗号，少用长从句

一句话说一件事，单句尽量压到 **30 字以内**。长句子拆成几个短句，中间用逗号喘气，别让读者憋一口气读到缺氧。

为什么重要：读者在手机上刷，眼睛一扫就知道这行字累不累。一行塞 40 字，视觉压力直接拉满。短句视觉轻、读得快、像一个人开口说话。

怎么拆：找出长句里"谁、做了什么、结果或伴随什么"三块，各提出来变成独立短句，用逗号或句号隔开。

- 拆前：「我们在充分调研了目标用户群体的真实痛点以及在竞品大量头部账号的发布数据基础上，经过反复论证，才最终确定了这一版对于当下更适配的内容选题方向。」
- 拆后：「我们把读者吐槽最多的十个问题拉出来排了个队，哪个听的人都点头，就写哪个。别贪多。」

判断标准：一句话读出来能不能一口气说利索。说不利索，就按"谁-做什么-结果"拆开。

### 规则 2：数字具体化

"省时间""涨粉快""效果好"都是废话。给数字，读者才信，才有画面。

- 反例：「用了这个方法，效率提升了一个很大的台阶。」
- 正例：「同一个选题，原来磨 3 天，现在半天出稿。」

数字怎么选才像人：优先用整、直观的量（省 20 分钟、少 3 个步骤、多 200 个阅读）。"半天""三个礼拜"比"37.5%"更像人说话。小数点不是不能用，只是在生活与职场场景里，整数量往往更可信、更好记。数字的完整写法（阿拉伯数字、加单位、关键数字加粗）见表达生动化（copy-style-vivid.md）。

### 规则 3：避免清单式 AI 腔（核心，五处盯死）

AI 腔有五张显眼的"脸"，见一张抓一张。

**脸一：夸大象征。** 硬把一件小事拔高成大道理。
- 反例：「他终于关掉了手机，这一小步，是人类重拾专注的一大步。」
- 正例：「他把手机塞进抽屉，整整一个下午没碰。」（小动作就够，不用上升）

**脸二：三段式排比。** 什么都来三个，表面"全面"其实是凑数。
- 反例：「这份工作不仅锻炼了我的能力，还开拓了我的视野，更让我收获了成长。」
- 正例：「这份工作让我学会把杂事理清，也认识了一群靠谱的人。」（两项就够，一项可能更有力）

**脸三：过度连接词。** "值得注意的是 / 综上所述 / 由此可见 / 首先其次最后 / 一方面另一方面"——作文里的话，不是跟人聊天的话。能删就删。
- 反例：「值得注意的是，即使天气不好，他也依然坚持每天跑步。」
- 正例：「下雨也没挡住他跑。淋着雨也得把那 5 公里跑完。」

**脸四：否定式排比。** "这不是……更是……""与其说是……不如说是……"，通篇用就是套路。
- 反例：「这不只是一份工作，更是一种使命。」
- 正例：「这份工作不用多高尚，能把每个月的房租挣回来，就行。」

**脸五：AI 高频词。** 赋能、闭环、抓手、打造、颗粒度、底层逻辑、方法论、维度、深耕、洞察、破圈、降本增效。一出现，懂行的读者立刻认定机器写的，一个都别留。

怎么改高频词：不是换同义词（"赋能"改"助力"还是机器味），而是想清楚人话版本。如"用内容赋能品牌"→"让内容真的帮品牌把货卖出去"。

### 规则 4：人称统一

一篇推文，说话人（我/我们）和说话对象（你）固定成一套。先问两问定口径：

- 主动方是谁？写方法、教程多"你"："你先打开设置，再点这里"；写品牌、团队故事用"我们"："我们做这行做了十年"。
- 全文定死。第一段用"你"、中段变"大家"、结尾蹦出"你们"，是最常见漂移。改稿通篇搜"你 / 你们 / 大家 / 我们 / 人们"，统一成一套。

特别提醒："我们为你准备了……"这种混搭，多半是作者没想清主体。想清"教"（你）还是"讲我们的事"（我们）再动笔。

### 规则 5：重点标记要克制

一屏（约二三十行手机正文）里，**加粗最多 2 处，高亮（====）最多 1 处**。加粗只给必须被看见的那一句（结论、金句、行动号召）。**不允许整段加粗**。

- 反例：整段黑体，像吵架，重点一个记不住。
- 正例：全文字色统一，一句关键结论加粗，放在一屏最显眼处。

下笔前问："全篇只允许读者记住这一句，是不是这句？"不是就撤。

### 规则 6：全文留一处"人味落点"

删完机器味，若整篇还像一份干净的"标准答案"，就是技术上干净但没灵魂。补法：留一处主观、带情绪或带细节的落点，让读者知道写这篇的是一个人。

- 例：「我自己也试过，最先放弃的是周四那版，太贪心了。」
- 例：「写到这我忽然想起我妈，她也这么念叨过我。」

一处就好，别撒得到处都是。它证明"这不是套出来的模板"。

### 规则 7：别从"改词"做到"过头"，变成另一种腔

去 AI 味不是把每句都压到最短。这里管的是"把不像人话的说成人话"，不是"把每句都砍成三个字"。过度执行的人会把"他喜欢周末早晨慢跑"改成"他喜欢周末早上慢跑，还行吧"，反而不伦不类。执行顺序和力度：先铲高频词和连接词，再破排比和夸大，最后才动长短。三步走完，读一遍觉得像人说话就够了，不必每句都改。

### 规则连招示范：从"满屏 AI 腔"到"像人说话"

为了看清七条规则怎么配合，下面给一段病文，每行病文后面标出病症，再给改后的人话版。

**病文**：「越来越多的职场人开始意识到，在当今竞争日益激烈的环境中，持续学习和自我提升已经成为了不可或缺的生存法则。值得注意的是，很多人往往陷入了一种"收藏不问"的误区，似乎收藏了就等同于学会了。综上所述，我们应当摒弃无效努力，培养真正高效的学习习惯。」

病症逐条看：
- 「越来越多的职场人开始意识到」——空话套话，可换具体场景。
- 「在当今竞争日益激烈的环境中」——空话。
- 「不可或缺的生存法则」——夸大象征。
- 「值得注意的是」——过度连接词。
- 「综上所述」——过度连接词。
- 「无效努力 / 真正高效」——形容词堆，没数字。

**人话版**：「你收藏了 300 篇干货，昨晚临睡又存了一篇，今晚还在刷新的。可你有几篇是回过头真正看过的？别收藏了，今天花 20 分钟，把去年的精华翻出来，删掉没用的，剩下的立刻去用。」

这一版把六处病症一次清完：空话换成场景、夸大删掉、连接词全删、形容词换成数字和动作，并统一了"你"的人称。补充一句：这里还用到了数字具体化（规则 2）、口语短句（规则 1）和对话感（见表达生动化）。三条文风规则是配着用的，不是各自为政。

### 规则 8：写作时 vs 润色时，两套动作别混

很多写作者误以为"去 AI 味"是写的时候一句话一句话憋出来的，其实很累，也容易把思路打断。更顺的做法是分开：

**写的时候（快）：** 先顺着写，把内容倒出来。允许先写出"值得注意的是""我们要意识到"这类废话占位，反正后面要删。写的时候专注于"把要点说清楚"。

**改的时候（慢）：** 对着本条目和自查要点过一遍。1 先删高频词和连接词；2 破排比、撤夸大；3 加数字、加细节；4 统一人称；5 控制标记；6 留一处人味落点；7 整段朗读一遍。三遍改完，比写一句憋一句快得多，效果也好得多。

这条对调用方尤其有用：**不要在生成第一版时就拘泥于句子长短，先把内容铺开，再扫机器腔。** 省时，也不容易把文章改成交作业味。

再给一段"病文二"练练手，这次是软文向：

**病文二**：「在快节奏的现代生活中，越来越多的人开始追求更加便捷高效的出行方式。值得一提的是，我们全新推出的智能出行产品，凭借其卓越的性能和人性化的设计，为用户带来前所未有的便捷体验，全方位满足了用户的多元化需求。」

- 「在快节奏的现代生活中」——空话开头；
- 「值得一提的是」——过度连接词；
- 「卓越 / 人性化 / 前所未有 / 全方位 / 多元化」——形容词堆，全篇没有一个数字和细节；
- 「便捷高效」——虚词。

**人话版二**：「赶地铁的人都知道，早高峰挤上去只要十五秒。我们这辆车，开门进，坐下，系好，到站，全程不用掏手机。实测比打车快了 9 分钟。」

这一版把形容词堆全清掉，换成"十五秒 / 9 分钟"两个数字和"开门进、坐下、系好"三个动作。读者一眼知道这东西好在哪，而不是听你夸它"卓越"。

## 三、应用场景

**干货/教程文（最要紧）。** 最怕"说明书腔"。每段问一句"我像在给朋友支招，还是像在讲课？"高频词和连接词零容忍。
- 别写：「建立科学的作息机制，是实现高效晨起的前提。」
- 写：「你把闹钟放远点，够不着，就起来了。」

**情感/随笔文（其次）。** 最怕"为赋新词强说愁"，把情绪拔高成大道理。多说细节、少说结论，删夸大象征。
- 别写：「这一刻，是成长的必经之路。」（夸大+套话）
- 写：「他下楼时三步一回头，到了转角又站住了。」

**软文/带货。** 最怕满屏"赋能 / 打造 / 闭环 / 生态"。卖点用数字和场景说，别用形容词堆。"闭环"这类词在带货文里尤其让人出戏。
- 别写：「本品赋能你的运动生活，打造健康闭环。」
- 写：「跑完回来，鞋垫还是干的。」

**新闻/资讯。** 口语可收着、可稍书面，但"奠定基础 / 标志着 / 彰显"这类夸大词照样删，事实直接给。人称多用"本报 / 记者 / 事件方"，少用"你"。

**品牌/宣言文。** "我们"人称的主场。去掉空喊口号，用事实和数字撑"我们是谁"。
- 别写：「我们致力于创造美好生活。」
- 写：「十年来，我们修过的桥有两百座。」

**极简/高冷号。** 对"AI 高频词"和"连接词"按最严执行，一个不留，连"此外"都删干净；句子更短、标记更少。

**判断一篇该用哪条规则为主：** 先看内容类型，再看读者。读者越"急着扫、没耐心"，短句和去连接词越关键；读者越"愿意细读、有专业背景"，数字具体化和去夸大越关键；读者越"年轻、爱共情"，人味落点和对话感越关键。每条规则都有它的主场景，不必一篇全用足，挑最对症的三条用力即可。

**跨类型提醒：** 同一篇里往往是混合类型（干货带情感、软文带教程）。这时先定"主类型"（决定语气重心），再让其他类型让路。比如"情感+干货"，就按情感文处理（细节-人味优先），干货点只做点缀；反过来"干货+情感"，则以清楚讲方法为先，情感落点收着放。别让两种语气五五开，那样最像机器人拼盘。

## 四、常见错误

1. **只删形容词不换思路。** 把"全方位的提升"改成"很好的提升"还是虚。要换成数字或动作，不是换近义词。这是最流行的"假改"。怎么办：凡是"很 / 非常 / 极其 / 大幅"这类，先问"到底是多少 / 什么动作"，写不出就整句重写。
2. **三段式排比下意识恢复。** "不仅……还……更……"写顺手，改稿通篇搜"不仅 / 不但 / 更 / 还"，砍成两项甚至一项。怎么办：同一内容有三个并列点，砍掉最虚的那个，留下最有信息量的两项。
3. **加粗上瘾。** 觉得重要就加粗，一屏五六处等于没重点。砍到两处以内，其余撤掉。怎么办：把要加粗的词全部临时取消，通读一遍，只把"最必须被记住的一句"加回去。
4. **人称漂移。** 一个自然段里"你"和"我们"切来切去。改稿通读扫人称。怎么办：定下主视角（教→你，品牌→我们），其余找到就改，允许统一用"你"到底。
5. **以为"口语=口水话"。** 口语化是句子短、句式顺，不等于加"啊呀嘛呢哈""懂的都懂"。那是另一种机器味。怎么办：删掉所有语气词后检查句子还顺不顺，顺的就是真口语，崩了的就是口水。
6. **连接词删了不接上下文。** 删掉"综上所述"后，前后两句要真接得上，不能生硬跳车。怎么办：删词后把前后两句连起来再读一遍，缺一层因果就补回一句人话过渡。
7. **把去 AI 味做成"改词游戏"。** 只扫词库、只盯高频词，不管整篇读起来像不像人说话。要在"读完像不像真人"的层面整体判断。怎么办：词库检查那步只作第一遍，第二遍整段朗读（或默读出声），只要有一处读着别扭就继续改。

## 五、自查要点

**句子与节奏：**
- [ ] 全文有没有一句超过 30 字？有就按"谁-做什么-结果"拆成短句，中间用逗号隔开。
- [ ] 每个自然段是不是只讲一件事？（一件事一段，别把三个意思塞进一段）
- [ ] 全文最长的句和最短的句，落差够明显吗？（节奏是否"有呼吸"见文风节奏）

**去 AI 味五连扫：**
- [ ] "省时间 / 涨粉 / 提升 / 高效 / 显著"这类虚词后，都跟了具体数字吗？
- [ ] 有"值得注意的是 / 综上所述 / 由此可见 / 首先其次最后 / 一方面另一方面"吗？
- [ ] 有"赋能 / 闭环 / 抓手 / 打造 / 颗粒度 / 底层逻辑 / 维度 / 深耕 / 破圈 / 降本增效"吗？
- [ ] 有连续的"不仅……而且……""不是……而是……"排比吗？
- [ ] 有没有把一件小事上升成大道理的"夸大象征"？有就撤，让细节自己说话。

**全局检查：**
- [ ] 一屏加粗超过 2 处、高亮超过 1 处了吗？有整段加粗吗？
- [ ] 人称"你 / 你们 / 我们 / 大家"从头到尾是一套吗？
- [ ] 全文留了一处"人味落点"（带情绪或带细节）吗？
- [ ] 把高频词和连接词全部删掉后，前后文还能自然接上吗？
- [ ] 通读一遍，能想象一个朋友当面跟你说这些话吗？

**终审口诀：** 三遍改完，大声（或默读）读一遍。任何一处你读着拗口、不像你自己会说的话，就回去改。直到"读起来自然"为止——这一条过了，其余都是细枝末节。

## 六、个性化空间

- **情感号**：可放松感叹号与语气词限制（感叹号细则见表达生动化），情绪词多一点无妨，但绝不飙 AI 高频词；人称多用"你"、少用"我们"，让读者代入。
- **极简号**：所有规则按最严执行——短句、零冗余标记、零连接词。句子可再短，3-5 个字的短句更出彩。人味落点更含蓄，往往是克制的一句。
- **文艺号**：短句规则放松为中长句，允许一点典雅书面词，但工商腔照禁。夸大象征容忍度可略高（文艺允许适度升华），前提是不整篇都是、且不空洞。
- **资讯/财经号**：口语化程度下调，句子可更长，数字具体化坚持执行（数据是生命线），连接词照样删。人味落点微乎其微也不违和。
- **儿童教育号**：可更活泼，但标记规则不松——儿童阅读更要少加粗、多留白，绝不用"这个功能赋能教育"式套话。
- **职场/管理号**：句子可比默认长一点（讲逻辑的地方允许长句），但"抓手 / 闭环 / 颗粒度 / 方法论"这类词是重灾区，必须换成大白话，否则内行读者一眼看穿。数字具体化对这类号尤其值钱。
- **生活方式/家居号**：最吃"人味落点和场景"，可用最大的力度去加细节和数字；高频词一个不留，"品质生活方式""美好生活"这类口号最招烦。

**调性速查表（默认 → 可放宽 → 严格收紧）**

| 账号调性 | 句子长短 | 口语化 | 语气词/感叹号 | 人味落点 | 标记数量 |
|---------|---------|--------|--------------|---------|---------|
| 热闹/情绪号 | 默认偏短 | 高 | 可多 | 必须有 | 默认 |
| 冷静/极简号 | 更短 | 中高 | 少 | 含蓄一点 | 少 |
| 文艺/散文号 | 中长 | 中 | 少 | 深一点 | 少 |
| 资讯/财经号 | 中长 | 低 | 几乎没有 | 可有可无 | 少、给数字 |
| 儿童/口播号 | 短 | 高 | 适中 | 必须有 | 默认上限 |

**判断准则**：红线（高频词、连接词、夸大象征、排比、整段加粗）是通用的，任何调性都该守；可变的是句子长短、口语化程度、语气词数量、人味落点浓度，这些随账号气质调整。改的时候**先守住"通用红线"，再调"可变量"去贴近账号人设**，两步都做完才定稿。红线是"内容能不能过关"的底线，可变量是"像不像这个号"的个性，缺一不可。
