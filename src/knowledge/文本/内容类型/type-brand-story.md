# 品牌故事（type-brand-story）

> 定位：讲品牌的初心、理念与历程，让读者从不信到认可"这个品牌相信什么、为什么值得尊重"，建立情感认同而非卖货。
> 调用时机：想让读者认识/认可一个品牌、为新品或里程碑站台、重塑或巩固品牌形象时。

---

## 一、类型定义与特征

品牌故事是**"交付理念认同"**的内容：通过叙述品牌创始的动机、走过的关键历程、坚持的价值观，让读者从理性了解走向情感认可。它的本质**不是卖产品**，而是**让读者认同"这个品牌为什么存在、它为谁坚持了什么"。**

### 核心特征

1. **以价值观为魂**：所有的故事都围绕"这个品牌相信什么"展开，一次选择、一次挣扎、一次取舍，都是为了印证一种理念。
2. **克制与真诚**：真正的品牌故事靠"做过的、经历过的"打动人，而不是靠形容词吹自己。自我吹嘘是它最大的敌人。
3. **有人、有情节、有细节**：价值观要靠具体的人和事撑起来——创始人的深夜、一次工艺的改良、坚持不涨价的决定。
4. **导向长期认同**：目标是让读者记住"这是个有理念的牌子"，愿意为它的理念买单、甚至为它辩护，而不是追求一次点击成交。
5. **有宣言感**：结尾往往落在一句能让人记住的"宣言"，像品牌的座右铭。

### 适用范围

- 品牌创立若干周年、里程碑节点；
- 品牌/产品发布会前的理念预热；
- 创始人专访式、品牌如何坚持某种品质/工艺；
- 品牌希望从"卖得动"升维到"被认可"时。

> 判断关键：核心是不是"讲品牌的理念与历程、让读者认可价值观"。如果是，就是品牌故事。它与 **人物故事**（type-person-story）的分界：重心是"品牌理念"还是"某个人的经历"；与 **产品软文**（type-soft）的分界：目标是"认可品牌"还是"想买产品"（详见 **类型全谱总览** type-catalog 第三节）。

## 二、标准结构骨架

> 三段式：**价值观 → 历程故事 → 宣言**。

### 阶段一：价值观（开场立住"相信什么"）

- **目标**：用一句话或一个细节，让读者立刻感到"这个品牌有点不一样，它有坚持"。
- **要点**：
  - 开场不炫耀成绩、不喊口号，而是抛出一个"源于一个朴素的想法"的起点；
  - 价值观要具体、可信，如"我们只是不想把廉价的东西卖给信任我们的人"；
  - 用创始人/团队的一句话引入，比自述更有温度。
- **篇幅建议**：全篇 15-20%。

### 阶段二：历程故事（用事件印证价值观）

- **目标**：用一个或几个真实经历，**让价值观在具体事件里立起来**，读者"眼见为实"地相信。
- **要点**：
  - 讲"真实做过的选择"：一次取舍、一次拒绝捷径、一次咬牙坚持；
  - 每个故事都要指向同一个价值观，别东讲一点西讲一点；
  - 有人、有冲突、有转机，读者被情节带动着理解品牌的坚持；
  - 克制描述，让事件本身说话，不额外添加自我表扬。
- **篇幅建议**：全篇 60-70%，是正文主体。

### 阶段三：宣言（收束到一句可记住的信念）

- **目标**：把前面的故事沉淀成一句"品牌宣言"，让读者带走一个想得起来、说得出口的信念。
- **要点**：
  - 宣言要短、真、可复述："把日子过好，把东西做好"；
  - 宣言回应开头的价值观，形成首尾呼应；
  - 结尾顺带一句"我们还在路上"或对未来/读者的期许，保持谦逊与开放。
- **篇幅建议**：全篇 10-15%。

## 三、写作要点（每条配示例）

### 1. 克制表达：让事件说话，而不是形容词吹自己

自我吹嘘最容易让读者反感。克制到"只陈述做了的事"，反而更显底气。

- 反例： "我们是最敬业、最有匠心、对品质有着极致追求的品牌，我们用了毕生心血……"（全是自夸）
- 正例： "第三批货发出去一周，我们收到 7 条差评都是同一个问题。团队连夜按原料批次追溯，最后决定：那批 300 件，召回重做。"（事件自己说话）

### 2. 价值观要具体，别喊抽象口号

"追求极致品质"谁都会喊，具体到"哪一个决定体现了品质"才立得住。

- 反例： "我们始终秉持极致匠心与高品质追求。"（抽象）
- 正例： "别人都用更便宜的辅料，我们只认这一种，成本贵三成。因为做出来的东西，手感差一点，我们心里过不去。"（具体到一个取舍）

### 3. 用人物和情节讲，别用说明书讲

价值观配一个"创始人当时怎么想"的瞬间，比列数据打动人。

- 反例： "本品牌成立以来，始终规范运营，重合同守信用。"（像报表）
- 正例： "第一次见供应商，对方问我们要不要用便宜的替代料。老板沉默了一会儿：'我家孩子也穿这种童装，我不愿意。'"（一个瞬间立住形象）

### 4. 承认困难与不完美，更显真实可信

一味报喜会假，敢讲"我们曾经也有过低谷/错误"反而更真。

- 反例： 只讲成功史、光环与荣誉。
- 正例： "我们也走过弯路——去年一度为了冲销量改了配方，结果老客户一眼就尝出来了。后来我们改回去了，还被骂了一顿，但值得。"（有起伏才像真的）

### 5. 宣言要有记忆点，能被读者复述

宣言是好故事能被带走的那句"话"，短而真。

- 反例： "我们将以最优质的产品回报每一位顾客的信任与厚爱。"（长且普通，记不住）
- 正例： "不偷工，不借力，把日子过厚。"（短、有态度、说得出口）

## 四、风格与模块建议

### 推荐风格

| 品牌气质 | 首选风格 | 理由 |
|---|---|---|
| 国货/老字号/文化品牌 | **国潮风** | 红金墨、庄重东方仪式感，匹配文化底蕴 |
| 前卫/极客/设计向品牌 | **极简风** | 大留白+克制，高级感，理念先行 |
| 时尚/观点/有态度的品牌 | **杂志编辑风** | 超大字号、编排感，宣言像杂志封面标题，有分量 |
| 生活/有温度的新消费品牌 | **手账风**或**日系风** | 温暖陪伴，降低"大厂感" |

> 风格细节与对应条目见 **风格维度索引**（index-style）；拿不准先读 **风格选择方法**（style-guide-choose）。

### 推荐模块组合

- **开头**：一句有分量的价值观/创始人引言（大字、大幅留白，见 **开头写法** copy-open）；
- **正文**：**时间线模块**（把创业关键节点排开，讲历程）+ 大幅留白/高级分割线（托住庄重与克制感，见 **花边分割模块** module）+ **引用框/金句模块**（把创始人关键时刻的话做成引用，module-quote）+ 人物/工艺大图（氛围感）；
- **结尾**：宣言大字 + 关注认同引导（**引导关注** module-followbar）；有条件可附品牌历程图文或主页入口。

## 五、常见错误（反例 + 正解）

### 错误 1：自我吹嘘，读者哈欠连天
- 反例： "我们是最棒的"式自夸，形容词砌墙，没有一件事作证。
- 正例： 克制陈述做过的事，让真实经历呈现品质，事件自己说话。

### 错误 2：价值观空喊口号，落不到具体事
- 反例： "极致匠心""突破创新""不忘初心"满天飞，却举不出一个印证的决定。
- 正例： 把价值观翻译成一个具体的取舍或选择：哪一点坚持、哪一次拒绝捷径。

### 错误 3：像企业年报/产品说明书
- 反例： 罗列成立年份、融资额、销量数据，通篇冷冰冰。
- 正例： 用人物、情节、细节把"为什么做、怎么坚持"讲出温度。

### 错误 4：只报喜、不认难，显得假
- 反例： 通篇成功与光环，没有任何挫折与低谷。
- 正例： 敢讲走过弯路、犯过错误、如何抉择，有起伏才真实可信。

### 错误 5：把品牌故事写成软文，硬塞产品卖点
- 反例： 讲着讲着变成"快来买我们的新品，全店 5 折"。
- 正例： 品牌故事重在理念认同，卖货交给别的类型（**产品软文**/活动促销）；真想顺带，也要放在自然收尾而非喧宾夺主。

## 六、示例骨架（可套用大纲）

```
标题：我们不偷工——一个童装厂的小小坚持

[价值观·开场]
做童装的头一晚，老板在厂里问自己：我家孩子也穿这种东西，
我做的东西，敢不敢给自己孩子穿？

[历程故事 1：一次留服]
第三批货发出去一周，收到 7 条差评，都是同一个问题。
团队连夜按批次追了原料，最后决定那 300 件全部召回重做。
成本大概白扔了几万块。老板说：衣服可以重做，信任坏了补不回来。

[历程故事 2：一次拒绝捷径]
有供应商说，换这种辅料能便宜三成，别担心没人看得出。
我们没用。因为我知道，手感差那么一点，做家长的一摸就明白。

[历程故事 3：一次改回去]
去年为了冲销量，我们偷偷改了配料。老客户一口就尝出来，
留言骂我们变味了。我们把配方改回去了——那阵子损失不小，
但值得。

[宣言]
不偷工，不借力，把日子过厚。
这些年我们没想追谁的速度，只想对得起每个把孩子交给我们的人。

[收尾]
故事还在写，东西还在做。谢谢一直相信我们的你们。
```

## 七、个性化空间（按账号自定的部分）

品牌故事最忌千篇一律的"伟大正确"，以下几处可按账号与品牌真实情况调：

- **叙事角度**：可创始人第一人称（有温度、更真）、可第三方编辑视角（更客观、更有报道感）、可匿名团队视角（突出集体坚持）。判断依据=账号想营造"个人情怀"还是"品牌整体"形象。
- **取材方向**：讲创始初心 / 一次危机如何渡过 / 一次工艺坚守 / 一项公益坚持。判断依据=哪个最能体现品牌当前想强调的价值观，别什么都讲。
- **篇幅**：可短宣言式（600 字、一个故事一个宣言）到长篇品牌列传（2000 字、多个故事串联）。判断依据=里程碑分量与读者耐心。
- **克制程度**：可"极端克制"（只陈述事实、留大量留白与想象空间）到"克制但有主旨议论"。判断依据=品牌调性越高端，越偏向留白少议论。
- **是否带产品/活动**：日常品牌故事可不带任何产品；里程碑/发布时可自然带出新品。判断依据=当前目标是"纯立理念"还是"理念+顺带预告"。若主要想卖货，应优先考虑 **产品软文** 或活动促销，别把品牌故事当广告写。

> 一句话原则：**品牌故事的全部价值，是让读者相信"这个品牌是有理念的，且说到做到"。** 它靠真实做过的事立起来，靠克制不夸大立住。具体讲哪个故事、多长、多克制，都由品牌真实的经历与当前的认同目标决定——但自我吹嘘、空喊口号这两条，任何情况下都要避开。
