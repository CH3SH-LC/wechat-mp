# 盘点清单

> 定位：把一堆同类对象罗列出来给读者挑，靠"选得准、排得好、每一条都值得看"留住人。
> 调用时机：整理"XX 个必做的 XX""XX 个宝藏去处""XX 本书/技巧"；做合集、攻略、资源包。凡是"标题带数字、正文一条一条列出来"的稿子，都是这一型。

## 一、类型定义与特征（详细）

**1. "盘点"的核心是三件事**

- 选什么：这条值不值得进这份清单，是取舍。
- 排第几：先后顺序是否合理，是排序。
- 每条写多满：这条的信息给得够不够，是详略。
- 三件事做对清单才有价值；做错任意一件，读者都会觉得"这份不行"。
- 好清单不是"把东西堆出来"，而是"帮读者决定先看哪个、哪个可以跳过"，是筛选器和导航。

**2. 它和教程、资讯的区别**

- 教程教读者"怎么做一件事"；清单只是"把好东西摆出来让他自取"。
- 资讯讲一件新事；清单一期讲一批旧物 / 资源。
- 读者看清单的心理是"想省时间凑齐好物"，所以清单的价值密度要比任何类型都高。
- 教程要"读完整篇才能用"；清单一期"读几条就能捞到想要的"。清单门槛更低，也更依赖"每一条都耐看"。

**3. 三个核心特征**

特征一：每一条都要"独立成立"。

- 读者可能只读其中三五条就划走了，所以每条都应自带完整小信息：是什么、好在哪、适合谁。
- 不能出现"第 6 条：还有一个很不错，具体不展开"这种半成品。
- 检验法：把每条单独发给朋友，他听到"这条在讲什么"时信息是否完整？不完整就补。

特征二：做一个"筛选器"而不是"搬运工"。

- 清单的含金量在于"你替我挑过了"。别人能搜到的都列进去 = 没有价值。
- 别人没列、你发现更冷门更好的 = 才有价值。筛掉平庸项、保留独特项，才是运营者该干的。
- 一个朴素标准：这份清单里有没有"自己用过 / 去过 / 看过、且真心想推荐的"？如果是网上能一键拿到的，先加工成自己的体验再写。

特征三：读者带着"我要用"的心在读。

- 清单不是陈列馆，是购物车。要让读者读着读着想直接收藏、转发给需要的朋友。
- 每条结尾最好落到"适合什么样的人 / 哪类场景"；一条"不知道给谁用的清单"读完只会被划走。

**4. 适用场景确认**

- 素材能凑出 5 条以上、彼此同类的对象；你动了"列出来"的念头，读者也"想一口气看完"——就够用。
- 凑不够 5 条、或对象属性差太远（书单混进优惠券），就不该用清单型，先去换类型或另攒素材。
- 清单是"攒出来的"，不是"凑出来的"。素材多而真的才建议做清单，为了更新硬凑一份反而伤口碑。

## 二、标准结构骨架（分阶段展开）

盘点清单用三段式：**总览 → 逐条 → 总结**。

**阶段一：总览（第 1-2 段）**

- 先说清"这一批是什么、按什么逻辑挑的、适合哪类读者"，给一个"门槛预告"和"看下去的理由"。
- 明确筛选口径："以下 8 本是我给准初中生挑的，只选国内能买到、家长陪读也读得懂的。"
- 给一个"价值承诺"：读完能省多少时间、解决什么问题。不要一上来就"开始第 1 条"，先让读者确认"这是给我列的"。
- 可预告这份清单的节奏（"入门 3 条 + 进阶 3 条""由贵到便宜"），读者知道结构更好扫。

**阶段二：逐条（主体，一个对象一段或一个卡片）**

- 每条遵循统一最简结构，扫读顺畅：名字 / 一句定位先亮出来（"第 3 条：XX 书店，主打二手童书"）→ 好在哪（区别于同类的点）→ 适合谁 / 什么时候用。
- 长度按 copy 维度"每条 40-120 字"节奏控制，重点的条可单独拉长；逐条版式尽量统一，让"扫条目"是享受。
- 可在中间自然插一句小分节（"前面 3 条给陪读型家长，后面 3 条给放手型家长"），帮读者重新对焦。

**阶段三：总结（结尾 1-2 段）**

- 收口这批东西合起来是什么；给使用顺序或优先级建议（"第一次入门先看 1、3、5"）。
- 引导评论补充："你还私藏了哪些？欢迎留言。"或转发给需要的人。
- 结尾给一个"从这份清单带走什么的抓手"，读者才觉没白看。
- 可补一句"如果只挑一个，我建议是第 X 条"，把精华再送一次，给读者一个"保险答案"。

## 三、写作要点（配示例）

要点 1：选取口径要统一。

- 攒条目前先问：这批东西共同的标准是什么？"适合学生的""本地能去的""百元以内的"？
- 反例："8 本适合小学生的书"混进一本家长看的育儿书。／正例：全部按"给孩子的书"口径挑，家长读物另起一期。
- 口径可以不止一个维度，但要在开头说清是哪几个叠加，别让读者自己猜。

要点 2：给"一个人一个抓手"。

- 每条至少有一个能让人"记住它的点"，否则就是凑数。
- 反例：这家书店环境不错，书也挺全。（环境好书全哪家不这样）／正例：第 2 家书店没有招牌，进门要按门铃，老板说"怕被人打扰"。
- 判断：把每条名字盖住，光看描述还能认出是哪家 / 哪本吗？认不出就是没抓手。

要点 3：推荐语落场景，不落空评价。

- "环境好"是空评价，"下雨天坐一下午也不累"是场景。场景里有"什么时候、什么感觉、什么体验"。
- 反例：这个文具店很好看，东西也全。／正例：开在 3 楼拐角，窗外就是老城巷子，挑本子能挑一整个下午。
- 场景越具体，读者越能"提前体验"，越容易收藏。

要点 4：写明"适合谁"，读者对号入座。

- 每条末尾补半句"适合……的人"，读者一眼就知道哪几条与他有关，直接跳到他那几条。
- 反例：这条书单很值得入。／正例：这条书单适合刚上小学、识字量还不大的孩子。
- 一个技巧：把同类"适合谁"收束成小分组（"3 条给学生 / 3 条给上班族"），比逐条零散写更有结构感。

要点 5：用具体数字 / 细节撑起可信度。

- "人均 30""藏书 2 万册""开在 3 楼拐角"比"性价比高""藏书丰富"更有说服力。
- 反例：这家店性价比很高。／正例：人均 30，这个价位能吃饱还有地方蹭空调。
- 数字要用得克制：需要支撑判断的用，纯粹填充别硬塞，免得"数字轰炸"。

要点 6：一条一个焦点。

- 一条里别堆三个好处，读者记不住；挑最独特的那个在亮点，其余一句带过。
- 反例：这家店价格合适、位置方便、老板人好、环境也好。（全而无当）／正例：最打动我的是老板按孩子年龄配书单。（一个焦点）
- 每条的"焦点句"决定读者会不会记住那一条。

## 四、风格与模块建议

风格优先考虑，按盘点对象气质挑：

1. 插画风——盘点活泼、好物、娱乐向，想热闹好看时用；高饱和撞色最衬"宝藏好物"。
2. 校园风——盘点学习 / 社团 / 校园去处，想要元气明快的校园感时用。
3. 复古港风——盘点老店、街巷、趣味打卡点，要胶片市井感时用。
4. 极简风——盘点对象偏理性 / 资源型时用，弱化装饰、突出每条信息。

模块上搭配使用：

- 引导钩子模块：放总览段，先给价值承诺。
- 顺序列表 / 编号胶囊标题：区分每个条目，编号醒目、先亮定位。
- 图片模块：多图条目配图，让每条有"看得到的样子"。
- 高亮卡片模块：把"最佳 / 最划算之选"单拎出来做本期主推。
- 图例 / 分类小标模块：给条目做"入门 / 进阶 / 学生向"分组，扫读有条理。
- 互动模块：结尾引导读者留言补充，形成评论区资源。

注意事项：逐条统一版式（同字号、同结构），只在标兵条目上做视觉强调，别让每条都花哨抢注意力；编号从头到尾连贯，不要中途跳号或重新计数。

## 五、常见错误（反例 + 正解）

错误 1：凑数充量。

- 反例："第 10 条：还有一个 App 听说不错，具体我没试。"凑数一眼穿帮，拉低前 9 条可信度。
- 正解：宁可 6 条每条都实，也不硬凑 10；写明"我只列了真实用过的 6 个"。
- 判断：某条写不满三句话给不出记忆点，多半在凑数。

错误 2：排序随意。

- 反例：第一条一般般，最强的一条藏在第 8 位无人注意。
- 正解：按"对目标读者最有用 → 越往后越边缘"排，或同维度归组（入门 / 进阶）。
- 判断：最好的放最后不是"悬念"是伤害判断力；主推要放前面或单独标出。

错误 3：选取口径不一致。

- 反例："8 本适合小学生的书"混进一本家长看的育儿书。
- 正解：口径统一为"给孩子的书"，家长读物另起一期或放入附录。
- 判断：每条自问"它和别的是不是同类"，不是就移除或单列。

错误 4：每条写空。

- 反例："环境好、内容全、很推荐"三连，读完全没印象。
- 正解：给每条一处具体记忆点（细节、数字、场景）。
- 判断：把一条发给朋友，问"记得住说的是什么吗"，记不住就是写空。

错误 5：全程不点人。

- 反例：通篇只说东西多好，不说这给什么人。／正解：每条结尾带一句"适合 XX 的人 / 那种场景用"。
- 判断：一段没有"适合谁"的条目，读者也不知道该不该看。

错误 6：只有"强烈推荐"没有理由。

- 反例：第 7 条我超级强烈推荐，闭眼入不会错！
- 正解：给理由——"第 7 条我用了一年还在回购，原因就两个字：不沉。"
- 判断："强烈推荐"是态度不是理由；每条都要补一个"因为哪一点"。

## 六、示例骨架（可套用大纲）

"盘点清单 · 校园风"骨架，可填空套用：

- 标题：暑假给孩子挑的 9 本桥梁书，附按年级怎么选
- 总览：说明"只选国内能买到、7-12 岁、从绘本过渡到章节书的孩子"，承诺"按这份顺一遍比你自己逛遍书城快"。
- 逐条（9 条）：每条统一结构——书名 + 一句定位 → 好在哪（一个记忆点）→ 适合几年级。最温和好入口的放第 1 条（入门），需要一定阅读量的放最后。
- 分组小标：可把 9 条拆成"入门 1-3 / 进阶 4-6 / 图多字少 7-9"三组配小标题，扫读更轻松。
- 高亮主推："第 5 条：XX 系列，字少图多，专治不爱看书"单独做成高亮卡片，做本期主推。
- 总结：给使用顺序——"第一次陪读从 1、3、5 开始；读完后按 7、8、9 递进"。
- 引导：再问"你家孩子最喜欢哪本？留言区聊聊"；结尾引导收藏 + 转发给挑书的家长群。

套用时可替换：把"桥梁书 / 7-12 岁"换成你的盘点对象与读者；把"按年级怎么选"换成你的排序逻辑；把"第 5 条主推"换成你最想推的；读者分层明显就加分组，单一则省。

另一版更偏"理性资源型"的可选骨架：

- 标题：给新入职的 8 个免费资料源，收藏这一篇就够
- 总览：说清"只要免费、能用、顺手"，承诺"按这份够撑过试用期"。
- 逐条：每条 = 名称 + 一句话 → 好在哪（一个使用场景）→ 适合什么时候用；好用的排前。
- 亮点条：把"最常用那个"单独高亮标"先用这个"。
- 总结：给一套"周一到周五分别用哪个"的安排，把清单变成可用清单。
- 说明：清单未必轻松活泼，资源 / 工具向走"实用可靠"同样成立。

## 七、个性化空间（按账号自定，附判断依据）

1. 条目数量：通常 5-15 条。预算 / 资源型可到 10-20，体验 / 情感型控制在 5-8。判断：对象够不够多、每条能不能写满记忆点——宁可少而精。
2. 排序逻辑：价值序（最有用的放前）、热度序（大家在用的放前）、逻辑序（入门到进阶）。判断：读者偏"快点挑最好"用价值序，"看大家都在用啥"用热度序，"一步步学会"用逻辑序。
3. 条目详略：前 1-2 条写满做主推，其余短条目，制造"王牌"。判断：是否有信心那一条确实最值得推——有才设主推，否则一律均等。
4. 风格选择：好物 / 娱乐向用插画，学习 / 校园向用校园，老城探店向用港风。判断：盘点对象整体气质匹配哪个最自然。
5. 是否设"主推条"：清单偏推荐单件（带货 / 重点安利）可设主推；纯信息盘点则均等。
6. 读者分层处理：读者群体明显分几类、条目梯度大就给条目分组（入门 / 进阶）；单一读者则逐条清爽。
7. 是否给"只挑一个"兜底：条数多、读者纠结时在结尾标"如果只选一个我选第 X 条"更贴心；条数少则不必。
