# 类型全谱总览（type-catalog）

> 定位：11 类内容的第一张对照总表，让你一眼看清它们各是什么、结构怎么摆、风格配什么。
> 调用时机：写推文第一步、还没确定类型时；看完这张表再决定读哪个类型条目的详细版。

---

## 一、为什么先要一张"类型总表"

公众号内容五花八门，但拆到底，写一篇推文其实是在回答一个问题：**读者为什么要点开我、读完后他得到什么。** 所有内容类型，本质都是"用一个结构，向一群特定读者交付一样东西"。

搞清类型之所以是第一步，是因为：

1. **类型决定结构骨架**——干货要分点讲步骤，资讯要结论先行，情感要最后升华，顺序颠倒了读者就懵。
2. **类型决定风格方向**——教人做事配科技/极简才显专业，抒发情感配手账/日系才显温度，卖东西配插画/国潮才热闹。
3. **类型决定话术边界**——公告通知不能煽情，软文不能胡吹，资讯不能带立场。

下面的总表把 11 类内容的关键信息压到一张表里，方便横向对比、快速锁定。

## 二、11 类内容总览对照表

> 这张表把**特征 / 结构 / 风格倾向 / 模块组合 / 常见错误**五栏并排，横向对比最能看出彼此差异。每栏都能单独用来"筛查"一个候选类型。

| # | 类型 | 一句话定位 | 特征关键词 | 结构骨架 | 风格倾向 | 常用模块 | 最常犯的错误 |
|---|---|---|---|---|---|---|---|
| 1 | 干货教程 | 教读者做好一件事、学会一个方法 | 步骤、方法、可操作 | 痛点 → 方法分点 → 案例 → 行动 | 科技/商务/极简 | 步骤/编号、卡片分组、图表、清单 | 只讲道理不给步骤、步骤太虚不能照做 |
| 2 | 新闻资讯 | 把新近发生的事实讲清楚 | 事实、时效、客观 | 倒金字塔：结论 → 细节 → 背景 | 商务/极简/报纸 | 时间线、数据图表、引用框 | 夹带个人观点、时效已过、标题党 |
| 3 | 情感随笔 | 写一段经历与感受，引发共鸣 | 场景、情绪、真实 | 场景 → 共鸣 → 升华 | 手账/日系/森系 | 手账贴纸、花边分割、金句引用 | 用大道理替代真实感受、矫情过头 |
| 4 | 产品软文 | 把产品放进生活场景，让读者觉得有用 | 场景、卖点、证言 | 场景 → 卖点 → 证言 → 行动 | 商务/日系/国潮（视产品） | 图卡/轮播、证言引用、自定义模块 | 硬广味重、卖点堆砌不讲场景、夸大功效 |
| 5 | 活动促销 | 告诉读者"现在买/参加很划算，快动手" | 利益点、优惠、限时 | 利益点 → 内容分点 → 规则 → 紧迫 → CTA | 插画/国潮/校园 | 倒计时、价格表、证言、按钮 | 规则含糊说不清、紧迫感造假、只催不陈利好 |
| 6 | 品牌故事 | 讲品牌的初心与历程，让读者认可理念 | 价值观、历程、宣言 | 价值观 → 历程故事 → 宣言 | 极简/国潮/杂志编辑 | 大幅留白、高级分割、宣言字 | 把品牌名硬塞成广告、没有真实故事支撑 |
| 7 | 人物故事 | 写一个人的经历，用细节立起形象 | 人物、细节、转折 | 引入 → 转折 → 细节 → 启示 | 杂志编辑/极简/手账 | 人物照片、引用对话、时间线 | 只写事迹不写细节、名人堆里无"人"味 |
| 8 | 盘点清单 | 把一堆东西按逻辑排开，供读者挑选收藏 | 罗列、排序、推荐 | 总览 → 逐条 → 总结 | 插画/杂志编辑/极简 | 编号清单、卡片网格、跳转链接 | 无筛选标准照搬、排序无逻辑、只罗列不点评 |
| 9 | 科普测评 | 解释原理、验证一个说法值不值得信 | 疑问、原理、证据 | 疑问 → 原理 → 验证 → 结论 | 科技/极简/森系 | 对比表、数据图、证据截图 | 只给结论不给证据、带立场预设立场 |
| 10 | 公告通知 | 把一件事、一套规则说明白 | 事项、时间、对象 | 事项 → 细节 → 联系方式 | 极简/报纸/商务 | 编号条目、注意事项、联系方式 | 关键信息藏太深、对象不分、误植煽情话术 |
| 11 | 连载栏目 | 一个固定栏目隔期更新，每期有承接 | 栏目、期数、悬念 | 栏目框架 + 每期变化点 | 视栏目内容而定 | 栏目头图、期数标识、预告模块 | 每期不衔接、栏目框架不统一、没悬念 |

> 说明：风格与模块栏给的是"偏好倾向"，不是硬性规定——同一类型可配多种风格，模块也可按内容调整。判断类型靠"特征 + 结构"，选风格与模块再单独进行（见风格索引、模块维度索引）。

## 三、最容易混淆的内容，怎么分

写手常在这几组之间卡住，先给"判定一把尺"（详细版见 **类型判断流程** type-choose）：

### 干货教程 vs 科普测评
- 干货教的是"**怎么做**"——给步骤、给方法，读者照着做就有结果。
- 科普讲的是"**为什么** / 对不对"——解释原理、给证据，回答一个疑问。
- 一句话分：读者是要"学会一个动作"（干货），还是要"知道一个真相"（科普）。

### 产品软文 vs 活动促销
- 软文推的是"这个产品本身"——讲场景、讲卖点、讲口碑，重点在"它好、适合你"。
- 促销推的是"这次活动划算"——讲优惠力度、限时规则，重点在"现在下手赚了"。
- 一句话分：核心卖点是"产品好用"（软文），还是"现在买便宜"（促销）。

### 品牌故事 vs 人物故事
- 品牌故事讲的是"品牌的理想要怎样世界变得更好"——重心在理念与品牌。
- 人物故事讲的是"某个人经历了什么、他怎么成长"——重心在个人命运。
- 一句话分：主角是品牌还是个人；用户记下的是"理念"还是"人物"。

### 新闻资讯 vs 科普测评
- 资讯报"新近发生的事实"——时效驱动、客观陈述，重点在"发生了什么"。
- 科普解"一个普遍疑问/说法"——原理驱动，重点在"为什么/对不对"。
- 一句话分：是"报新闻"（资讯）还是"验说法"（科普）。

### 情感随笔 vs 品牌故事
- 情感随笔是"一个人的真实感受"——主角是作者自己，表达情绪。
- 品牌故事是"一个品牌的理念史"——主角是品牌，表达价值观。
- 一句话分：写的是"我"（情感）还是"我们品牌"（品牌故事）。

> 都有点像的时候，别僵着选一个，去读 **类型混搭** 条目（type-mix）——它教你怎么定"主类型 + 辅类型"，让两样都表达好。

## 四、类型 → 风格 / 模块 / 文案速查

### 类型 → 风格速查

风格倾向不是"只能这样"，而是"这样最省力"。这里给的是首选与次选：

| 类型 | 首选风格 | 次选风格 | 一句理由 |
|---|---|---|---|
| 干货教程 | 科技 / 极简 | 商务 | 分点步骤要"清楚、可信"，少装饰 |
| 新闻资讯 | 商务 / 报纸 | 极简 | 客观中立，别用热闹风格抢事实 |
| 情感随笔 | 手账 / 日系 | 森系、治愈手绘 | 温柔陪伴，低饱和承载情绪 |
| 产品软文 | 商务 / 日系 | 国潮（视产品） | 视品类让可信/温暖/格调各取所长 |
| 活动促销 | 插画 / 国潮 | 校园、孟菲斯 | 热闹刺激冲动，风格越"冲"越搭 |
| 品牌故事 | 极简 / 杂志编辑 | 国潮 | 留白与编辑感立"理念的分量" |
| 人物故事 | 杂志编辑 / 极简 | 手账 | 编辑感立"采访质感"，细节借手账温柔 |
| 盘点清单 | 插画 / 杂志编辑 | 极简 | 条目多，亮色与编号卡让"可读、可摘" |
| 科普测评 | 科技 / 极简 | 森系 | 数据与原理要"可信、清爽" |
| 公告通知 | 极简 / 报纸 | 商务 | 清晰完整第一，别用花哨喧宾 |
| 连载栏目 | 视栏目内容而定 | — | 随栏目主题走，但保持跨期统一 |

### 类型 → 文案调性速查

| 类型 | 语气关键词 | 一句话例 |
|---|---|---|
| 干货教程 | 老师、清楚、直接 | "第三步，把参数调到 X，就能看到结果。" |
| 新闻资讯 | 记者、冷静、克制 | "据通报，事件发生在今晨，暂无人员伤亡。" |
| 情感随笔 | 朋友、真诚、走心 | "那晚我坐在窗边，忽然觉得时间很慢。" |
| 产品软文 | 推荐好物的朋友、专家 | "用了两周，才敢把这款枕头推给你。" |
| 活动促销 | 导购、热情、直接 | "限时 3 天，现在下单立减 50，别错过。" |
| 品牌故事 | 创始人/编辑、有分量 | "做这盏灯，是因为我们相信慢工出细活。" |
| 人物故事 | 说书人、有画面 | "三年前他还是个快递员，如今在南极拍企鹅。" |
| 盘点清单 | 指南、条理清晰 | "这 8 份免费资源，够你把 PPT 学到入门。" |
| 科普测评 | 求证者、严谨耐心 | "褪黑素到底有没有用？我们查了 5 份论文。" |
| 公告通知 | 官方、清晰完整 | "本期课程改期至 3 月 10 日，详见以下安排。" |
| 连载栏目 | 常驻主播、有仪式感 | "欢迎回到家书第 12 期，上期你读到哪儿了？" |

## 五、类型不是模具，是方向盘

需要反复记住的一句话：**类型只是让内容事半功倍的"方向"，不是把每个人框死的"模板"。**

- **同一主题可以换类型写**：比如"睡眠"这个主题——可以写成干货（怎么睡得更好）、科普（褪黑素有用吗）、情感（深夜失眠的独白）、软文（助眠枕头值不值得买）。换类型等于换了一个给读者的"交付承诺"。
- **可以定一个主类型 + 一个辅类型**：比如"品牌故事 + 干货教程"——先用故事立理念，再顺手给干货。谁主谁次看读者的核心诉求。
- **同一类型可以大改**：篇幅可长可短、口吻可冷可热、结构可松可紧——这些是每个类型条目最后"个性化空间"部分的重点，也是账号自己发挥的地方。

> 类型条目（type-tutorial、type-news 等）里都有一段"个性化空间"，专门讲哪些能按账号调。判断依据永远是同一个：**读者读完你希望他听到什么、记住什么、去做什么。**

## 六、速查用法说明（怎么用这张表）

1. **先定类型再读大表**：不确定类型时，先读 **类型判断流程**（type-choose）按步骤归到 11 类之一，再回到本表看它的结构/风格/模块。
2. **用"最常犯的错误"栏自查**：写完初稿后，回看自己类型的"错误栏"逐条比对，能少踩太多坑。
3. **用"结构骨架"栏搭主框架**：按最简主干起稿，细节照应到具体类型条目展开。
4. **风格与模块"按需选配"**：表里的倾向只是起点，最终搭配交给风格索引与模块索引，别被倾向框死。
5. **两类像时看第三节**：易混判别给的是"一句判定尺"，更细的主辅关系看 **类型混搭**（type-mix）。
