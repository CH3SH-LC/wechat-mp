# 类型判断流程（type-choose）

> 定位：拿到写作任务、拿不准"这篇是什么类型"时，用这套流程把任务归到 11 类之一。
> 调用时机：任何「要做内容但类型不明确」的情况；也是新手写手训练归类手感的方法。

---

## 一、凭什么要先判断类型

因为你交出去的东西，结构、语气、包装全由类型决定。同一个选题：

- 读者想学方法 → 你该给干货，别写成打广告；
- 读者想知道新鲜事 → 你该给新闻，别夹带观点；
- 读者想被触动 → 你该写情感，别满篇讲道理。

判断类型不是学术练习，是**对准读者的期待**。判断错了，前面写得再好也是"答非所问"。这一决策全靠任务里已有的信息（读者、内容、目的、场合），不需要额外调研。

流程共 4-5 步，每步都给你**要问自己的问题**和**判断标准**。慢慢走一遍，别凭感觉跳步。

---

## 二、五步判断流程

### 第 1 步：读者是谁、他要什么

先搞清楚这篇是写给谁看的、他们在什么情境下打开。

- **提问**：读者是谁？他此刻在焦虑什么、想解决什么、想了解什么、想被什么打动？
- **判断标准**：抓"读者关心的事"——是想省时间学方法，还是想了解刚发生的事，还是想寻求认同，还是正打算买东西。
- **示例**：
  - 读者是"刚入门想学做手冲咖啡的人" → 他要的是方法，偏向教程/科普；
  - 读者是"失眠一整夜、想找人懂我的人" → 他要的是共鸣，偏向情感。
- **常见的坑**：用"我要写什么"代替"读者要什么"。先把读者念三遍，再动笔，判断就稳了一半。

### 第 2 步：内容目的是什么

这一步是核心。用动词想清楚：你写完这篇文章，**希望读者大脑里发生什么变化**。

| 目的动词 | 读者变化 | 对应类型方向 |
|---|---|---|
| 教（教他方法） | 学会怎么做某件事 | 干货教程 |
| 告知（告诉他事实） | 知道一个新鲜事 | 新闻资讯 |
| 打动人（触动他的情绪） | 心里被戳中、有共鸣 | 情感随笔 |
| 卖产品（让他想买） | 觉得这产品适合我 | 产品软文 |
| 卖优惠（让他想现在买） | 觉得现在买划算 | 活动促销 |
| 让人认可品牌 | 觉得这个品牌有理念、可信 | 品牌故事 |
| 让人记一个人 | 记住某人的经历与品质 | 人物故事 |
| 让人收藏挑选 | 愿意存下这份清单 | 盘点清单 |
| 让人信一个结论 | 认可这个说法有依据 | 科普测评 |
| 通知一件事 | 清楚知道事项与规则 | 公告通知 |
| 让人持续追更 | 期待下一期 | 连载栏目 |

- **提问**：用一句话写下来——"我想让读者（动词）+（具体变化）。"
- **判断标准**：目的动词一旦写清楚，候选类型通常只剩 1-2 个。这一步是五步里最该停下来多想的一步。
- **示例**："我想让读者**学会**三步做出拿铁" → 干货；"我想让读者**觉得**褪黑素这事有说法" → 科普；"我想让读者**愿意**存下这 10 个旅行清单" → 盘点。
- **常见陷阱**：写完句子发现动词是"让读者开心/关注我"——这不是类型，是运营目标。要落到"读者因为这篇内容发生了什么具体变化"上。

### 第 3 步：对照特征表归类

用上一步锁定的 1-2 个候选，去对照 **类型全谱总览**（type-catalog）特征列的关键词，确认匹配。

- **看内容原生样子**：内容本身就是"步骤清单/新闻稿/一段经历/产品介绍/活动信息/理念宣言/人物传记/推荐列表/原理讲解/官方通知"？
- **判断标准**：内容"天生像什么"和"你想让它达成什么目的"，两个维度要对上。若对不上，多半是当前设想有问题，回到第 2 步重想目的。
- **示例**：若内容天生是一篇"测评对比表"，但你的目的是"让读者学会怎么挑"——这更接近干货或科普，需要确认主体是"给步骤"还是"给原理"，别让"测评"这个词把你的归带偏到五花八门。

### 第 4 步：确认有没有混搭需求

有些内容天生带着"两副面孔"。比如：先讲故事引出产品（品牌+软文）、科普完给购买建议（科普+软文）、促销文里夹几段故事（促销+品牌）。

- **提问**：这篇是不是同时要"达成两件事"？哪件是读者主要诉求、哪件是顺手带出的？
- **判断标准**：确定一个**主类型**（读者第一诉求），可选一个**辅类型**（次要诉求）。主辅次序就是内容的表达次序：先满足主的，再满足辅的。
- **示例**："先讲这段一路研发的故事，再顺势推这款产品" → 主类型=品牌故事（让读者认可理念），辅类型=产品软文（顺势转化）。
- **兜底**：混搭规则详见 **类型混搭** 条目（type-mix）。没有混搭需求就直接锁定单类型。

### 第 5 步：锁定类型，记下判断依据

写出最终答案："这篇是 **干货教程**，主目的=教读者学会 X，读者=Y，辅类型=无。" 并把依据写进你的写作红线里——它提醒你后面别跑偏。

这样做的价值：写作中途一旦迷茫（"该煽情吗""该上优惠吗"），回头读这句判断依据，就知道该回到哪条轨道。

- **示例句**："这篇是干货教程，主目的=教读者三步做手冲，读者=手冲小白，辅=无。所以结构走步骤、语气走老师、风格走极简，不煽情不卖萌。" 一句话把判断依据锁死，全篇不动摇。

## 三、每步给调用方/写手的快捷提问卡

| 步骤 | 一句话快问 | 若答案是 |
|---|---|---|
| 1 读者 | "读者此刻最想要什么？" | 方法→教程；事实→资讯；共鸣→情感；产品→软文；优惠→促销 |
| 2 目的 | "写完希望读者发生什么变化？" | 学会→教程；知道→资讯；感动→情感；想买→软文/促销 |
| 3 对照 | "内容天生像哪一类？" | 对得上照表归；对不上回去改目的 |
| 4 混搭 | "是不是要一次办两件事？" | 是→定主辅；否→单类型 |
| 5 锁定 | "结论+依据是什么？" | 写下来，写作中常回头对照 |

## 四、拿不准时的兜底规则

判断卡壳很常见，按下面顺序兜底，别硬挣扎：

1. **两个类型都像，且分不出主次** → 以"读者读完最想要的那一样"为主。想不出读者想要什么，就说明这个选题本身读者不明确，先回头把读者定清楚再写。
2. **信息实在不够判断** → 不要硬猜。先做"读者最可能的期待"假设，写一个最稳妥的类型，并在交付时说明"因信息不足，按 X 类型处理，读者/场合若不同需换 Y"。宁可明确标注假设，也不要假装确定。
3. **内容横跨太多类型** → 绝大多数情况下不是写手"要不要都写"的问题，而是**这题本身选题太大**。回到选题维度（index-topic）把主题收窄，聚焦读者最核心的一个诉求。
4. **判断完毕发现类型吃力** → 换个类型写同一个主题是允许的，甚至常是解法。比如"想推产品又不想太硬"就换成产品软文而不是活动促销。类型只是方向，同一主题换方向别怕。
5. **对着表还是觉得两可** → 把两个候选的"一句话定位"和"结构骨架"并排写下，用更靠前的那一栏"读者最想要的东西"来裁判——能定出主辅就按主辅走（type-mix），真分不出再回到第 2 步改目的。

> 兜底背后的总原则：**读者第一诉求 > 内容天生样子 > 写手个人偏好。** 任何纠结都用这条排座次。

**怎么把顺序记住**：先问"读者最想看哪个"→ 再问"内容天生更像哪个"→ 最后才轮到"我想写成哪个"。前两条都确定不了时，问题多半不在归类，而在选题本身太宽，先收窄主题再回来归。

## 五、常见归类错误（新手最易踩）

1. **看到"推荐"就当盘点**：盘点清单是"一堆可挑选的东西"；但"只推荐 1 个核心产品并深入讲"更接近软文。看数量与深度——罗列多→盘点，深耕一项→软文/干货。
2. **看到"测评"就当科普**：科技测评常讲原理，但"测出来这个更好，告诉你选哪个"可能偏盘点或软文；科普的核心是"解一个疑问、给一套依据"，别被"测评"二字带偏。
3. **看到"讲一个故事"就当品牌/人物**：先确认主角是"品牌/理念"还是"某个人"；主角也不是两者时，"讲故事的气氛"还可能让内容更接近情感随笔。
4. **看到"有优惠"就当活动促销**：促销的核心是"此刻划算、给你规则、催你行动"；若这只是顺带一句"可领优惠"而主体在讲产品价值，那是软文。
5. **把"栏目化"误解成连载**：连载栏目靠固定框架 + 跨期悬念连续更新；若只是"这篇发了同一主题系列的一期"而彼此不衔接、无悬念，不一定是 true 连载（看是否长期承诺）。
6. **看到"讲解一段流程"就当干货**：若读者要的不是"照着做一遍"，而是"了解这件事怎么运转以增见识"，可能接近科普或资讯——先问读者是要"技能"还是"知识"。
7. **看到"官方声明"就完全套通知模板**：若内容是重大/危机沟通，需要情感温度与立场，那可能是"公告 + 情感"的混搭而不该纯用冷冰冰的通知（走 type-mix 定主辅）。
8. **一碰到"总结今日"就当情感**：生活中的事件复盘可能是干货（方法复盘）、科普（现象解释）甚至资讯（今日要闻）——别因为"写了感受"就默认情感，先看主体的交付物是什么。

## 六、完整走一遍示例

**任务题面**：「公司下周有一次周年庆促销，想发一篇公众号告诉粉丝有折扣，但又不想太像广告、希望有点人情味。」

- 第 1 步：读者是粉丝老顾客/潜在顾客，他们想看"有没有便宜可捡"，但也讨厌硬广。
- 第 2 步：目的既有"告诉有折扣"（告知/促销），又有"别让读者反感、有点温度"（情感/品牌）。
- 第 3 步：对照类型表——"活动信息+优惠力度"符合 **活动促销**；"有人情味"是辅色，不是主。
- 第 4 步：确认混搭：主=活动促销（读者核心诉求是优惠），辅=品牌温度（降低广告感）。
- 第 5 步：锁定：**主：活动促销；辅：品牌故事**。判断依据=读者要优惠但反感硬广，先用品牌温度铺垫再上促销手法。

> 这样判断后，去读 **活动促销**（type-promo）做结构，必要时参考 **品牌故事**（type-brand-story）做开头温度，再按 **类型混搭**（type-mix）排主辅次序。

**为什么这个例子要记**：它示范了"判断不是非此即彼"——同一个题面可以有主有辅，只要先锁定读者最想要的那一头（要优惠），另一头（要温度）当作辅助来服务主类型。遇到"什么都像"的任务，都可以照这个"先主后辅"的办法解，而不是硬删掉一个维度。

## 七、这个流程的边界（个性化空间）

判断流程给的是"归类骨架"，但有几个地方**永远要结合账号情况**：

- **读者画像优先**：每个账号的读者需求不同，同一内容的类型判断可以不同。判断依据写进红线，比套模板更重要。
- **账号调性可压类型**：一个走极简高冷的账号，即便内容本质是"促销"，也会更靠近"克制版促销"；一个走活泼插画的账号同理。类型定方向，账号定温度。
- **别为流程而流程**：老手一眼认清类型可直接跳步，兜底规则只在卡壳时用。流程是训练工具，不是每次的必经仪式。
- **判断可随读者变化而改**：同一条内容在第一期读者反应不符预期时，可换类型重写——方向是活的，读者反馈是最终裁判。
- **别一次判断就焊死**：类型是"这一篇的交付承诺"，同一账号下一期完全可以换类型。今天写干货不等于永远只写干货，判断流程每次任务都该重新走一遍。
