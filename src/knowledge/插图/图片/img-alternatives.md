# 无图替代方案（没有合适图片时怎么办）

> 定位：找不到合适照片/版权不允许/内容本身不该配图时，用低饱和纯色块+细边框+文字、数据图表、装饰花纹、艺术资产、截图示意来"撑起版面"，并协调成与正文一致的风格；也讲清什么时候值得自制图而非用替代。本号正文一律零 emoji，emoji 拼图仅作平台版的例外选项，公众号内不使用。本篇是「图片插入组件」链条的收尾环（**找不到可插之图时**的替代方案）。
> 调用时机：找图环节发现无合适图片、或该处内容不需要真实照片时。

## 一、什么时候用替代

替代不只是"退而求其次"，有些场景**本来就不适合放照片**，替代是更优解：

- **抽象概念 / 流程说明**：讲观念、讲步骤，配照片反而误导 → 用图表/色块/步骤卡。
- **数据表现**：有数值要传达 → 用数据图表（柱/饼/折线），比照片准。
- **版权 / 时效顾虑**：没有合适的可商用图 → 用无版权风险的替代。
- **极简 / 纯文字风**：某些文字号故意不用图 → 用装饰性元素补呼吸感。
- 反例：日常/产品/事件类的**具体场景**，用照片仍是最佳，别强行上替代。

**给"要不要用替代"的一张决策小表：**
| 内容要传达… | 首选方案 | 说明 |
|---|---|---|
| 一个具体场景/外观/人物事件 | 照片（图库/自制/投稿） | 千万别用替代顶替 |
| 一个抽象概念/观点 | 纯色块+一句标语 / 图标 | 替代很合适 |
| 一个流程/步骤 | 步骤卡/流程图 | 替代或自制 |
| 一组数据/占比/趋势 | 数据图表 | 替代（图表）是最佳 |
| 只是"这一屏别太空" | 分割线/留白/装饰纹理 | 替代补排版 |

**再补一条"别乱替代"的红线：** 如果这处图位**承载信息、读者要从图里读内容**（产品外观、地图、实际界面），就不能用纯色块/图标顶替——那种位用替代等于丢信息。只有"非信息位"才适合用替代。

**一个判断口诀：** 问"这个位置放照片，是必须的吗？"——承载**具体场景、真实外观、人物/事件**的，是（用照片）；承载**概念、流程、数据、氛围**的，不是（用替代/自制）。答案清晰，选型就不纠结。

## 二、替代方案的品类清单（做法 + 适用）

**1. 低饱和纯色块 + 细边框 + 文字**
- 做法：一块低饱和纯色矩形、加一圈 1px 细边框，居中放一行大字（标题/要点），圆角、边框见"图片处理规范"。配色与品牌/深色模式协调，不用渐变、不用阴影。
- 适用：章节分隔、要点强调、无图但有标语。
- 注意：色块上的文字要满足对比与深色模式（见"对比度" "深色模式"条目）。

**2. 数据图表**
- 做法：用表格工具/设计工具把数值做成柱状/饼/折线图，导出为图；或用 HTML 表格（微信表格支持有限，建议截图转图）。
- 适用：趋势、占比、对比数据。
- 注意：图表标注数值标签，不仅靠颜色分组（见"对比度与色弱"的色弱原则）。

**3. 图标 / 图示组合（公众号内零 emoji）**
- 做法：用纯色小块/线框图标 + 文字的组合排成图；emoji 拼图仅在平台版（如小红书）可作例外，公众号正文一律不用（见跨平台条目）。
- 适用：轻松氛围、生活化装饰、替代小装饰图。
- 注意：emoji 在不同设备显示不同，跨 iOS/安卓效果有差异，别用它承载严肃关键信息；本号公众号内直接不使用 emoji 替代。

**4. 装饰花纹 / 艺术资产**
- 做法：用分割线、花纹（花边、竖线、几何纹）、上色卡条、留白加大来营造装饰，替代掉"为图文而图文"的图片位（见模块节奏）。
- 适用：过渡、分隔、氛围补位的非信息位。
- 注意：装饰要克制，别满屏花纹抢正文；与"模块节奏"条目的锚点思想一致。

**5. 艺术资产**
- 做法：可商用插画/矢量素材（来源照"图片来源""版权确认流程"），或自制插画元素。
- 适用：选题是插画风、需要统一视觉的配图。
- 注意：用素材仍要走版权确认（同照片）。

**6. 截图示意**
- 做法：把相关界面/文档截成图（敏感信息打码），配框/圆角统一风格。
- 适用：教程、软件说明、资料引证。
- 注意：截图属"图"，同样用"图片处理规范"做尺寸/清晰度/统一处理；涉及他人内容的截图注意版权与授权。

**7. 图标列表 / 编号卡（补充）**
- 做法：给并列要点配"数字图标 + 短标题 + 一段说明"的卡片排布，替代"要并列但没照片"的图位。
- 适用：并列要点、原则、清单类内容。
- 注意：编号要连续、字号与正文层级一致；别把每个要点都做成大色块卡片，重点卡住关键处即可。

## 三、替代方案与正文风格的协调

- **色调统一**：替代元素的底色/文字色取自本篇主色或品牌色（见 style/ 风格条目），与正文一致；别冒出"本篇从未出现的颜色"。
- **圆角/边框/留白统一**：替代块沿用正文图的那套参数（圆角 8px、细描边 1px、留白 16px），看起"成套"。
- **节奏一致**：替代元素承担的锚点/分隔功能与正文需要的节奏匹配（见"长文阅读节奏"）。
- **克制原则**：替代是为了"补排版"，不是为了让版面更花哨；满屏都是色块/装饰会盖过正文。

**生成替代元素前，先定一张"样式基表"（照着统一做）：**
| 参数 | 建议起点 | 怎么调 |
|---|---|---|
| 色板 | 本篇主色/品牌色 1–2 个 + 一个中性灰 | 只在"主色+中性色"里取，别乱加新色 |
| 圆角 | 8px（与正文图一致） | 卡片 8–10px，装饰条可直角 |
| 边框 | 有则统一 1px 细描边，无则都不加 | 和正文图同步 |
| 阴影 | 一律不用（低饱和纯色 + 细边框 + 留白） | 不依赖阴影分层 |
| 字体/字重 | 与正文同一家族 | 色块内用加粗短句 |
| 字号上限 | 色块内大字 16–20px | 大语句用"短句 + 大字"，别铺长文 |
| 上下留白 | 与图片来源相同的 16px 间距 | 守住 00-GUIDE 间距规范 |

**协调自检（可操作）：** 把所有替代元素和正文里的真图放一起扫一遍——它们是否"看着像同一套"。圆角一致吗、色板一致吗、字重一致吗？任何一样明显"跳出来"的元素，就是没协调好，回头统一它。

## 四、何时值得自制图而非替代

以下情况，自制一张小图比用替代更值得：

1. **关键信息的承载**：配一张"自制示意图/流程图"比纯色块更能讲清因果——自制图明确传达信息，替代只能撑版面。
2. **品牌辨识度高**：自制一套"统一风格的封面/题图/栏目 banner"能建立强识别，替代元素做不到。
3. **高流量/常青内容**：一篇反复被转发引用的干货，值得自制一张能作为"素材被转载"的正式图。
4. **内容的"记忆点"**：有些点配一张自制创意图比文字版式更能让人记住。

**判断依据：** 看这个图位是否**承载信息/品牌/记忆点**——是，则自制；只是"不能留白"的排版位，则用替代即可。

**给三档阈值：** 1 只是"这页别太空" → 纯色块/分割线替代即可；2 要讲清一个因果/流程 → 自制示意图/流程图；3 要当号的门面、反复被转发 → 自制正式 banner/信息图。成本依次升高，价值也依次升高，别在小排版位上投入大自制。

## 五、示例

**方案选型示例：**
- 讲"三步流程"无照片 → 用"步骤卡/流程色块 + 数字"（替代方案 1）比随手找三张无关图好。
- 讲"用户年龄占比" → 做一张饼图（方案 2），比放一张人群照片准确。
- 每章之间 → 用一条花纹分割线（方案 4）撑出节奏，不必硬塞图。
- 并列"三个原则" → 用编号卡（方案 7）逐一排开，好扫读。
- 选题是"开工指南" → 自制一张**信息图 banner**（自制），承载核心步骤，成记忆点。

**不合格反例：** 讲"数据分析"却配一张咖啡杯照片（不相关）；某章节该讲流程却用装饰图排字代替图表（信息承载不足）；满屏五颜六色色块盖过正文（不克制）。

**一套"能直接拆走用"的组合示范（约 1200 字科普文）：**
- 开头"本概念是什么" → 纯色块 + 一句话定义（方案 1）；
- 中间"分三小步怎么做" → 三步编号卡（方案 7）+ 每卡一行说明；
- "数据佐证" → 柱状/饼图一张（方案 2）；
- 每章切换 → 花纹分割线（方案 4）；
- 结尾"一图说清全文" → 自制一张信息图（自制）。
——全文无一张照片，但版面有节奏、重点有载体，比硬塞无关图强得多。

## 六、常见错误

1. **找不到图就硬塞一张无关照片** —— 反例：图不承载信息、和正文割裂。正解：用替代方案或自制承载信息。
2. **用替代但风格完全不一致** —— 反例：色块色和正文色毫无关系、圆角不同。正解：替代元素沿用本篇配色+圆角/边框统一。
3. **装饰图标承载关键信息** —— 反例：跨设备显示不同、严肃信息失真。正解：本号公众号内零 emoji，关键信息一律用文字/图表；装饰只用纯色块/线条。
4. **装饰过度、满屏花纹** —— 反例：抢正文、视觉噪。正解：装饰克制，替代元素为补节奏而非炫技。
5. **该做图表/自制信息图时只放纯色块** —— 反例：有数据有流程却不给可视化承载。正解：关键信息位用图表或自制图，纯色块只做排版位。
6. **替代元素和真图"两种世界"** —— 反例：真图圆角 8px、替代块圆角 20px 且配色突兀。正解：替代与真图同套参数，扫一眼"成套"。
7. **该自制却用替代省事** —— 反例：关键的流程/品牌门面用色块顶，没建立识别。正解：按第四节的阈值，去自制而非顶替。
8. **替代元素间距对不上** —— 反例：替代块上下留白和来源图片不一致，看着忽密忽疏。正解：替代与真图用同一套间距（对照"样式基表"里"上下留白"一行）。
9. **在所有图位都用同一种替代** —— 反例：全文只一种色块/只一种装饰符号，单调没有层次。正解：按内容类型混用"色块 + 步骤卡 + 数据图 + 分割线"，既有变化又不乱。

**自查补充：** 自查时把"图位是否承载信息"再问一遍——凡是信息位的替代，正文里都要有对应的可视化（图表/图示/流程图），而不是一句空话顶一张图。

## 七、自查要点（可勾选）

- [ ] 无合适图片来源时，优先选替代/自制，没有硬塞无关照片
- [ ] 承载信息/数据的图位用了图表或自制图，而非纯装饰
- [ ] 替代元素的配色/圆角/边框与正文一致，样式统一
- [ ] emoji/图标未用于承载严肃关键信息（公众号内零 emoji）
- [ ] 装饰元素克制，没有抢正文
- [ ] 版权无风险的替代（色块/自制/通用图标）未引入新的授权问题
- [ ] 截图替代已完成敏感信息打码
- [ ] 该承载信息/品牌/记忆点的图位已按需自制，未用替代顶替
- [ ] 替代元素与真图间距一致，无忽密忽疏
- [ ] 全文替代方案有类型变化（色块/步骤卡/数据图/分割线混用），不单一

## 八、个性化空间

- **替代的整体风格**：文艺号可偏重"花纹 + 留白 + 低饱和纯色块"，科技号可偏重"纯色块 + 数据图表 + 线性线框图标"。判断依据：品牌视觉基调（见 style/）。
- **是否用 emoji**：本号公众号正文一律零 emoji，跨平台版（如小红书）可少量保留；判断依据：读者群体与内容严肃度，以及是否在公众号内。
- **自制图的投入度**：有设计能力的号可为常青内容自制信息图建立记忆点；资源紧的号用统一风格色块+表格即可。判断依据：人力成本与内容复用价值。
- **替代与照片的比例**：视觉型账号努力用照片充分撑版面，替代仅补位；纯文字策略账号可全篇无真实照片全靠替代元素营造风格。判断依据：账号对"图文并茂"的产品定位。
- **编号卡的密度**：干货教程可把每个小节都用编号卡排开，扫读友好；情感长文只在关键"要点/清单"处用一个大卡，避免卡片化过重。判断依据：内容的步骤/清单属性 vs 沉浸叙事属性。
- **是否用数据图表之外的可视化**：偏好轻量的号可用"大数字 + 一句说明"的色块替代复杂图表；需要严谨呈现的号仍用标准柱/饼图。判断依据：内容的数据严谨度 vs 版面的轻快感。
