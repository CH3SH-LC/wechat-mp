# 无合适图片时的呈现选择

没有相关、可使用的图片时，可以保留文字，也可以在确有表达需要时制作图表、示意图或装饰插画。不要为了填满版面放无关图片，不把完整说明改成标语或碎句来适应图位。

## 按信息用途选择

| 内容用途 | 可用呈现 | 需要保留的信息 |
|---|---|---|
| 真实产品、界面、人物或事件 | 有依据的照片或截图；材料不足时保留文字说明 | 真实外观与来源，不能用装饰图冒充 |
| 因果、步骤、关系 | 示意图、流程图或完整文字 | 条件、方向与必要解释，不能为节点紧凑删掉关系 |
| 数值、占比、趋势 | 有来源的数据图表 | 数值、单位、口径与来源，不能编数据补图 |
| 并列项目 | 无底色编号、线框图标或普通分节 | 每项完整说明，不要求一行写完 |
| 章节区分、视觉氛围 | 线饰、留白、纹样或艺术插画 | 装饰不承载未知事实，也不规定正文句式 |

## 呈现方式

- 图表除颜色外还应使用文字标签，避免仅靠颜色区分数据。图表内容要与正文一致；交给当前引擎支持的图表或图片能力生成，不临时输出旧 HTML 组件。
- 步骤、列表可以编号。说明较长时让文字自然展开，或改用普通段落；不要把同一意思切成多张卡，也不要压成“短句＋大字”。
- 装饰可用细线、花纹、几何图形、线框图标与插画。明丽风格可以增加色彩和图案的变化，极简风格可以减少装饰，两者都须让文字易读。
- 正文容器可选协议浅底或无底，不用渐变或阴影；色彩可用于文字、线饰和独立插画。公众号内不使用 emoji。
- 截图用于界面说明或资料引证时，应保留需要说明的内容，按图片处理规则保证清晰度，并处理敏感信息。来源、授权与引用要求见图片来源和版权条目。
- 艺术资产可以统一文章的视觉语言，但不能伪装为活动现场、产品实物或使用成果；素材来源按同样的核验流程处理。

## 与文章风格协调

| 参数 | 处理原则 |
|---|---|
| 配色 | 从本篇色板选择文字、线饰和插画颜色，结合对比度检查 |
| 字体与字重 | 与文章层级一致；加粗标记重点，不以字重代替说明 |
| 字号 | 按标题、图注、正文用途区分；容器不能容纳时调整呈现，不切碎表达 |
| 边框与圆角 | 有实际分组需要才使用，并与其他图片的处理一致 |
| 留白 | 沿用正文与图片的间距规范，依据内容关系分组 |
| 明暗表现 | 检查细线、标签和图形在深色模式下仍能辨识 |

## 什么时候制作专用图

若已有材料包含需要看图才能理解的流程、结构或数据，制作准确的专用图；若只是觉得版面空，可以保留留白。封面、栏目题图与长期复用的信息图可以单独设计，投入取决于用途，不规定每篇文章都必须拥有这些元素。

自查时确认：图是否相关，数据和外观是否有依据，标签是否清晰，正文是否仍能完整表达，装饰是否影响阅读。不要规定固定的“开头一句定义—中间三张卡—结尾一图总结”组合，也不为凑齐组件重组全文。
