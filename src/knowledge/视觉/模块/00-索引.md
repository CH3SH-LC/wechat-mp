# 模块方向索引（视觉 / 模块）

> 定位：正文排版的「模块工具箱」——每个模块一个条目文件，含**组件资产如何生成**（类型模板/骨架/零件位）与语法/表现/时机/变体/风格适配/常见错误。
> 用法：确定内容类型与风格后，按正文需要挑选模块；每篇注意「模块组合铁律」与密度限制。
> 交叉：模块的具体表现随风格变化（见 风格 方向）；文案结构对应模块（见 文本/文案 的 copy-layout.md）；图片/视频素材准备与插入操作见 插图 方向。

## 一、模块组合铁律（先读）

- 同一模块**风格统一**：一篇里卡片只用一个样式（card 或 frame 或 cols，别混三种）。
- 装饰密度上限：气泡 ≤2、徽章 ≤3、花纹 ≤2 种、装饰标题 ≤2 处；其余靠留白与字号分层。
- 所有模块间距满足间距硬规范（块距 16px/行高 1.75），粘贴外部模板时自查。
- 每个模块条目内含「密度限制」小节，冲突时以条目为准。

## 三、模块条目的统一结构

模块定位一句话 → 可用语法与写法 → 双模式（文字/宣传）表现 → 适用内容类型 → 使用时机与位置 → 模板变体（≥3 种样式）→ 风格适配细节 → 配色配合 → 间距尺寸 → 密度限制 → 微信兼容注意 → 常见错误 → 个性化留白（可调参数）

（★ 重构条目为八节结构：〇核心模型 → 一构建总则 → 二组合方式构建模板 → 三风格填充规则 → 四现有实现=默认风格 → 五铁律（含整图资产构建规范）→ 六示例 → 七常见错误 → 八个性化空间）
