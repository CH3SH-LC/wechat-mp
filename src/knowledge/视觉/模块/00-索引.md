# 模块方向索引（视觉 / 模块）

> 定位：正文排版的「模块工具箱」——每个模块一个条目文件，含**组件资产如何生成**（类型模板/骨架/零件位）与语法/表现/时机/变体/风格适配/常见错误。
> 用法：确定内容类型与风格后，按正文需要挑选模块；依据实际信息关系与可读性组合。
> 交叉：模块的具体表现随风格变化（见 风格 方向）；文章组织由 文本/写作 的 writing-structure 负责，模块按信息用途取用；图片/视频素材准备与插入操作见 插图 方向。

## 一、模块组合铁律（先读）

- 同类信息保持一致的框线、内距与标题层级；不同信息关系可以分别使用 card、frame 或 cols，不为展示组件改变原文。
- 组件与装饰没有全文数量配额；按信息关系与窄屏可读性选择，不以数量判断完成度，不摘要原文来凑组件。
- 所有模块间距满足间距硬规范（块距 16px/行高 1.75），粘贴外部模板时自查。
- 历史条目的密度数值只作局部设计参考，不覆盖用户原文、图片安排或当前引擎协议。内置题签、纸框与角标可独立完成设计，无需新生成 SVG。

## 三、模块条目的统一结构

模块定位一句话 → 可用语法与写法 → 双模式（文字/宣传）表现 → 适用内容类型 → 使用时机与位置 → 模板变体（≥3 种样式）→ 风格适配细节 → 配色配合 → 间距尺寸 → 密度限制 → 微信兼容注意 → 常见错误 → 个性化留白（可调参数）

（★ 重构条目为八节结构：〇核心模型 → 一构建总则 → 二组合方式构建模板 → 三风格填充规则 → 四现有实现=默认风格 → 五铁律（含整图资产构建规范）→ 六示例 → 七常见错误 → 八个性化空间）
