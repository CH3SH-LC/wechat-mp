# 阅读与宣传场景的视觉强度（module-guide-dualmode）

> 定位：在用户需要时调整视觉强度，保留同一套信息、功能与可读性。

选材、标题、段落组织与结尾由 `文本/写作` 知识负责：按任务需要读取 `writing-purpose`、`writing-structure`、`writing-campus`、`writing-product`、`writing-explain`、`writing-story` 或 `writing-review`。视觉风格只决定呈现方式，不绑定文章结构、篇幅或语气。

## 可调整的设计轴

| 设计轴 | 素净方向 | 明丽方向 |
|---|---|---|
| 标题 | 常规尺度、清晰字重 | 更显著的尺度与主色 |
| 线饰 | 简单边线或无装饰 | 协议支持的几何点线、网点、速度线 |
| 小记号 | 低调或不使用 | 与色板协调并保持主次 |
| 图像 | 必要图像端正呈现 | 可增加与内容有关的插画表现 |
| 正文 | 可读深色与稳定层级 | 同样保持可读深色与稳定层级 |

色板与版式独立。需要明丽时可使用协议支持的 `scale=display`、`ornament=confetti|dots|speed`；明确极简时可采用 `ornament=none;mark=none;deco=none`。这些参数不决定章节、文章语气、卖点数量或是否出现行动号召。

## 保留的排版基准

正文行高 1.75、块距 16px、卡内留白至少 12px；图像、链接和来源仍保持原本用途。陶土橙 `#c96f4a`、雾青 `#5f8d8a`、墨 `#2f3640`、沙金 `#d9a35f`、暖灰 `#b08d8d` 可作已有配色参考，正文深灰 `#4a4a52`。正式色板按用户与本篇风格选择。

## 调整范围与复核

整篇或局部加强视觉均需有本篇用途，前后标题层级和间距应能衔接。需要区分不同性质的信息时，用清楚的标题或分隔表示；是否包含推介段、放在何处，由内容任务决定。

只有用户需要多个版本时才制作多个版本。复核事实、来源、图片与入口未因换外观而变化，读者仍可辨认主次。视觉更鲜明不要求增加紧迫词、夸大承诺或强行改成促销口吻。

实际输出以 `engine-write-protocol` 的 v2 语法为准。色板与版式分别选择；正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号与插画内部填色。保持零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用，生成需求使用协议支持的 `[[img]]` / `[[deco]]`；旧 HTML/CSS 片段仅用于理解视觉，不作为桌面输出语法。
