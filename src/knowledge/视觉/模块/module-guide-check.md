# 方法论·避免模块堆砌检查清单（module-guide-check）

> 定位：定稿前逐项自查，专门抓"模块堆砌"——一种模块装一屏、卡片连排、重点全靠彩色、间距失守的排版病。本条目是可勾选清单 + 每项"查什么、怎么改"。
> 调用时机：每篇发布前必做的一步终检。写完正文、排完模块、内容和标题都定了之后，用这份清单过一遍再交付。

## 一、为什么会"堆砌病"

堆砌的根源是"想让文章看起来丰富"却用了错的方法——靠不断加装饰、加卡片、加颜色堆出来的"丰富"，结果是视觉超载、重点全部失焦、读者扫不下去。堆砌不等于丰富：**真正的丰富来自信息本身的分层，而非模块与颜色的堆叠。**

三条铁律兜底（贯穿本清单）：
- 重点**单通道**表达——一个重点只用一个最强手段强调，别又变色又加粗又加亮底又加气泡。
- 每屏**可停靠**——手机上每 6-8 行正文有一块能歇脚的视觉锚点即可，不是越多越好。
- 间距**守硬规范**——16px 块距、1.75 行高，这是排版的地基，失守则整体错乱。

## 二、检查清单（发布前逐项勾选）

### 第一项：装饰密度
- [ ] 装饰元素总量在允许上限内？
  - 查什么：气泡 ≤2、徽章 ≤3、花纹 ≤2 种、装饰标题 ≤2 处（见《模块索引》密度限制）。
  - 怎么改：数一数全文气泡/徽章/花纹/装饰标题数，超限的删掉只留核心，用留白与字号分层替代。
- [ ] 每种"装饰工厂"是否同时投入使用？
  - 查什么：一种视觉手法（纯色块、角标、花边）是否被当成"必要装饰"反复出现在每块上。
  - 怎么改：同一装饰只服务于一个重点；其他内容靠自然排版，别全上装饰。
- [ ] 首屏是否成了"装饰集中营"？
  - 查什么：标题、气泡、徽章、图片是否全堆在第一屏抢眼，后面反而空。
  - 怎么改：把首屏装饰减到 1-2 处，其余分散到各分区，别让读者一进来就眼花。
    - 错：首屏同时有装饰标题 + 金色徽章 + 两个彩色气泡。
    - 对：首屏只留一个装饰标题，徽章与气泡放到后续对应小节。
- [ ] 装饰到底是帮信息还是挡信息？
  - 查什么：把某个装饰元素拿掉后，正文是否反而更清楚（说明它只添乱不帮忙）。
  - 怎么改：装饰必须服务于信息层级；凡让正文变糊的装饰一律删。
    - 错：满屏波点花纹把重点段落的底色衬成一团花，字都看不清。
    - 对：花纹只作分区底衬，重点段落用实色卡突出。

### 第二项：卡片样式统一
- [ ] 全文卡片只用了 1 种主要样式？
  - 查什么：是否混用了 card / frame / cols 三种卡片（见《模块索引》铁律），或一张纯色块一张白卡。
  - 怎么改：选一种卡片样式做主力，全文统一；次要卡片用同一系列的淡色/细边框，别风格跳跃。
- [ ] 卡内信息级别（主标题/正文/备注）有统一字号与颜色体系？
  - 查什么：卡内标题、正文、小字备注是否各有固定字号，还是每张卡自起一套。
  - 怎么改：定一套"卡内三级"（标题 15-16px / 正文 14px / 备注 12-13px），全文统一执行。
- [ ] 相邻卡片是否可一眼分清"主从、先后"？
  - 查什么：两张相接的卡片级别是否拉不开，让人误以为是一张。
  - 怎么改：主卡用底色或加粗边框，从属卡用同一系列的淡色、细边框，层级一眼可辨。
    - 错：主卡与从属卡同色同框，读者分不清哪张更重要。
    - 对：主卡用重点底色，从属卡用同一色系的浅卡。
- [ ] 卡片里的标记/符号是否各用各的？
  - 查什么：同一个含义的标记（如"提示""必看"）在两张卡里是否换了不同符号、不同颜色。
  - 怎么改：给常用含义定统一的符号与配色，一个含义一个样貌到底。
    - 错：上张卡"注意"用三角感叹号，下张卡又换成五星。
    - 对：全文"提示"统一用同一个 CSS 圆点 span 加同一个语义色。

### 第三项：每屏可停靠（但不过密）
- [ ] 每屏（6-8 行正文）至少一个可停靠视觉块？
  - 查什么：是否有连续一大段无卡片/列表/图的纯文字"平川"。
  - 怎么改：在每 300-600 字处补一个卡片、列表或图（见《长文节奏》）。
- [ ] 可停靠块是否"过密"到没有呼吸？
  - 查什么：是否每 1-2 行就一个卡片/气泡连排成碎片。
  - 怎么改：卡与卡之间留 24px + 一段正常正文，松紧交替。
- [ ] 停靠块是否只会重复同一种？
  - 查什么：全篇是不是从头到尾都是同一种卡片/列表，没有任何换气。
  - 怎么改：按内容性质交替用卡片、清单、金句图、步骤，让每屏的"歇脚点"有变化。
    - 错：全篇用同一种纯色卡片连排到底，读起来像复制粘贴。
    - 对：干货处用清单、结论处用金句卡、数据处用表格，交替呼吸。
- [ ] 首屏有没有足够醒目的停靠点？
  - 查什么：读者一进来是否先被一大段纯文字压住，找不到落脚处。
  - 怎么改：首屏放一个核心卖点气泡或一张关键图，让人先"踩实"再往下读。
    - 错：首屏就是三大段正文，滑三屏才看到第一张卡。
    - 对：首屏一个一句话卖点气泡 + 一行引导，画面先有靠点。

### 第四项：重点单通道
- [ ] 每个重点只用 1 个最强强调手段？
  - 查什么：一个重点是否同时"变色 + 加粗 + 加亮底 + 加气泡 + 加标记"多处强调。
  - 怎么改：选一个最强通道（如专用气泡用其语义色），其余通道降为自然级；同一屏不同要点的强调方式不重复冲突。
- [ ] 全文是否存在"每句都强调"（等于没强调）？
  - 查什么：通篇加粗、下划线、彩色文字是否铺满。
  - 怎么改：仅对真正的重点（1-2 屏一个）做强调；普通句保持正文常规样式。
- [ ] 同一屏几个重点的强调方式是否互不打架？
  - 查什么：一屏里既有左竖条、又有气泡、又有彩字，都在抢着当"最重"。
  - 怎么改：一屏只让一个重点最突出，其余降为次级强调，主次拉开。
    - 错：一屏同时冒出左竖条重点、一个气泡、一句加粗彩字，不知先看谁。
    - 对：一屏一个主气泡带一句加粗，其余保持常规。
- [ ] 标题与正文是否各自都清清爽爽只有一个重点？
  - 查什么：标题里塞了太多强调，正文里每句都想强调。
  - 怎么改：标题只突出最关键的一个词，正文只在转折/结论处发力。
    - 错：标题里三个词全加粗又变色。
    - 对：标题只高亮最关键的一个词，正文在结论句用一次强调。

### 第五项：间距合规
- [ ] 所有块间距为 16px、正文/块内行高 1.75？
  - 查什么：相邻段落、卡片、列表、图片之间的间距是否统一，行高是否达标（见 00-GUIDE 间距硬规范）。
  - 怎么改：统一用 `margin:0 0 16px`；行高统一 1.75；标题上方 28px 下方 12px；图片上下 12px；分割线上下 24px。
- [ ] 卡内内边距 ≥12px、无越边/三层缩进？
  - 查什么：卡片文字是否贴边、正文是否又额外设了左右缩进造成三层缩进。
  - 怎么改：卡内 `padding:14px 16px 12px`；正文不自设左右 padding，靠微信自带边距。
- [ ] 视觉强调双通道（无障碍）？
  - 查什么：重点是否只靠颜色表达（色盲/低饱和屏下会丢失）。
  - 怎么改：任何一个重点同时用颜色 + 字号/字重/底色至少两个通道（见《无障碍基线》）。
- [ ] 长图/长列表的上下与内部留白守住没有？
  - 查什么：长图或长步骤列表四周是否贴死、内部行距是否被压扁。
  - 怎么改：长图上下各留 12px，长列表行与行之间保持正常行距 1.75，不自压成一片。
    - 错：一张长图上下贴死文字，下方列表行距被压到看不清。
    - 对：长图上下各留出呼吸，列表行距回到 1.75。
- [ ] 三个端看过去间距是否都一致？
  - 查什么：是否只在一台手机上看过，安卓/PC 上的间距和行高没有核对。
  - 怎么改：iOS / 安卓 / PC 各过一遍，任何一端间距失守都算未过。
    - 错：只在 iPhone 上"看起来挺好"就发了。
    - 对：三端各检查一遍，间距、行高都达标才放行。

## 三、若在检查中发现堆砌，按这个顺序修

1. **先砍装饰**：删掉多余的徽章、花纹、装饰标题，留最核心的 1-2 处。
2. **再统一样式**：卡片只留一种主力样式，全文字号都归一到这套体系。
3. **然后调间距**：把所有块距、行高拉回硬规范。
4. **最后核对重点**：确认每个重点只剩一个最强通道，没有"每句都强调"。
5. **真机预览**：修改后再在手机/电脑预览一遍，确认"清爽但丰富"。

## 四、常见错误（堆砌的典型表现）

1. **一张正文塞三种视觉**：一个句子里又加粗又划线又变色又高亮——改成单通道。
2. **卡片连排不断**：五张纯色卡连着排，没有一段白底正文呼吸——补文字、拉开层。
3. **装饰比信息多**：满屏花纹、角标、星星，把正文挤成边角料——砍装饰，还正文以主角。
4. **间距失守**：碎片化排版，间距忽大忽小、行高不一——全部拉回硬规范。
5. **重点无别**：全文都是重点，等于没有重点——收敛到 1-2 屏一个。

## 五、发布前 5 分钟口诀

「**装饰收敛、卡片统一、每屏可停、重点单通道、间距守规**」
——念完这句，对照上面的勾选清单过一遍，基本就能避免堆砌病。

## 六、个性化空间（可调参数与判断依据）

- **装饰克制度**：极简/商务/专业号几乎可以不用装饰，靠留白与字号；年轻/促销号可略放飞但仍守上限。判断依据＝账号调性与读者对"视觉热闹"的接受度。
- **卡片样式选择**：统一到哪一套（card/frame/cols）按风格定（见风格维度）；关键是"一套到底"。判断依据＝风格模板。
- **可停靠块类型偏好**：干货号用清单/步骤，故事号用金句/图。判断依据＝内容类型。
- **重点强调方式**：有的号全程用左竖条强调，有的用气泡——选一种贯穿全文即可。判断依据＝风格统一性的偏好。

## 七、最终交付校验

- [ ] 对照本节勾选清单 5 大项全部通过。
- [ ] 用真机预览在手机/电脑扫一遍，确认没有视觉超载。
- [ ] 若与《模块×内容类型矩阵》的推荐档比对过，主心模块齐全、无硬塞。
- [ ] 间距、行高、字号体系全部符合 00-GUIDE 硬规范。

## 八、逐屏过一次的操作步骤

改完上面的勾选清单后别急着交付——回到文章**第一屏**，从顶往下**一屏一屏**滑着自查，最容易把"局部都对、整体堆砌"暴露出来。每屏都按"查什么→怎么改→怎么算过"三步走。

- **第一屏（进文即见）**：查什么——首屏是否让读者"踩实了"（有卖点、有停靠点），而不是一上来就是文字墙；怎么改——收紧首屏装饰、放一个核心点；怎么算过——能一眼说清"这篇给我什么"才算。
- **中段每屏（往下滑 2-3 屏停一次）**：查什么——每 6-8 行正文有无可停靠、卡与卡之间有无正常文字呼吸；怎么改——补停靠或抽走过密卡片；怎么算过——在任意位置停住，画面都"坐得稳"。
- **小标题处**：查什么——标题上方下方留白（上 28px、下 12px）是否守住；怎么改——把标题上下间距拉回硬规范；怎么算过——标题不贴死上下正文。
- **卡片/列表处**：查什么——相邻卡片能否分清主从、间距是否 16px、卡内文字没贴边；怎么改——统一样式与间距；怎么算过——卡内三级字号一致、边框统一。
- **图/长图处**：查什么——图片上下 12px 留白、图注是否紧挨对应图；怎么改——补全图片上下留白与图注；怎么算过——图片裁切正常、清晰、图注对上。
- **页尾/结尾处**：查什么——结尾行动号召是否单通道、没有被徽章花纹堆满；怎么改——结尾回归安静、只留一个核心动作；怎么算过——读者看完知道"接下来做什么"。

## 九、堆砌检查顺序表

按这个顺序查，能少走回头路；反过来先查间距、最后砍装饰，会白改好几遍。

| 顺序 | 检查项 | 为什么排在这个位置 |
|---|---|---|
| 先 | 装饰密度 | 装饰是堆砌的第一源头，先砍掉多余，后面统一样式才不会白做 |
| 再 | 卡片样式统一 | 装饰瘦身后再定统一卡片，避免"先统一又重排"的返工 |
| 接着 | 每屏可停靠 | 样式统一后调节奏，让版面疏密有致、张弛有度 |
| 然后 | 重点单通道 | 节奏清楚了再收敛强调，让重点真正从版面里跳出来 |
| 最后 | 间距合规 | 间距是地基，放到最后一次性收口，避免反复微调 |
| 收尾 | 真机三端预览 | 全部改完再端上核对一遍，确认"清爽但丰富" |

## 十、不同内容类型的典型堆砌表现

同样一堆模块，在不同内容类型里"堆"的方向不一样，对着你自己的类型重点盯。

**干货文（教程/盘点/方法）**
- 全程清单、步骤、要点卡连排，没有一句说明文字撑着，读起来像目录堆成一摞。
- 满屏"重点、必看、划重点"，每个词都想突出，结果一个都记不住。
- 图注、来源小字被挤成一行，信息是齐了但不"读得动"。

**促销文（活动/卖货/推优惠）**
- 价格、卖点气泡、徽章堆满首屏，一进来就眼花缭乱。
- 每句都想喊"限时、最后、超值"，重点单通道彻底失守，反而显得不真诚。
- 卡片与纯色块拉满当"档次感"，忽略了间距与呼吸，结果显得廉价。

**故事文（品牌/情怀/情感）**
- 金句卡、花纹色带频繁插入，把讲故事的节奏切成碎片。
- 抒情段落整段加粗、压亮底，失去了叙事的轻重缓急。
- 装饰比情节更抢眼，读者记住的是"花"而不是故事本身。

## 十一、与密度限制/间距硬规范的对照速查表

判断"是不是堆了"不用凭感觉，直接对数值。两张大表，一处不过就返工。

**装饰与模块密度上限**

| 装饰/模块 | 密度上限 | 说明 |
|---|---|---|
| 重点气泡 | 每屏 ≤2 | 关键信息一屏最多 2 个 |
| 徽章/高亮 | ≤3 | 全文标签与重点标记 |
| 花纹色带种类 | ≤2 种 | 斜纹/波点/棋盘等只选 2 种内 |
| 装饰标题 | ≤2 处 | 装饰化开篇/横幅标题 |
| 步骤 | ≤5 步 | 步骤模块每段不超 5 步 |
| 清单 | ≤8 项 | 清单模块每段不超 8 项 |
| 证言 | ≤4 则 | 证言不超 4 则 |
| 价格档 | ≤4 档 | 价格表不超 4 档 |
| 分割线种类 | ≤2 种 | 全篇分割线样式 |

**间距硬规范（00-GUIDE）**

| 项目 | 硬规范 | 说明 |
|---|---|---|
| 块间距 | 16px | 段落/卡片/列表/图片之间统一 |
| 正文与块内行高 | 1.75 | 代码块 1.6 |
| 卡内/气泡内容与边框 | ≥12px | 文字不贴边、不顶格 |
| 标题上方 | 28px | 下方 12px；h3 上 24px 下 10px |
| 分割线上下 | 24px | 分隔线两侧留白 |
| 图片上下 | 12px | 图片与上下正文的间距 |

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案
