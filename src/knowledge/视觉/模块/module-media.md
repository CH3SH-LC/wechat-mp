# 视频 / 音频卡片（module-media）

> 定位：在图文正文里嵌入视频号/小程序视频与音频卡片，把"看得见"的信息升级为"听得见/动起来"的多媒体体验。
> 调用时机：教学、访谈、娱乐内容需要插入视频/音频作为补充或核心载体时用；用于替代纯文字讲不清、或要给读者"转场换档"的场景。

## 一、可用写法与语法

平台硬约束：仅 HTML 内联 `style`；无 `<style>`/`<script>`/伪元素/外链字体。**微信正文不能直接贴任意视频/音频**——视频必须通过「视频号」或「微信小程序」插入，音频通过「微信音频号」或素材库插入；不能嵌入 YouTube/外部播放器 iframe 等外链。真正插入时用微信编辑器提供的「插入视频/音频」能力，本模块的"卡片"是在此之上的伴生排版（标题/说明/播放引导）。卡片视觉一律纯色 + 细边框，不写渐变、不加投影（本规范不推荐渐变）。

### 1.1 视频号视频卡片

视频号视频在微信正文中是一个可内嵌的播放块。其外层可以配一张"标题 + 说明 + 播放提示"的浅色卡片，把视频"包"起来更像独立单元。

卡片规格：`background:#f7f9fc`、`border:1px solid #e6ecf5`、`border-radius:12px`、`padding:14px 16px`、`margin:0 0 16px`。卡片内放视频插入位 + 标题 + 一行说明。标题前缀用 CSS 实心圆点或 `art://` 植物图案即可，不写 emoji。

```html
<section style="background:#f7f9fc;border:1px solid #e6ecf5;border-radius:12px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0 0 10px;font-size:15px;font-weight:700;color:#2b3a5e;line-height:1.75;">实操演示 · 3 分钟看懂怎么做</p>
  <!-- 在这里插入视频号视频 -->
  <p style="margin:10px 0 0;font-size:13px;color:#8a94a6;line-height:1.75;">点上方视频观看；配合下文文字版步骤使用更佳。</p>
</section>
```

> 视频插入本体的比例建议：封面尽量横版 16:9，避免竖版强行拉伸；视频下方说明与正文衔接，强调"看完视频再看文字步骤"或"看完文字再看视频回放"。

**视频使用要点**：
- 视频时长与目的对齐：短演示 1-3 分钟、深度讲解 5-10 分钟、访谈/课程可 20-60 分钟；图文里优先放"摘录片段"，全文放在结尾作延伸。
- 一篇文章的"视频锚点"：给视频一个好标题（点出"教什么/看点"），读者不点开也知道内容；不要用笼统的"点击观看视频"。
- 视频与文字分工：演示类（操作/过程）用视频更清楚，结论/步骤清单仍用文字；两者互补，别让读者看视频就没事干。
- 视频封面：优先用信息量大的静止帧，避免空白缩略图；封面上的字要≥在手机小图上可读。

### 1.2 小程序视频 / 音视频卡片

通过「小程序」插入的视频（如教育/知识类小程序的音视频），同样可用一张卡片包裹，卡片里放小程序入口或视频块 + 说明。

```html
<section style="background:#fff;border:1px solid #e6ecf5;border-radius:12px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0 0 8px;font-size:14px;font-weight:700;color:#2b3a5e;line-height:1.75;">配套课程 · 小程序直达</p>
  <!-- 在这里插入小程序卡片入口 -->
  <p style="margin:8px 0 0;font-size:13px;color:#8a94a6;line-height:1.75;">点击进入小程序看完整课程；正文下方是文字精要。</p>
</section>
```

### 1.3 音频卡片（纯音频 / 播客）

音频（微信音频、音频号、或音频素材）同样用卡片给出标题、出处、时长、收听提示。标题前缀可用一枚实心圆点 span 或 `art://` 植物图案作视觉锚点，不写 emoji。

```html
<section style="background:#f7f9fc;border:1px solid #e6ecf5;border-radius:12px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0 0 8px;font-size:15px;font-weight:700;color:#2b3a5e;line-height:1.75;">本期访谈音频 · 38 分钟</p>
  <!-- 在这里插入音频块 -->
  <p style="margin:8px 0 0;font-size:13px;color:#8a94a6;line-height:1.75;">通勤路上听全文；想记笔记可看下方文字纪要。</p>
</section>
```

**音频使用要点**：
- 音频适合"陪伴型"内容（访谈、播客、睡前故事、课程回放）——读者可听文字，正文提供精要或时间戳导航。
- 给音频标注时长（`38 分钟`），读者提前知道投入；可给时间戳（`00:00 开场`）帮跳听。
- 音频 + 文字纪要搭配：正文放字数少但信息密的纪要（要点列表），音频放完整对话，两者互补。
- 音频卡与视频卡一屏尽量不要同时出现，避免"点哪个"的选择负担。

### 1.4 占位 / 无平台入口时的替代写法

在某些未实际插入平台的排版预览里，可用一个"播放占位块"示意插入位（仅示意，不作为最终可点元素）。需要"播放"字样时用纯文字；想画三角三角，用两个等宽边框拼一个向右的 CSS 三角 span。

```html
<div style="width:100%;height:120px;background:#eef2f8;border:1px solid #dde5f0;border-radius:8px;display:flex;align-items:center;justify-content:center;margin:0 0 16px;color:#8a94a6;font-size:14px;">视频/音频插入位</div>
```

## 二、双模式表现（文字类 / 宣传类）

- **文字类**：媒体卡片仍偏"信息型"——卡片底色浅灰 `#f7f9fc`、说明调子平静，视频/音频是"补充讲解"，正文文字是主体；卡片不超过正文占比。
- **宣传类**：媒体卡片可更商业化——卡片白底 + 细边框 + 主色标题条，用"限时/全集/点开即学"等话术，视频作转化钩子；但卡片仍是"安利 + 引导"，不喧宾夺主。

## 三、样式变体（≥3 种，具体参数）

1. **浅灰信息卡**：`#f7f9fc` 底 + `#e6ecf5` 描边 + 12px 圆角 + 说明小字。教学、干货、访谈。（见 1.1）
2. **白卡 + 细边框（购物/课程感）**：`#fff` 底 + `#e6ecf5` 描边 + 12px 圆角 + 靠留白分层。课程、带货、会员。（见 1.2）
3. **深色强调卡**：纯色深底 `#1e2436` + 白标题，用于压台/开场重磅视频。适合娱乐、品牌大制作。
4. **极简卡**：无底色，仅标题行 + 说明，靠留白与分隔线衔接，适合极简白风格。

**深色强调卡示例**：

```html
<section style="background:#1e2436;border-radius:12px;padding:16px 18px;margin:0 0 16px;">
  <p style="margin:0 0 10px;font-size:15px;font-weight:700;color:#fff;line-height:1.75;">年度大片 · 一镜到底</p>
  <!-- 在此插入视频号视频 -->
  <p style="margin:10px 0 0;font-size:13px;color:#cfd6e4;line-height:1.75;">开篇即高潮，建议全屏观看。</p>
</section>
```
> 深色卡适合压台/开场高光视频，与浅灰信息卡区分开；若一篇文章用了深色强调卡，其余媒体卡尽量都用浅色，保持一个"视觉重心"。

## 四、使用时机与位置

- **位置**：视频/音频卡片放"该媒体最相关的正文位置"——步骤讲解前插入（先看演示）、深度内容中部插入（换档）、篇末插入（延伸）。
- **时机**：文字讲不清的操作/情感表达/娱乐内容用视频；通勤/陪伴型内容用音频；课程/访谈类既可用视频也可音频，按读者场景选。
- **内容类型**：教学（视频演示）、访谈（音频/视频）、娱乐（视频）、课程（小程序视频），以及"图文 + 媒体"双载体互补的作者。

**媒体 vs 图片怎么选**：

| 表达目的 | 用图片 | 用视频/音频 |
|---|---|---|
| 展示静态结果/外观 | 图（更轻、更稳） | 不必要 |
| 展示过程/操作/动效 | 需多张连拍 | 视频（一气呵成） |
| 叙述/访谈/情感 | 图文叙事 | 音频最贴（可听） |
| 短促信息、快速扫读 | 图 + 图注 | 视频反而打断节奏 |
| 深度教学 | 图文精要 | 视频详讲 |

> 原则：**"看得清静态对比"用图，"讲得清动态过程"用视频，"读得进长对话"用音频**。图片是最轻、最稳的默认项，只有确实需要"动起来/听起来"才上升用媒体。

**按内容类型推荐媒体配比**：

- 教学/教程：2-3 个视频（分步）+ 文字步骤清单；音频可作为通勤版。
- 访谈：1 个核心视频 + 1 个音频可选项；正文给时间戳纪要。
- 娱乐/带货：1 个高光视频 + 图文卖点；别堆多个视频。
- 课程/会员：小程序视频 + 文字精要；媒体卡用白卡 + 细边框"有价值感"。

## 五、风格适配（4 个风格例子）

- **科技商务**：浅灰信息卡 + 主色标题，说明小字；视频横版 16:9；标题前缀实心圆点；整体"专业演示"感。
- **校园清新**：白卡 + 细边框 + 薄荷绿标题；视频演示活泼，标题前缀草木绿实心圆点。
- **国潮红金**：视频/音频卡配红金标题条（深红纯色），说明浅米；娱乐/访谈大制作用深色强调卡压台。
- **极简白**：无底卡，仅标题 + 说明小字，视频直接铺开，卡片痕迹降到最低。

## 六、间距与尺寸（遵守硬规范）

- 媒体卡片底部边距统一 `margin:0 0 16px`（块距硬规范）。
- 卡内标题 14-15px、`color:#2b3a5e`、`font-weight:700`、`line-height:1.75`；说明 13px、灰 `#8a94a6`、`line-height:1.75`。
- 卡内边距 `padding:14px 16px`；标题与媒体之间 `margin:0 0 10px`，媒体与说明之间 `margin:10px 0 0`。
- 深色强调卡标题白字、说明浅灰一档，卡内边距可 `16px 18px`。
- 视频插入本体保持其自身纵横比，不强行固定高度。

## 七、密度限制

- **一篇文章视频/音频卡片 ≤3 个**；教学长文讲解可 2-3 个，其余类型 ≤1-2 个。
- 媒体卡不是"贴片广告"，只放与正文强相关的媒体；娱乐/访谈可 1 个核心视频 + 可选音频，别堆。
- 若同时有视频 + 音频，优先一个为主，另一个作补充；一屏尽量只出现一张媒体卡。
- 文字仍是主体：媒体卡 + 文字精要配比约 1:2（1 张卡配至少 2 段文字说明），避免"全篇都是视频/音频、正文空"。
- **卡片样式统一**：一篇里媒体卡只在"浅灰信息卡 / 白卡+细边框 / 深色强调卡"中选 ≤2 种（其中深色强调卡最多 1 处作视觉重心），其余都用一种主款，别每张卡换一种底色。
- **一屏 ≤1 张媒体卡**：媒体/音频与前后正文之间各隔一段文字，避免同一屏里又视频又音频又正文互相争夺注意力。

## 八、常见错误（反例 + 正解）

- **反例**：直接贴一条 YouTube/外链 iframe 视频，微信正文不渲染、发布后是裂块。**正解**：只用视频号/小程序插入视频，音频用微信音频号或素材库；不嵌外链播放器。
- **反例**：视频是竖版 1:1 强行拉伸到横版，画面变形。**正解**：保留视频自身纵横比，封面优先横版 16:9，不用固定高撑变形。
- **反例**：视频/音频卡片插了一大堆却没有任何文字说明，读者不知为何要看/听。**正解**：每张媒体卡给标题 + 一句"为什么看/怎么用"，让读完文字的人不点开也能懂。
- **反例**：全文塞了 6 个视频+音频卡，页面像视频合集、正文稀薄。**正解**：媒体卡 ≤3，配 1:2 的文字比例，文字始终是主体。
- **反例**：占位块"视频/音频插入位" 当作最终可点元素放给读者，读者点不动。**正解**：占位块仅用于排版示意图，正式发布前必须替换成真实可插入的视频/音频块。
- **反例**：视频标题写成"点击观看视频"这种笼统引导，读者不知内容。**正解**：给视频起信息量大、点出"教什么/看点"的标题（如"实操演示 · 3 分钟看懂怎么做"）。
- **反例**：一篇既有视频又有音频还配多张图，同一屏信息满天飞读者茫然。**正解**：一屏 ≤1 张媒体卡，视频/音频二选一为主，另一作补充，周围配文字精要。
- **反例**：把视频放正文最前端第一个元素，读者还没读文字就被视频钩走、跳过正文。**正解**：视频放"相关论述之后"作讲解/回放，优先让读者带着问题去看，或用小结引导。

## 十、个性化空间（可调参数与判断依据）

- **可调**：卡片样式（浅灰信息卡 / 白卡+细边框 / 深色强调）。**判断依据**：教学干货用浅灰（专业克制），课程带货用白卡+细边框（有价值感），重磅娱乐用深色强调（压台感）；一套调性统一。
- **可调**：卡片内边距与圆角（`10px 14px`~`16px 18px`，圆角 8-14px）。**判断依据**：信息多、标题大时加大内边距；极简时减小；圆角随风格（商务小、校园大）。
- **可调**：标题与说明的字号/颜色。**判断依据**：想让媒体更突出时标题 15px、加粗提升到主色；想弱化时标题 14px、说明更浅。
- **可调**：媒体数量（1-3 个）与正文配比。**判断依据**：长教程可 2-3 个按步骤插入；普通文章 1 个核心媒体；始终让文字保持主体、媒体作载体。

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案
