# 行动信息与入口呈现（module-cta-end）

> 定位：本篇确有报名、联系、购买、阅读补充资料或反馈等行动时，呈现清楚的说明与有效入口。

## 内容与功能

根据本篇目的交代读者可以做什么、入口在哪里，以及必要的时间、对象、费用或条件。没有这些需要时可以自然结束。行动内容不由风格推导，也不通过利益、情绪或悬念公式补写。

链接、小程序或其它入口需要实际有效。仅有卡片、徽章或按钮外观不能证明可以点击；发布端需另行插入或绑定的功能按真实平台操作。优惠、数量、截止时间与领取方式必须有材料依据。

## 视觉选择

可使用普通文字、清楚的链接标记或协议支持的提示组件。明丽稿可以增强标题、线饰与重点记号；极简稿保留文字层级和留白。入口与说明相邻，不固定整篇结尾顺序。

既有尺寸参考：模块外距 24px 0 16px；内边距 20px 16px；强调文字 17px，辅助文字 13px；正文行高 1.75；如接页脚，保持至少 24px 的视觉区隔。朱红 #b03a2e、蓝紫 #3f5bc2、青 #00b8a9 可作为对应色板的强调色，文字仍保持足够对比。

## 复核

确认入口说明与落地页相符，事实与条件完整，未把普通结束误当成缺失组件。需要多个独立动作时区分用途，避免不同入口难以辨认；不以统一数量删掉必要信息。

具体输出遵循 engine-write-protocol 的 v2 语法：色板与版式独立，正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号和插画内部填色；零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用。选材与组织按需查阅 文本/写作 的 writing-purpose、writing-structure、对应场景知识与 writing-review。
