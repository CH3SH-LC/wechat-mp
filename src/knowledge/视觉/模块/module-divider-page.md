# 章节分隔宣传页（module-divider-page）

> 定位：正文里「整块封面式」的大分隔页，像一章的封面，用一个有底色 / 花纹 / 大标题 / 页码的整块把超长文、特辑或连载的篇章之间硬断开，制造「章节翻开」的仪式感。
> 调用时机：**超长文（3000 字以上）、特辑、连载（一期含多章节）**。普通 1500 字短文用普通分割线即可，不用大分隔页。

## 一、可用写法与语法

分隔页是「整块视觉」，排版语法可用「花纹色带 + 标题横幅组合」，或内联样式自写整块背景。

**排版语法（花纹色带分隔带）**——`::: band` 花纹色带做章节衬底：

```markdown
::: band 斜纹
第一章　认识自己
:::
```

- `::: band 斜纹/波点/棋盘/条纹/圆环`：花纹种类（默认斜纹）；文字类蓝系、宣传类橙系。
- 色带下接正文，或用普通标题承接。

**排版语法（纯色横幅作分隔）**：

```markdown
[[banner:第二章 · 三遍阅读法|把你读过的书留下]]
```

**内联样式——整块封面式分隔页（推荐，含底色 + 大标题 + 页码）**：

```html
<section style="background:#e56b2f;border-radius:14px;padding:40px 20px;margin:28px 0 16px;text-align:center;">
  <p style="font-size:13px;color:rgba(255,255,255,0.85);letter-spacing:3px;margin:0 0 12px;">PART 01</p>
  <p style="font-size:26px;font-weight:bold;color:#fff;letter-spacing:4px;margin:0;line-height:1.4;">认识自我</p>
</section>
```

**带浅色衬底的分隔页（更精细——浅色块 + 细边框铺底）**：

```html
<section style="background:#fff3ec;border:1px solid #f3d9c8;border-radius:14px;padding:36px 20px;margin:28px 0 16px;text-align:center;">
  <p style="font-size:13px;color:#a5765a;letter-spacing:3px;margin:0 0 10px;">CHAPTER 02</p>
  <p style="font-size:26px;font-weight:bold;color:#8a4b2a;letter-spacing:4px;margin:0;line-height:1.4;">三遍阅读法</p>
</section>
```

**兼容注意**：整块分隔页用低饱和纯色底 + 细边框，微信主流内核渲染稳定；本规范不推荐渐变，统一纯色 + 细边框。文字对比度（纯色底与文字深浅）对可读性很关键（见「间距」节）。

## 二、双模式表现

| 维度 | 文字类 | 宣传类 |
|---|---|---|
| 底色 | 浅色（`#fff3ec` / 浅灰）+ 细边框 | 主色纯色（橙/青/紫）+ 高饱和 |
| 文字 | 深色标题 `#3a3a3a`、浅灰页码 | 白字标题、半透明白页码 |
| 花纹 | 蓝系或同色极浅 | 橙系纯色 |
| 强度 | 克制：大字号 + 极浅衬底 | 强视觉：纯色满块 + 大标题 |
| 密度 | 超长文可用 2–3 次 | 特辑宣传可到 3 次 |

## 三、样式变体（≥3 种）

**变体 A｜纯色底块（宣传特辑最爱）**——整块纯色底 + 白大标题。
参数：`background:#e56b2f` 纯色；`border-radius:14px`；`padding:40px 20px`；`margin:28px 0 16px`；页码 13px 白 0.85 透明度字距 3px；标题 26px 白字字距 4px `line-height:1.4`；居中对齐。宣传 / 促销特辑最直观的方案。

**变体 B｜浅色衬底块（文字类 / 国潮）**——浅底 + 细边框 + 深色标题。
参数：纯浅底 `#fff3ec` / `#fff` + 1px 细边框 `#f0e2d0`；`border-radius:14px`；`padding:36px 20px`；标题 24px 深主色、页码 13px 浅灰。浅底只做「衬底」，不压字。

**变体 C｜深色墨块（国潮 / 高端特辑）**——深墨底 + 金色标题与页码。
参数：`background:#2a2a2a`（纯墨色）；标题金 `#c9a063` 26px 字距 4px；页码金 `.85` 13px；`border-radius:12px`；`padding:40px 20px`。国潮 / 高端特辑的庄重方案。

**变体 D｜带页码编号 + 双行（连载）**——顶部大页码、中部小标题、底部一句引文。
参数：页码 40px 主色大号 + 细分割线；标题 22px；引文 14px 灰字；块浅底 `#fafafa` 1px 边框 / 主色纯色各配深浅文字；`padding:36px 20px`。连载「PART 01 / 上篇」感强。

**变体 E｜细线科技块（科技 / 数据文）**——细边框 + 色带点缀 + 深色标题。
参数：浅底 + 1px 细边框 + 顶部一道 3px 主色横条（纯色）；`border-radius:10px`；`padding:36px 20px`；标题 24px 深蓝。科技 / 学习 / 数据主题的「图纸」气质。

## 四、使用时机与位置

- **位置**：正文章节与章节之间，作为一章的开始封面（`margin:28px 0 16px`，上方留大，下方接该章正文）。
- **适用场景**：
  - **超长文**：3000 字以上拆成 2–3 个「卷」，每卷一个分隔页 + 页码目标。
  - **特辑**：多篇文章组成特辑，正文内用分隔页标「特辑·上 / 中 / 下」。
  - **连载**：一期里含多个子主题，用分隔页 + `PART 01/02` 页码拉开。
- **与普通分割线分工**：普通章节切换用「分割线」（`---`/`***`）；**只有章节级大切换才用分隔宣传页**。分隔页是「卷」级、普通线是「节」级，别混淆。
- 分隔页后第一行建议放该卷的小标题（章节标题）或一段导读，承上启下。
- **与目录 / 标题配合**：目录条目按卷组织时可与分隔页页码呼应；分隔页后第一个 `##` 用「章节标题」条目的样式并续上编号。

## 五、风格适配

- **国潮红金墨**：变体 C 深墨块 + 金标题，或朱红 `#b03a2e` 纯色 + 米白字；装饰用 art:// 植物图案（`art://blossom-branch` / `art://vine-frame`）或细纹。
- **科技蓝紫**：变体 A 用 `#3f5bc2` 纯色，圆角 10px，页码「00X」科技感；边框用细线科技块（变体 E）。
- **校园青春**：变体 A 用高饱和青 `#00b8a9`，大标题，圆角大（14px）更柔；不加图标字形装饰。
- **极简黑白**：变体 D 全黑墨块白字（或白块黑字 + 一道 1px 细线），零装饰，仅靠大字号与页码区分章节。
- **日系留白风**：变体 B 极浅衬底 + 深灰标题，大留白，页码灰 `#bbb`，宁静克制。

## 六、间距与尺寸（遵守硬规范）

- 分隔页整体与上下块距：上 **28px**、下 **16px**（`margin:28px 0 16px`）。
- 块内：`padding:36–40px 20px`（上大下小制造空气感，或均布）。
- 大标题 24–26px、`line-height:1.4`、字距 4px；页码 13–40px（视变体）字距 3–4px。
- 文字对比度：**深字压浅底、白字压实底**，保证可读（对比度 ≥4.5:1）；延伸装饰线不压字。
- 分隔页后接正文：回落 16px 块距。
- 若分隔页下方再补分割线，分割线上下 24px，别与分隔页的下 16px 叠加成 40px 大坑。

## 七、密度限制

- **一篇 ≤2–3 次**。超长文/特辑/连载最多 3 个分隔页，普通短文 0 次。
- 分隔页计数进「花纹 ≤2 种 / 装饰标题 ≤2 处」篇内上限；3 个分隔页都用纯色大块会显喧闹，建议浅/深交替。
- 分隔页是「卷」级标志；若每 500 字就放一个，等于把普通分割线升级成仪式，必显重复拖沓。
- 全篇分隔页的页码 / 编号体系统一（PART 01、02、03 连续递增），不许跳号。
- 一篇里最多一次用「装饰量」大的分隔页（如变体 E 顶条 + 边框），其余用纯块 / 浅块。

## 八、常见错误

- **反例**：1500 字短文每章放一个纯色分隔页，翻篇太快、页面全是色块。**正解**：普通短文用分割线，分隔页只给 3000 字以上 / 特辑 / 连载。
- **反例**：浅底块上压深色文字又用深纹装饰，对比不足看不清。**正解**：浅底衬深字、深底衬白字，装饰元素让位，保证可读。
- **反例**：分隔页 `margin:0`，跟前一章文字、后一章标题全粘连，没有「翻页」的留白感。**正解**：上 28px、下 16px。
- **反例**：三个分隔页一个橙、一个深墨、一个青，色彩体系混乱。**正解**：全篇分隔页同一色系语言（或浅深交替但同主色），与页眉统一。
- **反例**：分隔页大标题写 20 字长句，挤压到两行还折行难看。**正解**：标题 ≤12 字，短而有力，细内容放进该章正文。
- **反例**：把普通章节分割线也做成纯色满块，等于把分隔页密度撑爆。**正解**：分隔页只用于「卷」级，节级归普通线。



## 十、个性化空间

- **底色与衬边**：换账号主色 / 栏目色；判断依据品牌 VI；衬边方式（细边框 / 顶部色条）按栏目气质选（国潮靠深墨、科技靠细线）。
- **大标题措辞**：可写「卷名 / 章名 / 一句话主旨」；判断依据：超长文用章名，特辑用「上/中/下」+ 主题。
- **页码体系**：`PART 01` / `第一章` / `〇一` / `Chapter 1`；判断依据栏目语言与风格（科技用 Part、国潮用中文）。
- **是否带引文**（底部一句引文）：判断依据内容调性——观点/情感文加引文有仪式感，纯干货可省。
- **深浅交替策略**：3 个分隔页怎么排色；判断依据是整体色系统一原则——建议同一主色的深浅两档交替，或浅底衬边 + 一次深墨收束。
- **用量上限**：判断依据是文章「卷」数——有几卷才放几个分隔页，别硬凑仪式感。
