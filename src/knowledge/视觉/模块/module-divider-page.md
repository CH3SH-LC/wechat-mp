# 章节分隔与主题过渡（module-divider-page）

> 分隔服务已有章节关系：普通章节用轻分隔，真正的卷、篇或主题阶段切换才用封面式题头。只写当前 v2 语法；具体支持范围以 `排版引擎/engine-write-protocol.md` 为准。

## 让分隔延续主题

用户要求更花、更精致时，分隔应连接开篇、章标与图文框的主题。花枝在章标边缘出现，也可以在两章之间收束；票孔沿同一方向形成节奏；缎带与题头沿同一中轴或左边界组织。只有一根细线加零散小点，周围再撑出大片空白，不足以表达完整的主题设计。

`[[boxes:花笺]]`、`[[boxes:票笺]]`、`[[boxes:缎带]]` 会为题头、章节、气泡和分隔选用对应的统一语言。`ornament=botanical|ticket|ribbon` 可独立选择三种主题线饰；气泡骨架由 `shape` 决定。现有几何、网点、速度线可用 `ornament=confetti|dots|speed`，极简用 `ornament=none`。

## 可执行写法

普通章节间使用 `---` 即可让当前主题的分隔出现，不需要为每次过渡新生成图像：

```v2
[[theme:校园]]
[[boxes:花笺]]

## 原稿已有章节标题

该节完整正文。

---

## 原稿下一节标题

下一节完整正文。
```

`***` 为圆点分隔，`___` 为粗条，`~~~` 为丝带，`[[lace]]` 为花边分隔；这些是已有语法，不代表需要在一篇中轮流使用。优先保持同族结构，按前后内容的轻重选择。

原稿确有篇章级切换时，可用 `[[banner:原稿篇名|原稿已有副标题]]`，没有副标题就省略第二段。也可用现有色带语法：

```v2
::: band 条纹
原稿已有的篇章标题
:::
```

题头本身已经清楚标示新篇时，不再重复添加同名 `##`、手写页码和多道分隔。普通章节无需升级成占据大半屏的分隔宣传页。

## 密度、留白与形态

- 不按字数拆卷，不固定分隔页数量或装饰次数；原文有多少真实层级，就围绕这些层级设计。没有主题切换时可以不放分隔。
- 装饰可以持续呼应，但尺度要随角色变化。篇章起点可以展开，正文中段以较轻的同族元素连接；不把每个分隔都做成完整大框。
- 分隔前后留白共同构成一段过渡，不把分隔外距、标题上距与题签占位机械累加成无内容的大坑。
- 章节题头后紧接气泡时，给悬置题签留下实际空间。不能一边出现过大的章间空档，一边让标题框和下一题签几乎相贴。
- 所有分隔保持色温、线宽与对齐关系；花枝、票孔、缎带不在每章互换，除非原文确有需要区分的主题阶段。
- 装饰区与正文区分开，正文保持足够对比和连续阅读宽度。不通过拆句、删段、缩字或把原图改成小角饰来迁就版式。

## 成品复核

在375px视口连看章节末尾、分隔、下一章标题和第一段内容，确认过渡的整体节奏。只看到一条漂亮分隔不能证明整篇精致；须确认它与题头、章标及框体确实属于同一套设计。

内置主题分隔可重复使用，无需额外素材接口或生成调用。原稿图片、段落顺序与标题保持原样；极简、无底和少装饰等明确偏好优先。不写 HTML/CSS、旧素材地址或不存在的分隔变体参数。
