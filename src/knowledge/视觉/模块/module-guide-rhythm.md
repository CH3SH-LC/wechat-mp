# 模块衔接与阅读连续性（module-guide-rhythm）

> 定位：正文确定后，检查标题、图像、表格和提示块是否帮助定位与理解。

选材、标题、段落组织与结尾由 `文本/写作` 知识负责：按任务需要读取 `writing-purpose`、`writing-structure`、`writing-campus`、`writing-product`、`writing-explain`、`writing-story` 或 `writing-review`。视觉风格只决定呈现方式，不绑定文章结构、篇幅或语气。

## 沿内容关系安排

章节标题出现在实际主题变化处；流程用步骤呈现；可比数据用表格；图像与说明放在讨论它们的内容附近；来源与限定条件保持可找到。持续叙述可以保持普通段落，视觉不必定时换组件。

目录用于确有定位需要的内容，不因达到某个字数自动添加。气泡、引用和小结用于有独立作用的信息，不重复正文只为制造停顿。读者已经得到所需信息时，可以自然结束。

## 视觉基准

- 正文与块内行高参考 1.75，块间距参考 16px。
- 标题上方 28px、下方 12px；小标题可参考上 24px、下 10px。
- 图片与正文之间参考 12px，分隔线上下参考 24px；图注与对应图保持关联。
- 卡内文字距边框至少 12px。实际外观遵循当前引擎与所选版式。

这些是呈现参数，不是拆段、增补小结、改变文章顺序的理由。屏幕可见范围受字号、设备宽度和读者设置影响，不以固定屏数或字数推断疲劳点。

## 复核与调整

连续阅读时检查有没有孤立标题、错配图注、重复气泡、截断表格或不必要的分隔。先修复明确的布局问题；若主要问题是信息顺序或材料不足，回到写作知识修改内容。阅读数据只能作为线索，不能单凭读完率断定某一位置需要钩子或装饰。

实际输出以 `engine-write-protocol` 的 v2 语法为准。色板与版式分别选择；正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号与插画内部填色。保持零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用，生成需求使用协议支持的 `[[img]]` / `[[deco]]`；旧 HTML/CSS 片段仅用于理解视觉，不作为桌面输出语法。
