# 信息用途与模块选择（module-guide-matrix）

> 定位：按本篇实际信息选择模块；体裁名称不决定组件清单或全文顺序。

选材、标题、段落组织与结尾由 `文本/写作` 知识负责：按任务需要读取 `writing-purpose`、`writing-structure`、`writing-campus`、`writing-product`、`writing-explain`、`writing-story` 或 `writing-review`。视觉风格只决定呈现方式，不绑定文章结构、篇幅或语气。

| 已有信息 | 适合查阅的模块 | 使用前提 |
|---|---|---|
| 独立主题与分节 | header、heading、subheading | 正文确有对应的层级 |
| 需要快速定位的章节 | toc | 导航能帮助读者找到内容，条目对应实际章节 |
| 并列事项 | list、card | 项目具有相近层级 |
| 操作流程 | steps、checklist | 有实际顺序或可核对条件 |
| 时间节点 | timeline、countdown | 日期与节点已知；倒计时仅用于真实截止时间 |
| 数据或规格比较 | table、spec | 对象、单位、条件可比 |
| 真实引语与反馈 | quote、testimonial | 来源与适用范围可交代 |
| 图像或媒体证据 | image、media | 素材有效，说明不超出素材内容 |
| 活动、联系、招聘信息 | contact、job、miniapp | 读者确需这些信息与入口 |
| 价格与方案 | price | 价格、限制与对象已确认 |
| 相关材料与来源 | reading、disclaimer、footer | 补充理解、追溯来源或说明责任 |

校园、产品、解释与人物文章均可按需要取用上述模块。没有价格的产品介绍不补价格卡，没有读者行动的报道不补行动号召，没有实测材料的介绍不伪装成测评。

## 呈现检查

模块服务既有内容；同类信息的标签、单位、对齐和层级应一致。保留块距 16px、行高 1.75 等排版基准，通过实际宽度检查换行和留白。模块数量取决于材料关系，不按体裁、篇幅或运营目标分配配额。

实际输出以 `engine-write-protocol` 的 v2 语法为准。色板与版式分别选择；正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号与插画内部填色。保持零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用，生成需求使用协议支持的 `[[img]]` / `[[deco]]`；旧 HTML/CSS 片段仅用于理解视觉，不作为桌面输出语法。
