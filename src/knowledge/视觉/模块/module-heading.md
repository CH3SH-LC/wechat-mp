# 章节标题（module-heading）

> 当前桌面引擎用 `##` 表达原稿章节，`###` 表达节内层级。正文只写 v2；字号、编号与装饰由引擎排出。具体语法以 `排版引擎/engine-write-protocol.md` 为准。

## 标题参与整篇主题

章节标题是正文内部的锚点，应与开篇题头、图文框和分隔沿用同一套视觉语言。用户要求更花、更精致时，标题不能只剩默认序号与随意摆放的短线、小圆点；通过同族花枝、票孔或缎带，把主题从开篇带入正文。

| 声明 | 章节与全文的关系 |
| --- | --- |
| `[[boxes:花笺]]` | 花枝线饰在题头展开，在章节与分隔缩小呼应；适合花笺、节庆、自然气质 |
| `[[boxes:票笺]]` | 票孔与票面分界成为稳定标识；适合校园活动、资讯、市集与展览 |
| `[[boxes:缎带]]` | 缎带题头与章节线饰连贯使用；适合报道、纪念与仪式性内容 |
| `[[boxes:scale=display;ornament=confetti;align=left]]` | 大字与几何点线；适合明丽、活跃的主题 |
| `[[boxes:scale=standard;ornament=none;frame=none;label=none;mark=none;deco=none]]` | 无主题花饰、清楚的字形层级；尊重极简与安静阅读要求 |

`shape` 只决定气泡骨架，`ornament` 决定题头、章节与分隔的装饰。三个主题预置会同时选择两者；只改局部气泡时保留原预置，如 `[[boxes:缎带;shape=rail;frame=line]]`，避免章节突然回到默认样式。配色仍由 `[[theme:…]]` 或 `[[palette:…]]` 单独决定。

## 可执行示例

```v2
[[theme:校园]]
[[boxes:票笺]]

# 原稿大标题

原稿导语完整保留。

## 原稿第一节标题

该节已有正文完整保留。

---

## 原稿下一节标题

继续呈现原文，不为标题造型拆改自然段。
```

示例只说明标记关系，不指定本稿章节数，也不要求每两节之间都有分隔线。开篇已有 `#` 大标题时，不再用 `[[banner:同一个标题]]` 重复一遍；确需副标题的题头可改用 `[[banner:主标题|副标题]]`。

## 层级与编号

- 按原稿或实际主题关系使用 `##`，不按字数、屏数或装饰次数增删章节。`###` 只承载原有节内层级，不为了视觉变化混用。
- 新建标题不手写 `01`、`第一章` 等编号；引擎负责章节编号。用户给定标题中的编号和文字保持原样，交由引擎处理显示，检查成品不要出现自动数字与中文序号重复。
- 同层级标题延续同族造型，不必每章换一套框体。允许主题装饰持续出现；没有“装饰标题只能两处”的全文限制。
- 不把每个章标都做成大信息卡。章标与正文气泡需要有外观分工；附近已有气泡题签时，章标宜保持清楚的开放轮廓或主题题头。

## 375px 成品复核

题头应强于章标，章标应强于节内小标题；检查实际字重、颜色与尺寸关系，不把所有标题放成一样大。长标题自然换行，不能删词、缩窄字间距到拥挤或用固定高度裁切来追求一行。

检查章标与前段、章标与第一张气泡的实际距离，悬置题签占用的空间也应计算在内。若已有章标装饰，分隔可以沿用更轻的同族线饰，不再追加无关小点或形成很长的空白。装饰留在专用区域，不越过文字和照片的有效边界。

当前只用引擎支持的 v2：`#`、`##`、`###`、`[[banner]]`、`[[title:文字|box]]` 或 `[[title:文字|vine]]`。不写 HTML/CSS、旧素材地址或不存在的标题样式参数；不以局部截图清楚就宣称全文或真实微信预览通过。
