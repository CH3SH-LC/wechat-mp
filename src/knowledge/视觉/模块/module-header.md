# 标题与页眉呈现（module-header）

> 定位：用标题层级、对齐和线饰呈现本篇身份与视觉风格。页眉按实际需要取用，可以直接从标题进入正文。

## 内容边界

标题、副题、署名或栏目字段来自当前文章。副题只有补充信息作用时才添加，不自动填入卖点、紧迫感或口号。页眉不规定开头写法，也不要求后接关注条、目录或重点气泡。

## 视觉选项

- 素净标题：通过字号、字重与留白区分正文，可不加装饰。
- 线饰标题：通过对称或单侧细线呈现栏目识别，线条避让文字。
- 明丽标题：使用协议支持的展示字号、几何点线与主色，保持正文深色可读。

既有尺寸参考：主标题 22–32px，副题 14–15px，署名 13px；标题字距依据实际换行在 0.5–6px 范围调整。页眉下方保持 16px 块距；标题区可参考 20px 16px 或 30px 20px 的留白，线饰宽 70–110px、高 1–2px。具体尺寸由引擎和可用版式实现，不为凑一行删掉标题含义。

## 色板与素材

国潮可参考金 #c9a063、墨 #2a2a2a 与朱红 #b03a2e；科技可参考蓝紫 #3f5bc2；校园可参考青 #00b8a9；极简可参考近黑 #1a1a1a 与灰 #666；日系可参考米灰 #8a8078。色板不绑定副题语气或文章体裁。

需要图像时使用有效资产并检查授权、裁切和清晰度。不要把生成图伪装为活动记录，不把装饰文字当作真实署名或日期。

## 复核

核对标题与正文一致，副题没有重复标题，起始文字可找到，换行、字距与装饰没有遮挡。显式极简与明丽要求均通过设计轴实现，不改变全文顺序。

具体输出遵循 engine-write-protocol 的 v2 语法：色板与版式独立，正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号和插画内部填色；零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用。选材与组织按需查阅 文本/写作 的 writing-purpose、writing-structure、对应场景知识与 writing-review。
