# 模块 · 金句 / 大字号引用

> 定位：对文章中确有必要强调的观点或真实引文作独立呈现；组件不负责制造金句、情绪顶点或转发口号。
> 调用时机：材料中已有适合强调且与正文有关的内容时使用；没有合适内容就不使用，不规定全文位置。
> 一句话区分：金句是把"正文里的最强音"放成的大字，底色可淡可无、重在居中与字号；气泡是把"某段要单独强调的话"装进的色块，重在分块与底色。两者视觉节奏相反、可互相呼应，但同一屏只上其一。

## 一、可用写法与语法

写作语法用引用符号 `> 一句话`：编辑器会把这句套成引用样式（左竖条、稍缩进），排版上再把它做成 **居中大字 + 装饰**，与普通正文（默认左对齐、16px）截然区分。引用语法只是"标记这句话要特殊处理"的信号，真正让它"像金句"的是放大、居中、归位这三步加工。

**内容条件**：真实引语保留原文与必要语境，作者观点须有正文依据；需要解释时使用可换行引用或普通正文。不得套用反转、对仗、安慰或励志句式来补齐组件，也不得为了放大字号缩短原句。

**放大字号建议**：金句正文用 **18-20px**（比正文 16px 大两档，够清楚又不溢屏）。不需要像标题那么大（标题另有规范，zh字 20px 以上走标题权力）；金句是"正文里的重音"，不是章节头——抢了标题的层级，读者就分不清"这是标题还是引用"。

## 二、双模式表现（文字类/宣传类）

**文字类（文字排版优先）**：最克制的做法是"居中放大的正文"——保留同色系正文颜色或加深一档、字号 18px、加粗、可配一条细横线或一个引号符号。不换底色、不加渐变，靠字号与居中制造"停顿"。适合观点文、情感文、干货文的收束，读者视角是"这段读得慢一点"。文字类的核心是"话本身够分量"，装饰只是给停顿加一个台阶。

**宣传类（视觉优先）**：可以在金句上下各放一条装饰线，或用品牌色引导、把整句套进一个浅色横条/大引号背景。视觉更重、更像"全书腰封一句话"。适合促销、品牌宣言、活动 Slogan。宣传类的核心是"这句话得被亮出来"，底纹/横线/引号把记忆点从流动的正文里"钉"住。

**两个模式在同一篇里只选其一**：文字类全文金句只做居中大字，宣传类全文金句统一带装饰。不要这一句加底纹、下一句纯大字——混用等于让读者以为"底纹和纯字是两种不同语义"，破坏一致性（见模块组合铁律）。金句虽多自选，但模式要全篇统一。

## 三、样式变体（5 种常用，具体参数）

金句装饰走"四选一"的克制路线，以下给最常用的 5 种模板。**所有金句统一 `line-height:1.75`、底部 `margin:0 0 16px`**。装饰一律用 CSS 几何形状（细线、引号用 CSS 拼接或 `art://` 植物图案），不写 emoji 与图标字元（装饰引号、菱形等十进制装饰符一律禁止）。

**变体 A｜引号 + 居中大字（最常用）**——适用：一切观点文、评论、干货文收束：
```html
<p style="text-align:center;font-size:20px;font-weight:bold;color:#7a3cec;
line-height:1.75;letter-spacing:1px;margin:0 0 16px;">[需要强调的完整引文]</p>
```
- 参数：`font-size:20px`、居中、加粗、颜色用品牌紫 `#7a3cec`、`letter-spacing:1px`、行高 1.75（金句一般单行，行高仍按规范不塌）。可换主色橙 `#ff6b35`。判断依据：有没有一句"全文只需记住它"的话——有就非它莫属。

**变体 B｜上方/下方装饰横线**——适用：想强调"仪式感"、章节收束：
```html
<p style="text-align:center;font-size:18px;font-weight:bold;color:#333;
line-height:1.75;margin:0 0 16px;">[需要强调的完整观点]</p>
```
- 参数：两侧 `—` 用 `&nbsp;` 前后对齐；正文 18px、色 `#333`、居中。横线是"括住金句"的信号，比引号更中性，专业与克制场合都稳。需要更醒目的分隔，可用一个细 `border-top` 的短横线居中（见变体 F）。

**变体 C｜淡色底纹衬底（宣传类首选）**——适用：促销、Slogan、活动、品牌宣言：
```html
<div style="background:#fff7f2;border:1px solid #ffe0d0;padding:18px 16px;
border-radius:10px;margin:0 0 16px;text-align:center;">
  <p style="margin:0;line-height:1.75;font-size:19px;font-weight:bold;color:#ff6b35;
letter-spacing:1px;">[已有正文依据的完整表达]</p>
</div>
```
- 参数：浅橙纯色底 `#fff7f2` + 细边框 `1px solid #ffe0d0`（替代原渐变淡底）、圆角 10px、padding 18px 16px、文字 19px 橙字加粗居中。底纹像"聚光灯"，纯色浅底配深字、对比度高，反色风险低。

**变体 D｜引号 / 植物图案装饰（文艺式）**——适用：情感收尾、文学感、深夜暖文：
```html
<p style="text-align:center;font-size:15px;color:#999;line-height:1.75;
margin:0 0 10px;">![小草](art://sprig-grass)</p>
<p style="text-align:center;font-size:20px;font-weight:bold;color:#333;
line-height:1.75;margin:0 0 10px;">[有来源的引文原文]</p>
```
- 参数：上方用一枚 `art://` 植物图案（sprig-grass 小草 / vine-frame 藤蔓）作点题装饰，下方可再加一枚；正文 20px 加粗；装饰与正文间距 10px、整组底部 16px。整体构成"被引用"的回声，文学感最强。

**变体 E｜同色系深浅双行（结论式压轴）**——适用：全文最后一句点题、价值陈述：
```html
<p style="text-align:center;font-size:20px;font-weight:bold;color:#7a3cec;
line-height:1.75;letter-spacing:1px;margin:0 0 4px;">[需要强调的内容]</p>
<p style="text-align:center;font-size:15px;color:#7a3cec;line-height:1.75;
margin:0 0 16px;">[引文署名或已有补充信息]</p>
```
- 参数：主句 20px 紫字加粗，副句 15px 同色系浅一档、行首带 `——`。判断依据：主句是"题眼"、副句是"致谁/给谁的落款"，副行仅在已有信息需要单独标注时使用。

**变体 F｜品牌单色系「一行大字 + 底部细线」**——适用：品牌克制风：
```html
<p style="text-align:center;font-size:19px;font-weight:bold;color:#2777ff;
line-height:1.75;letter-spacing:1px;margin:0 0 4px;">[有依据的观点原文]</p>
<p style="margin:0 auto 16px;width:40px;border-top:2px solid #2777ff;"></p>
```
- 参数：品牌蓝 `#2777ff` 大字 + 底部 2px 蓝色短横线（用 `border-top` 实现，宽度 40px 居中）。判断依据：品牌色够不够撑起"一句话 + 一条线"的克制感——能就用，最显高级。

## 四、使用时机与位置

- **位置**：与引用所支持或回应的内容相邻，先后顺序由文章逻辑决定，不规定用作开场、压轴或行动号召前的铺垫。

## 五、风格适配（4 个例子）

- **极简/商务**：只留变体 A 的居中大字，16-18px、深灰 `#333`、不加引号和线，靠大量留白突出。金句越素越高冷，适合品牌号、知识付费号。
- **国潮风**：变体 B 的横线换成"菱形分隔"（CSS 旋转 45° 方块 span）：`<span style="display:inline-block;width:6px;height:6px;transform:rotate(45deg);background:#c0392b;"></span>`，文字用朱砂红 `#c0392b` 或墨色 `#2f2a26`，加 `letter-spacing:2px` 更有"题字"感，适合传统文化、汉服、文创号。
- **港风/城市感**：变体 C 底纹用青蓝浅纯色 `rgba(0,184,169,0.10)`，文字用霓虹感青色 `#00b8a9`，加粗压满，像街头灯箱，适合探店、城市生活号。
- **童趣/教育**：变体 D 装饰换成 `art://` 花枝/叶角图案（blossom-branch / leaf-corner），字号 20px 明亮色，适合亲子号、少儿教育号。

**风格统一原则**：金句的装饰语言要与整篇其他模块（标题、卡片、列表）保持一致——如果标题用墨色衬底，金句底纹也跟墨色系；如果全篇极简灰阶，金句就别贸然上彩色。金句是"正文的重音"，不是"突然换肤"。

## 六、间距与尺寸（遵守硬规范）

- **金句与前后**：底部 `margin:0 0 16px`（块距基线 16px，见 00-GUIDE「间距硬规范」）。金句是"压轴话"时，下方距下一块仍是 16px，不要为了"留白"用空占位超 24px——那是大章节切换才用的。
- **行高**：金句即便单行也设 `line-height:1.75`（与正文一致），避免浏览器默认行高把空 p 撑高或塌掉，扫读节奏不乱。
- **字号**：正文 16px → 金句 18-20px。**不要**大到 24px+ 抢标题的层级，也不要只比正文大 1px 等于没强调。按实际换行选择 18–20px，不截断原意。
- **装饰尺寸**：横线 `—` 或 `art://` 植物图案用 15-16px，明显小于金句，起"脚手架"作用，不跟正文比大。装饰越大越抢戏，金句反而变配角。
- **字距**：金句可加 `letter-spacing:0.5-1px`（硬规范正文 0.5px 起），加太多（>3px）在短句中反而散。标题字距 1-6px 是标题的权力，金句守住 1px 上限。
- **内距**：带底纹的变体 C padding `18px 16px`，内容与边框 ≥12px 满足硬规范；无底纹的纯金句不含内距。

## 七、配色配合（与全篇色盘协同）

金句不是独立元素，它的颜色必须从全篇色盘里"取"。推荐的做法：**正文只用 1 个主强调色贯穿所有强调点**（金句、卡片、列表符号、高亮共用同一主色）。

- **单主色用法**：整篇金句统一用一个主色（如紫 `#7a3cec`），靠字号与装饰强弱而非换色来分轻重——压轴金句上 20px 加粗，普通强调只 17px 不加粗。最克制、最容易维护。
- **双主色用法**：一个主色 + 一个文案色（如"主色紫 + 深灰 `#333`"）。需要"记忆点"的金句用品牌紫，需要"沉稳收束"的金句用深灰。对比较温和，观点文/情感文常用。
- **同色系加深**：想让金句"收在正文体系内"，直接用正文主色加深一档（如正文 `#333` → 金句 `#111`）；想让它"跳出来成为记忆点"才用品牌色。
- **避免**：金句用多种鲜艳色轮番上（紫一句、红一句、橙一句），读者以为每句都是不同的强调级别，整齐感全无。全篇金句颜色 ≤2 个主色最佳。
- **与正文关系**：金句颜色与正文 `#333`、正文灰 `#555` 区分度要够，深字浅底对比度 ≥4.5:1（见「可读性」维度）。金色/亮黄这类低对比色当大字要谨慎，白底上会看不清。

## 八、微信兼容注意

写金句时的"可用子集"与"要绕开的坑"（微信富文本编辑器）：

- **可用**：`text-align:center`、`font-size/font-weight/line-height:1.75/letter-spacing`、`background`（纯色）、`border-top/border-bottom`（细线装饰）、`border-radius`（4/8/10/12）、`padding/margin`、`width`（配 `margin:0 auto` 做居中短线）。
- **尽量别用**：`backdrop-filter`（基本不生效）、多层投影（旧端锯齿）、描边发虚的粗文字（安卓端渲染飘）、伪元素 `::before/::after`（编辑器多剥除，横线别用它做）。本规范不推荐渐变，底纹统一纯色 + 细边框。
- **反色风险**：金句大字要避开"白字叠在亮色上"——安卓端极易看不清。要么深字浅底（变体 C 正是这种最稳组合），要么深色底白字（变体 F 用深青整卡），别硬叠白字亮底。
- **空行撑高**：别用多个空 `<p style="margin:0;">` 来造金句上下留白，空行在手机端会叠出多余行高；留白交给金句自身的 `margin-bottom` 即可。
- **通用兜底原则**：任何装饰"锦上添花"时，优先保留"居中大字已可独立成立"的裸版——装饰失效后，纯居中大字仍然成立、仍然像金句。

## 九、密度限制（重要）

- **重点层级**：只突出确有必要强调的内容，不要求每篇制造金句或用金句收尾。
- **一句金句只做一个装饰**：要么引号、要么横线、要么底纹、要么短线——别金字+横线+底纹一次堆齐（那不是金句，是海报）。装饰通道一次只开一个。
- **金句不与气泡抢同一屏**：这一屏已有 `KEY` 重点气泡（见「模块 · 重点气泡」），就别再放大字号金句，二选一。金句是"静谧的重音"，气泡是"跳跃的色块"，节奏相反、撞车就互相稀释。
- **金句也不与其他强装饰叠屏**：已有花纹色带和大字号标题时，复核再加金句是否重复强调；不以全文气泡或金句数量反推正文。
- **能用加粗句装下的普通结论，不上金句**：金句是"全文顶点"，普通段落里一句普通加粗就够，别把每段的结论都放大成金句。

## 十、常见错误（反例 + 正解）

- **反例**：把普通说明改成无材料支撑的对仗格言。**正解**：先判断是否需要独立强调；保留原意和条件，不需要时用普通正文。
- **反例**：金句用了 26px 大红色 + 阴影 + 斜线 + 底纹，比标题还扎眼 **正解**：金句 ≤20px，单装饰，与正文同色系但更重一档，别抢标题层级。
- **检查**：重点是否过多而难以辨认；用实际论证作用决定保留哪些强调。
- **表达完整**：不为制造停顿省略主语、关系或条件，不用连续断行把一句话排成伪诗句。
- **反例**：金句放在正文中间却与上下文割裂，读者不知道它从哪来 **正解**：金句紧跟它所总结的那个观点段落，作为该段的"回扣句"，别悬空。
- **反例**：金句用亮黄/浅金大字，白底上对比度不足，手机端糊成一片 **正解**：金句颜色与底色对比度 ≥4.5:1，深字浅底或品牌深色大字最稳（见「可读性」维度）。

> [引用原文与必要的上下文]
```

line-height:1.75;letter-spacing:1px;margin:0 0 16px;">[已有正文依据的完整表达]</p>
```
**可替换处**：`font-size:20px`、颜色 `#7a3cec`、`letter-spacing:1px`；依据实际重点及手机换行选择呈现，不以截图传播潜力改写正文。

**使用位置**：由实际信息关系决定，不统一安排开头、中段或结尾组合。内容选取与组织按需查阅 文本/写作/writing-purpose、writing-structure、对应场景知识和 writing-review；本条只处理组件呈现。

## 十二、个性化空间（可调参数与判断依据）

- **字号**：18/19/20px 三档。判断依据：检查实际换行与层级；行长了就降字号，别砍内容。
- **装饰语言**：引号（文学/感怀）、横线（仪式/中性）、底纹（宣传/品牌宣言）、纯大字（极简/高冷）、bottom 短线（品牌克制）、art:// 植物图案（文艺/亲子）。判断依据：账号语气和文章位置的"情绪浓度"，越安静用越少装饰。
- **颜色**：正文同系加深、或品牌主色。判断依据：想让金句"收在正文体系内"就用同色加深一档；想让它"跳出来成为记忆点"就用品牌色。
- **位置**：与相关论述相邻，由内容关系确定；不自动在段末或全文末尾增写总结。
- **副行**：只承载已有引文署名或确有用途的补充；不自动加致意、安慰或献给读者的句子。
- **大字是否加粗**：18-20px 金句通常加粗，但极简高冷风可保留 `font-weight:500` 不加满。判断依据：走的语气是"铿锵"还是"清冷"，前者加粗、后者靠留白。
