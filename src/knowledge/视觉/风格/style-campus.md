# 校园风（style-campus）

> 定位：青春、明快、元气，像操场边的招新海报和一颗随手记在本子上的可爱便签，亲切又热闹。
> 调用时机：校园活动、社团招新、学习笔记、新生指南、学生党生活类内容，以及任何想"像同学拍了拍你肩膀"的年轻向轻内容。

## 一、气质与适用内容

**气质关键词**：青春、明快、元气、亲切、轻松、有活力；不端着、不严肃、不过分甜美，是一种让人想"一起玩、一起学"的邻家感。

**适合的内容类型与行业**，逐项说明为什么合适：

- **校园活动**：社团招新、迎新晚会、运动会、毕业季、校园市集、开学季企划。这类内容要"拉人参与"，校园风的贴纸标题和活泼的几何点缀天生适合号召。
- **学习信息**：考研、四六级、考试攻略、课堂笔记整理、高效学习法、时间管理（学生版）。学生读者最吃"明快清晰"的排版，校园风把干货包成好懂的样子。
- **学生党生活方式**：宿舍好物、平价穿搭、食堂/校园小店探店、省钱攻略、青春读物推荐。目标读者就是学生群体，风格与读者画像天然对齐。
- **年轻向轻互动**：校园采访、同学圈热点、趣味盘点、毕业季企划，需要轻松有参与感，校园风正好。

**不适合的场合**，逐项说明为什么是雷区：

- **严肃财务/医疗/法律内容**：这些领域要靠专业与权威说服，校园风的可爱会削弱可信度，读者会怀疑"这靠谱吗"。
- **高端品牌发布会**：奢侈品牌、旗舰新品发布会需要克制与质感，校园风会显得轻率、掉价。
- **B 端与决策层内容**：面向企业决策者、中年管理层的内容，校园风不够稳重。
- **品牌宣言/需留白的场合**：校园风本身偏"满"，与"留白高级"背道而驰。

**一句话判断标准**：内容要让读者感到"像被同学拍了拍肩膀、说咱们一起吧"，就用校园风；要让读者"正襟危坐、认真研读一份专业材料"，就别用。

## 二、完整色板表

**背景色**：

```text
#FFFFFF        纯白底：正文整体底色，清爽不闷，是校园风的主流底
#F2F8FF        浅天蓝：分区卡/重点块底，像晴天的一片蓝
#FFF6F2        浅珊瑚白：装饰块底，给暖色调一个软的落脚点
#F5F9F5        淡薄荷底：偶尔用于清新分区（三色淡底轮换着用，不堆在一起）
```

**主色**（挑 1 个做文章主线，忌三个都铺满）：

```text
#2F6FED        活力蓝：主标题、重点按钮色，就是校服和校徽上的那个蓝
#FF5E7A        珊瑚粉：搭配蓝色的暖色，副标题/贴纸点缀；女生向内容可以把粉做主力
#FFBE3D        明黄：高亮点缀、印章感，全篇用量最少，抢眼才有效
```

**辅助色**（结构用，弱化用）：

```text
#5B6B8C        深蓝灰：次级文字、图表里的线
#7A8BA6        中灰蓝：说明文字、小注释
#95A6C4        淡灰蓝：分割线、几乎不想被注意的弱化元素
```

**强调色**（全篇 ≤2 个，专门用来点名）：

```text
#FF6B35        活力橙：行动引导（CTA）、重点数字，让人想去点
#2EC4B6        青绿：批注/横批上的小强调，清爽提神
#FF3B5C        正红：最强的强调，只给"限量、中奖、必看"这种词
```

**文字色**：

```text
#3B4252        正文墨蓝灰：正文主色，避免纯黑（这是全库硬规范）
#5C6B8A        次级灰蓝：正文里的注释、辅助说明
#2E3A55        标题深蓝：标题用，比正文更实在
```

**深浅两档怎么用**：

- **浅档（默认）**：白底为主，淡蓝/淡粉卡片做层次。适合校园活动、学习笔记——清爽、日光明亮、像白天上课的教室。
- **深档（少用）**：深蓝 `#2E3A55` 底 + 白字 + 珊瑚粉/明黄点缀，多用于热闹的招新倒计时、晚间活动预告，或结尾的行动号召卡。深档通常在"横幅卡"和"行动卡"局部用 1–2 次，不建议满篇深底（会盖过青春明快）。

## 三、标题与字号层级

**标题样式特征**：大圆角"贴纸胶囊"感——白字彩底、圆角圆润、可配一个细线小胶囊角标。这是校园风里最醒目的记忆点，刻意做得不像商务风的硬直角，而是"像幼儿园玻璃上贴的卡通贴纸"。

**装饰语法**（全部是微信正文可用的内联样式写法，无伪元素、无外链字体、无 script/style 标签）：

- **胶囊标题**：`display:inline-block` + 彩底 + `border-radius:12px 12px 12px 4px`（右下角小斜切，像贴纸被揭起一角）+ 白字 + `padding:8px 16px` + `margin:0 0 16px`。字多会撑破，胶囊里字越少越好。
- **左竖条标题**：`border-left:6px solid #2F6FED` + 深蓝字 + `padding-left:12px`，给次级章节标题用，比胶囊更"正经一点"。
- **下划线标题**：主色 `border-bottom:3px solid #2F6FED` + 标题字下方 `padding-bottom:8px`，活泼又清楚。
- **小圆点前缀**：标题前放一个主色圆点（用 `span` 置 `border-radius:50%` 拼出的正圆）或菱形（`transform:rotate(45deg)`），成本最低又很校园。

**字号字重建议**，给出一张可直接照用的表：

| 层级 | 字号 | 字重 | 行高 | 用法 |
|---|---|---|---|---|
| 主标题（胶囊） | 18–20px | bold | 1.5 | 每章第一屏的贴纸标题 |
| 章节标题（竖条） | 16–17px | bold | 1.5 | 左竖条/下划线标题 |
| 小节/副标题 | 15px | 600 | 1.6 | 浅蓝底色块上的小标题 |
| 正文 | 15px | normal | **1.75** | 硬规范行高，字距 0.5px |
| 注释/标注 | 13px | normal | 1.6 | 灰蓝注释、来源标注 |

**间距硬规范**：标题上方留白 **28px**、下方 **12px**；区块之间统一 **16px** 底部间距；气泡内 `padding:14px 16px`。这些是全局铁律，改任何一条都要谨慎。

## 四、模块表现

在本风格下，每个模块给到具体可执行的数值：

- **重点气泡**：浅蓝底 `#F2F8FF` 或浅粉底 `#FFF6F2`，圆角 **14px**（比极简更圆润、比插画更收敛），`padding:14px 16px`（硬规范），左侧可加 `border-left:4px solid #2F6FED` 做主次强调；气泡内文字行高 1.75。气泡左上角可用一个 `span` 圆角小方块（约 12px、主色）当"角标"，或引用 art:// 植物图案 sprig-grass 小草做角饰，一个气泡顶多加一处装饰，避免杂乱。
- **卡片**：浅色底 + **圆角 16px** + 细边框 `1px solid #DCE6F5`，内文 `padding:14px 16px 12px`；顶部可加一条 **4px** 主色横条当"卡片标题带"，像贴在卡片上的标签。卡片和卡片、卡片和文字之间一律留 **16px**。
- **分割线**：不整条横穿——用「**点状/虚线 + 单个几何符号居中**」的分隔。写法：`border-top:2px dashed #B9C8E2`，下一行居中放一个主色圆点（span 正圆）或菱形，或 art:// 的 sprig-grass 小草图案（不要重复，一个就够）。分割线上方 **24px**、下方 **24px**（硬规范）。
- **花纹/底纹**：用**低饱和纯色**铺浅色"格纹"或"圆点"底，明度必须压得很低，近似 `#F2F8FF` 级别，只做背景氛围、绝不喧宾夺主。不用渐变、不用投影，靠细线（`2px dashed`）或稀疏圆点拼底纹。花纹全篇 ≤2 种。
- **列表**：用主色圆点/菱形（span 几何形状）当项目符号，每行 `line-height:1.75`。**忌**用系统默认的黑色实心圆圈（那是没排过版的样子）。
- **步骤**：横向"1→2→3"或纵向"圆圈编号 + 短句"。编号圈用主色实底白字、直径约 **24px**、圆角 50%（正圆）、`line-height` 对齐中心；编号旁文字 15px、行高 1.6；步骤之间 16px。
- **按钮式行动号召**（结尾做 CTA）：橙色 `#FF6B35` 实底白字、圆角 **20px**（椭圆胶囊）、`display:inline-block`、`padding:10px 22px`，旁边配主色「立即参加」字样，像操场边的报名处。按钮不用投影、不加渐变，纯色实底即可。

## 五、图片与装饰

- **图片处理倾向**：统一 **圆角 12–16px**，不让图露直角边。色调喜欢用**明亮/清透滤镜**（提亮、轻微提饱和、去灰）。比例多取 **4:3**（校园人文、活动合照）或 **1:1**（学习好物、单品）。图片上、下各留 **12px**（硬规范）。
- **氛围叠加**：可用低饱和主色纯色块罩在图片一角做"校园青春感"，或用一张不透的字卡盖住图片底部放标题；不叠加渐变、不加光影。图片是内容不是背景海报。
- **装饰克制**：装饰要低，只点缀关键处。标题可带 1 处角标、段落开头或关键句可带 1 个几何前置符号、重点气泡可配一处小草角饰。一个合理的目标是**每屏装饰点缀 ≤1 处，宁可留白**。绝不堆叠：一段 ≤2 处点缀，一屏 ≤5 处，否则会乱。
- **可用 art:// 植物图案**：校园风可引用大自然植物图案做装饰——**sprig-grass 小草**（做气泡角饰、分割线点缀）、**blossom-branch 花枝**（做标题旁的小花角）。只在标题、气泡角、分割线中央放，绝不用图标类图案、不用 emoji/Unicode 图标字符。

## 六、文案调性

**语气关键词**：亲切、元气、并肩、轻松；像学长学姐在给新人指路，不教训、不端着、不油腻。

**句式倾向**：
- 多用"一起 / 咱们 / 别忘了 / 这里有个小技巧"这种并肩语。
- 句子短，动词开头（"报名就送""先看这篇""试试这样做"）。
- 感叹号**克制**（每 100 字 ≤2 个），卖萌适度——"啦"可以用，"呀～"偶尔一个就够了。
- 可以用少量括号小感慨「（没看错，是真的）」，增加亲切感。

**示例句**（可直接套用或改写）：

- "开学第一周，社团招新开始啦！三个理由，让你爱上摄影社。"
- "这份四六级时间表，我亲测了两个月，真的管用。"
- "别盲抄笔记了，这个三步法，帮你把一节课 30 分钟拿下。"
- "周末去操场走一圈，正好撞上校园集市，全是宝藏摊位。"

## 七、禁忌与陷阱

这一节最容易把校园风做砸的地方，逐条给反例与正解：

1. **配色太花、太杂**：天蓝+粉+黄+橙+青全上 → 画面杂乱无重点。
   - 反例：标题是蓝、气泡是粉、强调又黄又橙又绿，全都要。
   - 正解：锁定 **1 个主色（蓝）+ 1 个暖色（粉或黄，二选一）** 打底，强调色全篇 ≤2 个，其余当极小点缀，点到为止。

2. **可爱过头、文案太嗲**：通篇"呀～啦～啾咪"→ 读者腻且不专业。
   - 反例："可爱死了呀啾啾～我要好好收藏～"
   - 正解：亲切但实用，卖萌点到即止，主信息永远清楚。

3. **分隔线乱撒点缀**：每条分割线都塞一条装饰 → 视觉噪音。
   - 反例：每隔 3 行就一条重复小图形装饰的横线。
   - 正解：分割线的点缀符号 ≤1 处、只在切换大章节时用；普通段落之间用留白或小圆点分隔即可。

4. **贴纸标题字太多**：把一整句口号塞进胶囊标题 → 胶囊被撑破、换行难看。
   - 反例：胶囊里放"新学期我们一起努力向上的每一天"这种长句。
   - 正解：胶囊字 **≤8 字**，长句子拆成"主标题短词 + 下方正文短句"。

5. **忽略可读性**：明黄底配浅字、浅蓝底配白字 → 对比度不够看不清。
   - 正解：彩底一律按"亮度深浅"配字色——**深蓝/正红底配白字**，**明黄/浅粉底配深字** `#3B4252`。拿不准就看底色 RGB 亮度再定。

## 八、混搭方向

校园风可以与相邻风格混搭，用「主 : 辅」比例控制：

- **校园 × 二次元（7 : 3）**：社团漫展、追番同好向内容，用校园的清爽底 + 二次元的萌系贴图与分镜卡。
- **校园 × 运动活力（6 : 4）**：运动会、健身、体育类内容，把校园的贴纸标题换成斜切色块与号服数字（见"运动活力"变体条目）。
- **校园 × 手账（7 : 3）**：学习笔记、复习打卡，加入手账的虚线框与待办清单模块，"正在做笔记"的感觉更强。
- **校园 × 美式复古（8 : 2）**：复古运动/日漫风标语，偶尔用奶油色做点缀，不喧宾夺主。

混搭的规则见"风格混搭与主辅法则"条目：**主风格负责开头与整体配色，辅风格只做模块级局部点缀**，别让两种风格平分秋色。

## 九、封面建议

- **构图**：居中一个大图形（一个可爱吉祥物 / 书本 / 棒球帽），上方或下方放胶囊标题；画面留白充足，别塞满。
- **配色呼应**：封面主色取正文主色（蓝或粉），再配一个暖色点缀（黄或橙）；背景用浅天蓝或白。
- **字要少**：封面大标题 ≤6 字，副标题一句话，别放目录式长文案。
- **气质**：笑容、明亮、青春；学生形象或纯图形皆可，别用昏暗压抑的画面。

## 十、深色模式表现

- 校园风的深档本来就是"深蓝底 + 白字"，暗黑模式下天然舒适：把浅蓝卡 `#F2F8FF` 换成深蓝卡 `#1E2A45`，白字不受影响。
- **重点注意**：浅粉气泡 `#FFF6F2`、明黄强调 `#FFBE3D` 在深色底上饱和度过亮会刺眼——深色模式下降一档明度（黄用 `#C9A227`，粉用 `#C96A7E`）。
- 正文文字在深底上保持 `#C9D2E3`（浅灰蓝）级别，不要用 `#3B4252` 的深字，会看不清。
- 说明：推文默认以浅色为主；如果账号读者大量使用深色模式（夜读段、年轻读者居多），可以考虑整篇走深档，但要看账号风格是否适合。

## 十一、个性化空间

这一节是"知识卡"而非"死模板"，明确哪些参数可按账号自定、以及判断依据：

- **品牌/校徽色替换**：如果账号有固定品牌色或代表色（如社团代表绿、学校校徽色、IP 角色色），把本条的活力蓝 `#2F6FED` 换成品牌色即可，其余配色逻辑不变——仍是"主色 1 个 + 暖色 1 个 + 黑白色点缀"。**判断依据**：品牌色出现频率高的账号优先用品牌色当主色，正文气质更统一、更有识别度。
- **冷暖偏好**：女生向/萌系内容可加重珊瑚粉在标题里的占比；纯干货学习笔记可把暖色降到最低、只留明黄做高亮。**判断依据**：读者性别构成与内容情绪。
- **装饰密度**：活动宣传（要热闹、要参与）可提高贴纸、分割线、几何点缀密度；学习干货则降密度（少花纹、少点缀、多留白）。**判断依据**：内容是让人"冲动参与"还是"安静读完"。**克制底线**：装饰点缀每屏 ≤1 处，宁可留白，靠细线与留白层次而非靠密铺。
- **年龄段微调**：初高中读者可更大字号（标题 20px）、更多几何点缀、更大圆角（16px）；职场青年则收敛点缀、收紧贴纸感、圆角降到 12px。**判断依据**：读者年龄与屏幕阅读习惯。
- **深浅档倾向**：主打活泼海报的账号可偏深档局部（横幅、倒计时），纯干货账号保持浅档清爽。**判断依据**：账号整体视觉定位。

> 记住：校园风的灵魂是"青春明快但有序"。**明快不等于杂**，配色、装饰、点缀密度都可按账号调，但"主色要统一、符号要克制、正文要可读"这三条底线别破。

## 十二、全篇排版走一遍示例

这一节用"社团招新 + 学习干货"两个典型场景，把校园风从头到尾串一遍，方便调用方照着拼装。注意所有写法都遵守硬规范，可直接落到微信正文。

**示例一：社团招新横幅式开篇**

```text
[装饰] 标题（胶囊：白字蓝底，左上角配一个小方块角标）
  社团招新，开始啦！
[正文] 正文首段（深蓝灰 #3B4252）
  这是我们今年最大的一波招新，三个理由，帮你决定要不要加入摄影社。
  第一个理由——免费借单反；第二个——每周一次外拍；
  第三个——帮你攒下一整套作品集。
```

**示例二：学习干货的分点与步骤**

```text
章节标题（左竖条 #2F6FED）
  四六级时间表，三步拿下
1 2 3（蓝色实底圆圈编号）
  圈 1 圈 2 圈 3 对齐三条短句
卡片1（浅蓝底 #F2F8FF + 圆角 16px + 顶部 4px 蓝条）
  晨读 30 分钟（7:00–7:30）
卡片2（同上，深浅轮换可用浅粉）
  晚间真题 45 分钟（21:00–21:45）
按钮 CTA（橙底 #FF6B35 + 20px 圆角 + 白字）
  领取完整时间表
```

**这两段示例说明的排版要点**：

- 每一个大块（标题、气泡、卡片、按钮、分割线、图片）之间，都留 **16px** 的底部间距。
- 标题类（胶囊/竖条）统一处理为"上 28px、下 12px"；移动端阅读时这个落差刚刚好。
- 一段正文内保持行高 **1.75**，字距 0.5px，段与段之间自然有 16px。
- 一个装饰点缀只出现在标题角标、段落开头、气泡角、列表符号这四处，绝不在正文句子中间乱插。
- 全篇主色只走"蓝 + 粉/黄"这一组，强调色最多 2 个（橙色 CTA + 一个红色"限量"词）。

**调用方落地清单（检查一遍再定稿）**：

- [ ] 主色是否统一（1 蓝 + 1 暖色，没混进第三种高饱和）
- [ ] 每个块间距是否 16px、正文行高是否 1.75
- [ ] 气泡 padding 是否 14px 16px、标题上下是否 28px/12px
- [ ] 装饰点缀是否克制（每屏 ≤1 处，一段 ≤2 处）
- [ ] 正文是否用深蓝灰而非纯黑
- [ ] 章节是否有至少一个"安静区"（普通浅底段落），别满屏贴纸
