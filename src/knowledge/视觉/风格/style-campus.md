# 校园风（明快配色与贯穿全文的主题装饰）

> 适用：大学生创作的社团招新、迎新、校园活动、学习分享、学生生活。它是可调的青春感，不是固定的彩色卡片模板；具体语法以 engine-write-protocol 为准。

## 气质与取舍

校园风采用明亮配色、清楚的标题层级和圆润记号。招新和市集可以提高视觉强度，学习经验可以更清爽，正式通知以信息易找为先。用户已说极简、安静或少装饰时，就尊重这种偏好，不因为题材属于校园而强行加热闹。视觉选择不要求正文模拟同学聊天，也不决定句子和段落长短。

文案围绕本次已知内容展开。避免幼儿化卖萌、连续口号和虚构福利；“免费借设备”“报名就送”“我亲测有效”等具体承诺或经历，必须有用户材料依据。风格不决定开篇套路、章节数量或统一长文字数。

## 配色与版式

用 `[[theme:校园]]` 取得明快色板。蓝色组织主线，粉、橙或黄色在记号与画作中形成暖色呼应，正文保持深色。品牌或校徽有明确色号时按协议给自定义色板，不凭学校名猜品牌色。

配色不会自动选择圆角、对齐或装饰。根据文章的主题与原稿关系单独写 `[[boxes:…]]`。用户想要更花、更精致时，把首屏题头、章标、框体、分隔当作同一套设计，既要有足够可辨的主题装饰，也要让完整正文连贯阅读。

| 方向 | 可执行声明 | 主题如何贯穿 |
| --- | --- | --- |
| 花笺舞台 | `[[boxes:花笺]]` | 花枝在题头展开、在框边与章间缩小呼应；适合节庆、自然或文化活动 |
| 校园票笺 | `[[boxes:票笺]]` | 票孔、票面边界与题签形成稳定识别；适合市集、展览、活动资讯 |
| 报道缎带 | `[[boxes:缎带]]` | 缎带题头与章标、细边框及分隔呼应；适合实践报道、纪念与正式校园活动 |
| 明丽几何 | `[[boxes:scale=display;align=left;ornament=confetti;shape=medal;frame=none]]` | 大字与几何点线适合活跃主题，长正文检查徽章栏是否挤窄阅读区 |
| 素净阅读 | `[[boxes:frame=none;fill=none;label=none;mark=none;deco=none;ornament=none]]` | 用标题层级、字重和留白呈现，不自动加热闹 |

这些是候选设计关系，不是文章提纲或强制题材路由。三个主题预置已同时设置气泡骨架与标题、分隔装饰，默认关闭机械语义小标签和额外角标，正文按17px排入。`deco=none` 不关闭预置的内置主题装饰；若需无底，写 `[[boxes:票笺;fill=none]]`。需局部减轻气泡可写 `[[boxes:票笺;shape=rail;frame=line]]`，保留章标与分隔的主题。

完整发言或图文单元仍可用 `[[boxes:题签]]`；纸面层次确有作用时可用 `[[boxes:纸笺;title=sans]]`。避免整篇每一层都套相同圆角卡、双框、白题签和“提示／注意／重点”标签，只换蓝黄颜色。章标、信息框与连续正文要有外观分工，标签不重复原稿标题。

标题用 `#`、`##` 或确有需要的 `[[banner]]`，不复制固定活动骨架；编号交给引擎，不手工追加第二套编号。章节与图片数量按原稿关系决定，不靠删文、碎句或缩小字号使版面显得轻巧。

## 装饰与图片

校园感可以来自花枝、票券、绶带、几何等不同主题，不局限于小草和几个彩色点。主题纹样主要位于题头、边缘和章节空档；正文面板维持低噪声。装饰允许连续呼应，不设每屏或全文次数配额；每处都要与标题或边界有清楚的对齐关系，避免大空白中零散的小圆点和短线。

内置花笺、票笺、缎带是可复用的矢量装饰，不需额外素材接口或模型绘图。用它们建立完整设计后，只有独立画面确实有内容价值时才另配插画，不为每章、每张框补画一份同类素材。

插画对象应贴合内容，例如摄影活动的取景动作、书市里的书摊关系，而非每篇都用小草、文件夹或通用工作台。确需画作时按协议先复用合适素材，再使用 `[[img]]` / `[[deco]]`；插画内部可以有鲜亮实色。已给真实照片则用实际 `local-image://` 引用，保留原件，不为贴合风格虚构滤镜、裁切能力或换成插画。

## 共同边界与复核

气泡与卡片可用浅底、细框、题签和纸笺，标题与横幅沿用当前引擎结构。青春感可来自标题层级、浅色分区、彩色线条、小徽章与图像；不以深色反白面板承载长正文。零 emoji、零图标字符、零渐变、零阴影，不输出 HTML/CSS 或旧素材地址。

看375px成品的题头、中段和结尾，主题是否持续可辨、章标与框体是否呼应、框内文字是否与框外一样舒适、章节与题签之间是否留出真实空间。用户要更花时，仅有通用提示卡与稀疏小图标不能视为完成；用户要极简时不强加装饰。报名时间、资格、费用、福利及联系方式只取已知材料；不为做完整“活动卡”补造缺项。
