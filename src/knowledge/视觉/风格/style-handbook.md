# 手账风（style-handbook）

> 定位：温柔、陪伴、小确幸，像一页精心贴满贴纸与便签的日记手账，亲切治愈、有手写的温度。

> 调用时机：情感随笔、亲子陪伴、日记体、读书笔记、治愈小事、自我成长记录，以及一切"想陪读者把日子记下来"的细腻内容。

## 一、气质与适用内容

**气质关键词**：温柔、陪伴、小确幸、治愈、贴心、细腻；粉紫奶油 + 虚线贴纸感是它的脸蛋，叙事是它的灵魂。手账风的核心是"陪伴"与"记录"，它不端架子，像朋友翻着日记本陪你回看这一天——有贴纸、有划重点的荧光笔、有随手写下的小心思。

它的分寸感来自"克制里的亲切"：底色柔、字色柔、边线多走虚线，让读者觉得"这是写给心事的，也是写给我的"。判定有三个抓手：一是底色是否粉紫奶油、二是边线是否带虚线/贴纸感、三是文案是否第一人称叙事，三条都占，手账味就出来了。

**适合的内容类型与行业**：

- **情感随笔**（心情记录、关系感悟、情绪疗愈、深夜碎碎念）：这类"心事型"内容本身就是写给第三人的日记，手账的柔与虚线条天生能接住情绪；读者会把自己代进去，仿佛在这一页里看到自己的日子。
- **亲子**（陪伴日常、育儿小事、亲子共读、孩子成长瞬间）：核心是"记录与见证"，手账的奶黄、粉彩和圆角让"孩子的成长"显得柔软温暖，特别适合收纳舍不得丢的小瞬间。
- **日记体**（每日一记、习惯打卡、感恩清单、自我复盘）：日记/打卡体最贴手账的名字本身，待办清单、日期行、荧光笔划重点在这里都自然成立，读者跟着"记下来"的动作产生仪式感。
- **读书手账**（读书笔记、金句摘抄、观影感受）：金句摘抄、奶黄高亮恰好像"见到好句就想把它划下来"的手感，摘抄与高亮都恰到好处。
- **女性向 / 治愈系生活方式**（自律、好物、小美好记录）：这类读者偏爱"温柔且有内容"的版面，手账既亲切又有结构，能装下小美好、也能收纳自律清单，亲和又耐嚼。

**不适合的场合**：

- **硬核数据、正式报告、严肃学术**——雷区：手账的柔会显得不够严谨，读者在需要信任与逻辑的场景里看到粉紫色加虚线只觉得"不专业"，反折损可信度。
- **B 端商用、金融合规、法律医疗等需权威的场景**——雷区：手账的"随手感"与"贴纸感"会破坏权威，读者不会把重要决定托付给它。
- **高强度促销、紧急活动、硬朗品牌发布**——雷区：促销要的是冲动与紧迫，手账的温柔节奏只会让读者平和看完再去睡觉，转化与"冲劲"完全对不上。

**判断一句**：内容是"记录、陪伴、分享心事"，手掌感的手账风最合适；内容是"论证、推销、要专业"，就不该用它。

**记录感从哪里来**：手账最强的情绪价值是"把寻常日子认真记下来"的仪式感。运营者下笔可多问一句"这一篇里哪个瞬间最值得写下来？"——把这个瞬间放进待办、放进图片、放进重点气泡，记录感就有了，读者也会跟着"想记一笔"。

**和日系怎么区分**：手账与日系都温柔，但手账更像"贴满贴纸的日记本"，多事件、多清单、多贴纸；日系更像"安静的米色杂志"，重留白、重纸感（见「日系风」条目）。两个抓手：手账看虚线+贴纸+第一人称，日系看米纸+暖棕+大留白，不会混。

**读者感受的底线**：无论怎么贴纸怎么甜，手账读者要的是"被理解、被陪伴"。如果做得只剩可爱、没了心事，读者会觉得好看但不走心——装饰是糖衣，心事才是核，别忘了核。

## 二、完整色板表

```text
背景类（粉紫奶油）
  #FFFFFF        纯白底：正文底色
  #FCF5F9        粉白：分区卡，轻柔
  #FFF7E0        奶油黄：高亮块/贴纸底，温暖
  #F3F0FB        淡紫白：另一装饰块，粉紫层次

主色类（柔和粉紫 1-2 个）
  #F0A3B0 / #E88AA0   樱粉：标题、主线，手账的甜度
  #9FB8AD            雾青：点缀主色的另一柔调（清新）
  #C7B8E8 / #A99AD9   淡紫：辅助，手账的另一温柔色

辅助色类
  #B8A9C4            藕紫灰：次级文字
  #C4B7A8            米灰：注释/分割
  #9A6A6F            豆沙玫瑰：次级强调标题色

强调色类（奶黄点睛）
  #F7C531 / #F7E08A   奶黄高亮：重点词/荧光笔感
  #E89BB0            樱粉：标签圆点强调
  #8FB8A5            雾绿：正向/已完成的小钩

文字色类
  #5A5A5F            柔碳灰：正文主色（柔和不发黑）
  #7A7A80            浅柔灰：注释/辅助
  #9A6A6F            豆沙玫瑰：标题与强调字
```

**每个色号一句话用法**：

- `#FFFFFF` 纯白：正文与多数卡片的底，干净清透，别让它被别的色盖满。
- `#FCF5F9` 粉白：分区卡与装饰块，最贴手账的"纸里带粉"，比纯白更"手账"的一层，撑起整页粉纸感。
- `#FFF7E0` 奶油黄：高亮块、贴纸底的暖黄，用来"划重点"和"贴标签"，温暖不刺眼，是一页里最"醒"但又很柔的存在。
- `#F3F0FB` 淡紫白：另一层装饰块，和粉白并排时显出"粉紫两层的温柔叠"。
- `#F0A3B0 / #E88AA0` 樱粉：主标题与主线，手账的"甜度"，偏粉偏温柔，是整页的情绪开关。
- `#9FB8AD` 雾青：副主色的清新方向，替粉色"降甜"，用于偏中性或植物向，让温柔不那么腻。
- `#C7B8E8 / #A99AD9` 淡紫：辅助主色，给版面加一层"紫的温柔"，克制使用。
- `#B8A9C4` 藕紫灰：次级文字，比主色更沉，负责次级层次。
- `#C4B7A8` 米灰：注释、分割线，弱化但可读。
- `#9A6A6F` 豆沙玫瑰：次级强调标题字，一种"不算太粉"的玫瑰，当标题与强调字时比樱粉沉、比柔碳灰暖。
- `#F7C531 / #F7E08A` 奶黄高亮：重点词与荧光笔感，是"划一下就重点"的记号。
- `#E89BB0` 樱粉：标签圆点/虚线点缀的粉色强调。
- `#8FB8A5` 雾绿：正向/已完成的小钩，也是清单里"做完"的肯定色。
- `#5A5A5F` 柔碳灰：正文主色，柔和不发黑，是"字不闷"的关键。
- `#7A7A80` 浅柔灰：注释/辅助，比正文再淡一档，保证可读底线。
- `#9A6A6F` 豆沙玫瑰：标题与强调字的第二层甜，与樱粉搭配出层次。

**浅档怎么用（默认）**：粉白底 `#FCF5F9` + 柔碳灰字 + 樱粉/奶黄点缀。柔碳灰让正文不发黑不硬，樱粉当标题、奶黄划重点，整体温柔耐读。这是手账的常态，段落与清单都能装，是最稳的默认，绝大多数内容不必切深档。

**深档怎么用（少）**：紫灰深底 `#332E40` + 米字，用于**晚间日记/情绪沉静**处，做"夜深了、想心事"的沉浸。关键是**全篇深档不超过 2 处**，每次都只占一个片段，多则腻、则重；深档一出现就代表"这一刻低下来了"，放在情绪最沉那一段最有效。

## 三、标题与字号层级

**标题样式特征**：**贴纸感标题**与**手写感标注**——圆润字重 + 粉/玫瑰字色 + 奶黄圆点或虚线标注，像手账里用荧光笔划过的一行。标题要"像手写、像贴纸"，而不是"像印刷体海报"；圆润的字重、奶黄的底、右下角的斜角都在提醒读者"这是人补上去的，有温度"。标题不必巨大，够温柔地够醒目。

**装饰语法**：

- **手写感标题**：粉/豆沙玫瑰字 + 奶黄高亮背景（用 `background:#F7E08A` 纯色块高亮，加 `border-radius:3px`，不叠加描边，不渐变、不投影）+ 圆角 2px。这是手账标题的灵魂，整个标题只划一处别划全句。
- **圆点前缀**：标题/小标前放一个主色圆点（span 拼正圆，樱粉），像话题序号，轻巧不喧闹。
- **虚线标注**：`border-bottom:2px dashed #E89BB0` 或胶囊小标，像胶带/贴纸边缘，是手账的"缝线感"，一条虚线就能把"贴上去的"意思带出来。
- **贴纸小签**：`display:inline-block` + `background:#F0A3B0` 白字/深字 + 圆角 4px 右下角带斜角（`border-radius:4px 4px 8px 0`），像一枚贴纸角，可爱又有定住感。不加投影、不加渐进色。
- **日期/序号**：`01` 或手账日期行（`#9A6A6F`），给"今天""第几天"一个明确落点。
- **荧光笔划重点**：正文关键词偶用奶黄高亮，别通篇划，划得太多等于没划。

**先定层级再看装饰**：动手前先把标题分主次——主标题用荧光笔+圆点，章节标题用虚线或圆点，小节标题让它安静。层级定了装饰才有的放矢；否则每层都想贴纸，反而看不出结构，装饰就成了添乱。

**标题是"温度"不是"音量"**：不必做最大最抢，够温柔地够醒目即可。它更像"日记本扉页上写下的今日主题"，是一个轻声的开场而不是广播；标题一开口就要让人安静下来，而不是把人吵醒。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 主标题（日记标题） | 19–21px | 600–bold | 樱粉/豆沙字 + 荧光笔底 |
| 章节标题 | 16–17px | 600 | 玫瑰字 + 圆点/虚线 |
| 小节/副标题 | 15px | 600 | 藕紫灰 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 注释/页码 | 13px | normal | 米灰 |

> 标题上 28px 下 12px（硬规范）；贴纸大标题可上 30px 下 14px。

**层级怎么落**：一层主标题用荧光笔+圆点，章节标题用虚线或圆点，小节标题让它安静，别层层都贴纸。手账的亲切其实是"只有一个地方最用力"，其它地方都让位，读者才抓得住重点。

**标题的字体感**：没有手写字体也没关系，靠字重、字色与奶黄底就能"装"出笔触感——重一点、暖一点、划一下，就有手写的意思了。

## 四、模块表现

每个模块单独给具体数值与可参考写法的内联样式，帮助落地时一眼抄用。

- **重点气泡**：**虚线边框气泡**——白/粉白底 + `border:2px dashed #E89BB0` + **圆角 14px** + `padding:14px 16px`（硬规范）。左上角可放一个主色圆点（span 正圆）像"贴纸固定点"，或干脆做"贴纸卡"（实底 + 右下角斜角）；虚线与实底挑一种，别混用。整篇重点气泡控制在 **1-2 个**，最要紧的心事才配用虚线框。
- **卡片**：粉白/奶油底 + **圆角 14px** + `1px solid #F0D8E0` 淡粉描边，或纯色无描边 + 内文 `padding:14px 16px 12px`；可加一条顶部 **4px 樱粉横条**。**卡片之间 16px**。卡片多数走淡粉描边或无描边，只让重点卡带虚线，普通卡保持轻与静。
- **待办 / 清单卡**：手账招牌——每行一个方形勾选框（span 拼方框）+ 短句，已完成项划线（`text-decoration:line-through`）行首用一个主色小圆点；**行距 1.75**。待办要"看得清楚、有完成感"，每行一句别塞长段，完成的小钩用雾绿给个"肯定"。
- **分割线**：**碎点/虚线 + 一个几何符号**——`border-top:2px dashed #E6C9D3`，下方居中放一个 span 主色小圆点；**分隔上下 24px**。手账感的分隔要"贴纸边缘"的随性，虚线让它像用剪刀剪下的缝线。
- **花纹**：极浅**圆点底纹**（用低饱和纯色 span 拼稀疏圆点，或细边框拼格纹，近似 #FCF5F9 明度，不用渐变）、格纹、稀疏小点；**≤2 种且很浅**，做背景温度。花纹只做"贴纸的肌理"，是"看出来有、指出来才注意"的程度，别让读者先看见花纹。
- **列表**：符号用 `主色圆点 / 小短线`，或 art:// 植物图案（sprig-grass 小草），**行距 1.75**；忌粗重系统默认圆圈或 emoji/图标字符，那会显得"印刷感"太重、不像手账。
- **步骤**：**手账打卡步骤**：圆形编号 `1 2 3` 或 "Day 1→Day 2" 打卡条，用樱粉圆点；**步骤间 16px**。步骤配一句"今天也做到啦"式的小话，比冷冰冰的数字更贴手账。

**模块之间怎么配合**：一篇手账的节奏大约是——封面开心事 → 开篇一句"我在写今天"的日期感 → 待办/清单卡装实用部分 → 一两张拼贴放照片 → 重点虚线气泡承接最想说的心事 → 结尾一句轻收。虚线气泡只出现一到两次，其余用普通卡与清单撑着，把"用力"留给最想说的话。

**一张卡片的内联写法参照**：底色 `#FCF5F9`，描边 `1px solid #F0D8E0`，圆角 14px，内侧留白 `padding:14px 16px 12px`。需要重点的那一处，把描边换成 `2px dashed #E89BB0`，其余卡片保持同款——靠"只有重点卡带虚线"来制造焦点，而不是每张卡都贴框。

## 五、图片与装饰

- **图片处理**：**圆角 14px**（柔），配**暖粉/奶油滤镜**（提亮、加暖、降锐度），或加白边像"照片贴纸"（`border:4px solid #fff` + 圆角，不加阴影、不加投影）。比例多取 **1:1** 或 **3:4**（记录碎片感）。照片加白边像贴在日记本上的照片，是手账最"有戏"的处理，一下就把图片变成了"贴进本子的一角"。
- **拼贴感**：可用多张圆角小图排成手账拼贴（flex 排列），每张加白边；克制排布别杂乱。拼贴是手账的"胶水时刻"，排太密就成了马赛克，留点缝让它像刚贴上去的，才有一点"手工感"。
- **图片温度**：画面整体走"暖粉奶油"，别让冷色大图破坏整页的柔。拿捏不好就让图小一点、圆一点、加白边，让它"退"到贴纸的位置，宁小勿串味。
- **图片密度**：图片是用来"记录瞬间"的，适量放 **2-4 张带白边的圆角图**就够，别为了热闹堆满，图解不了的部分交给文字。
- **装饰**：**偏高的密度但不乱**——手账靠植物图案/几何点缀的贴纸感，点缀每 **3–5 行 ≤1 处**，用柔和向的 art:// 植物图案与 span 拼几何（圆点、方块），避免刺眼电子感；**一段 ≤2 处**。装饰在这里是"贴纸"，可以比日系多，但别成串，点到为止。零 emoji/零 Unicode 图标字符。
- **可用 art:// 植物图案**：手账最需要"贴纸素材"，art:// 植物图案是它的理想来源——**sprig-grass 小草**（做清单行首符号、分割线、气泡角饰）、**blossom-branch 花枝**（做标题旁的小花）、**leaf-corner 叶角**（做卡片四角）。引法：正文用 `![说明](art://sprig-grass)` 当行首装饰，或作贴纸点缀。图案必须植物/自然类，绝不用图标类。

## 六、文案调性

**语气关键词**：温柔、陪伴、细腻、第一人称、小确幸、不评判。

**句式倾向（单独讲）**：**第一人称叙事多**——"今天""我""忽然想到"，让读者跟着"你"过这一天。多用"记得""有没有和你说过""忽然觉得"，把读者拉进"陪你聊聊"的距离。句子软、可停顿，常写感受与细节，承认脆弱与平凡——这是手账最动人的地方，别硬灌鸡汤、别强作坚强。

**不评判**是手账的重要底色：不指责、不说教，把"没完成也没关系"摆在明面上，让读者觉得被接住而不是被要求——这是手账能"陪到人心里"的根本。

**节奏怎么控制**：句子之间多留停顿，段落可以短，一段一两句也行。手账的"碎碎念"也要有呼吸，别一页压成一段长文——该换气的换气，该停的停。

**可直接套用的示例句**：

- "把今天的小事，记进手账里。"
- "今天下班路上，看到一朵云，忽然就想你了。"
- "孩子睡着前的十分钟，是我一天里最温柔的十分钟。"
- "没完成也没关系，明天还有一页可以再写。"
- "今晚不想讲太多大道理，只想陪你坐一会儿。"
- "写这页的时候，窗外的雨正好停了。"

**开头怎么写**：从一个"此刻的小画面"入场——"坐在书桌前，抬手往手账里写今天的日期"。这比从结论开场更贴手账的"记录感"，先把读者领进"本子前"，再往下讲今天。

**一段示例**：

> 星期五，晚上九点。把今天收到的几张车票和一片叶子夹进本子里，旁边写上：今天路过街角的花店，看到一盆打了花苞的雏菊。没忍住，买了。贴一张胶带，算是给它安了个家。

**结尾怎么写**：留一句给读者的轻巧收尾，比如"明天也在一起"或"这一页翻过去了，晚安"。不用硬留号召动作，行动引导放角落即可，别让一句营销话术抢走结尾的温柔。

## 七、禁忌与陷阱

1. **甜腻过度**：反例是通篇"宝贝呀～亲亲～啾咪" + 成串装饰（每段都堆小图形），读者腻到发齁，温柔变成装可爱、读者觉得假。正解：温柔但克制，治愈靠细节与真诚不靠装饰堆砌，点缀每段 ≤2 处；语气保持正常说话，只是更软一点，别"夹"。

2. **颜色太高饱和**：反例是樱粉+紫+黄+绿全塞成高饱和，画面又俗又刺眼，粉紫奶油感全没了。正解：柔粉紫奶油是低饱和系，**1 主（樱粉）+1 辅（雾青或淡紫）**、奶黄点缀统一即可，靠"柔"取胜。

3. **虚线框滥用**：反例是十几个气泡全用虚线框，视觉像一堆缝线缠在一起、成"麻花眼"，重点全被淹没。正解：虚线框留给**最重点的 1-2 个**气泡，其余卡片用实底淡色无框或细实线，靠"只有重点带虚线"来做区分。

4. **正文发黑/太柔**：反例是正文直接上纯黑 `#000`，在粉底上又硬又闷、碎掉柔感；反过来用太浅的字读者看不清。正解：正文柔碳灰 `#5A5A5F`，注释不低于 `#7A7A80` 可读线；标题才用玫瑰/樱粉字，"软和色"只在标题兑现。

5. **忽略结构、碎成一地**：反例是没有章节标题的纯流水账，一堆散句往下滑，读者翻到一半就迷路，"随性"成了"混乱"。正解：保留温度但用打卡/清单/日期分节，结构清楚（可用手账式章节标题）；骨架该有还要有，只是被贴纸盖住了而已。

6. **装饰过度当作正文**：反例是用装饰符号凑字数或代替语言，读者看出"没东西写了用图案填"，诚意打折。正解：装饰只当贴纸点缀，语言本身要能立住，内容是"人话"在先、贴纸在后。零 emoji/零图标字符。

## 八、混搭方向

- **手账 × 日系（主 7 : 辅 3）**：治愈生活方式，加入米纸纸感与暖棕，更"杂志向"的温柔（见「日系风」条目）；混搭时守住粉紫奶油与虚线，把日系的米纸、暖棕作为点缀色引入。
- **手账 × 治愈手绘（主 7 : 辅 3）**：需要更手绘/软线条质感时，用手绘变体加手账（见「治愈手绘」变体条目），气泡线条更软，呆萌感更足。
- **手账 × 校园（主 7 : 辅 3）**：学习打卡/学生向内容，保留手账待办，加校园的明亮与贴纸，更元气。
- **手账 × 森系（主 8 : 辅 2）**：植物向治愈，主色压向雾青/松绿，更清新（见「清新森系」）。

参照「风格混搭与主辅法则」；手账做主风格守粉紫奶油与虚线贴纸骨架——主风格定了，虚线、圆角、贴纸感这些"手账的语言"就要一直保留，变化只发生在颜色与配图上。

**混搭的收口**：辅色方向只加一个，别同时塞进两三个风格。混搭后问自己：这版还能第一眼看出"手账"吗？能，主就立住了；不能，辅就抢了。混搭不是为了堆元素，是为了让手账"换一件更合身的衣裳"。

## 九、封面建议

- **构图**：居中"日记页面"感——一张贴纸/手写标题/温馨小照片，主题字带荧光笔底色，可配手账边框与圆点。主体留白要多一点，像翻开日记本第一页，而不是塞满一张海报。
- **配色呼应**：粉白 `#FCF5F9` 底 + 樱粉 `#F0A3B0` 标题 + 奶黄 `#F7E08A` 高亮。画面柔暖，封面与正文同色系，点进去不落空。
- **字**：标题 ≤6 字、手写感、带荧光底；副标题一句话。封面文字点到为止，留一块像"日记本封面"的空白。
- **气质**：温馨、治愈，像朋友的手账封面。封面用暖光、粉彩、贴纸感，"像翻开朋友日记本第一页"就对了。

**封面别做三件事**：一、别用高饱和撞色，把柔写进封面配色里；二、别堆满元素，贴纸两三枚点到为止；三、别让标题占满画面——手账封面要的是"翻开一页"的松弛，不是"海报"的张力。封面是一条"预告"，它温柔了，正文才好接得住。

## 十、深色模式表现

- 深色模式把粉白底换成**紫灰深底**（`#332E40` / `#2B2633`）+ 米字 `#D9D2E2`。暖中带紫，保持手账氛围，夜间阅读不刺眼，深夜看也不累。
- 樱粉 `#F0A3B0` 在深底上保留或略提亮为 `#F3B8C5`；奶黄 `#F7E08A` 保持或提一点亮度，让重点在深底上仍"划得出来"，一划仍是最醒的那一处。
- 原柔碳灰字 `#5A5A5F` 在深底上提亮为 `#CFC6D9`，不可被吞。
- 虚线框的 `#E89BB0` 在深底上改稍亮 `#EE92A6`；白底贴纸卡在深底上改深紫卡。
- 深档阶段本来就用紫灰底，暗黑模式天然相融。注意别让荧光笔更黄刺眼——深底上奶黄要保持但不炸，否则夜间阅读"闪"。
- 深色下的图片：太亮的暖图压一点亮度或加暖罩，让图"沉"进深紫底；太暗的图提一点亮度，别让贴心事的氛围被看不清的图打断。

## 十一、个性化空间

- **主色替换**：账号若偏爱特定治愈色（个人色、季节色），把樱粉换成账号偏好色（染青、暖鹅黄、藕粉），粉紫奶油骨架保留。判断依据：读者群与账号的个人化治愈气质；换了主色，虚线、圆角、贴纸感这些"手账语言"要原样保留。
- **男女性向微调**：亲子/女性向可重温柔粉紫；偏中性治愈（焦虑缓解、职场减压）可压粉、加雾青与米灰，更中性。判断依据：目标读者与内容情绪——越偏向安抚"疲惫职场人"，越要往"柔而不腻、偏中性"的方向收。
- **植物图案/几何点缀密度**：年轻女性向可高，偏质感日记可低。判断依据：读者年龄与内容松紧，越年轻越接受贴纸，越追求质感越要收。
- **装饰密度**：纯日记可多贴纸感；职场减压手账可少点缀、多清单与克制线条。判断依据：是想"热闹陪伴"还是"安静自省"，点缀多还是线条多，跟着情绪走。
- **深档倾向**：晚间内容/夜读向可整篇走深紫灰底，白天治愈走浅档。判断依据：阅读场景与当下情绪，深灰底天然适合深夜心事，白天还是浅档稳。
- **清单风格**：有的号爱大段待办卡配打卡，有的号走得简洁。判断依据：读者使用意图——是"照着做清单"还是"看着治愈"，决定清单要不要多、要几分装饰。

以上为可调参数，调用方应结合读者画像落地，不做死模板堆料。手账风的"活"在于同一种粉紫之下的不同温度——贴纸多一点显热闹、线条多一点显安静，怎么调都记得"陪读者把日子记下来"这个初心，就不会走偏。

**给调用方的复查三问**：一、全篇主色是否只有一两个在撑，没有第三个跳出来抢？二、虚线框是否只留给了最重点那一两处，普通卡是不是都"安静待着"？三、文字是不是真的"软而真诚"，有没有用装饰符号填凑、用腻话讨好？三句话答得上来，这版手账的"亲切"就立住了，剩下的交给读者去体会。
