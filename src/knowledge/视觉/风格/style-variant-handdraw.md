# 治愈手绘（软线条手写感）

> 定位：手账风格与插画风格的**子系变体**，把两者都往「有人手碰过的温度」再推一把。底色仍是手账的温和粉奶油，但把「贴纸感」升级成「手绘感」——线条带笔触、边界不齐、字有书写感。
> 适用对象：公众号运营者/编辑里偏情感号、亲子号、学习笔记号、文创号。调用方（写推文的智能体）需要在排版时把硬框改成软框、规整改成随性。

## 一、属于哪个顶层风格的子系

- **母风格一：手账风格**（记录、情感、随笔、亲子）。本变体把手账的「虚线贴纸框、粉紫奶油色」保留，继承它的温柔气质。
- **母风格二：插画风格**（快消、母婴、娱乐、促销）。本变体借用插画的「图文并茂、圆润造型」，但把插画的高饱和撞色降成低饱和手帐色，把几何大色块换成线条小插图。
- **一句话**：想要「有人亲手画了一篇」的感觉时，同时放下手账与插画，走本变体。

### 何时用本变体，而不是直接用母风格

| 你的内容状态 | 选择 | 理由 |
|---|---|---|
| 记录心事、亲子日常，用虚线框贴纸就很够 | 手账风格（母） | 手账的贴纸感已足够，不必再加手绘笔触，加了反而信息过载 |
| 促销、快消需要高饱和冲击 | 插画风格（母） | 插画的撞色才撑得起热闹，手绘的软线条压不住促销冲动 |
| 想强调「手工、一笔一画、独一无二」的温度 | **治愈手绘（本变体）** | 只有手绘笔触能传递"人亲手画的"亲近感 |
| 读书笔记、手写摘抄，想让读者跟着抄 | **治愈手绘（本变体）** | 手写风标题与勾线小图最能唤起"我也要记一笔" |

判断尺：**只要"手工的亲近感"这一目的出现，就值得从母风格切到本变体**；只想"记录得可爱"时，母风格就够。

## 二、与母风格的差异点

| 对比维度 | 手账风格（母） | 插画风格（母） | 治愈手绘（本变体） |
|---|---|---|---|
| 线条 | 以贴纸/虚线框为主 | 粗描边几何 | **软曲线、非等宽笔触、起笔收笔有粗细** |
| 色相 | 粉紫奶油 | 高饱和撞色 | **低饱和粉彩 + 暖色调** |
| 边框 | 虚线圆角框 | 粗色块圆角 | **虚线偏细、转角用圆（像手画的括号）** |
| 装饰元素 | 圆点、格纹、贴纸图标 | 星星、波点大色块 | **勾线小插图：小花、云朵、叶片、爱心、小动物** |
| 标题 | 贴纸感 emoji 标题 | 白字彩底圆角 banner | **手写风标题：彩色字 + 波浪下划线 / 手画圈注** |
| 整体气质 | 温柔克制 | 热闹张扬 | **温暖 + 手工 + 一点笨拙的亲切** |

- **落笔区别**：母风格手账讲究"边界整齐的贴纸"，本变体刻意让线条**起笔粗、收笔细、微微抖**，例如下划线做成奶黄纯色的波浪短段，而不是一条硬直线；插画风的粗描边改为 1-1.5px 的低饱和细软线。
- **留白区别**：本变体比插画更重留白，每个手绘元素之间松一点，像本子上随手画，而不是填满一页；整体节奏比手账更"散、更有呼吸"。

## 三、完整色板

> 背景基色 + 主色 1 个 + 辅助色 2 个 + 强调色 1 个 + 文字色 2 档。全篇色相控制在 3 个以内，其余靠深浅变化，别把色板当调色盘全用上。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FFFBF7`（奶油白） | 全文底色，取代纯白，营造纸感 |
| 分区浅底 | `#FBF0EC`（浅杏） | 卡片/气泡底色，暖而不艳 |
| 主色 | `#E8A0B2`（樱粉） | 标题主字、下划线、模块图标主色 |
| 辅助色1 | `#B7CFC0`（雾青绿） | 副标题、图标、正文里的小强调 |
| 辅助色2 | `#F0CD8A`（奶黄） | 高亮底色、手画圈注圈内色 |
| 强调色 | `#C9777E`（豆沙玫瑰） | 关键信息强调、重点词加粗改色 |
| 正文文字 | `#6B5B53`（暖棕灰） | 正文用色，温而不刺眼 |
| 次级文字 | `#A09184`（浅暖灰） | 注释、图注、辅助说明 |

**每个色号一句话用法**：

- `#FFFBF7` 奶油白：全文的底，像一张带一点点米的纸，比纯白多一层"纸的温度"，别换成冷白。
- `#FBF0EC` 浅杏：给重点气泡、卡片、小分区上底色，暖到刚好不艳，是"比纸面更实一点"的一层。
- `#E8A0B2` 樱粉：主标题、波浪下划线、小图标，本变体的"甜度"，一页的情绪开关。
- `#B7CFC0` 雾青绿：副标题、图标、正文里的小强调，替樱粉"降一点甜"，让温柔不腻（偏植物/中性内容可把它提到主位）。
- `#F0CD8A` 奶黄：高亮底色、手画圈注的圈内色，用来"划重点"，温暖不刺眼。
- `#C9777E` 豆沙玫瑰：比樱粉沉一档的玫瑰，只用在"关键信息"和"重点词"，是整页的锚点。
- `#6B5B53` 暖棕灰：正文主色，温、深、不刺眼，是"字不闷"的关键。
- `#A09184` 浅暖灰：注释、图注、手写日期的辅助色，保证可读的底线。

**配色规律**：全篇 ≤3 个亮色（樱粉、雾青绿、奶黄），豆沙玫瑰只做点缀强调，底色两档（奶油白 + 浅杏）。若需换色，按「粉↔绿↔黄的同类低饱和关系」替换，保持粉彩质感，别引入纯度高的大红大蓝。

**深浅档切换**：白天治愈内容走浅档（奶油白底 + 樱粉 + 奶黄）；晚间/深夜心事内容可切一段深档（暖黑底 `#2A2520` + 暖米字），**深档每篇 ≤2 处**，只放情绪最沉的片段。深档必须配米字，否则字会被吞。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | 彩色字 + 手画波浪下划线；或「文字 + 手画圆住关键点」 | `今天也想好好生活`（樱粉，波浪下划线奶黄） |
| 章节小标题 | 行首小图标 + 彩色短句；下方留 12px | `把日子过成手账`（行首可放一枚 CSS 圆点徽章） |
| 重点句（金句） | 豆沙玫瑰加粗 + 倾斜感；或手画引号 | `「慢慢来，也是一种认真」` |

- 字号：开头大标题 20-22px，章节标题 18px，正文 15px，注释 13px。
- 标题字距 1px，正文 0.5px，行距 1.75（照间距硬规范）。

**手写感的三个实现姿势**（没有手写字体也能"装"出笔触）：

1. **波浪下划线**：用一段奶黄 `#F0CD8A` 的 `underline` 或 `border-bottom:2px solid #F0CD8A` 的短标线，做成"随手划了一笔"的低饱和纯色波浪感（不加渐变与投影）。
2. **手画圆圈注**：把关键词放在一个奶黄 `border-radius:50%` 的浅底圆里，像被人用笔画了个圈。
3. **斜角小签**：`<span style="background:#E8A0B2;color:#fff;border-radius:4px 4px 8px 0;padding:2px 8px;">今日手账</span>`，一词小签像手写贴的小纸条。

**层级怎么落**：只让主标题用"波浪线 + 圆注"的组合，章节标题用一个小图标即可，别每一层都画圈划波，否则结构被淹没。标题写给"手写风"，字距放宽到 1-2px，字重大约 600。

## 五、模块表现（如何把本风格套到各模块）

- **重点气泡**：浅杏底 + **细圆角虚线**（圆角 16px，边框 1.5px 樱粉虚线），左上角放一个手绘小图标圆形衬底；内文 14px 暖棕灰。整篇重点气泡控制在 **1-2 个**，最想说的心事才配虚线框。
- **卡片**：奶油白底 + 1px 浅杏纯色描边 + 圆角 14px，右上角可加一条手绘小花草做角标；忌厚阴影与柔光，只用低饱和纯色 + 细描边 + 留白撑起层次。内文 `padding:14px 16px 12px`。
- **分割线**：用「〜〜〜」的波浪字或一串小圆点（`· · ·`）代替直线；或花边交织感，上下 24px。
- **花纹色带**（如需要）：细碎叶片或圆点纹，浅档（透明度降到浅色），整篇 ≤2 处花纹色带。
- **列表**：把实心圆点换成「· 手写感圆点」或用 art:// 植物图案小图点缀；编号用「123」手账感圆圈。
- **步骤/清单**：步骤圈做成手绘圆圈缠带感，勾选框做成空心圆框，已完成项划线用雾青绿细线（`border-bottom:2px solid #B7CFC0`）。
- **框内引用/心情**：居中一句话 + 两侧各放一枚 art:// 植物图案（如 `leaf-corner` 叶角、`sprig-grass` 小草），放"今日感悟"，每篇 1-2 处，放在情绪转折点。

**一张卡片的内联写法参照**：底色 `#FBF0EC`，描边 `1px solid #E8A0B2`（透明度可降为 60% 让线更软），圆角 14px，`padding:14px 16px 12px`；需要重点的那一处把描边换成 `1.5px dashed #E8A0B2` 并在左上角放一个手绘小圆图标，其余卡片保持同款——靠"只有重点卡带虚线"制造焦点。

**一个重点气泡的完整骨架**（可直接照着搭）：

```html
<div style="background:#FBF0EC;border:1.5px dashed #E8A0B2;border-radius:16px;padding:14px 16px;margin:0 0 16px;">
  <span style="display:inline-block;background:#E8A0B2;color:#fff;border-radius:50%;width:22px;height:22px;line-height:22px;text-align:center;font-size:13px;">•</span>
  <p style="margin:8px 0 0;color:#6B5B53;line-height:1.75;">最想说的那句心事，放在这个带虚线框的气泡里。</p>
</div>
```

要点：气泡圆角刻意做「偏圆」（16px）让边像手画；虚线 1.5px 别太粗；整篇只用 1-2 个，其余用普通卡片，把"画重点"留给这一两处。

**一个手写引言的骨架**：

```html
<p style="text-align:center;margin:0 0 16px;color:#C9777E;font-weight:600;line-height:1.75;">
  「 慢慢来，也是一种认真 」
</p>
```

## 六、图片处理与装饰

- 图片：圆角 12px 以上；可用留白边让图像「贴纸」；不建议加粗黑描边。可多张圆角小图错落排成手账拼贴（像贴纸条），克制别杂乱。
- 滤镜：暖粉/奶油滤镜（提亮、加暖、降锐度），或加细白边像"本子里夹的照片"，别放冷色大图破坏整页的柔和。
- 装饰克制：图案/几何点缀每屏 ≤1 处，宁可留白。手账感已靠小插画承担装饰，装饰只用来点睛（起笔、小标题、收尾）。图案资产只可用植物/自然类：如 `sprig-grass` 小草、`vine-frame` 藤蔓花框、`blossom-branch` 花枝、`leaf-corner` 叶角——在正文用 `![说明](art://资产名)` 引用，或用这些图案做气泡/标题装饰。
- 贴纸图例（如手绘小图标）可适度多用，但整篇图标种类 ≤6 种，避免乱。

## 七、禁忌与陷阱

1. **别把笔触拉成草稿**：手绘是「线条不齐但有克制」，不是随便乱划；每处手绘元素仍要对齐页面节奏。
2. **别撞高饱和色**：出现纯红 `#FF4D4D`、纯蓝 `#2D5CF0` 就破功，全库手绘色都是低饱和粉彩。
3. **别全文正文都变色**：正文统一暖棕灰，只有强调词才用豆沙玫瑰，变色率 <10%。
4. **别用粗黑实线框**：实线粗框、厚重阴影会让手绘感秒变呆板。一律细、虚、淡。
5. **别忽略可读性**：手写感靠笔画标签，不靠把正文也做成潦草字体变体；正文仍用清晰 15px。
6. **别把 emoji 当装饰主料**：手绘感已经由线条和小插图承担，emoji 堆多了会从"手绘"变"表情包"，一段 ≤2 个、每屏 ≤1 个即可。
7. **别所有卡片都画圈注**：圈注、波浪线只在最要紧的关键点出现，划得太多等于没划，也容易让版面显得乱。

## 八、混搭方向

- **+ 日系**：把底色换成米纸 `#FBF3E3`，手绘更「自然手作感」，适合美食、旅行手记。
- **+ 森系**：主色从樱粉换成草绿系，保留手绘线条，适合亲子自然内容（参考清水森系条目的换色法）。
- **+ 手账（母）**：在手绘基础上留虚线贴纸框与待办清单，更适合"记录打卡"类内容，手绘与贴纸并存。
- **- 禁忌**：别混科技（冷色、锐利大反差会冲突）、别混国潮（红金墨庄重与稚拙手绘不搭）、别混孟菲斯（高饱和几何撞色会吃掉手绘的柔）。

**混搭收口**：辅助方向只加一个，别同时塞进两三种风格；混搭后问一句"这版还是第一眼像手绘吗"——能就像，不能就收。

## 九、封面与首屏建议

- 封面：用一张「笔记本纸面 + 手绘小图 + 手写字标题」的示意图；标题字压在手绘气泡里。
- 首屏开头：手账感居中式大标题 + 一句话手绘引言，第二屏再进正文。
- 配色呼应：奶油白 `#FFFBF7` 底 + 樱粉 `#E8A0B2` 标题 + 奶黄 `#F0CD8A` 高亮，封面与正文同色系，点进去不落空。

## 十、深色模式表现

- 微信深色模式下浅底会翻转成深底：需把奶油白改为 `#2A2520`（暖黑底）、浅杏改 `#3A322B`，樱粉/雾青/奶黄略微提亮一位（如樱粉 `#F2B4C4`）保持对比度。
- 手绘细线用暖灰 `#C9BDB2` 勾勒，避免在深底上消失。
- 原暖棕灰正文 `#6B5B53` 在深底上提亮为暖米字 `#CEBDB0`，否则会被吞；奶黄高亮在深底上提亮但别炸（闪光刺眼）。

## 十一、个性化留白（按账号自定）

- **主色三选**：樱粉（温柔版）／雾青绿（清新版）／奶黄（元气版）——先看账号性别与读者，情感类偏粉、亲子类偏绿、文创类偏黄。
- **手绘感的浓淡**：单图配单线（克制）／每段配小插图（满幅）——决定全篇插画密度。
- **是否保留虚线贴纸框**：留则更「手账」，去则更「极简手绘」。结合账号是否长期主打手账栏目判断。
- **装饰种类**：只留波浪线＋圆注（收敛）／加勾线小插图（热闹）——读者偏"安静手作"或"可爱热闹"决定。
- **是否上深档**：晚间/夜读向内容可整篇走一段深档，白天治愈走浅档。判断依据：阅读场景与当下情绪。
- 以上判断依据：读者画像（年龄/性别/内容偏好）、账号既有栏目气质、品牌主色（如有）。

**给调用方的复查三问**：一、全篇主色是否只有一两个在撑、强调色只在关键点？二、虚线框/圈注是否只留给了最想说的那一两处、其他卡片都"安静待着"？三、手绘线条是否有克制、没有变成乱涂或高饱和喧闹？

**手绘的"活"在哪**：同样的奶油粉彩之下，手绘比的不是谁画得多，而是谁把"那一笔"落对了地方——一处波浪线、一朵勾线小花、一句写下来的金句，就足够让读者读出"有人为我亲手画了这一页"。
