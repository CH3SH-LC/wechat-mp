# 美式复古（style-american-retro）

> 定位：复古广告、奶油色、怀旧美式，像一张 60 年代的美式复古海报和一家奶油色招牌的汉堡店，奶油棕橙 + 青蓝拼色是它的醒目组合。

> 调用时机：餐饮咖啡、美式生活方式、复古好物、牛仔裤/皮具/黑胶、美式运动，以及一切想"回到美式黄金年代，带点复古广告腔"的内容。

## 一、气质与适用内容

**气质关键词**：复古广告、奶油色、怀旧美式、粗犷亲切、暖、有年代感。奶油棕橙 + 青蓝拼色是它的双拼签名。

这个风格像一家开在加州老街拐角的汉堡店——奶油招牌挂着蜂蜜黄霓虹，橱窗贴张"今日特价"的双色海报，货架上是皮靴、牛仔和黑胶。推文要让读者隔着屏幕闻到烤面包和咖啡香，看见一个暖而热闹的老美国下午。

**适合的内容类型与行业**（逐项说明为什么合适）：

- **餐饮咖啡**（美式餐厅、汉堡炸鸡、咖啡烘焙、甜品店、复古酒吧）：天生自带"进店、落座、来一杯"的场景感。奶油暖底把读者的"进店冲动"放大成"想尝尝的老味道"，海报式配图 + 吆喝文案让下单欲被顺势点燃。
- **美式生活方式**（牛仔、皮具、靴子、老式机车、露营、复古运动）：这些产品自带"经年耐用、越用越有味道"的属性。复古的做旧质感与暖卡其能把"旧"讲成"品质"，让读者觉得它不仅不过时、反而有情怀。
- **复古好物**（黑胶、老相机、打字机、vintage、家居复古）：这类东西的可信度恰恰来自"它有年代、有来头"。怀旧广告腔与做旧滤镜能顺着读者对旧物的珍视一路走下去。
- **怀旧欧美文化**（老歌、老电影、老广告、60-70 年代怀旧）：这是美式复古的"主场"。读者本来就在追那段黄金年代，复古双拼和广告句式一步到位，天然同频、没有隔阂。
- **校园/美式运动**（复古球衣、运动服、学院风）：棒球衫、签名徽章、双线框标题与复古球衣高度贴合。青蓝这半色冷一点，还很"学院气"。

**不适合的场合**（逐项说明为什么是雷区）：

- **严肃金融、司法、医疗**：复古广告的轻松、吆喝、亲切会冲淡专业与权威。读者很难把它当可信的严肃信息，反而觉得像在闹着玩。
- **高冷极简、未来科技/赛博**：暖奶油棕和冷锋利、赛博荧光直接冲突。两套气质打架，观众会同时觉得"不够复古也不够现代"。
- **纯中文传统古风**：美式复古的根子是"洋味"。与东方水墨、古诗词的庄重相克，硬拼会让双方都失去原有气场。
- **需要极致权威或极度克制的高端商务**：它的亲切和年代感压不住"极简贵气"或"乙方专业感"，容易显轻、显旧、拉低信任度。

**判断一句**：内容要"复古广告的快乐、美式黄金年代的暖与虎、让人想进店/想入手"，美式复古正中；要"冷静现代或东方庄重"，就别用。

## 二、完整色板表

```text
背景类（奶油系）
  #FFF3E2        奶油米白：正文底色，暖
  #FBE9D3        奶油橙黄：分区卡，复古暖
  #F5D9B8        焦糖浅：装饰块
  #33261B        咖啡褐（深档底）：压场/logo 感

主色类（棕橙 + 青蓝双拼）
  #D2691E / #B75D2B   复古橙/生锈橙：主标题、主点睛，暖而抓眼
  #E8A33D            蜂蜜黄：第二暖主色/高亮
  #2E5A8C / #3A6EA5   复古青蓝：另一主色，双拼的另一半

辅助色类
  #7A5A2E            深咖褐：次级文字/结构
  #8A7560            暖褐灰：注释
  #B8A080            浅咖米：分隔线

强调色类（复古广告点睛，克制）
  #C0392B            番茄红：复古广告的"促销红"（如"全新/限量"）
  #2E5A8C            青蓝：徽章/标签
  #E8A33D            蜂蜜黄：圆点/高亮描边

文字色类
  #3A3028 / #33302B   暖咖啡黑：正文主色（暖调深字，避免纯黑发冷）
  #5C4E3E            深褐灰：次级文字
  #7A6A55            浅褐灰：注释
```

**每个色号怎么用（逐条落点）**：

- **奶油米白 `#FFF3E2`**：全篇正文底，暖而不脏，所有大段文字落在这层奶油上读。
- **奶油橙黄 `#FBE9D3`**：给分区卡、小卡片换底，一换就像"店里另一张菜单"，比纯白有温度。
- **焦糖浅 `#F5D9B8`**：做装饰块、贴纸背后的衬色，量少，像奶昔上的焦糖淋边。
- **咖啡褐 `#33261B`**：深档的底，压场、logo 块专属，一出现就是"招牌感"。
- **复古橙 `#D2691E` / 生锈橙 `#B75D2B`**：主标题、主点睛、描边和按钮，暖而抓眼，是双拼的"暖半色"。
- **蜂蜜黄 `#E8A33D`**：第二暖主色、高亮、圆点、描边，比橙更亮更跳，用来"点亮"。
- **复古青蓝 `#2E5A8C` / `#3A6EA5`**：双拼的另一半，平衡暖橙，做青蓝竖条、徽章、标签，冷得恰到好处。
- **深咖褐 `#7A5A2E`**：次级文字与结构，段落内的小标题、强调词。
- **暖褐灰 `#8A7560`**：注释、来源、小字，退到后面不抢主角。
- **浅咖米 `#B8A080`**：分隔线，细而暖的分界。
- **番茄红 `#C0392B`**：仅供促销点睛（"全新/限量"），全篇极小面积，一出现读者就懂"有活动"。
- **暖咖啡黑 `#3A3028` / `#33302B`**：正文主色，暖调深字，避开纯黑发冷。
- **深褐灰 `#5C4E3E`**：次级文字，比正文浅一档。
- **浅褐灰 `#7A6A55`**：注释底线，再浅就不够看清。

**浅档（默认挡）怎么切换**：

浅档是美式复古的日常本体——奶油米白底 `#FFF3E2` + 暖咖啡黑字 `#3A3028` + 复古橙/青蓝点缀。奶油调一铺，暖而亲切的"进店感"就有了；正文用暖咖啡黑而非纯黑，读久不刺眼。浅档适用于绝大多数正文：普通段落、列表、食材讲、店铺介绍都维持在这套奶油底上。想让某一块更热闹，就把蜂蜜黄或番茄红作为小块点缀放上去，但底色始终是奶油系，主次清楚。

**深档（压场/logo 感）怎么切换**：

深档只在开篇 logo 块、双拼 banner、结尾行动这类"封面感"位置用——咖啡褐底 `#33261B` + 奶油字 + 蜂蜜黄/复古橙点缀。深档一现，整篇就像"大牌复古店的招牌"，把一段金句举到招牌上。但深档**全篇 ≤2 处**，用多了会把整篇压暗、失去奶油底的开阔感。正文段落不要进深档——深档是"展示"，浅档才是"阅读"。想"先镇场"就开头放深档，想"先暖场"就浅档开场、结尾收一处深档 CTA。

## 三、标题与字号层级

**标题样式特征**：复古广告牌标题——粗壮加粗字、可斜印、可带描边，像美式店招与复古广告的大标题。常配徽章与边框，标题本身就是一块老店招。

**装饰语法**（可参考写法）：

- **复古招牌标题**：粗黑大字 + 复古橙/青蓝 + 可 `transform:rotate(-2deg)` 微微倾斜，像老招牌被风吹斜。整篇最多 1–2 处倾斜，多了会晃。
- **双色徽章**：用 `<span>` 做青蓝/橙底白字、圆角 4px 的小牌子，配"NEW／限量／本店"等词，像促销贴纸。
- **描边感**：粗体 + 深色底白字烘托。做不清晰时就用深底白字或亮色底来衬，别硬拼失真。
- **双线框标题**：`border:2px solid #B75D2B`（复古橙框）+ 内 `padding`，做成"印章/标签"式标题框，适合章节入口。
- **高亮圆点**：标题旁放一个复古黄 CSS 圆点（`span`，蜂蜜黄，圆角 50%），像老广告打在重点旁的星点。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 招牌主标题 | 20–22px | 900/bold | 复古橙/青蓝粗字 + 徽章 |
| 章节标题 | 17–18px | bold | 暖咖啡黑 + 双线框 |
| 小节/副标题 | 15–16px | 600 | 深咖褐 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 复古标签/价格感 | 13px | 600 | 青蓝/橙徽章 |

> 标题上 28px、下 12px（硬规范）；招牌主标题可上 30px、下 16px。

**标题不要做什么**：不要三种字体混排（复古来自一种粗字一路到底）；不要把整段设成倾斜空心字；不在纯白底上用纯黑大标题（咖啡黑更暖）；徽章词（NEW/限量）一场最多 2–3 次，多了贬值。

## 四、模块表现

**重点气泡（复古橙描边卡）**：奶油底 + `border:1px solid #C98A45` 复古橙边，或 `border:2px solid #B75D2B` 粗边。圆角取 8px（复古广告偏方、不圆润过头），加细边框 + 留白撑出内呼吸（不用阴影/光晕），`padding:14px 16px`（硬规范）。可配左侧青蓝竖条 `border-left`，让"重点提示"一眼被抓住。

**卡片**：奶油橙黄底 `#FBE9D3` + `1px solid #E3C190` 暖边 + **圆角 8–10px** + `padding:14px 16px 12px`。顶部可放一条 4px 蜂蜜黄 `#E8A33D` 横条，或复古双线点缀。卡片之间用 16px 块距隔开。

**分割线**：复古星点/条纹——`border-top:1px solid #E3C190`，或三线（细分 `border-top` + 下方居中一个 CSS 圆点/菱形，`span` 拼），上下留 24px 呼吸。可用 `border-style:dashed` 蜂蜜黄虚线，像老票根上的齿孔。

**花纹**：可选复古星星/格纹/波点（保持奶油色级的明度），或复古斜纹（约 50 度、蜂蜜黄/青蓝做点缀、量要少）。整篇 ≤2 种且克制，花纹是背景不是主角。

**列表**：用 CSS 圆点/方块（`span` 拼、圆角 50%）或复古徽章序号做项目符，行距 1.75。可用青蓝/橙双色项目点，一冷一暖让清单不呆板、像价目表。

**步骤**：复古广告流程——"步骤"用徽章编号（青蓝/橙圆徽章白字）+ 短句，像菜品 recipe 的工序。步骤之间 16px，可做成"本店招牌三连"式串联。

**CTA（行动引导）**：店招式号召——带框按钮感：`padding:14px 16px`，复古橙底/青蓝底白字 + 蜂蜜黄描边，文案直接吆喝（"现在就进店""别错过这一口"）。通篇 1 处主 CTA、最多 2 处，用深档收尾最有力。

**模块组合节奏**：一屏信息只突出一个重点模块；深档、促销徽章这类"嗨"元素分散不扎堆（开头一个、结尾一个正好）；卡片间留满 16px，让读者顺着一块块"菜单"往下走。

## 五、图片与装饰

**图片处理**：圆角取 6–8px（复古广告略方），配复古暖色滤镜——奶油提暖、降饱和、加颗粒/轻微褪色，像老广告照片看旧了的样子。可做复古拼贴：圆形徽章元素叠在图上。比例多取 3:4（食物/单品特写，更像"菜单图"）或 16:9（场景/店面全景）。

**氛围选图**：汉堡、咖啡、皮具、老式霓虹招牌、胶片感照片是绝配。画面里有个老物件，读者立刻进入"黄金年代"语境。

**图片搭配一句式说明**：每张主图下方配一句话小字，像老报纸的照片说明——"本店招牌手作汉堡，每日现煎"，用浅褐灰 `#7A6A55`、13px，图片与说明之间留 8px。

**装饰克制**：图案/几何点缀每屏 ≤1 处，宁可留白。要用装饰只放复古感几何（CSS 圆点/方块/菱形，蜂蜜黄/复古橙/青蓝）或 `![说明](art://vine-frame)` 藤蔓花框做角饰，避免夸张印花堆叠。能用一个 CSS 几何点或复古徽章替代的，就不放图标。

## 六、文案调性

**语气关键词**：复古广告腔、亲切、暖、有年代感、呼唤行动。像老牌子的广告文案，温暖又带点"嗨"——不端着，也不轻浮。

**句式倾向**：

- 多用亲切直接的吆喝式短句（"来杯吧""进店喝一杯""第一口就爱上"），短才能像 slogan、才有力。
- 讲味道、讲用料、讲"想让你体验的那个瞬间"，少讲干巴巴的数据罗列，数字只用来做"经典的、老派的"背书。
- 适度带美式怀旧元素（"回到 60 年代的下午"），把读者从当下带进更暖的旧时光。
- 语气诚实、不过度夸张。老牌子气质在于"可信的暖"，不是浮夸。

**语气怎么落到不同内容**：上新/促销用口号 + 限量词压前（"今日新烤，限量三十个"）；品牌/情怀用回忆 + 暖承诺（"开店十五年，还是那个配方"）；产品/手作讲用料 + 讲过程（"牛肉现打、面包现烤"）；活动/探店用吆喝 + 邀请（"周末来店里坐坐"）。

**可直接套用的示例句**：

- "多年配方，一口回到 60 年代的下午。"
- "这杯手冲，第一口就决定留住你。"
- "老派做法，用料从来不省。"
- "把黑胶和旧时光，一起转起来。"
- "进店别客气，招牌三连请点齐。"
- "这个冬天，让老味道先替你暖场。"

**一个自然段内不要叠三个以上口号**，口号太多像电视购物，一句顶一句的事交给徽章去说。

## 七、禁忌与陷阱

1. **颜色太现代/太艳**：纯亮红、荧光蓝一掺入，暖哑光的复古感就碎成"深夜大排档灯牌"。
   **反例**：标题用纯红 `#FF0000`，再配荧光蓝强调。
   **正解**：走奶油棕橙 + 复古青蓝 + 蜂蜜黄的复古双拼，饱和度压到"老广告"的哑光暖，鲜艳只留给一小块促销贴纸。

2. **双拼失衡/色彩打架**：橙+青蓝+黄+红全面积铺开，画面太满太吵。
   **反例**：橙色、青蓝都当底，再叠黄块、插红标题，双拼变"乱炖"。
   **正解**：锁 1 主（复古橙）+ 1 辅（青蓝或蜂蜜黄）+ 少量番茄红。双拼是"双主角"，不是把整张色卡铺上去。

3. **复古变廉价土俗**：把"旧广告"做成"土掉渣"——乱拼字体、配色脏污。
   **反例**：土黄字 + 土褐乱堆 + 几种不清的杂字体混排，变汽配城风。
   **正解**：复古要有对比清晰的双色 + 干净排版 + 恰当徽章。"旧"在质感与年代，不在脏乱混排。

4. **俗用 emoji 破坏年代感**：成串现代 emoji 堆上去，复古氛围当场崩。
   **反例**：每句末尾加一排大笑/火焰类大表情，复古氛围当场崩，像给老海报贴满彩色贴纸。
   **正解**：图标极少，用复古几何符号与贴纸式徽章代替。

5. **忽视暖字可读性**：奶油浅底配过浅棕字，读者看着费劲。
   **反例**：用 `#7A6A55` 浅褐灰放奶油底 `#FFF3E2` 上做正文。
   **正解**：正文用暖咖啡黑 `#3A3028`，注释也不低于 `#7A6A55`。复古可以暖，但不能牺牲看清。

## 八、混搭方向

- **美式复古 × 日系（主 7 : 辅 3）**：咖啡/生活方式，美式奶油橙 + 日系米纸暖棕，暖上加暖（与"日系风"条目互通）。
- **美式复古 × 港风（主 7 : 辅 3）**：复古好物/街头感，美式奶油 + 港风霓虹/旧纸，复古大家庭互通。
- **美式复古 × 报纸（主 8 : 辅 2）**：美式老报/复古广告，加报纸分栏与徽章，更像"广告时代"的纸媒感。
- **美式复古 × 二次元（主 8 : 辅 2）**：美漫/复古运动向，二次元分镜 + 美式双拼，别喧宾夺主。

混搭时永远有一方是"主"、一方是"辅"。做主时就守美式复古的色板与双拼；做辅时只借一到两个元素（一个复古徽章、一条蜂蜜黄虚线），别让两套配色同时铺满整页。参照「风格混搭与主辅法则」。

## 九、封面建议

- **构图**：复古广告海报感——居中一个大图形（一个汉堡/相机/皮靴/老式霓虹）+ 双色拼底（上暖橙下青蓝或对角双拼）+ 大字标题，底部压一行小 slogan 或年份。可用圆徽章套住主图。
- **配色呼应**：奶油米白 `#FFF3E2` 底 + 复古橙 `#B75D2B` 或青蓝 `#2E5A8C` 大字 + 蜂蜜黄 `#E8A33D` 点缀；深档用咖啡褐底 `#33261B` + 奶油字。
- **字**：粗招牌字 ≤6 字 + 徽章/年份感；副标一句。字一多，海报的力就碎了。
- **气质**：暖、亲切、带点 60 年代广告的怀旧快乐，让人一眼想点开。
- **翻车补救**：图太多、标题被挤 → 只留一个大图形；颜色太现代 → 罩一层奶油/做旧滤镜；slogan 堆两条 → 只留一句；深档封面 → 咖啡褐底 + 蜂蜜黄亮字，别在深底上再用深字。

## 十、深色模式表现

- 深色模式把奶油米白底换成咖啡褐/棕黑底（`#2A2018` / `#33261B`）+ 奶油黄字 `#F4E3C8`，暖调保持一致、不刺眼。
- 复古橙 `#B75D2B` 在深底上提亮为 `#D0803F`；青蓝 `#2E5A8C` 提亮为 `#4E87C0`，主色在暗底上依然看得清。
- 暖咖啡黑正文 `#3A3028` 在深底上会被吞，要提亮成奶油黄。背景一深，字就要跟着变浅。
- 蜂蜜黄 `#E8A33D` 在深底上保持或微提亮，注意别刺眼。
- 奶油卡 `#FBE9D3`、焦糖块 `#F5D9B8` 在深底上会太亮，改成深咖啡卡。
- 分割线浅咖米 `#B8A080` 提亮为 `#D0B890`，徽章/按钮用蜂蜜黄或复古橙做底、白字在上。
- **深浅切换口诀**：底变深、字变浅、点缀提亮一档。守住这条，深浅档都保持在同一种暖调里。

## 十一、个性化空间

- **双拼主色**："复古橙 + 青蓝"最经典（美式运动/咖啡）、"复古橙 + 橄榄绿"（露营/户外）、"复古橙 + 砖红"（更暖传统）。**判断依据**：品类联想色 + 品牌色系。
- **暖 vs 冷倾向**：咖啡/旧物重暖（橙+蜂蜜黄），美式运动可重青蓝（更学院）。**判断依据**：内容属性和读者想被点燃的温度。
- **复古浓淡**：vintage 好物/老歌可更旧更做旧，日常餐饮稍清亮奶一些。**判断依据**：读者对"老旧质感"的接受度。
- **徽章/贴纸密度**：美式运动/大促可多徽章双色拼，安静的生活方式内容少一点。**判断依据**：内容热闹程度。
- **装饰密度**：年轻向可适度多点美式复古几何/徽章点缀，怀旧收藏向少用、以留白代替。**判断依据**：受众年龄段与收藏属性。图案/几何每屏 ≤1 处。

**落地检查清单**：正文底是奶油系非纯白；双拼锁 1 主 1 辅；深档 ≤2 处；行高 1.75、块距 16px、气泡 padding 14px 16px；标题上 28 下 12；图案/几何每屏 ≤1 处、宁可留白；没有把纯黑、纯红、荧光蓝当正文色。

以上留白点为可调参数，调用方应结合账号与读者落地。
