# 清水森系（绿色自然版）

> 定位：日系风格的**子系变体**。日系的「米纸底 + 暖棕」偏暖和的都市慢生活，本变体把它往「绿色自然」再推一步——把主色从暖棕换成草绿/墨绿，字里行间都是植物的清气、山野的呼吸感。
> 适用对象：植物、自然、户外、健康、素食、民宿、生活方式里偏自然的内容。调用方：排版时把暖棕换绿色系，纹理多用「叶、水、木」的自然元素。

## 一、属于哪个顶层风格的子系

- **母风格：日系风格**（生活方式、美食、旅行、家居）。本变体继承日系的「纸感、留白、文字为主、温暖治愈」，只换主色家族与自然元素。
- **一句话**：日系内容不想「暖咖」想「清爽绿」，或偏户外/自然时，走本变体。

### 何时用本变体，而不是直接用日系母风格

| 内容状态 | 选择 | 理由 |
|---|---|---|
| 都市慢生活、咖啡馆、暖调手作 | 日系风格（母） | 暖棕米纸才是"咖啡馆温度"，青绿会偏冷偏野 |
| 植物、户外、度假、素食、自然疗愈 | **清水森系（本变体）** | 草绿墨绿的自然气息才接得住"山野呼吸" |
| 想强调"清爽、清透、接近自然" | **清水森系（本变体）** | 日系的暖咖偏温，本变体的青调偏"清新" |
| 民宿、生活方式里带自然庭院感 | **清水森系（本变体）** | 绿调让"住进自然"的意象更贴切 |
| 纯粹家居收纳、器物美学 | 日系风格（母） | 器物之美适合暖纸感，青绿会抢"器物的质感" |

判断尺：**内容是"喝杯咖啡的暖"还是"走进山野的清气"**——后者走清水森系。

## 二、与母风格的差异点

| 对比维度 | 日系风格（母） | 清水森系（本变体） |
|---|---|---|
| 主导色 | 米纸 + 暖棕 + 奶茶橘 | **米白 + 草绿 + 墨绿 + 木褐** |
| 气质 | 温暖、手作、慢生活 | **清爽、自然、呼吸感、山林间静谧** |
| 纹理元素 | 暖调纹样、无或极浅 | **叶形、水波、木纹、露珠感** |
| 底色 | 米纸底 `#FBF7F0` | **更净的米白 `#F9FBF2`（带一点青），分区用极浅绿** |
| 标题 | 居中带小符号、暖棕下划线 | **草绿标题 + 叶形/细线装饰 + 居中** |
| 气质关键词 | 治愈、陪伴 | **清新、通透、接近自然** |

- **冷暖区别**：日系是"米纸上的暖"，本变体是"米白里的清"——底色带一点青调（`#F9FBF2`），比纯米纸更"净"。
- **纹理区别**：日系极少用花哨纹理，本变体可多用叶、水、露的自然纹理，但保持一致地极浅、克制。

## 三、完整色板

> 核心是「绿 + 木褐 + 米白」。比日系更冷一分、更净一分。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FAFCF4`（净米白带青调） | 全文底色，比纯日系的米纸更清爽 |
| 分区浅底 | `#EEF5EA`（极浅绿） | 卡片/气泡底色 |
| 主色1 | `#5B8C5A`（草绿） | 标题主字、小标题、下划线、图标主色 |
| 主色2 | `#3F5F4A`（墨绿） | 强调、关键信息、按钮感元素 |
| 辅助色1 | `#A8C3A0`（浅鼠尾草绿） | 图标、图注、次级强调 |
| 辅助色2 | `#C9A227`（芥末黄） | 高亮点缀、叶尖色（少量） |
| 强调/木色 | `#9A7B5A`（木褐） | 图注、分割线、器物感元素 |
| 正文文字 | `#3D4036`（墨青灰） | 正文用色 |
| 次级文字 | `#8E9085`（灰绿） | 注释、图注 |

**每个色号一句话用法**：

- `#FAFCF4` 净米白：全文底，带一点青调，比纯白多一层"清"，别换成冷白或纯白色。
- `#EEF5EA` 极浅绿：卡片/气泡底色，清新的自然底，让分区带"叶的浅影"。
- `#5B8C5A` 草绿：主标题、小标题、图标，本变体的"主气息"，一棵草的绿。
- `#3F5F4A` 墨绿：强调与关键信息，比草绿沉一档，是"林深处"的重量。
- `#A8C3A0` 浅鼠尾草绿：图标、图注与次级强调，柔和的浅绿，用于层次。
- `#C9A227` 芥末黄：高亮点缀、叶尖色，只在"露珠/光点"或强调词用得极少（≤10%）。
- `#9A7B5A` 木褐：分割线、图注、器物感元素，给绿的方案加一份"木的暖"来平衡。
- `#3D4036` 墨青灰：正文主色，温、深、不刺眼的绿调墨色。
- `#8E9085` 灰绿：注释、图注，可读底线。

**配色规律**：草绿 + 墨绿为主要，木褐做「器物/分割」的暖平衡，芥末黄只做零星高亮（≤10%）。整篇亮色 ≤3 个。若内容偏「雨林/深林」，可把草绿换墨绿为主；偏「春芽」则草绿 + 嫩黄多些。

**深浅档切换**：白天/户外内容走浅档（净米白 + 草绿）；"深夜森林、篝火夜话"的沉浸内容可切一段深档（墨绿黑 `#1E2B22` + 提亮的草绿/墨绿 + 米字），**深档每篇 ≤2 处**，放在最有"山野夜色"的段落。深档必须保证绿色与深底有明度差。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | 草绿大字 + 居中 + 下方一条叶形/细线；或左对齐 + 小叶片图标 | `山里有风，风里有树` |
| 章节小标题 | 行首小叶片/露珠图标 + 墨绿字；或一条 CSS 细竖线 + 草绿字 | `在溪边坐一会儿`（行首一条纯色细竖线） |
| 重点句 | 墨绿加粗 + 浅绿底高亮；或夹在叶形图案间 | `慢，是给生活留白` |

- 字号：大标题 20-22px，章节 18px，正文 15px，注释 13px。
- 标题字距 1-2px，正文 0.5px，行距 1.9（舒展）。

**自然小标的写法**：章标题前放一枚纯色 CSS 圆形/叶形徽章（`<span style="display:inline-block;width:8px;height:8px;background:#5B8C5A;border-radius:50% 0 50% 50%;"></span>`）或一条细竖线；或引用 art:// 植物图案如 `leaf-corner` 叶角。标题下可放一条 `border-bottom:1px solid #A8C3A0` 的浅绿细线。居中标题配一条叶形/细线装饰，左对齐则多用叶形徽章，别把装饰集中到一处堆满。

## 五、模块表现

- **重点气泡**：极浅绿底 + 1px 鼠尾草描边 + 圆角 14px；左上角一片小树叶做角标；内文 14px 墨青灰。
- **卡片**：白/极浅绿底 + 1px 浅绿描边 + 圆角 12px + `padding:14px 16px`，靠低饱和纯色 + 细描边撑层次，不加投影。
- **分割线**：一条木褐色细线或「~」水波形，或一串小叶片；上下 24px。
- **花纹色带**：极浅叶纹或水波形（透明度降到很浅），或纯用静面极浅绿带；整篇 ≤2 条。
- **列表**：圆点换成叶片/水滴形；编号用木色圆圈。
- **图片**：图片圆角 12px 以上，可加极浅绿描边；多图错落如草木生长。
- **步骤**：步骤圈用木色圆形编号（`border-radius:50%`，直径 22px，白字），每步一句短说明，配一句自然感小话（"先走近一棵树，再慢慢坐下"），比冷序号更贴自然节奏；步骤间 16px。

**一个"自然高亮重点句"的骨架**：

```html
<div style="background:#EEF5EA;border:1px solid #A8C3A0;border-radius:12px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0;color:#3F5F4A;font-weight:600;line-height:1.75;">慢，是给生活留白</p>
</div>
```

要点：重点气泡圆角 12-14px（自然柔和），极浅绿底 + 1px 鼠尾草描边，别加粗黑描边——森系要"轻"不要"硬"。

## 六、图片处理与装饰

- 图片：首选自然实拍（叶、光、水、木），可统一加「青绿/低饱和」滤镜让整篇图片色调一致。
- 图片比例多取 4:3 或 3:4，圆角 12px 以上、可加极浅绿描边；多图错落排成像草木生长，别整齐堆成格子窗。
- 图太艳/太冷时，压饱和度 + 调一点青绿，或裁一小块做角落氛围。
- 也可给一张关键氛围图叠极浅水波/叶影细节，但别叠得太显，保持"看出来有、指出来才注意"的浅。
- 装饰克制：图案/几何点缀每屏 ≤1 处，宁可留白。别用图案字符破题，装饰只做标题、重点气泡的点缀。图案资产只可用植物/自然类：如 `sprig-grass` 小草、`vine-frame` 藤蔓花框、`blossom-branch` 花枝、`leaf-corner` 叶角、水波/叶形线条——在正文用 `![说明](art://资产名)` 引用，或用这些图案做气泡/标题装饰，一律低饱和纯色线条化，绝不用图标类图案。
- 自然元素密度：整篇图标/装饰 ≤6 处，集中在标题、重点气泡、分割线，正文保持素净与留白。

## 七、禁忌与陷阱

1. **别用高饱和荧光绿**：`#00FF00` 或亮黄绿瞬间变「网游/促销」，森系要墨绿、草绿、鼠尾草这种低饱和自然绿。
2. **别把底色做得太「塑料」**：纯白会失去纸感，用带青调的米白 `#FAFCF4`，别用纯 `#FFFFFF` 铺全文。
3. **别堆太多自然元素**：叶、水、木全上满就乱，宁缺毋滥，一屏 ≤1 个重点自然元素。
4. **别放弃文字为主**：森系是「轻装饰的文字风」，不是大片插画；图片与绿调服务于文字节奏。
5. **别忽略对比**：正文用墨青灰 `#3D4036`，别整段草绿字，否则长文阅读费眼。
6. **别用城市霓虹/灯光 emoji 或高饱和图片**：会瞬间把"山野清洁"切换回"都市夜场"，氛围全崩。
7. **别让木褐喧宾夺主**：木褐只做分割与图注，别把主色做成本褐，否则就从"清水森系"滑回日系暖咖。

## 八、混搭方向

- **+ 日系（暖）**：森系做主体，在氛围处加一抹暖棕/米纸，适合「植物系生活方式」兼顾温度。
- **+ 治愈手绘**：森系绿 + 手绘线条，适合亲子自然内容（见治愈手绘条目的换色法）。
- **+ 极简**：只留草绿标题 + 大留白，适合「新自然生活方式」的高端清冷感。
- **- 禁忌**：别混赛博朋克霓虹、别混国潮红金、别混孟菲斯高饱和撞色——冷绿气质冲。

## 九、封面与首屏建议

- 封面：自然实拍 + 左上或居中草绿大字标题 + 一条极简叶形线装饰。
- 首屏：居中大标题 + 「一句话自然引言」，第二屏进正文，保持大片留白。
- 配色呼应：净米白 `#FAFCF4` 底 + 草绿 `#5B8C5A` 标题 + 芥末黄 `#C9A227` 微量高亮，封面与正文同系"草木"，点进去如走进一片绿地。

## 十、深色模式表现

- 深色下：底色换「墨绿黑」`#1E2B22`，分区浅底换 `#28382E`；草绿提亮（`#78B075`）、墨绿提亮（`#5E8A6C`）保证对比；正文用米白 `#EDF2E3`；叶形描边用浅鼠尾草 `#C4D8A9` 避免在深底消失。
- 森系绿色在深色模式非常合适，但注意不要过度降低明度导致沉闷。
- 原墨青灰正文 `#3D4036` 在深底上需提亮为米字，否则被吞；芥末黄在深底上保持但要克制，别闪光刺眼。

## 十一、个性化留白（按账号自定）

- **绿调层次**：偏春（草绿+嫩黄，清新）／偏林（墨绿为主，沉静）／偏风（浅鼠尾草+大面积留白，疏朗）——按读者群与内容季节感定。
- **自然痕迹多少**：淡（仅配色）／中（加叶片点缀）／浓（木纹+水纹纹理）——结合内容是否真与自然相关（户外号可浓，普通生活方式号宜淡）。
- **是否保留日系暖元素**：保留（混合暖棕）／纯绿（彻底英式清新）——看账号长期调性。
- **木色 vs 纯绿**：加木褐（器物/民宿向）／几乎不用木色（纯净植物向）——按内容是否带"手作器物"感取舍。
- 判断依据：读者对清爽/自然感的偏好、内容实际与自然的关联度、账号品牌主色（若有绿色最契合，谨慎覆盖品牌色见」账号风格基线」条目）。

**给调用方的复查三问**：一、主色是不是草绿/墨绿/木褐在撑、没有荧光绿或城市霓虹跳出来抢？二、底色是不是带青调的净米白、没有铺一片塑料纯白？三、自然元素是不是克制地放在标题与重点、正文保持素净可读？

**清水森系的"活"在哪**：同样的绿调配方之下，比的是谁把"清爽"拿捏得刚刚好——一处草绿标题、一片极浅绿叶底、一行木褐分割，就足够让读者闻到"山间的风"。绿要厚，但别闷；像素净，但要有呼吸。
