# 视觉一致性检查（style-guide-check）

这份清单检查呈现，不评定文章语言，也不通过切碎句子、缩短段落或更换口吻修复版面。

## 逐项检查

- 配色：主色、辅助色、记号色具有明确用途，文字与纸面可区分。可参考深灰 #444444 或暖墨 #3D3A34 的文字深度，但最终检查实际对比度。
- 字形和字重：标题与正文层级清楚，普通正文使用清楚字体；装饰字体不覆盖连续正文。
- 对齐和留白：标题、段落、图片与图注保持对应关系，行距和间距由引擎执行。正文以当前引擎实际字级为准，花笺、票笺、缎带预置正文为17px；框内不应比相邻正文明显偏小。间距既看单块也看相邻组件的总和，悬置题签须有真实占位，章间分隔不能与标题外距叠成大片无内容空白。不从字号和间距推导句长或段长。
- 主题贯穿：花哨、精致的要求应在题头、章标、框体、分隔中共同可见。检查这些位置是否共享同族花枝、票孔、缎带或几何语言；只给提示卡换色、添小图标或孤立短线不算完整设计。极简要求则尊重少装饰。
- 角色分工：题头、章标、框体形态有轻重差别，不每层都套完整圆角框；双框、语义标签与角标各有用途，不把“提示／注意／重点”机械重复成一行。标题中没有自动编号与原稿编号叠加。
- 框线与图案：线条粗细、圆角、骨架与装饰体现用户选择，重点不相互遮挡。明丽风格可以有丰富图案，极简风格可无图案，不以“装饰更少”统一判优。
- 图片：原图身份、说明、裁切完整性和来源明确。不能为了统一冷暖擅自换图、补画事实或声称已有未执行的滤镜处理。
- 手机预览：核对溢出、遮挡、孤立标题、过窄文本列和深浅模式下的可读性。连续正文不因框宽不足而改成单行短语。

## 查看范围与判定

按375px实际宽度检查开篇、中段与结尾，既看单个框体细节，也看连续滚动节奏。装饰应足够明确地表达所选主题，正文区同时保持舒展。检查密集长段、长标题、章标紧接题签、框内照片等位置，不能用删除正文、切碎句子或把照片缩成角饰来修正布局。

局部截图只能确认可见区域，不能用截图上下边缘的截断认定文章裁切，也不能据此认证全文完整。是否保留全文、原图及原有章节，须独立比对；无实际预览时不编造质量评分。

## 如何修正

先调整主题母题、造型分工、配色、字重、对齐、间距、骨架和图案；内置主题装饰可直接复用，不为修正每个节点新增一次绘图。组件确实不适合连续说明时改用普通段落。内容错误回到写作方法处理，不把视觉偏好转换成聊天、安慰或口号要求。

当前输出只用 engine-write-protocol 的 v2 语法。正文容器按 `fill` 选择无底或浅底，常规横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构；花笺、票笺、缎带题头采用对应主题轮廓，可铺底部分遵循 `fill`；保留零 emoji、零图标字符、零渐变、零阴影。协议浅底、小记号及插画内部均可用色，用户明确无底时用 `fill=none`，不复制旧 HTML/CSS 或 art:// 地址。
