# 风格一致性检查清单（发布前逐项核对）

> 定位：跨风格通用方法论。写完后、发布前，把「风格有没有跑偏、有没有半路换味」逐项核一遍。每项都写「查什么、怎么改」，配合尾声的「常见误用对照表」。
> 适用对象：每篇定稿前 / 负责公众号排版的人逐项打勾。调用方：按清单一栏一栏过，全过才发布。本篇未命中某条（如没配图）时跳过该未勾选项。

## 一、发布前检查清单（逐项打勾）

> 全篇 7 大项、每项 3 个勾选项。全部打勾才算风格统一。每一项都写清「这一项在查什么」「发现问题怎么改」。

### 1 色板一致性
- [ ] 全篇主色只有 1 个（+ 至多 2 个辅助 + 1 个强调），没有混入出风格的色。
- [ ] 正文文字色与底色对比足够（正文文本深度 ≥ `#444444` 一档，勿用高饱和色做正文字）。
- [ ] 所有强调词、标题、植物装饰图案（art://）都在本风格色板内取色，没有「自动取色」出的杂色。

**这一项在查什么**：颜色的「血统」是否纯。混入一个不在色板里的颜色，是最常见、也最容易让风格「串味」的问题。

**怎么改**：
- 发现杂色 → 打开你选的那个「风格条目」的完整色板表，把杂色替换成色板里同明度、同调性的颜色。
- 正文太艳 → 换回 `#444444`~`#3D3A34` 级别的暖墨/墨蓝，把亮色只留给标题与强调。
- 想确认 → 用「色板核对」：把全文出现的颜色列出来，逐色对照所选风格色板，凡不在表内的逐一替换。

### 2 标题风格
- [ ] 标题样式全篇用一种（胶囊 / 左竖条 / 居中符号 / 斜切块 / 大圆角 banner…），没有两种并存。
- [ ] 大标题与章节小标题的字号、装饰保持层级一致（大 20-24px、章 18px、正 15px）。
- [ ] 标题用色与底色对比清晰（深字 / 白字彩底都算，不能灰扑扑看不清）。

**这一项在查什么**：标题是读者每一屏最先看到的，标题样式一旦不统一，整篇「骨架」就散了。

**怎么改**：
- 出现两种标题样式 → 以后出现的那一种统一回你主选的那一种。
- 字号错层 → 按「大 / 章 / 正」三档字号与装饰重新规整。
- 对比不足 → 浅底上换深色字；深底的标题该加亮或改白字彩底。

### 3 模块样式
- [ ] 全篇同一类模块只用 1 种样式（气泡只用 1 种、卡片只 1 种、分割线 ≤2 种）。
- [ ] 重点气泡 ≤2 个；装饰标题 ≤2 处；花纹 ≤2 种；徽章 ≤3 个（见「模块组合铁律」）。
- [ ] 所有块的间距符合硬规范（块距 16px、行距 1.75、标题上下 28/12px）。

**这一项在查什么**：正文由模块拼起来。同类模块混三种样式、或上限超编，是最常见的「堆砌」来源。

**怎么改**：
- 同类模块形式不一 → 归一成一种（卡片全用同款、气泡全用同款）。
- 超上限 → 删到上限内：重点气泡 ≤2、装饰标题 ≤2、花纹 ≤2、徽章 ≤3。
- 间距乱 → 按「间距硬规范」补齐：段落 / 卡片 / 气泡之间统一 16px，正文行距 1.75。

### 4 花纹用量
- [ ] 花纹只用在本风格允许的档位（浅档 / 中档），没有把花纹铺满正文区。
- [ ] 花纹种类 ≤2 种，且都是本风格该有的（森林用叶纹、国潮用云纹回纹、插画用波点…）。

**这一项在查什么**：花纹最能暴露「风格漂移」——用错花纹或铺满花纹，风格会瞬间跳走。

**怎么改**：
- 花纹种类 >2 → 删到 ≤2。
- 用了不该用的花纹（如国潮用了波点）→ 换回该风格条目列出的花纹。
- 花纹铺进正文区 → 只保留在「花纹色带」或「标题衬底」位置，正文区保持素底。

### 5 装饰克制 / 装饰图案密度
- [ ] 装饰只用「植物 / 自然类」图案（botanical：sprig-grass 小草、vine-frame 藤蔓花框、blossom-branch 花枝、leaf-corner 叶角，通过 ![说明](art://资产名) 引用），绝不用图标类图案。
- [ ] 装饰用量在克制阈值内（多数风格「图案 / 几何点缀每屏 ≤1 处」；插画 / 校园类可稍多但全篇仍收紧）。
- [ ] 装饰承担功能（起笔 / 小标 / 收尾），没有拿装饰当正文填充。

**这一项在查什么**：装饰用错类（图标 / 贴纸）或铺满，会让图文瞬间「掉价」或风格崩坏。

**怎么改**：
- 用了图标类装饰 → 换成植物 / 自然类图案资产（art:// 引用）。
- 用量超 → 删到阈值内，中间段落的装饰用留白或植物图案替代。
- 装饰过密 → 收敛到每屏点缀 ≤1 处，主要在起笔、小标题、收尾三处，其余宁留白。

### 6 图片滤镜 / 图片风格
- [ ] 图片风格统一（要么都实拍、要么都插画、要么都同一滤镜），没有「实拍 + 插画」混着还没道理。
- [ ] 图片圆角、描边、留白方式全篇一致，匹配本风格块的取法。
- [ ] 图片色调与主色情绪一致（冷色风格配冷调图、暖色风格配暖调图）。

**这一项在查什么**：图片是最容易「带跑风格」的部分——一张暖橙实景丢进冷调科技文，整段氛围破功。

**怎么改**：
- 图风格不统一 → 给整批图套同一滤镜 / 同一种描边，让「不一致」至少显得「有意为之」。
- 圆角 / 描边不统一 → 统一成一种（本风格条目里给了各风格图片做法）。
- 色调不配 → 换一张同色调的图，或给现有图套同款滤镜调回主色情绪。

### 7 结尾 / 行动号召
- [ ] 结尾块风格与正文主风格一致（不是正文走商务、结尾突然插画撞色）。
- [ ] 行动号召与风格情绪匹配（庄重风格用稳的号召、活泼风格用冲的号召）。

**这一项在查什么**：结尾是读者「最后一眼」的印象与行动点，结尾风格一跳最伤整体感。

**怎么改**：
- 结尾样式跳风格 → 回到主风格的做法。
- 号召语气不对 → 按所选风格的文案调性收：庄重风格的「礼遇 / 同行 / 共此时」这类稳的号召，活泼风格的「抢 / 限量 / 手慢无」这类冲的号召。

## 二、风格一致性的 3 个自检信号（快速粗查）

1. **3 秒测试**：把全文快速划一遍，能 3 秒说出「这是什么风格」吗？说不出 = 风格没立住，回查色板与标题。
2. **删除测试**：随意删掉一个装饰，风格还成立吗？若删掉就垮，说明之前靠堆料撑，需回到少而准的特征元素。
3. **黑白测试**：把全文看成黑白灰，还有层次吗？若只有颜色差异、没有字号 / 留白差异，改靠字号与留白补出「层次」。

> 三个信号是「快扫」，若 3 个信号都亮红灯，直接进第1、2、3项逐条改。

## 五、改不动时的兜底

- 若某项实在改不回（如图片已定稿），给出**合理的统一化处理**：给整批图套同一滤镜 / 描边，让「不一致」至少看起来「有意为之」。
- 若风格撕裂严重到修补成本高，优先保「色板 + 标题 + 模块样式」三项——这三项定节奏，其余（花纹 / 装饰图案）可容错收敛。

## 六、FAQ（常见疑问）

**Q：两个风格都「好看」，不舍得删一个，怎么办？**
A：这正是「混搭」的诉求，去走「风格混搭」主辅法则，别在同一篇硬做「风格一致性」。若又混又不想查一致性，二选一：要「统一」就单风格过此清单；要「两份好看」就守主辅比例。

**Q：检查太麻烦，能只查核心三项吗？**
A：能，最低保「色板 + 标题 + 模块样式」三项（这是风格骨架）。但注意花纹与装饰图案往往是「风格漂移」最大来源，建议至少再把「装饰克制」过一遍。

**Q：清单里「未命中」就跳过，会不会漏检？**
A：跳过的是「本篇没有的元素」而非「该检没检」。若这文明明有图片却跳过了图片项，属于漏检，请补做。

## 七、个性化留白（按账号自定）

- **检查严格度**：有的号每篇必过 7 项，有的号容许小节渗杂色——严格度是运营标准，本条目给全项清单，删减由运营者定。
- **装饰克制阈值**：不同风格条目给的阈值略有差异，以你选的风格条目里的数字为准，本清单的取值是通用基线。
- **是否把风格检查写进 SOP**：是否「每篇发布前必过此清单」并记录问题，是账号流程决策。
