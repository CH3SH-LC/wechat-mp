# 时令节日的视觉适配（style-guide-occasions）

> 定位：在已有视觉基线中选择与时令、节日或校园时点相关的色彩与图像。

选材、标题、段落组织与结尾由 `文本/写作` 知识负责：按任务需要读取 `writing-purpose`、`writing-structure`、`writing-campus`、`writing-product`、`writing-explain`、`writing-story` 或 `writing-review`。视觉风格只决定呈现方式，不绑定文章结构、篇幅或语气。

## 选择视觉方向

先确认文章的实际主题与用户偏好，再选择色板、线饰或配图。节日是视觉参考，不要求整篇换风格，也不要求添加节日开场、祝词或号召。

| 时点 | 可选视觉线索 |
|---|---|
| 春节、元宵 | 红金、灯火、花灯与圆月 |
| 清明 | 青灰、山水、纸鸢与留白 |
| 端午 | 粽叶青绿、水面、龙舟相关画面 |
| 中秋 | 月金、桂花、圆月与暖米色 |
| 国庆 | 红金、庄重构图与真实场景 |
| 年末、元旦 | 时间线、年度数据与账号既有色彩 |
| 毕业季、开学季 | 校园实景、书本、社团或毕业相关对象 |
| 母亲节、父亲节等 | 与真实人物和活动有关的画面，颜色由本篇决定 |
| 促销时点 | 与实际活动有关的产品图、日期和价格标识 |
| 节气 | 当地真实的植物、气候或季节线索 |

这些线索可选，不代表日期一到就必须使用某种风格。图片与文字需符合真实地点、时令和活动情况。

## 与账号基线配合

极简稿可以只调整标题或细线的强调色；明丽稿可以采用更鲜明的配色、线饰与插画。保留正文对比度和标题层级，不把节庆颜色铺成文字底色。

可参考中国红 `#C8102E`、月金 `#C9A24B` 等既有色值；最终需与本篇色板、背景与文字对比度一起判断。红金、青绿或暖棕都不自动决定文案语气。

## 素材与复核

采用已授权照片或与需求对应的插画；不要把生成的活动画面当作现场记录。价格、日期、人数和优惠条件由材料提供，视觉不新增这些事实。

检查节日元素是否遮挡文字、抢走信息层级，裁切后是否还能识别主要对象。用户明确要少装饰时，节庆题材也可保持素净。

实际输出以 `engine-write-protocol` 的 v2 语法为准。色板与版式分别选择；正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构，允许协议支持的小记号与插画内部填色。保持零 emoji、零图标字符、零渐变、零阴影。素材沿用有效引用，生成需求使用协议支持的 `[[img]]` / `[[deco]]`；旧 HTML/CSS 片段仅用于理解视觉，不作为桌面输出语法。
