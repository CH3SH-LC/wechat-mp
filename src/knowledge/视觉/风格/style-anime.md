# 二次元动漫风（style-anime）

> 定位：分镜、萌系、热血、二次元浓度高，像一话动漫分镜和一张漫画贴纸，画面感强、拟声词与吐槽并存、年轻人特爱。
> 调用时机：游戏动漫、追番、二次元周边、年轻向娱乐、热血/中二向内容，以及一切想"刷到就开心、像看番一样追下去"的内容。

## 一、气质与适用内容

**气质关键词**：分镜、萌系、热血、中二、夸张搞笑、次元感；分镜卡 + 萌系贴图是它的骨架，拟声与吐槽是它的语气。

**适合的内容类型与行业**，逐项说明为什么合适：

- **游戏动漫**：新番/新游、追番推荐、动漫盘点、游戏攻略、二次元梗。这类读者本身就在追番、刷 B 站，漫画对话框与拟声词是他们的母语，用分镜格讲"这一话发生了什么"比用长段落更省力，也更容易被截图传播。一个"本周必追榜"配三格分镜，比纯文字清单更能让人点进全文。
- **二次元周边**：手办、谷子、cosplay、漫展预告。周边产品的卖点常常在一个"画面"（这个角色的这个表情、这一格名场面），二次元的强烈描边与高饱和正好把单张图放大成主角，配合"开箱三连"式贴纸，购买冲动更强。
- **年轻向娱乐**：声优、广播剧、动画电影、B 站向内容。年轻受众的注意力节奏偏快，分镜式短卡 + 够大的拟声大字/亮色几何点缀，让他们即使在列表页扫一眼也愿意停下；拟声词制造的"轰——"冲击感，恰好符合他们"刷到就想点"的偏好。
- **热血/中二内容**：热血故事、成长励志（动漫化表达）。把抽象的一句"坚持就能出头"变成"我命由我不由天！"的冲击台词，再配一张斜切冲击波标题，情绪的爆发点更直观，转发欲也更强。
- **二次元文化科普**：设定、声优、圈层文化。讲"这部番的设定怎么来的"时，用分镜 + 对话框穿插说明，读者不会觉得在读论文，反而像在看彩页解说，科普的耐心就被分镜拆碎了、变得好吞。

**不适合的场合**，说明为什么是雷区：

- **严肃财经、法律医疗、政经报道**：二次元太"玩"，会直接损掉内容的权威感。读者在财经解读里看到萌系贴纸和拟声词，第一反应往往是"这是不是搞笑的"，信任感一降，把严肃结论也拖累了。
- **正式 B 端、高端商务场合**：面向企业决策者、发布会、招商材料里出现漫画分镜，极容易被认定"不够专业"，甚至显得儿戏，商务的庄重腔调会被贴纸击碎。
- **老年/非二次元受众为主的账号内容**：这是典型的群族错位。他们不熟悉黑话、不理解分镜节奏，反而觉得花哨、吵闹、看不懂，爽点的设计全部扑空。
- **需要极度冷静客观的内容**：当内容要求结论中立、语气克制（如客观盘点、数据说明）时，二次元的高浓度情绪表达会让语气"失控"，很难维持那份冷静，读者也容易觉得结论不可信。

**二次元浓度三档，落地前先定一档**：

- **低浓度（泛二次元/大众向）**：分镜、贴纸、拟声都有，但都用得克制，黑话有解释，偏"年轻化排版"。适合追大热番改编、轻度二次元受众所在的泛娱乐号。
- **中浓度（常规二次元号）**：对话框、分格、拟声词、梗按节奏穿插，黑话适度但尽量带一句解。最常用的一档，兼顾核心读者与路人读者的体验。
- **高浓度（纯圈层/资深号）**：黑话深度用、梗密集、分镜密度高、二次元浓度拉满。只适合纯二次元受众为核心的账号或特定圈层企划。

定档的原则：**跟着"读者以为自己是圈内还是圈外"走**——读者越纯、档位可越高；读者越泛、档位越要往下压。

**判断一句**：读者是二次元/年轻人、内容要"像追番一样有画面、有梗、想截图分享"，二次元正中；要"庄重专业、让人信服"，就别用。

## 二、完整色板表

```text
背景类（漫画纸白 + 分区）
  #FFFFFF        纯白底：正文底色，漫画纸感 —— 常规段落的主底，干净不抢戏
  #F7F8FA        浅灰蓝白：分区卡 —— 用来隔开"不同章节/不同栏目"的浅底，比纯白更松弛
  #FDF0E7        浅杏打底：字框/贴纸区 —— 漫画对话框感的暖白，重点引语用它会立刻"进画"
  #1A1A1A        深墨（深档底）：高光/扉页 —— 只在最强标题与结尾页出现，一压就出冲击力

主色类（亮快主色 1-2 个）
  #FF6B6B        活力橙红：主标题、主角色，热血 —— 全篇的第一亮色，标题底与对话框描边常用它
  #4FC3F7        天蓝/电蓝：另一主色，清爽 —— 与橙红二选一手、主画面清爽，竞技/夏日向更顺
  #FFD93D        元气黄：高亮/拟声词，第三主色（点缀） —— 单独做"高亮/荧光/拟声字"，不铺大片

辅助色类
  #7C3AED        糖果紫：点缀色 —— 用在角标、小徽章上，给画面一点惊喜色
  #FF9F43        南瓜橙：暖点缀 —— 暖色里的第二档，用低饱和实色做过渡点缀
  #4A5568        深板灰：正文次级（柔和深） —— 比纯黑柔和一档，次一级的说明文字用它

强调色类（点睛，全篇克制）
  #FF3B5C        正红：最强强调（"最强""必看"） —— 只在"最强/必看/最燃"这种最高级词上出现
  #18A0FB        亮蓝：超链接感/必看标 —— 需要"点这里/必看"的那种动作感时亮一下
  #FFE200        高亮黄：荧光笔/拟声高亮 —— 模拟荧光笔划重点，拟声词标配

文字色类
  #352B3D        深紫褐：正文主色（暖深，避免纯黑） —— 大半段正文都用它，暖而不刺眼
  #6A5A6E        浅紫褐灰：注释 —— 旁白、括号里的吐槽、出处说明用这档
  #3F3F46        深灰：次级 —— 列表里的补充与次要句，比注释稍深
```

**深浅两档怎么用**，分别成段：

- **浅档（默认）**：白纸底（`#FFFFFF`/`#FDF0E7`）+ 亮色块 + 深紫褐字（`#352B3D`）。这是二次元本体的漫画感：清爽、热闹、像翻开一本彩漫。日常的大部分段落、正文、清单都留在浅档，亮色块负责抓眼、深紫褐字负责好读。
- **深档（高光/扉页）**：深墨底（`#1A1A1A`）+ 亮色大字 + 白字。只用在全篇 2–3 处——「开篇扉页、最强标题、结尾高光」，像漫画的彩色扉页和冲击波画面。切到深档的那一刻画面会"一下沉下去"，正好对应情绪最燃的高光点。

把握深浅切换的节奏：大部分内容留在浅档让读者舒服地读，把小概率的深档留给"最强/必看/结尾"这几处，深档才不会因为用多了而失效。

**选色自检，写前过一遍**：

- 一张画面里亮色（橙红/天蓝/黄相加）**别超过 3 个**，超过就往回收。
- 大面积底色保持浅/深两档之一，别在浅档里突然切出中灰过渡色，画面会"脏"。
- 正文颜色永远比背景深、够得着可读性；高亮色只用来"圈"，不用来"垫正文"。
- 每一种亮色出现前，先问一句"这里真的需要它抢眼吗"——不需要就换深紫褐或深灰。

## 三、标题与字号层级

**标题样式特征**：**分镜式/漫画贴纸标题**——大白书字 / 粗体带描边感、可斜切、可带拟声词（"轰——""叮！"），像漫画对话框或书腰标题。

**装饰语法**，每类给可参考写法：

- 对话框标题：白底/浅杏底（`#FDF0E7`）+ `border-radius:12px 12px 12px 4px`（右下角小尾巴，像对话框）+ 深紫褐字 + 顶一个小 CSS 圆点装饰。适合章节标题与引用句，一出现就有"这格在说话"的画面感。
- 斜切冲击标题：`transform:rotate(-3deg)` 倾斜 + 亮色底（橙红 `#FF6B6B`/天蓝 `#4FC3F7`）+ 白字粗体，像漫画冲击波。用在"最强/名场面/必看"这种需要瞬间爆发的标题上。
- 描边感大字：粗体白字 + 亮色底，营造"贴纸"感；需要描边时优先用"粗白字 + 亮底"的组合代替，别让细描边在手机上糊掉。
- 拟声词标题：标题旁配拟声大字（"轰 / 唰 / 咻"），用高亮黄 `#FFE200`/橙红强调。拟声词一到，标题就有了"发出声音"的画面感。
- 标签徽章：`<span>` 橙红 `#FF6B6B`/天蓝 `#4FC3F7` 底白字，圆角 4px，像"主角登场 / 最强"。适合给标题或段落打小标签，读者一眼知道这段是什么主题。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 扉页/冲击主标题 | 20–24px | 900/bold | 斜切/对话框大字，亮彩 |
| 章节标题 | 17–18px | bold | 对话框/拟声+大字 |
| 小节/副标题 | 15–16px | 600 | 深紫褐 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 分镜旁白/吐槽 | 13–14px | normal | 浅紫褐灰、可带"（）"旁白感 |

> 标题上 28px 下 12px（硬规范）；扉页大标题可上 30px 下 16px。

正文用深灰蓝 `#3D4257` 级别的配色更耐读，避免通篇纯黑压在白底上反光发硬。

**什么时候用哪种标题**：

- **章节标题**优先用**对话框标题**（浅杏底 + 小尾巴），一进章节就有"这格要说话"的过渡感。
- 内容里有**最强、必看、名场面、冲击结论**时，才上**斜切冲击标题**；全篇 ≤2 个，它是"重拳"，不能每拳都重。
- **标题旁配拟声词**适合盘点/攻略的总起句，帮读者先建立"这期很热闹"的预期。
- **标签徽章**最适合给"每段讲什么"打小标（如"主角登场 / 本集看点 / 入坑提醒"），不是标题必需，但用了能显著提高分段可读性。

## 四、模块表现

每个模块单独成段，给具体数值与可参考写法：

- **重点气泡**：**漫画对话框气泡**——浅杏底（`#FDF0E7`）或白底 + `border:2px solid #FF6B6B`（或亮蓝）描边 + **圆角 12px 12px 12px 4px**（对话框尾巴）+ 深字 + `padding:14px 16px`（硬规范）。气泡只在真正的"重点台词/名场面台词"处用，尾巴朝下像在说话；可在尾巴旁放一个 CSS 圆点或逗号增加对话感。
  气泡是全篇最"二次元"的元素，**一段里放 1 个**，别让全篇到处都是；宁少勿多，气泡一出就是"这句话请记住"。
- **卡片**：白/浅灰蓝底（`#F7F8FA`）+ `border:2px solid` 亮彩粗边（橙红/天蓝/黄择一）+ **圆角 12px** + `padding:14px 16px 12px`；顶部可放 4px 亮色横条（`border-top:4px solid #FF6B6B`）。卡片之间用 16px 的块间距（硬规范）隔开，适合放"本集看点/速览/清单"这类成块信息。
  卡片是用来**聚拢一组相关要点**的容器，别拿它包一整段长文；一张卡讲一件成块的事，读者更好扫。
- **分镜卡**：二次元专属——**分格卡**：2–3 格并排（`display:flex`），每格一张图/一段话 + 圆角 8px + 细描边，像漫画分镜。适合盘点、攻略、剧情回顾，把"先后动作/几个选项/几幕画面"拆成格子，比列表更有"演出来"的效果。
  分格时**格数控制在 2–4**，格多了单格字就小、就难读；每格只放一条信息，别把格子当小块文章塞。
- **分割线**：**粗虚线冲击线**——`border-top:3px dashed #FFD93D`（黄）或 `#FF6B6B`（橙红），配居中拟声/图标；上下各 24px。分镜切换处可用一小段斜切色带（`transform:rotate`）做"场景跳转"的感觉。
  分割线本身也是画面的一部分，别只当普通分隔；在它上面放一个 CSS 圆点/方块（`span` 拼）或拟声大字，切换感会立刻出来。
- **花纹**：可选**波点/斜纹/星星**（亮一点无妨，漫画本身活泼），全篇 ≤2 种。用于区块底、标题背景或区分"栏目区"，但因为亮度偏高，密度要低，浅铺就好。
  花纹只做**背景气氛**，不放文字下面当主底，否则字会被花纹干扰；±≤2 种花纹足够，多了就花。
- **列表**：用 CSS 几何形状（`span` 拼的圆点/方块/菱形，亮彩轮换）当项目符，行距 1.75（硬规范）；二次元可以用亮色几何项目符拼出"游戏/番剧"的活泼氛围，一上来就有代入感。
  列表项之间保持呼吸，别堆成一堵墙；每项一句话说清一件事，比长句好扫。
- **步骤**：**分镜式步骤/升级**——「LV.1 → LV.2 → LV.3」等级感，或用"第 1 集/第 2 集"追番式编号 + 对话框短句；圆形编号用亮彩轮换（黄/橙/红轮流填）。步骤之间 16px（硬规范）。
  适合"新手怎么入门/三集决定要不要追"这类递进式内容，等级感让进度变得有成就感；每步一句，别把解释全堆在一步里。

## 五、图片与装饰

- **图片处理**：圆角 **8–12px**、可加细白/亮色边（`border:3px solid #fff`），配**高饱和、明亮、漫画感处理**；图像优先用插画/动漫风格。圆角偏大才贴合漫画贴纸的手感，直角会显得生硬。
- **比例**：多取 **1:1**（角色/谷子）或 **16:9**（画面/场景）。角色立绘用 1:1 好切割、方便做成卡片；场景/名场面大图用 16:9 更像"一帧画面"。
- **分镜排布**：多用"多格图拼贴"（`display:flex` 分格）做分镜感。把 2–4 张图并排，中间空出小 gap，立即像漫画的一页分格，比竖排大图更有动漫叙事感。
- **装饰克制**：图案/几何点缀每屏 ≤1 处，宁可留白。拟声大字、CSS 圆点/方块（`span` 拼，亮彩轮换）做列表/标题/旁白点缀；但**一段 ≤2 个**避免乱。多点会带来"热闹"的漫画感，但挤在同一句里就会变成噪音，控制好密度比数量更重要。需要图案时用 `![说明](art://sprig-grass)` 一类简洁草木角饰，绝不用图标贴纸。

**配图自检，进正文前过一遍**：

- 每张图都问"它是不是在讲这一话/这一段的事"，无关的配图宁可省。
- 图与图之间的分镜关系要能一眼看懂（先后/并列/对比），别让读者猜；并排的格子图文要对应得上。
- 图上的字或装饰别压住主角，主角永远是内容焦点，装饰只是背景。
- 1:1 用于单张角色/产品特写，16:9 用于场景/名场面大图；混用时保持统一，别一张方一张宽跳来跳去。

## 六、文案调性

**语气关键词**（独立成段）：热血、萌、吐槽、中二、梗、二次元浓度高；像解说番、像主角的旁白。这份语气要"像一个人在看番时忍不住跟你念叨"，既有兴奋也有会心一笑，而不是端着的正经说教。

**句式倾向**（独立成段）：

- 多用拟声词（轰/唰/咻/叮）与"！?"夸张语气，让画面"发出声音"。
- 可中二但**有分寸**——热血可以夸张，但不靠自我感动硬撑，别过度中二到让人尴尬。
- 有梗、有吐槽、有"本集看点"式追番叙事，读起来像在看一条番剧解说。
- 适度玩二次元黑话（"补番""cp""二刷"），每次出现配一句解释，让非资深读者也能接住。

**可直接套用的示例句**（4–6 句）：

- "本周新番炸场！这三点，追就完事了。"
- "第一次玩，直接上头，我连肝三晚。"
- "别问，问就是 '主角光环' 启动！"
- "这一幕，我愿称之为二刷必哭名场面。"
- "S 级卡池本期轮换，抽到的都给我'欧'字按满！"
- "本集爆点预警：主角终于……算了，我不剧透，你自己看。"
- "为什么我舍友都说要等完结才看？因为看完就想立刻二刷，根本停不下来。"

**一句话记住语气**：像追番时的自己，又燃、又萌、又来一两句挖苦；燃要燃得够劲，萌要萌而不腻，吐槽要稳准狠，别让三样打架。

## 七、禁忌与陷阱

每个坑给出"反例 + 正解"两段：

1. **二次元浓度过载、新人劝退**：通篇黑话缩写、圈外看不懂 → 非核心读者流失。
   反例：满篇 "yyds 爆 c 破防 磕到了" 堆在一起、一个都不解释，路人读者一头雾水直接划走。
   正解：黑话/梗**带一句解释**，如写"这波 '欧'（运气爆棚）拉满"；核心爽感放在画面与叙事里，而不是靠堆术语证明"我很懂"。让资深读者会心、让圈外读者也能跟上，才留得住人。
2. **拟声词/感叹号刷屏**：全篇"轰！唰！咻！上啊！" → 吵、累、像噪音。
   反例：正文每一句都外加"轰！！唰！！"和感叹号，读起来像被机关枪扫射。
   正解：拟声只在**分镜/标题/高光处**用（每大段 1-2 处），正文保持克制；越是反复出现的拟声越容易失效，稀有才值钱。
3. **颜色太杂、亮色失控**：橙红 `#FF6B6B`+天蓝 `#4FC3F7`+黄 `#FFD93D`+紫 `#7C3AED`+正红 `#FF3B5C` 全上 → 刺眼看花。
   反例：一张卡里五种亮色同时出现，格子互相打架，读者看两眼就累。
   正解：**锁 1 主亮色（橙红或天蓝）+1 辅 + 黄高亮**，全篇主色 ≤3；点缀色点到即止，别让每个格子都在抢话。
4. **忽略可读性**：浅底浅字、亮底亮字同色系 → 看不清。
   反例：把黄字 `#FFE200` 直接压在白底上、或把白字 `#fff` 放在明黄 `#FFD93D` 底上，亮度太近、辨识度差。
   正解：按亮度定字色——亮彩底配白字/深字（橙红/天蓝这种深底用白字 `#fff`，明黄/浅杏这种亮底用深字 `#352B3D`）；决定底与字的明暗差，别让它们"撞色融合"。
5. **中二过度自我感动**：一句话强行升华"这就是我们的羁绊啊"反复出现 → 尴尬隔阂。
   反例：通篇高浓度抒情、每一段都要"这就是青春啊"，读起来又油又假。
   正解：热血/中二**点到即止 + 搭配梗与幽默**；燃完之后立刻用一句吐槽把气氛拉回来，既够爽又不腻。

## 八、混搭方向

- **二次元 × 插画（主 7 : 辅 3）**：游戏/娱乐促销，二次元分镜 + 插画的大圆角 banner 贴纸，热闹加倍（见「插画风」）。
- **二次元 × 校园（主 7 : 辅 3）**：学生向/学习向二次元，加校园的清新蓝粉与贴纸（见「校园风」），更亲切年轻。
- **二次元 × 赛博朋克（主 7 : 辅 3）**：游戏/电竞内容，二次元分镜 + 赛博霓虹暗底，未来感更强。
- **二次元 × 杂志编辑风（主 8 : 辅 2）**：二次元深度/文化评论，重大字图画 + 对话框，偶尔"特稿化"。
- **二次元 × 复古报纸（主 8 : 辅 2）**：二次元"编年史/入坑时间线"企划，用报纸的日期与分栏把"这部番历年怎么走"排成编年表，理性+热血的混叠感很新（见「复古报纸风」）。

参照「风格混搭与主辅法则」；二次元做主风格时守死"分镜 + 萌系贴图"这套骨架，配的风格只负责托底，别把主骨架挤掉。

**混搭时先保骨架再看配色**：二次元的分镜格与贴图一定保留，配的风格只允许在"底纹、边框做法、个别强调色"上起作用；一旦把主骨都换了，二次元就会"变味"成别家风格。

## 九、封面建议

- **构图**：**动漫主视觉**——一个大幅二次元角色/场景 + 上方对话框式或斜切大字标题；或"分镜拼贴"封面。主角要够大、够醒目，标题像动画海报压在最显眼处。
- **配色呼应**：白底/浅杏 + 橙红 `#FF6B6B` 或天蓝 `#4FC3F7` 大字 + 黄 `#FFD93D` 高亮；保持漫画感配色，封面色与正文色一致，读者点进来不会"跳戏"。
- **字**：粗体大字，标题 ≤6 字 + 拟声词点缀，像动画海报/书腰；副标放一句，比干放一个标题更有追番感。
- **气质**：热血、萌、想追下去——封面要让人看一眼就有"这局我想看"的冲动。

## 十、深色模式表现

- 深色模式下，二次元的**亮色大字在暗底上更跳**：深墨底 `#1A1A1A` + 橙红 `#FF6B6B`/天蓝 `#4FC3F7` 大字 + 白字 `#fff`，扉页高光感反而更强。
- 原浅白纸底改 `#1F1F26` 深纸 + 白字 `#E6ECF2`；浅紫褐灰 `#6A5A6E` 提亮为 `#CFC0D8`。
- 深紫褐正文 `#352B3D` 在深底上提亮为 `#E2CFE0`，否则会被墨底吞掉看不清。
- 亮彩块在暗底上保持饱和、可略提亮，但注意别让太多亮色同时闪；拟声高亮黄 `#FFE200` 在暗底上别刺眼，可降一点亮度让眼睛舒服。

## 十一、个性化空间

明确哪些参数可按账号/读者自定，每项给判断依据：

- **主亮色**：热血少年向可选橙红 `#FF6B6B`，爽快竞技向可选天蓝 `#4FC3F7`，软萌向可选粉/樱（可把橙红换樱粉 `#FF9EB5`）。判断依据：内容的热血度与受众的年龄/性别画像——越燃越偏橙红，越软萌越偏粉樱。
- **中二浓度**：纯娱乐/梗号可拉高中二与梗，深度二次元评论降一点保客观。判断依据：内容定位是"娱乐爽文"还是"文化解读"——定位越娱乐越高、越严肃越低。
- **分镜格数**：盘点/攻略可多分格图，纯情感内容少分格多对话框。判断依据：内容的信息密度与叙事方式——信息密集适合分格拆解，情绪渲染适合对话框逐帧铺。
- **装饰密度**：年轻娱乐向可高（CSS 几何亮色点缀多一点），泛二次元向适度。判断依据：读者年龄与内容松紧——读者越年轻、内容越放松，几何/拟声点缀可以越多。但每屏 ≤1 处，宁可留白。
- **深浅档**：游戏/电竞向可偏深档暗底，日常萌系向偏浅档。判断依据：内容的氛围基调——偏燃、偏夜场感用深档，日常、软萌用浅档。自由判断，不做死模板。

以上留白点为可调参数，调用方应结合账号与读者落地。
