# 风格选择（内容、视觉偏好与呈现强度）

> 用途：用户只给一句需求时，由模型选择适合本篇的视觉表达。风格名称、配色、版式和图片数量都不是用户必须填写的条件；具体语法以 engine-write-protocol 为准。

## 选择依据

先看已给的偏好，再看内容目的与读者。用户明确要极简，就采用极简；明确要花哨、明丽、热闹，就让这些特点在成品里看得出来。未指定时自行决定，不发风格问卷，不把选风格变成动笔前的审批。

校园活动、社团招新、音乐节、校园市集可以有鲜亮撞色、醒目大字、几何线饰和主题插画。大学生也会写安静的书评、正式通知、研究解读；受众年轻不意味着每篇都要热闹。“克制”是一个可选方向，不能作为所有风格的终点，也不把装饰最少的方案永远评为最好。

**共同边界**：正文容器按 `fill` 选择无底或浅底，横幅与小标题在 `frame=plane` 且显式选择浅底时可使用浅底，默认保留线条结构；零 emoji、零图标字符、零渐变、零阴影。允许协议支持的小记号与插画内部填色。不要把可编辑正文移入插画文字卡，不手写 HTML/CSS 或引擎未支持的任意爆炸框、几何裁切。照片沿用实际 `local-image://` 引用，生成插画按协议复用素材或写 `[[img]]` / `[[deco]]`。

| 本篇想呈现的感觉 | 可选方向 | 看得见的特征 |
|---|---|---|
| 青春、明快、圆润 | 校园 | 蓝粉或暖色点缀、圆润记号、清楚的标题节奏 |
| 玩味、设计感、明丽几何 | 孟菲斯 | 撞色点线、错落几何、标题与正文尺度对比 |
| 响亮、戏剧感、艺术活动 | 波普 | 网点、角括号或较重框线、醒目的字形 |
| 热血、速度、竞技 | 运动活力 | 蓝橙对比、同向速度线、序号与跑道节奏 |
| 素净、安静、集中阅读 | 极简 | 少装饰、细线或无框、清楚的文字层级 |
| 专业、清晰、数据感 | 科技 / 商务 | 稳定色系、线性结构、内容本身的对照 |
| 温柔、日常、手作 | 日系 / 手账 / 森系 | 柔和配色、纸面留白、适合主题的图像 |
| 文化、仪式、书卷气 | 国潮 / 敦煌 / 杂志 / 画廊 | 衬线气质、对称或编辑式标题、图文疏密 |
| 怀旧、音乐、街头 | 港风 / 报纸 / 美式复古 | 复古色系、标题字重、印刷式线条 |
| 动漫、游戏、未来感 | 二次元 / 赛博 | 分镜思路、几何线条、贴合内容的插画 |

这些是候选，不是“活动必须孟菲斯”“观点必须极简”的类型路由。账号已有基线时考虑连续性；本次明确偏好优先。表中的温柔、热血等词只描述视觉感受，不要求正文转为聊天、安慰或口号。

常规标题沿用上述 frame 条件；花笺、票笺、缎带题头使用当前引擎的主题轮廓，可铺底部分遵循 `fill`，`fill=none` 仍关闭内容底色。

## 配色与版式分别决定

`[[theme:名称]]` 决定色板与图案词汇，`[[boxes:…]]` 决定版式轴。两者正交，不依赖同名绑定：孟菲斯配色可以排得素净，极简配色也可以配醒目的大字标题。只有换了色板、仍用默认骨架，不能算已经实现用户要求的版式变化。

先确定本篇的主视觉关系，再选轴，不要求按固定顺序作答：

- 标题与正文要多大反差：`scale=standard` 常规，`scale=display` 更醒目。
- 标题怎么对齐：`align=left` 有编辑感，`center` 有仪式感，`auto` 沿用引擎默认。
- 结构节点用什么主题：`ornament=botanical|ticket|ribbon` 为花枝、票孔、缎带，`none|confetti|dots|speed` 为无、几何点线、网点、速度线。它们作用于题头、章标与分隔；`shape` 单独决定气泡轮廓。
- 容器怎么组织重点：`frame` 决定线条，`shape` 决定气泡结构，`radius`、`label`、`mark`、`deco` 控制细节。

以下只示范声明，不是文章提纲，也不是必用组件组合：

| 方向 | 配色声明 | 一组可调整的版式轴 |
|---|---|---|
| 花笺舞台 | `[[theme:校园]]` | `[[boxes:花笺]]` |
| 校园票笺 | `[[theme:校园]]` | `[[boxes:票笺]]` |
| 报道缎带 | `[[theme:校园]]` | `[[boxes:缎带]]` |
| 明丽几何 | `[[theme:孟菲斯]]` | `[[boxes:scale=display;align=left;ornament=confetti;shape=medal;frame=none]]` |
| 响亮网点 | `[[theme:波普]]` | `[[boxes:scale=display;align=left;ornament=dots;shape=bracket;frame=edge;bar=5]]` |
| 运动速度 | `[[theme:运动]]` | `[[boxes:scale=display;align=left;ornament=speed;shape=index;frame=line;title=mono]]` |
| 素净阅读 | `[[theme:极简]]` | `[[boxes:scale=standard;align=left;ornament=none;frame=none;label=none;mark=none;deco=none]]` |

这些轴可跨色板组合；同一篇保留主视觉的连续性，内容确有转折时才局部调整。用户只要求换视觉时，不为配合风格重写事实、删改正文结构或替换原图。

## 让主题贯穿整篇

用户要求更花、更精致时，先确定一个可辨认的主题母题，再把它落实到题头、章标、框体、分隔。花枝可以在题头展开、在框边收束；票孔沿票边组织、在章间呼应；缎带连接标题和框体。它们应共享线宽、色温和对齐关系，不能只是同一通用提示卡换色，或在大空白里零散放小图标。

`花笺/botanical`、`票笺/ticket`、`缎带/ribbon` 三个预置同时选择同名 `shape` 与 `ornament`，并关闭机械的语义标签和额外角标。内置主题装饰可复用，无需额外素材接口或生成调用。`deco=none` 只关闭额外饰件，主题花饰由 `ornament` 和 `shape` 保留。若局部需要减轻框体，可用 `[[boxes:缎带;shape=rail;frame=line]]` 保留全文主题。

造型应有角色分工：题头建立主题，章标引导，框体承载，分隔连接。不要把每层都做成同样的大圆角卡、双框和悬置题签；“提示／注意／重点”小标签没有独立用途时用 `label=none`，原稿标题与风险正文保留。长正文仍按自然段排入，框体适应内容，原图保持原有身份与叙事位置。

## 明丽怎么落到纸面

标题、线饰、小记号、插画可以形成鲜明的色彩关系，正文持续保持可读深色。通常选择一个主色和一到两个辅助色，让最有力的位置先吸引视线，再让读者顺着层级读下去；亮色不能同时争抢每个段落。

装饰可以比极简丰富，不设“每屏至多一处”的通用上限。密度按本篇决定：信息密集处给文字空间，开篇和内容转折处可以更有表现力。每处图像或组件要有用途，不因“花哨”就生成固定数量的插画、气泡或章节，也不强制“横幅—引言—三个理由—行动卡”的提纲。

## 定稿前看什么

确认用户要的视觉强度已出现：花哨稿的题头、章标、框体和分隔确有持续的主题呼应，不能仅凭局部一张提示卡或换色就判定完成；极简稿没有自动冒出的花饰、网点和彩纸。再看主次与可读性、图片和正文的关系、颜色与版式是否各自选定。文案仍需兑现标题、有具体信息并保留材料依据；视觉改善不能替代文章质量。
