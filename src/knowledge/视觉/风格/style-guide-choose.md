# 风格选择决策流（读者 / 情绪 / 克制 + 完整矩阵）

> 定位：跨风格通用方法论。**一篇文章拿不准用什么风格的「第一站」**。给出三原则、全风格矩阵、4 步决策流程、逐步判断提问，和一个完整的走查示例。
> 适用对象：每次不确定用哪个风格、或主观想用某风格但说不清为什么时，先读本条目。
> 调用方：从「三原则」读起，再按「4 步决策流程」一步步走，矩阵只当对照锚点。

## 一、风格选择三原则（先建立直觉）

一切风格选择都围绕三件事，缺一不可，顺序别乱。

### 原则 1 · 匹配读者（第一优先，先想这个）
一篇文章的读者是谁，决定风格的上限。同一种内容，读者变了，风格就该换。

**判断提问（对着答，答不出就停下补）**：
- 这篇的读者是「学生 / 职场人 / 家庭用户 / 决策者 / 极客 / 中老年」中哪一类？
- ta 的年龄大致区间？有没有明显的生活角色（宝妈、打工人、长辈）？
- ta 是在什么场景刷到这：通勤、睡前、还是搜索找答案？

**示例（同一内容给不同读者）**：一篇「怎么睡得更好」。
- 城市上班族号 → 日系 / 森系（慢生活的治愈感）。
- 户外 / 徒步号 → 清水森系（山的呼吸感）。
- 中老年健康号 → 稳定克制的日系或商务，不整活儿。
一句话：**先定读者，再谈风格**。读者画像对不上，再好看的风格也是自嗨。

### 原则 2 · 匹配情绪（第二优先，想内容要给读者什么感觉）
内容想带给读者的情绪，必须与风格气质一致。热闹内容配极简、安静内容配赛博朋克，都会拧巴。

**情绪 → 风格速查**：
| 想给读者的情绪 | 风格 |
|---|---|
| 热闹、冲动、想立刻行动 | 插画、孟菲斯、波普、运动活力 |
| 冷静、专业、想被说服 | 科技、商务、极简 |
| 温情、陪伴、被治愈 | 日系、手账、治愈手绘、清水森系 |
| 庄重、仪式、被尊重 | 国潮、敦煌青绿 |
| 青春、元气、被点燃 | 校园、运动活力、二次元 |
| 怀旧、市井、会心一笑 | 复古港风、报纸、美式复古 |
| 高级、克制、有品味 | 极简、艺术画廊、杂志编辑 |

**示例**：一篇「焦虑自救指南」→ 情绪要「被安抚」，选日系/手账/森系这类温度型，别用高饱和撞色插画，那会越看越躁。

### 原则 3 · 克制执行（落地阶段，贯穿始终）
选对风格还不够，风格是「主色 + 2-3 个特征元素」的组合，不是把该风格的东西全堆上。

**硬约束（照抄执行）**：
- 全篇 ≤3 主色；
- 花纹 ≤2 种；
- 装饰标题 ≤2 处；
- 重点气泡 ≤2 个；
- 正文 15px、行距 1.75、块距 16px（照间距硬规范）。

**一句话**：活泼 ≠ 杂乱，专业 ≠ 冰冷。风格定了方向后，靠「少而准」落地，不是靠堆料。

**克制执行的「改三处分寸」示例（同一段插画风标题）**：
- 堆料版（错误）：标题给大红底 + 三色描边 + 两排几何圆点 + 跑马灯感，一屏全要素——这是「个人审美」在堆素材。
- 克制版（正确）：橙红 `#FF5A55` 圆角 banner 底 + 白字 + 右下角一个波点三角，其余留白——一屏即可识别「插画风」，且不生厌。
- 口诀：**一个主色块 + 一个特征元素，就够点出一个风格**。

**风格是「主色 + 特征元素」的组合自查**：
| 风格 | 主色（举例） | 特征元素（挑 1-2 个就够） |
|---|---|---|
| 校园 | 天蓝 `#4A90E2` | 贴纸胶囊标题、圆点花纹 |
| 科技 | 深蓝紫 `#2F6FED` | 左竖条标题、数据表格 |
| 国潮 | 红金墨 `#C8102E` | 低饱和金边、对称标题 |
| 日系 | 米纸 `#FBF7F0` + 暖棕 | 居中符号标题、细分割 |
| 手账 | 粉紫奶油 | 虚线圆角框、贴纸点 |
| 极简 | 黑白灰 + 单强调 | 大留白、左竖条 |
| 插画 | 橙红 `#FF5A55` | 圆角 banner、粗边 |
| 森系/清水森系 | 草绿 `#5B8C5A` | 叶形图案（botanical 植物类）、低饱和留白 |
| 港风 | 哑光暖调 | 霓虹招牌字、胶片感 |
| 杂志 | 大字图形 | 超大号字、网格 |
| 赛博朋克 | 深底霓虹 | 荧光描边、HUD |
| 银盘/报纸 | 纸张米灰 | 分栏、报刊徽章 |
| 运动活力 | 能量蓝 `#2F7CF6` | 斜切块、号服数字 |
| 孟菲斯 | 橙红青柠宝蓝 | 几何图形、波浪线 |

| 美式复古 | 奶油棕橙 | 复古广告、拼色 |

> 每个变体条目里的「完整色板」是它的真值来源，上表只是速记，细节以对应条目为准。

## 三、从任务到风格的 4 步决策流程

拿到一篇新文章，按下面 4 步走。每一步都配「判断提问」，卡住时对着问自己。

### 第 1 步 · 定内容类型（锁矩阵横轴）
**判断提问**：这篇本质上叫「干货 / 资讯 / 软文 / 活动 / 故事 / 情感 / 观点」哪一种？一句话能说清吗？

**作用**：内容类型决定风格大方向（矩阵横轴），也决定模块与文案，先别跳进配色。这道题不准，后面全歪。

### 第 2 步 · 套三原则筛候选（收窄到 2-3 个）
**判断提问1（读者）**：谁会点开？年龄、生活角色、阅读场景分别是什么？
**判断提问2（情绪）**：我想让 ta 读完「拿到干货 / 放松 / 冲动 / 有敬意 / 会心一笑」哪种？
**判断提问3（克制）**：这篇长还是短？信息很密还是很空？装饰多会不会影响读下去？

**作用**：从矩阵首选出发，按三原则加减，得出 1-3 个候选风格。举例：一篇「职场新人生存指南」，矩阵首选中没有直接命中，可以收窄到「商务（可信）／极简（克制）」，若读者偏年轻再加「校园（亲和）」。

### 第 3 步 · 对齐账号基线（查长期锁定）
**判断提问**：这个号是不是长期某风格在跑（一直极简、一直国潮）？这篇要不要破线？

**作用**：
- 有基线 → 同基线的直接沿用；破线只在节日、品牌大事件等明确理由下做，且按「风格混搭」与「时令节日」条目执行。
- 无基线 → 自由从候选风格里选。

### 第 4 步 · 做「克制一测」终选（定 1 个，落特征）
**判断提问**：假若稿中标，它的「主色 + 特征元素」各是哪几样？浏览一遍能不能在一屏内认出这个风格？

**作用**：对每个候选问「主色、标题样式、花纹各是什么」，选那个**特征元素最少但最像它**的。定稿后把「主色 + 2-3 个特征元素」落到四个点：**
- 开头首屏（大标题 + 一句话引言）；
- 一处章节标题（用该风格标题样式）；
- 一处重点气泡；
- 一处分割线或花纹带。
风格就从「概念」变成了「看得见的成品」。

> 四步速记：**定类型 → 三原则筛 → 对基线 → 克制终选**。第 2、3 步可并行，不用死板排先后。

**「克制终选」的 3 个落位动作（每个都要做）**：
1. 选一个「主色位 + 至多 2 个特征元素」并写成一句话（如「科技风＝深蓝紫 + 左竖条 + 数据表格」）。
2. 把这幅「一句话画像」落到开头首屏：大标题 + 一句话引言，让首印象即是风格。
3. 在正文选 2 处「风格浓度最高的点」：一处章节标题、一处重点气泡，余下段保持素净留白。这样全篇风格统一又不腻。

## 四、一个完整的走查示例（照着练一遍）

**任务**：给一家主打「测评 + 购买指南」的数码公众号写一篇「新款降噪耳机横评」。

- **第 1 步**：内容类型＝干货/测评 → 横轴落在「科技新品 / 数码测评」。
- **第 2 步**：读者是数码爱好者、理性参数党 → 情绪要「可信、有用」→ 候选「科技、商务、极简」。
- **第 3 步**：账号基线就是科技风（这个号一直走科技）→ 不破线，锁定「科技」。
- **第 4 步**：科技风特征＝深蓝紫主色 + 左竖条标题 + 数据表格（对比模块）＋朴素无花纹。落到开头大标题、章节标题、一张「竞品对比数据表」、一条评分分割线。

**产物**：蓝色调深底、三个候选耳机参数对比、专业冷静语调。风格一看就是「科技测评」。

## 五、决策中常犯的 4 个错

1. **只看「我喜欢」**：主编喜欢极简不代表读者受用。先想读者与情绪，再把个人审美放第二。
2. **矩阵当死规则**：矩阵是起点不是终点。读者画像/账号基线明显偏离时，果断跳矩阵。
3. **风格越界混搭**：一时国潮红金一时插画撞色，风格撕裂。要混就走「风格混搭」主辅法则。
4. **忘了克制**：选对风格却把特征元素堆满，等于没选。克制执行力决定风格成败。

## 六、一个对比示例（同一主题、两种读者 → 两种风格）

**任务**：一篇「如何布置一个舒服的小角落」，内容相近，但两个号读者完全不同。

**A 号（城市独居青年）**：
- 读者：20-30 岁、都市租房、爱生活美学。
- 情绪：要放松、被治愈。
- 候选 → 日系（暖米的都市慢生活）或森系。
- 锁定日系：米纸底 `#FBF7F0` + 暖棕主色 + 居中符号标题 + 大量留白。

**B 号（亲子 / 家长群）**：
- 读者：带娃家庭。
- 情绪：要实用、被理解。
- 候选 → 手账 / 治愈手绘（更有温度、接地气）。
- 锁定治愈手绘：奶油白底 + 樱粉 `#E8A0B2` + 虚线圆角框 + 小插图。

**结论**：同一份素材,因为读者不同,走了两种完全不同的风格。这就是「第一原则匹配读者」的在实操里的样子。

## 九、FAQ（常见疑问）

**Q：矩阵里「森林」和「清水森系」分不清，怎么选？**
A：两者都偏绿，但森林更「低饱和自然、沉静」，清水森系更「清爽鲜绿、山的呼吸感」。读者要「柔」选森林，要「清」选清水森系。拿不准就看内容更偏「花园治愈」还是「户外徒步」。

**Q：内容同时像两种类型（如「科技 + 美食」），怎么办？**
A：选占主导的那个类型做风格，另一个靠「风格混搭」引一个辅风格元素点缀即止。

**Q：我就是喜欢某风格，但读者不对口，能用吗？**
A：能，用它只会吸引对口读者重新聚拢，代价是现有读者可能流逝。运营者自行权衡（本条目只给判断依据，不给死规则）。

**Q：三个备选风格都拿不准，怎么破？**
A：两两「克制一测」——问它俩各自的「主色 + 特征元素」哪个更少、更像本篇。选那个「删掉一件装饰也不垮」的。

**Q：矩阵列表里没有我要的类型怎么办？**
A：按最近的类型选，再按三原则微调；或把它归为一与两种主流类型之一（多数内容都能归入表格里的若干类）。

**Q：这篇既要做周年庆又要严肃品牌，能用两种庄重风格吗？**
A：能，主国潮 + 辅敦煌青绿（两者是母系 / 子系，天然可混），但辅只做一处（如标题描金），其余收敛回国潮。
