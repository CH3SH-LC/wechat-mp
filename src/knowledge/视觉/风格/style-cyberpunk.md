# 赛博朋克风（style-cyberpunk）

> 定位：未来感、霓虹、暗黑科技、迷幻张力，像一座雨夜里霓虹翻涌的未来之城，深底 + 荧光描边是它的代码。
> 调用时机：游戏电竞、极客数码、潮流科技、未来概念、暗黑向内容，以及一切想要"年轻人、夜向、带点赛博浪漫"的硬核内容。

## 一、气质与适用内容

**气质关键词**：未来感、霓虹、暗黑、迷幻、锐利、赛博浪漫；深底是本能，荧光粉/青/蓝描边是签名。

**适合的内容类型与行业**：

- **游戏电竞**：新游上线、赛事、电竞选手、电竞外设。
  为什么合适：这些内容天生自带"对局、升级、燃"的紧张感。暗底加上荧光，恰好把"开打前的氛围"和"数值战力"做成视觉冲击，读者一眼就感到爽与竞争力，和游戏的节奏是同一拍。

- **极客数码**：硬件、AI、黑科技、未来概念、开发者向。
  为什么合适：数码圈读者亲近"屏幕光、指示灯、数据流"的美学。荧光描边能摆出"这台机器很厉害"的身位，和硬核围观的心态契合，讲新品也更容易讲出"下一代"的感觉。

- **潮流科技**：夜跑装备、潮流数码、机械键盘、改装文化。
  为什么合适：这类内容按"酷不酷"来买账，霓虹本身就是潮流语言。把产品包装成"夜行动物要用的装备"，正好对上追求个性的购买冲动。

- **亚文化/年轻向**：动漫赛博、末日废土、未来主义、摇滚/电子乐。
  为什么合适：这些题材本来就在讲"赛博世界"的故事。用同一套美学去讲它们不会违和，反而互相强化代入感，让读者觉得"这篇懂我"。

- **品牌黑科技发布（年轻向）**：发布会、新品类首发。
  为什么合适：新产品感配"未来之城"的仪式感，能把"首发"做足"敲响新时代"的分量，让开箱和预告都更有记忆点。

**不适合的场合**：

- **温暖治愈、亲子陪伴、美食生活**：为什么是雷区：暗底霓虹与暖柔、家常的意象直接冲撞。读者要的是"安心"而不是"上头"，用赛博反而会让本应温馨的内容显得冷硬疏离。
- **商务/金融/严肃政策**：为什么是雷区：这些场合要沉稳与权威。赛博太花、太夜，反而显得不专业、轻佻，读者很难把你当正经信息来源。
- **母婴、老年消费群体、需极度亲和的内容**：为什么是雷区：强对比、强霓虹对这部分读者的视觉与情绪都不友好，容易让他们感到刺眼、疏离，把信任感吓跑。
- **白天常态内容、需要"阳光晴朗"感的内容**：为什么是雷区：赛博的画风注定是夜向。白天主题硬套暗底会自相矛盾，气氛怎么撑都是别扭，不如换清新一点的方向。

**判断一句**：读者是年轻人/极客/玩家，内容要"潮、夜、未来、带点酷"，赛博朋克正中；要"温和可信、阳光正能量"，就别用。一句话记住：赛博卖给"想先酷起来"的那批人，不是"想先安心下来"的那批人。

## 二、完整色板表

```text
背景类（深底是主线）
  #0A0B12        极夜幕黑：正文底色，赛博的底宇宙
  #14161F        深蓝黑卡：卡片/分区，稍亮的层级
  #1B1E2E        深紫蓝卡：次级分区
  #0D0F1A        更深的削弱区

主霓虹色类（招牌荧光，挑 1-2 做主线）
  #FF2E97        霓虹粉：主标题/荧光描边，赛博代表色
  #00E0FF        霓虹青：另一主线，冷光未来
  #7C3AED        电紫：第三可能主色，迷幻

辅助色类（结构 & 支持光）
  #3A3F52        深钢灰：辅助文本/边框
  #5A6072        中钢灰：次级文字
  #8A93A8        浅钢灰：注释（在深底上的"灰"）

强调色类（点睛，全篇克制）
  #FF2E97        霓虹粉：重点荧光
  #00E0FF        霓虹青：高亮数据/链接感
  #00FFA3        荧光绿：二极光色/成功态（可选）

文字色类
  #EAF0FF        冰蓝白：正文主色（近白偏冷，发光感）
  #B9C2D9        浅蓝灰：次级正文
  #8A93A8        钢灰：注释/弱化
```

**每个色号怎么用**：

- `#0A0B12` 极夜幕黑：全篇正文的底色，是"夜城"的宇宙。不要在这上面直接放深色文字，它会吞字。
- `#14161F` 深蓝黑卡：卡片、分区块的地面，比底略亮一档，让"块"和"底"分得开。
- `#1B1E2E` 深紫蓝卡：次级分区或强调块，带一点紫，压在深蓝黑卡之上做更内层的层级。
- `#0D0F1A` 更深的削弱区：放弱化内容、脚注区，让它们"退到后排"。
- `#FF2E97` 霓虹粉：主标题与关键荧光描边的招牌色，潮、女性向/时尚赛博感。只做字/线，不做大面积底。
- `#00E0FF` 霓虹青：另一条主线的冷光，科技、玩家向，可做数据高亮、链接感与荧光边。
- `#7C3AED` 电紫：第三主色选择，迷幻/音乐向，比粉青更飘、更电子。
- `#3A3F52` 深钢灰：辅助文本与普通边框，在深底上偏暗，只做结构不是重点。
- `#5A6072` 中钢灰：次级文字，比深钢灰亮一档，用于正文次级说明。
- `#8A93A8` 浅钢灰：注释/弱化文字，是深底上能看清的"灰"底线。
- `#00FFA3` 荧光绿：可选的二极光色，成功态、已达成清单的绿点，克制用。

**选色原则一句话**：一屏里霓虹色最多出现两个（粉 + 青，或粉 + 绿），其他的都用钢灰去撑结构；霓虹越少越金贵，越稀疏越有"霓虹感"。

**深浅两档怎么用**：

- **深档（默认）**：夜幕黑底 `#0A0B12` + 霓虹粉/青荧光 + 冰蓝白字。赛博朋克的本体，暗黑霓虹是它的灵魂。深档把"夜城"的氛围直接铺满，荧光在暗底上自己会发光。绝大多数赛博内容都走这一档，尤其游戏、夜向、潮流类。
- **浅档（变体，少）**：如果想做"白日赛博/干净版"，用白底 + 深紫蓝字 + 霓虹色描边点缀。但浅档会削弱赛博最迷人的"暗夜霓虹"感，霓虹在白底上会显得发飘、不稳。浅档只在需要强可读性优先、或面向企业/正式语境时才用，且做成"霓虹点缀式干净"，默认仍走深档。

## 三、标题与字号层级

**标题样式特征**：**荧光描边 + 未来感锐利字型**——粗体大字 + 霓虹色描边或荧光发光，像夜城里的招牌；斜切、错位、编码感装饰都是赛博签名。

**装饰语法**：

- **霓虹发光标题**：大字（近白/冰蓝白）+ 霓虹粉/青高饱和纯色 + 细边框（`border-radius:8px`），靠"荧光纯色 + 加粗字重 + 高对比"做醒目效果，不用发光晕影。
- **描边效果**：若 `-webkit-text-stroke` 渲染不可用，用粗字重 + 对比色背景替代，保证标题在暗底上立得起来。
- **切角装饰**：标题卡可 `clip-path:polygon(0 0,100% 0,96% 100%,4% 100%)` 或 `border-radius:0` 加斜切，未来机械感，像被切了一角的数据板。
- **编码小标**：标题旁配 `0x01 / 01` 或 `<CORE>` 类小符，赛博感（写作时用可读代码词如「01 / CORE」即可）。
- **序号荧光块**：`<span>` 霓虹粉底黑字或霓虹色细边序号，圆角 8px，把"第几步"做成一块利落的荧光铭牌。

**标题与正文的关系**：标题负责"够亮够重"，正文负责"够清楚够读"。标题用了荧光发光，正文就老老实实用冰蓝白 `#EAF0FF`，让标题永远是画面里最亮的那一层，别让正文跟标题抢光。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 霓虹主标题 | 20–24px | 900/bold | 荧光纯色大字，够重够亮 |
| 章节标题 | 17–18px | bold | 霓虹色 + 切角/编码小标 |
| 小节/副标题 | 15–16px | 600 | 冰蓝白 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 数据/代码感 | 13px | 600 | 荧光色高亮数据 |

> 标题上 28px 下 12px（硬规范）；霓虹主标题可上 30px 下 16px。

## 四、模块表现

- **重点气泡**：**暗底霓虹边气泡**——`background:#14161F` + `border:1px solid #00E0FF` 或 `#FF2E97` 荧光细边 + **圆角 8px**（机械感，不用大圆角）+ `padding:14px 16px`（硬规范）；标题字用霓虹纯色。这是全篇最醒目的"强调盒"，一屏最多放 1-2 个。

- **卡片**：深蓝黑卡底 `#14161F` + `1px solid #3A3F52` 钢灰描边或荧光细边 + **圆角 6px** + `padding:14px 16px 12px`；顶部可加一条 4px 霓虹纯色横条（粉或青单色）。卡片间 16px。普通内容归卡片，别和重点气泡抢辉光。

- **分割线**：**霓虹细线**——`border-top:1px solid #00E0FF`（青）或粉；或 `border-top:1px solid #3A3F52` 钢灰细线 + 居中一个 CSS 圆点/方块（`span` 拼，霓虹色，圆角 8px）。上下 24px。分割线是"呼吸口"，能省则省，别每一段都来一条。

- **花纹**：可选**极浅网格/霓虹网格氛围**（用细微纯色网格线，暗底上淡淡的），或"故障条纹"（很细的粉青交替纯色线）；≤2 种且克制，别糊眼。花纹是背景氛围，读者不该一眼注意到它的存在。图案必须是网格/线条类，绝不用图标类图案。

- **列表**：荧光色圆点/方块（CSS `span` 几何形状，霓虹粉/青）或代码感 ` >>` 前缀，行距 1.75；忌可爱图标列表。列表符号是赛博的"钩子"，一个符号带一点荧光就够，别让整列都在发亮。

- **步骤**：**赛博流程**——荧光色圆点（CSS `span`，霓虹粉/青）或斜切序号块（`clip-path`）+ 短句；用 `00 >> 01 >> 02` 的"数据流"写法，步骤间 16px。每一步一句话，读者顺着数字往下走，像在读一段升级日志。

模块整体守住"深底 + 荧光点睛"的统一语法：底永远在暗的一侧，荧光只做字、边、点，谁也别整块用荧光铺底；一屏只让一个重点发光，其余都安静下来。

## 五、图片与装饰

- **图片处理**：圆角 **4–6px**，配**未来感滤镜**（深色压暗、加霓虹/青色偏色、高对比），或褪色/霓虹色调；硬朗不柔。
- **氛围**：赛博用图——霓虹城市摄影、电路/像素、暗黑人物、未来机械。可叠荧光色文字与色块，让图本身也像夜城的一帧。
- **比例**：多为 **16:9**（场景/夜景）或 **1:1**（产品/细节）。
- **裁剪与构图**：夜景大场面可裁成横幅增强纵深感，人物/产品细节用竖幅或方形；画面里的霓虹光带、光斑都是天然的赛博装饰，保留它们能省一张素材的力气。
- **文字压图**：在图上叠荧光大字时，给文字加一层深色半透明衬底（如 `background:rgba(10,11,18,0.6)`），保证暗底上的荧光字仍能读清，别让图和字互相吞。
- **选图避雷点**：别用白天强光、柔光少女感的素材，直接和夜城氛围打架；也别用别人用滥的互联网感模板图，挑有真实夜感的照片最有说服力。
- **装饰克制**：图案/几何点缀每屏 ≤1 处，宁可留白。需要点缀用中性/未来感的 CSS 几何形状（细线、方块、菱形）或 `![说明](art://sprig-grass)` 这类简洁几何草木角饰，禁用可爱/温馨系印花在正文大量出现。图案必须是几何/植物类，绝不用图标类图案。

图片不要修得太柔：赛博要的是"冷、硬、锐"，柔光淡出会把夜城的锋芒洗掉。选图优先暗调夜景，避免白天强光素材直接混进来，宁可少图也要每张都对味。

## 六、文案调性

**语气关键词**：未来、酷、硬核、犀利、暗黑浪漫、有梗（年轻人向）。

**句式倾向**：

- 短句利落，多用"上线""解锁""进入""连接"等动作性未来词，让读者感到"行动、进入、升级"。
- 可带一点中二与时代感（"这是新的秩序"），但有分寸，点到为止，别通篇端着。
- 术语可用但要可读（对非硬核读者解释一句），别让看不懂的人被拦在门外。
- 带一点冷幽默或梗，符合年轻受众的交流方式，但梗要贴内容，不硬凑。

**示例句**：

- "新版本已上线，你的夜晚，交给这一城的霓虹。"
- "解锁你的下一台装备，性能拉满。"
- "在赛博都市的边缘，我们仍在不断前进。"
- "别眨眼，这局，才刚刚开始。"
- "数据会说话，而今晚，它选择开口。"
- "把旧世界关掉，给未来通一次电。"
- "别问它有多狠，拉起你爱的那台设备就知道。"
- "霓虹亮起来的地方，就是今晚的主场。"

这些示例句的共同点是"短、带动作、有一层夜色在里面"：不急着解释，先把画面和氛围递给读者。真正的内容信息留给正文段落去展开，示例句负责把读者"引入夜城"，而不是替他读完。

## 七、禁忌与陷阱

1. **霓虹过度、满屏都是荧光**：每个模块都荧光描边 + 发光 → 糊成一片、看不清。
   反例：所有标题都三重发光 + 全卡 `#FF2E97` / `#00E0FF` 荧光描边 + 每行 `box-shadow` 全亮 → 满屏都在闪，重点被淹没。
   正解：霓虹给**招牌标题 + 1-2 个重点**，其余用钢灰 `#3A3F52` 结构；荧光要"点睛"不是"基色"，控制密度，让眼睛知道先看哪里。
2. **深底上对比不足**：深紫蓝字贴着深底、灰色字太深 → 看不清。
   反例：`#3A3F52` 注释直接放在 `#0A0B12` 底上 → 发虚，几乎读不出。
   正解：深底上文字尽量用冰蓝白 `#EAF0FF`，次级至少 `#8A93A8` 以上，保证对比；越关键的越亮。
3. **荧光色过于饱和刺眼**：荧光大面铺底 + 最大亮度 → 伤眼。
   反例：整屏 `#FF2E97` 霓虹粉底 + 白字 + 最大发光 → 盯十秒眼睛就累。
   正解：荧光在**深底上做字/线**而不是做背景底；用高饱和纯色 + 留白 + 少量细边撑出醒目标识，别铺成一片亮色。
4. **中二过度/文案太尬**：通篇"零之记忆""暗影降临"堆砌 → 中二出戏。
   反例：每一句都塞赛博名词、"我是夜之主""风暴降临"反复叠 → 像台词本，不像正经内容。
   正解：赛博是视觉与几个关键词的氛围，主体叙事仍要清楚、可读、有好内容；酷是调味不是全部。
5. **浅档滥用**：为求"安全"整篇白底 → 失去赛博最动人的暗夜霓虹。
   反例：不想冒险就全套普通白底科技风，霓虹只在角落 → 读者看不出这是赛博。
   正解：赛博默认深档；非要用浅档也是"霓虹点缀式干净"而非普通白底科技风，保住霓虹签名。

**总原则**：每一个坑的共同根源都是"量"——霓虹、发光、中二都各给一点是调味，多了就成了灾难。遇到任何模块，先问一句"它会不会抢主标题的戏"，会就收着。

## 八、混搭方向

- **赛博 × 科技风（主 6 : 辅 4）**：数码测评/黑科技，赛博霓虹 + 科技的理性数据卡，未来感 + 可信度（科技风做数据骨架）。
- **赛博 × 二次元（主 7 : 辅 3）**：游戏动漫内容，加萌系贴图/分镜混搭（见「二次元动漫风」），赛博做整体暗底霓虹。
- **赛博 × 暗黑科技（默认同源）**：本条目天然偏暗黑，可强调"暗黑"方向做更沉重版本（更多近黑、更少霓虹）。
- **赛博 × 港风（主 7 : 辅 3）**：夜的城市记忆/街头感，港风的霓虹招牌字与赛博的暗夜霓虹相通，可互相叠出"未来的香港老街"感。

参照「风格混搭与主辅法则」；赛博做主风格守暗底霓虹骨架，混搭时霓虹永远归赛博管，别让辅风格把它冲淡。

## 九、封面建议

- **构图**：**夜景霓虹城市/高反差人像** + 荧光大字标题，可用对称仰视构图或"脸的一半在霓虹光里"的赛博经典。
- **配色呼应**：夜幕黑 `#0A0B12` 底 + 霓虹粉 `#FF2E97`/青 `#00E0FF` 大字 + 冰蓝白；荧光做标题与光带，与正文同色系才连贯。
- **字**：超大荧光字 ≤6 字，可扭曲/斜切/发光的未来感；副标一句，别挤太多元素，封面是起点的唤醒不是信息堆。
- **气质**：未来、酷、夜、微微的暗黑浪漫；封面就要让读者一眼"够夜、够未来"。

封面是内容的分身，正文若是霓虹粉做主色，封面就让它也做主；封面和正文的荧光主色要一致，读者才会认出"这是同一篇赛博"。封面元素宁可少，也不要堆满——一个主视觉 + 一句大字足够。

## 十、深色模式表现

- 赛博朋克**就是深色模式的极致使用者**：暗黑下霓虹反而更亮更美，深档本体天然适合暗黑阅读。夜间阅读是它的主场，读者在这种模式下体验最好，不必特意迁就。
- 注意避免多重荧光同时过亮（排版上让霓虹集中在一两个焦点，其余压低），否则深色下到处发光反而乱。
- 荧光纯色/细边的高亮在暗底上更明显，别让焦点太多；一屏里亮着的东西尽量让读者数得过来。
- 冰蓝白正文字在暗底上保持 `#EAF0FF`，次级不低于 `#8A93A8`；避免紫色字放紫底，尤其是电紫 `#7C3AED` 别配深紫蓝卡。
- 读者若反感太黑，可把底用 `#14161F` 稍亮，霓虹不变；底亮一点不影响赛博感，只是更温和。

深色模式下赛博基本是"本色出演"，它要做的不是改变，而是克制：越是本来就能打的环境，越要管住荧光数量，别在优势领域里自己把氛围做糊。

## 十一、个性化空间

- **主霓虹色归属**：可选霓虹粉（潮、女性向/时尚赛博）、霓虹青（冷、科技/玩家）、电紫（迷幻/音乐）。判断依据：品牌色与内容情绪——品牌偏粉就让它成为账号代表色，读者自然会记住"这家是粉霓虹"。
- **"潮夜" vs "干净科技"**：强调暗黑的年轻化多霓虹与暗底；偏产品介绍的科技版可降光、加结构与留白（混搭科技风）。判断依据：读者是纯玩潮流还是偏理性用户，两者对光的耐受力不同。
- **荧光强度**：电竞/赛事可拉满霓虹热度，日常科普向降光保可读。判断依据：内容"燃不燃"与读者用眼——越燃越敢亮，越科普越收着。
- **浅档是否使用**：面向企业/严肃向时偶尔用浅档（霓虹点缀式），纯年轻潮向就用深档。判断依据：读者群与内容语境，正式场合才交出浅档这张牌。
- **代码/感小标**：可把栏目做成 `<CORE>` 式赛博品牌小标，形成语言识别定番。自由判断，但栏目名一旦定了就统一，别每期换。

这里列的都是可依据账号与读者自定的可调参数，调用方应结合品牌色、目标读者与内容语境落地，不做死模板。
