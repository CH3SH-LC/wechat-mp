# 科技风（style-tech）

> 定位：理性、锐利、数据感，像一块发光的电子屏幕和一行精确的代码，克制而不冰冷、专业而不疏远。
> 调用时机：科技新品发布、数码测评、技术干货、数据报告、产品功能介绍，以及任何想让读者觉得"专业、前沿、可信"的深度内容。

## 一、气质与适用内容

**气质关键词**：理性、专业、简洁、锐利、未来感、数据感、可信；刻意克制，不用花哨装饰堆热闹，用逻辑与数据说服。

**适合的内容类型与行业**，逐项说明为什么合适：

- **科技新品**：手机/电脑/智能硬件发布、参数解读、上手实测。这类内容要靠数据与参数建立可信度，科技风的锐利冷调正好。
- **数码测评**：真实体验、对比横评、性价比分析。测评要显得"客观理性"，科技风的克制是最好的包装。
- **技术干货**：方法论、原理讲解、效率工具清单、代码向/工具向内容。讲原理需要清爽不干扰的排版，科技风留白充分。
- **数据报告**：行业白皮书、数据盘点、趋势分析、图表解读。数据卡片 + 大留白，天然贴合"数据感"。
- **互联网/开发/产品向内容**：只要读者期待"严谨与逻辑"，科技风都适配。

**不适合的场合**，逐项说明为什么是雷区：

- **情绪化内容**：情感随笔、亲子陪伴、治愈向——科技风的冷静会显得没人情味、冷冰冰。
- **热闹促销**：限时抢购、娱乐互动，需要兴奋感的内容科技风压不住场子，也不够"嗨"。
- **文艺/文化类**：需要纸感温度的内容，科技风的冷与"文青"相悖。
- **纯小白读者排斥冷调**：读者如果完全不吃冷色调与术语，要降冷增暖再考虑，否则会被劝退。

**一句话判断标准**：内容核心是"说服读者、建立专业信任"，就用科技风；内容核心是"打动读者、制造情绪"，就别用。

## 二、完整色板表

**背景色**：

```text
#FFFFFF        纯白底：正文底色，干净利落，科技风的地基
#F5F8FF        极浅蓝：数据卡/图表区块底，像液晶屏的背光
#F0F4FF        浅蓝紫：强调块底，冷感更足一档
#111827        深蓝黑（深档底）：焦点卡/结论卡偶用，压场
```

**主色**（挑 1 个做主线）：

```text
#2F6FED        主蓝：按钮、强调、重点线；浅档主力
#3B4FC0        深蓝紫：深档主色，更沉、更"研发"
#00B8D9        电光青：数据高亮、关键数字、荧光点缀
#4F6DF5        电光蓝：图表主色、关键线，理性又醒目
```

**辅助色**（灰阶是骨架，别忽视）：

```text
#667085        中灰：次级文字、坐标轴、辅助说明
#98A2B3        浅灰蓝：注释、弱化文字
#A5B4FC        淡蓝紫：轻边框、辅助线（很淡，只做线条）
```

**强调色**（数据/结论点睛，全篇 ≤2 个）：

```text
#00C897        数据绿：正增长、通过、成功态——"对"的信号
#FF8A3D        数据橙：峰值、重点、待办提示——"注意"的信号
#EF4444        警示红：风险、负向数据（慎用，只在 A/B 对比时给负向用）
```

**文字色**：

```text
#1E3A5F        墨蓝黑：标题主色
#334155        深蓝灰：正文主色（避免纯黑，这是硬规范）
#64748B        次级灰蓝：注释、辅助
```

**深浅两档怎么用**：

- **浅档（默认）**：白底 + 浅蓝卡 + 深蓝字。适合干货与正文密度高的内容，清爽且专业，是大多数情况的选择。
- **深档（局部焦点）**：深蓝黑 `#111827` 底 + 白字 + 电光青点缀，用在「核心结论卡」「数据横幅」「开篇结论」这类**最关键**的地方，全篇 ≤2 个深档块，其余浅底。整篇都深底除非账号是硬核极客审美，作者必须自己判断要不要；默认推荐"深浅夹杂、深底点睛"。

## 三、标题与字号层级

**标题样式特征**：**左竖条**是最签名式的标题——深蓝大字 + 左侧一条 4–6px 的竖色条；或**编号块标题**（01/02 序号徽章 + 标题）。无花哨装饰、无贴纸、无渐变影、无投影，克制的结构就是它的风格。

**装饰语法**（微信正文可用内联写法）：

- **左竖条**：`border-left:5px solid #2F6FED` + `padding-left:12px`，标题字用深蓝 `#1E3A5F`。这是科技风的"身份证"。
- **编号标题**：`<span style="background:#2F6FED;color:#fff;border-radius:6px;font-size:14px;padding:2px 8px;margin-right:8px;">01</span>`（编号徽章）+ 标题字。适合多步骤/多章节内容。
- **荧光下划线**：`border-bottom:2px solid #00B8D9`，数据标题专属，强调"这个重点跳出来"。
- **关键数字上色**：标题或正文里的关键数字用 `#00B8D9` 或 `#00C897` 上色，数据感立刻出来。

**字号字重建议**，给出一张可直接照用的表：

| 层级 | 字号 | 字重 | 行高 | 用法 |
|---|---|---|---|---|
| 主标题（结论/大屏） | 19–21px | bold | 1.5 | 开篇结论、章节总标题 |
| 章节标题（竖条） | 16–17px | 600–bold | 1.5 | 左竖条 / 编号块标题 |
| 小节/副标题 | 15px | 600 | 1.6 | 浅蓝底块上 |
| 正文 | 15px | normal | **1.75** | 硬规范行高，字距 0.5px |
| 数据/标签 | 13–14px | 600 | 1.5 | 图表标注、参数行 |

**间距硬规范**：标题上方 **28px**、下方 **12px**；区块间 **16px**；气泡 `padding:14px 16px`。深档结论卡内标题可放宽到上 30px、下 14px。

## 四、模块表现

每个模块给到具体可执行数值：

- **重点气泡**：浅蓝纯色底 `#F5F8FF`（不用渐变），**圆角 10px**（比校园更硬朗），`padding:14px 16px`（硬规范），左侧 `border-left:4px solid #2F6FED`；气泡内文字行高 1.75。结论气泡可以走深档 `#111827` 底白字，让结论"跳"出来。
- **卡片**：浅蓝底 + **圆角 8–10px** + `1px solid #E1E8F5` 细边框，无投影、无阴影，靠纯色与细边框分层；内文 `padding:14px 16px 12px`。卡片与卡片、卡片与文字之间一律 16px。
- **数据卡/指标行**：白底 + `1px solid #DDE5F5` 细边 + 圆角 8px，左侧放一个主色/电光青小方块（span 几何）＋ 电光青或数据绿大数字（20px bold），右侧放指标名。这是科技风"数据感"的招牌模块。
- **分割线**：不用花纹，用**细实线** `border-top:1px solid #E1E8F5`；分隔上、下各 24px（硬规范）。大章节之间可用 `border-top:2px solid #2F6FED` 粗线做"翻页式"切分。
- **花纹**：科技风「**宁缺毋滥**」——最多用极浅的纯色细斜纹或网格底（用细边框 `1px solid #E1E8F5` 拼网格，或低饱和 `#F0F4FF` 块面），多数情况干脆不用花纹，留白本身就是科技感。不用渐变底纹、不用投影。
- **列表**：横线分隔列表（每行底部加 1px 细线）或编号列表（数据序号）；**忌** emoji/Unicode 图标字符列表——科技风里图标类符号很掉价。
- **步骤**：**流程线**——横向箭头「1 → 2 → 3」或纵向「节点 + 灰蓝连接线 + 短句」；节点用深蓝圆点或序号方徽章（`border-radius:6px`）。步骤之间 16px。
- **对比块**：左右分栏「旧 vs 新」或「A vs B」，左右分别浅蓝底 + 中间 `border` 竖分隔；对比点用主色圆点（span 正圆）/细线区分，数据绿 vs 警示红谨慎用，别滥用红。

## 五、图片与装饰

- **图片处理倾向**：**圆角 6–8px**（偏小偏硬，别圆润），可以用**冷调/通透滤镜**增强"屏幕感"；产品图务必干净、高质、少杂物。
- **叠加信息**：可配「参数标注 / 数据角标」——在图片上层放一块低饱和深蓝底白色小字标签（纯色块，不加渐变、不加投影），如「42%」「5G」「拆解即视感」，一秒数据化。
- **比例**：产品纵图多取 **3:4** 或 **1:1**；数据图表取 **16:9**。图片上、下各留 12px（硬规范）。
- **装饰**：**密度低**，是科技风的克制信号——全篇 **每 10 行点缀 ≤1 处**，且只用中性/技术向的几何形状（主色圆点、小方块、菱形）或序号徽章。**禁用**可爱图形与任何 emoji/Unicode 图标字符。
- **数据符号替代图标**：多用 span 拼的主色圆点、方块、菱形（几何）＋ 序号，比图标更有数据感，推荐优先用几何符号。
- **可用 art:// 植物图案**：科技风偶尔需要一个自然质感收尾时，可用 **sprig-grass 小草**做数据卡一角、或用 **leaf-corner 叶角**做章节标题尾角，纯植物类装饰，绝不反客为主、绝不用图标类图案。

## 六、文案调性

**语气关键词**：数据说话、结论先行、无废话、术语准确、权威克制；不夸大、不卖萌、不空喊。

**句式倾向**：
- 结论前置："3 组数据告诉你……""先给结论："
- 多用数字与对比："快了 42%""提升 3 倍""比上一代轻 15g"。
- 句子利落，少铺垫；每段一个重点，每点一个论据。
- 慎用感叹号，需要用放大强调时选"数字 / 加粗 / 上色"而不是"！"。

**示例句**（可直接套用或改写）：

- "3 组实测数据告诉你：新算法比旧方案平均快 42%。"
- "结论先行：这台机器的续航，是上一代的 1.8 倍。"
- "我们测了 20 款同类工具，只推荐这 3 款。"
- "别只看跑分，这三项真实场景测试才见分晓。"

## 七、禁忌与陷阱

这一节最容易把科技风做砸的地方，逐条给反例与正解：

1. **花哨装饰堆砌**：科技风标题加贴纸、图标、圆润渐变 → 失去锐利专业感。
   - 反例：标题上放一排小图形表情 + 大圆角胶囊。
   - 正解：标题就"左竖条 / 编号块"，装饰减到最少；活泼感交给别的风格，这里要冷静。

2. **颜色太多太花**：蓝 + 青 + 绿 + 橙 + 紫全上 → 画面像儿童涂色。
   - 正解：**1 主蓝 + 1 电光青 + 数据绿或数据橙（二选一）**，灰阶是骨架，彩色是点睛，别让彩色互抢。

3. **术语堆砌、空有术语无数据**：全文名词轰炸却无数据支撑 → 像空壳宣传、看不到说服力。
   - 反例："本产品深度融合前沿架构、全面赋能生态闭环"（纯修辞）。
   - 正解：每个关键 claim 配一个**可验证的数字或对比**，"再强"不如"快 42%"。

4. **纯黑正文大段**：`#000` 大段文字刺眼、冷硬过头。
   - 正解：正文用 `#334155` 深蓝灰（硬规范），标题才用墨蓝黑 `#1E3A5F`。

5. **深浅档混乱无节奏**：一会儿深底白字一会儿浅底深字，切换毫无规律 → 视觉颠簸。
   - 正解：深档只在「结论 / 数据横幅」≤2 处用，且每次深档后回到浅档要层次清楚，明确"深底=重点增强"的节奏。

6. **炫技过度、可读性下降**：为了"炫"把荧光高亮、发光堆满 → 眼睛难受。
   - 正解：荧光（高饱和）用于**关键数字 1–2 处**，不加发光外晕，别让整屏发亮。

## 八、混搭方向

科技风可与相邻风格混搭，用「主 : 辅」比例控制：

- **科技 × 极简（6 : 4）**：观点/产品发布类，科技的数据块配极简的大留白，更高级克制，是科技风最有质感的一个混搭。
- **科技 × 赛博朋克（7 : 3）**：游戏/电竞/潮流硬件，科技的数据感配一点霓虹荧光描边，未来感更足（见"赛博朋克"条目）。
- **科技 × 商务（7 : 3）**：面向决策层的行业洞察，科技风接管数据与图表，商务风的克制细线做底。
- **科技 × 校园（7 : 3）**：数码测评 + 学生党内容，偶尔用明黄做高亮点缀增加亲和，但保持主结构理性冷静。

混搭规则见"风格混搭与主辅法则"条目：科技风做主风格时，辅风格只做**局部小元素**，别污染整体冷调。

## 九、封面建议

- **构图**：中心产品/数据图形 + 大占位的数字或主标题；可用**切割式构图**制造"锐利感"（斜切、错位色块、数据图形）。
- **配色呼应**：低饱和纯色深蓝紫底（`#1E3A5F` 或 `#3B4FC0`，二择一纯色，不渐变）+ 电光青/数据绿点缀数字，冷调科技感直接拉满。
- **大字要少**：标题大而醒、≤6 字；可配一个小数字角标（如「42%」「3 倍」）。
- **别花**：封面最多 2 个强调色，留白与结构清晰优先，别用装饰把封面填满。

## 十、深色模式表现

- 科技风是**深色模式最游刃有余**的风格：深蓝黑底 + 白字 + 电光青点缀，本身就是它频繁出现的形态，暗黑下依然清晰酷炫。
- 浅蓝卡在深色底上改为深卡 `#1E293B` + 白字；深蓝字 `#1E3A5F` 在深底上要提亮为 `#CBD5E1`。
- 电光青 `#00B8D9` 在深底上略微提亮为 `#2EE6FF` 增强对比；数据绿 `#00C897` 保持即可。
- 荧光色（高饱和电光青）在深底上靠**提高明度的纯色**增强对比，可**局部**用在关键数字/结论上成实色块，别滥用、不加外发光。
- 深色模式读者多的账号，科技风基本无需大改造，本身就是暗色亲和的风格。

## 十一、个性化空间

这一节是"知识卡"而非"死模板"，明确哪些参数可按账号自定：

- **品牌/产品色替换**：科技号常有固定品牌色或用色习惯（如某品牌的橙、某竞品的青），把主蓝换成品牌色即可，数据结构（左竖条、编号块、数据卡）完全不用动。**判断依据**：账号长期视觉统一 > 风格标准色；品牌色做主色有利于读者形成记忆。
- **冷感强度**：纯极客/硬核读者可加重深档与荧光比例；大众读者则多浅档、多留白、少荧光。**判断依据**：读者对"硬核感"的接受度。
- **术语浓度**：深度技术账号保高浓度 + 专业术语；垂直新媒体向则升可读性（配通俗示例）。**判断依据**：账号垂直度与读者认知水平。
- **数据卡片密度**：报告类可铺满指标卡与表格；产品介绍则减少显示密度、更多大图。**判断依据**：内容的信息密度需求。
- **装饰密度**：默认克制的科技风，个别年轻向账号可加一档几何点缀与植物图案；自律严谨型账号保持最低密度。**装饰克制底线**：点缀每屏 ≤1 处，宁可留白，靠细线与纯色分层。

> 科技风的底线是"**理性、克制、数据说话**"。品牌色、冷感、术语深度都可调，但"不堆装饰、色彩统一、每点有据"三条别破。

## 十二、全篇排版走一遍示例

这一节把科技风用"数码测评"和"数据报告"两个场景从头串到尾，调用方可照着拼装。所有写法都遵守硬规范，可直接落到微信正文。

**示例一：数码测评的结论前置开篇**

```text
01（编号徽章蓝底白字）深度测评
主标题（左竖条 #2F6FED）+ 关键数字上色 #00B8D9
  这台机，续航实测领先 42%
正文首段（#334155 深蓝灰）
  我们按同一套标准测了三台机器：重度使用、连续视频、熄屏待机。
  结论先行——它在"重度使用"场景下最稳。
数据卡（白底 + 细线 + 电光青大数字）
  圆点 42%     比上一代多撑的近一半
  圆点 1.8x    接口带宽提升倍数
深档结论卡（#111827 白字）
  一句话：参数先放一边，真续航才是王道。
```

**示例二：数据报告的对比块与流程**

```text
章节标题（编号徽章 02）
  过去一年的三个关键变化
对比块（左右分栏，中间竖线分隔）
  左栏：2024 旧方案   右栏：2025 新方案
  圆点 处理慢 12%     圆点 处理快 42%
  细线 维护成本高      细线 组件可替换
流程线（1→2→3 箭头）
  1 采集 → 2 建模 → 3 输出结论
列表（横线分隔 + 行高 1.75）
  每个要点一条，段落后留 16px
```

**这两段示例说明的排版要点**：

- 大块之间统一 **16px** 底部间距；结论/数据卡是深档（2 处上限），其余浅底。
- 标题类（左竖条/编号块）为"上 28px、下 12px"；正文行高 **1.75**、字距 0.5px。
- 全篇主色只走"主蓝 + 电光青 + 一个数据色"，灰阶（#667085 系）是骨架。
- 正文用 `#334155` 深蓝灰，只有标题才用墨蓝黑；不出现纯黑大段。
- 关键数字 / 结论用 `#00B8D9` 或 `#00C897` 上色，不用感叹号堆情绪。

**调用方落地检查清单**：

- [ ] 主色是否统一（1 蓝 + 1 青 + 1 数据色，没混第三种高饱和）
- [ ] 每个块间距是否 16px、正文行高是否 1.75
- [ ] 深档块是否 ≤2 处，且都是"结论/数据"级重点
- [ ] 每个关键观点是否都有数字或对比支撑
- [ ] 正文是否用 #334155 而非纯黑
- [ ] 装饰是否克制（点缀每屏 ≤1 处，多用几何符号/序号，零 emoji/图标字符）
