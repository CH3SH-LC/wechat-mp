# 运动活力（斜切色块、号服数字）

> 定位：校园风格与插画风格的**子系变体**。它把「青春元气」强化成「速度、冲劲、竞技感」——用斜切色块、号服大数字、旗帜三角、跑道线条，像一件球衣和一面加油横幅。
> 适用对象：运动、健身、赛事、校运会、跑步、球类、训练营、体育用品。调用方：排版时多用斜切色块、大号数字、三角旗帜、速度线。

## 一、属于哪个顶层风格的子系

- **母风格一：校园风格**（校园活动、社团招新、学习笔记）。本变体继承校园的天蓝+珊瑚粉明亮感，但把「活泼」换成「冲劲」。
- **母风格二：插画风格**（快消、母婴、娱乐、促销）。本变体借用插画的高饱和撞色与圆形节奏，但把「可爱」换成「竞技」。
- **一句话**：内容是「动起来、拼一拼、冲线」时走本变体；静态校园内容仍用母风格校园。

### 何时用本变体，而不是直接用母风格

| 内容状态 | 选择 | 理由 |
|---|---|---|
| 静态社团招新、学习笔记、活动通知 | 校园风格（母） | 静态校园内容不需要"冲劲"，青春明亮就够 |
| 促销快消、可爱向母婴娱乐 | 插画风格（母） | 可爱圆润的插画更适合温柔带货，运动活力太"冲" |
| 运动、健身、赛事、冲线、竞技感 | **运动活力（本变体）** | 斜切、号服数字、速度线才是"动起来"的语言 |
| 训练营、体育用品、校运会要"热血" | **运动活力（本变体）** | 大数字 + 斜切块最能烘"冲线一击"的紧张感 |
| 需要"速度/进度/冲刺"意象的排比 | **运动活力（本变体）** | 跑道线、倒计时条正好表达"向前、未完待续" |

判断尺：**内容是"动起来、拼一拼、冲线"还是"安静的青春/可爱"**——前者走运动活力。

## 二、与母风格的差异点

| 对比维度 | 校园风格（母） | 插画风格（母） | 运动活力（本变体） |
|---|---|---|---|
| 核心元素 | 天蓝+珊瑚粉、贴纸胶囊 | 高饱和撞色、圆润 banner | **斜切色块、号服大数字、三角旗帜、跑道线** |
| 色板 | 天蓝、珊瑚粉、明黄 | 橙红、青柠、明黄 | **能量蓝 + 亮橙 + 荧光绿点缀 + 大块纯色** |
| 标题 | 贴纸胶囊、emoji | 圆角 banner | **大号纯色字 + 斜切底块 + 大数字编号** |
| 边框/图形 | 大圆角、细彩边 | 粗描边、圆角 | **直角斜切、粗色块、旗帜三角、速度线** |
| 气质 | 青春、可爱、元气 | 热闹、圆润 | **力量、速度、竞技、热血** |

- **力度区别**：校园的活泼是"青春的欢快"，运动活力是"冲线的紧张"——前者圆润贴纸，后者直角斜切。
- **节奏区别**：运动活力多用"斜切方向"制造前倾的速度感，所有斜切统一朝一个方向（多数向右倾）时，版面的"奔势"最强。

## 三、完整色板

> 运动要「亮 + 狠 + 聚焦」。能量蓝 + 亮橙为主，荧光绿只做零星点缀，配大量白色让色块跳出来。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FFFFFF` 或 `#F7FBFF`（冷白） | 底色，白色多才显色块力量 |
| 主色1（能量蓝） | `#2F7CF6`（蓝） | 主强调、标题底、旗帜、跑道 |
| 主色2（亮橙） | `#FF7A1A`（橙） | 次要强调、号服数字、斜切块 |
| 辅助色（荧光绿） | `#A6E22E`（荧光绿） | 零星高亮、倒计时、强调词（点缀 ≤10%） |
| 辅助深色 | `#1F3A6E`（深海军蓝） | 文字主色、深底块、沉稳基底 |
| 中性 | `#111111` + `#FFFFFF` | 大数字、正文、细线 |
| 正文文字 | `#222A35`（墨蓝黑） | 正文用色 |
| 次级文字 | `#7A8694`（蓝灰） | 注释、图注 |

**每个色号一句话用法**：

- `#FFFFFF` 或 `#F7FBFF` 冷白：底色，白色多才显色块力量，别让彩色糊墙压扁。
- `#2F7CF6` 能量蓝：主强调、标题底、旗帜、跑道，运动的主引擎，蓝队/冷峻版主色。
- `#FF7A1A` 亮橙：次要强调、号服数字、斜切块，橙队/热血版主色。
- `#A6E22E` 荧光绿：零星高亮、倒计时、强调词，只在"冲刺"moment用一次，别当主色。
- `#1F3A6E` 深海军蓝：正文主色、深底块、沉稳基底，给热血一块"定海神针"。
- `#111111` / `#FFFFFF`：大数字与细线的中性组合，用于号服号、正文反白。
- `#222A35` 墨蓝黑：正文主色，深、稳、不刺眼的蓝黑。
- `#7A8694` 蓝灰：注释、图注，可读底线。

**配色规律**：一屏锁定「蓝 + 白」为主，橙做第二主角，荧光绿只在「重点冲刺」处用一次。整篇亮色 ≤3 个。若受众偏「热血橙队」可橙为主，反之蓝队；荧光绿永远当点缀。

**深浅档切换**：白天/训练内容走浅档（冷白 + 蓝橙）；"夜跑、晚间赛事、灯光球场"的沉浸内容可切一段深档（深墨蓝黑 `#141B26` + 提亮蓝橙 + 荧光绿点缀），**深档每篇 ≤2 处**，放在最有"冲刺感"的高潮段。深档要保证亮色块与深底有明度差。

**深浅档切换**：白天/训练内容走浅档（冷白 + 蓝橙）；"夜跑、晚间赛事、灯光球场"的沉浸内容可切一段深档（深墨蓝黑 `#141B26` + 提亮蓝橙 + 荧光绿点缀），**深档每篇 ≤2 处**，放在最有"冲刺感"的高潮段。深档要保证亮色块与深底有明度差。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | **斜切色块**底 + 白字；或「大数字编号 + 标语」 | `GO! 今天开始，把身体跑起来`（白字在蓝橙斜切块上） |
| 章节小标题 | 行首「大数字序号 + 短横 + 深蓝字」像球衣号 | `07 ／ 用一周，找回体力` |
| 重点句 | 亮橙加粗 + 深蓝底高亮；或夹在旗帜三角图案间 | `坚持到最后一圈`（夹一枚纯色三角旗） |

- 字号：大标题 22-24px，章节 18px，正文 15px，注释 13px。
- 标题可加 `font-weight:900`，字距 0-1px（紧贴），正文 0.5px，行距 1.75。

**斜切标题块的写法**：标题底用 `clip-path:polygon(0 0, 100% 0, 85% 100%, 0 100%)`（或上端斜切），白字压在蓝底上；或「大数字编号 + 短横 + 标语」。斜切统一朝右，制造一致的前冲方向，别一左一右乱切。标题块放最醒眼处，正文区域保持干净，别让每个小标题都斜切到飞。

## 五、模块表现

- **重点气泡**：**斜切右上角**的色块（`border-radius:4px`，右上角用 `clip-path` 或三角形元素切掉）蓝底白字；或做成「横幅」深蓝底白字；内文 14px。
- **卡片**：白底 + 3px 纯色边（蓝或橙）+ 直角偏圆的 8px + `padding:14px 16px`，靠粗色边与色块撑层次，不加投影；或整块深海军蓝底白字（重点数据卡）。
- **分割线**：一条斜切的速度线，或一条「旗帜长条 / 斜线箭头」纯色色块；上下 24px。
- **花纹色带**：深蓝底 + 一个荧光绿斜切块 + 白色跑道虚线（纯色细条重复排列的跑道线，非平滑渐变）做进度感；整篇 ≤2 条。
- **列表**：圆点换「纯色小三角旗」或跑道圆点；数字用大号「球衣号」徽章。
- **步骤/倒计时**：倒计时条做成分段跑道，每跑完一段换块颜色（可参考「倒计时条模块」）。
- **数据卡**：重点数据块做"记分牌"——深海军蓝底 + 白大数字（如 `08` + "天"）+ 下方橙字说明，像球场记分牌一样让数字"镇场"；数据卡整篇 ≤3 个，用在最有说服力的数字上。

**一个"斜切重点气泡"的骨架**：

```html
<div style="background:#2F7CF6;border-radius:4px;padding:14px 16px;margin:0 0 16px;clip-path:polygon(0 0, 100% 0, 94% 100%, 0 100%);">
  <p style="margin:0;color:#fff;font-weight:900;line-height:1.75;">坚持到最后一圈</p>
</div>
```

要点：重点气泡做"右上角斜切"（`clip-path` 切掉小三角），蓝底白字、直角偏圆的 4px；整篇斜切块 ≤8 处，集中在标题、重点气泡、数据卡，正文段保持白底清晰。

## 六、图片处理与装饰

- 图片：运动实拍 > 展示；可加蓝色调/运动速度感滤镜或斜切选框；多图可用「记分板/格子」排。
- 重点数据图可做成"深海军蓝底 + 白大数字"的记分牌风；动作抓拍图加斜切或多图连排制造"动感连拍"。
- 装饰克制：图案/几何点缀每屏 ≤1 处，宁可留白。避免可爱图案字符，装饰只用斜切块、大数字、纯色三角旗这类几何元素。若要用图案资产，只可用植物/自然类并统一低饱和纯色线条化：如 `sprig-grass` 小草、`vine-frame` 藤蔓花框、`blossom-branch` 花枝、`leaf-corner` 叶角——在正文用 `![说明](art://资产名)` 引用，或只做角落点缀，绝不用图标/竞技类图案破坏运动几何语言。
- 运动元素密度：整篇斜切块/大数字/旗帜 ≤8 处，集中在标题、重点气泡、数据卡，正文段保持白底清晰。
- 一组动作图可做成"连拍格"——同一动作 3 帧等宽小图横向排，配斜切或箭头，制造"动起来"的动态；每格留底、别挤出边框。

## 七、禁忌与陷阱

1. **别把「运动」做「可爱」**：别再堆 emoji 贴纸、奶油色、圆润贴纸感，运动活力要力线条与斜切，不要卖萌。
2. **别全篇荧光**：荧光绿是冲刺点缀，用它当主色会让长文刺眼、像促销。
3. **别做成「儿童卡通运动」**：大圆角+Q版可能导致「童趣」而非「青春竞技」，注意用直角斜切与大字压回力量感。
4. **别用太柔的渐变**：运动追求「块面与速度」，用纯色斜切，少用柔和大渐变。
5. **别忽略深浅层次**：正文全用亮蓝会刺眼，正文锁墨蓝黑 `#222A35`，亮色只做标题与块。
6. **别让斜切乱方向**：统一向右切出来才有一致"奔势"，一会左一会右会让版面乱、失去速度感。
7. **别让数字盖过信息**：号服数字是"节奏符号"，别把正文也全做成大数字，数字只做编号与进度感。

## 八、混搭方向

- **+ 赛博朋克**：运动活力 + 霓虹速度线/数字 HUD 感，适合电竞、潮流运动、市集赛事。
- **+ 二次元**：运动分镜 + 漫画框 + 大数字，适合热血动漫联名、漫画向运动内容。
- **+ 插画（母）**：需保留一点角色的话，运动块做框架、插画形象做主角，是"运动插画海报"。
- **- 禁忌**：别混日系纸感、别混国潮庄重、别混极简留白——速度感会被拖垮。

## 九、封面与首屏建议

- 封面：斜切蓝橙色块背景 + 一个「球衣号 / 大数字 / GO」大字 + 跑道或速度线。
- 首屏：一条斜切速度带页眉 + 爆炸感大标题 + 一句「冲刺式」开场口号。
- 配色呼应：冷白 `#F7FBFF` 底 + 能量蓝 `#2F7CF6` 大字 + 亮橙 `#FF7A1A` 点缀，封面与正文同用"蓝橙冲刺"，点进去衔接毫不冷场。

## 十、深色模式表现

- 深色下：白底换「深墨蓝黑」`#141B26`，蓝/橙提亮（蓝 `#3A8BFF`、橙 `#FF8B2E`）保对比；深海军蓝块、荧光绿同步提亮；正文换米白 `#EAF0F7`；白色大数字换纯白仍醒目。
- 运动色高饱和、在深色模式很出挑，注意亮色块与底色的明度差别过大（避免炫光）。
- 原墨蓝黑正文 `#222A35` 在深底上提亮为米白，别沿用浅档的字；斜切的深海军蓝块在深底上要保持可辨。

## 十一、个性化留白（按账号自定）

- **主队配色**：蓝主橙辅（冷峻专业）／橙主蓝辅（热血激情）／黑白主 + 单彩点缀（潮流街头）——按读者与品牌气质选。
- **斜切程度**：微斜（8px 斜边）／明显斜切（大三角块）——结合「运动」是内容主题还是点缀。
- **是否用大数字叙事**：用（章节=第N节）／不用（常规标题）——若内容有进度/序列感则用。
- **荧光绿位置**：倒计时/冲刺词／区间分隔／几乎不用——按内容是否有"冲刺、倒计时"意象取舍。
- **是否用速度线**：用力线条（纯色细斜线或箭头）／少用（只留斜切块）——若内容偏"起步、助跑"感可用，偏"稳健积累"则收着。
- 判断依据：读者年龄与运动向程度、内容主题（赛事/健身/生活）、账号品牌主色（见「账号风格基线」条目）。

**给调用方的复查三问**：一、一屏是不是蓝/白为主、橙做第二、荧光绿只在冲刺处用？二、斜切方向是否统一、没有一左一右乱切？三、正文是不是用墨蓝黑保持清晰、没被大数字和亮色块抢走可读性？

**运动活力的"活"在哪**：同样的蓝橙配方之下，比的是谁把"奔势"做得一致——一处统一方向的斜切、一个号服大数字、一段跑道速度线，就足够让读者感到"要冲线了"。热血要有力量，也要有秩序。
