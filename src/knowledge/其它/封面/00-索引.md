# 封面方向索引（其它 / 封面）

> 定位：处理封面、摘要字段与文章起始区域的呈现和一致性。
> 交叉：选材、标题与文章组织按需查阅 文本/写作 的 writing-purpose、writing-structure 和 writing-review；视觉风格见 视觉/风格。

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| cover-spec.md | 封面图尺寸、裁切安全区与格式 | 制作封面时 |
| cover-text.md | 封面文字的位置、字号、对比度与留白 | 封面含文字时 |
| cover-summary.md | 摘要与正文一致性、实际字段限制与截断检查 | 需要摘要时 |
| cover-firstscreen.md | 文章起始区域的层级、图文关系与可读性 | 检查起始呈现时 |
| cover-consistency.md | 封面与正文的色调、字体和元素呼应 | 封面与正文分开制作时 |

先确认内容，再按输出用途取用相关条目。首图、关注条与目录均按实际需要安排；发布字段及尺寸要求以当前可验证的载体规则为准。
