# 首屏组合拳（cover-firstscreen）

> 定位：拆解「点进来之后第一屏」的整体排布——标题→摘要→首图→引导关注→正文第一屏怎么排、每层做什么、第一屏信息是否完整钩子是否可见。每篇发布前检查首屏时必读。
> 调用时机：一篇推文排版完成、准备发布前，用它做「第一屏检查」；也用于规划「开篇」怎么写、首图放几张、关注引导放不放。

## 一、核心规范

### 1. 什么是「首屏」，为什么它决定留存

- **首屏**指读者点进文章后，最先看到的那一页内容（大约一屏的篇幅：标题、摘要、首图、开头几句正文）。
- 后台数据里，「点开率」管的是「封面有没有骗你点进来」，「后读率 / 完读」管的是「点进来之后看不看得下去」。首屏就是这两者之间的「接驳站」——它决定「点进来的这个人，愿不愿意继续滚下去」。
- 首屏没做好，前面前期多辛苦引流、封面多好，都会在「第一屏就退出的读者」手上打水漂。因此首屏是每一篇都值得专门检查的关卡。

### 2. 第一屏各层级的顺序与作用

一篇图文的「第一屏」从逻辑上由五层组成，顺序固定、各司其职：

```
第一屏排布顺序
1 标题        —— 承上启下，把「点进来的理由」再讲一遍
2 摘要        ——（注意）图文卡片里通常不重复显示，但发布时它填在信息流里
3 首图        —— 正文里的第一张配图，承接封面视觉，给读者「找对地方」的熟悉感
4 引导关注条  —— 可选，轻轻提示「可以关注」，克制不要刷屏
5 正文开头第一屏 —— 承接封面承诺，不让读者「点了却发现和封面说的不一样」
```

五层的作用逐个说：

- **1. 标题**：在正文页它通常显示在顶部，是读者点进来后第一眼看的文字。它要和封面、摘要连成一条线，别在这里才突然换了另一个说法。
- **2. 摘要**：摘要主要在信息流卡片里显示（列表场景）；进入正文后不一定再见。但它是首屏「点击决策」的一部分，所以排在「首屏组合拳」里一起讲——详见 cover-summary 摘要写法。
- **3. 首图**：正文内第一张图。理想状态是和封面同图 / 同风格，让读者产生「我点对了」的确认感。别放一张和封面毫无关系的图，会造成错位。
- **4. 引导关注条**：可选的关注引导。放得好是自然带新，放得差是打扰。原则是**克制**：一屏内顶多一条，不要连发几条「关注我不迷路」。
- **5. 正文第一屏**：正文开头的头几段。它要**承接封面和标题的承诺**，把读者点进来时心里期待的那个「答案 / 好处」迅速给到，不能是无关开场白。

### 3. 首屏优化检查三件事

发布前，用三件事自查首屏：

1. **第一屏信息是否完整**：标题、首图、正文开头几句，是否已经足够回答「我要看什么、有没有价值」。首屏信息残缺（比如一进来是大段无关引言、或大片空白），读者会在半屏内就划走。
2. **钩子是否可见**：「点进来的理由」在第一屏内是否一眼可见。如果读者要往下滚很久才看到重点，等于钩子被埋得太深，留存会掉。
3. **关注引导是否克制**：关注引导条有没有多到干扰阅读？是否在第一屏就强行逼关注？克制的一屏一条、文案自然，通常比几连发更有效。

这三件事能不能过，直接决定「进来了多少、留下来多少」。它是每篇发布前都要做的小检查，不是可选项。

### 4. 首屏和「后读率」的关系（看数据验证首屏好坏）

首屏做得好不好，不是只能靠感觉，后台数据会给你答案：

- **如果「后读率 / 读完率」和同类内容比明显偏低，多半首屏有问题**——读者进来了却没留下，问题大多是第一屏钩子不清晰或正文开头没接上封面。
- **如果「平均阅读时长」很短、且集中在开头一两屏**，说明大部分读者看完第一屏就划走了，首屏的「留人陈述」没做到位。
- 判断方法：不用看细节，就看「读完率」这一个值。它低，就回头检查首屏的「三件事」；它正常，说明首屏整体成立，可以放行。
- 注意区分：读完率低也可能来自正文中后段无聊或太长，不一定全是首屏的锅；但首屏是最先、也最容易修复的一环，值得先看。

## 二、正文第一屏怎么写（承接封面承诺）

**这是首屏的核心难点，单独讲。** 正文第一屏不能和封面两张皮——读者因封面「某个词」点进来，正文开头就要让这个词」或它的答案，尽快出现。

**为什么第一屏「承接」这么重要**：如果封面上写着「效率翻倍」，读者点进来第一屏却是另一篇毫不相干的开场白，读者会立刻产生「被标题骗了」的感觉，很可能在这一屏就退出。第一屏的第一句，本质上是在替封面向读者做一次「履约」——兑现点进来时的那个人设和期待。

### 正文第一屏的三种开法

**开法一：承接承诺式（最常用）**

- 封面说「效率翻倍」，正文第一句就交代「这篇要给你 7 个让阅读效率翻倍的习惯」。
- 作用：秒速让读者确认「我点对了」，消除「点后悔」。
- 适用：干货 / 教程 / 清单类，几乎必用。
- 示例句：「今天这篇不绕弯子，直接拆 7 个让我阅读效率翻倍的习惯——你挑 3 个今晚就能用上。」

**开法二：直接给结论 / 答案式**

- 封面是提问（「为什么读了很多书记不住」），正文第一屏就直接给一句判断或结论（「不是记忆问题，是阅读方法问题」）。
- 作用：把钩子从「好奇」快速推进到「想听解释」。
- 适用：观点类、解惑类。
- 示例句：「先说结论：读了很多书却记不住，多半不是你记忆力差，而是你从头到尾在用『读』而不是『记』。」

**开法三：场景代入式**

- 封面是故事 / 情绪（「30 岁后我戒掉了无效社交」），正文第一屏用一个具体的场景/情绪切入，让读者「代入进来」。
- 作用：建立情感连接，愿意继续看。
- 适用：故事、见闻、情绪类。
- 示例句：「那天下班我第三次把手机里翻到底，才发现我加了 600 个『好友』，却半小时没等到一条真心的消息。」

**每屏的节奏提示**：首屏的正文文字建议单行短句、段距清晰（微信排版规范里行距 1.75、段距 16px 等，见 00-GUIDE 间距规范），这样首屏能放下「能留人的信息量」。别在第一屏就用大段密集文字劝退读者。

## 三、可执行步骤（首屏优化流程）

1. **排版完成后先「手机预览」第一屏**：不要只看电脑上的编辑器，手机预览最接近真实阅读。
2. **对照五层顺序核对**：标题、摘要（发布时填）、首图、引导关注条（如有）、正文第一屏，是否都在、顺序是否自然。
3. **检查三件事**：
   - 第一屏信息完整吗？
   - 钩子（点进来的理由）在第一屏内就被看见了吗？
   - 关注引导克制吗？
4. **把正文第一屏再读一遍**：它是否承接了封面 / 标题的承诺？有没有在第一句就给出篇的核心指向？
5. **回到 cover-spec 与 cover-summary** 交叉核对封面尺寸与摘要，确保首屏的视觉和文案是一条线。
6. **通过则发布；不通过就调整正文开头或首图，直到首屏独立成立。**

## 四、示例（一个完整首屏骨架）

**示例：干货推文「7 个阅读习惯」的完整首屏骨架**

```
1 标题　　　　：7 个让你效率翻倍的阅读习惯
2 摘要（发布）：不灌鸡汤，就 7 个能直接上手的习惯，至少 3 个现在就能用。
3 首图　　　　：与封面同一张（2.35:1 大图原图），强化「点对了」的确认感
4 引导关注条　：一行小字「关注我，每周一篇效率干货」（轻、不刷屏）
5 正文第一屏　：
   第一段（承接承诺）：「今天这篇，直接给你 7 个让阅读效率翻倍的习惯，
   先把最有用的 3 个放在最前面。」
   第二段（给一个立刻的钩子）：「第一个：手抄金句法——读时把打动你的句子抄下来，
   读完合上书复述一遍，能记住的量直接翻倍。」
   （之后进入正文分层）
```

**这个骨架的关键点**：标题抛钩子 → 摘要加利益 → 首图确认「点对了」→ 关注引导克制 → 正文第一屏秒接「能留下我的价值」。五层环环相扣，读者从「看封面」到「读第一屏」，始终在做同一个决定：「这篇值得看」。

**示例二：观点推文「为什么你读了很多书却记不住」的完整首屏骨架**

```
1 标题　　　　：为什么你读了很多书却记不住？
2 摘要（发布）：不是记忆问题，是方法错了——试过「复述式阅读」，没有一本白读。
3 首图　　　　：与封面同幅的深蓝纯色大字图
4 引导关注条　：文末小字「关注我，别再记不住读过的书」（放在结尾而非开头）
5 正文第一屏　：
   第一句（给结论）：「先说结论：记不住，多半不是你记忆力差，是你一直在『读』而不是『记』。」
   第二句（引向解释）：「这篇把 3 个最有效的方法拆给你，从第一个开始。」
```

两个骨架的差异点：干货用「承接承诺」，观点用「先给结论」；引导关注一个放开头、一个放文末。说明第一屏的「五层」是骨架，其内的具体表达方式由内容类型决定。

## 五、常见错误

| 错误反例 | 问题出在哪 | 正确做法 |
|---|---|---|
| 首图放一张和封面毫无关系的图 | 读者「点了却发现不是我要的」，失去确认感 | 首图和封面同图 / 同风格，给「点对了」的暗示 |
| 正文第一屏是大段无关引言或寒暄 | 第一屏信息残缺，读者在半屏内划走 | 在第一句就进入「承诺的内容」，别绕 |
| 钩子埋得太深，要翻很久才看到重点 | 留存掉，读者耐心耗尽 | 把核心要点 / 结论 / 好处提前到第一屏 |
| 关注引导条一屏发好几条 | 强行逼关注，打扰阅读 | 克制放一条、文案自然，放在开头或文末 |
| 封面上一个词，正文第一屏完全不提 | 封面和正文两张皮，读者觉得被骗 | 第一屏尽快让「封面那件事」出现或给答案 |
| 标题/摘要/首图三处口径不一致 | 信息打架，读者不知道该信哪个 | 三者共同服务于「同一个点进来的理由」 |

## 六、自查要点

- [ ] 标题、摘要、首图、正文第一屏顺序自然，首屏信息完整
- [ ] 首图和封面同图 / 同风格，给「点对了」的确认感
- [ ] 「点进来的理由 / 钩子」在第一屏内肉眼可见
- [ ] 正文第一屏第一句就承接了封面 / 标题的承诺
- [ ] 关注引导克制（一屏 ≤1 条），没有刷屏
- [ ] 用手机预览过第一屏，单行短句、信息量足够
- [ ] 与 cover-spec（封面尺寸）、cover-summary（摘要）核对过，是一条线

## 七、个性化空间

- **首图是否与封面完全同图可调**：信息型账号可以首图就用封面原图，最省事也最稳；视觉型账号可以首图换一张同风格的「展开画面」，但不建议换成毫无关系的内容。判断依据：读者是否需要「原地确认我点对了」。
- **引导关注条的位置与文案可调**：可以放开头、可以放文末，取决于你更看重「开头就带上」还是「读完再带」；文案也自由，只要克制自然。判断依据：读者处在「刚进来」还是「快读完」的哪个状态更可能愿意关注。
- **正文第一屏的「开法」按内容类型定**：干货用承接承诺式、观点用结论先行、故事用场景代入。判断依据：你的读者此刻带着什么期待点进来。
- **是否一定放首图可调**：资讯 / 短文可以不放首图直接进正文；但「没首图」时要确保正文第一屏更强，否则少了「确认感」这块。判断依据：首图对这个内容类型的确认价值有多大。
- **第一屏的「信息密度」可调**：快节奏 / 资讯号喜欢一句一个信息点；深度 / 观点号可以留白多一些、开头慢一点。判断依据：账号一贯的阅读节奏和读者耐心阈值。
