# 字号、行距与中文排版（项目参考参数）

本条的尺寸来自项目既有排版约定，是可调的检查起点，不是微信官方标准、主流账号统计或阅读效果保证。实际输出由 engine-write-protocol 与当前引擎决定；是否清楚需查看实际页面。

## 字体与阅读尺度

正文可从 15–16px、行高 1.75、块距 16px 起步，采用清楚的系统字体。字号、字体、屏幕和阅读设置会共同影响呈现，不能保证某个数值能让所有人久读不累。

15px 字号乘以 1.75 行高约为 26px，这是行框高度；字形的实际高度取决于字体。需要调整时在预览中比较 1.7、1.8 等行高，避免行间粘连或过分疏散，不按题材固定调整方式。

## 标题与辅助文字

以下保留既有项目参考尺寸，实际层级按引擎与所选版式呈现，不要求额外增加标题：

| 视觉角色 | 参考尺度 | 检查重点 |
| --- | --- | --- |
| 主标题 | 20–22px，醒目版式可更大 | 与正文区分，不截断标题 |
| 分节标题 | 17–19px，较重字重 | 主题变化明确，保持对齐 |
| 正文内标签 | 15–16px 或引擎规定值 | 字重与普通段落可区分 |
| 引用 | 14–16px，行高 1.7–1.75 | 保留完整引文与来源 |
| 图注与来源 | 12–14px，行高约 1.5 | 在实际预览中可读，不能为了版面省去说明 |

标题上下留白可参考 28/12px，次级位置可参考 24/10px。相邻层级可通过约 2px 的字号差、字重与留白区分，具体效果由页面验证。代码、标签等若小到 10–11px，需特别检查；这些数值不是已证明的可读性分界。

注释色可用 #666 作起点，#999 等浅色需要结合纸面计算对比度。不能只凭色号名称断言达标。

## 中文排版与对齐

正文以左对齐或引擎支持的两端对齐为基础，标题可按构图居中。数字列可用等宽处理，不通过堆空格对齐。字体与图片中文字的授权、可用性分别核对，不声称当前引擎支持任意字体嵌入。

正文字距可参考 0.5px；标题可参考 1–6px，但需看字形和实际宽度，不因为追求疏朗而把正文拉散。中文标点、数字、英文与单位的间距保持一致，不用手工空格、空段或 HTML 缩进占位。

屏幕自动换行不同于分句、分段。长词、URL 和表格造成溢出时调整呈现；不能把完整书面句切成碎句、把说明拆成逐行短语，也不为框宽删去原因、条件和限定信息。

## 预览检查

核对普通正文、标题、图注、引用的层级及清晰度，检查孤立标题、字距拉散、行间粘连、横向溢出和深浅背景的对比度。组件过窄时换成合适布局或普通段落，不以改短句子代替排版修复。

段间 16px、独立图文间 20px 或 24px 都可作为项目内对照参数，实际关系比套用数字更重要。只记录实际查看过的环境和结果；不把桌面预览等同于微信后台或所有手机已验证。
