# 复古港风（style-hk-retro）

> 定位：胶片感、市井烟火、怀旧摩登，像老港片里的一帧霓虹招牌和一段粤语独白，浓烈、有故事、有人间味。

> 调用时机：怀旧生活、本土文化、独立音乐、老城探店、香港/粤地主题、复古潮流品牌，以及一切想"回到旧时光、讲有滋味的故事"的内容。

## 一、气质与适用内容

**气质关键词**：怀旧、胶片感、市井烟火、霓虹、摩登、浓烈、有人情味。

它最醒目的组合是"哑光暖调 + 霓虹招牌字"。一面是胶卷照片里那种发黄的旧，一面是夜晚灯牌亮起来的光；这两种质感叠在一起，就是港风特有的"旧而有味"。

**适合的内容类型与行业**，逐个说为什么合拍：

- **怀旧主题**（老物件、老街区、旧日生活、时代记忆盘点）：这类内容本身就在"考古回忆"，港风的旧黄底与胶片感正好当回忆的画布。读者读到的是同一段旧时光，视觉和情绪同频，不会觉得形式抢了内容。
- **本土文化**（粤语文化、港式美食、大排档/茶餐厅、老街探店）：茶餐厅的霓虹招牌、大排档的烟火气本质就是港风。用港风写港式生活等于让"场景"自己上镜，读者一眼就对味，不需要额外解释"这是香港味"。
- **独立音乐/电台**（复古粤语歌、现场、乐评，音乐节企划）：音乐内容天然讲究氛围与画面。港风的霓虹粉/青/黄正好做出"演出、现场、夜晚"的光感，把歌词里的旧香港情绪从耳朵搬到眼睛。
- **复古潮牌**（港风服饰、胶卷相机、黑胶、复古生活方式）：这类产品本身就长在"八十/九十年代审美"上。港风让品牌的年代感更完整，不是单一卖货，而是"买回一段旧时光"。
- **故事/人物**（城市记忆、老手艺人、市井人物访谈）：人物故事需要人情味和温度。港风的暖褐字色、旧纸张的柔光，让被访谈的人像从旧照片里走出来，讲的话也更有回味的余地。

**不适合的场合**，逐个说为什么是雷区：

- **严肃正经的金融合规、医疗法律**：这类内容要冷静、准确、可信——港风具象的城市燥热感和霓虹的戏谑光感会冲淡权威，读者会觉得"页面像娱乐号"，反而给专业结论减分。
- **高冷极简、未来科技**：极简讲留白和安静，科技讲冷调与未来感——港风偏偏是暖调、浓烈、拥挤的市井，两者气质温差太大，硬拼只会两头不讨好。
- **跨国极客、纯英文向的高端现代场景**：港风地域感极强（尤其粤港符号）——目标读者若完全不懂这片文化语境，那些旧招牌、茶餐厅、粤语点缀都会变成看不懂的符号，反而增加理解门槛。

**判断一句**：内容要"讲故事、念人情、带烟火气、回味旧时光"，港风正中；要"冷静论证、抢占第一眼"之类则未必。简单判断——你写完这篇，是想让读者"心里一热想回旧时光"，还是"马上记下几个要点"？前者适合港风，后者不适合。

## 二、完整色板表

```text
背景类（哑光暖调）
  #1A1A22        墨蓝黑底（深档主轴）：霓虹夜底，港风最带感
  #F7EFE3        发黄米纸底（浅档）：记忆照片的陈旧暖白
  #EFE2CC        旧纸黄：分区卡
  #2B2B33        深灰紫：次级深底

主色类（哑光暖调 + 霓虹彩，搭配着用）
  #C0392B / #D35400   砖红/铁锈橙：主标题、招牌暖色，市井
  #E67E22            南瓜橙：暖光色点（低饱和实色）
  #D4AF37            旧金：招牌描边/点缀

霓虹强调色类（港风强记忆点，做"招牌字"用）
  #FF2E97            霓虹粉：招牌字/荧光描边，夜晚闪亮
  #00E0FF            霓虹青：另一荧光色，招牌感
  #FFE200            霓虹黄：大字/高亮，夜市灯牌感

辅助/文字色类
  #F5EBD8            米白：深底上的正文字，旧白
  #C9BFA8            浅米灰：次级字
  #4A3F38            暖黑褐：浅档正文（避免纯黑，发暖才"旧"）
```

**颜色怎么用，逐个说一次**：

- **#1A1A22 墨蓝黑底**：深档的主场底。
  它比纯黑多一层蓝调，压得住霓虹，又不会死黑一片，这是全篇夜晚氛围的地基。
- **#F7EFE3 发黄米纸底**：浅档的主场底。
  那种"旧照片纸发黄"的暖白是港风轻档的关键，用纯白就丢了旧Feel了。
- **#EFE2CC 旧纸黄**：比米纸再深一档的黄。
  适合做分区卡、小卡片，让版块之间有"纸的层次"。
- **#2B2B33 深灰紫**：深档里的次级深底。
  比如次要分区或卡片背景，比墨蓝黑再浅一档，用来分区不抢主底。
- **#C0392B 砖红**：主标题、招牌暖色的首选，市井感最正。
  很多"老招牌"的底色就是这种砖红。
- **#D35400 铁锈橙**：跟砖红搭着当第二暖色。
  用在低饱和暖色点缀或次级强调上，比砖红再亮一档。
- **#E67E22 南瓜橙**：负责"暖光"的感觉。
  用低饱和实色做标题下的一小段暖色点缀，做出灯箱照到招牌上的暖橘感，别用渐变。
- **#D4AF37 旧金**：招牌描边、点缀用。
  旧金比亮金更黯淡复古，做描边或小分隔很适合。
- **#FF2E97 霓虹粉**：招牌字、荧光描边，夜里最闪的粉。
  记忆点极强，但一定只做"点睛"。
- **#00E0FF 霓虹青**：另一支荧光，招牌感。
  跟粉是港风最有记忆点的"对面色"，常搭配用。
- **#FFE200 霓虹黄**：大字/高亮用，夜市灯牌感。
  跟粉青放一起，就是"一条灯牌街"。
- **#F5EBD8 米白**：深底上的正文色，旧白不刺眼。
  深档正文首选。
- **#C9BFA8 浅米灰**：次级字、注释，比米白暗。
  做次要信息。
- **#4A3F38 暖黑褐**：浅档正文。
  关键在"发暖"，不是纯黑，带一点褐，这样才"旧"而不"冷"，避免大段纯黑刺眼。

**深浅两档怎么切换**：

- **深档（默认更有味）**：以 #1A1A22 墨蓝黑为底，招牌字用霓虹粉/青/黄，正文用 #F5EBD8 米白。
  这一档港味最浓，简直像夜晚霓虹下的老街——招牌亮、背景沉、层次分明，适合音乐、潮店、夜向内容，也适合任何想一开头就"咚"一下把读者拉进港夜氛围的内容。切换方法：底换成墨蓝黑，正文换成米白，强调色换成一支霓虹，其余暖色（砖红、旧金）继续当配角。
- **浅档（日怀旧）**：以 #F7EFE3 发黄米纸为底，主色用砖红/铁锈橙，正文用 #4A3F38 暖黑褐，霓虹只在极少量点缀处出现，适合老城探店、旧生活回忆、白天向内容。
  切换的关键提醒：浅档底色是"发黄的旧"，绝不是纯白——这是港风浅档和普通简洁风最根本的区别。切过来的方法：把底换掉、字色换暖、霓虹收敛到一两个点。

## 三、标题与字号层级

**标题样式特征**：霓虹招牌字，或粗狂大字粗体。像店铺招牌或电影片名的粗黑大字，配上霓虹色描边感或暖色实底，辨识度极高，一眼就是港片海报/灯牌的味道，不需要任何额外说明。

**装饰语法**，逐条说明：

- **霓虹招牌标题**：粗壮黑字 + 霓虹色（粉/青/黄）+ 低饱和实色底或细描边（`border-radius:8px`）。
  做成路灯牌在夜里发光的质感，适合主标题，是全篇的记忆点。
- **粗黑字头**：整行通栏（`width:100%`）铺一个 `background:#FF2E97`（或砖红）的底色 + 白色/深色字。
  做成字头横幅，像一条电影字幕卡，铺满屏很抓人，适合开篇的"定场标题"。
- **黄色描边**：黑字 + 霓虹黄或白描边，做出"灯牌勾边"的感觉。
  注意：描边功能在微信里未必可靠，跑不通时就改用"大粗字重 + 对比色背景"来达到同样的醒目效果。
- **序号港版**：用「壹贰叁」或「01」衬托年代感，配砖红色。
  这种旧式数字一出现，读者立刻就有"老报纸/旧招牌"的条件反射。
- **分隔字符**：用 CSS 几何形状（`span` 拼的圆点、方块、菱形、细线，圆角 8–14px）或「— / ─」细线，刻意做出一点"旧广告牌"的复古感。
  比普通横线更有年代味道。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 霓虹/字头主标题 | 20–22px | 900/bold | 霓虹色或暖色实底，粗壮抢眼 |
| 章节标题 | 16–18px | bold | 砖红/铁锈橙粗体 |
| 小节/副标题 | 15px | 600 | 米白（深底）/暖黑（浅底） |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 注释/落款 | 13px | normal | 米灰/旧金字 |

> 间距硬规范：标题上 28px 下 12px；正文行高 1.75、字距 0.5px；正文色建议用 #4A3F38 级别暖褐，避免整段纯黑。

霓虹/字头主标题可以再加大，上 30px 下 16px，强调"招牌感"，让标题有"立起来"的呼吸空间。

## 四、模块表现

每个模块怎么画，逐项给具体数值和可参考写法：

- **重点气泡**：深档用墨底霓虹边气泡，可参考写法 `background:#25252F;border:1px solid #FF2E97;border-radius:4px;padding:14px 16px;`。圆角 4px——港风偏方、偏粗，不追求大圆角；padding 是硬规范 14px 16px。标题字用霓虹色；浅档则换成旧纸卡 `background:#EFE2CC` + 砖红细边框，暖旧不发光。
- **卡片**：粗描边卡——浅档旧纸黄底，或深档墨底，加 `border:2px solid` 砖红或霓虹色，圆角 4–6px，padding 用硬规范 14px 16px 12px，顶部可放一条 4px 的砖红横条做"招牌横眉"。可参考写法 `border:2px solid #C0392B;border-radius:6px;padding:14px 16px 12px;`。卡片之间间距用 16px（硬规范）。
- **分割线**：霓虹细线 / 几何点——深档用 `border-top:1px solid #FF2E97`，浅档用砖红细线，线中可放一个 `span` 拼的圆点或菱形（圆角 8–10px），上下各留 24px。要有间隔，别连排；想更复古，可用竖排"旧招牌"式的分隔，但字数要少。
- **花纹**：克制使用——浅档用旧纸格纹/波点，明度要压在米纸级别，别太黑；深档可用极淡的留白几何点做街灯光斑感。全篇花纹 ≤2 种，且只放在分区边缘当装饰，不能铺满。
- **列表**：每行前用「— / 方块 / 斜杠」CSS 几何形状或霓虹色圆点（`span` 圆点，圆角 50%），行距保持 1.75（硬规范）。这个列表符号很关键——它决定了"老派"还是"土气"，选这几个旧式几何符号就有广告牌/旧报纸的味道，千万别用普通黑圆点糊弄。
- **步骤**：电影/旧历步骤——用「壹贰叁」或霓虹色编号，配大数字 + 短句，像片尾字幕或旧报纸编号，步骤之间间距 16px（硬规范）。每步可做成一行："壹 ＋ 先淘一张旧照片"（＋ 用 CSS 圆点/方块几何形状代），短句断句干净，年代感自然出来。

## 五、图片与装饰

- **图片处理**：做旧效果——强烈暖调 / 胶片感滤镜，提暖、加对比、降一点清晰度带颗粒感，或干脆做黑白旧照处理；四角可加暗角（用低饱和深色块裁边做成，不用渐变），像老镜头拍出的四周变暗。圆角 4–6px 或直接直角。比例多取 3:4（竖版街景/人物）或 4:3，横平竖直地放，更像旧影集排版。
- **氛围**：霓虹灯元素（招牌、灯光、夜景）是港风绝配——可以做背景氛围，或做标题后的底图。一张亮着霓虹的街景，比任何文字都更能把气氛点起来。
- **装饰克制**：图案/几何点缀每屏 ≤1 处，宁可留白。旧感氛围只用一个 `.svg` 几何点或一处 `![说明](art://vine-frame)` 藤蔓花框做角饰，慎用热闹的贴纸符号。装饰在这里是"一点点人间烟火"，不是"卖萌热闹"，多了会把胶片感冲掉。

## 六、文案调性

**语气关键词**：怀旧、有故事、烟火气、浓烈、带点"江湖"味、有人情。

**句式倾向**，逐条说明：

- 有旁白/独白感，像电影画外音，比如"那时候……""记得吗，老码头边……"——这种句式一开口，就把读者带到"讲古"的氛围里，港味最足。
- 多用粤语/老派词点缀（适度），比如"饮茶""盏鬼""呢个城市""老友"——只能点缀，要挑读者能看懂的词，避免晦涩（详见禁忌）。
- 句子有节奏，可长可短，重氛围与画面——先甩一个长句铺画面，再接一个短句敲重点，就像电影蒙太奇。
- 结尾常收在一个"有滋味"的短句或一句旧语——让读者回味的余韵，落在最后一句上。

**可直接套用的示例句**：

- "老九龙，霓虹还亮着，故事的下一集还没写。"
- "那碗云吞面，我从少年吃到鬓角发白。"
- "呢个城市慢下来的时候，像一部没赶完的好戏。"
- "胶片里的街角，还藏着几十年前的热气。"
- "旧招牌没拆，故事就还有得讲。"
- "一盏灯，一条巷，就是一份日子。"

## 七、禁忌与陷阱

每个坑给"反例 + 正解"两段，反例带具体色号/写法：

**坑1：霓虹滥用、全屏闪。**
- 反例：每一个卡片都 `border:1px solid #FF2E97`，每一个标题都 `text-shadow:0 0 8px rgba(255,46,151,0.9)`，全篇底色也是霓虹彩——整篇荧光发光，视觉炸裂，读起来又俗又刺眼，像劣质霓虹店门口闪烁的灯牌。
- 正解：霓虹色只做招牌级标题 + 1 个分段点，这两处。其余标题和正文都交给砖红 #C0392B、铁锈橙 #D35400 这些暖色去推进。霓虹是"点睛"，不是"基色"——点到为止，记忆点才在。

**坑2：底色不用"旧黄"。**
- 反例：浅档直接把背景写成 #FFFFFF 纯白，正文用纯黑 #000000——这一下就回到普通网络风格，整篇"旧"的底子全没了。
- 正解：浅档底色必须用发黄米纸 #F7EFE3 或旧纸黄 #EFE2CC，正文用暖黑褐 #4A3F38。底一黄、字一暖，"旧"的味道才在。

**坑3：粤语过多难懂。**
- 反例：每句话都往尾上挂粤语口语——一整段读下来，北方和外地读者直接卡壳看不懂，感情没传到位，反而把读者推走了。
- 正解：粤语/老派词点缀 2–3 个即可，主体用普通话。优先选"饮茶、老友、情怀"这类不用解释也懂的词，照顾大部分读者。

**坑4：土 vs 复古失衡。**
- 反例：配色用脏土黄 + 脏土褐，字型拼得乱七八糟，像海报纸一样的大杂烩——读者第一眼只觉得"脏乱旧"，直接退出。
- 正解：复古要用有对比的暖色 + 霓虹点缀 + 干净排版。底色旧，但版式要清晰、留白要给够。"旧"在氛围，不在脏乱——色板表里的颜色都有明确分工，按它走就不会乱。

**坑5：emoji 破坏胶片感。**
- 反例：文里堆一串欧美大笑的大表情——情绪是热闹了，但复古胶片氛围当场崩掉，像给老电影截图贴满卡通贴纸。
- 正解：装饰极克制，图案/几何点缀每屏 ≤1 处，宁可留白。需要标记的地方多用 CSS 几何点、方块或一处 `art://vine-frame` 藤蔓花框营造年代，而不是用表情。

## 八、混搭方向

按"主 7 辅 3"或"主 8 辅 2"搭配，港风做主风格，守住墨底霓虹或旧纸暖调的底子：

- **港风 × 美式复古（主 7 辅 3）**：咖啡/复古好物向——港风的霓虹 + 美式复古的奶油棕/青蓝拼色，两个复古大家庭的审美能互通（参照「美式复古」条目）。
- **港风 × 复古报纸（主 7 辅 3）**：旧历史/城市记忆盘点——加报纸分栏与徽章，做出"旧报读史"的载体（参照「复古报纸风」条目）。
- **港风 × 杂志编辑风（主 7 辅 3）**：人物/故事向——港风的叙事 + 杂志的大字图形化标题，更强"大片/人物特稿"的冲击（参照「杂志编辑风」条目）。
- **港风 × 二次元（主 8 辅 2）**：港漫/复古动漫向——可加一点漫画分镜感（上格下图、台词条），但别喧宾夺主，守住港风底调。

> 具体主辅怎么分、哪个做版式骨架，参照「风格混搭与主辅法则」条目，别硬拼两套系统。

## 九、封面建议

- **构图**：夜景霓虹一眼即港——一张夜景/旧街/胶片感的竖版大图，上方压霓虹色粗字标题；或近景招牌人像。封面就要"一帧老港片"，别放花哨拼贴。
- **配色呼应**：深档用墨蓝黑 #1A1A22 + 霓虹粉 #FF2E97 或霓虹青 #00E0FF 做标题字；浅档用旧纸黄 + 砖红 #C0392B + 旧金 #D4AF37。封面配色和正文首屏保持同一套，别换体系。
- **字**：超大粗黑/霓虹大字，≤6 字，像电影片名那样短而有力；副标一句勾起怀旧。字太多就读不出"片名感"了。
- **气质**：有故事、有滋味、旧而有味——封面要先勾起一句"想看看里面讲什么旧事"。

## 十、深色模式表现

复古港风天然适合深色模式。墨蓝黑底本来就是它的深档主场，霓虹字在暗底色上发光会越来越好，暗黑下浓郁感完全不减。

浅档的旧纸黄在深色模式下，直接切回墨蓝黑底 #1A1A22 + 米白字 #F5EBD8，效果跟深档一致——所以浅档写得再久，深色模式一启用就有现成的替代方案。

米白 #F5EBD8 在深底上是理想正文色，保持不动；暖黑褐 #4A3F38 在深底上要提亮成米白，不然太暗看不清；霓虹粉/青的高亮在深底上更跳、更有"灯牌亮起"的感觉。

但注意别让太多荧光同时出现——深档的霓虹只定位在招牌标题那一两处，其余仍用暖色推进。这样暗黑下既浓郁又耐看，不会闪成一片。

## 十一、个性化空间

以下留白是可按账号/读者自定的参数，每项给判断依据：

- **霓虹色归属**：可选霓虹粉（潮店/女性向、甜美霓虹）、霓虹青（科技复古、理性蓝光）、霓虹黄（暖市井、夜市烟火）。判断依据：内容情绪与品牌主色——账号想让霓虹色代表什么情绪，就选哪支；也可以让霓虹色固定成账号的招牌色，形成最高辨识度。
- **深档 vs 浅档占比**：夜向内容/音乐潮牌多深档，老城探店/回忆日常多浅档旧纸。判断依据：内容的时段感与场景——夜里发生的内容用深档，白天/回忆性的用浅档；可在一篇里按段落混用，制造"白天到夜晚"的节奏。
- **胶片满度**：可做黑白旧照或强烈颗粒胶片（更"旧"、更厚重），或淡暖调仅微旧（更"耐看"、更日常）。判断依据：读者对"旧"的厚重接受度——纪实/收藏向可重颗粒，日常消费向偏淡。
- **粤语点缀浓度**：粤语区读者可多点方言味，全国读者则只留 2–3 个通用词。判断依据：读者地域与接受度——账号后台读者大多在粤语区就放宽，面向全国就收紧。
- **霓虹密度**：青年潮流向可多霓虹，怀旧纪实向少霓虹、重暖调。判断依据：内容的年轻度与传播诉求——要"更潮更跳"就多点霓虹，要"稳、有味道"就压住。

> 以上留白点为可调参数，调用方应结合账号定位与读者画像落地，而不是机械地套用同一套数值。
