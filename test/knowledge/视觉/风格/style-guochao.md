# 国潮风（style-guochao）

> 定位：庄重、东方、仪式感，像一张红纸烫金的年礼卡片，既有节日热乎气又压得住场面。
> 调用时机：节日营销、传统文化、国货品牌、非遗节气、礼赠主题、周年庆，以及任何需要"东方美学 + 仪式感"的内容。

## 一、气质与适用内容

**气质关键词**：庄重、东方、仪式感、大气、厚重、节庆；红金墨是它的魂魄，对称与留白是它的骨架。

这是知识库里最有"情绪浓度"的一档风格。它不追求前卫或俏皮，追求的是让读者隔着屏幕也能感到"这份内容是被郑重对待的"。红是它的脉搏，金是它的荣光，墨是它的骨架——三者缺一不可。读者打开一篇国潮推文，第一眼要的不是"快、爽"，而是"讲究、有分量"。

**适合的内容类型与行业**（逐项说明为什么合适）：

- **节日营销**：春节、中秋、端午、元宵、国庆等节令企划。春节要热乎、中秋要团圆，这些情绪只有红金墨扛得住——红传达喜庆热闹，金传达贵重与祝福，墨压阵避免轻飘。节令内容本身自带"仪式期待"，国潮的对称横幅与祝词正好把这份期待接住，容易出氛围，也不会显得刻意。

- **文化内容**：非遗、节气、博物馆/文创、古风文化科普。这类内容自带历史厚度，读者看的是"文化的分量"而非"信息的轻快"。红金墨和印章、纹样天然贴合文物与传统，能帮读者建立"这是有根的东西"的第一印象，比现代花哨配色更可信，也更耐看。

- **国货品牌**：本土品牌发布、经典品牌焕新、礼赠产品线。国货现在普遍打"东方匠心""传承"牌，国潮正是这套话语的视觉回声。经典老字号用国潮显"底蕴"，新品礼赠用国潮显"讲究"，读者一眼读到"国货自信"与"品牌根脉"。

- **礼遇主题**：年货、好礼推荐、会员答谢、开业/周年庆。送礼场景最忌讳"随便"，国潮的仪式感把"这份心意是郑重的"写在了脸上。年货集市、答谢宴、周年贺词都适合用红金祝词收尾，把"礼"字立住，读者还没拆礼物就先感到被尊重。

- **东方审美向**：茶、香、器、衣、家居（新中式）等生活美学。茶器衣居这些品类本就源于东方，用国潮呈现是"风格即身份"——读者看的就是那股东方气韵。新中式家居配米纸底、留白和对称，比冷调现代风更贴合物件本身的温度，所谓"东西本来就这么好看"。

**不适合的场合**（逐项说明为什么是雷区）：

- **现代极客/硬核数码**：红金墨的庄重与锐利冷调天然冲突。数码测评要的是参数、速度、前沿感，国潮的热乎气和仪式感会让品牌显得外行、不专业，读者甚至会质疑你对产品的理解。

- **轻松俏皮/娱乐八卦**：国潮的仪式感会显得端着。娱乐内容要轻快、要梗、要自来熟，一上朱红横幅和祝词就像把段子念成了悼词，气氛全冷，读者想笑又笑不出来。

- **日常琐碎/极简主义**：繁的国潮与"少即是多"相悖。极简读者要的是呼吸感和通透，红金墨加纹样的繁复会让他们喘不过气，觉得闹、觉得吵，直接划走。

- **严肃医疗/法律/金融风控**：仪式感易冲淡专业审慎感。这类读者信任建立在冷静、严谨、零情绪上，红红火火的国潮会让他们误判为营销话术，反损可信度，甚至不敢采信内容。

- **明确走"洋气/国际现代"路线的品牌场景**：品牌人设已定国际感、极简、西式审美，突然插入国潮会让调性撕裂，读者认不出这个品牌。除非做明确的"本土回归"企划，否则别硬套。

**判断一句**：内容要传达"文化分量、东方仪式、礼遇之心"，就用国潮；要传达"快、轻、潮"，就别用。

## 二、完整色板表

```text
背景类（浅档为主）
  #FFF9EF        宣纸米：正文底色，纸感温润
  #FFF3DE        绢黄：装饰块/卡片底，如古绢
  #FBF0E0        浅杏黄：轻微分区
  #2B2118        墨黑（深档底）：隆重横幅/结尾卡用

主色类（三色联动，红金为魂、墨为骨）
  #C8102E / #C03A2B   朱红/枣红：主标题、主线点缀，国潮之魂
  #D4AF37 / #B8860B   鎏金：金边、金角、纯色金点缀
  #2B2118            墨黑：标题与正文骨架，厚重压阵

辅助色类
  #7A1F16            深红：次级强调、章节色
  #8C7A5B            棕褐调：辅助文字、线描
  #6B5B45            暖褐灰：注释色

强调色类（点睛，全篇克制）
  #D4AF37            金：边框/分隔线/装饰圆点
  #C8102E            朱红：重点词、印章红
  #1E6B5A 或 #3E6B5A   黛青：极少量冷色反衬（如丝缎青），增添层次

文字色类
  #2B2118            墨黑：正文主色与标题（避免纯黑替代，#2B2118 是暖调墨）
  #7A1F16            深红：强调词、副标题点缀
  #6B5B45            暖褐：注释/辅助
```

**每个色号的用法一句话**：

- `#FFF9EF` 宣纸米：通篇正文底色，约等于"默认白纸"，但更暖更温润，压住红色不让它刺眼。

- `#FFF3DE` 绢黄：重点气泡、卡片的内底，比宣纸米略暖一层，做出"古绢"的分区层次。

- `#FBF0E0` 浅杏黄：更轻的分区托底，用在次级色块，与绢黄拉开一级明度差。

- `#2B2118` 墨黑：深档横幅、结尾祝词的底，全篇 ≤2 处作压场；也是标题与正文的骨架色。

- `#C8102E` 朱红：主标题、主线点缀、按钮、印章红，是国潮的情绪担当，热烈正。

- `#C03A2B` 枣红：朱红的深档/庄重档，用于点缀线、次要强调，比朱红更沉稳少刺。

- `#D4AF37` 鎏金：金边、金角、金色分隔线、纯色金点缀，代表"贵重"，但只做点缀。

- `#B8860B` 暗金：金的深档/辅助版，深底上作次级金，比亮金更有年代感。

- `#7A1F16` 深红：章节色、副标题点缀、次级强调，比朱红低一档音量。

- `#8C7A5B` 棕褐调：辅助文字、线描、器物轮廓，低饱和不抢戏。

- `#6B5B45` 暖褐灰：注释、落款、辅助说明色，最安静的一档。

- `#1E6B5A / #3E6B5A` 黛青：极少量冷色反衬（一处丝缎青、一条黛青线），给通篇暖调透口气，全篇 ≤1 处。

**深浅两档怎么用（各单独成段说明切换）**：

**浅档（默认）**：宣纸米底 `#FFF9EF` + 红金点缀 + 墨字。适合大多数文化/节日内容——温润、有仪式、不压抑。切换要点：底色锁死宣纸米，红只要一处主线（标题或一条装饰线），金只走边框与分隔线，文字一律墨黑。这样浅档不会滑向"花"，也不会压成一团暗。

**由浅转深的衔接**：当一篇内容要从平常氛围过渡到"隆重时刻"（比如文化科普讲完要落一个庆典祝词），在深档横幅出现前，先用一条纯色朱红描边或朱红小横幅做"信号预热"，让读者感到"要压场了"，再上墨黑底，转折才不生硬。

**深档（隆重时刻）**：墨黑底 `#2B2118` + 金字 + 白/米字，用于**开篇横幅、结尾祝词、周年主视觉**这类"压场"处，全篇 ≤2 处。切换要点：上深档时把正文亮色提到白/米 `#F3E3C3` 级别，金字可用 `#E7C65C` 提亮防被墨底吞掉，朱红提亮到 `#E23B45` 保持识别。深档一出便是大气端庄，但只能点缀，不能通篇。

## 三、标题与字号层级

**标题样式特征**：**对称庄重**——居中大标题，下方纯色金边或双线装饰；或用"红底金字/墨底金字的印章式横幅标题"。刻意不歪不斜，追求稳与气场。标题是国潮的门面，读者先看标题再决定要不要读正文，所以标题务必"立得住"、居中、平衡、有仪式。

**装饰语法**（可直接套用）：

- 金字标题：标题字 `#D4AF37`（金），不加阴影、不加发光，纯金字配色即可稳而亮，靠底色对比出分量。

- 金边下边框：`border-bottom:2px solid #D4AF37`（纯色金线，不渐变），在标题底部画一条金细线，庄重又有层次。

- 印章式横幅：`background:#C8102E` + 白字/金字 + 小幅内边距 + 居中，像一枚朱文印章扩成横幅，开篇压场最有效。

- 双线装饰：标题上或下用 `border-top/bottom` 细金线做对称夹线，上下两条线夹住标题，规矩稳重。

- 章节小标：红 `#C8102E` 或深红 `#7A1F16` + 编号字样（壹/贰或 01），取「中式编号」的仪式感，章节一眼可辨。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 主标题（横幅/总标题） | 19–22px | bold | 居中对齐、红底金字或墨底金字 |
| 章节标题 | 16–18px | bold | 墨黑 + 下方纯色红金细线 |
| 小节/副标题 | 15px | 600 | 深红 或 暖褐 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px |
| 祝词/落款 | 14px | 600 | 结尾对称短句，金或深红 |

区块间距注意：标题上 28px 下 12px（硬规范）；横幅型主标题可上 30px 下 16px 稍宽松。正文行高 1.75，字距 0.5px，正文色建议用暖调墨 `#2B2118` 级别，避免纯黑大段。标题与下一段正文之间至少留 12px，让层级分明；居中的祝词类标题周围可再多留几行白，营造"落款感"。

## 四、模块表现

**重点气泡**：放"必读要点/核心结论"的盒子。宣纸绢黄底 `#FFF3DE` + `border:1px solid #D4AF37` 金字描边 + **圆角 6–8px**（偏方稳重，不用大圆角）+ 内层 `border:3px solid #C8102E`（细朱红内边，代替外金晕）+ `padding:14px 16px`（硬规范）。左边可加朱红 `border-left:4px solid #C8102E`。整体"金线框 + 细朱红内边 + 左侧朱红"三层强调，纯色金与红分层、不加金晕光、不加阴影，放在关键结论下，读者一眼锁定。

**卡片**：放多块并列内容的"收纳盒"。宣纸米/绢黄底 + `1px solid #E4CDA8` 暖金描边 + **圆角 6px** + 内文 `padding:14px 16px 12px`。顶部可加一条纯色朱红或鎏金横条当"页眉"（`border-bottom:4px solid #C03A2B` 夹一细金线，不渐变）。卡片间 16px。多做"一个卡片讲一个点"，上下排开，避免叠太密；卡片内文字用墨黑，卡名用朱红点缀。

**分隔线**：段落与段落之间的"呼吸口"。用**对称装饰**——纯色金线 + 居中一个几何圆点（span 正圆）或 art:// 叶角 leaf-corner。可用 `border-top:1px solid #D4AF37`，下方居中放一个主色小圆点或小草图案（一个，不堆叠）。分隔上下 24px。它既划开节奏，又保持中轴对称的仪式感，是最便宜也最见功力的东方元素，几乎每个国潮推文都会用到。

**花纹**：可选**浅档云纹/回纹/棋盘**的氛围（用低饱和纯色细线拼出的极浅几何底，近似宣纸色 #FFF3DE 级别，几乎不可见），或**角饰**——在卡片四角放纯色金角线（细边框拼角）。花纹全篇 ≤2 种且克制，作用是"隐隐有传统底子"，不是拿来炫技的，越隐越高级。底色用低饱和纯色与细线，不用渐变、不加投影。

**列表**：分点列示用「几何圆点 / 壹二叁」或朱红圆点（span 正圆）当符号；行距 1.75，字距 0.5px。分点之间留足前行距，营造"从容列陈"的仪式感。忌用 emoji/图标字符喧宾夺主，符号本身就带中式味，几何与数字符号比表情更有文人气。

**步骤**：**中式礼序步骤**——用中文数字「壹→贰→叁」+ 朱红字徽章（`background:#C8102E` 白字，圆角 4px 方徽章），或纯色金线连接的"礼程线"，把流程写出"走礼数"的庄重感。步骤间 16px，编号徽章宁小毋大，保持克制；若步骤很多（超过三步），可以三段为一组、组间再用金分隔线。

**CTA/结尾**：横幅式收尾——墨黑底 `#2B2118` + 金字居中短句（祝词），配一行朱红小字"公众号名称 / 品牌名"。整篇在最高潮处砸下一枚深档横幅，仪式感收满，纯色墨底金字、不加渐变不加光晕，是让读者记住品牌的关键一笔；结尾一句工整祝词比十句催促更打动人。

## 五、图片与装饰

- **图片处理**：圆角 **6–8px**（方正稳重），可配**宣纸/低饱和暖调滤镜**（淡黄提暖），或在图片四周加金线细框（`border:1px solid #D4AF37`）。比例多取 **3:4**（竖版器物/人物）或 **4:5**，器物、物件竖着拍更有"文房雅致"的味道。图片上下留 12px，别贴着文字。

- **氛围叠加**：可在图片一角叠一个低饱和纯色块角标或金字印章式水印（纯色块 + 细线框，不加渐变、不加投影），但别遮主体——水印只做"这图属于本文"的暗示，主体清楚是第一位的，过度叠加会显脏、显糊。

- **配图选择**：优先用有质感的实拍与高清文物/器物图，宣纸色、木色、瓷色等暖调背景的图最契合；避免冷白棚拍和过度修图的"电商脸"，那会破坏东方的温润感。

- **装饰**：**密度低**，国潮靠几何与文字符号不靠图标。全篇 **点缀每 8–10 行 ≤1 处**，且只做线条与色块，绝不用 emoji/Unicode 图标字符。多数场合用几何圆点、金线、中文数字（壹贰叁）等**文字符号**替代图标更有味道——图标是"热闹"的，国潮要的是"讲究"。

- **可用 art:// 植物图案**：国潮天然适合植物纹样做装饰——**vine-frame 藤蔓花框**（做标题花框/卡片边框）、**blossom-branch 花枝**（做标题旁题词小枝）、**leaf-corner 叶角**（做分隔线两端角饰）。引法：在正文用 `![说明](art://vine-frame)` 做标题边框，或用图案做气泡/标题角饰。植物是国潮"东方生机"的天然载体，绝不选用图标类图案。

## 六、文案调性

**语气关键词（单独成段）**：庄重、文雅、礼遇、情怀、仪式。整体字词有分量、不轻飘、不白话过量。要像请帖和贺词，不像刷屏段子。情绪靠"讲究的遣词"而不是"大声感叹"来传达，越克制越显厚重；宁可少说，也不要说得很廉价。

**句式倾向（单独成段说明）**：

- 用"礼遇""匠心""共赴""团圆""岁时""传承"等有文化重量的词，铺出东方语感。

- 偏爱对仗/短句、四字短语收尾（"明月共此时""一炉香，一纸山河"），念起来有节奏、好记，也方便转发。

- 主谓分明，少口水词；关键处可用一句工整的祝词压住节奏，一篇一两个"金句"就够。

- 感叹号克制，多用加点与排比制造仪式，而不是用大量感叹号嘶吼；段落间多用短句制造喘息与留白。

**示例句（可直接套用）**：

- "中秋礼遇，明月共此时——一份东方美学的团圆心意。"

- "一炉香，一纸山河。千年窑火未曾熄。"

- "把团圆的意头，烧进每一件器物的骨里。"

- "一席茶，半卷书，与你共赴这场东方之约。"

- "时岁有信，礼遇如期。把最好的时节，留给你。"

- "朱砂为印，鎏金为边，一份亲手备下的年礼。"

## 七、禁忌与陷阱

**1. 红金滥用、金光闪闪过度**：通篇金字金边金卡 → 俗气、晃眼、像暴发户。

反例：每个卡片都 `border:2px solid #D4AF37` + 金角 + 金渐变描边 + 外金晕光，读者满屏金光直接划走，越亮越廉价。

正解：**金是点缀不是底**——金走边框/分隔线/装饰点，底色交给宣纸米与墨，红是主线；金占比 ≤20%。一个界面只允许 1–2 处金子，其余靠结构撑，贵重感靠"少"而不是"闪"。

**2. 墨黑与纯黑混淆、通篇色太沉**：正文用 `#000` 纯黑 + 大量暗底 → 压抑没灵气，读起来像一张阴沉的讣告。

反例：正文标题全 `color:#000`，再叠两三块墨黑深档横幅，通篇阴沉，读者心情都被压暗。

正解：正文用暖调墨 `#2B2118`，深档只局部、≤2 处；留宣纸米的"亮"做呼吸，暗处和亮处要有节奏交替，该亮的亮、该压的压。

**3. 花纹堆满 + 印章乱贴**：每个模块都印一枚大印章 → 像盖章狂魔，混乱抓不住重点。

反例：标题一枚、每张卡一枚、结尾再来两枚，全篇六七处大朱印，读者眼花，重点全被冲散。

正解：印章/装饰元素全篇集中 ≤2 处（开篇 + 结尾），中间走干净的对称线——印章是"落款"，落多了就廉价，一处足显讲究。

**4. emoji/图标字符破坏气场**：金链标题后跟成串彩色小图形 → 庄重感崩盘，像中年表情包大联欢。

反例：标题后一行彩色小图形，把好不容易立的仪式感全冲掉，读者皱眉。

正解：装饰极克制、每 8–10 行 ≤1 处，用几何圆点、金线、中文数字或 art:// 植物图案；要情绪加一处 plant 小花即可，一处就够，多一处都是破功。

**5. 中西混杂**：红金墨大标题旁边放现代霓虹/极简纯黑区块 → 气质断裂，读者觉得"这不是一个东西"。

反例：横幅是红金底，旁边正文区却用 `#00E5FF` 霓虹描边卡，风格劈成两半，自相矛盾。

正解：全篇统一东方美学逻辑，混搭其他风格要非常克制（见第八节），辅风格最多做局部元素，不破坏主调。

## 八、混搭方向

- **国潮 × 敦煌青绿（主 7 : 辅 3）**：需要在东方美学上加一层艺术与壁画质感（见「敦煌青绿」变体条目），把绢黄换青绿山水，更适合博物院/文创——把浓烈国潮转成淡雅艺术向，更耐看，气质也更"雅"。

- **国潮 × 复古报纸（主 8 : 辅 2）**：历史文化盘点类内容，可加报刊徽章/分栏做"读史"的纸媒感，但保持红金主调，读者既读到历史感又不失品牌喜庆，适合做"那年今日""历史回顾"。

- **国潮 × 日系（主 8 : 辅 2）**：器皿/茶香生活美学，可用米纸的温润做底，国潮的红金做点缀——东方生活的气质相通，暖上加暖，越混越素雅，适合生活美学号。

- **国潮 × 极简（不可强混）**：两者气质相反，除非品牌明确要"新中式的克制留白"，大幅压低纹样和金色只留一点红，否则不鼓励，容易两不像、两头不讨好。

参照「风格混搭与主辅法则」：国潮做主风格要守它的仪式骨架，辅风格只做局部元素，主从分明，主风格的红金墨与对称骨架不能被动摇。

## 九、封面建议

- **构图**：**对称**是国潮封面铁律——中央主图形（圆月/印章/器物/书法字）+ 左右对称留白，或上圆下方（天圆地方）。对称稳住气场，不比对称的构图立刻显单薄，读者一眼看出"讲究"。

- **配色呼应**：红 `#C8102E` + 金 `#D4AF37` + 墨黑 `#2B2118` 三色；背景用宣纸米或墨黑深档，看节日与隆重程度——寻常节日走宣纸米，周年/大促走墨黑深档，更要隆重的才压满墨。

- **字**：书法感大字标题 ≤6 字，可配一枚小印章（品牌名/栏目名），主字一眼看清、印章添分量，不要塞进太多字，字越少越有章法。

- **留白**：别塞满，对称 + 留白 = 大气。节日可加月/灯笼等单一大图形，一个就够，多则乱。封面的空比满更高级，别把封面当海报贴满。

## 十、深色模式表现

- 国潮的**墨黑深档本来就是深色美**：深档头图/横幅在暗黑下依然大气，金字 `#D4AF37` 在深底上不够亮可提亮到 `#E7C65C`，深色里更醒目。

- 宣纸米底 `#FFF9EF` 在深色模式下改为墨黑 `#201a14` 底 + 米字 `#EAD9C0`，金字保持——这样深色读者看到的是"墨底米字"，不刺眼且仍暖，仪式感不打折。

- 朱红 `#C8102E` 在深底上偏暗，可提亮为 `#E23B45` 保持识别；深红 `#7A1F16` 在深底上更要提高亮度，否则看不清成一片黑红，形同虚设。

- 纯色金边 `border:1px solid #D4AF37` 在纯深底上仍可清晰呈现；想在深底强调一句，用一条纯色朱红/金的细实线即可，注意别过亮刺眼，调一档低饱和即可。

- 提示：国潮默认浅档温和，深色模式读者多时建议整篇偏暖墨底，保持仪式感与可读，别让深色模式读成"一团黑"；黛青这类冷色反衬在深底上可略提亮，别丢。

## 十一、个性化空间

**哪些参数可按账号/读者自定，每项给判断依据**：

- **品牌主色替换**：国货品牌常有固定品牌色（红/金之外的品牌专属色），可把朱红换成品牌红或品牌主色，金与墨保留成东方骨架。判断依据：品牌视觉统一优先；若品牌是青色/绿色系，走敦煌青绿方向更合适（见国潮 ×敦煌混搭）。

- **金的比例**：偏高端礼赠/老品牌可提高金的比例（更贵重），偏文化科普可降金、加墨与留白（更文雅）。判断依据：内容是想"显贵重"还是"显沉静"——礼品金多、科普墨多，这一条最直接影响档次感。

- **中西文化倾向**：纯传统非遗可更"古"（多纹样、多印章），现代新中式生活美学可更"简"（少纹、多留白、加现代排版线）。判断依据：目标读者对传统与现代的偏好——艺术向重传统，年轻向重简化。

- **节日浓淡**：春节年货可高饱和红多、金多、热闹满；平日文化栏目可降饱和、多留白。判断依据：节令氛围与内容性质——大节的"满"是应景，平日的"空"是气质，浓淡要有计划。

- **纹样/装饰密度**：读者是文艺收藏向可多文物纹样感，年轻人消费向可适当活泼一点但不失庄重主体。判断依据：读者圈层年纪与收藏偏好，仍以庄重为底线。

- **深档份量**：周年庆、礼赠答谢可多一处墨黑深档压场；平日轻量科普可几乎不用深档。判断依据：内容的分量与隆重程度，深档是"礼遇的顶点"，别平均分配。

以上每一处留白都是"可调参数"，调用方需结合具体账号与读者判断，不要机械套用固定值。
