# 波普艺术（网点、漫画框）

> 定位：插画风格的**子系变体**。波普（Pop Art）把插画的活泼升级成「戏谑、艺术、有点呐喊」的表达——用网点、漫画框、撞色描边、重复的人像/图标，制造夸张的视觉力量。
> 适用对象：戏谑向、艺术向、年轻化、话题性、反差萌内容。调用方：排版时加入「纯色网点、漫画对话框、黑白描边、重复图形」。

## 一、属于哪个顶层风格的子系

- **母风格：插画风格**（快消、母婴、娱乐、促销、文创）。本变体继承插画的高饱和与夸张，但把「可爱圆润」换成「硬朗的漫画/标语感」。
- **一句话**：内容带「反讽、口号、艺术腔、要喊出口」的气质时，从插画切到波普。

### 何时用本变体，而不是直接用插画母风格

| 内容状态 | 选择 | 理由 |
|---|---|---|
| 需要可爱、圆润、亲和地"讲故事" | 插画风格（母） | 可爱形象更适合温柔带货与亲子向，波普太"硬" |
| 要"喊口号、有态度、有艺术腔"的表达 | **波普艺术（本变体）** | 漫画框 + 大字标语 + 网点是"喊出来"的语言 |
| 做话题性、反差、戏谑玩笑的内容 | **波普艺术（本变体）** | 波普天生的夸张正好接住"敢说敢玩"的调性 |
| 常规促销需冲动热量 | 插画风格（母） | 促销要的是冲动好感，波普的戏谑可能冲淡转化 |

判断尺：**内容要"表达一种态度/腔调"而非"讨好可爱"时，从插画切到波普**。

## 二、与母风格的差异点

| 对比维度 | 插画风格（母） | 波普艺术（本变体） |
|---|---|---|
| 视觉元素 | 圆润可爱插画 | **纯色网点、漫画对话框、黑白粗描边、重复人像/图形、印章式标语** |
| 色板 | 高饱和撞色 + 奶油底 | **红黄蓝白黑经典四色 + 少量粉** |
| 描边 | 细/粗白描边 | **粗黑描边（2-3px），强调轮廓分明** |
| 标题 | 圆角 banner | **漫画框标题（对话框/爆炸框）+ 大字标语** |
| 气质 | 活泼、可爱、热闹 | **戏谑、艺术、夸张、有态度** |

- **力度区别**：插画的"快乐"是温暖轻松的，波普的"夸张"是响亮、略带挑衅的——它更接近海报与街头艺术，不是"哄你开心"。
- **重复区别**：波普喜欢"重复同一图形/同一句话"，制造罗夏测试式的复制感，这是插画通常不用的手法。

## 三、完整色板

> 波普讲究「极少的颜色，极大的力量」。经典四色红黄蓝 + 黑白，可加一个粉作柔化。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FFFFFF`（白） | 主打底色，白得多才显波普的「印刷感」 |
| 主色1 | `#E62B2B`（正红） | 主强调、图形、标题底 |
| 主色2 | `#F5C518`（金黄） | 辅助强调、墨点衬底 |
| 主色3 | `#2B5BE6`（群青蓝） | 图形/文字强调，与红互补 |
| 辅助色 | `#FF6FA5`（粉） | 柔化点缀、小图形 |
| 网点色 | 主色之一（常用金黄/群青） | 用纯色网点（重复的圆形色点纹理，平面印刷感，非平滑渐变） |
| 文字/描边 | `#111111`（近黑）+ `#FFFFFF`（白） | 粗描边、印章字、正文 |
| 正文文字 | `#2B2424`（暖黑） | 正文用色 |
| 次级文字 | `#8A7F7F`（暖灰） | 注释、图注 |

**每个色号一句话用法**：

- `#FFFFFF` 白：主打底，白得多才显"印刷感"，也是反黑描边字体的用色。
- `#E62B2B` 正红：主强调与标题底，波普的"第一声呐喊"，别和金黄色底同屏抢。
- `#F5C518` 金黄：辅助强调与网点衬底，柔和一点的热度，常用作网点的源头色。
- `#2B5BE6` 群青蓝：与红互补的冷锚点，图形/文字强调，制造撞色的"冷静对比"。
- `#FF6FA5` 粉：柔化点缀与小图形，只在"少女波普"或小面积用得深色的地方出现。
- `#111111` 近黑：粗描边与印章字，波普的标志，没有它波普就稀释成普通插画。
- `#2B2424` 暖黑：正文主色，压住阅读重心。
- `#8A7F7F` 暖灰：注释、图注，弱化但可读。

**配色规律**：一屏内主要「红 + 黑 + 白」，金黄与群青做分区或点缀；粉只用于小图形软化和「少女波普」场合。整篇亮色 ≤4 个，网点的颜色从这 4 个里取，别单独新开色。

**深浅档切换**：白底配大字是波普的"日间印刷感"；做"夜场、演出、街头艺术"氛围时可切一段深色底（暖黑 `#211D1D` + 提亮三色 + 浅色描边），**深档每篇 ≤2 处**，专放最"炸"的高潮段。深档必须保留明暗对比，别让红蓝金在深底上发闷。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | **漫画爆炸框**（不规则圆角描边）+ 内放粗黑大字；或印章式方框 | `POW! 年轻，就是要喊出来` |
| 章节小标题 | 行首加一个纯色对话框三角（三角形色块）+ 彩色粗字 | `网点里的旧时光`（行首一枚三角色块） |
| 重点句 | 金色高亮 + 黑描边仿印章；或用纯色对话框承载 | `[ 敢想，才敢做 ]` |

- 字号：大标题 22-24px，章节 18px，正文 15px，注释 13px。
- 标题可加粗 `font-weight:900`，字距 1-2px，正文 0.5px，行距 1.75。

**爆炸框的写法**：`<span style="display:inline-block;background:#E62B2B;color:#fff;font-weight:900;padding:6px 14px;border:3px solid #111;border-radius:4px 18px 8px 22px / 18px 6px 20px 8px;">POW!</span>`——不规则圆角让边框"炸开"一点，比等圆更漫画。

## 五、模块表现

- **重点气泡**：做成**漫画对话框**——白底 + 3px 黑描边 + 带一个指向角（可用小三角元素/图形）；或爆炸形（不规则圆角）。内文 14px 暖黑 + 黑描边强调词。
- **卡片**：白底 + 3px 黑描边 + 硬圆角 6px + `padding:14px 16px`，靠粗描边与色块制造"印刷贴纸"的平面层次；需区分时换红/金黄底。
- **分割线**：用一串重复的纯色实心方块/三角（平面交替）或「印刷感」斜纹长条；上下 24px。
- **花纹色带**：**纯色网点**（重复的圆形色点纹理，平面印刷感，非平滑渐变）铺成一条；或斜纹「印刷感」；≤2 处。
- **列表**：圆点换成「印章圆点」或对话框；数字用爆炸徽章。
- **图片**：给图加 3px 黑描边 + 白底 offset，像印出来的贴纸；可重复同一图数次制造「罗夏/复制」效果。

**一个漫画对话框的骨架**：

```html
<div style="background:#fff;border:3px solid #111;border-radius:10px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0;color:#2B2424;font-weight:900;line-height:1.75;">
    这句重点，用"喊出来"的方式说！
  </p>
</div>
```

要点：对话框只用最要紧的 1-2 处，别通篇都是对话气泡；黑描边粗而清晰，内文白底黑字才有"印刷张贴"的力度。

**一个印章式标语的骨架**：

```html
<p style="text-align:center;margin:0 0 16px;font-weight:900;color:#F5C518;background:#E62B2B;border:3px solid #111;border-radius:4px;padding:8px 16px;display:inline-block;">
  [ 敢想，才敢做 ]
</p>
```

要点：印章框圆角做小（4px）更"盖章"；金字红底黑框三层对比让标语"跳"出来，一篇最多放 1-2 条，别让整页都盖章。

## 六、图片处理与装饰

- 图片：强烈推荐**图片转「印刷网点/高对比」效果**（如有条件），或至少加粗黑描边 + 纯色底块衬托。
- 可把图片裁成圆或方、压上深色填充，重复贴同图制造「复制感」；别让图片太"真实细腻"而失去波普的印刷感。
- 装饰克制：图案/几何点缀每屏 ≤1 处，宁可留白。波普的力量在图形与字体，不在图案字符；装饰只做「对话框气泡 / 纯色角标」这类功能点缀。图案资产只可用植物/自然类并统一平面线条化：如 `vine-frame` 藤蔓花框、`sprig-grass` 小草、`blossom-branch` 花枝、`leaf-corner` 叶角——在正文用 `![说明](art://资产名)` 引用，绝不用图标类图案。
- 重复元素密度：整篇 ≤6 处重复图形/网点区，集中在标题与分区，正文保持白底黑字可读。

## 七、禁忌与陷阱

1. **别用卡通渐变**：波普反「柔化」，别用粉彩渐变、圆润柔光；要硬边、平面、高对比。
2. **别丢黑色描边**：没有粗黑描边的波普会稀释成普通插画，黑边是波普的标志。
3. **别一次上满所有色**：红黄蓝全堆一屏是灾难，一屏锁定 1 个主色 + 黑 + 白。
4. **别让网点抢正文**：网点只做色带/底色，正文区不用网点铺底，否则 15px 字会被墨点干扰。
5. **别用太过可爱的 emoji/贴纸**：与波普的「艺术腔」冲突，除非走少女波普（那另说）。
6. **别把标语写太满**：大字标语是"一击命中"的，一段刷三个感叹号、三句口号会让力度解散，一句最响的就够。
7. **别忽略深色下的网点**：网点色若不在深底提亮、不能看清，就失去"印刷质感"这个关键锚点。

## 八、混搭方向

- **+ 孟菲斯**：两者都玩几何撞色，孟菲斯收掉网点和漫画框、波普收掉波浪线，共享黑白斜纹很顺（见孟菲斯条目）。
- **+ 复古港风**：港风霓虹 + 波普网点，适合「本土艺术/街头文化」内容。
- **+ 插画（母）**：需保留一点可爱形象时，用波普做边框与大字、插画做画面主体，是"态度插画"。
- **- 禁忌**：别混日系（纸感温柔冲突）、别混商务（克制冲突）、别混极简（装饰多与少即是多冲突）、别混森系（自然清新冲突）。

## 九、封面与首屏建议

- 封面：经典波普「人像/产品 + 网点背景 + 大字标语」构图，红黑黄撞色。
- 首屏：一条纯色网点页眉 + 漫画爆炸框大标题，制造「我要喊出来」的第一印象。
- 配色呼应：白底 + 正红/金黄大字 + 黑描边 + 网点背景，封面与正文同用"印刷感"的色系，点进去不跳戏。

## 十、深色模式表现

- 深色下：白底换暖黑 `#211D1D`，红蓝金三色为保持对比提亮一位（红 `#FF4444`、蓝 `#4D7CFF`、金 `#FFD24D`）；网点颜色同步提亮，黑描边换浅描边 `#FFFFFF` 或 `#F5EBDD`。
- 波普在深色模式表现抢眼，但注意大字仍须足够对比。
- 深色下的网点条要保证墨点与深底的明度差，否则网点会"融"进背景、失去印刷质感。

## 十一、个性化留白（按账号自定）

- **色板 X 型**：经典红黄蓝（艺术型）／粉黄青（少女波普）／黑白 + 单彩（极简波普）——按目标读者审美与内容调性选。
- **网点密度**：低（仅色带/标题）／中（每屏一处）／高（背景全铺网点）——结合账号设计向程度与图片质量（网点对画质要求高）。
- **漫画框用量**：仅标题用／重点句也用／整篇对话框叙事（漫画体）——看是否做「分镜感」内容。
- **是否做重复复制图**：做（罗夏感、街头感）／不做（更克制）——看内容要"戏剧化"还是"收着喊"。
- 判断依据：读者年龄、内容艺术/话题属性、封面图质量可行性。

**给调用方的复查三问**：一、一屏是不是红/黑/白为主，没有让红黄蓝同时挤爆？二、粗黑描边有没有守住、网点有没有只做装饰没抢正文？三、那句"要喊出口"的标语是否够短够响、没有被三段口号冲散力度？

**波普的"活"在哪**：同样的四色配方之下，波普比的是"谁把态度喊得刚刚好"——一处粗黑描边、一处网点、一句响亮的标语，就足够把"有态度"立起来。大喊也要懂，音量调到最响的那一句，才叫艺术。
