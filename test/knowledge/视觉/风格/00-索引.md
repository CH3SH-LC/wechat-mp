# 风格方向索引（视觉 / 风格）

> 定位：解决「这篇推文用什么视觉风格、风格如何填充组件模板」——每种风格给出气质/色板/标题层级/各模块表现/图案词汇表，填入组件模板的零件位。
> 用法：先看「风格选择速查」，锁定候选风格后读对应条目文件；拿不准时读 style-guide-choose。
> 交叉：风格条目的文案调性参见 文本/文案 各条目；组件模板（零件位）见 模块 方向；封面呼应参见 其它/封面。

## 三、风格条目的统一结构（每个风格条目都含）

气质定位 → 适用内容与行业 → 完整色板表（背景/主色/辅助/强调/文字五类）→ 标题与字号层级 → 模块表现（气泡/卡片/分割线/花纹如何取该风格）→ 图片处理与图案装饰（零 emoji/零图标字符，art:// 植物图案）→ 禁忌与陷阱 → 混搭方向 → 封面建议 → 深色模式表现 → 个性化留白（哪些参数按账号自定）
