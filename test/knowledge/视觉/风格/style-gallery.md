# 艺术画廊风（style-gallery）

> 定位：展馆、留白、衬线、艺术性，像一间白墙画廊里挂着一幅幅画和一行行作品说明，安静、高级、有审美。

> 调用时机：艺术展览、设计/策展、文创机构、高端品牌、拍卖收藏、艺术家/作品介绍，以及一切要"像进美术馆看展、安静又高级"的内容。

## 一、气质与适用内容

**气质关键词**：展馆、留白、衬线、艺术、克制、审美。衬线 + 大幅留白 + 画框卡是它的三段签名。

这个风格像一间白墙画廊——墙面纯净、只有一幅幅画和一行行作品说明。它不喧哗，靠"空"和"克制"把读者的注意力送回作品本身上去。推文要让人感到"在看展"，而不是"在看广告"。

**适合的内容类型与行业**（逐项说明为什么合适）：

- **艺术展览**（展讯、看展记、作品导览、策展理念）：这是它的原生场景。展讯要传达"值得安静去看"，画廊的留白和作品签天然承接这种语境，氛围一步到位。
- **设计创意**（平面/空间/产品/时装设计）：审美是这类内容的核心资产。黑白灰的大留白能把设计作品衬托得干净利落，不抢作品的戏。
- **文创机构**（美术馆、博物馆、画廊、文化基金、书店艺术线）：机构形象本身就要"高级、可信、有底蕴"，艺术画廊风正好把这份格调穿在身上。
- **高端品牌**（奢侈品、高端体验、艺术联名、品牌美学）：品牌想要的不只是卖货，而是"有品位"。画廊的克制精准贴合高端叙事的慢节奏。
- **拍卖收藏**（藏品介绍、拍卖企划、艺术家专题）：藏品的价值来自"它是一件有来头的珍品"。画廊的画框与作品签能把藏品抬到"值得收藏"的台面上。

**不适合的场合**（逐项说明为什么是雷区）：

- **快节奏促销、娱乐狂欢、电商大促**：画廊的"静"和促销的热闹直接冲突。读者冲着剁手来，画廊的留白反而让"马上买"的冲动冷下来。
- **超密集工具清单、赶时效的资讯聚合**：它是"慢下来看一件好的"，扛不住又密又急的信息堆，读者会嫌它"太慢太绕"。
- **接地气的民生快消、日常生活猛料**：太具象的热闹生活，和画廊的抽离感对不上，显得装、也显得远。
- **高温情绪化内容**：它要娓娓道来、保持冷静，扛不住大起大伏的情绪，读者想要的热烈它给不了。

**判断一句**：内容要"像逛展、重审美、安静高级"，艺术画廊风正中；要"热闹促销、快节奏抓眼球"，就别用它。

**该风格区别于相邻风格的地方**：

- 比"极简风"多一点"展馆语境"——它也有空，但空是为了展品让位，而不只是为省。
- 比"杂志编辑风"多一点"留白的仪式感"，它是墙上的画，而不是页面上排版的字。
- 比"商务风"多一点艺术气质，克制里带着审美判断，不是冷冰冰的公式。

## 二、完整色板表

```text
背景类（白墙系）
  #FFFFFF        纯白底：正文底色，画廊白墙
  #F7F7F7        极浅灰：弱分区，美术馆地面灰
  #F2F0EC        米白：暖一点的画廊纸墙（可选）
  #111111        近黑（深档底）：暗展厅/压场

主色类（黑白灰 + 单强调）
  #111111        近黑：标题/主骨架，够重
  #1A1A1A        深灰黑：结构
  #4A4A4A        中灰：次级结构

辅助色类
  #8A8A8A        次级灰：注释/作品信息
  #B5B5B5        浅灰：分隔线/弱化
  #E5E5E5        极浅灰线：画框边线

强调色类（画廊里唯一"上墙的高光"，全篇 1 个）
  #8C1D18        赭石红：极经典，像画廊标签/印章
  #2E5A8C        钴蓝：理性文艺
  #7A6A55        陶土棕：暖艺收藏（任选其一贯穿）

文字色类
  #111111 / #1A1A1A   近黑：标题
  #2B2B2B            正文主色（避免纯黑刺眼）
  #6B6B6B            次级灰、注释/作品信息
```

**每个色号怎么用（逐条落点）**：

- **纯白 `#FFFFFF`**：正文底色，画廊白墙，是所有留白的起点。
- **极浅灰 `#F7F7F7`**：给弱分区、引语卡换底，像美术馆的地面灰，比白多一层"地面感"。
- **米白 `#F2F0EC`**：可选暖纸墙，适合老派暖美术馆，比纯白多一分温度与年份。
- **近黑 `#111111`**：深档的底、标题的主骨架，够重、够压场。
- **深灰黑 `#1A1A1A`**：结构、次级标题，比纯黑多一层灰、更耐看。
- **中灰 `#4A4A4A`**：次级结构、强调性内容的分层。
- **次级灰 `#8A8A8A`**：注释、作品信息，退到作品签的位置。
- **浅灰 `#B5B5B5`**：分隔线、弱化元素，细而淡。
- **极浅灰线 `#E5E5E5`**：画框的边线，几乎看不见的优雅。
- **赭石红 `#8C1D18`**：经典强调色，像画廊的标签/印章，给重点作品盖章（三选一）。
- **钴蓝 `#2E5A8C`**：理性文艺的强调色，适合现代设计（三选一）。
- **陶土棕 `#7A6A55`**：暖艺收藏的强调色，适合陶艺/暖款（三选一）。
- **正文主色 `#2B2B2B`**：正文主字，避免纯黑刺眼。
- **次级灰 `#6B6B6B`**：注释、作品信息，比正文浅一档。

**浅档（默认·白墙挡）怎么切换**：

浅档是画廊的本体——纯白墙底 `#FFFFFF` + 黑字 + 唯一强调色 + 大留白。白墙一铺，安静高级的"展馆感"就立住了。浅档适用于绝大多数正文：展讯、看展记、作品导览都在白墙上读。想让某一处多一层"地面灰"，就把 `#F7F7F7` 用在引语卡、弱分区上，但白色始终是底色。

**深档（暗展厅挡）怎么切换**：

深档只在压场开场、作品高亮、结尾这类"特展"位置用——近黑底 `#111111` + 白字 + 强调色，像画廊的暗厅与特展。暗厅一出，更有"沉浸看展"的仪式感。但深档**全篇 ≤2 处**，用多了会让整篇失去白墙的开阔。正文不进深档，深档是"特展"、浅档才是"日常展厅"。

## 三、标题与字号层级

**标题样式特征**：衬线感大标题 + 作品标签式副标——标题偏大、字距舒展、可有衬线/细字重，像展厅入口墙上的字。配"作品名 + 艺术家 + 年份"式的信息小字，整个标题就是一块展签。

**装饰语法**（可参考写法）：

- **衬线大标题**：大号标题 + 略衬线观感（字号大 + 细字重 + 字距放宽），黑字，字距的舒展是画廊的高级感来源。
- **作品标签**：标题下方排一行小字（如「《作品名》 · 艺术家 · 2024」），用浅灰 `#8A8A8A` + 字距，像美术馆墙上的说明签。
- **左竖条/细线**：章节标题用极细左竖线（`border-left:3px solid #111111`）+ 大留白，像目录上的指引。
- **强调色小标**：唯一强调色用于"重点作品/结论"，用 `<span>` 赭石红或钴蓝小标签。
- **引语（策展人语）**：用斜体/浅灰做一段策展人引言，带画廊气息，克制而有分量。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 展名/总标题 | 22–24px | 600–bold | 衬线观感大字 + 作品标签 |
| 章节标题 | 17–18px | 600 | 黑字 + 极细竖线 |
| 小节/副标题 | 15px | 600 | 深灰 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 作品信息/注释 | 13px | normal | 浅灰 + 字距放宽 |

> 艺术画廊风尤其重留白：标题上 28–36px、下 12–16px（可在硬规范基础上加大上留白给大字与"展签"呼吸），正文保持标准块距 16px。

**标题不要做什么**：不要用粗黑填充块当标题（会太重、失去"空"）；不要在标题旁堆一排卡通 emoji 或贴纸；字距不要收太紧（画廊的从容来自字与字的距离）；纯白底上别用 #FFFFFF 白字。

## 四、模块表现

**重点气泡/引语卡（策展人语）**：不用厚重气泡，用"策展人语"引语卡——白底无边框或极浅 `#F7F7F7` + 左侧 `border-left:3px solid #111111` + 大号引语（16-17px 600）+ `padding:14px 16px`（硬规范）+ 周围大留白。整段像一句话被安静地挂在展厅墙上。

**画框卡**：画廊专属——作品画框卡：白底 + `border:1px solid #E5E5E5` 细框 + **圆角 0px**（直角画框，不圆润）+ 四周大留白 + 窗垫 `padding:20px`，内放作品图/文字，下方一行作品信息小字（浅灰）。这是画廊的签名模块，像裱好的一幅画。

**卡片**：白/极浅灰底 + `1px solid #E5E5E5` + **圆角 4px** + `padding:14px 16px 12px`。不加彩色底部、不加阴影，让卡片只靠一条细边分出层次。卡片间 16px。

**分割线**：细长细线——`border-top:1px solid #E5E5E5`，上下留白大（上 32px 下 24px 可选）；细分隔用 `border-bottom:1px solid #E5E5E5`。画廊的分割要"几乎看不见"的优雅，所以线极浅、留白极大。

**花纹**：无花纹——艺术画廊风最忌底纹，白墙与留白就是它的一切，不设格纹、波点、条纹。任何花纹都会立刻把"展厅"拉回"装饰页"。

**列表**：作品清单式——每条一个作品名（可加编号 01/02）+ 一句话说明 + 下方一条细线分隔，像展览目录。行距 1.75。忌 emoji 列表。

**步骤/观赏路线**：观展动线——"第一展厅→第二展厅"式的动线叙述，用编号 Ⅰ Ⅱ Ⅲ 或 01/02 + 作品卡，带读者按顺序走完。步骤间 16px。

## 五、图片与装饰

**图片处理**：画框式——直角或极微圆角（`border-radius:0` 直角最画廊），配白边/留白像"裱纸"，或直接原图 + 大留白。滤镜倾向中性/高质感（不过饱和、可轻微偏冷或中性）。比例随作品，多取 4:3 或原图比例，不必硬裁。

**布置**：把图片当"画框卡"处理，上下留白大，像一幅画挂在墙上，而不是一张贴图糊在页面上。

**作品信息签**：每张图下方配一行作品信息（名称/艺术家/年份/材质），用浅灰 `#8A8A8A`、13px、字距放宽。这是画廊风的"血条"——没有它，图就只是图；有了它，图才是一幅作品。

**装饰克制**：近于零——艺术画廊风基本不用图标装饰，一切靠排版、留白与文字表达。要标记用「Ⅰ Ⅱ Ⅲ / · / —」或 CSS 极细线（`span` 拼细线，`#E5E5E5`）符号。图案若需点缀只用 `![说明](art://leaf-corner)` 叶角一类极淡草木角饰，圆角 8px，绝不喧宾夺主。

## 六、文案调性

**语气关键词**：观赏、策展、娓娓道来、克制、审慎、有审美。像导览解说和策展人语，不喧哗，靠分寸让人信服。

**句式倾向**：

- 用策展/导览口吻（"让我们走近这件作品""艺术家在此……"），把自己放在"带你看"的位置。
- 句子舒缓、留白，重描述与感受，少推销、多呈现，让作品自己说话。
- 用作品/艺术术语但配解释，让不专业的大众也能读懂。
- 结尾收在一个"观后/策展人按语"，给整篇一个安静的回味。

**语气怎么落到不同内容**：展讯多用导览邀请（"本周起，欢迎来看"）；作品介绍重描述与背景（"这件长 3 米的重器，是艺术家 2021 年的一组实验"）；品牌/机构稿重理念与克制（"把极简还给自己"）；拍卖收藏重价值与来头（"它替一个时代安静开口"）。

**可直接套用的示例句**：

- "策展人语：安静，是对美的最高礼遇。"
- "当目光落在这件重器上，你会先看见一份克制。"
- "走过七个展厅，我们想把这件《共生》留给你久一点。"
- "藏品之所以珍贵，是它替一个时代安静开口。"
- "我们不急着让你看完，只愿你记住这一刻。"

## 七、禁忌与陷阱

1. **圆润/卡通装饰破坏展馆感**：大圆角气泡、emoji 列表、贴纸一进来，画廊就变成儿童手账。
   **反例**：作品卡做大圆角 + 放一堆卡通 emoji。
   **正解**：直角画框、无 emoji、留白为主。画廊是"静"不是"甜"。

2. **配色失控/彩色多**：多主色 + emoji 色块一起上，高级感当场崩。
   **反例**：标题红、蓝、黄全彩铺开。
   **正解**：近黑 + 白墙 + 1 个强调色贯穿，强调色只给高光（作品/结论）用，一次一色。

3. **装饰堆叠**：衬线 + 双线 + 画框 + 编号 + 引语全摞在一起，就失去画廊的"空"。
   **反例**：一个作品卡上又有衬线标题、又叠双线框、又加编号徽章。
   **正解**：一个模块一个手段——作品卡就画框 + 作品签；标题就衬线字 + 极细线；引语就左竖线。别叠。

4. **忽略"注脚/导览"价值**：只有图没有作品说明、没有策展人语，画廊的"信息签"缺位，显得空洞。
   **反例**：通篇放图没有任何作品信息签。
   **正解**：作品旁配一行信息签（名称/艺术家/年份）或一段导览，画廊风才完整。

5. **可读性翻车**：浅灰字放白底过浅、或深档里灰字过深，读者看不清。
   **反例**：`#B5B5B5` 注释放 `#FFFFFF` 底，肉眼几乎看不见。
   **正解**：正文用 `#2B2B2B`，注释至少 `#6B6B6B`；深档用白/浅灰字。

## 八、混搭方向

- **艺术画廊 × 极简（主 7 : 辅 3）**：品牌/设计内容，画廊的衬线画框 + 极简的黑白克制，同一套"少即是多"的语言。
- **艺术画廊 × 杂志编辑风（主 6 : 辅 4）**：艺术人物/深度，画廊的展签 + 杂志的大字头版，编辑力 + 美术馆（见「杂志编辑风」条目）。
- **艺术画廊 × 国潮（主 7 : 辅 3）**：中国艺术/博物馆内容，画廊白墙 + 国潮红金墨，东方的展厅感。
- **艺术画廊 × 日系（主 8 : 辅 2）**：日式美学/器物展，画廊的留白 + 日系的米纸暖，禅意契合。

混搭时始终有一方为主。做主就守白墙留白 + 衬线画框这套签名；做辅只借画廊一个元素（一帧作品画框、一行展签），别让两套装饰同时铺满。参照「风格混搭与主辅法则」。

## 九、封面建议

- **构图**：展厅画框感——一张大幅作品 + 大留白 + 题字，像美术馆入口或一条展签，用"挂在白墙的装裱画"为主体构图。
- **配色呼应**：白墙 `#FFFFFF` / 极浅灰 `#F7F7F7` 底 + 近黑字 + 唯一强调色小标；深档暗厅 `#111111` + 白字 + 强调色。
- **字**：展名大标题 ≤6 字 + 一行作品标签小字；副标一句导览。
- **气质**：安静、高级、美术馆入口感，让人想点进去"看看展"。
- **翻车补救**：图太满、缺留白 → 四周多留白再放"装裱画"；纯白底太空 → 加一行作品信息签或一条极细导览线；标题太挤 → 字距放宽。

## 十、深色模式表现

- 艺术画廊风的暗展厅深档在暗黑下很适合：近黑底 + 白字 + 强调色，沉浸看展感强。暗黑模式其实是画廊风格的优势区。
- 白墙浅档在深色模式下改为近黑 `#111111` 底 + 白字 `#FFFFFF`/`#E6E6E6`；浅灰字 `#B5B5B5` 提亮为 `#9C9C9C`。
- 强调色（赭石红/钴蓝）在深底上略微提亮保对比（赭石 `#A65A50`、钴蓝 `#5B78C0`）。
- 白边画框卡在深底上取消白边，改用 `1px solid #3A3A3A` 深灰细框。
- 画廊对对比度极敏感，弱化元素必须与底有明显区分，深色模式尤其要留意。
- **深浅切换口诀**：白墙转暗厅、字转白/浅灰、强调色提亮一档，黑白灰的"空"一定要保住。

## 十一、个性化空间

- **强调色归属**：画廊风最要紧的自由度——赭石红（传统美术馆/收藏）、钴蓝（现代/理性设计）、陶土棕（陶艺/暖艺）。**判断依据**：品牌色与艺术气质；可让强调色成为账号的代表高光色。
- **"白墙"冷暖**：可用纯白或米白 `#F2F0EC` 做纸墙暖调。**判断依据**：内容是"现代白盒子"还是"老派暖美术馆"。
- **衬线 vs 无衬线**：大标题字距放宽、细字重可营造衬线观感。**判断依据**：品牌现代感 vs 经典感——现代设计偏无衬线留白，收藏/经典偏衬线感。
- **留白幅度**：收藏/策展向可极大留白；面向大众的设计科普可稍密一点、多步骤卡保理解。**判断依据**：读者审美层次与信息需求。
- **深档暗厅频率**：重"沉浸特展"的内容可多一处暗厅，日常艺术资讯保持浅档白墙。**判断依据**：内容属性与节奏。

**落地检查清单**：白墙底非花哨色；锁定 1 个强调色贯穿；画框卡用直角 + 细框；正文行高 1.75、块距 16px、气泡 padding 14px 16px；标题留白 28–36px 上；无 emoji、无底纹；每处作品配一行信息签。

以上留白点为可调参数，调用方应结合账号与读者落地，画廊风的灵魂是"克制与审美"——调可以，别堆。
