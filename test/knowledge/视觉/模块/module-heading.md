# 章节标题（module-heading）

> 定位：正文内部「分节的锚点」，用 h2 层级划分层次，让读者保持「我知道现在读到哪、接下来是什么」的方向感，是长文节奏的骨架。
> 调用时机：**每篇多章节内容都用**。以「每 300–500 字一个章节」为节奏打点，把正文拆成若干可被扫读的单位。

## 一、可用写法与语法

章节标题就是 `##`（h2 层级）。排版语法里 h2 会自动编号或加装饰，也可用 `[[title:文字|样式]]` 显式指定变体。

**排版语法（h2 自动样式，交给排版工具）**：

```markdown
## 三遍阅读法
```

- 「文字类」：h2 默认左侧竖条 + 强调色；「宣传类」：h2 默认**纯色序号自动编号**（如「01」前缀）或紫左条。
- 想让装饰更明确，用装饰标题语法：
  - `[[title:三遍阅读法|flower]]` —— 花边 + 上下虚线装饰
  - `[[title:三遍阅读法|box]]` —— 纯色边框盒（宣传）/ 实线框（文字）

**内联样式——左竖条变体（最常用、最稳）**：

```html
<p style="margin:28px 0 12px;height:24px;display:flex;align-items:center;">
  <span style="display:inline-block;width:4px;height:18px;background:#ff6b35;border-radius:2px;margin-right:10px;"></span>
  <span style="font-size:19px;font-weight:bold;color:#333;letter-spacing:1px;">三遍阅读法</span>
</p>
```

**标题层级与字号的配合**：

- `#` 大标题（页眉）用 26–30px；`##` 章节标题用 17–22px；`###` 小标题用 15–16px。
- 层级靠字号 + 装饰（竖条 / 编号 / 框）区分，别只看颜色；同一篇 `##` 统一一个主样式。
- **避免用 `###` 和 `##` 混用无差别**：`##` 是「章节」，`###` 是「章节下的小点」；两级的间距硬规范不同（`##` 上 28 下 12，`###` 上 24 下 10）。

## 二、双模式表现

| 维度 | 文字类 | 宣传类 |
|---|---|---|
| h2 默认形态 | 左竖条 + 纯色，前面有强调色竖条 | 纯色序号「01」+ 左条，自动编号 |
| 装饰强度 | 克制，单竖条 / 细框 | 可上纯色框、纯色序号、box 盒 |
| 颜色 | 强调色单色（蓝 `#2f6fed`） | 主题纯色（橙 / 青 / 紫） |
| 节奏 | 每 300–500 字一个，编号朴素 | 同样节奏，序号纯色强化「进度」 |
| 上限 | 同篇标题风格 ≤2 种 | 同 |

## 三、样式变体（≥3 种）

**变体 A｜左竖条（默认最稳）**——4px 竖条 + 文字，兼容性最好。
参数：竖条 `width:4px;height:18px;background:<主色>;border-radius:2px;margin-right:10px`；标题 19px、加粗、`color:#333`、字距 1px；上下 `margin:28px 0 12px`。全风格通用首选。

**变体 B｜编号块（宣传 / 步骤感）**——纯色编号框前置。
参数：`<span style="display:inline-block;min-width:28px;height:28px;line-height:28px;text-align:center;border-radius:6px;background:#f26d21;color:#fff;font-size:14px;font-weight:bold;margin-right:10px;">01</span>` + 标题 19px；上下 `margin:28px 0 12px`。编号框强化「递进、进度」感，教程 / 方法文最爱。

**变体 C｜纯色块（报告 / 特辑）**——标题衬在纯色长块上。
参数：`<section style="background:#3f5bc2;border-radius:8px;padding:10px 16px;margin:28px 0 12px;"><p style="font-size:17px;font-weight:bold;color:#fff;margin:0;letter-spacing:1px;">02 · 如何做整理</p></section>`。视觉最重的章节标志。

**变体 D｜box 框（品牌 / 正式）**——标题装进细边框盒。
参数：`<p style="border:1px solid #d7dce8;border-left:4px solid #2f6fed;border-radius:6px;padding:10px 14px;font-size:17px;font-weight:bold;color:#333;margin:28px 0 12px;letter-spacing:1px;">03 · 常见误区</p>`。品牌 / 机构号偏正式。

**变体 E｜flower 花边（情感 / 国潮）**——标题两侧小花边装饰，庄重。
参数：两侧用 CSS 圆点 / 细线拼出的花枝，或 art:// 植物图案（`![花枝](art://blossom-branch)`）+ 上下虚线；标题 19px、字距 3px、色用主色深档；居中 `text-align:center`；上下 `margin:28px 0 12px`。情感 / 国潮 / 日系开篇级装饰。

**变体 F｜纯文字大字号（极简 / 观点）**——零装饰，只加大字号加字距。
参数：`font-size:22px;font-weight:700;color:#1a1a1a;letter-spacing:2px;margin:28px 0 12px`；不加任何线/框/块。极简阵营的收敛答案。

## 四、使用时机与位置

- **节奏**：正文**每 300–500 字**插入一个 h2 章节标题，把内容切成扫读友好的单元；过稀（1000 字没标题）读者迷路，过密（每 100 字一个）标题喧宾夺主。
- **位置**：每个章节内容块之前；标题前留白 **上 28px、下 12px**（遵守硬规范），下一段正文紧贴标题下方 12px 处开始。
- **与目录呼应**：若开头有目录，正文 h2 标题文字必须与目录条目逐字一致（见「目录 / 索引区」）。
- **编号规则**：多章节建议编号（01/02/03）建立进度感；单观点短文可不编号直接写名。
- **与「章节分隔宣传页」配合**：超长文在卷级用分隔页，分隔页之后的第一章 h2 用同一编号体系续上（PART 01 → 章节 01/02 …）。

## 五、风格适配

- **国潮红金墨**：变体 E flower 花边 + 金 `#b8860b`、墨 `#3a2f26`，字距拉大到 3–5px，庄重；或 box 框配红色左条。
- **科技蓝紫**：变体 B 纯色编号（`#3f5bc2`）或变体 C 纯色块；标题 17–19px，利落。
- **校园青春**：变体 B 用高饱和青 `#00b8a9`，编号块圆角 8px；标题可配 CSS 圆点或 art:// 小草装饰。
- **极简黑白**：变体 F 纯文字大字号，无装饰线无框；用白（留白）与黑（文字）的对比分层。
- **日系留白风**：变体 E flower 花边浅色（`#c9b8a8`）+ 大上留白，字距 3px。

## 六、间距与尺寸（遵守硬规范）

- 标题上 `margin-top:28px`、下 `margin-bottom:12px`（**硬规范**，h3 为 24px/10px）。
- 标题内文字与装饰间距：竖条右侧 `10px`、编号块右侧 `10px`。
- 标题字号 17–22px（正文 15–16px 之上），字重 700，字距 1–3px 视风格。
- 标题后正文 `line-height:1.75`；标题与上一章末尾内容之间保留 28px 的「结束感」留白。
- 若章节间用分割线辅助，分割线上下 **24px**（标题在分割线之后仍保持上 28px）。

## 七、密度限制

- **同篇标题风格 ≤2 种**：整篇 h2 只能混用 ≤2 种变体（如「左竖条」为主、个别重点章用「编号块」），不许每章换一个花样。
- 「装饰标题 ≤2 处」的篇内上限计入本文风格（flower / box 属于装饰标题，整篇 ≤2 处；左竖条算常规 h2 不计）。
- 标题字数建议 ≤14 字，宁可简短；过长折行会破坏 line-height 节奏。
- 300–500 字一个章节是「频率」，不是每段都加标题——同一小点内正文别频繁打断。

## 八、常见错误

- **反例**：每个章节 h2 换一种样式（这章竖条、下章纯色块、再下章 flower），全篇花哨无统一感。**正解**：全篇 ≤2 种变体，主样式贯穿。
- **反例**：`margin` 写成 0，标题顶天立地贴到上段文字。**正解**：上 28px、下 12px。
- **反例**：标题 26px 超大 + 字距 8px，比正文大两圈像大标题。**正解**：h2 保持 17–22px，靠字重与竖条区分，别和 `#` 大标题抢层级。
- **反例**：1000 字没有标题，或每 100 字一个标题。**正解**：300–500 字一个章节打点。
- **反例**：编号块里放「01」但同时标题又写「01 · 三遍阅读法」，重复编号。**正解**：有编号块就别在文字里再写编号，二选一。
- **反例**：`##` 和 `###` 无差别使用，或把 `###` 当 `##` 用却用了 28px/12px 的间距。**正解**：`##`（上 28 下 12）与 `###`（上 24 下 10）各按其规范，层级分开。
- **反例**：标题字距拉到 6–8px、字号又大，导致中文之间空隙过大像「散开」。**正解**：字距与字号匹配——正文类标题用 1–2px，纯装饰大标题才用 3–6px。
- **反例**：编号块用「01」但号后没有内容承接，或编号在 `##` 与 `###` 里重复计数造成混乱。**正解**：编号沿 `##` 层级连号（01→02→03），`###` 可不编号或用「1.1」子编号，避免两套打架。

## 九、示例（骨架，标注可替换处）

```markdown
还有几句起承转合，作为上一章的收尾。

## 01 · 三遍阅读法

本章正文（可替换）……大概 300–500 字，讲清一个小节。
```

**左竖条内联骨架**：

```html
<p style="margin:28px 0 12px;display:flex;align-items:center;">
  <span style="display:inline-block;width:4px;height:18px;background:#ff6b35;border-radius:2px;margin-right:10px;"></span>
  <span style="font-size:19px;font-weight:bold;color:#333;letter-spacing:1px;">01 · 三遍阅读法</span>
</p>
```

**纯色编号块骨架**：

```html
<p style="margin:28px 0 12px;display:flex;align-items:center;">
  <span style="display:inline-block;min-width:28px;height:28px;line-height:28px;text-align:center;border-radius:6px;background:#f26d21;color:#fff;font-size:14px;font-weight:bold;margin-right:10px;">02</span>
  <span style="font-size:19px;font-weight:bold;color:#333;letter-spacing:1px;">如何做整理</span>
</p>
```

**排版语法版**：

```markdown
## 02 · 如何做整理
```

> 无论选哪种变体，都先想清楚：这篇的 `##` 主样式是什么、最多加一个点缀变体用到哪里。先用「左竖条」把全篇搭稳，再决定要不要给关键章升级成「编号块 / 纯色块」。

## 十、个性化空间

- **主样式选择**：判断依据是风格——左竖条全风格通用最稳；编号块强化进度感适合教程/递进；flower 适合情感/国潮；box 适合正式；纯大字适合极简。
- **编号格式**：数字 `01` / 中文 `一、` / 英文 `Part 1` / CSS 圆点；判断依据是栏目语言（科技连载用 Part，国潮用「一」）。
- **主色**：竖条 / 编号块 / 左条颜色换账号主色；判断依据品牌 VI，与页眉、关注条、目录同体系。
- **标题措辞**：是否动词开头 / 是否带问句；判断依据是内容类型——教程用「如何做 X」，观点用「为什么 X」。
- **编号是否随正文进度**：连载可在编号后加「（下）」「（完）」标明进度；判断依据是否多期连载。
- **是否加装饰点 / 植物图案**：判断依据风格轻松度——生活 / 亲子可用 CSS 圆点或 art:// 小草，商务 / 科技克制。
