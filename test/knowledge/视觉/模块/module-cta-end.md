# 结尾行动号召（module-cta-end）

> 定位：文章收尾处把读者「从读到到行动」的最后推一把——关注、转发、在看、下单、留言、领福利。是决定一篇从「看完」到「有行动」的关键模块。
> 调用时机：**每篇必用**。位于正文最后、页脚区之前；驱动句要有明确动词，从利益 / 情绪 / 悬念三式中选主式（可叠加副式）。

## 一、可用写法与语法

排版语法里可用「卡片 + 徽章 + 高亮」组装，或内联样式写大号号召块。

**排版语法（交给排版工具）**：

```markdown
::: card 喜欢这期吗？
如果你觉得有用，随手点个在看，让更多人看到。
:::

[[badge:关注]] 别走丢，下期我们聊怎么选书。
```

`[[badge:文本]]` 是行内胶囊徽章（文字类蓝底、宣传类橙底纯色）；`==文字==` 是荧光高亮。

**更多排版语法**：

- `> [!KEY] 行动理由`：CTA 前用重点气泡给「为什么值得现在做」的理由（限时、数量、价值）。
- `==点个在看==`：把动作词高亮，引导读者视线落在动作上。
- `[链接]` / 小程序卡片 / `::: miniapp`：真行动入口（下单 / 报名 / 领资料），跳到微信生态内动作。

**内联样式——大号号召块（宣传 / 强行动）**：

```html
<section style="background:#e56b2f;border-radius:12px;padding:20px 16px;margin:24px 0 16px;text-align:center;">
  <p style="font-size:17px;font-weight:bold;color:#fff;margin:0 0 8px;line-height:1.5;">别错过，点击下方卡片立减 30 元</p>
  <p style="font-size:13px;color:rgba(255,255,255,0.9);margin:0;line-height:1.7;">限时 7 天，名额有限</p>
</section>
```

**CTA 主句公式**：〔动词〕＋〔利益/理由〕＋〔限定/落点〕。示例：「点在看 ＋ 让更多人看到」；「点关注 ＋ 不错过下期」；「领资料 ＋ 立减/限量」。

**结尾收束句 + CTA 的顺序**：先一句**收束句**（点题 / 呼应开头，帮读者合上情绪），再上 CTA 行动号召。收束句是「情绪落点」，CTA 是「动作出口」，两者配套而非替代。

## 二、双模式表现

| 维度 | 文字类 | 宣传类 |
|---|---|---|
| 主选三式 | 情绪驱动 > 悬念驱动 | 利益驱动 > 悬念驱动 |
| 视觉 | 克制：一行文字 + 高亮 / 轻徽章 | 大号纯色号召块 + 限时徽章 |
| 文案口吻 | 「如果对你有用，点个在看」式的求认同 | 「立减 30」「限量抢」式的利益锤 |
| 可叠加 | 可叠悬念（配往期回顾） | 可叠悬念 + 利益（双驱动） |

## 三、三式详解（≥3 种「样式」，这里按驱动式给足 3 种）

**式一｜利益驱动**——给读者「值」，最常见于带货/课程/活动。
核心句式：「点击〔动作〕+〔利益〕」。示例：「点击下方小程序卡片，**立减 30 元**」。
内联样式片段：纯色号召块（见「一」），文字 17px 白字 + 13px 白 0.9 限时副句；`padding:20px 16px`、`border-radius:12px`。利益要具体（减多少、送什么、多少名额），别只喊「超值」。

**式二｜情绪驱动**——给读者「被认可/共鸣感」，常见于观点、情感、干货收尾。
核心句式：把动作包装成「认同」。示例：「如果这篇文章对你有用，点个在看，让更多人看到。」把 `在看` 用 `==在看==` 高亮。
内联样式：不放大块，一行 15px 正文 + 高亮 + 可选细分割线；克制，`margin:16px 0 0`。情绪驱动先给理由（价值 / 共鸣）再给动作，别裸喊「快点赞」。

**式三｜悬念驱动**——给读者「钩子」，常见于连载、系列教程、栏目。
核心句式：「下期聊 X，关注我别错过」。示例：「下期聊聊怎么选书，关注我，别错过。」
内联样式：`::: card 下期预告` 或用往期回顾 + 一句悬念；配「下一期」徽章 `[[badge:下期预告]]`。悬念式是「给下一步的期待」，靠下期内容勾住关注。

**可叠加示例**（宣传类）：利益式大块 + 末尾一句悬念（「留言告诉我你最想看哪期」），双驱动最稳。

## 四、使用时机与位置

- **位置**：正文结束后、页脚区之前；收束句在前，CTA 在后，最后接页脚（作者/版权/往期）。
- **顺序建议**：……正文收尾、收束句（画句号）、CTA行动号召、页脚区。
- **收束句的配合**：收束句呼应开头钩子（首尾圆合），再给 CTA；不要让 CTA 裸奔在正文后没有情绪缓冲。
- **三类 CTA 各自主打**：带货/活动用利益式；观点/情感用情绪式；连载/系列用悬念式（也可 + 利益/情绪叠加）。建议给明确动词：关注、转发、在看、点开、留言、领取、报名、下单。
- **与「页脚区」接口**：CTA 是「这期最后一个行动点」，页脚是「账号长期入口」；CTA 驱动本期行动，页脚承接长期关注，二者分工不重复。

## 五、风格适配

- **国潮红金墨**：CTA 用朱红 `#b03a2e` 纯色或金奖励徽章；文案礼貌利落（「承蒙厚爱，点个在看」），情绪式偏多。
- **科技蓝紫**：CTA 用 `#3f5bc2` 纯色块；利益式给明确参数（「限名额」），字距 2px 利落。
- **校园青春**：CTA 用高饱和青 `#00b8a9`；文案口语（「点个在看」），克制不用装饰字形。
- **极简黑白**：CTA 退成一行黑字加粗 + 下划线式引导，无纯色大块无装饰；情绪式或悬念式，克制。
- **商务 / 机构**：CTA 用主品牌色细框卡，文案正式（「欢迎订阅，及时获取更新」），利益式给具体权益。

## 六、间距与尺寸（遵守硬规范）

- CTA 块与上下：`margin:24px 0 16px`（收束句到 CTA 之间留 16–24px）。
- 号召块 padding：`20px 16px`；大字号 17px、副句 13px；
- 正文 CTA 行 `line-height:1.75`。
- CTA 后接页脚区：靠页脚自身的 `margin-top`（建议 ≥24px）避免粘连。
- 若 CTA 用气泡 `> [!KEY]`，气泡 padding 按 `14px 16px` 规范。

## 七、密度限制

- **每篇 1 个主导 CTA**（可叠加不重复）；不在一篇里同时摆 3 个不同的大号召块。
- 徽章 ≤3、高亮每屏 ≤2 处的篇内上限计入（CTA 内徽章别叠太多）。
- 利益式 CTA 一篇一次；连载结尾可每期固定一句悬念式（成为标签），但行动动词不变多。
- CTA 块（纯色大块 / 卡片）只出现一次；若情绪式只求「在看」，用轻行即可不上大块。

## 八、常见错误

- **反例**：CTA 没有动词（「这篇就到这里」），读者不知道怎么行动。**正解**：动词开头——关注 / 转发 / 领取 / 留言 / 下单。
- **反例**：利益式 CTA 没有落点（「好东西不容错过」但没说怎么拿）。**正解**：给清晰动作 + 利益 + 限定（「点击卡片立减 30，限 7 天」）。
- **反例**：情绪式 CTA 只求「在看」却没有任何情绪理由（「快点赞快分享」）。**正解**：先给价值 / 共鸣理由再给动作（「如果对你有用，点在看让更多人看到」）。
- **反例**：标语太长，一行塞满甚至折行，CTA 力度削弱。**正解**：CTA 主句 ≤15 字，限定 / 理由放副句。
- **反例**：CTA 夹在正文中间不是收尾处，或收尾处既没收束句又没 CTA 戛然而止。**正解**：放正文之后、页脚之前，配收束句。
- **反例**：利益式 CTA 承诺不实（「全场免费领」实际没有或不符），触合规红线。**正解**：利益点必须真实、有明确落点与限制，先过合规检查。

## 九、示例（骨架，标注可替换处）

**利益式（宣传）**

```markdown
篇幅有点长，收藏起来慢慢练。

::: card 限时福利
点击下方小程序卡片，**立减 30 元**，仅 7 天。
:::

[[badge:限时]] 名额有限，售完即止。
```

**情绪式（文字）**

```markdown
写这个话题，是因为身边太多人被「读不进书」卡住。

如果这篇文章对你有用，==点个在看==，让更多人看到。
```

**悬念式（连载 / 系列）**

```markdown
这一讲我们先把阅读的「方法」讲清。

::: card 下期预告
下期聊聊怎么选书——一份从入门到进阶的书单。
:::

关注我，别错过下期。也可以留言告诉我你最想看哪本。
```

**内联大块（利益驱动强转化）**

```html
<section style="background:#e56b2f;border-radius:12px;padding:20px 16px;margin:24px 0 16px;text-align:center;">
  <p style="font-size:17px;font-weight:bold;color:#fff;margin:0 0 8px;line-height:1.5;">点击下方卡片，立减 30 元</p>
  <p style="font-size:13px;color:rgba(255,255,255,0.9);margin:0;line-height:1.7;">限时 7 天，名额有限</p>
</section>
```

## 十、个性化空间

- **三式主次选择**：判断依据是内容类型与转化目标——带货/课程选利益、观点/情感选情绪、连载/系列选悬念；账号可固定一种收尾风格建立辨识。
- **动作动词**：关注 / 转发 / 在看 / 留言 / 领取 / 报名 / 下单 二选一为主；判断依据是本期转化目标，别贪多。
- **利益点 / 限定**：优惠数、名额、时间；判断依据真实活动政策，必须真实不虚标（合规红线）。
- **是否叠加副词式**：连载可「写作者自己的话」做收束 + 悬念 CTA；判断依据是账号人设——IP 向多放个人收束，机构向收束克制。
- **CTA 视觉强度**：纯色大块 / 一行文字 / 徽章；判断依据是行动紧迫度——强转化用大块，弱转化（仅求认可）用一行。
- **是否上小程序 / 链接**：判断依据是否有真实动作落点（下单 / 报名 / 领资料），有才放真入口，避免「关注公众号打赏」类繁琐多步的无效入口。
