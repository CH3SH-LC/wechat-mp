# 方法论·典型模块组合模式（module-guide-combos）

> 定位：给"不知道模块怎么排"的调用方一套**可直接套用的组合骨架**。组合 = 一组有顺序、有间距衔接、有目的的一组模块，而不是零散地堆卡片。
> 调用时机：每篇开工前，先按内容类型选一套组合再填充细节。本条目是模块维度的方法论总纲，具体每种模块的表现见各自条目。

## 一、组合背后的一条规律

读者阅读不是"一个个模块分开看"，而是把一整段连续视觉当成一次呼吸。组合的意义在于安排**节奏**：什么时候给信息、什么时候给视觉停靠、什么时候引向行动。任何组合都由三类模块构成：

- **钩子模块**（开头）：标题、引导关注、核心卖点气泡——先留住人。
- **信息模块**（中段）：步骤、清单、卡片、列表、案例——给价值。
- **行动模块**（结尾）：回顾、CTA、关注引导——收口并沉淀。

### 各组合的通用间距衔接（硬规范）
- 组合内相邻模块之间块距 **16px**；阶段切换（钩子→信息→行动）用 **24–32px**；阶段间可用分割线（细线）或留白软分隔，同篇分割线 ≤2 种。

## 二、组合一：开头三件套（每篇必配的起手式）

**模块顺序**：`标题`（含头图/横幅）→ `引导关注条` → `核心卖点气泡(KEY)`

- **间距衔接**：标题下块距 16px；关注条下 16px；卖点气泡下 16px 接正文钩子段。
- **适用类型**：全部类型通用。干货/教程、连载、情感类靠卖点气泡留住读者；促销/活动用横幅强化。

**逐模块要点**：
1. 标题：文字类极简标题、宣传类横幅/title 装饰标题。
2. 引导关注条：干货/连载/涨粉需求强时放，一句"关注我，每周更新 XX"。
3. 核心卖点气泡：`> [!KEY]` 用一句讲清"这篇给你什么/看完你得到什么"，1 屏 ≤2 个。

**为什么这顺序**：先把注意力从标题落到人，再给读者一个"留下理由"。关注条放标题下、卖点前，防止读者在读懂卖点前就因"不认识这个号"而划走。

### 可改写骨架示例（组合一）

```markdown
> [!KEY]
> 这篇 3 分钟教你配齐一套能被直接套用的排版组合，看完就能上手。

--- 到这里接正文钩子段（16px 起，块距统一） ---
```

## 三、组合二：干货四件套（教程/方法文的主力）

**模块顺序**：`痛点气泡(WARN)` → `步骤(steps)` → `清单勾选(checklist)` → `案例(case)`（或 `图文交替`）

- **间距衔接**：痛点→步骤之间 24px（阶段切换，从"为什么"进入"怎么做"）；步骤→清单 16px；清单→案例 24px（信息→佐证）。
- **适用类型**：干货教程、方法文、科普测评、复盘。文字类主力。

**逐模块要点**：
1. 痛点气泡：`> [!WARN]` 先戳中读者"这个问题我也有"，建立"这篇跟我有关系"。
2. 步骤：`::: steps` 动词开头、循序渐进，每步一句话。
3. 清单勾选：`::: checklist` 把关键动作列成可勾选核对项，读者照抄即可用。
4. 案例：`::: case` 用一个具体"问题—做法—结果"收尾，证明这套方法真有用。

**为什么这顺序**：痛点点燃动机 → 步骤给路径 → 清单给工具 → 案例给信任。四件套让读者既有"道理"又有"操作"还有"证据"。

### 可改写骨架示例（组合二）

```markdown
> [!WARN]
> 上周还有人问我：排完的推文总被说"太挤"，到底卡在哪？

::: steps
1. 先定组合，再填内容，别零散堆卡片。
2. 套开头三件套留住读者，正文才开始。
3. 阶段之间给 24–32px 留白，读起来不闷。
:::

::: checklist
- [ ] 组合内相邻模块块距是 16px
- [ ] 阶段切换用了 24–32px 分隔
- [ ] 结尾接上了回顾、CTA、关注引导
:::

::: card
**问题**：排版太挤 → **做法**：统一 16px 块距 + 24px 分段 → **结果**：读者停留明显变久
:::
```

## 四、组合三：卖点五连（带货/课程/促销的转化主力）

**模块顺序**：`标题` → `重点气泡(KEY)` → `优点列表(list)` → `价格表(price)`/`参数(spec)` → `证言(testimonial)` → `CTA(小程序/领福利)`

- **间距衔接**：前四段信息块之间 16px；价格表→证言 24px（从"值不值"进入"别人验证"）；证言→CTA 24px（临门一脚）。
- **适用类型**：产品软文、课程招生、商品详情、活动促销（宣传类主力）。

**逐模块要点**：
1. 标题：横幅/强力标题。
2. 重点气泡：一句话核心卖点（"3 天学会公众号排版"）。
3. 优点列表：3-5 条这产品/服务好在哪，逐条给理由。
4. 价格表：多档对比（基础/进阶/推荐），突出主推档位。
5. 证言：真实反馈拼卡，"别人用过有效"替你说观。
6. CTA：小程序卡/领福利/价格行动，动词明确。

**为什么这顺序**：卖点金句开道 → 优点铺理由 → 价格做决策 → 证言补信任 → CTA 促成行。先把"值不值"说服，再让读者"放心买"。

### 可改写骨架示例（组合三）

```markdown
::: list
- 亮点一：3 天就能上手
- 亮点二：不用求人，自带整套模板
- 亮点三：一次配齐，之后照抄即可
:::

::: price
- 基础版：xx 元（够用）
- 进阶版：xx 元（推荐，含全部模板）
- 尊享版：xx 元（附一对一答疑）
:::

::: testimonial
- "照着排了一篇，阅读明显上去了。" —— 运营小 A
- "最省心的是不用自己抠间距，全都安排好了。" —— 编辑小 B
:::

- 点下方小程序立即领取
```

## 五、组合四：结尾三连（每篇必配的收口）

**模块顺序**：`简短回顾(bullet/list)` → `行动号召(CTA)` → `关注引导/延伸阅读(footbar)`

- **间距衔接**：回顾→CTA 24px（语义切换，进入收尾）；CTA→关注 16px（连续仪式感）；关注引导后再接页脚。
- **适用类型**：全部通用。

**逐模块要点**：
1. 回顾：用 2-3 条一句话概括本篇核心（文字类可省，干货/教程建议保留）。
2. 行动号召：利益/情绪/悬念三式选一，动词明确（"点在看""回复关键词""点小程序"）。
3. 关注引导：`关注我+更新时间`，或接延伸阅读（往期推荐）后再关注。

**为什么这顺序**：先帮读者记住要点 → 再给一个当下行动 → 最后沉淀长期关注。回顾让干货"带得走"，CTA 让当下"有动作"，关注让未来"找得到"。

### 可改写骨架示例（组合四）

```markdown
::: list
- 记住：先选组合，再填内容。
- 记住：16px 块距、24–32px 分段。
- 记住：结尾三连不要省。
:::

- 觉得有用，点个「在看」并回复「排版」领模板。

关注我，每周更新一篇公众号运营方法论。
```

## 六、组合五：活动倒计时组合（促销/报名/限时场景）

**模块顺序**：`倒计时条(countdown)` → `重点卖点(KEY)` → `报名方式(steps)` → `截止提醒(WARN)` → `CTA`

- **间距衔接**：倒计时是强视觉锚，放最前最醒目；其后信息块 16px；截止提醒→CTA 24px。
- **适用类型**：活动促销、限时优惠、报名招募、新品首发。

**逐模块要点**：
1. 倒计时条：开篇即放，制造紧迫感（`::: countdown`）。
2. 重点卖点：讲清"这次活动/这次机会的价值"。
3. 报名方式：步骤——怎么参与/怎么下单，动词开头。
4. 截止提醒：`> [!WARN]` 再戳一次"时间有限/名额有限"。
5. CTA：回到行动入口收口。

**为什么这顺序**：紧迫感先行 → 讲清价值 → 给参与路径 → 二次催单 → 促成事。倒计时类文章的本质是"用时间压力推动读者立即行动"。

### 可改写骨架示例（组合五）

```markdown
::: countdown
距报名截止还有：**48 小时**
:::

> [!KEY]
> 本周限时：前 50 名报名者额外送一套选题模板。

::: steps
1. 点下方进入报名页。
2. 填好基础信息提交。
3. 名额有限，先到先得。
:::

> [!WARN]
> 名额仅剩 12 个，截止时间为本周五 24:00，过时不候。

- 现在就去报名
```

## 七、组合六：品牌故事组合（建立信任/情感链接）

**模块顺序**：`叙事情节(bubble/quote)` → `时间线或历程(timeline)` → `理念总结(quote)` → `互动/关注(interact CTA)`

- **间距衔接**：叙事段用普通块距 16px；时间线是主视觉，前后 24px；理念金句用 quote 停顿强化；互动 CTA 收尾 24px。
- **适用类型**：品牌故事、人物故事、门店介绍、周年纪念。

**逐模块要点**：
1. 叙事情节：开头一段具体叙事（一个场景/一个真实时刻），别讲大道理。
2. 时间线/历程：`::: timeline` 用节点串起"我们怎么走到今天"。
3. 理念总结：一个金句收束全文（`> [!KEY]` 或 quote），把品牌价值观说出来。
4. 互动/关注：投票/留言/关注，让读者参与进故事。

**为什么这顺序**：先讲"我是谁、怎么来的"，再给"我信什么"，最后"欢迎你参与"。故事文不打硬广，靠情感与认同留住读者并导向关注。

### 可改写骨架示例（组合六）

```markdown
::: card
那年创业只带了一台电脑，和一句"没人看也要把文章做出来"。
:::

::: timeline
- 2019：开始一个人更新公众号
- 2021：第一次被读者催更
- 2024：累计服务了几万位运营者
:::

> [!KEY]
> 我们相信：好内容值得被认真排版，也值得被好好看见。

- 留言聊聊你和公众号的故事，点个关注不迷路。
```

## 八、选组合的判断流程（调用方 3 步定夺）

1. **定内容类型**（见《模块×内容类型矩阵》）：干货→组合二，卖货→组合三，活动→组合五，故事→组合六。
2. **加必配骨架**：每套开头前补上"开头三件套"（组合一）的引导关注+卖点，结尾补"结尾三连"（组合四）。
3. **按风格收敛装饰**：套用组合时，卡片样式只选一类、徽章 ≤3、气泡每屏 ≤2（见《模块堆砌检查清单》）。

## 九、组合的密度与冗余自检

- 一篇**主线组合 1 套**，开头/结尾三件套算作骨架，不算额外组合。
- 组合内每类模块按密度限制执行：步骤 ≤ 5 步、清单 ≤ 8 项、证言 ≤ 4 则、价格 ≤ 4 档、气泡每屏 ≤2。

## 十、常见错误

**整体四类**：1 **组合混搭不专一**——干文章里穿插促销价格表，又塞证言；根据内容类型定主心，别硬塞转化模块。2 **只有信息没有行动**——干货排完直接结束，没结尾三连；每篇都要收口。3 **装饰过度压过信息**——卖点五连里每块都加粗大色，视觉超载；装饰收敛，靠留白与字号分层。

**逐套组合再各补一例**：
- **组合一（开头三件套）**
  - 错：一上来就甩卖点气泡，读者还不认识这个号就划走。
  - 对：标题 → 引导关注条 → 核心卖点（KEY），关注条兜住"留下的理由"。
- **组合二（干货四件套）**
  - 错：痛点戳到了，但步骤一步写了三行、清单列了 12 项抄都抄不完。
  - 对：痛点一句戳中 → 步骤每步一句话（≤5 步）→ 清单 ≤8 项可勾选 → 案例收尾。
- **组合三（卖点五连）**
  - 错：没有真实反馈硬编证言，价格表塞 6 档让读者看花眼。
  - 对：证言只写真名真反馈（没有就省掉），价格表 ≤4 档并突出主推档位。
- **组合五（倒计时）**
  - 错：截止时间只提一次，读者滑到底早忘了"限时"。
  - 对：开篇倒计时 + 中段截止提醒再戳一次，两头都收紧时间感。
- **组合六（品牌故事）**
  - 错：通篇讲大道理，找不到一个具体时刻，故事写成了说教。
  - 对：从一个真实场景切入 → 时间线串历程 → 金句停顿 → 互动收尾。

## 十一、个性化空间（可调参数与判断依据）

- **组合内模块取舍**：同一组合允许根据篇幅删减。干货四件套短文可省案例；卖点五连可省证言（无真实反馈时别硬造）。判断依据＝素材是否真实可用、篇幅是否允许。
- **阶段间距**：正式/科普号用 24px 干净分隔；活泼/年轻号可用分割线花边。判断依据＝账号调性。
- **CTA 落点**：干货/资讯用"在看+关注"；带货/促销用"小程序+领福利"；故事用"留言+关注"。判断依据＝转化目标。
- **单个模块行高取用**：内容密、偏干货的模块（步骤、清单）统一用 1.75 行高，保证多行文字不挤在一团；金句、证言这类单行短句可适当收紧，但不能低于身边的 16px 块距观感。判断依据＝该模块文字密度。
- **阶段切换留白**：钩子→信息、信息→行动两大切点，除 24–32px 间距外，可额外留一行空行或一根细线，让读者明确"换话题了"。判断依据＝该处是否语义转折。
- **长段拆气泡 + 清单更透气**：一段超过 3 行的长内容，拆成 1 个 `> [!TIP/WARN]` 气泡 + 1 个 `::: checklist` 清单，比塞在大段正文里更易读。判断依据＝这一段是否同时"要点 + 动作"两种信息。
- **泡内再分主次**：同一屏要放两个气泡时，主卖点用 KEY、补充提醒用 TIP，别全用 WARN 把语气拉满。判断依据＝信息和情绪是否分层。

## 十二、组合与文字/宣传双模式配合

组合不是"选一套就锁死风格"，它和排版双模式（文字态/宣传态）是两层：**组合决定排什么，模式决定怎么装饰**。

- **天然属文字类**：组合二（干货四件套）——步骤、清单、案例以信息为本，用文字态最干净，不抢内容本身的注意力。
- **天然属宣传类**：组合三（卖点五连）、组合五（倒计时）——卖点、价格、证言、紧迫劝买单，用宣传态加装饰更有说服力。
- **两种通用**：组合一（开头三件套）、组合四（结尾三连）——无论哪类内容都必配，风格跟随正文走，可平可艳。
- **间距规范对两模式一致**：无论文字态还是宣传态，都要遵守 16px 块距、1.75 行高的硬规范；宣传态的装饰靠颜色和纯色块做层次，不靠压缩间距。
- **别做的事**：别在文字类清单段里硬插强促销；也别把宣传类文章整篇做成一色促销，间隔处仍要用文字态呼吸。判断依据＝读者读到某段时，是"想看下去"还是"被按头买"。正文主干（组合二信息段）保持文字态克制，只在开头/卖点/结尾穿插宣传态装饰，该亮处亮、该净处净。
