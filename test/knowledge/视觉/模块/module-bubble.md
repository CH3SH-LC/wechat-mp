# 重点气泡（module-bubble）

> 定位：**气泡 = 一个组件类型（type）**。本条目记录**这一类组件的生成方式**——7 种组合方式（骨架模板）分别怎么组织、零件位在哪、怎么按风格替换内容；以及"**类型 × 风格**"二维模型（风格决定内容）。气泡是"把一段话从正文里拎出来"的强调组件，用一块带色底的气泡让读者一眼抓住"这里重要/要小心/能学到东西"。生成 art:// 气泡底图资产时必读 **§五 5.0 整图资产构建规范**（画布 750×215 / zone 容量 / PNG ≤1MB / 三层验证闭环）。
> 调用时机：正文有关键信息需要单独强调时——一句核心结论、一条操作小技巧、一处易踩的坑、必须禁止的事、全文最重要的那句话。**生成/改造气泡时**：先定组合方式（类型），再按风格填充内容（标记图案/色板）；不是"从变体清单里挑一个"。
> 素材来源：真实知识库 module-bubble（7 变体 A-G 参数）+ 2026-08-29 调研（秀米"布局+背景+文字+边框圆角+间距"五层拼装）+ 第 8 轮类型×风格模型。

---

## 〇、核心模型：类型 × 风格（2026-08-29 第 9 轮确立）

**气泡组件的美术资产由 2 个角度决定：类型（type）和风格（style）。**

| 角度 | 回答什么问题 | 在气泡上的体现 |
|---|---|---|
| **类型（type）** | 组件**怎么组织**（结构骨架）——这类资产怎么构建 | 气泡类型下有 **7 种组合方式**（左竖条浅底式/整块实色式/细边角标式/警示边框式/双层深浅式/品牌单色五档式/对照双泡式） |
| **风格（style）** | 组件里**放什么内容**（零件填充） | 同一种组合方式配不同风格 = 标记图案与色板不同（花草 / 球类 / 印章 / 几何……） |

**两条核心关系**：
1. **类型决定骨架**：同一类型的所有气泡共享结构。例如"左竖条浅底式"= 容器（浅底+右侧圆角）+ 左竖条 + 形状标记位 + 标题句槽 + 内容句槽，无论什么风格，骨架不变。
2. **风格决定内容**：骨架不动，内容图案随风格替换。**例如：左竖条浅底式 + 阳光校园风 → 形状标记换成迷你球类图形（足球/篮球/网球），角饰挂小奖杯**；配自然风 → 标记是草叶/花瓣；配国潮 → 标记是印章方块/回纹。

**知识库应该记录什么**：记录**类型的生成方式**（骨架怎么搭、零件位在哪、怎么按风格替换内容），而不是一份"现成气泡样式清单"。清单只是某个默认风格下的实现示例（见 §四）。

> 与 design-logic-components 的关系：组件 = 美术素材 + 文字；素材维度 = 类型 × 风格——类型管骨架（可复用结构），风格管内容（可替换零件）。气泡的"美术素材"主要来自 **CSS 容器 + 形状标记/角饰零件**（art:// 图案或 CSS 几何），与小标题的整图资产不同：气泡是**代码骨架组件**，素材只占零件位。

## 一、构建总则（气泡类型怎么生成）

### 1.1 7 种组合方式（类型的子类）

| # | 组合方式 | 一句话结构 | 典型用途 |
|---|---|---|---|
| 1 | **左竖条浅底式** | 浅底容器 + 左竖条 + 标记 + 标题句 + 内容句 | 文字类默认，中性说明/技巧 |
| 2 | **整块实色式** | 实色底容器 + 白标记 + 白/米白双层字 | 宣传类 TIP/KEY，核心干货 |
| 3 | **细边角标式** | 细边浅底 + 右上角标 + 标记 + 文字 | 活泼、点名"NEW/限时" |
| 4 | **警示边框式** | 红系浅底 + 整圈边框 + 方形标记 | DANGER 强阻断、合规红线 |
| 5 | **双层深浅式** | 深底 + 深一档描边 + 白首句 + 淡副句 | KEY 压轴、全文收尾点题 |
| 6 | **品牌单色五档式** | 单品牌色 + 五档深浅表达轻重 | 品牌克制风，五语义一套色 |
| 7 | **对照双泡式** | 红系泡（反例）+ 青系泡（正例）成对 | 教学"错误示范+正确示范" |

### 1.2 构建五步（生成方式总流程）

1. **定组合方式**：按文体与内容选 1 种（双模式同篇只选其一：文字类全浅底、宣传类全实色）。
2. **搭骨架**：按 §二 对应模板搭容器与零件位（先只画结构，不填内容）——容器（底/边/圆角）+ 左竖条或边框 + 标记位 + 标题句槽 + 内容句槽。
3. **按风格填内容**：查风格条目（style-* / index-style）得到该风格的**图案词汇表**（标记图案 + 色板），填入零件位（§三）。
4. **填字与排版**：标题句（首句）放标记后、内容句放第二行；间距按 6px 层级收紧；行高 1.75。
5. **验证**：375px 壳实测——密度铁律（每屏 ≤2）、对比度 ≥4.5:1、微信兼容检查（§五）。

### 1.3 通用约束（先读，违反即返工）

- **一泡一意**：每个气泡只装一个意思，文字 **1-3 行**（约 20-50 字），装不下拆成两句或改卡片。
- **首句是"标题"式短句**（放在形状标记后，如"提示：""进阶方法"），没有标题句的气泡像没领子的衬衫。
- **密度**：每屏（约 6-8 行正文）≤2 个气泡；全文通常 3-5 个；五种语义不必都用（一篇 2-3 种即可）。
- **语义一致性**：选定某个语义表达某件事后全篇统一（别这次 WARN 下次 NOTE），读者才能建立"形状即情绪"的默契。
- **零 emoji/零图标字符铁律**：标记图案必须**可绘制的图形**（CSS 几何 span 或 art:// 植物图案），字符图标永不进入气泡。
- **强调 ≥2 通道**：颜色 + 字重/底色/边框，靠两个以上通道表达轻重。
- **微信兼容**：纯色底 + 细边框最稳；禁投影/渐变/backdrop-filter/伪元素；`position:absolute` 角标必须父容器 `position:relative`（稳妥备选：行内 span 角标）。

**形状即情绪——五语义标记规格表（语义选择速查）**：

| 标记 | 中文名 | 形状标记（CSS） | 表达的情绪 | 一句话区分 |
|---|---|---|---|---|
| `> [!NOTE]` | 说明 | 空心圆 16px + 细边框 2px + 中性色 | 中性补充 | 只是"顺带告诉你"，不紧急 |
| `> [!TIP]` | 技巧 | 实心圆 10px + 主色 | 可学干货 | "这么做更好"，想让他记方法 |
| `> [!WARN]` | 注意 | 旋转 45deg 方块 10px + 警示橙 | 转折/易错 | "这里别走岔"，提醒但不致命 |
| `> [!DANGER]` | 警示 | 方形细边框 16px + 红 | 强阻断 | "千万别这么干/会出大事"，最重 |
| `> [!KEY]` | 重点 | 实心菱形 10px + 主紫 | 结论/金句 | "整段最核心一句话"，压轴 |

优先级从轻到重：`NOTE < TIP < WARN < DANGER`；`KEY` 是另一个维度（结论维度），不与轻重冲突。形状标记是"契约"：全篇同一语义用同一形状，形状即情绪。风格替换只换标记的**图案内容**（草叶/球类/印章），不换形状语义（圆=中性、方=警示、菱=结论）。

## 二、7 种组合方式的构建模板（核心：这类组件怎么构建）

> 每个模板给出：**骨架结构**（元素清单与位置）、**零件位**（可替换槽）、**尺寸与间距规范**、**叠字方式**（文字排布）、**风格可变内容**、**默认实现**（当前库中已完成的一个风格版本）。

### ① 左竖条浅底式

- **骨架**（块级容器）：浅底容器（`padding:14px 16px`，`border-radius:0 8px 8px 0`）→ 左竖条（`border-left:3px solid 主色`）→ 形状标记位（行首，`display:inline-block`）→ 标题句槽 → 内容句槽。
- **零件位**：A. **形状标记**（圆点/方块/菱形/CSS 几何→风格词汇可换，或 art:// 植物图案）B. 左竖条样式（宽度 2-4px、颜色）C. 语义色板（底/条/字三色）D. 标题句+内容句文字槽。
- **尺寸**：padding `14px 16px`；圆角 `0 8px 8px 0`（右圆左直）；标记 8-16px（圆点 8-10px、方块/菱形 10px）；标题句 15-16px、内容句 14px；行高 1.75。
- **叠字**：标记为行内 span 前置（`margin-right:6px;vertical-align:1-2px`）→ 标题句（首句，加粗）→ 换行内容句（`margin:6px 0 0`）。
- **风格可变内容**：**形状标记图案**（草叶/球类/印章/几何……）+ 语义色板（可换品牌色系）+ 竖条宽度。
- **默认实现**：变体 A（`#eef6ff` 底 + `#0ba89b` 条 + `#1a4a66` 字，青系 NOTE）+ 变体 F（品牌蓝 `#2f6fed` 五档同骨架）。
- **五语义底色档（换语义只换底色，骨架不动）**：NOTE 青系 `#eef6ff`、TIP 橙系 `#fff8e8`、WARN 红系 `#fdf2f2`、DANGER 红系深档（配整圈边框见④）、KEY 紫系 `#f4f0ff`；文字同色深一档、竖条取主色。

### ② 整块实色式

- **骨架**：实色底容器（`padding:14px 16px`，`border-radius:10px`）→ 形状标记位（白色）→ 标题句槽（白字 15px 加粗）→ 内容句槽（米白 14px）。
- **零件位**：A. **形状标记**（白色几何/风格图案）B. 实色主色 C. 双层文字槽（白首句 + 米白副句）。
- **尺寸**：实色底 `#e56b2f`；圆角 10px；标题句 15px 白字 `font-weight:600`；内容句 14px 米白 `#fff7f0`；标题与正文间距 6px。
- **叠字**：标记（白）→ 标题句（首句）→ 内容句（第二行）。
- **风格可变内容**：标记图案 + 实色主色（风格色板）。
- **默认实现**：变体 B（TIP 橙 `#e56b2f` / KEY 紫 `#6b4fc4` 均可套此骨架）。

### ③ 细边角标式

- **骨架**：细边浅底容器（`padding:16px 18px`，`border-radius:12px`，`border:1px solid 浅边`，父容器 `position:relative`）→ 右上角标位（`position:absolute;top:0;right:0`）→ 标记位 → 标题句槽 → 内容句槽。
- **零件位**：A. **角标**（文字+底色，如 NEW/限时）B. 形状标记 C. 细边色/底色 D. 文字槽。
- **尺寸**：padding `16px 18px`（比默认大，给角标留空间）；角标 11-12px、`border-radius:0 10px 0 8px` 贴合顶角；容器圆角 12px。
- **叠字**：标记 → 标题句 → 内容句；角标 absolute 定位（**父容器必须 `position:relative`**）。
- **风格可变内容**：角标文字与配色 + 标记图案 + 底色。
- **默认实现**：变体 C（淡紫底 `#f4f0ff` + 紫角标 `#6b4fc4`）。
- **风险注意**：绝对定位在部分旧客户端会飞逸，稳妥备选是把角标改写为行内 `<span style="background:主色;color:#fff;border-radius:5px;padding:2px 8px;margin-right:6px;">NEW</span>` 放在标题前，不依赖定位、永不跑飞。

### ④ 警示边框式

- **骨架**：红系浅底容器 + 整圈边框（`border:1px solid 红`）→ 方形细边框标记（14-16px）→ 标题句槽（加粗）→ 内容句槽。
- **零件位**：A. 边框色/文字色 B. **方形标记**（细边框方框，风格词汇可换形状）C. 文字槽。
- **尺寸**：`background:#fff2f2`；`border:1px solid #d33`；`border-radius:10px`；padding `14px 16px`；标记 14-16px 方形细边框；标题句加粗 `color:#a11`。
- **叠字**：方形标记 → 加粗标题句 → 内容句。
- **风格可变内容**：红系深浅 + 标记形状（警示语义的"形状即情绪"契约）。
- **默认实现**：变体 D（`#fff2f2`/`#d33`/`#a11`，全库视觉权重最高；DANGER 专属）。

### ⑤ 双层深浅式

- **骨架**：深底容器（`border:1px solid 深一档`）→ 白色标记 → 首句槽（16px 白字 700）→ 副句槽（14px 淡色）。
- **零件位**：A. 深底主色/描边深一档 B. **标记**（白）C. 首句+副句双层文字槽。
- **尺寸**：`background:主色` + `border:1px solid 主色深一档`；圆角 10px；padding `14px 16px`；首句 16px 白字 700、副句 14px 淡色（`#f4efff`）、间距 6px。
- **叠字**：白标记 → 首句（压轴结论）→ 副句（补充）。
- **风格可变内容**：主色系 + 标记图案（KEY 语义专属，允许上 16px）。
- **默认实现**：变体 E（`#6b4fc4` + 描边 `#5a3caa` + 副句 `#f4efff`，KEY 压轴）。

### ⑥ 品牌单色五档式

- **骨架**：同①左竖条骨架，但**五档深浅全由单一品牌色**表达（极浅 `#f0f5ff` → 浅 `#dbe7ff` → 中 `#b8d0ff` → 实色 `#2f6fed`）。
- **零件位**：A. **品牌主色**（一套色五档）B. 标记（同色系）C. 文字槽。
- **尺寸**：同①；竖条 3px（重语义 4px）+ 文字加深一档表达轻重。
- **叠字**：同①。
- **风格可变内容**：品牌色五档（换品牌=换整套深浅）。
- **默认实现**：变体 F（品牌蓝 `#2f6fed`）。判断依据：品牌色够不够撑起"从轻到重"的梯度——能就用，最专业。

### ⑦ 对照双泡式

- **骨架**：红系泡（上，反例）+ 青系泡（下，正例）成对，各自沿用①左竖条骨架 → 各自标记位 → 各自标题句+内容句槽。
- **零件位**：A. 反例语义色（WARN/DANGER 红系）B. 正例语义色（TIP/KEY 青系）C. 标记（可两泡不同）D. 文字槽。
- **尺寸**：各泡同①；两泡之间底部 `margin:0 0 16px`。
- **叠字**：反例泡（方形细边框标记 + 红系）在上、正例泡（实心圆标记 + 青系）在下。
- **风格可变内容**：语义组合（反例 WARN/DANGER、正例 TIP/KEY）+ 标记 + 色板。
- **默认实现**：变体 G（红 `#fff2f2`/`#9a281f` + 青 `#eef6ff`/`#0ba89b`）。

## 三、风格如何决定内容（填充规则）

1. **风格条目 → 图案词汇表**：每个风格条目（style-*，见 index-style）应提供该风格的**图案词汇表**（如：阳光校园风 = 球类/跑道/奖杯/校徽；自然田园风 = 草叶/花枝/果实；国潮风 = 印章/回纹/祥云；科技风 = 几何/菱形/网格）。
2. **填入零件位**：把词汇表中的图案绘制为 SVG/CSS 图形，填入 §二 对应模板的"风格可变内容"零件位——骨架（容器/竖条/边框/双层）保持不变，只换内容。
3. **图案必须是可绘制图形**：足球/篮球/网球等是**具体图形**（可用圆形+线缝弧线绘制），不是 emoji/字符图标——符合 v10 铁律（禁 emoji/图标字符，但允许具体器物图形）。
4. **标记优先 CSS 几何、复杂图案走 art://**：气泡是代码骨架组件，简单标记（圆点/方块/菱形）用 CSS span 拼（最稳）；需要风格图案（花草/球类）时用 `![图案](art://资产名)` 或新增资产（按小标题资产库的复杂度铁律构建）。
5. **颜色随风格**：语义色板（NOTE 青/TIP 橙/WARN 红/DANGER 深红/KEY 紫）可整组替换为风格色板，但**必须保留轻重梯度**（NOTE < TIP < WARN < DANGER 的视觉递进），同篇颜色 ≤2 个主色。
6. **验证**：生成后按 §五 铁律实测（375px 壳、对比度 ≥4.5:1、密度），并登记 REQUIREMENTS（先记录后开发）。

> 示例：**左竖条浅底式 + 阳光校园风**——骨架：浅底容器 + 左竖条 + 标记位 + 双行文字槽；内容：标记①=迷你足球（圆形+五边形缝线）、标记②=迷你篮球（圆形+曲线缝线）、标记③=迷你网球（圆形+弧线缝线）；色板：校徽橙/球场绿；语义五档用同一校园色系深浅表达；标题句/内容句结构不变。

## 四、现有实现 = 默认风格（中性/自然花草）的实现示例

> 真实知识库 module-bubble 的 7 个变体 A-G 是**默认风格**下各模板的实现示例——不是全部可能，只是一份样板。生成新风格时按 §二 模板 + §三 规则重新填充即可。

| 组合方式 | 默认实现（变体） | 语义落点 |
|---|---|---|
| ① 左竖条浅底式 | 变体 A（青系 NOTE）+ 变体 F（品牌蓝五档） | 中性说明/技巧/品牌克制 |
| ② 整块实色式 | 变体 B（TIP 橙） | 核心干货、进阶方法 |
| ③ 细边角标式 | 变体 C（紫底 NEW 角标） | 活泼点名、新品/限时 |
| ④ 警示边框式 | 变体 D（红系方形标记） | DANGER 合规红线 |
| ⑤ 双层深浅式 | 变体 E（紫 KEY 压轴） | 全文收尾点题 |
| ⑥ 品牌单色五档式 | 变体 F（`#2f6fed` 蓝五档） | 品牌单色贯穿 |
| ⑦ 对照双泡式 | 变体 G（红反例+青正例） | 错误示范+正确示范 |

## 五、构建验证与铁律（生成任何气泡必须满足）

### 5.0 整图资产构建规范（生成 art:// 气泡底图时必须满足，2026-08-29 第 9 轮·实测修正）

> 气泡底图是**整图资产 + 中央嵌字模式**（与小标题 combo 资产一致）：SVG 画布模拟气泡容器 + 标记/装饰长在结构上，**中央区域留作文字区（zone）**。子智能体首轮失败根因：嵌字区高度只留 27px 显示，装不下两行文字；水平背景渐变致 PNG 超 1MB；只验"zone 内无装饰"未验"zone 装得下文字"。以下为强制规范：

1. **画布规格（默认）**：750×215（375px 壳显示 343×98px，缩放比 ≈0.457）。容器圆角矩形 y10 h195；**顶部装饰贴顶（y≤50）、底部装饰贴底（y≥170）**，中央 110..730 × 50..170 为文字区。
2. **文字区容量（核心，首轮失败点）**：zone 必须装下"标题句 15px（行高1.4）+ 间距 6px + 内容句 14px（行高1.5）+ 上下留白"≈ **48-55px 显示高**。换算为设计尺寸：zone 显示高 ≥55px → **设计高 ≥120px（y 50..170）**；zone 显示宽 ≥280px → **设计宽 ≥620px（x 110..730）**。双泡组件每个泡的 zone 显示高 ≥33px（设计 ≥72px），每泡只放一行文字（反例/正例各一句，≤16 字）。**文案长度约束（375px 壳实测前提）**：单泡"标题句 ≤8 字 + 内容句 ≤22 字（14px 一行 ≈22 字，内容句必须单行不换行）"；双泡每泡一句 ≤16 字。375px 壳叠字实测用此长度的真实文案，超长文案会换行越界 = 不合格。
3. **PNG 体积铁律**：4x 渲染后 **≤1MB**（uploadimg 硬限）。**大面积背景渐变必须用垂直方向**（水平渐变在 750px 宽的每一行都是不同像素，PNG 熵爆炸：实测 bar-note 1309KB 超限；改垂直后 ≤348KB）。渐变仍用 `gradientUnits="userSpaceOnUse"` + 绝对坐标。
4. **zone 字段**：每个资产必须带 `zone`（单泡 `{x0,y0,x1,y1}` 设计坐标；双泡用数组两个 zone），标注文字安全区。
5. **验证闭环（三层，缺一不可）**：
   - ① 资产级：渲染 4x PNG + probe 像素验证（落纯色部件，容差 ±12）+ 体积 ≤1MB；
   - ② zone 洁净度：相邻像素突变扫描（x105..730 区域逐行扫，相邻像素 RGB 差之和 >40 计数，突变 >12 的行必须为 0 或只在 zone 外）；
   - ③ **375px 壳叠字实测**（首轮缺失项）：把真实文案（标题句+内容句）按 zone 缩放后叠入图片，DOM 检查文字边界全部落在 zone 矩形内（getBoundingClientRect 对比），**10/10 全部通过才算完成**。双泡每泡一行、单泡两行都要实测。

### 5.1 通用铁律（继承 §一/§三）

- **密度铁律**：每屏 ≤2 个气泡；同屏两个需分工（一个 KEY/TIP 亮 + 一个 WARN/NOTE 收敛，不连放两个实色亮块）；全文 3-5 个；五种语义不必全用（通常 2-3 种）。
- **文字铁律**：一泡一意、1-3 行（20-50 字）；首句标题式；最重字号 ≤16px（仅 KEY 双层式允许）。
- **对比度铁律**：气泡文字与底色对比度 ≥4.5:1；浅底配深字、深底实色配白字最稳。
- **语义契约铁律**：形状即情绪——NOTE 空心圆/TIP 实心圆/WARN 旋转方块/DANGER 方形边框/KEY 菱形；选定后全篇统一。
- **零 emoji/零图标字符铁律**：标记必须是 CSS 几何 span 或 art:// 可绘制图形。
- **微信兼容铁律**：纯色 + 细边框；禁投影/渐变/backdrop-filter/伪元素/outline/border-image；absolute 角标必须父 relative（备选行内 span 角标）；`vertical-align:2px` 对齐行内徽章。
- **双模式铁律**：文字类全文浅底左竖条、宣传类全文实色底，一篇只选其一。
- **验证方式**：375px 壳截图自查（一眼分清重点/标签/正文）；改参后整段截图到手机看一屏。

## 六、示例（骨架，markdown 用法）

```markdown
> [!NOTE]
> 提示：本方法对新手尤其友好，配合文末清单使用效果更佳。
```
（文字类默认：左竖条浅底式。**可替换**：语义标记 `NOTE`（→TIP/WARN/DANGER/KEY 自动换色板）、正文文字。）

```markdown
> [!KEY]
> 一句话记住本文：真正拉开差距的，是每天愿意多读 20 分钟正文的那批人。
```
（KEY 自动套双层深浅式或实色式，见 §二 ⑤/②。）

```html
<!-- 较强的重点强调（宣传类 TIP 整块实色式）：可替换语义/颜色/标记 -->
<div style="background:#0ba89b;border:1px solid #09877d;padding:14px 16px;border-radius:10px;margin:0 0 16px;">
  <p style="margin:0;line-height:1.75;font-size:15px;color:#fff;font-weight:600;"><span style="display:inline-block;width:9px;height:9px;transform:rotate(45deg);background:#fff;vertical-align:1px;margin-right:6px;"></span>新知速递</p>
  <p style="margin:6px 0 0;line-height:1.75;font-size:14px;color:#ffffff;">这里放一句最想让读者记住的新信息。</p>

```

**五语义组合示例（一篇的稳妥用法）**：开篇一个 `KEY` 结论 → 中段一个 `TIP` 干货 → 收尾一个 `WARN` 避坑（或 `DANGER` 合规）。

## 七、常见错误

- **反例**：一个气泡塞 4 个意思（"水果含糖，吃多了会胖，而且维生素C会流失，建议每天吃但要适量"）。**正解**：一泡一意，拆成两个气泡。
- **反例**：全文 9 个气泡，第三屏满屏底色。**正解**：保留 ≤2 屏最关键的 3-5 个，其余改加粗或列表。
- **反例**：免责声明用实色大色块（"注意：最终解释权归我方"）。**正解**：免责用 NOTE 浅底小字，别用最强的视觉表达最弱的信息。
- **反例**：28px 大红加粗满溢。**正解**：最重字号 ≤16px，强调 ≥2 通道（颜色+字重/底色/边框）。
- **反例**：把图片、整个段落塞进气泡。**正解**：气泡只装 1-3 行句，长素材给卡片，大图给图片模块。
- **反例**：同一篇 NOTE 用浅蓝条、WARN 也画得浅淡没差异，轻重分不清。**正解**：DANGER/WARN 视觉明显重于 NOTE（加重边框/加粗/方形标记）。
- **反例（类型×风格新）**：想换风格时改骨架——把左竖条浅底式改成整块实色式（"换个风格"）。**正解**：换风格只换零件（标记图案/色板），换骨架是换组合方式；组合方式按文体选，风格按账号选。
- **反例（类型×风格新）**：风格词汇用 emoji/字符图标（🏀⚽ 直接贴进气泡）。**正解**：球类必须绘制成具体图形（圆形+缝线）或 art:// 资产，字符图标永不进入气泡。
- **反例（类型×风格新）**：每种风格换一套骨架（校园用竖条、国潮用实色、科技用角标），读者认不出"这是气泡"。**正解**：全篇一种组合方式贯穿（按文体定），风格只换内容零件——"形状即情绪"的契约比换花样重要。
- **反例（整图资产·首轮实测失败）**：画布 750×150、zone y45..105（显示仅 27px 高），装不下"标题15px+内容14px+6px"两行文字。**正解**：画布 750×215、zone y50..170（显示 ≥55px 高），见 §五 5.0。
- **反例（整图资产·首轮实测失败）**：大面积背景用水平渐变，PNG 4x 渲染 1309KB 超 1MB（每行像素全不同，熵爆炸）。**正解**：大面积背景渐变用垂直方向（实测 ≤348KB），见 §五 5.0。
- **反例（整图资产·验证缺失）**：只验证"zone 内无装饰侵入"就宣称完成，没把真实文字叠进去实测——文字实际放不下。**正解**：三层验证闭环（资产级 probe + zone 洁净扫描 + **375px 壳叠字 DOM 实测**），见 §五 5.0。

## 八、个性化空间

- **语义色板**：默认 青 `#0ba89b`/橙 `#e56b2f`/红 `#e0532a`/深红 `#9a281f`/紫 `#6b4fc4`；可整体换品牌主色（判断：品牌色能区分情绪层次才换）。
- **左竖条宽度**：3-4px（文字类）/ 2px（极简）；越粗越有仪式感。
- **圆角**：右 8px（竖条式）/ 10px（整块）/ 14px（活泼）；商务极简收小。
- **标记形状**：同一语义标记全篇固定；轻松号可用 art:// 植物图案，严肃号可去掉标记只留字。
- **角标有无**：需要"点名某某事"才加 NEW/限时角标。
- **风格扩展方向**：阳光校园（球类标记/奖杯角饰）、国潮（印章方块/回纹）、科技（几何菱形/网格）、手账（涂鸦/胶带）——每种风格 = 一套图案词汇表填入 7 种模板的零件位，先调研再入库（REQUIREMENTS.md 登记）。
