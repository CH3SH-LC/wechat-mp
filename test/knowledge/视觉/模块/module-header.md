# 开头页眉（module-header）

> 定位：一篇文章的「门面」。决定读者扫到标题后 3 秒内是继续往下看还是退出去，负责建立风格基调、承接标题与首屏注意力。
> 调用时机：**每篇必用**。正文第一屏、标题之后、首段钩子之前的位置；按内容类型与风格从三种开篇结构中选一种（横幅开篇 / 装饰标题开篇 / 极简开篇），不依赖账号性质，看类型与调性。

## 一、可用写法与语法

页眉有「排版语法」与「内联样式 HTML」两套写法，二选一即可（排版语法交给排版工具转换，内联样式直接用）。

**排版语法三式**（对应三种开篇结构）：

```
# 大标题

[[banner:主标题|副标题]]          ← 横幅开篇
[[title:副题|flower]]             ← 装饰标题开篇（flower / box 二选一）
#（不写装饰，直接跟钩子段）        ← 极简开篇
```

- `# 大标题`：正文系统标题，排版工具会按模式渲染（文字类左竖条、宣传类荧光下划线居中）。
- `[[banner:主|副]]`：整行横幅，主标题 + 副标语，「宣传类」默认紫粉纯色横幅 + 装饰圆，「文字类」默认居中标题 + 下划线。
- `[[title:文字|flower]]` / `[[title:文字|box]]`：装饰化标题——`flower` 是花边 + 上下虚线装饰，`box` 是细边框盒。两者文字类用实蓝 / 蓝花边，宣传类用纯色框 / 橙花边。

**更多开篇可用的排版语法**：

- `==开篇金句==`：荧光高亮，适合极简 / 观点开篇里把结论先行的那句关键词点亮。
- `::: card 一句话导读`：开篇上一个小导读卡，适合干货长文先给读者「读完你将获得什么」。
- `> [!KEY] 核心观点`：开篇第 1 屏放一个重点气泡强调卖点或立论（促销/干货都常见）。

**内联样式（横幅开篇整块页眉）**：想自己控制版式时用这段骨架（尺寸基于微信正文区 677px），可替换主色与文字：

```html
<section style="text-align:center;padding:30px 20px 20px;margin:0 0 16px;
border:1px solid #f3d9c6;border-radius:10px;background:#fff3ec;">
  <section style="margin-bottom:16px;">
    <span style="display:inline-block;vertical-align:middle;width:70px;height:1px;background:#ff6b35;"></span>
    <span style="display:inline-block;vertical-align:middle;width:8px;height:8px;background:#ff6b35;transform:rotate(45deg);margin:0 8px;"></span>
    <span style="display:inline-block;vertical-align:middle;width:70px;height:1px;background:#ff6b35;"></span>
  </section>
  <section style="margin-bottom:10px;">
    <span style="display:inline-block;font-size:30px;font-weight:bold;letter-spacing:4px;color:#8a4b2a;line-height:1.4;">大标题文案（可换）</span>
  </section>
  <section style="margin-bottom:14px;">
    <span style="display:inline-block;font-size:15px;color:#a5765a;letter-spacing:2px;">副标语（可换）</span>
  </section>
  <section style="margin-bottom:12px;">
    <span style="display:inline-block;vertical-align:middle;width:70px;height:1px;background:#ff6b35;"></span>
    <span style="display:inline-block;vertical-align:middle;width:8px;height:8px;background:#ff6b35;transform:rotate(45deg);margin:0 8px;"></span>
    <span style="display:inline-block;vertical-align:middle;width:70px;height:1px;background:#ff6b35;"></span>
  </section>
  <section>
    <span style="display:inline-block;font-size:13px;color:#b0987f;letter-spacing:1px;">撰文 / 署名 · 分类标签</span>
  </section>
</section>
```

**极简开篇**不加任何装饰容器，直接 `# 大标题` 后接首段钩子；若想加一条极细分割线收住页眉区，可用：

```html
<p style="height:24px;margin:0;line-height:1px;font-size:1px;">&nbsp;</p>
<p style="text-align:center;color:#dcdcdc;font-size:14px;letter-spacing:6px;margin:0;">—　—　—</p>
```

**兼容注意**：装饰尽量用 `rotate(45deg)`、`border-radius`、细边框 `border:1px solid` 这类微信稳定的写法，统一纯色 + 细边框，不依赖伪元素 / 外链字体；本规范不推荐渐变，统一纯色 + 细边框兜底。

## 二、双模式表现

| 维度 | 文字类 | 宣传类 |
|---|---|---|
| 首选结构 | 极简开篇 > 装饰标题开篇 | 横幅开篇（必选） |
| 视觉 | 左竖条标题、无或极少装饰、留白大，靠文字张力 | 纯色横幅、装饰圆、主色块、副标语双行 |
| 颜色 | 强调色单色（如蓝 `#2f6fed`） | 主题三主色（橙 `#ff6b35` / 青 `#00b8a9` / 紫 `#7a3cec`）或纯色 |
| 文案侧重 | 结论先行、一个观点钩子 | 卖点锤、紧迫感副标语（限时/数量/利益） |
| 字距 | 0.5–2px | 3–6px（更讲究仪式感） |

选型规则：

- **促销 / 活动 / 新品 → 横幅开篇**：利益和紧迫感最需要被第一眼看到。
- **品牌 / 内容型 / 国潮 / 日系 → 装饰标题开篇**：要的是「这是正经栏目」的仪式感，不抢眼球。
- **观点 / 干货 / 科技 / 极简 → 极简开篇**：靠观点张力说话，装饰越多越臃肿。

## 三、样式变体（≥3 种）

**变体 A｜横幅块（宣传促销最爱）**——纯色底 + 白字，视觉焦点最强。
参数：`background:#f26d21`，圆角 10px、`padding:20px 16px`，细边框 `border:1px solid #c25a12`，居中对齐；主标语 22px、白字 `#fff`、字距 3px；副标语 14px、`rgba(255,255,255,0.9)`。下方 `margin:0 0 16px`。想改紫色系就整体换成 `#6b4fc4`，青色系 `#0ba89b`。

**变体 B｜对称装饰标题（品牌/栏目）**——左右细线 + 菱形 + 圆点，对称聚焦。
参数：左右线宽各 70–110px、高 1–2px、纯色金色系（`#c9a063`）；菱形 10×10px `rotate(45deg)`、圆点 5×5px、间距 3px；标题 22px、字距 4px；外围 `margin:26px 0 14px`。菱形加 `border-radius:1px` 减弱反锯齿白边。

**变体 C｜单色文字页眉（极简/科技）**——只加大字号 + 字距 + 居中，零装饰。
参数：标题 30px、字重 700、字距 4px、`color:#1a1a1a`；下方副题 15px、`#666`；整块 `text-align:center;margin:8px 0 16px`。靠留白与字号建立层级，不添加任何线/块。

**变体 D｜胶囊主标语（活动/栏目标签感）**——胶囊底 + 白字横幅。
参数：`display:inline-block;background:#e2574c;color:#fff;font-size:16px;letter-spacing:3px;padding:8px 20px;border-radius:22px;font-weight:bold`。居中，`margin:24px 0 12px`。想要旗形可在胶囊下补一段同色实色短条（宽 60%、高 18px、居中、实底 `#e2574c`）；锯齿缺角微信做不了，退化仍见胶囊。

**变体 E｜深色纯色大标题（强调核心句 / 品牌仪式）**——深色纯色底块承托白字。
参数：标题 26px、字距 6px、`color:#fff`；块底 `background:#1e2436`、圆角 8px、`padding:4px 16px`、四周细边框 `border:1px solid #3a4256`。用纯色底块与白字对比形成轮廓，不做阴影投影——微信不支持负模糊，且本规范去光影，统一纯色平面化。

## 四、使用时机与位置

- **位置**：紧跟文章题图/标题之下，正文第一屏顶部，正文任何其他模块之前。极简开篇的钩子段就紧贴标题。
- **横幅开篇结构顺序**（保持固定）：`# 大标题` → banner → 首段钩子 → 首个重点气泡 `> [!KEY]` 或 `[!TIP]` 收住卖点。促销文案强烈建议这一步。
- **装饰标题开篇顺序**：`# 标题` → `[[title:副题|flower]]` 或 `[[title:副题|box]]` → 引言段。
- **极简开篇顺序**：`# 标题` → 结论先行的钩子段。
- 页眉之后接正文第一段（或目录 / 关注条），块间距保持 16px。
- **特殊搭配**：干货长文可在页眉后接「目录 / 索引区」让读者先看全貌；有涨粉诉求可接「首屏引导关注条」。三者位置顺序：标题 → 页眉 → 关注条 → 目录 或 标题 → 页眉 → 钩子段。

## 五、风格适配

- **国潮红金墨**：横幅用金 `#c9a063` 与墨 `#2a2a2a` 撞色，副标语红 `#b03a2e`；装饰标题选 flower/菱形金线，字距加大到 5px，庄重。
- **科技蓝紫**：横幅纯色 `#3f5bc2`，圆角 8px 偏利落；极简开篇副题补一行 13px 技术注释字段；字距 2px。
- **校园青春**：横幅用高饱和青 `#00b8a9` + 白字，前置装饰圆点用 CSS 空心圆 18px + 细边框 2px + 主色，或 art:// 小草图案（`![小草](art://sprig-grass)`）；装饰标题用 box 变体，副标语活泼口语化，字距 2px。
- **极简黑白**：只走极简开篇；标题 30px 纯黑、正文灰 `#333`，副题可省略；克制到不出现任何色块或装饰线（可留一条 1px 灰细线 `#e5e5e5` 收尾）。
- **日系留白风**：装饰标题选 flower 花边 + 大留白，字距 4px，颜色用低饱和米灰 `#8a8078`，横幅配色块则显拥挤。

## 六、间距与尺寸（遵守硬规范）

- 页眉整体与正文块距：**16px**（`margin:0 0 16px`）。
- 页眉内部：上内边距 **30px**、下 **20px**、左右 **20px**（横幅块）；装饰标题线上下 **26px/14px**。
- 大标题字号 30px、行高 1.4、字距 4px；副标题 15px；日期署名 13px。
- 正文 `line-height:1.75`、`letter-spacing:0.5px`。
- 若页眉下方紧跟分割线，分割线上下 **24px**；紧跟图片，图片上下 **12px**。
- banner 或整块页眉之后一律回落 16px 块距，不叠加空隙。
- 极简开篇标题下到钩子段的间距走默认 16px 块距即可，不必额外加大。

## 七、密度限制

- **一篇文章只有一个页眉区**，三种结构选一种，不叠加、不并用（绝不 banner + 花边标题 + 双层描边叠一起）。
- 页眉内的装饰元素计数进「装饰标题 ≤2 处 / 花边 ≤2 种」的篇内上限；页眉自身算 1 处装饰标题。
- 横幅开篇的 `[!KEY]` 卖点气泡仍计入「气泡 ≤2」上限，别在页眉区塞多个。
- banner 只用于促销 / 活动 / 新品 / 特辑等强仪式感场合；普通干货文章强行上 banner 反而显浮夸，克制使用。

## 八、常见错误

- **反例**：横幅 + flower 花边标题 + 双层描边大标题三种全上，装饰标题超限、页面像爆炸贴。**正解**：一种开篇结构到底，只留 1 个主装饰元素（线 / 块 / 圆点 / 纯色块四选一）。
- **反例**：副标语写成长句堆满一行，折行后行高不一、字距撑爆。**正解**：副标语 ≤14 字，单行放不下就主动减字，不加字距过多的长句。
- **反例**：页眉块 `margin-bottom:0`，紧贴下一段无空隙，视觉粘连。**正解**：页眉后空 `16px` 块距。
- **反例**：标题跨行时自动折行，字距 4px 导致断在难看的字上。**正解**：用 `<br/>` 主动断在语义点，或缩小字号 / 减字距让整行放进 677px。
- **反例**：深色横幅上压深色副标题文字，对比不足。**正解**：深底一律白字 `#fff` 或 `rgba(255,255,255,.9)`，保证两个表达通道（颜色 + 字重）。
- **反例**：极简开篇标题 `#` 和正文之间没留白、或装饰标题独占整屏所有注意力。**正解**：极简就要「空白 + 一个焦点」，标题下方 16px 后就要有实际内容。

## 九、示例（骨架，标注可替换处）

**横幅开篇（宣传/促销）**

```markdown
# 夏日狂欢大促

[[banner:全场五折起|仅限 7 天，售完即止]]

优惠力度直给，不等不犹豫。今天起，把错过打折的遗憾都补回来。

> [!KEY] 限时抢购
> 爆款直降 50%，满 299 再减 30
```

**装饰标题开篇（品牌/内容型）**

```markdown
# 关于坚持这件事

[[title:慢下来的力量|flower]]

开头引言段（可替换）：坚持不是咬牙硬撑，而是找到让自己持续下去的节奏。
```

**极简开篇（观点/干货/科技）**

```markdown
# 高效阅读的三个方法

结论先行（可替换）：读书慢，不是阅读方法不对，而是没带着问题进场。今天给三个立即可用的方法。
```

## 十、个性化空间

- **主色 / 强调色**：换掉变体里的灰度色号即可切账号品牌色（如品牌蓝 `#0f52ba`、品牌金 `#c9a063`）；判断依据是账号 VI 或栏目固定色，全篇页眉与正文保持同色系。
- **字号与字距**：大标题 26–32px、字距 2–6px 视账号「成熟稳 vs 活泼」调；判断依据：庄严栏目放小字距，年轻栏目放大字距 + CSS 装饰圆点或植物图案（art:// 小草）。
- **是否裸奔（极简 vs 横幅）**：判断依据是**内容类型**而非账号——促销必须亮横幅抢眼球，深度干货用极简彰显克制；账号可做成「栏目模板」固定一种开篇，建立辨识度。
- **副标语措辞**：可填「卖点 / 栏目 slogan / 本期一句话观点」三选一；判断依据：促销填利益点、品牌填 slogan、观点填核心结论。
- **署名与标签行**：是否展示看账号习惯；连载号建议固定位置形成「这一期的情绪锚」，方便老读者秒认。
- **装饰复杂度上限**：判断依据是「装饰清越正文」与「一屏装饰 ≤3 处」两条线——装饰不压文字、不清越正文，越简单越稳。

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案
