# 方法论·复用模板包（module-guide-templates）

> 定位：把全库"可直接复用的成品模块片段"按场景集中索引到这里，调用方写稿时按场景查表，直接抄对应条目的模板片段，再局部替换色号/文案/图片即可，不用从零排。
> 调用时机：不想重新设计、想快速用一套稳定的排版时；或要保证某类内容（门店卡、招聘块、延伸列表…）全号风格统一时，统一从这里取模板。

## 一、这个"模板包"是什么

它不是把 HTML 抄在这里，而是**一张场景→可用模板的索引**：每种"你想实现的效果"对应到"用哪个条目的哪个变体"，并给出"要替换哪些东西、注意什么"。真正的成品骨架在各模块条目里，这里只负责「你现在要干嘛 → 去抄哪段 → 抄时要改什么」。

一句话记住用法：**先"要什么效果"，再查这张表"去哪抄"，最后按 "替换清单"逐项改**。这张索引不存样式，只存"路线"——因为样式一旦写死在这里，条目更新时就会两头失同步。

## 三、模板替换时的三大通用要点（每抄必做）

1. **换色号**：所有模板抄过来后，把主色/背景/描边色替换成账号主色（橙 `#ff6b35` / 青 `#00b8a9` / 紫 `#7a3cec`，或你自己的品牌色）。别留模板里的默认色。
2. **换文案与图片**：把示例文字换成真实文案，`你的图片ID` 之类占位换成微信上传后的真实图片 URL（不能留本地/外链）。关键信息（电话/地址/价格）务必核对为当前真实值。
3. **对照间距自查**：模板粘贴后逐块核对 **16px 块距、1.75 行高、卡内 padding ≥12px**——外部/手抄模板最易在这一步失守（见《避免堆砌》）。

## 四、如何建立一个"本号专属模板库"

与其每次现抄，不如把用顺手的模板沉淀成本号资产：
1. 从上面场景表里，挑出你**常用**的 8-10 类模板（如门店卡、干货气泡、结尾CTA）。
2. 把每类**换成你自己的色号+常用文案**后，存成一份"本号排版模板.md"。
3. 每次发文从这份专属库取，只改当篇内容——既快又能保证全号视觉统一。
4. 换季/改版后统一更新一份，别各篇各自为政。

判断依据：账号发文量大、要保证风格统一时，专属模板库的价值最大；单篇/偶尔发稿可直接现抄条目。

### 建库的五个动作（选类→换色→存库→取用→更新）

1. **选类**：先不贪多，只挑你 2-3 周内真会用到的 8-10 类。卖货号重点要价格/证言/倒计时/CTA，干货号重点要气泡/步骤/清单/延伸——按账号内容结构选，别把全表都搬。
2. **换色**：把这一类的默认色全换成你的主色（含背景、描边、按钮四处的色号一起换，别只换标题那条），再把"示例文案"换成你这号说话口吻的"常用开场/常用结转句"。
3. **存库**：每类存成一份单独小节（如 `## 门店卡`、`## 干货气泡`），带一句"替换说明"注明哪里要改。全部存在同一份"本号排版模板.md"里，勿散落各聊天/文档。
4. **取用**：发文时按"先查本号库、没有才回本条目标"的顺序取——库里有的直接用，库里缺的再回场景表抄新类并补进库。
5. **更新**：每季或大改版时统一过一遍库：废弃的类删掉，新增的类补上，色号是否跟上品牌升级。更新后就从单点改，各篇旧文不用回改。

## 五、使用模板的边界（模板 ≠ 一劳永逸）

- 模板是"骨架"，不是"照抄就完事"——每篇都要按内容、读者、这篇的目标微调（见各条目"个性化留白"）。
- 模板之间要遵守"组合"与"密度"：只抄单块没问题，组合起来要按《组合模式》和《避免堆砌》校验，别把每类模板都放一遍。
- 模板样式要与本篇的**双模式**一致：文字类文章别抄宣传类的纯色横幅模板（见《双模式切换》）。

## 六、常见错误

1. **留了模板默认色/占位图**：抄完忘了换色号、图片还是"你的图片ID"——每抄必做三大替换。
2. **模板之间风格打架**：这篇抄白卡、那篇抄彩卡，或一块里混两种卡片——同篇只用一套卡片样式。
3. **照搬不校验间距**：手抄/外部模板间距失守——粘贴后逐块查 16px/1.75/padding≥12px。
4. **把模板当全文**：为追求丰富每类模板都放一遍→堆砌病——按内容选主干 + 少量点缀。
5. **不同账号共用一个模板库**：品牌色、调性不同——专属库按号维护。
6. **模板库删了现场取**：每篇现抄现改，改完不留底稿——发现好用的组合立刻补进库。
7. **旧模板一直不过期**：换季改版后还沿用上季临时色/临时图——更新库时把过季类一并清掉。
8. **占位符漏换成真值**：`{…}`、示例人名、示例电话漏改发出去了——发布前用"替换清单"逐项比对一遍。

## 七、各场景模板的"可替换文案清单"（快速替换锚点）

抄任何一个模板，重点替换这几个位置：
- 标题文字（含副题/横幅文字）。
- 主色相关（背景/描边/按钮色号）。
- 关键数据（价格、数字、时间、日期、地点、电话、地址）。
- 示例占位（`{…}`、`你的图片ID`、示例人名/公司名）。
- 图片 URL（一律换微信上传的真实链接）。
- 按钮/CTA 文案与停留。

发布前可用这份清单当"发布自检表"：逐类过一遍，标记"已换/未换"，未换的一律先补再发。

## 八、个性化空间（可调参数与判断依据）

- **专属库规模**：常做干货的号重点沉淀"气泡/步骤/清单/延伸"；常卖货的号重点沉淀"价格/证言/CTA/倒计时"。判断依据＝账号内容结构。
- **主色替换**：有品牌色用品牌色；无品牌色按风格选（宣传类用橙青紫体系）。判断依据＝品牌识别 vs 风格调性。
- **是否建多套变体**：同一种卡（如证言）可存"文字态"与"宣传态"两版，切换模式时直接用。判断依据＝是否经常刷双模式。
- **例句要不要存**：把常用结转句（如"下面进入正题""最后划重点"）一并存进库，替换时顺手就用，减少现场想话术。判断依据＝写稿时是否常卡在过渡句。

## 九、模板替换完整示例：门店卡

以「联系方式/营业卡 → 门店/双入口卡」为例，一次完整替换给你看：

1. **抄模板**：从《联系方式卡》条目复制"门店/双入口卡"整块。
2. **换主色**：把模板默认的描边/按钮色换成你号主色——假设账号品牌色是青 `#00b8a9`，把所有旧色号一次性替换。
3. **换店名与地址**：把"示例门店名""示例路名"换成真实的门店名与地址，城市/街道别简写。
4. **换电话与营业时间**：把"400-000-0000""9:00-18:00"换成真实电话与营业时间段；强调周休就单独标注。
5. **换图片**：`你的图片ID`/`外链图`换成微信上传后的门店实景图或地图截图 URL，**不能留占位**。
6. **补特色话术**：按你门店的卖点补一行"我们这里有/提供什么"，别只留干巴巴的地址。
7. **对照间距自查**：16px 块距、1.75 行高、卡内 padding ≥12px 逐块核对（见《避免堆砌》）。
8. **发前核对**：让同事或自己把电话拨一遍确认能接通、地址能在地图搜到——信息类模板最容易在这漏发。

> 看完一例就够：**门店卡**、**招聘块**、**证言墙**的替换步骤几乎一致，都是"换色 → 换真值 → 换图片 → 补特色 → 查间距 → 发前核对"，只是同类内的字段不同。

## 十、模板替换完整示例：干货卡

以"强调一个重点 → 《重点气泡》的 KEY 变体"为例，看干货文怎么把模板抄成自己的内容：

1. **框住结论**：先想清楚这篇最关键的一句话是什么，把它放进 KEY 气泡的加粗位——这句就是读者带走的重点。
2. **展开讲为什么**：在气泡下接一段"这个结论为什么成立"的小段落，用你自己的大实话，别复述模板原文。
3. **接一个行动建议**：在下方补一条"你可以马上做什么"，让重点落到动作上（配《步骤》/《清单勾选》单块）。
4. **换色与间距**：KEY 气泡的语义色整块换主色，核对 16px 块距、1.75 行高、padding≥12px。
5. **查密度**：如果全文已放了多个强调气泡，检查是否都在说同一件事、是不是换了一种样式在重复同一句话——是就去掉只留最硬的那个（见《避免堆砌》）。

> 干货卡与门店卡的区别只在"换什么"：干货卡追"结论真诚不存话术"，门店卡追"信息真值不存占位"。前者防"空话病"，后者防"错信息病"。

## 十一、复用时的"组合"写法（多块怎么拼）

单块好抄，组合要讲次序。同一种卡用于不同位置时，套用这些稳定组合：

| 开篇 | 中段 | 收尾 | 组合要点 |
|---|---|---|---|
| 横幅 + 引导关注 | 内容 → 步骤 → 清单 | 回顾 + CTA + 页脚 | 一块一节奏，中间别塞过多花样 |
| 引言 + 目录条 | 分节用同色卡 | 延伸阅读 + 收口 | 中段只换色不换形，保持连贯 |
| 活动横幅 | 排期线 + 报名入口 | 抽奖 + 预告 | 转化类从前到后一条主线 |

> 组合的最高原则：**主干一套卡、点缀不超过两三种**。一眼看过去读者能有"顺"的感觉，而不是每段都像新换了个版式（见《组合模式》《避免堆砌》）。

## 十二、模板库的文件结构与版本更新

本号专属模板库建议按下面这样组织，方便长期维护：

- **一份主文件**：「本号排版模板.md」放库根——里面按 `## 场景` 分小节的"可直接抄、只改内容"的模板，如"门店卡""干货气泡""结尾CTA"。
- **含替换说明**：每个小节开头写一行"此处必改：色号/电话/地址/图片"，提醒自己和同事别漏。
- **附一张取用索引**：文件顶部放一张与上面场景表同构的小表（我想做→库里哪个小节），发文时先看这张表。
- **版本怎么更新**：每季或大改版时整库过一遍——标记为"当前版/待更新/已废弃"三类；已废弃的直接删，避免库里堆旧版。更新只会影响新发文，已发出的旧文无需回改。

文件结构示意（不必照抄，按需增删）：

- 本号排版模板.md（主库，含 `## 门店卡` `## 干货气泡` `## 结尾CTA` …）
- 双模式备选.md（同一批卡的文字态/宣传态两版）
- 组合示例.md（存几个你常用的"开篇→中段→收尾"整排样例）

### 主库内一个小节该长什么样（以"门店卡"为例）

- `## 门店卡`
  - 首行注释："此处必改：店名 / 地址 / 电话 / 营业时间 / 图片"
  - 正文：可直接复制的门店卡成品（已换成你的主色）
  - 末行备注："发前请拨一次电话确认接通"

这样每个小节都是"拿来即改"，接手的人不用猜哪里要动。

### 多长时间更新一次库（建议节奏）

- **每周小的**：这周发现某类用得不顺，顺手调整该小节。
- **每季中的**：过一遍全库，删掉已成型的临时类，补进新沉淀的类。
- **大改版时大的**：品牌色、整体调性变了，全库统一换代（见第四章第 5 步）。

## 十三、引用其他条目时的交叉索引写法

写稿或整理库时，要"指到"别的知识点/模板，统一用「《条目名》」这类写法，方便自己和团队快速跳转。约定如下：

- **指到具体条目**：写「《避免堆砌》」「《组合模式》」「《双模式切换》」——名字即定位，不写全路径。
- **指到条目里的某块**：「《卡片》的白卡变体」「《证言》的文字态」——先条目再变体。
- **指到某个约束**：「间距见《避免堆砌》」「密度见《组合模式》」——把"该去哪找规矩"写清。
- **取用顺序**：先「本号排版模板.md」，库里没有再回《module-guide-templates》这张表，最后才回具体条目抄新类。

> 交叉索引写在**一句话末尾**最稳：既点名了去处，又不打断正文阅读。编成段的话术如"模板组合方式与密度控制见《组合模式》《避免堆砌》"。

## 十四、新作者快速上手清单（给刚接手本号排版的人）

1. 先读一遍本文件从 A 到 H 的场景表，知道"要什么效果能去哪抄"。
2. 打开「本号排版模板.md」看已沉淀的类，至少会用其中 3-5 类。
3. 做一次"门店卡/干货卡"的完整替换练习（照本文第九、十节跑一遍），建立手感。
4. 发文前跑两遍自检：一遍"三大替换"（色/文案/间距），一遍"替换清单逐项比对"。
5. 不确定某做法对不对，回看第五章"边界"与第六章"常见错误"先自查。

## 十五、同篇里"门店卡 + 干货卡"怎么共存（组合拆解示例）

一篇讲"某门店的招牌菜特色"的文章，可以很自然地把两类模板拼起来，顺序如下：

1. `## 开头页眉` 横幅：写"招牌菜的三大坚持"，定全篇主题。
2. `## 重点气泡` KEY：放最大的一句结论（如"只用当天鲜料"）。
3. `## 步骤`：三步讲招牌菜的做法（只换内容，不改形态）。
4. `## 互动块` ：让读者猜哪道菜最受欢迎，插入交互点。
5. `## 联系方式卡` 门店卡：末尾给门店地址、电话、营业时间，促成到店。
6. `## 页脚区`：关注引导收口。

**为什么这个顺序顺**：干货在前（讲做法与坚持），转化在后（给地址促成到店），信息与行动不打架。反之若把门店卡放在最前，读者还没读到干货就先被"推销感"劝退；若把干货一直拖到门店卡之后，读者可能没耐心看完就走（密度判断见《组合模式》）。

## 十六、一句话总纲

**先查场景表找"去哪抄" → 再到专属库或原始条目"取块" → 按"三大替换+替换清单"逐项改成真值 → 组合时守住"一块一节奏"与间距硬规范 → 发布前自检两遍。** 模板包是让排版快而稳的地图，不是照抄复制的橡皮章。
