# 分割线（module-divider）

> 定位：**分割线 = 一个组件类型（type）**。本条目记录**这一类组件的生成方式**——8 种组合方式（骨架模板）分别怎么组织、零件位在哪、怎么按风格替换内容；以及"**类型 × 风格**"二维模型（风格决定内容）。分割线是用细线、圆点、纯色条、花边等分隔元素把章节、段落隔开的"视觉停顿"组件，是比缩进更清楚的天然分段标志。生成 art:// 分割线底图资产时必读 **§五 5.0 整图资产构建规范**（画布 750×90 / 无文字型 exempt zone / PNG ≤1MB / 三层验证闭环）。
> 调用时机：长文章节切换、观点转折、正文到末尾过渡、需要"换口气"的地方时用——分割线是"小节之间的停顿"；真正要告诉读者"下一章讲什么"时用章节标题，分割线只做切换缓冲。**生成/改造分割线时**：先定组合方式（类型），再按风格填充内容（线体颜色/端点图案/色板）；不是"从变体清单里挑一个"。
> 素材来源：真实知识库 module-divider（8 骨架 A-H 参数）+ 2026-08-29 调研（微信兼容实证：不用 `<hr>`/禁伪元素）+ 第 9 轮类型×风格模型（与 module-bubble 同构重构）。

---

## 〇、核心模型：类型 × 风格（2026-08-29 第 9 轮确立）

**分割线组件的美术资产由 2 个角度决定：类型（type）和风格（style）。**

| 角度 | 回答什么问题 | 在分割线上的体现 |
|---|---|---|
| **类型（type）** | 组件**怎么组织**（结构骨架）——这类组件怎么构建 | 分割线类型下有 **8 种组合方式**（细线式/圆点分隔式/短横条式/art花边式/横条色带式/双条拼色式/章节组合式/留白分节式） |
| **风格（style）** | 组件里**放什么内容**（零件填充） | 同一种组合方式配不同风格 = 线体颜色与端点/中心装饰图案不同（花草 / 珍珠 / 菱形 / 印章……） |

**两条核心关系**：
1. **类型决定骨架**：同一类型的所有分割线共享结构。例如"短横条式"= 线体（主色短条 + 细描边）+ 水平居中定位 + 上下 24px 停顿，无论什么风格，骨架不变。
2. **风格决定内容**：骨架不动，内容图案随风格替换。**例如：短横条式 + 国潮红金风 → 主色换红金（`#9a281f`/`#d4a24c`）、端点加 CSS 菱形点缀**；配科技商务风 → 主色蓝 `#2f6fed`、无装饰、纯"结构线"；配校园清新风 → 薄荷绿 `#0ba89b`、宽 60px、圆角 3px。

**知识库应该记录什么**：记录**类型的生成方式**（骨架怎么搭、零件位在哪、怎么按风格替换内容），而不是一份"现成分割线样式清单"。清单只是某个默认风格下的实现示例（见 §四）。

> 与 design-logic-components 的关系：组件 = 美术素材 + 文字（分割线多数无文字）；素材维度 = 类型 × 风格——类型管骨架（可复用结构），风格管内容（可替换零件）。分割线是**代码骨架组件**：绝大多数组合方式用 CSS 线体/形状 span 直接拼装（细线/圆点/短横条/色带/双条/留白），与小标题的整图资产不同；仅 art花边式的植物图案零件位和章节组合式底图走 `art://` 资产（见 §五 5.0）。

## 一、构建总则（分割线类型怎么生成）

### 1.1 8 种组合方式（类型的子类）

| # | 组合方式 | 一句话结构 | 典型用途 |
|---|---|---|---|
| 1 | **细线式** | 全宽 1px 横线 + 上下 24px 停顿 | 最万能兜底，文字类主款 |
| 2 | **圆点分隔式** | 居中 3 个 CSS 圆点排一行 | 轻松简洁、收尾、观点转折轻停顿 |
| 3 | **短横条式** | 主色短条居中 + 细描边 | 章节强调，科技/商务"现代干净"款 |
| 4 | **art花边式** | 居中植物图案 / 点条点几何拼花 | 节日、纪念、情感（专属色） |
| 5 | **横条色带式** | 全宽纯色色带 + 细描边（+两端圆点） | 品牌、宣传、新年 |
| 6 | **双条拼色式** | 两条同尺寸短横条并排（主色+辅色留缝） | 章节强调/宣传，"多段提亮"装饰轴 |
| 7 | **章节组合式** | 章节标题 + 下方短横条贴合（带文字槽） | 章节导航切换，8 种中唯一带文字 |
| 8 | **留白分节式** | 大留白 + 居中圆点组/过渡文案，"无线的分隔" | 极简白、文艺类 |

### 1.2 构建五步（生成方式总流程）

1. **定组合方式**：按文体与内容选 1 种（双模式同篇只选其一：文字类全细线/圆点、宣传类全短横条/花边）。
2. **搭骨架**：按 §二 对应模板搭线体与零件位（先只画结构，不填内容）——线体 + 端点/中心装饰位 + 文字槽（仅⑦章节组合式）。
3. **按风格填内容**：查风格条目（style-* / index-style）得到该风格的**图案词汇表**（线体颜色 + 端点图案），填入零件位（§三）。
4. **排布与间距**：上下 24px 硬规范；短横条/色带水平 `margin:24px auto` 居中；行高 1.75 内不额外撑高。
5. **验证**：375px 壳实测——密度铁律（同篇 ≤2 种、短文 1-2 处）、对比度、微信兼容检查（§五）。

### 1.3 通用约束（先读，违反即返工）

- **间距硬规范**：分割线上下各留 **24px** 空白（`margin:24px 0`），与图片的 12px、普通块的 16px 区分开——分割线是"更强的停顿"，间距更大。**这条是必守项，违反即返工**。
- **密度**：同篇 ≤2 种（锚定 1 个主分割线贯穿，另一个只在关键章节出现一次）；短文 1-2 处、长文按大章节 1 次；一段内不连续两个同款；一个章节内不重复。
- **分割线是缓冲不是导航**：真正要提示"下一章讲什么"时用章节标题（见「章节标题」条目），分割线只做视觉停顿；全文需要 4 条以上分割线理层次，说明结构该靠标题承担。
- **零 emoji/零图标字符铁律**：花边/端点装饰必须**可绘制的图形**（CSS 几何 span 或 art:// 植物图案），字符图标永不进入分割线。
- **颜色同源**：分割线只用正文主色的「相对淡」版本（`#e8e8e8`~主色），不引入第三个不相关颜色；与花纹色带同篇同用必须同源（同一主色浅档），避免分割线一色、花纹另一色打架。
- **微信兼容**：不用 `<hr>`（微信对 hr 默认样式覆盖不稳，用自建 `<div style="border-top:1px solid 色">`）；禁伪元素（花边的"对称装饰尾巴"别用 `::before/::after` 拼，直接写 CSS 形状 span 或 art:// 植物图案）；嵌在彩色卡片里两端留白或配细边框，不用透明过渡。
- **与图片/模块相邻**：分割线不与图片直接贴边，中间至少隔一个 24px 停顿，避免线与图挤在一起。

## 二、8 种组合方式的构建模板（核心：这类组件怎么构建）

> 每个模板给出：**骨架结构**（元素清单与位置）、**零件位**（可替换槽）、**尺寸与间距规范**、**叠字方式**（分割线多数无文字，仅⑦有文字）、**风格可变内容**、**默认实现**（当前库中已完成的一个风格版本）。
> 零件位三件套贯穿全部模板：**A. 线体**（粗细/颜色/形状）**B. 端点/中心装饰图案**（风格词汇可换：花/珍珠/菱形/印章）**C. 相邻文字槽**（仅章节组合式）。

### ① 细线式（原骨架 A）

- **骨架**：块级 `<div style="height:0;border-top:1px solid #e8e8e8;margin:24px 0;">`——一条实线/淡色线全宽居中，可左对齐可带两侧小形状。
- **零件位**：A. **线体**（`border-top` 1px + 颜色）B. 端点小形状（可选，风格词汇可换）C. 无文字槽。
- **尺寸**：线高 1px；`margin:24px 0`；颜色三档 `#e8e8e8`（默认）/`#d8d8d8`（中灰）/`#f0f0f0`（虚化浅档）；全宽 100%。
- **叠字**：无（纯线）。
- **风格可变内容**：线色深浅 + 是否带端点小形状。
- **默认实现**：骨架 A（`#e8e8e8` 1px）。**任何风格都能兜底的基础款，非风格强约束时优先选它**。

### ② 圆点分隔式（原骨架 E）

- **骨架**：`display:flex;justify-content:center;gap:10px` 居中容器 + 3 个圆点 span（`width:6px;height:6px;border-radius:50%`）。
- **零件位**：A. **线体 = 圆点组**（直径/颜色/数量）B. 端点/中心装饰（圆点可换菱形/珍珠串等风格形状）C. 无文字槽。
- **尺寸**：圆点直径 6px、`border-radius:50%`、`gap:10px`（紧凑 8px / 稀疏 12px）、居中；**三个点最标准**（五个更疏朗但别超过五个，避免像省略号）。
- **叠字**：无（三点排一行）。
- **风格可变内容**：圆点颜色（中性 `#c0c4cc` 或主题色如 `#2f6fed` 带一点品牌色）+ 点距 + 形状。
- **默认实现**：骨架 E（`#c0c4cc` 三点 gap 10px）。轻松、简洁风格；观点转折的轻停顿、收尾款。

### ③ 短横条式（原骨架 B）

- **骨架**：块级 `<div style="width:80px;height:3px;border-radius:2px;background:#2f6fed;border:1px solid #d6e4ff;margin:24px auto;">`——主色短条居中，低饱和纯色 + 细边框，中间实色。
- **零件位**：A. **线体**（短横条：长度/厚度/主色/描边浅档）B. 端点装饰（可选，风格词汇可换）C. 无文字槽。
- **尺寸**：`width:80px`（范围 60-120px）、`height:3px`（范围 3-5px）、`border-radius:2-3px`（圆头）、`margin:24px auto`（上下 24px + 水平居中）；醒目档宽 120px、厚 4-5px。
- **叠字**：无（纯条）。
- **风格可变内容**：主色 + 描边浅档 + 长度/厚度（辅色可做第二短横条并排，见⑥）。
- **默认实现**：骨架 B（`#2f6fed` + 描边 `#d6e4ff`，80×3px）。**最"现代、干净"的强调款，适合科技、商务；章节强调首选**。

### ④ art花边式（原骨架 C + 原条目 1.4 花边）

- **骨架**：居中容器 + art:// 植物图案或 CSS 几何拼花（单株植物居中，或"圆点 + 短横条 + 圆点"点条点拼法）。
- **零件位**：A. **线体**（短横条/植物茎，颜色）B. **中心/端点装饰图案**（花/草/叶角——风格词汇可换：回纹/印章/祥云/珍珠/菱形）C. 无文字槽。
- **尺寸**：CSS 拼花 `gap:8px` 点线留缝、字号 14px 适中（太大显笨）；圆点 5px + 横条 60×2px + 圆点 5px；art:// 资产（`art://sprig-grass` 草丛 / `art://blossom-branch` 花枝 / `art://leaf-corner` 叶角）居中排布。
- **叠字**：无（图案一行排开）。
- **风格可变内容**：中心/端点图案（花/珍珠/菱形/印章……）+ 花边颜色（主题彩或节日专属色）。
- **默认实现**：骨架 C（`#9a281f` 红系：7px 圆点 + 2×7px 竖条 + 7px 圆点，gap 6px）+ `art://sprig-grass` 单株小草。**节日、纪念、情感专用，不作为默认款**，只在特定情感/宣传场景用。

### ⑤ 横条色带式（原骨架 D）

- **骨架**：块级全宽 `<div style="margin:24px 0;height:4px;border-radius:2px;background:#d4a24c;border:1px solid #f0d9a8;">`——纯色色带横贯，中间满色 + 两端圆点装饰（见原条目 1.4）。
- **零件位**：A. **线体 = 色带**（高度/主色/描边）B. 两端圆点/端点装饰（风格词汇可换）C. 无文字槽。
- **尺寸**：`height:3-5px`、`border-radius:2px`、全宽、`margin:24px 0`；两端圆点拼法（5px 圆点 + 60×2px 横条 + 5px 圆点，gap 8px）。
- **叠字**：无。
- **风格可变内容**：色带主色（主色/金色）+ 描边浅档 + 高度 + 两端装饰。
- **默认实现**：骨架 D（金色 `#d4a24c` + 描边 `#f0d9a8`，4px）。品牌、宣传、新年。

### ⑥ 双条拼色式（原骨架 F）

- **骨架**：`display:flex;justify-content:center;align-items:center;gap:8px` 居中容器 + 两条同尺寸短横条（主色 + 辅色），中间留缝——视觉像一个"多段提亮"的装饰轴，两端以留白收边。
- **零件位**：A. **线体 = 两条短横条**（各自颜色/尺寸）B. 一般不带端点装饰（保持装饰轴干净，风格词汇可换时除外）C. 无文字槽。
- **尺寸**：每条 `width:48px`（范围 40-60px）、`height:4px`（范围 3-5px）、`border-radius:2px`、`gap:8px` 留缝、`margin:24px 0`。
- **叠字**：无。
- **风格可变内容**：主/辅两色（科技蓝 `#2f6fed`+紫 `#6b4fc4` / 国潮红金 `#9a281f`+`#d4a24c`……）。
- **默认实现**：骨架 F（`#2f6fed` + `#6b4fc4`，各 48×4px）。章节强调/宣传；主色 + 辅色并排留缝的"多段提亮"装饰轴。

### ⑦ 章节组合式（原骨架 G）—— 8 种中唯一带文字槽

- **骨架**：h3 章节标题（上）→ 短横条（下贴合）→ 正文（再下），三者一个块；把「章节标题」与「分隔短横条」结合，比单独用分割线更有"导航感"。
- **零件位**：A. **线体**（短横条：主色/长度/厚度）B. 端点装饰（可选）C. **相邻文字槽**（章节标题 + 正文——唯一需要 zone 的模板，见 §五 5.0）。
- **尺寸**：h3 `font-size:18px;font-weight:700;color:#1b2a4a;margin:0 0 8px`；短横条 `width:60px;height:3px;border-radius:2px;background:#2f6fed;border:1px solid #d6e4ff`；正文 `font-size:15px;color:#333;line-height:1.75;margin:16px 0 24px`。
- **叠字**：标题在上、短横条在下贴合（间距 8px），正文跟线 16px 后；标题 18px 一行 ≈11 字，标题 ≤10 字。
- **风格可变内容**：章节序号与标题文字 + 短横条主色 + 端点装饰。
- **默认实现**：骨架 G（`第三章 · 开始行动` + `#2f6fed` 60×3px 短横条 + 开场说明）。

### ⑧ 留白分节式（原骨架 H）

- **骨架**：大留白块（`margin:40px 0`）+ 居中圆点组（或一句过渡文案）——真正的极简版，"无分割线的分隔"。
- **零件位**：A. **圆点组**（直径/颜色/间距）B. 过渡文案槽（可选一句，风格词汇可换）C. 无标题槽（过渡话不是标题）。
- **尺寸**：`margin:40px 0`（比 24px 大，本身就是"停顿"）；圆点 6px 直径、`margin:0 4px`；过渡文案 `font-size:14px;color:#8a94a6;text-align:center;margin:-32px 0 40px;line-height:1.75`（负 margin 把文案拉进圆点组下方）。
- **叠字**：圆点组居中一行，过渡文案用负 margin 叠圆点组下方。
- **风格可变内容**：圆点样式（CSS 圆点 span / art:// 植物图案）+ 颜色 + 过渡文案。
- **默认实现**：骨架 H（`#c0c4cc` 三点 + `—— 间歇片刻，继续 ——`）。极简白、文艺类专属，整篇作为唯一分节手段。

## 三、风格如何决定内容（填充规则）

1. **风格条目 → 图案词汇表**：每个风格条目（style-*，见 index-style）应提供该风格的**图案词汇表**（如：科技商务风 = 蓝 `#2f6fed`/灰 `#e8ecf3`、纯"结构线"不用花边；国潮红金风 = `#9a281f`/`#d4a24c`、回纹/印章/祥云/菱形；校园清新风 = 薄荷绿 `#0ba89b`、花草；极简白 = `#f0f0f0`、大量留白）。
2. **填入零件位**：把词汇表中的线体颜色与端点/中心图案填入 §二 对应模板的"风格可变内容"零件位——骨架（线体结构/圆点排布/短条尺寸）保持不变，只换内容。
3. **图案必须是可绘制图形**：花边/端点图案是**具体图形**（CSS 形状 span 或 art:// 植物图案），不是 emoji/字符图标——符合 v10 铁律（禁 emoji/图标字符，但允许具体器物/植物图形）。
4. **标记优先 CSS 几何、复杂图案走 art://**：分割线是代码骨架组件，简单端点（圆点/菱形/短竖条/旋转方块）用 CSS span 拼（最稳）；需要植物图案（花草/叶角/花枝）时用 `![图案](art://资产名)` 或新增资产（按 §五 5.0 构建）。
5. **颜色随风格且同源**：分割线只用正文主色的「相对淡」版本（`#e8e8e8`~主色），不引入第三个不相关颜色；与花纹色带同篇同用必须同源（同一主色浅档）。花边只在确认"此风格允许装饰"时使用（国潮/校园/节日可以，科技商务、极简白原则上不用）。
6. **验证**：生成后按 §五 铁律实测（375px 壳、密度、对比度），并登记 REQUIREMENTS（先记录后开发）。

> 示例：**art花边式 + 国潮风**——骨架：居中容器 + 线体 + 中心装饰位；内容：中心装饰换成**回纹/印章图形**（CSS 旋转方块印章或 art:// 印章资产），两端配 CSS 菱形点缀；色板：红金（`#9a281f`/`#d4a24c`）；线体 60×2px + 描边浅档不变。再如 **短横条式 + 校园清新风**——主色换薄荷绿 `#0ba89b`、宽 60px、圆角 3px、端点加小叶片装饰。

## 五、构建验证与铁律（生成任何分割线必须满足）

### 5.0 整图资产构建规范（生成 art:// 分割线底图时必须满足，2026-08-29 第 9 轮·按分割线特性调整）

> 分割线是**横长条组件**，绝大多数组合方式是代码骨架组件（CSS 拼装，无需整图）；仅 art花边式整图版 / 章节组合式底图需要生成 art:// 资产。分割线**多数无文字**：无文字型资产 **exempt zone**（zone 置 0 或省略），但需保留**装饰洁净带**。以下为强制规范：

1. **画布规格（默认）**：750×90（375px 壳显示 343×41px，缩放比 ≈0.457）。横长条高度空间极小：装饰必须**长在水平结构线上**（线体两端/线中），不做纵向堆叠；线体主轴沿 y45 中线，装饰洁净带 y10..80。
2. **文字区容量（仅⑦章节组合式需要）**：分割线多数无文字——无文字型资产（①细线/②圆点/③短横条/④花边/⑤色带/⑥双条/⑧留白）**exempt zone（zone 置 0 或省略）**，但装饰洁净带内要求"装饰互不重叠、线体与端点间距 ≥8px 显示"（换算设计 ≥18px）。**章节组合式才需要 zone**：标题 18px（行高1.4）+ 8px 间距 + 短横条 3px + 上下留白 ≈ **50-60px 显示高** → 画布 **750×150**、zone 显示高 ≥50px → **设计高 ≥110px（y 20..130）**、zone 显示宽 ≥300px → **设计宽 ≥650px（x 50..700）**。**文案长度约束（375px 壳实测前提）**：章节标题 ≤10 字（18px 一行 ≈11 字），超长文案换行越界 = 不合格。
3. **PNG 体积铁律**：4x 渲染后 **≤1MB**（uploadimg 硬限）。分割线**纯色平面化优先**（零渐变/零阴影）；大面积背景渐变若必须使用，**必须用垂直方向**（水平渐变在 750px 宽的每一行都是不同像素，PNG 熵爆炸）。渐变仍用 `gradientUnits="userSpaceOnUse"` + 绝对坐标。
4. **zone 字段**：无文字型资产 `zone:null`（标注 **exempt zone：无文字**）；章节组合式带 `zone:{x0,y0,x1,y1}` 设计坐标，标注文字安全区。
5. **验证闭环（三层，缺一不可）**：
   - ① 资产级：渲染 4x PNG + probe 像素验证（落纯色部件，容差 ±12）+ 体积 ≤1MB；
   - ② 装饰洁净带：y10..80 区域相邻像素突变扫描（线体连贯、装饰互不重叠，突变行必须为 0 或只在带外）；
   - ③ **375px 壳实测**：章节组合式把真实标题文案按 zone 缩放后叠入图片（DOM 检查文字边界全部落在 zone 矩形内，getBoundingClientRect 对比，**10/10 全部通过才算完成**）；无文字型验证装饰显示尺寸（端点显示 ≥8px、线体显示 ≥2.5px，375px 壳下抽查）。

### 5.1 通用铁律（继承 §一/§三）

- **密度铁律**：同篇 ≤2 种（锚定 1 个主款贯穿，另一个只在关键章节出现一次）；短文 1-2 处、长文按大章节 1 次；一段内不连续两个同款；一个章节内不重复；全文 ≥4 条说明结构该靠章节标题。
- **间距铁律**：上下各 24px（`margin:24px 0`）硬规范，短横条/色带水平居中额外 `margin:24px auto`；留白分节 40px；与图片/模块相邻中间至少隔一个 24px 停顿。
- **对比度铁律**：线体颜色与底色有对比；颜色与正文主色同源（只用相对淡版本），不引入第三个不相关颜色。
- **零 emoji/零图标字符铁律**：花边/端点必须是 CSS 几何 span 或 art:// 可绘制图形，字符图标永不进入分割线。
- **微信兼容铁律**：不用 `<hr>`（微信默认样式覆盖不稳，用自建 `<div style="border-top:1px solid 色">`）；禁伪元素（花边"对称装饰尾巴"不用 `::before/::after`，直接写 CSS 形状 span 或 art:// 植物图案）；嵌彩色卡片两端留白或配细边框、不用透明过渡；纯色平面化。
- **双模式铁律**：文字类以细线/圆点为骨（浅灰 `#e8e8e8`~`#c0c4cc`、短横条用主色但短而淡）、宣传类以短横条/花边为骨（80-120px 主色铺面、art:// 植物图案 + 主色），一篇只选其一模式；两种模式同篇都 ≤2 种。
- **验证方式**：375px 壳截图自查（分割线在正文里是"静"还是"吵"）；改参后整段截图到手机看一屏。

## 六、示例（骨架，可直接用）

**骨架 A · 细线（通用）**：

```html
<div style="height:0;border-top:1px solid #e8e8e8;margin:24px 0;"></div>
```
> 可替换处：线色 `#e8e8e8`（深一点 `#d8d8d8`，浅一点 `#f0f0f0`）、间距 24px。

**骨架 B · 主色短横条（章节强调）**：

```html
<div style="width:80px;height:3px;border-radius:2px;background:#2f6fed;border:1px solid #d6e4ff;margin:24px auto;"></div>
```
> 可替换处：主色 `#2f6fed`、宽度 60-120px、高度 3-5px、圆角 2-3px、描边色随主色浅档。

**骨架 C · 圆点 / 花边（收尾轻松）**：

```html
<div style="margin:24px 0;text-align:center;display:flex;justify-content:center;gap:6px;">
  <span style="width:7px;height:7px;border-radius:50%;background:#9a281f;"></span>
  <span style="width:2px;height:7px;background:#9a281f;"></span>
  <span style="width:7px;height:7px;border-radius:50%;background:#9a281f;"></span>
</div>
```
> 可替换处：颜色 `#9a281f`（主题色）、分隔符 `gap:4-8px`；也可用 `![小草](art://sprig-grass)` 居中替代。

**骨架 D · 横条色带（宣传/新年）**：

```html
<div style="margin:24px 0;height:4px;border-radius:2px;background:#d4a24c;border:1px solid #f0d9a8;"></div>
```
> 可替换处：色带色 `#d4a24c`、描边 `#f0d9a8`、高度 3-5px。

**骨架 E · 圆点分隔（中性通用）**：

```html
<div style="margin:24px 0;text-align:center;display:flex;justify-content:center;gap:10px;">
  <span style="width:6px;height:6px;border-radius:50%;background:#c0c4cc;"></span>
  <span style="width:6px;height:6px;border-radius:50%;background:#c0c4cc;"></span>
  <span style="width:6px;height:6px;border-radius:50%;background:#c0c4cc;"></span>
</div>
```
> 可替换处：颜色 `#c0c4cc`、`gap:8-12px`。

**骨架 F · 双条拼色横条（章节强调/宣传）**：

```html
<div style="margin:24px 0;display:flex;justify-content:center;align-items:center;gap:8px;">
  <div style="width:48px;height:4px;border-radius:2px;background:#2f6fed;"></div>
  <div style="width:48px;height:4px;border-radius:2px;background:#6b4fc4;"></div>
</div>
```
> 可替换处：主/辅两色、宽度各 40-60px、高度 3-5px。

**骨架 G · 章节切换（章节标题 + 下方短横条组合）**：

```html
<div style="margin:24px 0 0;">
  <h3 style="margin:0 0 8px;font-size:18px;font-weight:700;color:#1b2a4a;">第三章 · 开始行动</h3>
  <div style="width:60px;height:3px;border-radius:2px;background:#2f6fed;border:1px solid #d6e4ff;"></div>
</div>
<p style="font-size:15px;color:#333;line-height:1.75;margin:16px 0 24px;">跟正文呼应的章节开场说明。</p>
```
> 可替换处：章节序号与标题、短横条主色；此骨架把「章节标题」与「分隔短横条」结合，比单独用分割线更有"导航感"（参见「章节标题」条目）。

**骨架 H · 留白分节（极简/文艺）**：

```html
<div style="margin:40px 0;text-align:center;line-height:1;">
  <span style="display:inline-block;width:6px;height:6px;border-radius:50%;background:#c0c4cc;margin:0 4px;"></span>
  <span style="display:inline-block;width:6px;height:6px;border-radius:50%;background:#c0c4cc;margin:0 4px;"></span>
  <span style="display:inline-block;width:6px;height:6px;border-radius:50%;background:#c0c4cc;margin:0 4px;"></span>
</div>
<p style="font-size:14px;color:#8a94a6;text-align:center;margin:-32px 0 40px;line-height:1.75;">—— 间歇片刻，继续 ——</p>
```
> 可替换处：圆点样式（可用 CSS 圆点 span / art:// 植物图案）、颜色 `#c0c4cc`、过渡文案；留白间距 `40px` 大于常规的 24px，本身就是"停顿"。

**一篇的稳妥用法**：文字类——主款细线 `#e8e8e8` 贯穿 + 唯一一处章节切换换短横条 `#2f6fed`；宣传类——主款主色短横条 80px + 关键章节换 120px 双条拼色（或节日节点换 art花边式）。同篇 ≤2 种。

## 七、常见错误

- **反例**：`<hr>` 或 `<div>` 没设 `margin`，线贴到上下文字——密集挤成一团。**正解**：分割线 `margin:24px 0`，上下留足 24px 停顿（硬规范）。
- **反例**：一篇里细线、短横条、花边、横条色带四种全用，风格乱。**正解**：同篇 ≤2 种，锚定 1 个主分割线贯穿，另一个只在关键章节出现一次。
- **反例**：用 `<br>` 空行堆出"假分割线"——不同手机行高不同，间距不可控。**正解**：用真正的块级分割线元素 + `margin`/`height`。
- **反例**：横条写固定 `width:600px`，手机端超宽溢出破版。**正解**：宽度用固定小值 60-120px + 居中，或 `max-width:80%`，绝不用大 px 全宽。
- **反例**：文档中间无分割线、结尾才突然一条花边，读者感觉突兀。**正解**：分割线节奏均匀，或只在明确的"章节切换/情感转折"处出现，保持一致性。
- **反例**：分隔线粘在某个彩色卡片里，两端靠透明过渡，卡片深色底时出现生硬白圈。**正解**：嵌在彩色底上的装饰条用纯色 + 细边框，两端以留白收边即可，不做透明淡出。
- **反例**：把分割线当"标题占位"，在无数段落间堆叠却从不配文字标题。**正解**：线与标题分工——真正要提示"下一章讲什么"时用章节标题，分割线只做视觉停顿，别替标题说话。
- **反例（类型×风格新）**：想换风格时改骨架——把短横条式改成花边式（"换个风格"）。**正解**：换风格只换零件（线体颜色/端点图案/色板），换骨架是换组合方式；组合方式按文体选，风格按账号选。
- **反例（类型×风格新）**：风格词汇用 emoji/字符图标（🌿🌸 直接贴进分割线当花边）。**正解**：花边必须绘制成具体图形（CSS 形状 span 点条点拼法）或 art:// 资产，字符图标永不进入分割线。
- **反例（类型×风格新）**：每种风格换一套骨架（科技用细线、国潮用花边、校园用圆点轮着来），读者认不出"这是分割线"。**正解**：全篇一种组合方式贯穿（按文体定），风格只换内容零件——"停顿感一致"的契约比换花样重要。
- **反例（类型×风格新）**：端点装饰图案与风格错配——国潮风分割线端点却用西式珍珠串。**正解**：端点图案从该风格的图案词汇表取（国潮=回纹/印章/祥云/菱形，轻奢=珍珠，校园=花草），词汇表错配即返工。
- **反例（整图资产）**：给无文字型分割线硬套 zone（y 留 50..170 高文字区），画布被撑高成"竖条"，不再是横长条。**正解**：无文字型资产 exempt zone（zone:null）+ 装饰洁净带 y10..80，画布保持 750×90；只有章节组合式才建 zone（750×150），见 §五 5.0。

## 八、个性化空间

- **组合方式（类型）**：细线最万能/圆点最轻/短横条最现代/花边最有情调/色带最有仪式感/双条最"多段提亮"/章节组合最有导航感/留白最极简——按文体与风格选，同篇 ≤2 种。
- **线体参数**：线宽（细线 1px、短条 3-5px）、长度（短条 60-120px）、圆角（2-3px）；"一款主分隔 + 一款章节强调"两档——主款用中性（细线/圆点），章节款用该风格代表色。
- **颜色**：只用正文主色相对淡版本；短横条颜色数量（单主色 or 双条拼色）——科技商务单主色 `#2f6fed` 即可，国潮/节日红金双条 `#9a281f`+`#d4a24c`；颜色越多越"装饰"、越少越"结构"，别让分割线变成全文最花的地方。
- **长度与位置**：居中最正式、最通用；左对齐偏"手记"感；长文统一偏向一种，避免来回切换。
- **上下留白**：默认 24px，可微调 20-28px；想要"嘎然而止"的强转折可加大到 28-32px，但仍保持整篇一致、≥20px 底线。
- **与其他模块耦合**：分割线+花纹/章节宣传页可做更强的转场（见「花纹色带」「章节分隔宣传页」），但同篇装饰密度有限，别叠加过多；默认分割线保持独立简洁。
- **花边/留白分节"隐形分隔"**：极简白、文艺类用留白分节最贴合；其余风格默认用可见的分割线款；若文中已有多处强装饰（花纹/徽章），就用最轻的分割线甚至纯留白对冲。
- **风格扩展方向**：科技商务（结构线）、国潮（红金+回纹/印章）、校园（薄荷绿+花草）、极简白（隐形）——每种风格 = 一套图案词汇表填入 8 种模板的零件位（线体颜色 + 端点图案），先调研再入库（REQUIREMENTS.md 登记）。

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案
