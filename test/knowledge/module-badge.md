# 徽章 / 高亮（module-badge）

> 定位：**徽章 = 一个组件类型（type）**。本条目记录**这一类组件的生成方式**——5 种组合方式（骨架模板）分别怎么组织、零件位在哪、怎么按风格替换内容；以及"**类型 × 风格**"二维模型（风格决定内容）。徽章/高亮是"盖章 + 涂色"的强调组件：用小徽章（标签、角标）给价格/标签/类别"盖个章"，用高亮标记把重点文字"涂出来"，一眼抓住读者。若做 art:// 徽章底图资产（仅复杂图案徽章需要）必读 **§五 5.0 整图资产构建规范**（画布 300×120 / zone 容量 / PNG ≤1MB / 三层验证闭环）。
> 调用时机：价格、促销标签、栏目名、金句、关键词需要"点出来"时用；替代大段下划线/加粗，提升可扫性。**生成/改造徽章时**：先定组合方式（类型），再按风格填充内容（图案词汇表/色板）；不是"从变体清单里挑一个"。
> 素材来源：真实知识库 module-badge（5 种写法 A-E 参数 + 4 风格例子 + 双模式对照）+ 2026-08-29 类型×风格模型（与 module-bubble / module-subheading 同轮确立）。

## 〇、核心模型：类型 × 风格（2026-08-29 第 9 轮确立）

**徽章/高亮组件的美术表现由 2 个角度决定：类型（type）和风格（style）。**

| 角度 | 回答什么问题 | 在徽章上的体现 |
|---|---|---|
| **类型（type）** | 组件**怎么组织**（结构骨架）——这类组件怎么构建 | 徽章类型下有 **5 种组合方式**（行内小标签式/右上角角标式/高亮标记式/圆点状态式/描边胶囊式） |
| **风格（style）** | 组件里**放什么内容**（零件填充） | 同一种组合方式配不同风格 = 底色/字色/描边与点缀图案不同（国潮红金 / 科技蓝 / 校园薄荷 / 极简灰……） |

**两条核心关系**：
1. **类型决定骨架**：同一类型的所有徽章共享结构。例如"行内小标签式"= 行内 span（浅底 + 圆角 + 小字号）+ 文字槽，无论什么风格，骨架不变。
2. **风格决定内容**：骨架不动，内容色板与点缀随风格替换。**例如：描边胶囊式 + 国潮风 → 边框换朱红、文字换沙金，辅以 art:// 印章图案点缀**；配科技风 → 描边换蓝 `#2166ff`；配极简 → 描边换灰 `#d9d9d9`。

**知识库应该记录什么**：记录**类型的生成方式**（骨架怎么搭、零件位在哪、怎么按风格替换内容），而不是一份"现成徽章样式清单"。清单只是某个默认风格下的实现示例（见 §四）。

> 与 design-logic-components 的关系：组件 = 美术素材 + 文字；素材维度 = 类型 × 风格——类型管骨架（可复用结构），风格管内容（可替换零件）。徽章的"美术素材"主要来自 **CSS 行内 span（形状语言 + 色板）+ art:// 植物点缀**：徽章是**行内代码组件**（CSS span 为主，随文字排布），装饰点缀用 art:// 资产，与气泡/小标题的整图资产不同——多数徽章不需要整图，只有复杂图案徽章才走 art://。

## 一、构建总则（徽章类型怎么生成）

### 1.1 5 种组合方式（类型的子类）

| # | 组合方式 | 一句话结构 | 典型用途 |
|---|---|---|---|
| 1 | **行内小标签式** | 浅底小圆角 span 挂在词条/价格旁 | 价格/标签/类别盖章（官方认证感） |
| 2 | **右上角角标式** | absolute 定位到卡片右上角 + 斜角切边 | 卡片提示 HOT/爆款/限量 |
| 3 | **高亮标记式** | 行内 span 给关键词加浅底深字 | 金句/关键词"涂色"闪出重点 |
| 4 | **圆点状态式** | CSS 圆点（实/空）+ 状态文字 | 状态标注：报名中/售罄/已读 |
| 5 | **描边胶囊式** | 不填色，边框 + 深色文字 + 胶囊圆角 | 商务极简、栏目/系列名归类 |

### 1.2 构建五步（生成方式总流程）

1. **定组合方式**：按用途选 1 种（价格/标签→行内小标签或描边胶囊；卡片提示→角标；正文关键词→高亮；状态→圆点；双模式同篇只选一种调性：文字类全浅底深字、宣传类全纯色底白字）。
2. **搭骨架**：按 §二 对应模板搭行内 span 与零件位（先只画结构，不填内容）——形状语言（圆角/胶囊/描边/实底）+ 位置（行内/角标）+ 文字槽 + art 点缀位。
3. **按风格填内容**：查风格条目（style-* / index-style）得到该风格的**图案词汇表与色板**，填入零件位（§三）。
4. **填字与排版**：徽章文字 2-4 字（如"新品/限时/干货"）；挂到词条/价格旁（`margin-left:8px` 或 `margin-right:8px`）；行内徽章 `vertical-align:2px` 对齐；所在段落行高 1.75、块距 16px 不变。
5. **验证**：375px 壳实测——密度铁律（徽章 ≤3/篇、高亮每屏 ≤1、角标 ≤2/篇）、对比度 ≥4.5:1、微信兼容检查（§五）。

### 1.3 通用约束（先读，违反即返工）

- **一徽章一标签**：每枚徽章只装一个标签词（2-4 字），徽章不承载句子；句子给正文/卡片。
- **行内元素铁律**：徽章/高亮是行内 `<span>`（随文字排布）或单个块；不单独占块距，段落行高 1.75、块距 16px 由所在元素维持。
- **密度**：徽章 ≤3 个/篇；高亮每屏 ≤1 处；角标 ≤2 个/篇；同一卡片标签 ≤2 个；超出就收，让徽章保持"盖章"的稀缺感。
- **颜色 ≤3 色**：整体颜色数 ≤3 主色；一屏徽章+高亮不超 4 个色样，避免花。
- **零 emoji/零图标字符铁律**：点缀必须**可绘制的图形**（art:// 植物图案：`![小草](art://sprig-grass)`、`![花枝](art://blossom-branch)`），字符图标永不进入徽章。
- **强调 ≥2 通道**：高亮 = 颜色 + 字重/底色（浅底 + 深字 + `font-weight:700`），靠两个以上通道表达重点。
- **微信兼容**：徽章/高亮是行内元素微信端渲染稳定，但有两个坑——①绝对定位角标必须容器 `overflow:hidden`，否则斜角切不开；②浅底在深色背景下对比不足，务必"浅底 + 足够深的字"，不在徽章上写浅色字配浅色底。禁伪元素/投影/渐变/backdrop-filter。

**高亮 / 加粗 / 下划线三层分工（徽章语义选择速查）**：

| 层级 | 用法 | 密度上限 | 一句话区分 |
|---|---|---|---|
| **加粗** | 普通层级强调（小标题缩写/关键流程词） | 可多次（≥4-10 处） | "提一下"，不打断阅读 |
| **高亮** | 浅底+深字涂色，制造唯一焦点 | **每屏 ≤1 处** | "这一屏最要紧的一句" |
| **下划线** | 主要用于链接/可点击 | 不建议强调 | 易与链接混淆，别拿来强调 |

三者不叠在同一词上；若一句话有"提一下"与"必须记住"两个层次，加粗给前者、高亮留给后者——一屏只留一个高亮焦点。高亮只标 1-4 字短词，前后留标点/空格做停顿。

## 二、5 种组合方式的构建模板（核心：这类组件怎么构建）

> 每个模板给出：**骨架结构**（元素清单与位置）、**零件位**（可替换槽）、**尺寸与间距规范**、**叠字方式**（徽章是行内元素随文字排布）、**风格可变内容**、**默认实现**（当前库中已完成的一个风格版本，参数全部来自真实知识库 module-badge）。

### ① 行内小标签式

- **骨架**（行内 span）：`<span>`（浅底 + 小圆角 + 小字号）→ 文字槽（标签词 2-4 字）→ 挂在词条/价格旁。
- **零件位**：A. **形状语言**（直角 `border-radius:4px` / 胶囊 `999px` / 实底或浅底）B. 位置（行内，挂在标题/词条/价格数字旁）C. **文字槽**（标签词）D. **art 植物点缀位**（可选，跟在徽章旁不占文字）。
- **尺寸**：`display:inline-block`、`font-size:12px`、`line-height:1`、`padding:3px 7px`、`border-radius:4px`、`margin-left:8px`、`vertical-align:2px`。
- **叠字**：行内元素随文字排布——徽章紧贴词条/价格之后（`margin-left:8px`），与正文同一行基线对齐（`vertical-align:2px` 微调，否则贴到词条底部错位）。
- **风格可变内容**：**底色与字色**（浅底深字：红 `#fff1f0`/`#d4380d`、橙 `#fff7e6`/`#d48806`、蓝 `#e6f4ff`/`#1890ff`）+ 形状语言（4px 直角 / 999px 胶囊）+ 可选 art 点缀。
- **默认实现**：`font-size:12px`、`padding:3px 7px`、`border-radius:4px`、浅底深字、`margin-left:8px`、`vertical-align:2px`（原文 1.1 规格；价格旁示例：红 `#fff1f0`/`#d4380d`"新品"、橙 `#fff7e6`/`#d48806`"仅今天"）。
- **双模式**：文字类浅底深字（`#fff7e6` 米/`#f5f5f5` 极浅灰）；宣传类纯色底白字（`#c0392b` 红/`#2f6fed` 蓝，12-13px 加粗）。结构位置不变、只换外观。

### ② 右上角角标式

- **骨架**：容器 `<section>`（`position:relative` + `overflow:hidden` + 圆角）→ 角标 span（`position:absolute;top:0;right:0` + 斜角切边）→ 卡片文字槽（标题句 + 说明句）。
- **零件位**：A. **形状语言**（实底纯色块 + 斜角切边 `border-radius:0 12px 0 12px`，与容器圆角呼应）B. 位置（卡片右上角，绝对定位）C. **文字槽**（角标词 HOT/限量/新品，2-4 字）D. art 植物点缀位（可选）。
- **尺寸**：角标 `font-size:11px`、`line-height:1`、`padding:4px 10px 4px 12px`（左多留 2px 因切角）、`border-radius:0 12px 0 12px`（左上 0、右上 12、左下 0、右下 12）；容器 `border-radius:12px`、`padding:14px 16px`。
- **叠字**：角标 absolute 定位到卡片右上角，顶到卡片右上角、一角贴合容器圆角；标题在卡片内留 `padding-top` 空间，角标不挤正文标题。
- **风格可变内容**：角标纯色（红 `#c0392b` / 金 `#d4a24c` / 主品牌色）+ 角标词 + 卡片底色。
- **默认实现**：`background:#c0392b;color:#fff;font-size:11px;padding:4px 10px 4px 12px;border-radius:0 12px 0 12px`，容器 `#f7f9fc` 圆角 12px + `overflow:hidden`（原文 1.2 规格）。
- **铁律提醒**：容器必须 `overflow:hidden` 保证斜角裁切干净；角标 ≤2 个/篇，只给最重要的卡片。

### ③ 高亮标记式

- **骨架**（行内 span，模拟 `<mark>`）：`<span>`（浅底 + 深字 + 小圆角 + 加粗）→ 文字槽（关键词 1-4 字）→ 嵌在正文句子里。
- **零件位**：A. **形状语言**（浅底 `border-radius:3px` 小圆角）B. 位置（行内，正文句子内）C. **文字槽**（高亮词，1-4 字短词）D. art 植物点缀位（一般不用，高亮最克制）。
- **尺寸**：`background:浅底`、`color:深字`、`padding:1px 4px`、`border-radius:3px`、`font-weight:700`；字号 13-15px 跟随正文；与前后文字间距正常、不加额外 margin。
- **叠字**：行内随文字排布——高亮词嵌在句中（`==重点词==` 的视觉等价物），前后留标点/空格做停顿，不打断朗读。
- **风格可变内容**：**高亮色板**（浅黄 `#fff3bf`/`#b8860b` 字=最通用、主色浅底 `#e6f4ff`/`#1890ff` 字、警示橙 `#fff7e6`/`#d48806` 字、中性浅灰 `#f5f5f5`/`#333` 字）+ 圆角。
- **默认实现**：`background:#fff3bf;color:#b8860b;font-weight:700;padding:1px 4px;border-radius:3px`（原文 1.3 规格；高亮与加粗并用要克制，一段里高亮 ≤1 处）。
- **判断**：强调"重要"用黄、强调"品牌"用主色浅底、强调"警示"用橙、极简用灰；与正文底色的对比要足够（浅底 + 深字）。

### ④ 圆点状态式

- **骨架**（行内组合）：外层 span（状态文字 + 前置圆点）→ 圆点 span（`display:inline-block` + 圆形 + 颜色）→ 状态文字槽。
- **零件位**：A. **形状语言**（实心圆点 8px / 空心圆点=描边圆）B. 位置（行内，状态文字前）C. **文字槽**（状态词+说明："报名中（本周三截止）"）D. art 植物点缀位（可选）。
- **尺寸**：圆点 `width:8px;height:8px;border-radius:50%`、`margin-right:6px`；文字 `font-size:13px;color:#333;line-height:1.75`。
- **叠字**：圆点前置（`margin-right:6px` 与文字隔开），行内随文字排布；点色传达"开/关"语义。
- **风格可变内容**：**点色语义**（绿 `#18a058`=可行/开放、橙=提醒、灰=关闭）+ 点形态（实心/空心描边）+ 文字颜色。
- **默认实现**：绿点 `background:#18a058` + 状态文字（原文 1.4 规格："已读/未读、开票/不开票、正在报名"等状态标注）。
- **语义契约**：同篇点色语义固定——绿=开放、橙=提醒、灰=关闭，别今天绿=开放明天绿=售罄。

### ⑤ 描边胶囊式

- **骨架**（行内 span）：`<span>`（`border:1px solid 主色` + `color:主色` + 胶囊圆角 + 深色文字）→ 文字槽（栏目/系列名）→ 可选 art 点缀。
- **零件位**：A. **形状语言**（胶囊 `border-radius:999px` + **描边**——不填色，只边框+深字）B. 位置（行内，栏目标签/系列名前，`margin-right:8px`）C. **文字槽**（标签词）D. **art 植物点缀位**（可选——原文明确"辅以 art:// 植物图案做点缀，不占位、不加字形字符"）。
- **尺寸**：`border:1px solid 主色`、`color:主色`、`font-size:12px`、`line-height:1`、`padding:3px 10px`、`border-radius:999px`、`vertical-align:2px`。
- **叠字**：行内随文字排布——徽章前置（`margin-right:8px`）后跟正文；`vertical-align:2px` 对齐。
- **风格可变内容**：**描边色与文字色**（同色：蓝 `#2166ff` / 灰 `#d9d9d9`+深灰字 / 朱红+沙金）+ 胶囊圆角 + 可选 art 点缀图案。
- **默认实现**：`border:1px solid #2166ff;color:#2166ff;border-radius:999px;padding:3px 10px`（原文 1.5 规格："新功能"示例；极简/商务风最常用）。
- **判断**：归类清晰、不抢正文；商务极简首选。

## 三、风格如何决定内容（填充规则）

1. **风格条目 → 图案词汇表**：每个风格条目（style-*，见 index-style）应提供该风格的**图案词汇表与色板**（如：国潮红金 = 朱红/沙金/印章图案；科技商务 = 蓝 `#2166ff`/几何；校园清新 = 薄荷绿/叶片；极简白 = 灰描边/留白）。
2. **填入零件位**：把词汇表中的色板填入 §二 对应模板的"风格可变内容"零件位——骨架（形状语言/位置/文字槽）保持不变，只换颜色与点缀。徽章是**行内代码组件**（CSS span 为主），装饰点缀用 art:// 资产（`![小草](art://sprig-grass)`、`![花枝](art://blossom-branch)`、印章图案）。
3. **点缀必须是可绘制图形**：art:// 植物/印章图案是**具体图形资产**，不是 emoji/字符图标——符合 v10 铁律（禁 emoji/图标字符，但允许具体器物图形）。点缀不占位、不加字形字符。
4. **颜色随风格**：徽章底色/字色/描边色整组替换为风格色板，但**必须保留对比度**（浅底 + 深字 / 纯色底 + 白字）与**同篇颜色 ≤3 色**铁律；双模式切换只换外观不换结构。
5. **形状语言随风格微调但不混**：直角 4px 更理性、胶囊 999px 更亲和；**同一篇只保留一种形状语言（全直角或全胶囊），别混**。
6. **验证**：生成后按 §五 铁律实测（375px 壳、对比度 ≥4.5:1、密度），并登记 REQUIREMENTS（先记录后开发）。

> 示例：**描边胶囊式 + 国潮风**——骨架：`border:1px solid` + `border-radius:999px` + 文字槽不变；内容：边框换朱红 `#9a281f`、文字换沙金 `#d4a24c`，徽章旁加 `![印章](art://seal-stamp)` 点缀（不占文字位）；高亮同步换浅米 `#fff6ec`/`#a06a1a` 字。骨架不动、只换色板与点缀 = 类型 × 风格的正解。

## 四、现有实现 = 默认风格（中性/浅底深字）的实现示例

> 真实知识库 module-badge 的 5 种写法是**默认风格**下各模板的实现示例——不是全部可能，只是一份样板。生成新风格时按 §二 模板 + §三 规则重新填充即可。

| 组合方式 | 默认实现（真实参数） | 典型落点 |
|---|---|---|
| ① 行内小标签式 | 12px / `padding:3px 7px` / 圆角 4px / 浅底深字 / `margin-left:8px` / `vertical-align:2px` | 价格/促销标签、栏目名 |
| ② 右上角角标式 | 11px / `padding:4px 10px 4px 12px` / `border-radius:0 12px 0 12px` / 容器 `overflow:hidden` | 卡片 HOT/限量提示 |
| ③ 高亮标记式 | `padding:1px 4px` / 圆角 3px / 加粗 / 浅黄 `#fff3bf`+`#b8860b` 字 | 正文金句/关键词 |
| ④ 圆点状态式 | 圆点 8px 圆形 / `margin-right:6px` / 绿 `#18a058`=开放 | 状态标注（报名/售罄） |
| ⑤ 描边胶囊式 | `border:1px solid 主色` / `color:主色` / `padding:3px 10px` / 圆角 999px | 栏目/系列名、极简商务 |

> 变体参数（色号/圆角/padding/字号）完整保留于 §二 各模板"默认实现"行，不再重复列出。原文 4 个风格例子（科技商务/国潮红金/校园清新/极简白）即 4 套"风格词汇表"填充示例，见 §八。

## 五、构建验证与铁律（生成任何徽章必须满足）

### 5.0 整图资产构建规范（仅复杂图案徽章做 art:// 底图时满足；2026-08-29 第 9 轮·实测修正）

> **默认路径：徽章是行内代码组件（CSS span 为主），直接用 CSS 拼装，不走整图**。只有需要复杂图案（印章徽章/纹样徽章等无法用 CSS 几何表达的图案）时才做 art:// 底图资产。此时为**整图资产 + 中央嵌字模式**（与气泡/小标题 combo 资产一致）：SVG 画布模拟徽章形状 + 图案长在结构上，**中央区域留作文字区（zone）**。子智能体首轮失败根因：嵌字区高度只留 27px 显示，装不下徽章文字；大面积水平渐变致 PNG 超 1MB；只验"zone 内无装饰"未验"zone 装得下文字"。以下为强制规范：

1. **画布规格（默认）**：300×120（375px 壳显示 ≈137×55px，缩放比 ≈0.457）。徽章主体 y10 h100；**图案贴边（顶部/两侧），中央 40..260 × 35..85 为文字区**。
2. **文字区容量（核心，首轮失败点）**：徽章文字一行 12px（行高1.4）+ 上下留白 ≈ **20-24px 显示高**。换算为设计尺寸：zone 显示高 ≥20px → **设计高 ≥40px（y 35..85）**；zone 显示宽 ≥120px → **设计宽 ≥220px（x 40..260）**。**文案长度约束（375px 壳实测前提）**：徽章词 ≤4 字（12px 一行 ≈22 字，徽章标签 2-4 字必须单行不换行）。375px 壳叠字实测用真实文案（如"限时 5 折"），超长文案会换行越界 = 不合格。
3. **PNG 体积铁律**：4x 渲染后 **≤1MB**（uploadimg 硬限）。**大面积背景渐变必须用垂直方向**（水平渐变在每行都是不同像素，PNG 熵爆炸：实测水平渐变超限；改垂直后显著缩小）。渐变仍用 `gradientUnits="userSpaceOnUse"` + 绝对坐标。纯色平面化徽章无此风险。
4. **zone 字段**：每个资产必须带 `zone`（`{x0,y0,x1,y1}` 设计坐标），标注文字安全区。
5. **验证闭环（三层，缺一不可）**：
   - ① 资产级：渲染 4x PNG + probe 像素验证（落纯色部件，容差 ±12）+ 体积 ≤1MB；
   - ② zone 洁净度：相邻像素突变扫描（x35..265 区域逐行扫，相邻像素 RGB 差之和 >40 计数，突变 >12 的行必须为 0 或只在 zone 外）；
   - ③ **375px 壳叠字实测**（首轮缺失项）：把真实文案（徽章词 ≤4 字）按 zone 缩放后叠入图片，DOM 检查文字边界全部落在 zone 矩形内（getBoundingClientRect 对比），**10/10 全部通过才算完成**。

### 5.1 通用铁律（继承 §一/§三）

- **密度铁律**：徽章 ≤3 个/篇；高亮每屏 ≤1 处；角标 ≤2 个/篇（只给最重要的卡片）；同一卡片标签 ≤2 个；颜色 ≤3 色（一屏徽章+高亮不超 4 个色样）。
- **文字铁律**：一徽章一标签、徽章词 2-4 字；高亮词 1-4 字短词、前后留停顿；最重字号 ≤15px（高亮 13-15px 跟随正文）。
- **对比度铁律**：徽章/高亮文字与底色对比度 ≥4.5:1；浅底配深字、纯色底配白字最稳；不在徽章上写浅色字配浅色底（深色模式必翻车）。
- **零 emoji/零图标字符铁律**：点缀必须是 art:// 可绘制图形（植物/印章），字符图标永不进入徽章。
- **微信兼容铁律**：行内徽章 `vertical-align:2px` 对齐；absolute 角标必须容器 `overflow:hidden`（否则斜角切不开）；禁伪元素/投影/渐变（CSS 内）/backdrop-filter/outline/border-image。
- **双模式铁律**：文字类徽章浅底深字（中性浅底、比例低、色泽温和）、宣传类纯色底白字（高饱和更抓眼）；同一枚徽章只换外观不换位置与数量；一篇只选其一。
- **验证方式**：375px 壳截图自查（一眼分清重点/标签/正文）；改参后整段截图到手机看一屏——若满屏都是"盖章/涂色"说明密度超了，回退到密度铁律。

```html
  <span style="display:inline-block;background:#fff7e6;color:#d48806;font-size:12px;line-height:1;padding:3px 7px;border-radius:4px;margin-left:8px;vertical-align:2px;">买一送一</span>
</p>
```
（行内小标签式，文字类默认。**可替换**：徽章文字与浅底/深字色、圆角 4px→999px；数量保持 ≤3 个徽章。）

（描边/浅底胶囊式变体。**可替换**：徽章文字、浅蓝底 `#e6f4ff`/蓝字 `#1890ff`、圆角 999px；如需描边改 `border:1px solid #2166ff;color:#2166ff;padding:3px 10px;background:none`。）

## 七、常见错误

- **反例**：一篇贴了 7 个徽章，读者麻木，不知道该注意哪个。**正解**：徽章 ≤3，只在价格、栏目、促销等关键标签上"盖章"。
- **反例**：一段正文连续 4 处 ==高亮==，全部"重点"等于没重点。**正解**：高亮每屏 ≤1 处，其余用普通加粗/留白区分层级。
- **反例**：角标徽章的 `border-radius:0 12px 0 12px` 忘了容器 `overflow:hidden`，斜角露出难看缺口。**正解**：角标所在卡片写 `overflow:hidden`，切角才干净。
- **反例**：徽章用 `display:inline-block` 却忘记 `vertical-align:2px`，标签贴到词条底部错位。**正解**：行内徽章 `vertical-align:2px` 微调垂直对齐。
- **反例**：高亮直接嵌在超长句中间、前后无停顿，读者读不出边界。**正解**：高亮只标 1-4 字的短词，前后留标点或空格作为停顿。
- **反例（类型×风格新）**：想换风格时改骨架——把行内小标签式改成描边胶囊式（"换个风格"）。**正解**：换风格只换零件（底色/字色/描边/art 点缀），换骨架是换组合方式；组合方式按用途选（价格→小标签、栏目→胶囊、状态→圆点），风格按账号选。
- **反例（类型×风格新）**：风格词汇用 emoji/字符图标（🔥 NEW 🏷️ 直接贴进徽章）。**正解**：点缀必须绘制成 art:// 植物/印章资产（`![花枝](art://blossom-branch)`），字符图标永不进入徽章。
- **反例（类型×风格新）**：同篇里直角 4px、胶囊 999px、圆角 6px 混着用，读者认不出"这是同一种徽章"。**正解**：全篇一种形状语言贯穿（全直角或全胶囊），风格只换色板与点缀——"形状即语言"的契约比换花样重要。
- **反例（双模式）**：文字类推文给价格徽章用红纯色块大字号，温和文风变促销风。**正解**：文字类价格徽章只用中性浅底小标签淡淡标"限时"，宣传类才放纯色底白字放大加粗；双模式只换外观不换结构。
- **反例（整图资产·首轮实测失败）**：徽章底图画布 300×120 但 zone y30..60（显示仅 14px 高），装不下 12px 徽章文字。**正解**：zone 设计高 ≥40px（y 35..85），见 §五 5.0。
- **反例（整图资产·验证缺失）**：只验证"zone 内无装饰侵入"就宣称完成，没把真实文字叠进去实测——文字实际放不下。**正解**：三层验证闭环（资产级 probe + zone 洁净扫描 + **375px 壳叠字 DOM 实测**），见 §五 5.0。

## 八、个性化空间

- **形状语言**：直角 4px（理性）/ 胶囊 999px（亲和）；填色（实底）or 描边（不填色）。**判断依据**：商务极简用描边胶囊，宣传带货用纯色填色；**同一篇只保留一种形状语言，别混**。
- **高亮色板**：浅黄 `#fff3bf`/`#b8860b`（重要）、主色浅底 `#e6f4ff`/`#1890ff`（品牌）、警示橙 `#fff7e6`/`#d48806`（警示）、中性浅灰 `#f5f5f5`/`#333`（极简）。**判断依据**：与正文底色对比要足够（浅底 + 深字）。
- **字号与 padding**：副标题/正文旁徽章小一号（11-12px、`padding:2px 6px`），标题/价格旁可 12-13px（`padding:3px 8px`）；高亮统一 13-15px（跟随正文）、`padding:1px 4px`。字号越大越像"印章"，越小越像"脚注"。
- **一屏徽章数量**：信息密集的带货文可到 3 个（价格+限时+赠品），观点/干货文 1-2 个即可；同一卡片标签 ≤2 个避免拥挤。若要多挂，改用更小的字号与更淡的颜色对冲。
- **层级关系**：想让"标签"高于正文（如价格）就用实色/稍大字号；想让其低于正文（如脚注/来源）就用浅底小号、`color` 灰化。层级清晰是徽章排版的关键。
- **风格扩展方向（原文 4 风格例子即 4 套词汇表）**：科技商务（描边蓝 `#2166ff` + 高亮蓝浅底 `#e6f4ff`/`#1890ff`）；国潮红金（红底白字 `#9a281f` + 角标金 `#d4a24c` + 高亮浅米 `#fff6ec`/`#a06a1a` + art 印章点缀）；校园清新（薄荷绿实底 `#0bbf8f` 白字、圆角 6px + 高亮浅薄荷 `#e8faf4`/`#0a6b52`）；极简白（一律描边灰 `#d9d9d9` + 深灰字 + 高亮浅灰 `#f5f5f5`/`#333`）。每种风格 = 一套色板+点缀词汇表填入 5 种模板的零件位，先调研再入库（REQUIREMENTS.md 登记）。
- **调参自查**：改完任何一项后，把整段文字截图到手机看一屏——若一眼能分清"哪个是重点/哪个是标签、哪个是正文"，则火候正好；若满屏都是"盖章/涂色"，说明密度超了，回退到 §五 5.1 的限制。
