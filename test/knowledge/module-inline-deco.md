# 行内装饰资产（module-inline-deco）

> 定位：**行内装饰 = 随文字排布的小尺寸图案零件**（行首小花、句间星点、徽章旁小草等）。本条目记录这一类装饰的**生成方式与使用规范**——为什么旧写法会"飘到第一行上面"、怎么用新语法、行内资产必须满足什么构建规范。
> 调用时机：正文段落想加"行首小花 / 句间点缀 / 词旁小草"时；**整行居中的装饰图（独立成行）不归本条目**（那是整幅资产，走 module-art-assets 或整行图片路径）。
> 交叉：module-badge / module-list / style-* 里所有"行内 art:// 点缀"的写法均以本条目为准；气泡/标题的 absolute 角饰（`|grass` 等）不属行内装饰（独立定位，见 module-bubble）。
> 版本：2026-08-29 第 12 轮新建（svg 资产与文字协调问题根治）。

---

## 〇、核心模型：行内装饰 = 尺寸受控 + 底部锚点 + 基线对齐

- **旧问题（用户反馈）**："应该在第一行行首的小花由于大小问题飘到了第一行上面"。根因有二：
  1. **渲染器无行内模式**：`inline()` 对 `![说明](art://xxx)` 统一输出 `max-width:56%;height:auto;vertical-align:middle;margin:12px auto`——本意是整行居中装饰，行首小花也被放大到近 192px 宽 / 105px 高的巨盒，图案带与 15px 文字带底差达 -40px（实测）。
  2. **资产无对齐契约**：旧资产（sprig-grass 300×300、blossom-branch 400×220 等）图案在画布内位置不固定（有的贴底、有的居中、有的偏上），即使缩小也无法预测与基线的相对关系。
- **修复三板斧**（缺一不可）：
  1. **尺寸受控**：语法带显示高 `art://名称:px`（缺省 16px），渲染成 `height:Npx;width:auto` 的小图，不再按百分比放大。
  2. **底部锚点**：行内资产画布内图案底部**贴画布底边**（底边留白 ≤5px 设计）——这样 `vertical-align:baseline` 时图案"站在"文字基线上。
  3. **基线对齐**：渲染 CSS 用 `display:inline-block;vertical-align:baseline;margin:0 3px 0 0`，图片底边即文字基线，与 15px 正文天然同线。

---

## 一、构建总则

1. **语法**：`![说明](art://名称[:显示高px])`——`art://inline-flower:16` = 16px 显示高；`art://inline-star` = 缺省 16px。行内图**必须给高度**（或接受默认 16px），禁止让行内装饰按宽度百分比放大。
2. **渲染 CSS（inline() 内 art:// 分支）**：
   `display:inline-block;height:Npx;width:auto;vertical-align:baseline;border-radius:0;margin:0 3px 0 0`
3. **显示尺寸**：正文 14-16px 时，行内装饰显示高 **12-20px**（默认 16px；12px 极轻点缀、20px 强调徽章）。不小于 12px（太小不可见）、不大于 24px（超过一行字高显笨重）。
4. **密度**：行内装饰每屏 ≤2 处；一篇 ≤3 处。行首花/句间点二选一，不叠用。
5. **位置语义**：行首装饰 = 段首强调（像"¶"），句间装饰 = 轻点缀。**装饰不打断阅读**：行首花后紧跟正文，句间点前后留标点或空格。

## 二、构建模板（行内资产 = 紧裁 + 底部锚点）

### 骨架（SVG 画布 120×120 设计）

- **画布**：120×120 设计单位，4x 渲染 480×480 PNG；显示高 12-20px（缩放比 ≈0.10-0.17）。
- **零件位**：A. **主图案**（花/草/叶/星/球/印章等单一主题，1 个）B. **辅助件**（可选：叶/脉/高光/缝线，≤2 个）C. **底部锚点线**（y=115 设计基准，图案最低点贴此线）。
- **紧裁铁律**：主图案包围盒 ≥70% 画布宽 AND ≥70% 画布高（像素验证：4x PNG 非白 bbox ≥336×336px）。小尺寸下"透明边距"就是视觉上的错位，必须紧裁。
- **底部锚点铁律**：图案最低像素距画布底 ≤20px@4x（=5px 设计）。`vertical-align:baseline` 后图案底 ≈ 文字基线。
- **零 emoji/零字符/零渐变**：行内装饰是纯图案，同 v10 平面铁律（小尺寸下渐变不可见且增体积，纯色 2-3 层即可）。

## 三、风格如何决定内容

- 骨架（紧裁 120×120 + 底部锚点）不动，**主题与色板随风格替换**：
  - 校园风 → 球（足球/篮球/网球）+ 球场绿；行首花可用校徽橙。
  - 国潮风 → 朱印方章/回纹；金点缀用沙金。
  - 自然花草 → 花/草/叶 + 低饱和绿橙。
  - 科技风 → 星/菱形几何 + 冷蓝 #2f6fed。
  - 极简风 → 单色圆点/短线，宁少勿多。
- 图案词汇必须**绘制成具体图形**（SVG 路径/圆/椭圆），禁 emoji/字符图标。

## 五、铁律

1. **行内装饰必须给显示高**（`art://名称:px` 或默认 16px），禁止百分比宽度放大（旧 bug 根因）。
2. **行内 CSS 固定**：`vertical-align:baseline` + `margin:0 3px 0 0`；不要用 `vertical-align:middle`（巨盒时图案上飘）或 margin 12px（拉开与文字的距离）。
3. **资产紧裁 ≥70% + 底部锚点 ≤5px 设计**（见 §二）——这是"站上基线"的保证。
4. **密度**：每屏 ≤2 处、一篇 ≤3 处；行首花与句间点不叠用。
5. **零 emoji/零字符/零渐变**；纯色平面 2-3 层。
6. **独立成行的整幅装饰**（居中式）不适用本条目，仍走整行图片路径（居中 ≤56%）。

## 七、常见错误

1. **行首小花按百分比放大**（旧 bug）：`![小花](art://blossom-branch)` 被 inline() 输出 `max-width:56%` → 192×105px 巨盒飘离文字行。**正解**：行内装饰用 `art://名称:px` 语法给显示高；旧整幅资产不做行内用。
2. **行内图垂直居中**：`vertical-align:middle` + 高图 → 图案中心对齐文字中线，视觉上图案"浮在行上方"。**正解**：`vertical-align:baseline`（底边=基线）。
3. **资产图案不贴底**：用了 300×300 大画布、图案在画布中上部 → 缩小后图案与基线相对位置随机。**正解**：行内资产必须紧裁 + 底部锚点（§二）。
4. **行内装饰当整幅用**：把 16px 小图标放独立成行当分隔装饰 → 太小显单薄。**正解**：独立成行用整幅资产（居中 ≤56%），行内用小图标。
5. **密度失控**：一段里三四处行首花/句间点 → 花哨干扰阅读。**正解**：每屏 ≤2 处。

## 八、个性化空间

- **尺寸**：12px 极轻 / 16px 默认 / 20px 强调（徽章感）。
- **主题扩展**：按风格词汇表新增主题（球类家族：足球/篮球/网球；印章家族：回纹/云纹/如意）——沿用本条目骨架（120×120 紧裁 + 底部锚点 + probe 三层验证）。
- **色板**：同一主题换色 = 换风格（橙花→蓝花即科技风），骨架不动。
