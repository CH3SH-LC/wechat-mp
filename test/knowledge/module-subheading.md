# 小标题排版与装饰素材（module-subheading）

> 定位：**小标题 = 一个组件类型（type）**。本条目记录**这一类资产的生成方式**——7 种组合方式分别怎么组织、构建模板怎么用；以及**"类型 × 风格"二维模型**（风格决定内容）。小标题文字怎么写见 copy-subheading；组件设计世界观见 design-logic-components；风格条目见 index-style（style-*）。
> 调用时机：需要生成/选择小标题美术资产时——先定组合方式（类型），再按风格填充内容；不是"从清单里挑一个"。
> 素材来源：2026-08-29 深度调研（编辑器样式生态 15 类 + SVG 装饰素材 16 类 + 微信官方兼容实证）+ 7 轮开发（v1-v5 精细度 ×4），详见 `research/2026-08-29-research-subheading.md`。

---

## 〇、核心模型：类型 × 风格（2026-08-29 第 8 轮确立）

**一个组件的美术资产由 2 个角度决定：类型（type）和风格（style）。**

| 角度 | 回答什么问题 | 在小标题上的体现 |
|---|---|---|
| **类型（type）** | 组件**怎么组织**（结构骨架）——这类资产怎么构建 | 小标题类型下有 **7 种组合方式**（徽章式/夹线嵌字式/上下分割线式/下划线式/居中边框式/左对齐式/缎带横幅式） |
| **风格（style）** | 组件里**放什么内容**（零件填充） | 同一种组合方式配不同风格 = 内容图案不同（花草 / 球类 / 建筑 / 几何……） |

**两条核心关系**：
1. **类型决定骨架**：同一类型的所有资产共享结构。例如"序号徽章式"= 徽章底（形状+渐变）+ 内容图案槽 + 数字槽，无论什么风格，骨架不变。
2. **风格决定内容**：骨架不动，内容图案随风格替换。**例如：序号徽章式 + 阳光校园风 → 每个徽章分别由足球、篮球、网球构成**（内容图案换成球类）；配自然风 → 徽章内容是花草；配国潮 → 徽章内容是窗格纹。

**知识库应该记录什么**：记录**类型的生成方式**（骨架怎么搭、零件位在哪、怎么按风格替换内容），而不是一份"现成资产清单"。清单只是某个默认风格下的实现示例（见 §四）。

> 本节与 design-logic-components 的关系：组件 = 美术素材 + 文字；素材维度 = 类型 × 风格——类型管骨架（可复用结构），风格管内容（可替换零件）。

## 一、构建总则（小标题类型怎么生成）

### 1.1 7 种组合方式（类型的子类）

| # | 组合方式 | 一句话结构 | 典型用途 |
|---|---|---|---|
| 1 | **序号徽章式** | 徽章（底+图案+数字）前置 + 标题文字 | 教程/清单/编号 |
| 2 | **夹线嵌字式** | 左右线 + 中央留空嵌字 + 端点装饰 | 观点/居中标题 |
| 3 | **上下分割线式** | 上线+下线框架，文字叠中央 | 章节/大节标题 |
| 4 | **下划线式** | 标题在上、装饰线在下贴合 | 观点/金句/步骤 |
| 5 | **居中边框式** | 边框套标题，装饰长在框线上 | 精致/框式标题 |
| 6 | **左对齐式** | 左锚点装饰 + 左对齐标题 + 下划线 | 清单/左对齐 |
| 7 | **缎带横幅式** | 缎带横幅 + CTA 文字叠中央 | 活动/CTA/节日 |

### 1.2 构建五步（生成方式总流程）

1. **定组合方式**：按文体与内容选 1 种（一文 ≤2 种，样式一致性铁律）。
2. **搭骨架**：按 §二 对应模板搭结构元素与零件位（先只画结构，不填内容）。
3. **按风格填内容**：查风格条目（style-* / index-style）得到该风格的**图案词汇表**，填入零件位（§三）。
4. **叠字与排版**：标题文字用负 margin/absolute 叠入（微信白名单兼容）；间距按组件行距铁律收紧。
5. **验证**：渲染 375px 壳实测——显示尺寸铁律（主装饰 ≥10px）、精细度铁律（v5 ×4）、复杂度铁律（§五）。

### 1.3 通用约束（先读，违反即返工）

- **一文标题样式 ≤2 种**；装饰标题数量按文体分层（正文型 ≤2 处、宣传型 3-5 处）。
- **装饰密度分级**：功能性视觉元素（分隔/强调/编号/CTA）随组件走；纯装饰每屏 1-2 处。
- **素材一律 `art://` PNG 资产**：禁内联 SVG、禁 data URI、禁外链图片（T/CASME 1609—2024 白名单实证）。
- **零 emoji/零图标字符铁律**：图案必须**可绘制的图形**（植物/自然/几何/器物/球类等具体图形），字符图标永不进入素材库。
- 深度融合：装饰 ≤2 处/组件、同色系、长在结构线上（不是贴上去）。

## 二、7 种组合方式的构建模板（核心：这类资产怎么构建）

> 每个模板给出：**骨架结构**（元素清单与位置）、**零件位**（可替换槽）、**尺寸与间距规范**、**叠字方式**、**风格可变内容**、**默认实现**（当前库中已完成的一个风格版本）。

### ① 序号徽章式

- **骨架**（96×96 画布）：徽章底（形状 + 渐变底）→ 内容图案槽（中心，占徽章半径 60-70%）→ 数字槽（<text> 占位 "01"）。
- **零件位**：A. 徽章形状（圆/方/六边/菱形/花形/旗形……）B. **内容图案**（由风格决定：花草/球类/建筑/几何）C. 数字文本。
- **尺寸**：画布 96×96（或 120-130×120-130 带融合装饰），显示 24-48px；徽章直径≈标题行高；徽章与文字间距 6-12px。
- **叠字**：徽章左置 + 标题文字同行 flex 对齐（基线对齐）。
- **风格可变内容**：**徽章内的图案**（足球/篮球/网球 / 花朵/叶子 / 窗格纹……）+ 徽章形状 + 渐变配色（同色相深浅可换品牌色）。
- **默认实现**：`badge-num-circle/square/hexagon/diamond/flower/ring/banner`（7 个纯图案底）+ `combo-badge-vine/laurel/wreath/ribbon`（融合装饰版）。
- **换风格示例（用户点名）**：阳光校园风 → 徽章底换成球类图案徽章（足球/篮球/网球各一个），骨架与数字槽不变。

### ② 夹线嵌字式

- **骨架**（750×80-90）：左线 + 右线 + **中央留空 ≥260px（嵌字槽）** + 端点/线中装饰。
- **零件位**：A. 端点装饰（卷草/藤蔓花/珍珠/菱形/箭头……）B. 线样式（实线/虚线/双线/渐变线）C. 中心花饰（可选，必须在嵌字区外）。
- **尺寸**：画布 750×80-90，显示 343px（100%）或 60-70%；中央留空 300px 供 16-18px 标题嵌字；装饰线视觉 2-3px。
- **叠字**：文字叠线中央（absolute 居中 + `background:#fff` 遮断，线断于文字两侧）；**禁止"线在上、标题在下"**。
- **风格可变内容**：端点装饰图案 + 线样式 + 配色。
- **默认实现**：`clamp-line/line-flower/double/vine/dash/arrow`（6）+ `combo-clamp-vine-flower/pearl/diamond-flower`（3）。

### ③ 上下分割线式

- **骨架**（750×130）：上线 + 下线 + 中心花饰（上线正中）+ 左右端点。
- **零件位**：A. 中心花饰（花/玫瑰/菱形/星）B. 线样式（单/双/波浪/渐变）C. 端点装饰。
- **尺寸**：画布 750×130，显示 343px（100%）；上下线间距内为嵌字区（文字 16-18px）；端点显示 ≥8px。
- **叠字**：文字叠上下线中央（absolute 居中），线是框架 → 组件与正文间距 12-18px 收紧。
- **风格可变内容**：中心花饰图案 + 线样式 + 配色。
- **默认实现**：`combo-frame-lines` + `combo-lines-rose/double-vine/wave`（4）。

### ④ 下划线式

- **骨架**（520×70-80）：标题文字位（上方）+ 装饰线（下方贴合）+ 两端装饰。
- **零件位**：A. 装饰线样式（波浪/双线/藤蔓/树枝/金枝）B. 两端装饰（叶/花/珍珠/圆点）。
- **尺寸**：画布 520×70-80，显示 213px（62%）；线距文字 6-8px 贴合；线宽显示 ≥2.5px。
- **叠字**：标题在上、线在下（下划线式为常态）；**禁止上划线式**（线在标题上方）。
- **风格可变内容**：线的形态（线是"内容"载体——藤蔓风/金枝风/波浪风）+ 两端装饰。
- **默认实现**：`underline-wave/double/scribble`（3）+ `combo-underline-center/vine/double-flower/branch`（4）。

### ⑤ 居中边框式

- **骨架**（600×150）：双线圆角框 + 四角装饰位 + 顶部/底部装饰线 + 中央嵌字区。
- **零件位**：A. 角部装饰（左上花右下叶/四角花/珍珠链/花枝——**长在框线上**）B. 框样式（单线/双线/渐变描边）C. 中央嵌字槽。
- **尺寸**：画布 600×150，显示 343px（100%）；框内嵌字区 ≥100px 高；角部装饰显示 ≥20px。
- **叠字**：文字叠框内中央（absolute 居中）；框自带分隔 → 组件与正文 16-20px。
- **风格可变内容**：角部装饰图案（花/叶/珍珠/几何）+ 框样式 + 配色。
- **默认实现**：`combo-frame-corner-flower/vine-rose/quad-flower/gold-band/corner-branch`（5）+ `frame-title-*`（3 简易框）。

### ⑥ 左对齐式

- **骨架**（520×100）：左锚点装饰（花锚）+ 左对齐标题文字位 + 横向下划线（从左延伸）。
- **零件位**：A. 左锚点（花锚/几何锚）B. 下划线样式 C. 线上点缀（珍珠/圆点）。
- **尺寸**：画布 520×100，显示 180px（52%）；标题文字叠左侧线上方（左对齐）；线距文字 6-8px。
- **叠字**：文字 absolute 叠左侧（左对齐），线在文字下方。
- **风格可变内容**：左锚点图案 + 线样式 + 配色。
- **默认实现**：`combo-underline-left`（1）。

### ⑦ 缎带横幅式

- **骨架**（340×110）：缎带面（渐变）+ 顶部/两端装饰位 + 虚线饰线 + 中央文字区。
- **零件位**：A. 顶部/两端装饰（花冠/双侧花/藤蔓花——**长在缎带上**）B. 缎带形态（折角/卷轴/旗串）C. 中央文字槽。
- **尺寸**：画布 340×110，显示 213px（62%）；CTA 文字叠缎带中央（白色 15px）；CTA 与正文 20-26px。
- **叠字**：CTA 文字叠缎带中央（absolute 居中）。
- **风格可变内容**：装饰图案（花冠/花束/星星）+ 缎带形态 + 配色。
- **默认实现**：`combo-banner-crown/twin-flower/scroll-vine/flag-crown`（4）+ `banner-mini/flag/scroll`（3 简易）。

## 三、风格如何决定内容（填充规则）

1. **风格条目 → 图案词汇表**：每个风格条目（style-*，见 index-style）应提供该风格的**图案词汇表**（如：阳光校园风 = 足球/篮球/网球/跑道/奖杯/校徽；自然田园风 = 花草/叶子/藤蔓/果实；国潮风 = 窗格/回纹/祥云/印章）。
2. **填入零件位**：把词汇表中的图案绘制为 SVG 图形，填入 §二 对应模板的"风格可变内容"零件位——骨架（形状/线/框）保持不变，只换内容。
3. **图案必须是可绘制图形**：足球/篮球/网球等是**具体图形**（可用圆形+线缝弧线绘制），不是 emoji/字符图标——符合 v10 铁律（禁 emoji/图标字符，但允许具体器物图形）。
4. **颜色随风格**：风格条目定义色板（同色相深浅两档可换），渐变用同色相明暗。
5. **验证**：生成后按 §五 铁律渲染实测（尺寸/精细度/复杂度），并登记 REQUIREMENTS（先记录后开发）。

> 示例：**序号徽章式 + 阳光校园风**——骨架：圆徽章底 + 内容图案槽 + 数字槽；内容：徽章①=足球（圆形+五边形缝线）、徽章②=篮球（圆形+曲线缝线）、徽章③=网球（圆形+弧线缝线）；配色：校徽橙/球场绿；数字 "01/02/03" 不变。

## 五、构建验证与铁律（生成任何小标题资产必须满足）

- **线条方向铁律**：装饰线以下置（下划线式）为常态；夹线必须嵌字（线断于文字两侧）；禁上划线式。
- **组件行距铁律**：组件自带线条/边框分隔时四周空行收紧（组件与正文 12-20px、标题与装饰线 6-8px、段落 12px）。
- **深度融合铁律**：装饰长在组件结构上（框角/线端/缎带顶）、≤2 处/组件、同色系。
- **显示尺寸铁律**：设计像素 = 目标显示像素 ÷ 缩放比（375px 壳显示宽 179-343px，缩放 0.4-0.6）：主装饰花显示 ≥20px、叶 ≥16px、珍珠 ≥8px、线 ≥2.5px；主装饰最小边 ≥10px 判定 OK。
- **精细度铁律（v5 ×4）**：花瓣 4 层（外瓣渐变+中层 0.85+内层 0.9+高光月牙）+花蕊丝 3 根；渐变 4-6 stop；叶子主脉+侧脉×2+边缘高光；珍珠径向渐变+双高光；S 形双弧卷曲；渲染分辨率 4x（PNG ≤1MB）。
- **复杂度铁律**：渐变 ≥2 段、装饰 ≥2 处且长在结构上、珍珠/叶脉/多层花瓣细节、嵌字类装饰避开文字区（中央留空 ≥260px）。
- **SVG 实现要点**：线渐变用 `gradientUnits="userSpaceOnUse"` + 绝对坐标（x2=画布宽）；花/主体画在叶子等覆盖物之上；批量升级必须限定匹配范围（大形状不套小装饰规则）。
- 验证方式：`render-subheading-test.mjs` / `render-combo-test.mjs` / `render-combo2-test.mjs`（4x 渲染 + probe 像素验证 + 体积检查）+ `render-top20.mjs`（375px 壳实测）。

## 七、常见错误

- **反例**：每章换一种标题花样（竖条/徽章/夹线/框轮着来）。**正解**：一文 ≤2 种，主样式贯穿。
- **反例**：把"选现成资产"当生成方式——清单里没有就拼不出。**正解**：按 §二 模板搭骨架，按风格填内容（类型 × 风格模型），清单只是默认风格示例。
- **反例**：标题旁边塞 3 个装饰（徽章+夹线+分隔线全堆在一个标题上）。**正解**：一个组件最多 1 处容器装饰 + 1 处点缀；纯装饰每屏 1-2 处。
- **反例**：正文型干货文也照宣传型堆装饰。**正解**：按文体分层——干货文收紧，宣传/活动文才放开。
- **反例**：直接贴内联 `<svg>` 进正文做装饰。**正解**：微信白名单会清洗，一律走 art:// PNG 资产。
- **反例**：用 emoji/图标字符当标题装饰。**正解**：图案必须可绘制图形（植物/自然/几何/器物/球类等具体图形），字符图标永不进入素材库。
- **反例**：徽章数字与标题文字重复编号（"01"徽章+"01 · 标题"）。**正解**：二选一。
- **反例**：夹线/分隔线放在标题上方（上划线式）。**正解**：线条装饰下置或夹线嵌字；上划线式真实推文极少见。
- **反例**：标题组件上下都有线条，再加宽空行。**正解**：一个标题一个方向（≤1 处线条装饰）；组件自带分隔时收紧四周空行。
- **反例**：装饰图宽 750px 通栏铺满。**正解**：整行装饰自动收窄 ≤56%≈179px，或选更窄的资产。

## 八、个性化空间

- **徽章形状**：圆/方/六边/菱形/花形/旗形对应不同气质（圆=通用/方=干货/六边=国潮特辑）；**内容图案随风格换**（球类/花草/窗格/几何）。
- **夹线宽度**：默认 750×80 中部留空 300px（嵌字式）；标题更长可换 CSS 拼线。
- **组合套路**：教程=徽章+动宾标题；观点=夹线+问句标题；特辑=六边徽章+对仗标题；极简=分隔线+纯文字；活动=缎带+CTA。
- **风格扩展方向**：阳光校园（球类/跑道/奖杯）、国潮（窗格/回纹/祥云）、科技（几何/电路/网格）、手账（涂鸦/胶带/贴纸）——每种风格 = 一套图案词汇表填入 7 种模板，先调研再入库（REQUIREMENTS.md 登记）。
- **深度融合**：优先用 `combo-*` 复合资产（装饰长在结构上）；单资产拼贴时装饰 ≤2 处、同色系、长在结构线上。

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案（SVG 内渐变/高光仅存在于资产 PNG 图片中，合法）
