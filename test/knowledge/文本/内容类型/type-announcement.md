# 公告通知

> 定位：向读者正式告知一件事的变动或一项规则，让"看了就懂、能照做"，靠清晰完整和得体语气避免信息错漏。
> 调用时机：公众号改名 / 迁移、营业时间调整、场馆 / 课程 / 活动变更；报名 / 领奖 / 截止通知、规则与政策声明、接受反馈的公告。凡是"有明确事项要读者知道并照做"的官方稿件，都是这一型。

## 一、类型定义与特征（详细）

**1. 公告通知和普通推文的最大区别**

- 读者看完是要去"办一件事"的——报名、改签、遵守新规、联系你。
- 它不追求有趣，追求"零误差"。定位一句话：让读者三分钟看清"发生了什么、我需要做什么、有问题找谁"。
- 有趣是加分项，清晰可执行是及格线；两者冲突时永远优先清晰。
- 换角度看：通知不是写来"被喜欢"的，是写来"被照做"的。读者每次"照做成功"，都是对公告最好的检验。

**2. 三个核心特征**

特征一：信息必须是完整的、可执行的。

- 读者拿着通知就能直接办事，不需要再回来问你。时间、地点、对象、规则、联系人，缺一项都可能让读者白跑或错过截止。
- 完整度自查法：把自己当读者，按通知把该办的事从头办一遍，看在哪一步会停下来找答案——停下的地方就是缺信息的地方。

特征二：语气正式但不冰冷。

- 要有权威感（这是官方宣布），却不能让读者觉得被命令、被训话。公告写得太冷，往往引来大量"没看懂 / 太凶了"留言，反而不省事。
- 权威感靠"信息确凿"，亲和感靠"措辞有缓冲"，两者可并存。判断：读完是"知道了、照做"的顺畅，还是"被吼了"的反感？前者对。

特征三：便于扫描和复查。

- 读者通常带着问题来读（"改到几点了？""我符合吗？"）。要用加粗、分条、小标题把关键信息挖出来，让他 30 秒找到答案。
- 读者可能事后回来看一眼确认，所以关键信息最好固定在稳定位置（都放开头 / 编号条目），他第三次看也不迷路。

**3. 适用场景确认**

- 只要你要"正式告知一件必须遵循的事"，就套公告。如果只是分享想法、推荐好物，那是别的类型。
- 同一件事偏分享口吻可转情感 / 资讯，但涉及规则 / 截止 / 变更，宁可正式走公告型避免误导；偏向"让人照做"就坚定用公告。
- 判断技巧：先问"读者不照做会有什么后果 / 损失"？有后果就正式公告，后果越重越要正式严谨。

## 二、标准结构骨架（分阶段展开）

公告通知用三段式：**事项 → 细节 → 联系方式**。

**阶段一：事项（第 1-2 段，必须开门见山）**

- 第一段就说清"要宣布什么"，不要铺垫、不要绕；读者最怕点进来看一堆开头抒情才知道是通知。
- 正例（直接）：自下月 1 日起，本自习室营业时间调整为 8:00-22:00。／反例（绕）：春天来了，我们也想给大家更好的自习环境……最后才抖出时间。
- 若为变更，先点明"改了什么、何时生效"；若为新规，先说"新规是什么、谁适用"。把最关键"结论"放第一屏，是该类型铁律。
- 第一段公式可固定："关于 XXX 的调整，自 XX 时间起生效，要点如下。"一句话把对象、动作、时间、性质交代完。

**阶段二：细节（主体，按读者关心的点拆条）**

- 把"关键信息"逐条写清，放在读者一眼能抓到的位置。常见必核项（按实际取舍）：时间（具体到日期 / 时刻 / 生效日，注明含节假日否）、地点 / 渠道、对象 / 适用范围、规则 / 步骤、截止 / 变动。
- 用加粗小标题或列表逐条呈现，一条单独成句；避免一句塞多个信息。反例："每周二和周四 14:00 在 A 栋和 B 栋都有课"这类合并句要拆开。
- 拆条顺序按"读者行动的顺序"：先办第 1 步 → 第 2 步 → 第 3 步，或"改了什么"→"谁受影响"→"怎么办"，别按你自己习惯的顺序。

**阶段三：联系方式（结尾，必留）**

- 给出读者有问题时找谁：联系人 / 电话 / 微信号 / 客服、工作时间、问题类型建议走哪种渠道；再附一句"若不便看，可随时留言 / 私信"降低摩擦。
- 联系方式是让公告"闭环"的最后一环，缺失整篇判不合格。
- 最好按问题类型区分"报名问题找 A、系统问题找 B"，避免读者拿着问题又回到原点。

## 三、写作要点（配示例）

要点 1：关键信息要"齐全且互不冲突"。

- 写完逐项核对：时间、地点、对象、规则、联系人，每项都问"读者按这个去办会不会卡住"。
- 正例："报名截止 5 月 20 日 24:00，逾期不候；若报名后临时有事，请至少提前 1 天取消。"／反例："尽快报名，以免名额不足。"（几号？没法安排）
- 尤其核对最易冲突的三条：生效时间、截止时间、节假日安排，这三条常打架。

要点 2：一个动作一句话，别挤在一起。

- "先扫码填表，再转账，然后截图发客服"三步连一起很容易漏。拆成有序列表逐条写。
- 反例：请先扫码报名并付款然后加客服微信备注姓名。／正例：1 扫码填报名信息 2 完成付款 3 截图支付页发给客服并备注姓名。三步各占一行。
- "一步一行"是最省脑筋的写法，读者大脑不用自己拆解长句。

要点 3：语气正式但不冰冷。

- 多用"请您""我们建议""如有不便深表歉意"缓冲命令感，但别滑向全套客套话。
- 正例："因系统升级，本周六起旧版报名入口暂停，请您改用新入口（见下）。不便之处敬请谅解。"／反例："旧入口已废弃，谁再报就不行了。"（生硬）
- 缓冲只作用于命令句，核心信息仍要果断确凿；一句"如有不便敬请谅解"够了，别每段三句道歉显得卑微。

要点 4：重要的信息要"强调"但别"全篇强调"。

- 把生效时间、截止日期、联系电话这三类最易戳的信息加粗或高亮，别的留白；到处加粗等于没强调。
- 一个原则：一屏只亮一个重点。时间、地点、联系人各自单独一行亮出，不挤一行互相抢。

要点 5：给"对接下来的安排"衔接。

- 涉及变动时，说明"已有的安排怎么衔接"（已报名怎么办、原预约如何顺延），消除读者焦虑。
- 反例：只说改了，不说原来报名的人怎么办。／正例：已报名的名额自动保留 / 原预约顺延至下周一同一时段。
- 变动类衔接要具体到"谁、怎么办、什么时限"："已约满 5 月 20 日前课时的读者，请在 5 月 15 日前确认改期。"

要点 6：说清"这是在帮谁、为什么"。

- 涉及打扰读者的变动，补一句"为什么改"（维护需要 / 为了更好地服务大家），让读者配合时心里舒服。
- 反例：三天两头改却从不解释，读者只觉得烦。／正例：为配合一年一度的场馆维护，本周营业时间调整如下……给您带来不便敬请谅解。
- 一句合理的"为什么"，能把一次打扰变成一次理解，性价比极高。

## 四、风格与模块建议

风格优先考虑：

1. 商务风——职场 / 机构 / 正式公告，藏蓝 + 灰、细线边框最显专业可信。
2. 极简风——想让通知克制、信息突出、大留白时用。
3. 校园风——机构面向大众的活动通知，明快友好。
4. 插画风——促销 / 趣味公告，活泼热闹。

核心原则：正式度高的用商务 / 极简传达"可靠"；亲和场景用校园 / 插画传达"友好"。

模块上搭配使用：

- 引言 / 导语模块：放事项段，开门见山给结论。
- 列表模块：细节段一个事项一条，扫读友好。
- 时间线模块：呈现"旧安排 → 新安排"的衔接。
- 高亮 / 强调模块：突出截止与生效时间。
- 联系方式模块 / 行动号召：结尾给出"找谁"和行动入口。

注意事项：公告尤其要遵守间距规范，信息一多更靠清晰排版站稳；关键信息加粗 / 高亮要克制集中，别让整篇都在强调；标题用直述式"关于……的通知 / 调整通知"，读者是来办事的不是来猎奇的。

## 五、常见错误（反例 + 正解）

错误 1：信息缺失。

- 反例："报名截止时间我们会另行通知。"（那这篇公告等于没说）
- 正解：一次写清截止日、操作路径、联系人，宁可啰嗦不可少。
- 判断：读者按公告能不能直接办成事？办不成就是信息缺失。

错误 2：语气不当（太冷或太软）。

- 反例（太冷）："逾期不报，责任自负。"／反例（太软）："可以的话麻烦尽量参加一下哦～"
- 正解（中性带缓冲）："请您在 5 月 20 日前完成报名；考虑到大家时间安排有差异，我们优先保障先报名者。"
- 判断：读完是觉得被命令，还是觉得能照做？缓冲 + 确凿并存才对。

错误 3：关键信息被埋。

- 反例：一大段文字最后一句带出"即日起改为 9 点"。
- 正解：生效时间放最前或独立加粗，让 30 秒能定位。
- 判断：把公告合上，问读者"改到几点了"，答不出就是没埋到位。

错误 4：写成宣传文。

- 反例：三百字情怀铺垫后才说正事，读者刷走时还不知道改了什么。
- 正解：第一段直接入正题，情怀放到结尾可有可无。
- 判断：第一段是不是在"宣布事项"？不是就先改第一段。

错误 5：只喊话不落地。

- 反例："本活动时间和地点有所调整，请留意。"（调成什么？原报名的怎么办？）
- 正解：新时间地点写全，并补"已报名名额自动保留 / 需重新确认"衔接句。
- 判断：取消所有模棱两可的"有所调整 / 请留意"，换成确凿的数字和日期。

错误 6：一处信息前后矛盾。

- 反例：开头写"截止 5 月 20 日"，末尾提示又写"5 月 19 日前完成报名"。
- 正解：一套数字从头用到尾，核对所有提到时间 / 地点的句子是否一致。
- 判断：日期、金额、地点三类信息全篇核对一遍，一个字都不能打架。

## 六、示例骨架（可套用大纲）

"公告通知 · 商务风"骨架，可填空套用：

- 标题：关于周末自习室开放时间调整的通知
- 事项（1-2 段）：第一段点明"为配合场馆维护，本周末（5 月 18-19 日）自习室开放时间调整为 8:00-18:00，其余日期不变。"先给结论。
- 细节（逐条，列表）：
  - 生效时间：5 月 18 日、19 日，8:00-18:00；5 月 20 日起恢复正常 8:00-22:00。
  - 适用对象：在读且有资格的学员；临时访客不受影响。
  - 原预约衔接：已预约两日 18:00 后座位自动顺延至下周一同一时段，无需重新预约。
  - 营业变化提示：周六 18:00 闭馆消毒，请提前安排离场。
- 联系方式（结尾）：需调整预约或咨询，联系值班客服（微信：XX，工作时间 9:00-17:00）；不便之处敬请谅解。
- 结尾：一句礼貌收束，不喊口号。

套用时可替换：把"自习室开放时间"换成你要告知的事项；把"5 月 18-19 日 / 8:00-18:00"换成真实日期时段；把"原预约顺延"换成匹配的衔接方案；把客服信息换成你的真实联系方式与工作时间。

另一版更偏"规则声明"的可选骨架（不涉及变更，是立新规）：

- 标题：关于规范评论区的几点说明
- 事项：第一段宣布"为给大家更好的交流环境，自即日起评论区内禁止出现 XX 三类内容"。
- 细节：逐条列出禁止行为 + 违规处理后果 + 适用范围（所有读者 / 长期有效）。
- 提示：给一个"对正常交流无影响"的安心句，说明"正常提问、分享、友善讨论完全不受影响"。
- 联系方式：对处理有异议或申诉，联系客服。
- 说明：公告不全是"改什么"，也可以是"规定什么"；核心仍是要点清晰 + 找得到人。

## 七、个性化空间（按账号自定，附判断依据）

1. 语气冷热：给学员 / 会员的公告可亲和一些（加"辛苦了""感谢理解"）；涉及规则 / 红线 / 安全的公告偏正式权威。
2. 信息详略：面向学生 / 大众、出错代价高就写细；面向老手、代价低可精简。
3. 是否加感情与衔接段：这次变动会让读者困惑 / 不满就加"为什么改"的解释；例行通知则不加。
4. 视觉正式度：商务 / 极简偏冷正式，插画 / 校园偏活泼；严肃事项别用太花俏风格，会削弱可信度。
5. 是否放"常见问题"：本次变动可预见疑问多、篇幅允许就加一段问答；纯例行则不必。
6. 是否标"公告编号 / 版本号"：多次修订的规则类公告适合编号方便区分新旧；一次性通知不必。
7. 是否附"接受反馈"入口：规则争议大、需要安抚时给反馈入口；纯例行通知可省。
