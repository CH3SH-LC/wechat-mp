# comp-banned · 广告法违禁词：绝对化用语清单与合规改写

> 定位：绝对化用语（"最""第一""顶级"等）是《广告法》明令禁止的表述，触碰即违规，是公众号内容里最常见的踩线原因。本条目给出完整违禁词清单、变体规避的误区、合规改写对照与发布前自查流程。
> 调用时机：**每篇推文定稿后、发布前必读**；尤其带货、软文、品牌宣传、标题与卖点文案里出现夸张表述时。

## 一、核心规则（绝对化用语全面拆解）

### 1.1 为什么这些词不能碰
《广告法》明确禁止使用**绝对化用语**——也就是把商品、服务的能力说成"没有例外、独一无二、无法超越"的词。这里的逻辑是：任何产品在客观上都无法做到百分之百地"最"，宣称"最"就是一种无法被证实的虚假、夸大连带不正当竞争。一旦被认定，轻则单篇删除、限流，重则面临罚款甚至暂停发布（具体处罚机制见「违规后果与申诉」条目）。因此对待这些词的态度是**宁严勿松**——宁可删掉一个有诱惑力的词，也不要抱着侥幸心理去赌平台和执法不看到。

### 1.2 「最」系违禁词（出现频率最高，发布前必查）
这是全篇最需要注意的一类，几乎每篇带货、软文、产品介绍都可能踩中。凡是把"最"用在宣称质量、排名、实用性、性价比、受欢迎程度的，都属于违禁项。

- 最、最优、最佳、最美
- 最新、最先进、最创新、最前沿
- 最专业、最权威、最经典
- 最受欢迎、最畅销、最火爆、最热门
- 最全面、最适合、最值得
- 最大、最小、最强、最快
- 最高端、最低廉、最优惠、最具性价比
- 最舒适、最好用、最好看、最好吃
- 最耐用、最安全、最省心、最可靠
- 最受信赖、最靠谱、最值得拥有

> 判断要领："最"后面接的如果是一个**可比较的质量、体验、排名**（最好用、最划算、最专业），几乎都是违禁项；只有当"最"在描述一个客观位置、且没有夸耀意味时不在此列（后文 1.3 会细讲判断法则）。

### 1.3 「一」系（"唯一、第一"及"独一无二"类）
这类词通过宣称"占据第一、独占鳌头"来抬高自己，同样无法被普遍证实，属于违禁项。

- 第一、全国第一、世界第一、行业第一、销量第一、排名第一
- 名列前茅、独占鳌头、无出其右、无与伦比
- 独一无二、绝无仅有、史无前例、前所未有
- 顶级、顶尖、顶峰、巅峰、极致、极限、登峰造极
- 业界翘楚、金字塔顶端、含金量拉满
- 首款、首创、首发、绝版

> 关于"首款/首创/首发"：如果确实是**行业头一遭、且能拿出媒体发布、备案、专利等可查证据**，站在"新品发布"的角度勉强可用；但绝大多数情况下运营者拿不出权威证据，稳妥起见一律改写。**"独一无二/绝无仅有"这类抽象表述几乎不可证，一律改写。**

### 1.4 「级」系（"国家级"类，尤其医疗/权威背书场景）
用"国字头""权威"身份抬高身价，是医疗、保健、教育、培训等领域的重灾区，也往往是平台重点盯防的对象。

- 国家级、国家性、全球级、世界级、国际级、顶级
- 一流、超一流、超级、一级棒、最高级别
- XX级（如"教科书级""大师级""冠军级"）
- "国家级XX""权威XX""官方认证XX"（凡以此自居，必须有真实授权文件，否则即视为虚假、夸大宣传）

> 特别提醒：像"国家级专家""国家重点实验室认证""权威机构背书"这类，如果账号或产品拿不出政府授权、检测报告、官方授权书，**光靠文字自封就是违规**。做图库/资质图也救不了文字，平台看的是能不能当场证明。

### 1.5 「极」系及绝对化效果类
强调"完美、绝对、零风险"属极端表述，尤其在效果、安全、收益方面使用，属于高风险。

- 极致、极品、极度、极佳、极速
- 完美、完美无缺、无可挑剔、十全十美
- 100%成功、百分百、零风险、零副作用
- 绝对、绝对安全、绝不含、绝无副作用
- 包治、根治、药到病除、永不复发
- 稳赚不赔、只赚不亏、保本保息

> 关于"极简/极速"：作为**中性的风格与性能描述**（"极简设计""极速加载"）在某些语境可用，但要区分是"描述客观风格/性能参数"还是"宣称用户体验与效果"。"极简设计"描述设计风格可保留；"极致体验""极致效果"则在宣称体验和效果，必须改写。

### 1.6 判断一句话是否违禁的三条法则
不要死记单个词，学会判断"这句到底违不违"，遇到新词也能举一反三。

1. **是否存在"超越/独占"意味**：这句话是不是在宣称自己比别人强、独一无二、无法被超越？如果是，违禁。
2. **能否拿出可验证的证据**："我们最便宜"要能证明全市场最低价，"销量第一"要能出示权威榜单，"国家级"要能出示官方授权。拿不出，就删或改。
3. **是描述事实还是质量宣称**：「极简设计」描述的是产品客观风格，属中性描述；「极致效果」宣称的是用户收益，属质量宣称。**事实可以写，宣称要谨慎。**

## 二、对照表/清单：变体规避的误区与合规改写

### 2.1 变体规避＝照样违规（必须看）
有人用同音字、拼音、英文、符号、谐音新词来"打擦边球"，以为躲过机审就安全。实际上平台与执法**同样认定为违规**，只是检查成本高一点，不等于安全。以下是常见被点名的规避式写法，**一律不可用**：

| 规避方式 | 违规写法示例 | 为什么仍然违规 |
|---|---|---|
| 同音字 | "最"改成"蕞""最zui""最(gāo)" | 语义仍是"最"，属变体，人工审查一查即穿 |
| 拼音/缩略 | "the best""No.1""tops""1st" | 英文绝对化同样受广告法管辖，不因语言换写而免责 |
| 谐音俗称 | "绝绝子""天花顶""行业天花板" | "天花板"已成代替"最"的流行说法，被列入重点关注 |
| 符号遮挡 | "最!优""第·一""∞优选" | 夹符号属刻意规避，审查从严 |
| 同义替换 | "市面没有比这更好的了""舍我其谁""无法再好了" | 语义等同于"最"，属变体 |
| 数字游戏 | "销量遥遥领先""领先所有人" | "遥遥领先"等同"第一"，无权威数据即违规 |

**结论**：不要花心思钻谐音、拼音、英文字母的空子。合规改写是用**具体、可验证、有边界**的词替换"绝对"的说法，而不是换汤不换药。

### 2.2 合规改写对照表（把"绝对化宣称"改写成"客观描述 + 具体证据"）
这套对照表可以当模板直接抄用，越到后面越接近真实写作场景：

| 原违规写法 | 合规改写 | 改写要点 |
|---|---|---|
| 全网最低价 | 今日特惠价 ¥99（较常规价立省 ¥40） | 给具体数字与可比口径 |
| 效果立竿见影 / 百分百见效 | 参考 XX 报告，使用后 X 周内多数用户反馈改善（数据见文末） | 效果给数据与来源，不打包票 |
| 行业第一 / 销量第一 | 连续 X 年入选 XX 平台畅销榜（榜单见 XX 年度报告） | 把"第一"换成"入榜"并给口径 |
| 最权威 / 国家级机构 | 由 XX 机构（取得 XX 资质）提供技术支持 | 资质具体可查，而非抽象"权威" |
| 顶级用料 / 一流工艺 | 采用 XX 材料（含量≥X%）、经 XX 工艺 X 道工序 | 用料给参数与可检验点 |
| 极致性价比 | 同价位段里料/功能较常见产品多 X 项 | 用对比清单代替"极致" |
| 最受欢迎的课程 | 课程上线 X 个月，累计报名学员 X 万名（评价见文末） | 用可验证的运营数据 |
| 独家/独一无二配方 | 配方含 X 种成分，其中 X 为 XX 专利成分（专利号见下） | 有专利号才能说"专利"，否则说"特殊" |
| 100% 正宗 / 绝对正品 | 每一件均附官方防伪码，可扫码验证（示例见下图） | 用"可验证动作"代替"绝对保证" |
| 史上最强优惠 | 本次活动价格较上月直降 ¥XX，历史新低 | 用具体可比数据代替"史上"时间跨度的夸大 |

### 2.3 常用合规说法词库（可放心用的"安全词"）
发红包、降价、好用这类诉求，完全可以用不带"最"的客观表述达到同等效果：

- **质量类**：优质、良好、实用、耐用、清晰、顺手、用料实在、做工扎实、质感不错
- **价格类**：实惠、划算、性价比高、限时优惠、会员专享、满减后到手价 ¥XX、较 X 天前直降 ¥XX
- **排名类**：入选、上榜、多次获奖、得到 XX 机构测评认可（要给出处，且"认可"也要有凭据）
- **受欢迎类**：受欢迎、口碑不错、反馈良好、被不少用户喜欢（"不少"仍模糊，最好给量级，如"累计 X 条真实评价"）
- **自身特色类**：专注 XX 领域、深耕 XX 年、坚持 XX 工艺、从源头把控用料（用自身努力与时长，不与他人比"最"）
- **效果类**：有一定改善、帮助舒缓、多数人反馈不错、效果因人而异（不给承诺，给数据与边界）

> 原则：**"安全词"不等于随便用**。"优质/良好"等描述性较强的词，最好再配一句参数或实例支撑，越客观越稳。

## 三、合规做法（改写与自查的具体方法）

### 3.1 改写三步法
拿到一句带绝对化词的话，按下面的三步走：

1. **找出去掉绝对化的核心信息**：这句话到底想夸"贵得值"还是"效果好"还是"品质强"？先把想传达的核心提炼出来。
2. **换成可验证的客观信息**：能用数字就用数字（价格、含量、数量、年份、榜单名次区间），能用资质就用资质（证书编号、专利号、备案号），能用过程就用过程（工序、时长、规模）。数字和资质是最好的"安全料"。
3. **留有余地 / 加声明**：涉及效果、结论、收益类表述，主动补一句"效果因人而异""以实际为准""数据来源见文末"，把"绝对"降级为"通常、多数、因人而异"。理念与疗效要分开：**"每天进步一点"这类理念可写，"用了就 100% 变好"这类疗效宣称不能写**。

### 3.2 发布前全文自查五步流程
把自查变成固定动作，就能大幅降低踩线概率：

1. **标题与卖点段重点扫**：标题、开篇"钩子"、商品卖点段、海报文案、引导性结语——绝对化词 90% 藏在这里，先扫最危险的地方。
2. **全文搜一遍违禁词库**：把"最/一/级/极"四系清单当检索表，通读正文，见到一个改一个，不放行任何一个。
3. **专查"变体区"**：搜同音字、拼音、英文（the best、No.1）、谐音新词（天花板、绝绝子、遥遥领先）、夹符号写法——这些是"自以为安全"的雷区。
4. **核实"有依据就能写"的词**：凡靠"第一/首创/专利/权威/国家级"支撑的说法，必须能当场拿出报告、证书、榜单链接；拿不出就删，或降级为"入选、获得"。
5. **叠加行业自查**：医疗、金融、教育、食品、化妆品、保健品等强管制行业，对照「特殊行业红线」条目再叠加一轮行业词检查，绝不写疗效、收益、升学等承诺。

## 四、常见错误（反例 + 正解）

1. **用谐音/拼音打擦边球**——反例：写"全网蕞低价""No.1 销量"。正解：没有"安全擦边球"这回事，直接改"今日现价 ¥XX，较 7 天内有直降 ¥XX"。所谓安全写法是伪命题。
2. **"我有内部数据所以能写第一"**——反例："销量全国第一"，以为厂商内部数据也算依据。正解：除非是第三方可查的权威榜单（如官方平台年度榜），个人/厂商自说的一律不稳，改写"入选 XX 平台热销榜（见榜单页面）"。
3. **对"极"系中性词过度紧张**——反例：把"极简设计"一棍子打死，或反过来把"极致体验"当没事。正解："极简设计"描述风格可用；"极致体验/效果"宣称体验与效果，改写"体验流畅""效果见实测"。
4. **只查正文不查标题与落款**——反例：正文全合规，摘要或海报文案里却留着"最优惠"。正解：标题、摘要、封面文案、文末引导、落款水印全部过一遍自查流程，一个都不能漏。
5. **用免责声明"兜底"绝对化用词**——反例："本产品效果最棒，仅供参考"。正解：免责声明兜不住绝对化违规——**违禁词本身就不能出现**，免责只在"建议/观点"层面起作用（见「免责声明与风险提示写法」条目），不能拿"仅供参考"包裹"最/治愈/保本"。

## 五、自查要点（发布前勾选）

- [ ] 标题、摘要、开篇钩子有"最/第一/顶级/国家级/首选/绝无仅有/极致"等绝对化词？
- [ ] 出现了谐音、拼音、英文（the best / No.1）、谐音新词（天花板/遥遥领先/绝绝子）、夹符号等变体？
- [ ] 每一处"第一/首创/专利/权威/国家级/独家"都能当场拿出可查证据？拿不出就删或降级
- [ ] 涉及价格、效果、排名、用料、收益的说法都换成了具体数字/参数/榜单口径？
- [ ] 行业敏感描述（疗效、收益、升学率、功效）落到了「特殊行业红线」条目的合规区间？
- [ ] 定稿后对全文做了一次违禁词库通读（含标题、摘要、落款、封面文案）？

## 六、注意

- **法规与平台规则会更新**：本清单基于现行《广告法》与公众平台常见查处口径整理，**实际以最新法规与平台最新规则为准**；拿不准的词宁可改写弱化，也不要去赌。
- **个性化空间**：可按账号行业微调适用范围——严监管行业（医疗、金融）把"建议、稳妥首推"这类较安全说法也纳入从严；生活、文艺类账号里近乎中性的风格词（极简、极速）可放宽到"描述风格但不宣称质量"。**统一原则不变：只要在宣称"超越、独占、绝对"，一律改写。**
- 具体处罚机制与申诉路径见「违规后果与申诉」条目；强监管行业的行业红线见「特殊行业红线」条目；行业数据与免责写法见对应条目。
