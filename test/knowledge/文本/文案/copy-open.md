# 开头钩子（copy-open）

> 定位：开头 3 秒内要不要"抓住读者"的决定性文字。读者是否继续往下读，取决于首段是否给了他一个非读不可的理由。本条目给 8 种钩子写法、首段的硬性规则（长度/呼应标题/禁忌）以及钩子后的承上启下句。
> 调用时机：写完标题（或与标题同时斟酌）后，写正文第一段时调用。标题负责"点进来"，开头负责"留下来"。

---

## 一、核心规则

**规则 1：首段 ≤3 行、≤35 字，进正题。**
手机阅读习惯决定：超过 3 行还没有切入主题，读者就划走了。控制在 2–3 句、35 字以内，第一句就要见钩子，不要在开头铺背景、自我介绍。

**规则 2：首段必须呼应标题。**
读者是被标题点进来的，他在期待标题里那个"缺口"被填上。若开头完全不搭标题，读者会立刻产生"是不是点错了"的失落，直接退出。开头第一句通常要口语化地"接住"标题，或重复标题的核心关键词。

- 反例：标题"为什么你读了很多书却记不住？"，开头却写"大家好，我是小编，今天聊聊阅读。"——完全没接住钩子。
- 正解：开头直接回应"记不住"："你是不是也有这种体验：读完一本好书，两周后连主角名都忘了？其实不是记性差，是方法不对。"

**规则 3：首段禁忌——不说空话、不自夸、不绕弯。**
- 空话套话："随着社会的发展""众所周知""在这个信息爆炸的时代"——全是正确的废话，浪费黄金 3 秒。
- 自夸自捧："重磅消息！""这是一篇价值 999 元的干货！""不看会后悔！"——读者对这类吆喝戒备心极高。
- 绕弯铺垫："说来话长，这件事要从三个月前的一次偶然说起……"——迟迟不进入主题，读者等不及。
  - 反例（空话）："随着互联网的飞速发展，人们的生活方式发生了巨大改变。"→ 删，直接说你的现象。
  - 反例（自夸）："这是我写过最走心的一篇，你一定不能错过。"→ 删，用内容证明。
  - 反例（绕弯）："很多朋友一直在后台问我，那我现在就来回答这个问题，其实要分几个方面来看……"→ 直接给答案。

**规则 4：钩子之后要有一句"承上启下"句，点出本文给你什么。**
钩子抛出悬念/唤起共鸣后，紧接着用一句过渡点明"接下来我会告诉你什么/你能得到什么"，给出阅读路线图。这是把"情绪勾住"转化为"理性预期"，读者知道不会白读，就有了读下去的动力。

- 示例："这个方法我用了三年，今天一次讲清楚，保证你能抄走。" / "下面我会用 5 点拆明白，每一句都能直接用。"

## 二、钩子公式 / 模板

下面 8 种钩子，选一种即可。每种给写法模板、示例、适用类型。可结合账号调性微调语气（见「六、个性化空间」）。

**1. 结论先行**
- 模板：`直接说结论：……。为什么/怎么做到？往下看。`
- 示例："3 组数据告诉你：直接给结论，反而记得最牢。" / "先说结论——副业也能不上班地赚，重点在选对赛道。"
- 适用：干货、科技、商务、效率类。读者偏好"先给答案再讲道理"。

**2. 痛点共鸣**
- 模板：`你是不是也……？（场景 + 情绪，不夸张）`
- 示例："你是不是也这样：写完的计划，第二天就作废？" / "减肥三周没掉一斤，不是你不够狠，是方法错了。"
- 适用：情感、职场、教育、成长。要点是"精确说出读者正难受的那一点"，越具体越有共鸣。

**3. 悬念提问**
- 模板：`为什么……？答案可能和你想的不一样。`
- 示例："为什么你刷手机两小时，却觉得什么都没干成？" / "为什么有人工作五年就买房，有人十年还在租房？"
- 适用：观点、科普、揭秘。制造"我知道你不知道"的信息差。

**4. 场景代入**
- 模板：`具体时刻 + 具体动作/画面（画面感短句）`
- 示例："周四晚 11 点，你躺在床上第 20 次刷新朋友圈。" / "打开冰箱的那一刻，只有半根黄瓜和一盒过期牛奶。"
- 适用：生活方式、美食、情感、日系温柔向。用细节制造"这就是我"的代入感。

**5. 故事开场**
- 模板：`一个具体的人 + 一个具体的事件起点`
- 示例："上周，朋友小陈在群里发了张离职单的照片。" / "我认识一个女孩，辞职去大理住了一年。"
- 适用：人物故事、叙事类、情感长文（配合《人物故事模板》）。

**6. 数据震撼**
- 模板：`一个反直觉的/具体的数字 + 一句解读`
- 示例："90% 的人读完一本书，两周后就忘光。" / "每天多刷半小时短视频，一年就多出 180 小时被'偷走'。"
- 适用：科普、观点、干货。数字务必有据可查，别编造（配合《内容合规》）。

**7. 反常识**
- 模板：`大家都以为……，其实……`
- 示例："大家都以为多喝水好，其实过量也伤身。" / "都说越努力越幸运，但很多人是把命拼在了没意义的事上。"
- 适用：观点、健康、理财、思维升级。

**8. 引用开场**
- 模板：`一句名言/一句话 + 一句结合现实的接应`
- 示例："'你的注意力在哪，你的成就就在哪。'——但我们的注意力，正被手机切成碎片。" / "有人说过：我们不是缺时间，而是不知道时间去哪了。"
- 适用：情感、观点、人文向。引用要短、要贴合下文，不要为引用而引用。

## 三、示例

**完整示例（选用"痛点共鸣 + 承上启下"钩子），主题同《标题写法》——教打工人做快手早餐。**

标题：《给打工人的一周早餐清单：每天 15 分钟，吃饱再出门》

开头：
"你是不是也这样：早上闹钟响了三次，还是没时间好好吃口早饭，只能饿着出门，到公司胃里打鼓？（痛点共鸣）

这份清单我已经实操了一个月，今天一次分享给你——7 个方子，每个 15 分钟内搞定，一周不重样。（承上启下，点出给读者的东西）"

**第二例（结论先行 + 承上启下），主题：高效阅读。**
"先说结论：读完记不住，不是阅读姿势问题，是给大脑的'加载方式'错了。

底下我会用一个三步框架讲透——照着做，明天读完一本书你就能复述大半。（承上启下）"

**第三例（数据震撼 + 承上启下），主题：反消费主义。**
"一个数字：柜子里 80% 的衣服，你今年都没穿过。

不是让你不买，是教你把钱花在'会增值'的地方——下面 4 点，句句扎心但真实。（承上启下）"

**第四例（故事开场 + 承上启下），主题：亲子陪伴。**
"上个周末，我放下手机陪儿子玩了一下午乐高，晚上他搂着我说'爸爸你今天陪我了'。

那一刻我才明白，陪伴不在时长，在'有没人在场'——这篇文章就是从这顿饭开始的改变里，拆出 3 个可照做的方法。（承上启下）"

---

### 八种钩子的搭配原则（怎么组合不算贪多）

1. **一次选一个主钩子即可**，开头不是要凑齐几种钩子；"读者被哪种方式留住"取决于他当时的情绪状态，选最贴近你内容调性的一种。
2. **可搭一个小元素**：如"数据震撼 + 一句解读"里其实兼带一点反常识；"故事开场 + 承上启下"里可含一句痛点。只要主线钩子清晰，副元素是润色不是累赘。
3. **主钩子与内容类型对齐**：写教程就别用"引用开场"当主钩（除非名言特别贴）；写情感就别用"数据震撼"当主钩（除非数字本身很打动人）。
4. **钩子之后必接承上启下句**：这是最容易被忽略却最重要的"半句"，它把"被抓住的情绪"转成"读下去的预期"。

## 四、常见错误

- **错误 1：首段过长，超 35 字 / 超 3 行才进正题。**
  反例："首先我要先自我介绍一下，我是一个在自媒体行业摸爬滚打了三年的编辑，今天呢想跟大家聊一个很严肃也很普遍的问题……"（满满两段废话）
  正解：删掉自我介绍与背景，第一句就见钩子。

- **错误 2：开头写作"正确无比"的空话。**
  反例："随着人们生活水平的提高，越来越多的人开始重视身体健康。"
  正解：换成有画面、有冲突的具体现象（场景代入）。

- **错误 3：开头自夸，透支读者戒备。**
  反例："这篇是我呕心沥血之作，务必收藏！"
  正解：让开头自己说话，用痛点或用结论赢得信任。

- **错误 4：开头与标题脱节。**
  反例：标题"为什么你……"，开头大谈作者自己的故事背景，迟迟不回应标题。
  正解：第一句就口语化接住标题关键词。

- **错误 5：钩子抛完就断，没有承上启下。**
  反例：开头抛出悬念后直接进入分点"第一点是……"，读者不知道接下来能得到什么、值不值得读。
  正解：钩子后补一句"接下来我会告诉你……"，给阅读路线图。

## 五、自查要点

- [ ] 首段 ≤3 行、≤35 字，第一句就是钩子
- [ ] 用了 8 种钩子中的一种（结论/痛点/悬念/场景/故事/数据/反常识/引用）
- [ ] 首段口语化呼应了标题的关键词或承诺
- [ ] 无空话套话、无自夸、无绕弯铺垫
- [ ] 钩子后有一句承上启下，点明本文给读者什么
- [ ] 人称与标题、全文一致（一篇固定"你/我们"）

## 六、个性化空间

- **钩子类型的选择偏好**：理性向账号（科技/商务/理财）更常用结论先行和数据震撼；温度向账号（情感/生活方式）更常用痛点共鸣、场景代入、故事开场。判断依据：你的读者更信"逻辑"还是更吃"情绪"，正文语气也朝这个方向靠。
- **人称代称**：开头可用"你""我""我们"三种视角切换出不同亲切度。判断依据：与账号定位和全文口吻保持一致，不混用。
- **引用段落的来源偏好**：引名言时选与账号气质相符的人物——年轻向可引网络流行语，商务向引行业大咖，人文向引经典作家。判断依据：你的读者认谁。
- **承上启下的口气**：可硬朗（"下面 5 点照着做"）可温柔（"慢慢来，我们从第一步开始"）。判断依据：你想营造"教练"还是"陪伴者"的账号人设。
