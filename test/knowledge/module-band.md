# 花纹色带（module-band）

> 定位：**色带 = 一个组件类型（type）**。本条目记录**这一类组件的生成方式**——8 种组合方式（花纹家族骨架模板）分别怎么组织、零件位在哪、怎么按风格替换内容；以及"**类型 × 风格**"二维模型（风格决定内容）。色带是"把一条花色带铺在分区之间/小标题之下"的强调组件，用低饱和纯色块 + 细边框拼出斜纹/波点/棋盘/圆环等平面花纹，给分区做强调、给小标题做衬底，需要一点"装饰味"但不至于花哨。生成 art:// 色带底图资产时必读 **§五 5.0 整图资产构建规范**（画布 750×160 / zone 设计高 ≥70px / PNG ≤1MB / 三层验证闭环）。
> 调用时机：想让两个大段落有清晰分界（分区强调）、或让小标题更醒目（小标题衬底）时用；想让读者"这里有文章氛围/这是一个新板块"时用；不必每章都用，只用在最重要的 1-3 处。宣传类、活动类、专题/特辑、品牌故事最常用；纯干货长文可只在小标题衬底用一条浅斜纹，点到为止。**生成/改造色带时**：先定组合方式（类型），再按风格填充内容（花纹单元图案/色板）；不是"从变体清单里挑一个"。
> 素材来源：真实知识库 module-band（8 花纹家族 + 全部参数：透明度档 rgba(色,.08/.16)、高度 36-100px、颜色 ≤2 等）+ 2026-08-29 第 9 轮类型×风格模型（与 module-bubble 同构）。

---

## 〇、核心模型：类型 × 风格（2026-08-29 第 9 轮确立）

**色带组件的美术资产由 2 个角度决定：类型（type）和风格（style）。**

| 角度 | 回答什么问题 | 在色带上的体现 |
|---|---|---|
| **类型（type）** | 组件**怎么组织**（结构骨架）——这类组件怎么构建 | 色带类型下有 **8 种组合方式**（斜纹式/波点式/棋盘式/条纹式/圆环式/分段彩条式/大理石式/星芒放射式） |
| **风格（style）** | 组件里**放什么内容**（零件填充） | 同一种组合方式配不同风格 = 花纹单元图案与色板不同（球类 / 花朵 / 星星 / 几何……） |

**两条核心关系**：
1. **类型决定骨架**：同一类型的所有色带共享结构。例如"波点式"= 容器（浅底+圆角）+ 花纹单元排布位（一行圆点）+ 底色深浅档 + 文字衬底层，无论什么风格，骨架不变。
2. **风格决定内容**：骨架不动，花纹单元图案随风格替换。**例如：波点式 + 校园风 → 圆点换成迷你球类（足球/篮球/网球）/星星图案**；配自然风 → 圆点换成花苞/叶片；配科技风 → 圆点换成菱形/网格点。

**知识库应该记录什么**：记录**类型的生成方式**（骨架怎么搭、零件位在哪、怎么按风格替换内容），而不是一份"现成花纹样式清单"。清单只是某个默认风格下的实现示例（见 §四）。

> 与 design-logic-components 的关系：组件 = 美术素材 + 文字；素材维度 = 类型 × 风格——类型管骨架（可复用结构），风格管内容（可替换零件）。色带是**代码骨架组件**：美术素材主要来自 **CSS 拼装**（纯色块 + 细边框），花纹单元就是可替换零件；复杂花纹（大理石色斑、宣传类头图衬底、需精细纹理）才生成 art:// 资产，素材只占零件位。

## 一、构建总则（色带类型怎么生成）

### 1.1 8 种组合方式（类型的子类）

| # | 组合方式 | 一句话结构 | 典型用途 |
|---|---|---|---|
| 1 | **斜纹式** | 旋转细边框块排成斜向节拍 | 最百搭：细分隔/栏目衬底/标题行分隔/页眉 |
| 2 | **波点式** | 一行实心圆点 span 排成周期 | 温和通用：轻松卡片底/标题衬底/活动物料 |
| 3 | **棋盘式** | 纯色方块 + 留白交替成格 | 趣味辨识度高：游戏/极客/轻互动（细格纹=学习/清单/科技极简） |
| 4 | **条纹式** | 一排同宽纯色竖/横条均匀排开 | 榜单条背景/上下分段装饰/双品牌色 |
| 5 | **圆环式** | 细边框圆环错位出鳞片感 | 海洋/自然主题 |
| 6 | **分段彩条式** | 多个等宽纯色块切段 + 留白 | 分段轴/节日彩条/多色序列 |
| 7 | **大理石式** | 多组半透明纯色块叠加模拟云纹 | 画册封面/艺术引言卡/文字局部衬底 |
| 8 | **星芒放射式** | 多个旋转细边框块拼出放射感 | 能量/颁奖/激励主题 |

### 1.2 构建五步（生成方式总流程）

1. **定组合方式**：按文体与内容选 1 种（全篇 ≤2 种花纹，锚定 1 个主花纹；双模式同篇只选其一：文字类全浅档矮带、宣传类全深档高带）。
2. **搭骨架**：按 §二 对应模板搭容器与零件位（先只画结构，不填内容）——容器（底/圆角/overflow:hidden）+ 花纹单元排布位 + 底色深浅档 + 文字衬底层（如需叠字）。
3. **按风格填内容**：查风格条目（style-* / index-style）得到该风格的**图案词汇表**（花纹单元图案 + 色板），填入零件位 A（§三）。
4. **叠字与排版**（如需）：衬底文字用实色浅底隔开放在花纹上；`line-height:1.75`、字号 14-15px；色带容器底部 `margin:0 0 16px`（块距硬规范）；间距按 6px 层级收紧。
5. **验证**：375px 壳实测——密度铁律（全篇 ≤2 种/≤3 处）、文字可读底线（衬底 ≤.15）、对比度、微信兼容检查（§五）。

### 1.3 通用约束（先读，违反即返工）

- **平台硬约束**：仅 HTML 内联 `style`；无 `<style>`/`<script>`/伪元素/外链字体；**花纹全靠低饱和纯色块 + 细线边框叠加**实现，不使用任何渐变、不推荐投影（统一纯色 + 细边框）；如需真实纹理图，一律用微信 `uploadimg` URL。
- **一色带一用途**：每条色带只服务一个目的（分区强调 / 小标题衬底 / CTA 前节奏停顿），不混用。
- **透明度约定（深浅两档）**：浅档 = `rgba(色, .08)`、深档 = `rgba(色, .16)`；正文衬底默认用**浅档（≤.15）**保文字可读；色块、页眉、CTA 装饰可用**深档（.16）**。深浅档控制的是**视觉密度**而非颜色本身。
- **颜色 ≤2**：花纹主色取色板中的品牌主色；辅色/对比色只用色板内相邻或互补色（示例统一用主色蓝 `#2777ff`、辅紫 `#6b4fc4`、强调橙 `#e6550d`、中性灰 `#333`）。
- **密度铁律**：全篇花纹 ≤2 种（如"斜纹 + 波点"或"斜纹 + 棋盘"，别 6 种杂糅）；最多 2-3 处出现；锚定 1 个"主花纹"贯穿、1 个"点缀花纹"只在页眉/CTA 出现一次。
- **同类家族统一**：斜纹三款（细/粗/交叉）同属"斜纹"语言，选一种即可，别把三种都上。
- **文字可读底线**：衬底花纹上若有文字，花纹透明度 ≤.15（正文衬底默认 ≤.08）；文字层必须用**实色浅底隔开**；衬底花纹只建议 3 行内正文使用，长段落一律纯色或 ≤.08 细纹。
- **零 emoji/零图标字符铁律**：花纹单元必须是**可绘制的图形**（CSS 几何 span 或 art:// 图案），字符图标永不进入色带。
- **微信兼容**：纯色块 + 细边框最稳；禁投影/渐变/backdrop-filter/伪元素；斜纹 `transform:rotate` 必须容器 `overflow:hidden`；双色条纹色块等宽、间隔对齐才会交错出双色。

## 二、8 种组合方式的构建模板（核心：这类组件怎么构建）

> 每个模板给出：**骨架结构**（元素清单与位置）、**零件位**（可替换槽）、**尺寸与间距规范**、**叠字方式**（衬底文字层）、**风格可变内容**、**默认实现**（原家族参数）。
>
> **三个通用零件位（所有组合方式共享，先记住）**：
> - A. **花纹单元图案**（斜纹/波点/棋盘/圆环/色块/色斑/放射块……——**本身就是风格词汇载体**，风格替换就换它）
> - B. **底色深浅档**（rgba alpha 控制视觉密度：浅档 ≤.08、中档 .12、深档 .16）
> - C. **文字衬底层**（实色浅底隔开，衬底花纹透明度 ≤.15 保可读）

### ① 斜纹式

- **骨架**（块级容器）：容器（`background:rgba(主色,.04-.05)` + `overflow:hidden` + `border-radius:8px`）→ 旋转细边框块排布位（`transform:rotate(45deg)`，`position:absolute` 横贯容器）→ 底色深浅档 → 文字衬底层（中央，可选）。
- **零件位**：A. **斜纹单元**（细斜纹 4px 高 / 粗斜纹 18px 高 / 双色交叉 ±45deg 两组叠出编织感）B. 底色档 C. 文字衬底层。
- **尺寸**：细斜纹带高 52px、粗斜纹带高 80px、双色交叉带高 56px；斜纹块高度 3-18px、`border:1px solid rgba(主色,.35-.45)`、旋转 45deg 后 `scale(1.6)` 防露角；深档把 `.16` 换成 `.24`；细线高度与 `border` 粗细成对改。
- **叠字**：衬底文字放中央（`position:relative` span 叠在花纹上），实色浅底 `padding:6px 18px`、圆角 6px、`line-height:1.75`、字号 15px。
- **风格可变内容**：**斜纹单元**的粗细/方向/双色组合（交叉 = 编织感，工艺/手作/非遗主题）+ 主色与底色档。
- **默认实现**：3.1 斜纹家族三款（细斜纹蓝 `rgba(39,119,255,.05)` 底 + `.16` 块 + `.35` 边，带高 52px；粗斜纹橙 `rgba(230,85,13,.05)` 底 + 两条 18px 斜带 `.16`/`.4`，带高 80px；双色交叉蓝 `#2777ff` + 紫 `#6b4fc4` ±45deg 各一条 3px 斜线，带高 56px）。

### ② 波点式

- **骨架**：容器（`background:rgba(主色,.04)` + `border:1px solid rgba(主色,.14)` + `border-radius:8px`）→ 花纹单元排布位（`display:flex;gap:16px;align-items:center;justify-content:space-around;padding:0 16px`）→ 底色深浅档 → 文字衬底层。
- **零件位**：A. **波点单元**（实心圆点 span：单层 10px / 双层大 14px + 小 6px 错落）B. 底色档 C. 文字衬底层。
- **尺寸**：带高 56px；圆点 10px（双层 14px+6px）、`border-radius:50%`、`rgba(主色,.22-.26)`、间距 gap 16px（双层 `flex-wrap:wrap` + `padding:4px 16px`）。
- **叠字**：衬底文字行内置于点阵中央，实色浅底隔开。
- **风格可变内容**：**圆点图案**（圆点/球类/花朵/星星……形状契约=圆形几何，图案内容随风格换）+ 主色与底色档。
- **默认实现**：3.2 波点家族两款（圆点阵蓝 `rgba(39,119,255,.04)` 底 + `.14` 边 + 10px 圆点 `.22`×5；双层点阵蓝 `rgba(39,119,255,.26)` 小点 + 紫 `rgba(107,79,196,.22)` 大点错落）。

### ③ 棋盘式

- **骨架**：容器（`border-radius:8px` + `overflow:hidden`）→ 两行格位（`display:flex;flex-direction:column`，每行再 flex）→ 纯色方块 + 留白交替排布 → 底色深浅档（可无底，靠方块本身）。
- **零件位**：A. **棋盘格单元**（双色棋盘 28px 方块 + 14px 留白交替 / 细格纹 = 横竖细线 1px 相交）B. 底色档（细格纹用 `#fafbfc` 浅实底）C. 文字衬底层。
- **尺寸**：带高 56px；双色棋盘方块 28×28px、留白 14px（两行错位成格）；细格纹横线 y 0/18/36、竖线 x 24/48/72、`1px solid #d9dde3`、`position:absolute`。
- **叠字**：衬底文字叠在格纹中央（细格纹配实色浅底更稳）。
- **风格可变内容**：格的大小/疏密 + 方块颜色（可双色交错）+ 细线颜色。
- **默认实现**：3.3 棋盘格两款（双色棋盘蓝 `rgba(39,119,255,.14)` 块 + `.22` 边，块 28px 留白 14px；细格纹灰 `#d9dde3` 线 + `#fafbfc` 底，横 3 竖 3）。

### ④ 条纹式

- **骨架**：容器（`border-radius:8px` + `display:flex;gap:8px;align-items:stretch`）→ 等宽条纹单元排布位 → 底色深浅档 → 文字衬底层（可选）。
- **零件位**：A. **条纹单元**（竖条纹 `flex:1` 等宽 / 横条纹 8px 高 3 条 / 双色条纹两色交替）B. 底色档 C. 文字衬底层。
- **尺寸**：竖条纹带高 48px、横条纹带高 56px、双色条纹带高 48px；条纹 `flex:1` 等宽、gap 8px、`rgba(主色,.14)` 底 + `.22` 边；横条纹 `flex-direction:column;gap:6px;justify-content:center`。
- **叠字**：衬底文字放横条纹间隙行中央（横条纹自带节奏，文字叠中央）。
- **风格可变内容**：条纹方向（竖/横）+ 颜色交替（双色 = 两组品牌色交错，**色块等宽、间隔一致**才会交错出双色条纹）。
- **默认实现**：3.4 条纹家族三款（竖条纹蓝 4 条；横条纹蓝 8px×3；双色条纹蓝 `#2777ff` + 紫 `#6b4fc4` 交替 4 条）。

### ⑤ 圆环式

- **骨架**：容器（`background:rgba(主色,.04)` + `border-radius:8px`）→ 圆环单元排布位（`display:flex;gap:12px;align-items:center;justify-content:space-around;padding:0 12px`）→ 底色深浅档 → 文字衬底层。
- **零件位**：A. **圆环单元**（细边框圆环 span：20px、`border:2px solid rgba(主色,.35)`）B. 底色档 C. 文字衬底层。
- **尺寸**：带高 56px；圆环 20×20px、`border-radius:50%`、边框 2px、gap 12px。
- **叠字**：衬底文字居中叠在圆环行上方，实色浅底隔开。
- **风格可变内容**：圆环大小/边框粗细 + 主色。**圆环与波点同属"点状语言"只变了疏密，同篇里别同时用圆环又用波点，避免重复啰嗦**。
- **默认实现**：3.5 圆环家族（鱼鳞感蓝 `rgba(39,119,255,.04)` 底 + 20px 圆环 `.35` 边 ×4）。

### ⑥ 分段彩条式

- **骨架**：容器（`border-radius:8px` + `display:flex;gap:6px;overflow:hidden`）→ 等宽色块切段位 → 无底色档（色块本身即颜色）→ 文字衬底层（可选，色块上垫实色浅底）。
- **零件位**：A. **彩条单元**（等宽纯色块 `flex:1`，可多色、可增删）B. 色块深浅档（宣传类可用 .16 深档）C. 文字衬底层。
- **尺寸**：带高 24px（细分隔/分段轴）或 48-80px（分区强调）；色块 `flex:1` 等宽、gap 6px、`rgba(色,.16)` 底 + `.28` 边。
- **叠字**：彩条上叠字**必须**垫实色浅底（彩条是多色排布，直接叠字可读性最差）。
- **风格可变内容**：色块数量（可自行增删）+ 颜色序列（分段轴/节日彩条 = 多色序列）。
- **默认实现**：3.6 分段色块条（蓝 `rgba(33,102,255,.16)` + 橙 `rgba(230,85,13,.16)` + 紫 `rgba(107,79,196,.16)` 三段，带高 24px）。

### ⑦ 大理石式

- **骨架**：容器（`position:relative;overflow:hidden;background:#f7f9fc` + `border-radius:8px`）→ 多组半透明色斑位（`position:absolute` + `border-radius:50%` 大椭圆）→ 色斑深浅档（叠加本身即颜色）→ 文字衬底层（中央实色浅底）。
- **零件位**：A. **色斑单元**（多组不同位置、不同大小、不同透明度的半透明纯色块）B. 色斑深浅档（.08-.10）C. 文字衬底层。
- **尺寸**：带高 80px；色斑 3 组（如 `top:10%;left:10%;right:30%;height:40%` 等不同位置大小），`rgba(主色,.08-.10)`。
- **叠字**：衬底文字叠中央，实色浅底隔开（大理石纹理最花，文字衬底必须最扎实）。
- **风格可变内容**：色斑数量/位置/透明度 + 配色。**无法全景平铺**，只适合单块装饰元素（画册封面/艺术引言卡/文字局部衬底），不适合满幅背景。
- **默认实现**：3.7 大理石（蓝 `rgba(39,119,255,.10)` + 紫 `rgba(107,79,196,.10)` + 橙 `rgba(230,85,13,.08)` 三色斑，`#f7f9fc` 底，带高 80px）。

### ⑧ 星芒放射式

- **骨架**：容器（`background:rgba(主色,.05)` + `border-radius:8px` + `display:flex;align-items:center;justify-content:center`）→ 放射块拼装位（细长纯色块横竖交叉成十字）→ 底色深浅档 → 文字衬底层（可选）。
- **零件位**：A. **放射单元**（细长纯色块：8×48px 竖 + 48×8px 横十字，可加多组旋转块拼放射感）B. 底色档 C. 文字衬底层。
- **尺寸**：带高 80px；放射块 8×48px + 48×8px、`rgba(主色,.18)` 底 + `.35` 边。
- **叠字**：衬底文字叠十字一侧或中心下沿（放射是中心构图）。
- **风格可变内容**：放射块数量/角度 + 主色。**兼容性**：全部为纯色块 + 边框，任何内核都稳定渲染，无需兜底。
- **默认实现**：3.8 星芒/放射（橙 `rgba(230,85,13,.05)` 底 + 十字放射块 `.18`/`.35`，带高 80px）。

## 三、风格如何决定内容（填充规则）

1. **风格条目 → 图案词汇表**：每个风格条目（style-*，见 index-style）应提供该风格的**图案词汇表**（如：阳光校园风 = 球类/星星/奖杯；自然田园风 = 花苞/叶片/果实；科技商务风 = 菱形/网格/细斜纹；国潮风 = 回纹/印章格）。
2. **填入零件位**：把词汇表中的图案绘制为 CSS 几何 span（简单图案）或 art:// 资产（复杂图案），填入 §二 对应模板的"风格可变内容"零件位 A——骨架（容器/排布/底色档/衬底层）保持不变，只换花纹单元内容。
3. **花纹单元 = 风格词汇载体**：波点式的"圆点"换成球类/花朵/星星时，圆形几何骨架不变，图案内容（缝线/花瓣/尖角）随风格替换——形状契约保留、内容随风格（与气泡"形状即情绪"同理：圆点语言还是圆点语言）。
4. **图案必须是可绘制图形**：足球/篮球/网球/花朵/星星等是**具体图形**（圆形+细节线绘制），不是 emoji/字符图标——符合 v10 铁律（禁 emoji/图标字符，但允许具体器物图形）。
5. **CSS 优先、art:// 兜底**：色带是**代码骨架组件**（CSS 拼装为主），简单花纹（斜纹/波点/棋盘/条纹/圆环/星芒）一律 CSS span 拼（最稳）；复杂花纹（大理石色斑、宣传类头图衬底、需精细纹理的单元图案）才生成 art:// 资产（按 §五 5.0 整图资产构建规范构建）。
6. **颜色随风格**：花纹主色取风格色板（品牌主色），辅色只用色板内相邻/互补色；同篇颜色 ≤2；深浅档（.08/.12/.16）可整体随风格换，但必须保留密度层级（文字衬底浅档、装饰深档）。
7. **验证**：生成后按 §五 铁律实测（375px 壳、密度 ≤2 种/≤3 处、文字可读），并登记 REQUIREMENTS（先记录后开发）。

> 示例：**波点式 + 校园风**——骨架：浅底容器 + 圆点排布位 + 底色浅档 + 文字衬底层；内容：圆点①=迷你足球（圆形+五边形缝线）、圆点②=迷你篮球（圆形+曲线缝线）、圆点③=迷你星星（五角星几何）；色板：校徽橙/球场绿；衬底文字"每周运动打卡"实色浅底隔开，结构不变。

## 五、构建验证与铁律（生成任何色带必须满足）

### 5.0 整图资产构建规范（生成 art:// 色带底图时必须满足，2026-08-29 第 9 轮·实测修正）

> 色带底图是**整图资产 + 中央嵌字模式**（与小标题 combo 资产一致）：SVG 画布模拟色带容器，花纹单元长在上下装饰区，**中央区域留作文字衬底层（zone）**。子智能体首轮失败根因（与气泡同源）：嵌字区高度只留 27px 显示，装不下衬底文字一行；大面积水平渐变致 PNG 超 1MB；只验"zone 内无装饰"未验"zone 装得下文字"。色带特性：**横长条**（画布 750×160 含文字衬底层）+ 衬底文字单行。以下为强制规范：

1. **画布规格（默认）**：750×160（375px 壳显示 343×73px，缩放比 ≈0.457）。容器圆角矩形 y10 h140；**花纹装饰区贴顶（y≤40）、贴底（y≥120）**，中央 90..660 × 45..115 为文字衬底层区（zone）。
2. **文字区容量（核心，首轮失败点）**：zone 必须装下"衬底文字一行 15px（行高 1.4）+ 上下留白"≈ **32-40px 显示高**。换算为设计尺寸：zone 显示高 ≥32px → **设计高 ≥70px（y 45..115）**；zone 显示宽 ≥250px → **设计宽 ≥550px（x 90..640）**。**文案长度约束（375px 壳实测前提）**：衬底文字单行 ≤14 字（15px 一行 ≈14-15 字），超长文案会换行越界 = 不合格；无文字的分区强调带（纯花纹带）可不设 zone 或仅标注上下装饰区。375px 壳叠字实测用此长度的真实文案。
3. **PNG 体积铁律**：4x 渲染后 **≤1MB**（uploadimg 硬限）。色带是横长条，**大面积背景禁用水平渐变**（750px 宽的每一行都是不同像素，PNG 熵爆炸）；纯色块 + 细边框拼装最稳；大理石等复杂纹理用大色斑（单斑宽 ≥30% 画布）压低像素熵，实测超限时减少色斑数量/增大色斑面积。渐变仍用 `gradientUnits="userSpaceOnUse"` + 绝对坐标。
4. **zone 字段**：每个资产必须带 `zone`（`{x0,y0,x1,y1}` 设计坐标），标注文字衬底安全区。
5. **验证闭环（三层，缺一不可）**：
   - ① 资产级：渲染 4x PNG + probe 像素验证（落纯色部件，容差 ±12）+ 体积 ≤1MB；
   - ② zone 洁净度：相邻像素突变扫描（x90..640 区域逐行扫，相邻像素 RGB 差之和 >40 计数，突变 >12 的行必须为 0 或只在 zone 外）；
   - ③ **375px 壳叠字实测**（首轮缺失项）：把真实文案（衬底文字一行 ≤14 字）按 zone 缩放后叠入图片，DOM 检查文字边界全部落在 zone 矩形内（getBoundingClientRect 对比），**10/10 全部通过才算完成**。

### 5.1 通用铁律（继承 §一/§三）

- **密度铁律**：全篇花纹 ≤2 种、≤3 处出现；锚定 1 个主花纹贯穿、1 个点缀花纹只在页眉/CTA 出现一次；同类家族统一（斜纹三款选一）。
- **文字可读铁律**：衬底花纹透明度 ≤.15（正文衬底默认 ≤.08）；文字层必须实色浅底隔开；衬底只给标题/短小结（≤3 行正文），长段落一律纯色或 ≤.08 细纹；文字 `line-height:1.75`、字号 14-15px。
- **对比度铁律**：色带文字与底色对比度 ≥4.5:1；深档只用于无文字装饰区域，文字区一律浅档。
- **颜色铁律**：整条色带颜色数 ≤2；花纹主色取品牌主色，辅色只用色板内相邻/互补色。
- **零 emoji/零图标字符铁律**：花纹单元必须是 CSS 几何 span 或 art:// 可绘制图形。
- **微信兼容铁律**：纯色块 + 细边框拼装（`border:1px solid rgba(色,中档)`）；禁投影/渐变/backdrop-filter/伪元素；斜纹 `transform:rotate` 必须容器 `overflow:hidden`；双色条纹色块等宽、间隔对齐才会交错。
- **双模式铁律**：文字类全文浅档（≤.08）矮带（40-60px）；宣传类深档（.16）高带（80-100px），一篇只选其一；文字落在花纹上时必须垫一层浅实色底或用浅档。
- **验证方式**：375px 壳截图自查（一眼分清重点/标签/正文）；改参后整段截图到手机看一屏。

## 七、常见错误

- **反例**：半篇正文都铺在花纹上，字被线压花、读不动。**正解**：衬底只给标题/短小结（≤3 行），且透明度 ≤.08；长段落用纯色。
- **反例**：一篇里斜纹+波点+棋盘+竖条全上，视觉一片花。**正解**：全篇 ≤2 种花纹、≤3 处出现，锚定一个主花纹。
- **反例**：双色条纹两层周期不一致，叠成整片深色看不出条纹。**正解**：双色条纹色块等宽、间隔对齐，才会交错出双色。
- **反例**：用了不兼容的渐变写法做棋盘却忘了垫一层浅实色底，老手机整块变纯色。**正解**：本规范统一用纯色块 + 细边框平铺棋盘，任何内核都稳定，无需兜底。
- **反例**：色带高 200px 又用深色满铺，视觉压迫正文。**正解**：分区强调带 60-100px，深档只用于无文字装饰区域，文字区一律浅档。
- **反例（类型×风格新）**：想换风格时改骨架——把波点式改成棋盘式（"换个风格"）。**正解**：换风格只换花纹单元图案与色板（圆点→球类/花朵），换骨架是换组合方式；组合方式按文体与用途选，风格按账号选。
- **反例（类型×风格新）**：风格词汇用 emoji/字符图标（⚽🏀 直接贴进色带当波点）。**正解**：球类必须绘制成具体图形（圆形+缝线）或 art:// 资产，字符图标永不进入色带。
- **反例（类型×风格新）**：每种风格换一套骨架（校园用波点、国潮用棋盘、科技用斜纹满篇混），读者认不出"这是色带"。**正解**：全篇 ≤2 种花纹、锚定 1 个主花纹贯穿，风格只换内容零件——"同类家族统一"的契约比换花样重要。
- **反例（整图资产·首轮实测失败）**：画布 750×120、zone 设计高 45px（显示仅约 20px），装不下衬底文字一行。**正解**：画布 750×160、zone y45..115（设计高 ≥70px），见 §五 5.0。
- **反例（整图资产·首轮实测失败）**：大面积背景用水平渐变，PNG 4x 渲染超 1MB（每行像素全不同，熵爆炸）。**正解**：大面积背景渐变用垂直方向或纯色块拼装，大理石用大色斑，见 §五 5.0。
- **反例（整图资产·验证缺失）**：只验证"zone 内无装饰侵入"就宣称完成，没把真实文字叠进去实测——文字实际放不下。**正解**：三层验证闭环（资产级 probe + zone 洁净扫描 + **375px 壳叠字 DOM 实测**），见 §五 5.0。

## 八、个性化空间

- **可调 · 花纹类型**：斜纹/波点/棋盘/条纹/圆环。**判断依据**：干货与商务用斜纹/细格（克制），宣传与活动用粗斜纹/分段彩条（跳眼）；间隔越大越疏朗，越小越密实。
- **可调 · 深浅档（.08 / .12 / .16）**：文字衬底用浅档保可读，无文字装饰区可深档；深浅档改变的是密度，不换配色。
- **可调 · 颜色**（`rgba(R,G,B,.a)` 三组数字即 RGB）：花纹主色取品牌主色，辅色只用色板相邻/互补色；颜色数 ≤2。
- **可调 · 高度与圆角**：小标题衬底 36-60px、分区强调带 60-100px；圆角与高度配合（矮带 6-10px、高带 8-12px）。**判断依据**：越高的带越像"正式分区页"，越矮越像"标题衬底"；宣传类可更高更有仪式感。
- **文字衬底层**：有文字必垫实色浅底（`padding:6px 18px`、圆角 6px、`line-height:1.75`、字号 14-15px）；衬底花纹透明度 ≤.15。
- **风格扩展方向**：校园（球类/星星波点）、自然（花苞/叶片圆环）、国潮（回纹/印章格棋盘）、科技（菱形/网格细格纹）——每种风格 = 一套图案词汇表填入 8 种模板的零件位 A，先调研再入库（REQUIREMENTS.md 登记）。

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案
