# 图片插入组件（图片如何落进正文版位）

> 定位：处理定稿后的图片如何"插进组件"——上传通道、版位选型、图注配套、防翻车五查。本篇是「图片插入组件」链条的**第四环（插入）**；各版位的完整排版写法在 视觉/模块 的 module-image.md，本篇负责"最后一公里"的操作检查，不重复模板代码。
> 调用时机：图片按 img-processing 处理定稿后、写入正文排版前。
> 依据：module-image 四条铁律 + img-processing 处理规范 + 微信 uploadimg 平台事实（jpg/png ≤1MB）。

## 一、上传通道（唯一合法路径）

- 正文图片必须是**微信 uploadimg 上传后返回的 URL**（仅 jpg/png，≤1MB）；本地路径、`data:` 内嵌、外链 CDN 在发布后都会失效。
- 上传前先按 img-processing 完成处理定稿（尺寸 ≥1080px 宽、压缩 ≤1MB、同篇统一）。
- 正文 HTML 的 `<img src>` 一律填上传后的 https URL；本地图片路径必须走草稿箱通道上传后再引用。

## 二、版位选型（决定用哪个组件模板）

按这张图要承担的任务，从 module-image 选模板：

| 图要干什么 | 用 module-image 的模板 | 提示 |
|---|---|---|
| 通栏氛围 / 场景 | 单图 | 正文最基础版位，圆角 8px |
| 图文对照（产品/步骤配图） | 左图右文 | 图列 `flex:0 0 40%`，锁比例防变形 |
| 对比 / 并列 | 双图并排 / 三图 | 同比例裁切，网格对齐 |
| 多图拼贴 | 网格 / 拼贴 | 成套感来自同套圆角边框 |
| 图 + 说明条 | 图卡 | 说明条与图同宽 |
| 全篇配图节奏 | 每 400–600 字一张 | 单篇至少 1–2 张 |

**特殊版位**：封面图（2.35:1 + 1:1）另见 其它/封面；文内小标题旁的小图装饰走 art:// 行内资产（见 视觉/模块 的 module-inline-deco），不是本条目讨论的正文配图。

## 三、图注配套

- 需要署名 / 条款要求署名的图，图注标"图 1：来源 xxx"，与素材来源清单一一对应（登记方法见 img-sources 第四节）。
- 图注样式：字号 12–13px、行高 1.5、灰色 `#999`、居中；与图片间距 ≥6px。

## 四、防翻车五查（插入后必过）

1. **无固定 px 宽**：图片容器 `max-width:100%;width:100%`，`img` 写 `width:100%;height:auto;display:block`，绝不用固定像素宽（防横向溢出）。
2. **圆角/描边写在父容器**：外包装 `border-radius + overflow:hidden` 的容器再塞 img，不直接写在 `<img>` 上（部分机型对 img 自身圆角失效）。
3. **间距用块级容器 + margin**：图片上下 `margin:12px 0`，不用 `<br>` 堆空行。
4. **src 无残留**：每张图都是上传后的微信 URL，无本地路径 / `data:` / 外链残留。
5. **同篇统一**：圆角、边框、比例与 img-processing 第三节的"标准样"一致，扫一眼成套。

## 五、常见错误

1. **处理完直接放行不检查** —— 反例：缩略图 / 超 1MB 直接上传被拒（40009）或发糊。正解：过 img-processing 清单再上传。
2. **本地图片路径直接写进 HTML** —— 反例：发布后图片消失。正解：全部 uploadimg 上传后引用 URL。
3. **该用图卡却用裸图堆说明** —— 反例：图与说明分家，读者对不上。正解：图文对照场景用左图右文 / 图卡模板。
4. **多图圆角边框不一致** —— 反例：一张圆角一张直角。正解：整批套同一套参数（见 img-processing 第三节）。

## 六、自查要点（可勾选）

- [ ] 每张图已过 img-processing 处理清单（尺寸/体积/统一）
- [ ] 全部图为 uploadimg URL，无本地/外链/data: 残留
- [ ] 版位按任务选对模板（单图/左图右文/多图/图卡）
- [ ] 需要署名的图已配图注且与来源清单对应
- [ ] 防翻车五查全过（无 px 宽/圆角在父容器/margin 间距/src 合法/成套统一）

## 七、个性化空间

- **图注是否常开**：严谨资料类号每图必注来源；氛围类内容可在文尾统一列来源。判断依据：内容严谨度与授权条款要求。
- **配图密度**：干货教程 400 字一张是下限参考；情感长文可更稀、靠留白呼吸。判断依据：账号的图文比定位（见 style 方向各风格条目的图片处理节）。
