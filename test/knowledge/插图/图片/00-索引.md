# 图片方向索引（插图 / 图片）

> 定位：解决「这张图从哪来、能不能用、怎么处理、怎么插进组件、没有图怎么办」——图片素材到组件的**完整链条**。
> 用法：按链条顺序取条目：获取 → 授权确认 → 处理定稿 → 插入组件 → 无图替代；组件排版模板（单图/左图右文/图卡等写法）在 视觉/模块 的 module-image.md，本方向只管素材与插入操作。
> 交叉：版权法律红线在 文本/合规 的 comp-copyright.md；视频插入走同属 插图 的 视频 方向。

## 一、链条速查

| 环节 | 条目 | 一句话要点 |
|---|---|---|
| 1 获取 | img-sources.md | 图库原图 / 自制 / 读者投稿，取图即登记来源 |
| 2 授权确认 | img-copyright.md | 四步：查授权 → 确认可商用 → 记录来源 → 保留凭证 |
| 3 处理定稿 | img-processing.md | ≥1080px 宽、≤1MB、同篇统一（比例→色彩→体积） |
| 4 插入组件 | **img-insert.md** | 上传 uploadimg → 按任务选 module-image 模板 → 图注 → 防翻车五查 |
| 5 无图替代 | img-alternatives.md | 色块/图表/装饰/截图示意，替代不顶替信息位 |

## 二、条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| img-sources.md | 图片来源：免费图库清单/自制图/截图/读者投稿的适用规范 | 找图前 |
| img-copyright.md | 版权确认流程：授权类型识别、免版权核实、记录留证 | 使用任何非自制素材时 |
| img-processing.md | 图片处理规范：尺寸/压缩/格式/水印/滤镜统一 | 图片定稿前 |
| img-insert.md | 图片插入组件：上传通道/版位选型/图注/防翻车五查 | 图片定稿后、排版插入前 |
| img-alternatives.md | 无图替代方案：纯色块/图表/美术资产/排版图形 | 没有合适图片时 |

## 三、使用顺序

1. 找图（img-sources）→ 2. 确认版权（img-copyright）→ 3. 处理统一（img-processing）→ 4. 插入组件（img-insert，模板写法跳 module-image）；无图时用 img-alternatives。

## 四、条目统一结构

定位一句话 → 详细规则 → 示例/反例 → 常见错误 → 自查要点（可勾选）→ 个性化空间 → 交叉引用
