# 版权确认流程（照片/图片用前必核四步）

> 定位：任何非自制素材，用之前必须走"查授权类型 → 确认可商用 → 记录来源 → 保留凭证"四步确认；本篇给四个常见授权类型的含义、无明确授权时的处理，以及风险自查。本篇是「图片插入组件」链条的第二环（**授权确认**）。
> 调用时机：使用任何非自制图片、插图、图标、模板元素前；与"图片来源"条目搭配（一个讲去哪找，一个讲确认流程）。

> 合规边界：本条目讲**操作流程**（怎么核、怎么留证）。法律红线（什么是侵权、赔多少、哪些行业更严）以合规维度的版权条目为准。这里给的是每一次取图都该执行的"下判断步骤"。

## 一、使用非自制素材前的确认流程（四步）

**第 1 步 · 查授权类型**
- 素材来源页找 `License / 授权 / 条款`。图库一般有统一授权页；作者个人分享的素材通常附在描述/简介里。
- 找不到任何授权声明的，**一律视为未授权**，见第四节。

**第 2 步 · 确认可商用**
- 读授权条款里的"可用场景"。重点看三条：
  - 是否**允许商用**（有的只允许个人/非商业用途）；
  - 是否**允许修改**（你可能要裁切、加字、套滤镜）；
  - 是否**要求署名**（CC BY 类要求标注作者）。
- 你的场景（公众号推文 = 公开传播的商业/非商业内容都算公开传播）必须被条款覆盖。**"公开发布"就已超出个人自用**，不要拿个人用途授权顶上去。

**第 3 步 · 记录来源**
- 把"素材 + 来源 URL + 作者 + 授权类型 + 授权链接"登记进来源清单（见"图片来源"条目第四节）。这一步和下一步合起来就是"留证"。

**第 4 步 · 保留凭证**
- 保存：原图文件、来源页面 URL、授权条款页面 URL、下载/使用日期。
- 若素材被要求署名，记录的授权链接就是将来自证"我按条款用了"的依据。
- 有条件就把"来源 + 授权说明"写进正文图注（当条款要求署名时必须写）。

**四步要不要"每张都走"？** 批量从同一图库取图时，授权页通常全站一致，可"每批核一次全站授权 + 每张记录来源页"，不必每张重读条款；但若取自不同站点/不同作者，就要逐站/逐作者走全四步——**授权是"站/作者"粒度的，不是"全互联网"一个尺子**。

**四步的"用意"速记（为什么这四步缺一不可）：**
| 步骤 | 防的是什么 | 缺了会怎样 |
|---|---|---|
| 1查授权类型 | 用错协议、用错粒度 | 根本不知道这张图能不能用 |
| 2确认可商用 | 把"个人/非商业"授权当商用 | 公开发布后违约 |
| 3记录来源 | 事后找不到出处 | 被追问时拿不出依据 |
| 4保留凭证 | 条款变动/被追责时自证 | 无法自证"我按条款用了" |

**给一张"我到底要不要担心"的简化问答（日常快速过）：**
- 这张图**来源明确、标注可商用** → 放心用，照做 34 留证即可；
- 来源明确但**没标可商用** → 按"个人/未知"处理，走第三节顺位；
- 来源**不明**（搜索引擎/各处流传）→ 默认不可用；
- **含人物/品牌/敏感信息** → 即使授权允许，还要多看肖像/商标这一步。

## 二、常见授权类型解释

| 授权类型 | 含义 | 公众号使用注意 |
|---|---|---|
| **CC0（公有领域贡献）** | 作者放弃版权，可商用/可修改/可再分发，通常免署名 | 最省心；但图片中的人物肖像、商标、建筑形象仍需注意（CC0 只管版权，不管肖像/商标） |
| **CC BY** | 可商用/可修改，**必须署名作者** | 使用要在图注或文尾标明作者与来源链接，否则违约 |
| **付费授权** | 购买后获得授权，通常含商用，可能限定用途/次数/渠道 | 保留购买凭证与授权范围；看清是否限定了"公众号"之外的平台再分发 |
| **个人使用授权** | 只允许个人学习/自用，**不允许公开展示/商业用途** | 公众号公开传播本就不属于个人使用，**不可用** |

**CC 族谱补充（作者可能标了这些变体）：**
- **CC BY**：需署名，商用可但必须注明作者；
- **CC BY-SA**：需署名 + 你的衍生内容也要用相同协议开放（SA 传染，谨慎用于"要独占"的号）；
- **CC BY-NC**：需署名 + **禁止商用**——公众号若带货/引流变现即属商用，**不可用**；
- **CC0**：放弃所有版权，最自由。
- 一句话速记：**见到 NC（非商用）就默认不能进公众号，除非你确定自家推文纯粹非商业。** 教程/干货类"不含广告也不变现"的文章用 NC 也危险，别赌。

**图库站的"可商用"模板（Pexels/Unsplash/Pixabay 常见）：** 通常标注"免费商用、无需署名、可修改"，个别作品除外（含商标/人物时仍要谨慎）。以站内每条素材的授权说明为准，不是整站一概而论。

## 三、无明确授权时的处理

**原则：没有明确"可商用"说明 = 不能用。** 顺位处理：

1. **不用**（首选）：删掉这张图，换一张有明确授权的；
2. **替换**：在合规图库/自制里重新找一张同主题的；
3. **联系作者**：素材作者个人发布且未标授权时，可私信/邮件征求"用于公众号推文"的书面同意，**拿到同意再留证再用**（对话截图就是凭证）；
4. 三种都不顺 → 回到 1，直接不用。为一张图冒险不值。

**"联系作者"怎么谈（可操作）：** 说明你的公众号类型/大概阅读量、想用哪张图、用在什么位置、是否会署名，请对方回复"同意用于公众号推文"。对方回复同意就是留证；对方不回复或犹豫，就按"不可用"处理，别默认默许。

**联系作者的留言模板（照抄改名字就用）：**
> 你好，我是「公众号名」的小编，后台看到你的图作品很契合我们做的一篇「主题」。想请你是否允许我们把这张图用作公众号推文配图？会注明作者 / 尊重你的署名要求。方便的话回复"同意"即可。谢谢！

**"谈不成/没回音"的统一处理：** 不回复、含糊（"随便用"但没说清范围）、或回复但没明确涉及公众号推文——一律按"不可用"对待，换一张。拿到明确书面同意才最稳。

## 四、风险自查（什么样的图默认危险）

- **来自搜索引擎（百度/谷歌图片）**：搜出来的图绝大多数没授权信息，**默认不可商用**，几乎必然踩雷。
- **明星/人物的照片**：涉及肖像权与平台监管，除非有授权，否则不用。
- **带品牌 LOGO 的产品图**：涉及商标，说明性引用可斟酌，但不宜做夸张营销暗示。
- **付费素材的截图/重录**：截图不算获得授权，仍受原授权限制。
- **"以图搜图"相似图**：相似源不等于授权，source 依旧无凭证。
- **图片网站"免费"字样但实际要付费/VIP**：看清是需要购买，免费标签可能只针对编辑用途（editorial，不商用）。
- **漫画/插画/CG 图**：情感类公众号爱用漫画插图，这类多半是作者原创、版权在作者，除非有明确授权（如作者声明可商用），否则**默认不可用**；找不到出处却在各号流传的，风险更高。
- **热点新闻图**：新闻配图多为通讯社/媒体版权，官网转载往往限报道用途，个人号取用需谨慎，别当普通素材。
- **带水印/角标的搬运图**：图上若有别的号/站的水印，通常是二传，同样无凭证，风险等同搜索引擎图。
- **"网上都说这组图可免费"的传言**：口头/群里传的"可免费"不构成授权，必须以素材来源页的书面声明为准。

**风险自查的一句话总纲：** 只要心里冒出"这张图出处我其实不太确定"——它就该被归为"不可用"，换图永远比冒风险省心。

## 五、示例

**合规全流程：** 在 Pexels 取一张图 → 站内该素材/授权页确认"免费商用、可修改" → 登记来源 URL + 作者 + 授权页链接到来源清单 → 保留原图与网页。发布若素材要求署名，图注注明。

**违约反例：** 从某图库取一张标"限个人使用"的图直接进公众号 → 公众号公开传播不属于个人使用 → 违约。
**侵权反例：** 百度图片右键保存明星杂志图当配图 → 无授权、涉肖像 → 高风险。
**NC 隐患反例：** 用一张 CC BY-NC 的插画配一篇含带货链接的推文 → NC 禁止商用，带货即商用 → 违约。

**一张"来源清单"该长什么样（填空模板，直接抄用）：**

| 文件名 | 来源图库 | 原图URL | 作者 | 授权类型 | 授权页URL | 使用日期 | 图注署名? |
|---|---|---|---|---|---|---|---|
| hero-1.jpg | Pexels | https://… | Lai Ma | 站内可商用 | https://…/license | 2026-01-02 | 可免 |
| tablet.png | Unsplash | https://… | Ivana | 站内可商用 | https://…/license | 2026-01-02 | 可免 |
| stats.png | 自制 | — | 编辑部 | 自制 | — | 2026-01-02 | 不需要 |
| reader-1.jpg | 读者投稿 | 私信 | 「小芳」 | 已授权 | 私信截图 | 2026-01-02 | 已注明 |

**留证的另一层（条款会变）：** 授权条款常会更新，尤其新手友好、后收紧的站不少见。稳妥做法是**发布当时把授权页"另存/截图"一份**存进归档文件夹，将来条款变了也能证明"我当时用是合规的"。这个动作很小，但能兜住"作者改条款"这类事后风险。

**补充：授权页怎么快速定位**——多数图库网站底部或"关于/法律"页有统一 License；素材详情页通常也有"License / 版权"或"Download"附近的授权说明链接。找不到就返回整站授权页判断，还找不到即按"未授权"对待。

## 六、常见错误

1. **看到"免费"就默认可商用** —— 反例：免费站有免费条款，"免费 == 个人非商用"很常见。正解：读条款区分商用授权。
2. **不做记录，事后无法自证** —— 反例：被追问来源拿不出凭证。正解：四步必含记录 + 凭证。
3. **把"个人使用授权"套到公众号** —— 反例：公开传播 = 个人使用？错。正解：公众号一律按"公开展示"走，个人授权不可用。
4. **CC0 就万无一失** —— 反例：CC0 只管版权，图里的人物肖像/商标仍可能出事。正解：CC0 之外仍要审肖像/商标/敏感信息。
5. **"我裁一下、调个色就没事了"** —— 反例：修改不洗掉版权，改图照样侵权。正解：授权类型必须先允许修改，否则改也是违约。
6. **把 NC（非商用）授权用于可能变现的文章** —— 反例：NC 禁商用，带货/引流后违约。正解：见到 NC 默认不可用，除非能确认纯非商业且不引流。
7. **批量取图只核一张就代表全站** —— 反例：个别作品有额外限制（含人物/品牌）被漏掉。正解：站级授权核一次 + 每张看有无"含人物/商标"的特别提示。
8. **把授权页当作"永久事实"不复核** —— 反例：站内条款半年后更新，旧图"当时合规"也不代表永远没变。正解：发布时顺手把授权页另存/截图，条款变动可自证。
9. **觉得"来源是朋友/同事发的不需要核"** —— 反例：转来的图同样带版权，来源是熟人不等于授权。正解：任何第三方给的图都按"非自制素材"走一次四步。

## 七、自查要点（可勾选）

- [ ] 拿到的是"可商用 + 允许修改"的授权，或已获作者书面同意
- [ ] 授权类型明确（CC0 / CC BY / 付费 / 已授权），没有"无明确授权"
- [ ] 已按 4 步走完：查类型 → 确认可商用 → 记录来源 → 保留凭证
- [ ] 若条款要求署名，已在图注/文尾标注作者与来源
- [ ] 图内无未授权的人物肖像、品牌 LOGO、敏感信息的违规使用
- [ ] 未使用任何来自搜索引擎/来源存疑的图
- [ ] 授权条款用到时已"另存/截图"留证（防条款变动）
- [ ] 熟人/同事转来的图也按"非自制素材"走了一次四步
- [ ] 没有仅凭"网上都说可免费"就使用的图
- [ ] 批量取图时，该批素材的授权记录一一对应
- [ ] 未使用含 NC（非商用）限制的素材于可能变现的推文

## 八、个性化空间

- **风险承受档位**：新闻/严肃类账号素材合规要求极高，默认"来源存疑一律不用"；生活随笔类可稍微宽松但同样要留证。判断依据：账号性质与内容被追责的可能。
- **是否走"联系作者"路线**：小众作者素材找你愿意谈，可建立长期约图合作；大众图库素材不值得逐一联系作者，直接换图。判断依据：素材的不可替代性与联系成本。
- **署名习惯**：即使不强制署名，养成"来源记录 + 可加注"的习惯有助于长期自证；是否把"图源"公开写进正文，看账号要不要显出品控严谨。判断依据：账号透明策略。
- **付费素材的预算**：重要栏目/常青高流量推文可投入付费图库授权；一次性小图用免费合规即可。判断依据：素材的复用频率与流量价值。
- **内容是否变现的界定**：纯科普/公益号用 NC 素材较安全；有带货/广告/知识付费的号一律按"商用"从严。判断依据：账号真实的变现路径，宁可从严。
- **是否把授权核进"发布 SOP"**：把"取图→核授权→登记→留存证"固定成每次配图前的固定动作，比临时想起来稳妥；是否制度化看团队是单人还是多人协作。判断依据：团队的记忆连贯性与出错频率。
