# 视频素材准备与上传（video-prepare）

> 定位：视频从"想放一段视频"到"素材可插入"的准备链——放什么内容、时长多少、画面怎么拍、封面帧怎么选、字幕与体积怎么处理，以及素材库上传路径。本篇是「视频插入组件」链条的**第一环（素材准备）**；插入操作见 video-insert，卡片排版模板见 视觉/模块 的 module-media.md。
> 调用时机：正文需要视频素材时、拍摄/剪辑前；上传素材库时。
> 依据：module-media 的视频使用要点 + 公众号平台事实（视频须经视频号/小程序/素材库通道，正文 HTML 不能直接放任意视频——平台硬约束见 module-media 第一节）。

## 一、先判断：这处放视频是必须的吗

视频的代价（制作/加载/打断阅读）高于图片，值得放的只有"动起来才清楚"的内容：

| 内容要传达… | 用视频 | 用文字/图片 |
|---|---|---|
| 操作过程、动手演示 | 是（首选） | 步骤清单仍要文字 |
| 声音/氛围（音乐、现场、访谈原声） | 是 | 无法替代 |
| 复杂讲解（讲师对着镜头讲） | 看时长，5 分钟以上才值得 | 短说明用文字 |
| 结论、数据、清单 | 否 | 文字/图表（见 img-alternatives） |

**判断口诀**：读者"看一遍"比"读一遍"多得了什么？多得了过程/声音 → 放视频；只是多花了时间 → 别放。

## 二、时长与内容结构

- 图文内的视频锚点建议：**短演示 1-3 分钟、深度讲解 5-10 分钟、访谈/课程 20-60 分钟**（与 module-media 一致）。
- 图文里优先放**摘录片段**（最有信息量的 1-3 分钟）；完整长视频放结尾作延伸。
- 一个视频只讲一件事：标题能点出"教什么/看点"，读者不点开也知道内容（不要笼统的"点击观看视频"）。

## 三、画面与收音

- **横版 16:9 优先**：正文嵌入与封面比例一致，避免竖版强行拉伸；竖版素材若非内容需要（如竖屏采访）慎用。
- 光线充足、主体清晰；手持拍摄保持稳定（或上稳定器/固定机位）。
- 收音优先于画质：访谈/讲解类用领夹麦或近麦，嘈杂环境后期难救。
- 与文字分工：演示类用视频讲过程，**关键结论/步骤清单仍落到正文文字**（读者可回查）。

## 四、封面帧

- 优先用**信息量大的静止帧**（动作进行中、关键界面），避免空白缩略图。
- 封面上的字（如有）要保证在手机小图上可读——压到小图看一次再定。

## 五、字幕与文字信息

- 关键数字、术语、操作步骤建议加字幕（静音场景也能看）；
- 无字幕/长视频：正文配"文字版要点"，两者互补，别让读者看完视频就没处回查。

## 六、导出与体积

- 剪辑导出用常见格式（如 mp4），导出前按**公众号素材库当时的格式与大小提示**处理（后台会校验，以提示为准）；
- 控制体积：同一内容先压码率/分辨率而不是降低内容质量；上传前预览一遍确认无花屏/音画不同步。

## 七、素材库上传

- 在微信公众平台的素材管理里上传视频，上传成功后素材才可用于正文；
- **正文 HTML 无法自造视频 URL**——视频必须通过微信编辑器（视频号/小程序/音频通道）插入，见 video-insert 与 module-media 的平台硬约束；
- 上传后把素材名与正文位置对应记一下，避免插入时选错素材。

## 八、常见错误

1. **文字讲不清就硬塞长视频** —— 反例：3 秒能说清的事放 10 分钟视频。正解：先过第一节判断表。
2. **竖版素材强行铺满** —— 反例：正文里被拉伸变形。正解：横版 16:9 优先，竖版内容慎用或换呈现。
3. **空白缩略图/黑帧当封面** —— 反例：读者看不出内容不点开。正解：信息量大的静止帧。
4. **视频与文字脱节** —— 反例：视频讲 A、正文讲 B，或看完视频没有文字可回查。正解：视频讲过程、文字留结论与步骤。
5. **忽略素材库校验直接引用本地文件** —— 反例：发布后无法播放。正解：一律走素材库上传 + 编辑器插入。

## 九、自查要点（可勾选）

- [ ] 该处内容确实"动起来才清楚"（过程/声音），不是为放而放
- [ ] 时长符合定位（演示 1-3 分钟/讲解 5-10 分钟），摘录优先
- [ ] 横版 16:9、光线清晰、收音可听
- [ ] 封面帧有信息量、手机小图可读
- [ ] 关键信息有字幕或正文文字版承接
- [ ] 已按素材库提示导出并上传成功，无本地文件残留

## 十、个性化空间

- **自制 vs 剪辑已有素材**：有出镜条件的号可做真人演示建立信任；无条件的号用屏幕录制 + 旁白做教程。判断依据：账号人力与内容类型。
- **视频密度**：教学号可每篇 1-2 个短演示；资讯号只在事件本身是视频（现场/采访）时才放。判断依据：正文节奏与制作成本。
- **是否全文配"视频 + 文字精要"**：深度干货文可在文首放"3 分钟看懂"摘要视频、文尾放完整版。判断依据：内容体量与读者耐心。
