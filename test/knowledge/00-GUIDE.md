## 三、间距硬规范（所有排版必须遵守，违反即返工）

- **块间距**：段落/气泡/卡片/步骤/列表/代码块/图片之间统一 **16px** 底部间距（`margin:0 0 16px`）。
- **行距**：正文与块内文字统一 **1.75**；代码块 1.6。
- **页边距**：微信正文视口自带左右边距，正文内**不自设**左右 padding；卡片/气泡内容与边框 ≥12px（气泡统一 `padding:14px 16px`，纯色气泡 `16px 18px 14px`，卡片内文 `14px 16px 12px`）。
- **标题层级**：标题上方 **28px**、下方 **12px**（h3 上 24px 下 10px）。
- **分割线**：上下 **24px**；**图片**：上下 **12px**。
- **字距**：正文 `letter-spacing:0.5px`；标题 1-6px 视风格。

## 三·五、审美硬规范 v10（所有排版必须遵守，违反即返工）

1. **零 emoji、零图标字符**：正文**绝对禁止** emoji 与装饰性图标字符（✅⚠️🔥💡❀✦▸➤★☆◆●▲📌🎉 等一律不得出现，包括气泡标题、列表符号、分割线）。需要"做标记"时用文字序号（1 2 3 / 01 02 03）、CSS 几何形状（span 圆角/旋转拼的圆点、方块、菱形、细线）或 art:// 植物图案资产。
2. **零渐变、零阴影**：禁止 linear-gradient（配色渐变，气泡/横幅/标题的大面积渐变填充）、禁止 box-shadow。底色一律低饱和纯色 + 细边框 + 留白；band 花纹用纯色几何 span 拼装（圆点/方块/空心圆/细条/菱形），同样零渐变。
3. **图案素材（美术）**：需要装饰时优先用 **art:// 植物图案资产**（完整资产目录见 视觉/模块 的 module-art-assets.md）——角饰常用 `sprig-grass`（小草，气泡右下角）、`leaf-corner`（叶角）；标题边框用 `vine-frame`（藤蔓花框）、`arch-garden`（拱门花框）、`frame-gilt`（描金双线框）；章节横幅用 `sunrise-panorama`（日出山水）、`moon-night`（月夜星空）、`bamboo-mist`（竹林晨雾）；里程碑用 `seal-red`（朱印圆章）、`laurel-badge`（桂冠徽章）；植物插画用 `spring-branch`（春花枝）、`rose-branch`（玫瑰枝）、`lotus`（莲花荷叶）、`plum-branch`（梅花枝）。用 `![说明](art://名称)` 引用（行内装饰用 `art://名称:px`，见 module-inline-deco.md），或用气泡装饰语法与标题风格语法。**资产是 PNG 图片：SVG 内允许渐变与明暗（渲染成图上传），正文 CSS 平面化铁律不受影响**；图案必须植物/自然类，绝不用图标类图案；每屏装饰 ≤1 处，不铺满。
4. **配色平面化**：全篇主色 ≤3（低饱和），纯色填充、无阴影、无渐变；每个版块同一套圆角（12-14px）与留白节奏。

## 四、写一篇推文的工作流

1. 澄清主题/读者/字数/调性（最多 1 问）。
2. 定**内容类型**（文本/内容类型 的 00-索引）→ 按类型推荐定**风格**（视觉/风格 的 00-索引）。
3. 拟标题、写文案（文本/文案 的 00-索引），结构=钩子→分层→行动号召。
4. 选模块排版（视觉/模块 的 00-索引），按类型与风格挑选模块点。
5. **落地风格化配色**：排版系统不提供内置配色主题——从所选风格的点文件读取完整色板（背景/主色/辅助/强调/文字），以**模板 HTML 或内联样式**在正文中显式落地（风格点的「模块表现」节给出具体色值与写法）。落地时遵守三·五审美硬规范：低饱和纯色、零渐变、零阴影、零 emoji/图标字符，图案装饰走 art:// 植物资产。
6. 配图片/视频（插图 的 00-索引）与封面首屏（其它/封面 的 00-索引）；检查合规（文本/合规）与可读性（其它/可读性）。
7. 用排版工具生成，检查输出符合间距规范（第三节）。
8. 交付：导出文件 → 写入草稿箱 → 发布/查询状态（发布操作知识不在本库，见 ops-knowledge/ 归档）。

## 五、条目的使用原则（写给调用方）

- **点文件是"知识卡"，不是死模板**：每个点给出详细规则、示例与可调参数，同时明确"需要结合账号情况自行判断"的部分——读者群、品牌色、账号定位不同，结论可以不同。
- **点文件之间允许引用**：一个点可引用其他点（如风格点引用模块点、文案点引用类型点），按需跳读。
- **信息以点文件为准**：若本主索引/方向索引与点文件表述不一致，以点文件为准（索引只负责路由与速查，细节在点里）。
