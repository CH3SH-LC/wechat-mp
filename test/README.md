## 〇·十、第 4 轮记录：装饰显示尺寸修正（2026-08-29，按用户反馈"花纹小到看不见"）

用户反馈：对大小的理解有误——生成的很多花纹小到根本看不见。

根因：SVG 画布 600-750px，但 375px 手机壳中实际显示宽仅 179-343px（缩放比 0.4-0.6）；设计时按画布比例画装饰（花 r5-12、叶 w5-8、珍珠 r2.5-5），缩放后仅 0.6-5px，肉眼不可见。

修正（29 个 combo 资产全部重设计尺寸）：
- **主装饰花** r 5-12 → 14-24（显示直径 17-27px）
- **叶子** 宽 5-8 → 12-18、长度拉长到 36-44（叶脉加粗 1.2→2.5）
- **珍珠/圆点** r 2.5-5 → 6-11（显示直径 8-11px）
- **端点圆** 3.5 → 6-9；线状元素 stroke 加粗
- probe 全部重校准（放大后 9 处落在白点/渐变/叶上 → 花心环/纯色部件）；laurel 虚线环改实线便于验证
- accent-branch 花被放大叶覆盖 → 花移至叶上层
- 验证：8/8 + 21/21 probe 全绿；375px 壳实测主装饰显示尺寸——玫瑰 97px、花冠 26px、内端花 17px、中心花 18px、藤叶 9px、左端叶 12px、波浪线 39px，全部可见
- **显示尺寸铁律**入 module-subheading §十（设计像素 = 目标显示像素 ÷ 缩放比；主装饰花 ≥20px、叶 ≥16px、珍珠 ≥8px、线 ≥2.5px）
