# 本轮能力验证的修复输入

本目录为 [DS 修复指南](../../design/ds-repair-guide-2026-09-29.md) 的配套证据入口，状态为**待修复**。

- `failure-fixtures.json`：受控自动修复首稿/失败稿/正例，真实桌面三回合完整会话，已保存 canonical source 与绑定，禁止外链样例。仅包含合成验收文章，不含 API 凭据。
- `evidence-index.json`：原始证据的绝对位置、大小与 SHA-256。完整图像、日志和版本文件仍在原始证据目录，未搬移或覆写。
- `fact-matcher-design-probes.json`：准备指南时追加的生产函数反例，属离线函数证据，不是实际模型改错日期或电话的证据。

夹具中的旧 ID 仅用于复现输入和关联原始记录；真实验收须分配新的 session/run/profile/端口，不得对旧记录执行提交。

重要：完整会话证实第三回合已有 v2 修改稿，应用却只保存了聊天。不要根据 UI 中不含围栏的助手摘要，误写成“模型未产出正文”。该候选又保留了历史 `|new`，修复接线后必须防止只改文字时重复绘图。

调查探针的 exit 0 可能意味着成功复现缺陷；DS 需将期望转为正确业务行为，并证明修复前红、修复后绿。复制/改造测试时另设输出目录，原始证据保持不变。
