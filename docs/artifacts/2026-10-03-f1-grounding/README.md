## 二、怎么验的：真实 App 实参截获（新增 `scripts/app-message-grounding-check.mjs`）

任务卡第 3 节要求「用零模型替身截获**真实 App 实际发出**的消息……不能以常量匹配或源码字符串断言代替」。

做法：把**真实 App** 原样跑起来（真实 React 组件、真实 `turn()`、真实交付门禁），只在
`src/lib/chat.ts` 模块末尾注入替身，把 Rust 侧通道换成受控实现——页面里 `window.__TAURI_INTERNALS__` 因此为真，
App 走的就是**桌面端**的组装路径（digest、baseMsgs、revise 追加、正式稿回读）。命令：

```
node scripts/app-message-grounding-check.mjs --out <dir> http://127.0.0.1:1420
```

三个受控场景，覆盖任务卡点名的四个入口：

| 场景 | 覆盖入口 | 夹具（受控响应，**非**原响应回放） |
| --- | --- | --- |
| `compose-write-and-revise` | prep 普通轮 ×2 + **末轮**、compose **WRITE**、WRITE 后的**自动 REVISE** | prep：`load_knowledge` → `load_knowledge` → `finish_preparation compose`（**走满 3 次**才触得到末轮提醒）；撰写稿含 emoji（触发 `html.emoji` 阻断 → 进修订环） |
| `candidate-then-revise` | prep 普通轮 ×2 + **末轮**（**直接 candidate**）、candidate 后的**自动 REVISE** | prep：同上三次，第 3 次 `finish_preparation candidate` |
| `prior-doc-title-only`（G2b） | 续改：正式稿回读 + 权威限定 + 素材保持 | 预置一份 accepted 正式稿（含材料未给的"续借不受影响"），用户只说"只改标题" |

断言全部打在**实际发出的 `messages` 实参**上，三条纪律：

1. **追加指令类断言按消息定位，不按整串文本**：prep 的断言钉在含"创作类请求的处理方式"的
   **PREP_INSTRUCTION 那条消息**上、末轮提醒钉在含"最后一次请求"的那条上；WRITE/REVISE 钉在**最后一条消息**上。
   用整串文本会因为 system 里本来就有共同规则而变成恒真，抓不住"某入口漏接"。
2. **实参必须在调用时刻深拷贝**：`runPrep` 传出的 `convo` 是同一个数组引用、后续轮次还会被 push 工具结果；
   按引用存会把"第 1 次请求"记成最后一次的最终形态（三份记录逐字节相同），记的根本不是当时发出去的那份。
3. **末轮必须真的走到**：`PREP_LAST_ROUND_REMINDER` 只在第 3 次请求追加，两轮的剧本永远触不到它。

  ③ 仍要求保持既有素材引用、④ 上一版那条"续借不受影响"**按原样保留在提示里**（不静默删除、不插"待确认"占位）。

  **模型是否真的照做，语义未验**。

### G3 正向授权（过度阻断对照）

- 实际发给模型的共同规则里**保留**了正向授权（"可以写连接语和明确标识的普通建议"）、
  **明确不要为缺项反复追问**、**允许省略非必要缺项**（不是"缺任何字段都不成稿"），
  且**没有**"见到承诺就删/封"式口径——四条都断言在实际实参上（见红绿对照）。
- **边界（独立复核提出的弱项，如实标注）**：这些都是**文本层**的对照。第三条的"不得出现"查的是一组措辞，
  换个说法仍可能绕开；它证明的是"规则本身没有过度阻断口径"，**不证明**模型在正向材料下真的会保留承诺。
- "材料明确给了免费/顺延/值守时必须准确保留"属于**语义**，**本轮未验**。

## 七、真实模型小样（用户明文授权，2026-10-03）

用户原话「**明文写入，允许授权api做测试**」，据此按 [样本卡](samples.md) 的三个冻结样本跑了真实小样。
**密钥口径不变**：Key 仍只从环境变量 / 应用本机设置 / 旧 `~/.dsh/.credentials.yaml` 兼容路径读取，
**没有写进任何文件**——"明文写入"指的是把授权这条记录落纸（已写进 [REQUIREMENTS](../../../REQUIREMENTS.md)）。

驱动侧给 `live-acceptance.mjs` 加了四个 phase（**只改验收脚本**）：`G1`（稀疏长稿，**逐字同 L7 题面**，

判定读的是**成品正文**（不是产品侧的关键词阻断——产品里没有也不允许有）。
