见微 X1 记录心率、血氧和睡眠，平时不响不震，只在需要的时候开口。日常盯的就是三件事：

::: cols
- 心率与血氧：持续记录，明显偏高时轻震一下提醒
- 睡眠：区分深睡、浅睡和清醒段，早晨给一句小结
- 久坐：满一小时提醒起身，走几步就安静
:::

数据在 App 里按周叠成趋势，能看出这周比上周睡得多了还是动得少了。手环和 App 里没有广告，数据也不做社交公开。
