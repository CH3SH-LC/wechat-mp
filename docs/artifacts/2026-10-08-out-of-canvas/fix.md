# 修复记录：越界判定的三类误判（2026-10-08）

上游是同一目录的 [根因报告](README.md)。本轮**只修已实证的误判**，不动阈值、不动模型侧提示词——
因为"被拦的 7 张原件没留存"，真画错与误杀的占比仍是 UNKNOWN，改阈值会造成"为了转绿而放宽"。

## 改了什么

改动文件：`src/lib/svg-quality.ts`（唯一），另加 `scripts/svg-quality-check.mjs` 的夹具与断言。

| # | 误判 | 旧行为 | 修法 |
| --- | --- | --- | --- |
| D1 | **贴边的零厚度元素**被判越界 | 相交判定用严格 `box.x + box.w > 0`，顶边横线（`h=0`）与 `x=0` 竖线（`w=0`）因此恒为假 | 改**闭区间**相交（`>=` / `<=`）。只放过"贴着边界"这一种；整体在画布之外仍判越界 |
| D2 | **祖先 `<g transform>` 搬进画布的元素**仍按变换前坐标判 | 只看元素**自身**有没有 `transform`，子孙照判 | 新增 `collectTransformedGroupRanges()` 扫 `<g>` 嵌套，落在带 transform 的组内的元素**不参与越界判定** |
| D3 | **`viewBox` 的 `min-x`/`min-y` 被丢弃** | `viewBox = { w, h }`，原点被当成 0 | 保留原点，判定与占画比都按 `[minX, minX+w] × [minY, minY+h]` |

D2/D3 都遵循该文件既有的口径（注释原文）：「带 transform 的元素一律视为在画布内……**宁可放过，不能误杀**」。

## 本轮**没做**（明确登记，不夹带）

1. **被拒 SVG 的落盘留存**——这是把 UNKNOWN 变成定论**唯一缺的东西**。**不能**塞进 trace：
   Rust 侧 `TRACE_MAX_FILE_BYTES = 512KB` 会轮转分片，而验收驱动按文件读 trace，塞大对象可能把
   "记录少记"判成失败。需要一条**独立的落盘通道**（Rust 命令）或独立的证据目录，属单独一步。
2. **有信息重画**：现在第二次重画原样重发同一 prompt（`image-agent.ts` 的 `genOnce` 调用处），
   模型拿不到失败原因——实测出现 11→44、30→15 的越画越差。属行为变更，需单独验收。
3. **阈值与模型侧提示词一律未动**（等拿到被拒原件、能用根因报告 §6.2 的三条互斥判别式定性之后再说）。
4. **部分降级通道**（少量装饰越界不整张丢弃）：策略未定，不动。

## 第二个缺陷：驱动侧把"大概率"当硬失败（run3 测出来的）

`scripts/live-acceptance.mjs:798` 原来是：

```js
if (!ready) fail('launch', `隔离 profile 预热 45s 仍未见 ${marker}——后续 CDP 大概率不可用`)
```

措辞自己写着"**大概率**"，却是一个硬 `fail()`。实测（BIG run3）：**26 项检查全部通过、0 条 FAIL、成稿 accepted**，
`run-result.json` 的 `errors` 里**只有这一条**，整轮却被判成 `ERROR`。

**修法**：降级为 `observe`（如实留痕、不判死）。真正的门禁保留在下游 `openApp` 的 CDP 连接结果——
连不上会以**确定**的理由失败或阻塞，不需要靠一个概率性告警提前判死一次已经成功的运行。

## 结论边界（不得外推）

- **可以说**：三类已实证的误判不再误杀、规则未被关掉（对照条证）；维修前 5/14 张被误杀 → 修复后
  10/10 全成、0 重画，大文章**从"0 产出"变成 `accepted` 成稿**。
- **仍不能**说"误杀是真凶"：被拦的 7 张原件没留存，**没有**逐一确认它们都属于 D1/D2/D3。
  证据是**行为侧**的强相关（拦下数归零），不是**逐张**定性。
- 也**不能**说"大文章已达标"：字数未达题面要求（1313 < 1500），且本轮只跑了一个样本。
