# 长期风格基线（pos-baseline）

> 定位：定下一套"无论哪篇、谁写、什么时候发都保持不变"的账号级底线——包括视觉主色、标题风格、页眉页脚、文风语气。它是让读者把"这一篇"认出是"你这个号"的长期一致性机制。
> 调用时机：账号观感不统一（有的篇大红大绿、有的篇纯黑极简）时；团队多人写作怕风格飘时；想系统性建立账号辨识度时。配合风格维度条目一起用。

## 一、核心方法

### 步骤 1：定"账号级视觉一致性"——哪些东西所有文章都一样

视觉基线不是每篇都要换花样的地方，而是**所有文章默认一致的"底版"**。需要固死的参数：

| 视觉参数 | 要固定什么 | 示例（工具号「Echo 的职场说明书」） |
|---|---|---|
| 主色 | 一两个主色，全号统一 | 深蓝 #2f6fed + 灰 #f5f7fa，不改 |
| 标题风格 | 标题字号/是否加粗/段落标题的前缀 | 正文小标题统一"序号 + 短句"，不用花体 |
| 页眉 | 每篇开头那块的固定版式与文案 | 固定一句"职场实用工具箱 · 第 N 期" |
| 页脚 | 每篇结尾的固定收尾与引导 | 统一"喜欢就收藏 · 评论区提问 · 点关注追更" |
| 封面基调 | 封面图的配色/版式/字体套路 | 统一色块底 + 大字标题，不换 |
| 分割线 | 文中分隔用什么样式 | 统一细横线，不换花纹 |

> 原则：**"底版"要素全号统一、"单篇"要素（篇内配色强弱、个别配图）可变。** 主色页眉页脚这类是底版，必须一致性；具体某一期的演绎是单篇，可以灵活。

### 步骤 2：定"文风一致性"——语气、人称、格式习惯

文风比视觉更难量化，但更有辨识度。至少固定这 4 块：

| 文风参数 | 要固定什么 | 示例 |
|---|---|---|
| 语气 | 是教练式/陪伴式/朋友式，还是幽默/克制 | 「新人的一封信」固定"温柔长辈式" |
| 人称 | 全号统一用"我""你"还是"我们" | 统一用"我教你"的"我–你"，不混用 |
| 格式习惯 | 是否用项目符号、每段多长、是否用 emoji/感叹号 | 固定"短段 + 分点"，emoji 一律为零 |
| 开头结尾习惯 | 每篇是否都走"钩子→正文→引导"的固定套路 | 固定首段 3 行内见钩子、结尾固定行动号召 |

> 把这几条写成"文风一句话"：「本号语气是____，人称用____，格式____，开头____、结尾____」。

### 步骤 3：把基线写成"基线文档"（可记录哪些固定参数）

"基线"要能落地，写成一份**一个页面就能看全**的文档（账号有一个就行）。记录哪些参数：

```
# 【账号名】风格基线 v2.1    最后更新：____

一、视觉底版
  主色：#____（主）、#____（辅）
  标题风格：____  段落标题：____
  页眉：____  页脚：____  封面基调：____  分割线：____

二、文风
  语气：____   人称：____
  格式：____（分段/分点/emoji 一律零）
  开头套路：____  结尾套路：____

三、栏目特别约定
  栏目A 的固定元素：____
  栏目B 的固定元素：____

四、允许变 / 不允许变 的清单
  可变：单篇配色强弱、个别配图风格
  不可变：主色、页眉页脚文案、人称、标题风格
```

> 基线文档的写点：**写"默认参值 + 可调清单"双行**。默认参值让所有人照做；可调清单明确"哪些能变、哪些不能变"，避免一刀切死。版本号 + 更新日期很重要——基线会迭代，留痕才不混乱。

### 步骤 4：基线被打破时的处理——分清"主动改版"和"无意跑偏"

- **主动改版**（品牌升级、读者更替）：先改基线文档再发内容，发前给读者一句预告（"最近号在做视觉升级，风格会有些变化"），改版要"成体系地改"，不是某几篇乱改。
- **无意跑偏**（某位编辑临时发挥、某篇为了追热点改版式）：按"是否影响辨识度"处理：
  - 影响不大（单篇配图风格略偏）→ 不改，下篇拉回即可。
  - 影响辨识度（主色变了、页眉没了、人称混用）→ 单篇不重发，但要在基线层提示编辑，更新基线文档的"反面示例"，防止再犯。
- **读者反馈风格变了** → 先对照基线文档自查，判断是无意跑偏还是主动改版没预告；无意跑偏就回归基线，并在后台统一说明。

### 步骤 5：理解"基线 + 单篇变化"的灵活关系

基线不等于"每篇都一个样"。正确的是：**底版全号统一（基线），单篇在底版内做风格演绎（可变）。**

- 基线在，辨识度才在——读者靠主色、页眉、人称认出你。
- 单篇变，才好内容才不腻——同一套底版下，可以换栏目、换情绪浓度、换个别视觉变体。

> 打个比方：基线是餐厅的"装修和招牌菜"，单篇是"今天这套菜单的出品"。装修招牌不变，菜单可以天天换。两者结合，才是长期风格。

## 二、可操作工具

**工具 1：基线文档模板（新建账号即建，见上步骤 3，直接复制填空）**

```
账号名：______   版本：v___    最后更新：____
视觉底版：主色___；标题___；页眉___；页脚___；封面___；分割线___
文风：语气___；人称___；格式___；开头___；结尾___
栏目特别约定：______
可变清单：______
不可变清单：______
```

**工具 2：发布前台核单（每篇发布前对一遍）**

- [ ] 主色用的是基线主色，没有临时换色
- [ ] 页眉文案与基线一致；页脚引导齐全
- [ ] 人称全文统一，和基线一致
- [ ] 标题风格符合基线（字号/加粗/序号）
- [ ] 文内 emoji/感叹号用量为零（固定零 emoji 基线）

**工具 3：季度基线自检清单**

- [ ] 抽查最近 10 篇，主色/页眉/页脚/人称是否仍全号一致
- [ ] 有没有"为追单个爆款而改版式"的先例——如有，是否已拉回归
- [ ] 基线文档最近一次更新是什么时候，是否过时
- [ ] 团队里每个人是否都看过并照做基线文档

## 三、示例（虚构账号）

**示例 1：「妈妈厨房周记」的基线片段（虚构）**

- 视觉底版：主色暖橙 #ff8c42；标题用"长句 + 一句心情"（「这一周，给家人端上热乎的」）；页眉统一小图 + "妈妈厨房 · 周记"；页脚统一"喜欢就收藏 · 评论区交作业 · 关注追更"。
- 文风：语气"亲切大姐式"，人称"我–你"；格式短段 + 分点，固定零 emoji，不用感叹号堆砌。
- 可变：单篇配图可换色系；不变：主色、页眉页脚、人称。

**示例 2：「Echo 的职场说明书」的基线片段（虚构）**

- 视觉底版：主色深蓝 #2f6fed；标题用"序号 + 短句"；页眉统一"职场实用工具箱 · 第 N 期"；页脚统一"收藏备用 · 提问进留言 · 关注不迷路"。
- 文风：语气"冷静教练式"，人称"我教你"的"我–你"；格式严格分点、每段短句；不用 emoji、不用感叹号。
- 可变：个别栏目的开场情绪浓度可调；不变：主色、页眉 Slogan、分点格式、克制文风。

> 注意：两个号基线都很"有签名感"，但风格南辕北辙——这就是基线该有的效果：一翻就认出是谁。

## 四、常见错误

- **错误 1：基线文档建了，但从没人照着做。**
  反例：文档躺在后台，编辑各写各的，号观感还是乱的。
  正解：基线文档进团队/个人 checklist，发布前台核单每篇必过（见工具 2）。
- **错误 2：把基线写死了，连单篇演绎都不允许。**
  反例：规定"一律不许用除主色外的任何颜色"，结果每篇死板、读者也腻。
  正解：基线只固死"底版"，可变清单明确放开的范围（单篇配色/情绪可调）。
- **错误 3：为了追热点临时改版式，破坏辨识度。**
  反例：看到别人用花哨海报火，某篇整个换掉主色和版式追风。
  正解：热点也只套在基线底版里做内容，不为热点破坏账号一致性。
- **错误 4：主动改版不预告、不同步。**
  反例：突然一天号整个换风格，读者惊讶甚至取关，内部也没更新基线。
  正解：改版先发预告、更新基线文档版本号，再成体系地换。
- **错误 5：只有"不可变"，没有"可变清单"。**
  反例：基线文档只写死不能改什么，没写哪些能灵活，结果要么乱要么僵。
  正解：基线文档固定"不可变 + 可变"两栏，明确边界，让单篇仍有发挥空间。

## 五、个性化空间

- **基线的颗粒度**：个人 IP 号基线可以松（人本身有辨识度，视觉文风略自由）；团队/机构号基线要严（多人协作靠文档保证一致）。判断依据：是不是"一个人写"——一个人写靠手感即可，多人才需要强基线。
- **主色的选择**：判断依据是定位气质——情感/家庭号偏暖色，工具/科技号偏冷色清晰，搭配《长期风格》主色体系。
- **允许变的幅度**：判断依据是账号类型——垂直知识号变幅小（读者为稳定内容来），内容型生活号变幅可大（读者期待新鲜）。把握"底版不变、演绎可调"的度。
- **基线更新的节奏**：判断依据是账号阶段——新号头几个月迭代快（半月一版本），成熟号稳定后低频（半年一版本即可）。主动改版必须预告+留痕。
