# 更新节奏（pos-rhythm）

> 定位：定下这个号"多久更新一次、什么时候更新"，并保证这个节奏能长期做到。节奏解决的是「读者习惯」和「可持续」，而不是"发得越多越好"。
> 调用时机：定更新计划时；发现更新断断续续、读者总要重新想"你多久发一次"时；觉得最近发不动、想调整频率时。

## 一、核心方法

### 步骤 1：用三个依据选频率——内容产能、读者预期、平台算法

频率没有一个"标准答案"，要从三个角度一起看：

| 依据 | 要问自己 | 若满足说明可加密 |
|---|---|---|
| 内容产能 | 每周我能稳定产出几篇"不注水"的文章？（不是能发几篇，而是能做好几篇） | 尚有富余 → 可加密 |
| 读者预期 | 读者是多次轻阅读型，还是深度追更型？ | 读者期待更密 → 可加密 |
| 平台算法 | 更新是否利于触达（活跃度）、持续有产出是否更易被推荐 | 更新有助于曝光 → 有加密动力 |

> 一句判断：**像"每周 1 篇良心深作"还是"每周 3 篇轻量更新"，取决于你产能的补给线，而不是"别人发多少我发多少"。** 频率的上限永远是你的"能做好"的产能，而不是你的"想发"。

**起步建议（供参考，非标准）：**

- 内容生产能力强、快：每周 2–3 次。
- 单篇质量型、生产较慢：每周 1 次（固定某一天更，形成强的读者预期）。
- 起步期建议先"少而稳"（如每周 1 次），跑顺产能再加密。宁可稳 1 篇，不要断更式拼 3 篇。

### 步骤 2：把频率和"固定更新日"绑死——节奏的两大好处

固定节奏不只是习惯，有两层实打实的好处：

1. **养成读者习惯**：读者在固定时间知道你来，形成"追更"认知，甚至会主动来留言。固定更新日比"想起来就更"更能沉淀粉丝。
2. **算法友好**：稳定有节奏的产出，让平台对账号的活跃度/稳定性判断更正面，曝光有机会更稳定（以微信官方平台实际规则为准）。

**固定更新日的做法：**

- 选一个能长期保证的日子（结合你的时间与读者阅读高峰，参考号内阅读分布）。
- 主栏目固定在特定日（如"周三更周会工具箱"见《栏目体系》），让栏目和日子绑定成双重预期。
- 万一固定日没法更，用"预告 + 补更"兜底，不要默默忍掉（见步骤 4 停更处理）。

### 步骤 3：产能撑不住时，怎么降频——"降频不减质"、合刊

节奏再稳也会有撑不住的时候（忙、灵感枯竭、质量下滑）。降频不是失败，**前提是"降频不减质"、向读者交代清楚**。两招：

- **降频不减质**：宁可把每周 2 篇，并成"每周 1 篇更用心"，也不要硬凑 2 篇注水。质量是长期口碑，频率可以波动。
- **合刊**：若担心频率下降导致"存在感降低"，可用"合刊"弥补——两三个短主题合成一篇多段落的"合刊"（如「本周三件事合集」），一篇顶上多期，既维持触达又控制产能。

**降频时的读者交代话术（模板）：**

> "最近在做内容升级，更新频率会从每周二/四调整为每周四一篇，但我保证每期都更用心。追更的朋友别走丢，我们周四见。"

> 原则：**频率是"可承诺的量"，承诺前想清楚，承诺后尽量兑现。** 临时降低频率是合理的，长期失信承诺（该更的不更、还不交代）才伤信任。

### 步骤 4：节假日、停更的预告处理

**节假日**：如果是会断更的节日，不必硬撑，但要留口——文章末尾或菜单提前说一句"假期停更，节后首期见"，比默默消失好。读者知道"你不是不更，是放假更"，预期就稳了。

**停更（暂停一段时间）：**

| 情况 | 建议 |
|---|---|
| 短期停更（1–2 周） | 固定更新日前 1 篇预告"下期延后/停更 X 周，节后回归" |
| 长期停更（月级别） | 发一条明确的"暂别说明"，说明原因与回归时间，避免读者以为号死了 |
| 回归 | 回归首期要有"回归感"，哪怕只是一句"我回来了"+ 当期内容，让追更的人能续上 |

> 停更不等于失踪：让读者知道"你会回来、什么时候回来"，节奏在读者感知里就不会断。

### 步骤 5：用数据来校正节奏——"这个频率真的合适吗"

节奏定下来不是一成不变，要隔一段时间用数据回看"这个频率是不是最优解"：

| 看的数据 | 说明 | 判断 |
|---|---|---|
| 每篇阅读 vs 更新频率 | 加密后阅读下滑，可能是读者吃不消或产能摊薄了 | 太密 → 降回 |
| 固定更新日那天的阅读是否显著高于其他天 | 高 → 固定日策略有效，坚持 | 不高 → 换日子试试 |
| 停更/低配期后的回归阅读 | 回归那篇阅读是否还是正常水平 | 是 → 频率调整没伤到读者 |
| 长期的趋势 | 有没有"越更越水、阅读越降"的恶性循环 | 有 → 立即降频止损 |

> 一个实用技巧：**每次调整频率，记录下调整日期和当时的阅读/关注数据。** 一个月后回看，就知道这个频率对你到底是"最优"还只是"最累"。不用天天盯，固定日回看一下趋势即可。

## 二、可操作工具

**工具 1：更新节奏卡（一张卡钉死频率与固定日）**

```
账号名：______   版本：v____  最后更新：____
更新频率：每___更新一次
固定更新日：周___ / 我选择这个日子的原因是____（时间/读者阅读高峰）
主栏目节奏：主栏目「____」每周/每月___更新；辅栏目「____」每月___更新
产能预案：若本周产能不足 → 执行「降频不减质」或「合刊」
停更规则：节假日如何预告 / 短期停更如何交代 / 长期停更发什么说明
```

**工具 2：每月能量检查表（评估这个月产能是否撑得住当前频率）**

- [ ] 我这个月实际发了几期？和承诺频率对得上吗
- [ ] 有没有临时降到"注水"来凑数？如有→下月主动降频
- [ ] 下一月内容选题库里有没有备用题，产能是否够维持
- [ ] 固更新日是否已被其他事项（节假日/出差）占掉，需不需要调整

**工具 3：读者预期管理三段式（用于频率调整/停更）**

```
预告：提前 1 期说明"下期起频率调整/停更"，说清新节奏/回归时间
过渡：调整前 1–2 期用固定元素照常收尾，保持熟悉感
回归：回归首期带一句回归语，让读者知道你守约回归
```

## 三、示例（虚构账号）

**示例 1：「妈妈厨房周记」（虚构）**

- 节奏卡：每周四更新一期（主栏目「周记快手菜」周四，其余按需做辅栏目）；选周四因为数据显示周四阅读高峰、且周四更新赶得上周末下厨需求。
- 产能预案：忙的时候把快手菜"合并成一篇三道菜合集"，不降质；遇到长假提前一篇预告"假期停更两周，节后第二周回归"。
- 读者交代："周四没见到我的时候，记得我不是不更，是在加班，回来给你带热乎的好菜。"

**示例 2：「Echo 的职场说明书」（虚构）**

- 节奏卡：每周三一期主栏目「周会工具箱」，每月 2 期辅栏目；选周三因要赶上周五前的会议准备需求。
- 产能预案：若某月主栏目连续两次没时间认真做，就把两期合刊成"这个月最该会的 3 个会议场景一次讲"；出差时提前一篇说明"本周停更，下周三补上"。
- 读者交代："周三见是约定，真忙到那周发不了我会提前说，绝不让你们白等。"

## 四、常见错误

- **错误 1：为了"更新频繁"硬凑注水内容。**
  反例：定每周 3 更，产能不够就把每篇都写成水文，号的质量整体垮掉。
  正解：频率服从产能——"做不好就不发那么多"，宁可降频不减质。
- **错误 2：频率定的太高，承诺无法兑现。**
  反例：头脑一热说"我日更"，坚持两周就断更，读者以为号死了。
  正解：先定"稳得住"的频率（少而稳起步），跑顺了再加密，承诺多少做到多少。
- **错误 3：完全没固定更新日，读者无法形成习惯。**
  反例：周三更过、周五更过、有时隔两周，读者根本记不住你什么时候来。
  正解：选固定更新日并绑到主栏目，让"周三=周会工具箱"成为读者心智。
- **错误 4：断更不交代、不预告。**
  反例：出差一周默默停更，读者在后台问"你号是不是不做了"。
  正解：停更/假期提前一篇预告，配回归话术，让读者感知到节奏仍在。
- **错误 5：把"阅读高就是更新多"当唯一标准。**
  反例：看别人日更涨粉就跟着日更，忽略自己产能和读者深度预期。
  正解：更新节奏是产能、读者预期、算法三方平衡的结果，不是单看频率高低。
- **错误 6：明明撑不住还硬挺，最后一次性断更大段时间。**
  反例：连续好几周硬撑日更，某天彻底崩了直接消失一个多月。
  正解：提前察觉产能拐点，主动降频/合刊 + 交代读者，比硬撑后崩盘可控得多。
- **错误 7：一次调整就频繁改，节奏永远稳定不下来。**
  反例：二月周三更、三月改两周更、四月又日更，读者永远没法建立预期。
  正解：一次调整固定下来跑一段时间（至少一个月），用数据判断，别频繁变阵。

## 五、个性化空间

- **频率高低**：判断依据是内容类型与产能——干货教程/深度内容宜少而精（每周 1–2 次），轻资讯/热点类可更密（每周 2–4 次），且看你能稳定兑现多少。起步期一律"少而稳"。
- **固定更新日的选择**：判断依据是号内阅读分布与读者作息——看哪几天阅读/收藏最高，选那个日子固定；也可结合栏目类型（职场号赶在周一/周三，家庭号赶在周末前）。
- **节假日是否停更**：判断依据是节日对读者是否有相关内容——非相关节日可停（并预告），相关节日(如中式节日做食谱/职场年节)反而是出内容时机。判断标准：有没有值得为读者做的那期内容。
- **降频的幅度与节奏**：判断依据是产能拐点——轻微产能不足用合刊，持续产能不足就正式降频并同步读者；不要先硬撑再三降，先交代再降更成熟。
