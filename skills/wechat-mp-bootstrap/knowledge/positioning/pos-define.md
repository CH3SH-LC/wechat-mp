# 定位与读者画像（pos-define）

> 定位：用一句话说清楚「这个账号是做什么的、给谁看、为什么和别的号不一样」。定位是内容选择的北极星——写什么、不写什么、用什么语气、怎么排栏目，全都从这句话推导。没有定位的号，就像没有菜单的餐厅，读者不知道怎么点、也没有理由再来。
> 调用时机：建号时先定定位；账号转型、内容方向调整时重定；发现内容越写越散、自己都不知道下一篇写什么时回来校正；写每一篇前没有底的时候，也回到定位句对一遍。

## 一、核心方法

### 步骤 1：用"一句话定位法"打出账号的定位句

一句话定位 = **给谁** + **提供什么** + **为什么不同**（三个空缺填全，缺一个就是没定位清）。

- 给谁：你的核心读者是谁，不要写"所有人"，越具体越有力量。这里要写出"正在经历什么的人群"，不是放之四海皆准的"喜欢阅读的人"。
- 提供什么：你能为这群人持续产出什么价值。可以是信息（第一手资讯）、方法（怎么做）、情绪（被理解/被鼓励）、陪伴（稳定更新陪你走一段）。
- 为什么不同：凭什么读者关注你不关注别人——你的独特角度、经历、立场、资源。这是辨识度的来源，"别的地方看不到的"。

**一句定位模板：**

> 我运营的账号，是给「____人群」提供「____内容价值」，让他们「____场景下/____痛点上」得到帮助，而我和别的号不一样的地方是「____」。

**五个反例 → 一个正解：**

- 「一个分享生活日常的公众号」→ 只填了"提供什么"，且太泛。
- 「给年轻人看的号，什么都有点」→ 三缺二，等于没定位。
- 「给职场人提供干货」→ 有了给谁和提供什么，但"为什么不同"没有，可替代性高。
- 「专门讲好吃的号」→ 只有主题没有人群、没有差异化，竞争者无数。
- 「一个什么都写的个人号」→ 完全没定位，读者不知道你代表什么。
- 正解：「给 25–35 岁职场中层提供『把复杂管理工作落地成表格和步骤』的实操干货，其他号讲理念，我讲今天就能用的动作。」——给谁、给什么、为什么不同，三件全满。

> 判断方法：把定位句念给一个陌生人听，如果他能立刻说出"哦，所以这个号是干这个的、和谁不一样"，定位就成立了。如果听完他只能点点头说不出重点，说明还没定位清，回去再磨。

**三种常见定位原型（可以按需套用）：**

| 原型 | 一句话 | 适用 |
|---|---|---|
| 干货工具型 | 给 X 人群提供可落地的方法/工具 | 知识、职场、教程号 |
| 情绪陪伴型 | 给 X 人群提供被理解与陪伴 | 情感、成长、生活号 |
| 资讯信息型 | 给 X 人群持续提供某个领域最新信息 | 新闻、行业、垂直资讯号 |

> 号的实际定位常常是"一种原型为主、另一种做补"，主次分清即可，不必只选一种。

### 步骤 2：画读者画像（5 个要素）

读者画像不需要做严谨人群调研，用你已有的观察（后台粉丝数据、留言、私信、朋友圈）快速归纳即可。核心抓 5 块：

| 画像要素 | 要问的问题 | 示例（职场干货号） |
|---|---|---|
| 年龄 | 主流年龄层，决定语言习惯 | 25–35 岁，副业刚需期 |
| 职业/身份 | 什么身份在读，决定场景 | 互联网/传统行业中层、项目负责人 |
| 场景 | 他多在什么时刻点开你的文章 | 通勤路上、午休、晚上加班后 |
| 痛点 | 他现在最难受、最想解决的一件事 | 任务靠人催、会议开不完、向上汇报没套路 |
| 关注点 | 他在意的价值维度（省时间/升职/安全感/被认可） | 更看重"少踩坑、可复用、被领导看见" |

**读者画像一句话版（用于速查）：**

> 我的读者是【在____场景下，正被____困扰】的【____人群】，他们最想要____，最怕____。

**画像的三种来源（由易到难）：**

1. 后台数据（性别/年龄段/地域/常读）：先看大方向。
2. 留言与私信（读者主动说的话）：最真实的痛点来源。
3. 自己的经验与行业判断（我是这群人的同类/我服务过这群人）：补充空白。

> 画像产出后，写进账号后台备注或一张卡片，每次选题、定标题、选语气都对一遍，能大幅减少"写偏"。写之前心里先"看见"一个具体的读者，比对着抽象的"人群"写得准得多。

### 步骤 3：用定位决定"内容范围"（什么写 / 什么不写）

定位不是嘴上说说，要落到"清单"——明确这个号**写什么**、**坚决不写什么**，防止内容越做越杂。这是"这个号我不做什么"的边界，边界清晰反而让主线更强烈。

| 内容类型 | 确定"写"的原则 | 确定"不写"的原则 |
|---|---|---|
| 与定位直接相关 | 写，且作为主线 | — |
| 与定位弱相关、但有读者刚需 | 谨慎写，做成"副线栏目"，控制比例 | 若会稀释定位则砍掉 |
| 与定位无关的追热点/爆款 | 不写，除非能挂到定位上 | 一律不写 |
| 读者主动索要、但不在定位内 | 评估能否挂进定位，挂不进就转介或明说 | 不硬写，保护定位边线 |

**示范：一个「职场实用工具」号的内容边界**

- 写：管理方法、时间管理模板、向上汇报话术、SOP 制作教程。
- 不写：情感散文、社会时评、明星八卦、与工作无关的鸡汤。(即使爆款，也不追。)
- 边界的例外规则：热点若要挂到定位上（如"某公司裁员的向上沟通"），只在角度与定位相关时写，换了个角度蹭就不写。

> 边界一旦写好就贴在选题库里（见《选题》维度条目），每次新选题先问"这条属不属于边界内"，不属于就丢。"不写什么"和"写什么"一样重要，它是保护主线的护栏。

### 步骤 4：识别"定位跑偏"的信号，及时校正

**跑偏信号（中 2 条以上就该停一下）：**

1. 连续几篇阅读/点赞下滑，但自己觉得"写得挺好"。
2. 新粉丝涨得少，且老粉丝留言开始问"你号到底做什么的"。
3. 自己选题时越来越依赖"昨天刷到什么热点"，而不是"读者需要什么"。
4. 同一批读者在评论区说你"和别的号没区别了"。
5. 后台粉丝画像和你当初定位的人群对不上（关注的人不是你想服务的那些）。

**校正方法（三步回归法）：**

1. 回看定位句：把当初写的那句话翻出来，逐项对"还在不在做"——给谁变没变、提供什么变没变、为什么不同还在不在。
2. 看数据归因：跑偏通常不是内容质量问题，而是"换了人群"或"丢了角度"，用粉丝画像核对是换了读者还是丢了定位。弄清是"内容变了"还是"读者变了"。
3. 小步拉回：用 1–2 篇"回归主线的强内容"先试探（发一篇你定位里最强的类型），看老读者反应，再决定大改还是微调。不要一次性推翻重来。

> 转型不等于推倒：可以在既有定位上"聚焦"（从泛职场收到某一个垂直刚需），比"换一个完全不相干的赛道"稳得多。转型也分"微调"（给谁略收窄）和"大转"（换赛道），能微调就别大转。

### 步骤 5：把定位说进四件"对外的事"（说一句给它做一次）

定位不是只写给自己看的秘密，要让读者在四件地方"一遍就能感受到你是做什么的"：

| 对外位置 | 怎么写 | 示例（职场号） |
|---|---|---|
| 账号简介 | 一行把"给谁+给什么+为什么不同"塞进去 | "给 25–32 岁职场人拆汇报、会议、沟通，今天就能照着用的话术" |
| 每篇标题 | 标题关键词要落在定位里的主赛道词 | 标题常带"汇报/会议/职场"等定位词 |
| 菜单栏 | 用定位里的核心主题做菜单命名 | 「汇报话术」「合集」「答疑」 |
| 封面/首屏 | 封面色调与版式与定位气质一致 | 职场工具号用冷色干净版式（见《长期风格基线》） |

> 关键：**定位在四件对外的地方要"统一发声"。** 读者刷到简介、标题、菜单、封面，四处的感觉对得上，定位才真正"立住"。这也反向帮你发现问题——如果某处和你定位对不上，就是跑偏信号。

**定位对外表达的模板（简介一行版）：**

> 给「____」讲「____」，今天就能用/每天陪着你/一手资讯。【区别一句话】。

> 这行字既是账号门面，也随手用来写标题的关键词和菜单命名，一举多得。

### 步骤 6：把定位变成"在用的机制"，而不是"写过就忘"

很多号"定位写在文档里就再也不看"，等于没定位。要让它真正生效，需要四个常设动作：

1. **贴进选题库**：内容边界清单长期贴在选题流程里（见《选题》维度条目），每篇先过边界。
2. **写前拿定位对一遍**：用工具 5 快问，花 30 秒避免一篇写偏。
3. **季度定位复盘**：每季度花一次时间对"读者画像是否还准、边界清单是否还合适、定位句还成立吗"。
4. **新栏目前先过定位**：要不要开新栏目，先问"它服务定位里哪一块"（见《栏目体系》），答不上就不开。

> 一句话：**定位不躺在文档里，长在"每篇选题、每篇开头、每个菜单"的动作里。** 有了这些常设动作，定位才不会只停在纸上。

## 二、可操作工具

**工具 1：一句话定位填写卡（填空式）**

```
给谁：______（再具体一点：年龄＋身份＋正在经历的场景）
提供什么：______（信息 / 方法 / 情绪 / 陪伴，选主项＋次项）
为什么不同：______（我的独特经历 / 角度 / 资源 / 立场）
---
一句话版：给【____】，提供【____】，因为【____】所以不一样。
```

**工具 2：读者画像速填表**

```
主流年龄：____  身份：____
阅读场景：____   最痛点：____   最怕：____   最想要：____
画像来源：1后台数据____ 2留言私信____ 3个人经验____
一句话画像：______
```

**工具 3：内容边界清单（定期更新，贴到选题库）**

```
1 一定写：1____ 2____ 3____
2 谨慎写（限量，作副线）：____
坚决不写：____（为什么：会稀释定位）
边界例外规则（热点怎么挂）：____
```

**工具 4：定位自查 5 问（每季度对一次）**

- 我最近 10 篇，有几篇落在我的边界清单里？
- 谁在给我点赞留言？是当初定位的那群读者吗？
- 我写的内容，有没有一篇比别的同类号"多给了一步"？
- 我现在做得最顺手的那类内容，是不是也被我当成主线？
- 如果只允许我发 3 类内容，我选哪 3 类？——这 3 类就是我的主线。

**工具 6：读者代表卡（写前抽出来当"给一个人"写）**

```
我的读者代表：叫他/她 [名字]，____岁，____身份
他今天最让我"必须写这篇"的一件事：____
他看完这篇最想带走的一句话：____
我写的时候想象他正____（场景）拿起手机
```

> 用法：实在写不下去或怕写偏时，想象这个"读者代表"就坐在对面，把话讲给他一个人听——比对着"粉丝"这个抽象词顺畅很多，也不容易飘。

**工具 5：定位落地检查（写每篇前快问一遍）：**

```
这篇是给"定位里的那群人"看的吗？──是不是
这篇给了他们定位里承诺的价值吗？──给没给
这篇在"为什么不同"上有发挥吗？──有/没有
这篇落在内容边界内吗？──在/不在
```

## 三、示例（虚构账号）

**示例 1：「妈妈厨房周记」（虚构）**

- 一句话定位：给 28–40 岁、家里有娃、下班晚了没思路做饭的妈妈，提供「每周 5 道 30 分钟快手菜连图带步骤」，因为号主自己就是双职工妈妈，每道菜都试过、踩过坑，所以和其他菜谱号的"只会拍漂亮图"不一样。
- 读者画像：年龄 28–40；身份：上班族妈妈；场景：晚上 6 点半到家的厨房；痛点：不知道做什么、时间不够；关注点：省时间、娃爱吃、健康。
- 内容边界：写——快手菜谱、备菜技巧、剩菜改造、娃的便当。不写——高端摆盘、复杂烘焙、纯美食探店。
- 一句话画像：给"晚上六点半推开家门、冰箱里不知道做什么、娃还等着吃饭"的上班族妈妈，提供"今天就能照着做"的快手菜。

**示例 2：「Echo 的职场说明书」（虚构）**

- 一句话定位：给 25–32 岁的职场新人到中层，提供「把汇报、会议、沟通拆成话术模板和步骤清单」的实操干货，因为号主做过 6 年大厂中层带过人，讲的是"今天我就能照着用"，而不是理念鸡汤。
- 读者画像：年龄 25–32；身份：职场新人/小团队负责人；场景：写周报、开周会、向上汇报前；痛点：不会说、怕做错、没人教；关注点：可复制、能落地、被看见。
- 内容边界：写——汇报模板、会议话术、沟通拆解、SOP 清单。不写——宏观职场社会学、情感话题、纯个人经历流水账。
- 一句话画像：给"例会前还在纠结怎么说才不被追问"的职场新人，提供一套"打开就能念"的话术与步骤。

## 四、常见错误

- **错误 1：定位写在简介里，却不落到内容。**
  反例：简介写"专注职场成长干货"，实际天天发段子和时事评论，读者点开十篇八篇对不上简介。
  正解：把定位落到内容边界清单，每篇选题先过边界，简介只是定位的"对外露头"，正文才是真定位。简介写什么，正文就写什么。
- **错误 2：把"写爆款"当定位。**
  反例：什么火写什么，今天追热点、明天跟风，账号没有稳定人群，涨的粉留不住。
  正解：热点可以蹭，但必须能挂到自己的定位上；定死"主线 3 类内容 + 少量热点副线"，副线不能超过主线。
- **错误 3：给谁写得太宽（"所有人""大众"）。**
  反例："一个写成长、理财、生活的号，适合每个人阅读。"——等于没给谁。
  正解：聚焦到一群具体的人，写作时甚至想象一个具体的读者，聊给"一个人"听,越具体越有共鸣。
- **错误 4：定位一确定就永远不动。**
  反例：账号运营三年，市场和读者都变了，还守着最初那句话不校正，内容越来越脱离当下读者。
  正解：读者画像和内容边界要按季度复核；读者变了，定位里的"给谁"也要跟着微调，但"提供什么/为什么不同"尽量稳定。
- **错误 5：定位清晰但"不执行"——正文语气和定位打架。**
  反例：定位是理性工具号，正文却满屏感叹号、口语卖萌；定位是温暖陪伴号，正文却冷冰冰列数据。
  正解：定位同时决定内容范围与语气底盘，写作时对齐（语气细节见《长期风格基线》条目），让读者"读一句就知道是你"。

## 五、个性化空间

- **给谁的范围粗 vs 细**：新号可先粗（一个宽人群），跑出核心粉丝后再聚焦细分。判断依据：越窄越容易做出辨识度，但前提是你对这群人有足够深的了解；不了解就先粗后细，别为了窄而窄。
- **"为什么不同"的来源**：可以是独特经历（你踩过的坑）、独特资源（你能拿到的内部资料）、独特立场（你反主流认为应该怎样）。判断依据：哪个是你真实最有优势、别人难复制的，就主打哪个；不要选一个你撑不住的人设。
- **内容边界的松紧**：个人 IP 号边界可以松一点（人本身有魅力，范围宽些也能撑住）；垂直知识号边界要紧一些（读者就是为某个方向来的）。判断依据：读者是冲着"人"来还是冲着"主题"来——冲主题来的号，边界必须紧。
- **读者画像的更新频率**：成熟期每季度、成长前期每月。判断依据：数据样本是否够——阅读刚破千就急着改画像意义不大，数据稳定后更新才有参考价值；画像要跟着真实粉丝走，不看自己想象。
- **单原型还是混合**：判断依据是竞争环境——单一原型在竞争充分领域难出头时可"一种为主+另一种补"，但主次要分清，别两头都浅。
