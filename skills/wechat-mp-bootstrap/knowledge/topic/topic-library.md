# 选题库管理（topic-library）

> 定位：把随时挖到的候选选题变成一张可查询、可排期、不丢失的"选题表"，让账号从"每次现想"变成"从库里取"，长期不缺内容。本条目给登记表字段、分类与优先级规则、周/月排期机制，以及每周补充、每月清理的维护节奏。
> 调用时机：**建立长期选题池时必读**。想系统化经营选题时，把登记表拉起来；日常只要往里加题、定期排期、月底清理。与《选题来源》（负责挖）、《选题判断标准》（负责筛）、《热点日历》《系列化规划》（负责排期）配套使用。

---

## 一、核心方法

### 1. 选题登记表：六列定乾坤

不建议用复杂的系统，一张表格（Excel / 飞书 / 石墨 / 笔记本都行）就够。核心六列：

| 字段 | 填什么 | 示例 |
|---|---|---|
| **主题** | 一句话说清要写什么 | 没经验的第一份简历怎么写 |
| **类型** | 属于哪类内容/哪类来源 | 干货教程 / 来自痛点 |
| **来源** | 从哪挖来的（点开即溯源） | 上周《简历》评论区 |
| **优先级** | P0/P1/P2 或 高/中/低 | P1 |
| **状态** | 待写 / 写作中 / 已排期 / 已发布 / 放弃 | 待写 |
| **备注** | 适合的发布时间、角度提示、相关线索 | 可做系列第 1 篇；关联跳槽季 |

关键填写要求：

- **主题**要写"能算数"的一句话，别写"写一篇关于职场的"。好的主题 ="对象 + 动作 + 收益"，如"新人避免被边缘化的 3 个习惯"。
- **类型**优先挂你的《内容类型》维度定的类型（干货/观点/热点/生活/活动…），排期和写稿时能一眼知道用什么结构。
- **来源**必须写清出处，一是溯源判断价值，二是避免重复挖同一个点。
- **状态**要让"这张表落在哪里、写到哪一步"一眼可见，别让已写、待写、已发混在一起。
- **备注**是灵活区：写适合的推出时机、可延伸的系列方向、关联的热点节点。

### 2. 分类：按"账号定位"来分，不是按心情

分类的目的是让书单能导向你的账号定位，两条主轴：

- **按内容类型分**：干货教程 / 观点共鸣 / 热点评论 / 生活故事 / 活动软文…… 分类要先看你的《内容类型》维度定了哪些类型，表里与之一致。
- **按栏目分**：如果你的账号有固定栏目（见《栏目体系》），直接以栏目为分类标签（如"周一干货""周五观点"），排期时最省事。

分类的落地建议：

- 一个选题建议挂**一个主分类 + 一个来源标签**即可，别同时挂五六个标签导致难排序。
- 栏目标签与内容类型标签二选一为主：有栏目用栏目，没栏目再落内容类型。
- 每周排期先看"类型/栏目"分布是否均衡，防止连续几篇都是同类内容。

给一个"往表里怎么填"的分步示范（拿一条挖来的题走一遍）：

| 步骤 | 动作 | 示例"试用期被辞怎么办" |
|---|---|---|
| 1 | 写主题：对象+动作+收益 | 试用期被辞，下一份工作怎么圆 |
| 2 | 归类型 | 干货教程 |
| 3 | 写来源 | 上周评论区 3 条提问 |
| 4 | 定优先级 | P1（痛点正热） |
| 5 | 置状态 | 待写 |
| 6 | 备注 | 可作"职场应急系列"第 1 篇

### 3. 优先级：P0/P1/P2 三级

结合账号定位与当前目标定优先级，规则给两种可选的：

| 优先级 | 含义 | 判断依据（二选一） |
|---|---|---|
| **P0** | 必须尽快做 | 贴近账号核心定位 + 当下读者最想要 + 有明确时间窗（热点/节点临近）|
| **P1** | 应该做 | 符合定位、有稳定价值、无硬性时间窗 |
| **P2** | 可做可不做 | 泛价值 / 边缘题材 / 待深化才够格 |

优先级使用注意：

- 优先级可以写**多个题并列**同档（不必每题都排第一）。
- 优先级会随节日、热点、账号阶段变化——**排期前复查一遍**，别把写好的 P2 硬塞进重要档期。
- 不要把所有题都标 P0，那样等于没有优先级；P0 保持"当下真必须"的数量（建议占全部 ≤20%）。

### 4. 排期机制：周计划 + 月计划

- **周计划（一周一张）**：周日/周一花 20 分钟，从库里按优先级 + 时效挑出下周要发的题，标到具体日期，并注明"哪天写、哪天审、哪天发"。更新频率高（日更/双更）的账号周计划列得密些；周更号列 1–2 篇即可。
- **月计划（一月一版）**：每月初把"节日、行业节点、平台活动、系列进度"（来自《热点日历》）落到月历上，标出"本月必须做"的题，再让周计划在整体框架里微调。

排期的核心原则：**库里永远比排期多**——准备量大于实际更新量，才有从容挑选的余地。建议维持"库存 ≥ 未来 2–4 周更新量"。

排期的三件事：

| 事项 | 做法 |
|---|---|
| 挑题 | 先 P0，再三 P1，P2 视档期富余 |
| 定日期 | 按时效（热点/节点近）优先排前，固定栏目占固定位 |
| 配人力 | 注明哪天写、哪天审、哪天发，多人则写清负责人 |

### 5. 维护节奏：每周补充、每月清理

- **每周补充（跟挖题动作合并）**：每次挖完选题，把候选（先不过筛）全塞进库里，数量净增 ≥ 本周更新数。
- **每月清理（定时做）**：
  1. 把"已发布"归档；
  2. 把超过 3 个月仍 P2 且没可写价值的题做"放弃"标记（别占着优先级，但保留记录）；
  3. 把被热点顶掉、时效已过的节点题移出；
  4. 把重复主题合并成一条。

清理不等于删除历史，建议用一个"已放弃"状态保留，方便日后需要时翻回来。

**每月清理的四步操作（对着表做）：**

1. **归档**：把状态为"已发布"的行移到一个"已发布归档"区（或加黄色标记），保留标题/来源/数据,便于月底复盘选题质量。
2. **清僵尸**：扫一遍 P2 且超过 3 个月没进展的题，问"还值不值得做"，不值得就标"放弃"（保留记录）。
3. **移时效过期**：被热点顶掉、节点已过的题移出"待写"，标"过期"或"放弃"。
4. **合并重复**：明显重复的主题合成一条，保留备注重合后较全的那条。

清理的另一个好处是触发"选题质量复盘"：本月的题哪些来源出得好（多、转化高）、哪些来源荒废,下月就加大好来源的挖法（配《选题来源》《数据复盘》）。

## 二、可操作工具

**选题登记表示例（表头 + 示例行）：**

| 主题 | 类型 | 来源 | 优先级 | 状态 | 备注 |
|---|---|---|---|---|---|
| 没经验的第一份简历怎么写 | 干货教程 | 评论私信 | P1 | 待写 | 可作"求职系列"第 2 篇；关联跳槽季 |
| 远程办公下新人别被边缘化 | 热点评论 | 本周热搜 | P0 | 排期周五 | 热点窗口窄，当天写当天审 |
| 一年读 50 本书的方法清单 | 干货清单 | 数据反馈（收藏高）| P1 | 已发布 | 已在此前发布 |
| 跳槽前别忽略的三笔账 | 干货清单 | 行业节点 | P0 | 待排期 | 排到跳槽季前 2 周 |
| 办公室绿植怎么养 | 生活随笔 | 个人兴趣 | P2 | 放弃 | 定位边缘，保留记录 |

**周计划 / 月计划小模板：**

```
【本月行动计划】（每月 1 日更新）
- 必须做：____（对应节日/节点，来自《热点日历》）
- 系列进度：____（第几期、预计几期，来自《系列化规划》）
- 重点备货：____（本月想主攻的方向 2–3 个）

【本周排期】（每周日/一更新）
- 周一：____ ｜ ____ 写、____ 审
- 周三：____ ｜ ____
- 周五：____ ｜ ____（若逢节点/热点则此为 P0 档）
```

**库存健康度自查：**

- [ ] 库存（待写 + 已排期）是否 ≥ 未来 2–4 周更新量？
- [ ] 是否有 ≥30% 都是"来不及或没价值"的僵尸题占着位？→ 该清理
**库的"健康"不只是数量，更是"动线畅通"：**

- **数量健康**：库存 ≥ 未来 2–4 周更新量,别饿着也别撑爆。
- **动线健康**：一个题能顺畅走完"待写→写作中→已发布→归档"，不被卡在某一状态。
- **优先级健康**：P0 不泛滥（建议 ≤20%），否则等于没有优先级。

如果发现某个状态长期堵着该题（比如一堆题卡在"待写"超过 4 周）,那不是题不好,往往是**排期或拆分有问题**——要么排期没跟上,要么一题太大没拆成可做的多篇（配《系列化规划》）。这时别硬塞,先把"为什么卡住"问清楚再处理。

## 三、示例

一个"职场新人成长"号，月计划这样落库：

- **月初**：把未来 1 个月排期写进月历——第 2 周四有"跳槽季攻略"节点 → 定为 P0；"求职系列"规划 5 期 → 本周排第 1 期。
- **本周周一挖题**：评论区新冒出"试用期被辞"3 条提问 → 加进库，标 P1（痛点类），备注"可做'职场应急系列'第 1 篇"。
- **周计划定稿**：周一发"求职系列 1：简历"；周五发热点稿（远程办公新人）。周一写完简历稿同日更新库状态为"已发布"，移入归档区。
- **月底清理**：把 2 条 4 个月没动的 P2（如"办公室绿植怎么养"）标为放弃（保留记录）；2 条被热点顶掉的节点题移出本赛季。

**多人协作的库使用示例**：主编 + 两个写手共用一个共享表格。主编负责排期（把题标到具体日期和负责人），写手按"状态→写作中→已发布"认领与更新。月底主编按状态列清理"已发布"和长期"待写"的僵尸题。

**一份健康的周排期长什么样（以周更号为例）：**

| 日期 | 排了什么 | 状态流转 |
|---|---|---|
| 周一 | 《求职系列 1：简历》 | 待写 → 写作中 |
| 周三 | 热点稿《远程办公新人自救》 | 写作中 → 审稿 |
| 周五 | 观点稿《把批评接住》 | 审稿 → 已发布 |
| 周日 | 下周排期落位、补库 3–5 条 | 状态统一盘点 |

整套闭环就是：**挖题 → 装库 → 过筛 → 排期 → 写作 → 发布 → 归档 → 复盘**。周计划管"这周做什么"，月计划管"这个月别漏什么"，两者一起让选题告别"临时拍脑袋"。

## 四、常见错误

- **错误 1：库里只装不排、只排不清。** 选题越堆越多，优先级失效，最后又回归"临时想"。正解：坚持"每周补、每周排、每月清"三动作，库存保持动态不过量。
- **错误 2：没有优先级，全按心情取题。** 结果重要档期（节日/热点窗口）被边缘题占据。正解：每个选题落优先级，排期优先 P0，复查紧随热点的临时变动。
- **错误 3：分类挂一堆标签。** 一个题挂 5 个分类，排序时无所适从。正解：主分类一个 + 来源一个，最多再加一个系列标签。
- **错误 4：主题填得太抽象。** "写一篇关于睡眠的"排期时根本不知道要写什么。正解：主题写"对象 + 动作 + 收益"的一句可执行描述，如"睡够 8 小时还困的 3 个原因"。
- **错误 5：只记来源不记备注。** 过去半年后"这个题当初为什么采"无从考证。正解：备注里写清适合时机、系列关联、角度提示，让"下一个接手的人"也能看明白。

## 五、个性化空间

- **工具选择**：单独笔记软件（Notion/飞书/石墨）、Excel、甚至纸质笔记本都行。判断依据：使用习惯与协作需求——多人账号建议共享表格带权限；单人可轻量起手。
- **列数增减**：基础六列可加"字数预期""配图需求""完成期限"，也可砍掉"备注"为纯极简。判断依据：团队规模与排期精细度——单人极简、团队建议加责任人列。
- **优先级命名**：P0/P1/P2 或"高/中/低"或"必/应/可"都可以。判断依据：团队是否都懂分级，看不懂就换朴素词。
- **库存健康阈值**：文中建议"库存 ≥ 未来 2–4 周更新量"，更新频率高或库存焦虑低者可放宽到 4 周以上。判断依据：你的生产速度与内容变更的稳定性——赛道变化大的行业需要更快的"缓存周转"。
- **清理频率**：月清一次是基准，若你单量小或赛道慢热，可改为两月一清。判断依据：库存增量的速度快慢，增量快就勤清。
- **是否加"负责人/完成期限"列**：单人账号可不加；团队账号强烈建议加，避免选题停在"待写"无人认领。判断依据：是否有协作者以及排期是否需要明确到人。
