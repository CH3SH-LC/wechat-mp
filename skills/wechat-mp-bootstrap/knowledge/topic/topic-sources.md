# 选题来源（topic-sources）

> 定位：常备一张"选题挖掘地图"，让账号随时有 10–30 个可用的候选选题排队，而不是每次发稿前临时拍脑袋。本条目讲六类来源各自怎么挖、每类给具体做法与示例，以及把发现记下来的习惯。
> 调用时机：**常规找选题时必读**。适合每周固定做一次"挖题动作"，或在灵感枯竭、临时要补一篇时快速从六类里挑最容易出的一类。与《选题库管理》《热点日历》《选题判断标准》配合使用——本条目负责"挖出来"，库里负责"装起来"，标准负责"能不能用"。

---

## 一、核心方法

选题来源有六类：**热点事件、读者痛点与提问、系列化延伸、竞品与同类账号、数据反馈、行业节点**。一条好的选题往往不只是某一类，而是"热点 × 自己定位"的结合。下面每类给"怎么挖 + 具体做法 + 示例"。

六类来源一句话速记：

| 来源 | 一句话做法 | 最省力程度 |
|---|---|---|
| 热点事件 | 热门事件 + 你的垂直角度 | 中（要快+角度） |
| 读者痛点提问 | 评论区/私信里反复问的，就是题 | 最高（省力又稳） |
| 系列化延伸 | 历史爆款/深度文，拆开再挖 | 高（有验证） |
| 竞品同类账号 | 看别人验证了什么、缺什么 | 高（横向找空） |
| 数据反馈 | 用历史阅读/转/藏定明天方向 | 中（要数据） |
| 行业节点 | 固定日期，确定性提前备 | 最高（可预期） |

### 1. 热点事件（借势）

热点流量大但窗口短，关键是**快**和**角度准**。热点本身人人都知道，你的价值在于"别人没讲的那个角度"。

- **做法一：热点 + 垂直落点。** 把社会热点转到你账号领域里问一句"这对我读者意味着什么"。
- **做法二：热点 + 反常识。** 热点里通常有一个被默认的看法，你去找那个"其实不是"的点。
- **做法三：热点 + 实用清单。** 把热点带出的议题做成"遇到它该怎么处理"的步骤。

三个做法的差别用同一个"大厂裁员潮"来示范：

| 做法 | 落到简历 | 原文参考标题 |
|---|---|---|
| 垂直落点 | "裁员潮下，打工人先保住这 3 件事" | 讲自救顺序 |
| 反常识 | "裁员名单里，最危险的往往不是新来的" | 推翻常识 |
| 实用清单 | "被裁后 90 天，照着这 5 步走" | 给行动步骤 |

再给更多具象示例：

| 热门事件 | 蹭法 | 落在什么账号 |
|---|---|---|
| 某电影大火 | "看完我也去学了 XX" | 成长励志 |
| 医保新政策出台 | "新政下普通家庭要做三件事" | 保险/民生 |
| 某公司裁员消息 | "被裁后 90 天内最该做的 5 件事" | 职场求职 |
| 某行业设备涨价 | "涨价前，普通家庭该不该囤？" | 数码/家居 |
| 一次全网范围的停电/事件 | "遇到突发停电，家里要备这几样" | 生活/应急 |

> 追热点的关键不是"蹭"，而是"这跟我们读者的关系是什么"。热点只是引子，落脚点必须是自己的垂直内容（详见《热点日历》对突发事件的跟进判断）。

### 2. 读者痛点与提问（最稳）

这是**最可持续、最不会跑偏**的来源，因为问题直接来自你的目标读者。痛点往往是"反复出现、没被满足、读者愿意为答案停留"的题材。

- **做法一：翻后台与评论区。** 每篇文章的红利在于评论区永远有人问"那 X 呢？""如果我 Y 怎么办？"——这些没有被正文回答的问题，就是下一篇选题。
- **做法二：整理咨询与私信。** 读者私信、付费咨询、群内提问里反复出现的高频问题，复制粘贴出来就是选题。
- **做法三：列"初学清单"。** 把领域里"新手最常问的 20 个问题"一次性列出来，每个都是一个独立选题。
- **做法四：反推"读者在找什么"。** 你擅长、读者又正在犯难的领域，主动设问。

各类账号的痛点示例选秀：

| 账号领域 | 读者高频痛点（= 现成选题） |
|---|---|
| 职场 | 试用期被辞怎么办 / 简历空白期怎么写 / 谈薪开口难 |
| 育儿 | 辅食从哪个月开始 / 娃不肯睡怎么调理 / 两岁叛逆期 |
| 房产 | 首付差多少钱能上车 / 看房要看哪几点 / 贷款被拒怎么破 |
| 理财 | 月光族从哪开始存 / 钱放哪更稳 / 被套了要不要割 |
| 饮食健身 | 一个人怎么备一周菜 / 平台期如何突破 / 聚餐如何不掉队 |

> 判断"是不是真痛点"的三问：1这个困惑是不是不只一个人有？2解决它之后读者是不是明显更好？3相关提问是不是隔一段时间又会冒出来？三问都"是"，就是稳定选题。

### 3. 系列化延伸（借已有资产）

把你**已经发过的爆款或高深度的文章**延伸成系列，是性价比最高的来源——读者已经验证过的话题，拆开再挖一遍。

- **做法：爆款二连/三连。** 上一篇讲了"A"，下一篇讲"A 的细节、A 的坑、A 的进阶"。
- **做法：把单篇拆成系列。** 一篇讲"养猫入门"的文章太大，拆成"选猫→接猫→卫生→喂养"各一篇。
- **做法：同一题材换角度重讲。** 不同时期、不同读者阶段，同一题材可以有新的讲法。

延伸的常见四个方向：

| 上一篇文章 | 可延伸成下一篇 |
|---|---|
| 《看完一篇就够的简历攻略》 | 《被 HR 筛掉的简历长什么样》 |
| 《新手怎么开账号》 | 《账号开好之后，第一周该做什么》 |
| 《为什么存不住钱》 | 《月光族的第一笔 5000 元怎么攒》 |
| 《一次完整的买房流程》 | 《看房时最容易忽略的 5 个细节》 |

> 详见《系列化规划》：一个主题如何拆多期、如何命名与排期。这里强调的是"去历史文章里找可延伸的富矿"。

### 4. 竞品与同类账号（横向找灵感）

研究做得好的同类账号，不是抄，而是**看别人已经验证了什么方向、还缺什么**。

- **做法一：拆爆款清单。** 收藏 3–5 个同类头部账号，每周看它们的选题分布，记下"哪类选题它们反复做且数据好"。
- **做法二：找"反向选题"。** 别人的文章讲了"A 的好处"，你写"A 的坑"或"A 适合谁、不适合谁"，错位竞争。
- **做法三：填空白。** 同类账号都没认真做的细分方向，往往是你的机会。

从三个"别人都做了"找你的空位：

| 同行的强项 | 你的错位切入 |
|---|---|
| 都教"怎么做饭" | 写"一个人怎么备一周菜" |
| 都在讲"怎么管教孩子" | 写"妈妈情绪崩了怎么办" |
| 都在发"干货技巧" | 写"技巧背后的底层逻辑" |
| 都在追热门话题 | 写"被忽略但读者天天问的冷门" |

> 边界：参考人家的**选题方向与角度**，不抄**标题和正文**，否则踩版权与原创红线（《转载与开白》《原创声明》里有说明）。

### 5. 数据反馈（用昨天的数据定明天的题）

- **做法一：看高阅读/高分享文章的共同点。** 把你历史文章按阅读量排序，找出 Top 5，总结它们共有的题材、标题类型、切入角度，同类方向多做。
- **做法二：看转发与收藏。** 分享多说明"值得被转发给他人"，收藏多说明"读者想存下来慢慢看"——转发多的更适合做成"观点/共鸣文"，收藏多的更适合做成"工具/清单文"。
- **做法三：看搜一搜。** 后台"搜一搜"关键词里读者每次搜到的你的文章，是你被"需要"的证据，顺着搜到的话题扩展。
- **做法四：留言热度反推。** 争议越大、评论区越热闹的篇目，越说明这个话题有黏性，可跟进续写。

用数据给选题定性的两个例子：

| 数据信号 | 说明什么 | 该做什么样的题 |
|---|---|---|
| 某篇收藏高 | 读者想存下来对照做 | 延伸成"步骤清单/模板"类 |
| 某篇转发高 | 读者想转给特定人群 | 延伸成"观点/共鸣/给某类人看"类 |
| 某关键词常被搜到 | 你这块有"被需要" | 顺话题扩展细分支 |
| 评论区争论激烈 | 有强黏性与讨论欲 | 跟进"对立方观点"续写 |

### 6. 行业节点（可预期的确定性选题）

节日、节气、行业活动、新品窗口、考试季、开学季等**固定日期**都是确定性选题，不需要抢，提前备好即可。这类来源与《热点日历》重合最深——日历化的做法与提前规划时间窗都在那里展开。

按行业给节点示例：

| 账号行业 | 固定节点选题 |
|---|---|
| 教育 | 中考倒计时 / 寒假计划 / 开学第一周 |
| 电商 | 双 11 攻略 / 年货清单 / 618 怎么买 |
| 理财 | 年终总结怎么算 / 新年预算怎么做 / 被套怎么解 |
| 职场 | 金三银四跳槽 / 年终答辩 / 毕业求职季 |
| 饮食 | 节气进补 / 开学便当 / 过年聚餐 |

### 六类来源怎么配着用

不要一次只盯一类。成熟运营的配比思路：

| 账号目标 | 建议配比 |
|---|---|
| 守住基本盘（稳定更新、垂直信任） | 痛点 + 系列 + 节点占大头（约 70%），热点补充 |
| 抢增长、拉新 | 适度提高热点占比，其余保持 |
| 处于定位探索期的冷启动 | 多蹭热点 + 多点开放式提问，快速试市场 |

落到每周，一个相对均衡的排法是：**每周 4 篇里，约 1 篇热点/节点、1 篇系列、2 篇来自痛点或数据**。当然这只是参考，跟着你的数据与阶段调。

## 二、可操作工具

**每周挖题动作（建议 30–60 分钟，固定一个时段）：**

| 步骤 | 干什么 | 时长 |
|---|---|---|
| 1 | 翻一周评论区 + 私信 + 群提问，剔掉已写过的问题 | 10 分钟 |
| 2 | 逛 3–5 个同类账号，记录它们本周的选题与角度 | 10 分钟 |
| 3 | 看自己的后台数据 Top 文章共同点，标出可延伸方向 | 10 分钟 |
| 4 | 对照《热点日历》看未来 2 周有哪些节点 | 5 分钟 |
| 5 | 顺手刷热搜/行业资讯记 3 条可用热点（先不过筛） | 10 分钟 |
| 6 | 把收获填进《选题库》，至少补 3–5 条 | 10 分钟 |

**抓热点的快速清单（当天看到热点时过一遍）：**

- [ ] 这个热点跟我的读者有关吗？（无关就放，蹭不来）
- [ ] 我的垂直领域里有多少人能因此受益/被触动？
- [ ] 有没有"别人没讲"的一个角度？能不能一句话说清？
- [ ] 我一天内能不能写完？（热点超 24 小时价值骤降）
- [ ] 蹭上热点后,这篇内容放在我的定位里理不违和？

**"痛点是否成立"三问卡：**

- [ ] 1这个困惑是不是不只一个人有？
- [ ] 2解决它之后读者是不是明显更好？
- [ ] 3相关提问是不是隔一段时间又会冒出来？
- （三问都选"是"，就是稳定好选题）

## 三、示例

**场景一：一个做"职场新人成长"的账号，周五晚上挖下周的 3 篇文章选题。**

1. **热点类**：本周"远程办公新规"上了热搜 → 角度"远程办公下，新人怎么避免被边缘化"，落点是"主动汇报 + 留痕"两个技能 → 可写（走垂直落点蹭法）。
2. **痛点类**：上周《简历怎么写》评论区 5 个人问"0 经验怎么办" → 单独成题《没经验的第一份简历，这样写也能过筛》→ 直接投喂读者。
3. **数据类**：后台发现《被领导当众批评怎么办》阅读与收藏双高 → 延伸《把批评接住，是职场必修课》做共鸣向 → 借历史爆款后再挖一篇。
4. **节点类**：下月有"金三银四"跳槽季 → 提前备《跳槽前，别忽略这三笔账》→ 确定性选题。

最终本周排 3 篇：热点稿（远程办公）、痛点稿（简历）、数据延伸稿（接批评），时间上热点稿最先发抢时效。剩下来自节点的"跳槽三笔账"进《选题库》排到跳槽季前两周。

**场景二：灵感枯竭、临时要补一篇时。** 作者没思路，就回到"读者提问"类——把上周评论区翻一遍，几乎一定有 1–2 个能被回答的问题。这类最省时间又最贴合读者，是最可靠的"临时救场"来源。

**场景三：六类齐备、系统性储备。** 该账号在每月初一次性把六类来源都扫一遍：热点（本月可能的大事件）、痛点（本月积累的提问）、系列（上月爆款延伸）、竞品（同行近况）、数据（上月 Top 文）、节点（未来 2 个月日历），产出 15 条左右候选全部入《选题库》。这样一整月都有题可选，不会中途枯竭。

（示例只演示"怎么从各来源得出选题"，这些候选是否都保留，要再过《选题判断标准》那一关。）

## 四、常见错误

- **错误 1：只会蹭热点。** 热点流量来得快也去得快，天天蹭会让账号失去垂直感与新读者画像。
  正解：热点只占选题的一部分（建议 ≤1/4），且必须以自己领域落脚；日常以痛点与系列为主。
- **错误 2：把"自己想写"当成"读者想看"。** 选题应以读者的提问、痛点、数据反馈为优先，而不是作者的个人兴趣。
  正解：没把握时，先用`读者三问`（是否多人有/解决后是否更好/会不会反复出现）自测。
- **错误 3：挖到一条就急着写，不存库。** 一次只出 1 篇，剩下灵感随手丢，下次又枯竭。
  正解：每次挖题把候选全填进《选题库》，让库里常年保持 10 条以上。
- **错误 4：直接照搬竞品标题和正文。** 既没有独特性，又踩版权与抄袭红线。
  正解：只借鉴方向与角度，反写/错位，用自己的表达。
- **错误 5：追热点追过头，一天赶出没打磨的"快稿"。** 快不等于糙，热点稿写得太浅反而伤账号信用。
  正解：热点稿也要过《选题判断标准》的最低线，宁可少发也不发次稿。

## 五、个性化空间

- **六类来源的配比**：可以按账号阶段自行调。新号定位模糊时期适合"多蹭热点 + 多点开放式提问"来试验市场；成熟号定位清晰后更适合"痛点 + 系列 + 行业节点"稳住基本盘。
  判断依据：你的定位清晰度与读者画像的稳定度——定位越清晰，越难容忍跑偏选题。
- **挖题频率**：每日更新号可以每天都做轻量挖题（只翻评论 + 刷热搜）；周更号一周集中做一次 30–60 分钟即可。
  判断依据：你的更新频率决定挖题周期，保证"库的总量 ≥ 更新量 × 3"。
- **竞品对象**：选 3–5 个"比你略大一号、同赛道但定位略不同"的账号最有参考价值；选头部超大号参考面太泛，无差异化空间。
  判断依据：你跟谁更"可对标"——能学到方法又挤不出重叠的死角。
- **热点取舍尺度**：偏稳健的账号宁可少蹭也不违和；偏增长期的账号可以适当提高热点占比。
  判断依据：账号当前阶段性目标——保信任还是抢流量。
- **是否把"读者痛点"作为第一优先级**：多数账号如此；但纯兴趣/创作型账号也可能优先写"自己想写、读者也喜欢"的题材。
  判断依据：账号是靠"解决问题"服务读者，还是靠"分享热爱"聚拢同好。
