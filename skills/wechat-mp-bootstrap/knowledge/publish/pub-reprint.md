# 转载与开白（pub-reprint）

> 定位：搞清"转载别人的文章要守什么规矩"和"自己的文章被转载时怎么管理白名单"，让转载不踩版权雷、被转载时能控住使用边界。本条目给转载他人文章的授权规则、署名与开白流程，被转载时的白名单管理，以及转载内容的合规注意。
> 调用时机：**涉及转载或被转载时必读**。想转载别家内容前、或发现自己的文章被别家转载后，先看本条目。与《原创声明与合集》（你的原创被怎样对待的关系）、《多平台同步》（跨平台转载）配套。

---

## 一、核心方法

### 1. 转载他人文章：三步拿授权

**核心原则：先授权，后转载。** 平台对转载有"原创保护"机制，未授权转载可能被判定侵权、被强制下架或投诉。

**第一步：找到原作者并请求授权。**
- 在公众号后台/原文处找作者联系方式(作者名、公众号名、后台入口、文末联系方式)。
- 用规范话术私信/发邮件请求:说明你的账号、为什么要转载、会怎么署名、是否会在账号内注明来源。
- 对方同意后请保留沟通记录(截图/文字),作为授权凭证。

**请求授权的一段参考话术（可改写）：**

> 你好，我是 [账号名] 的运营。我们做 [领域/定位] 的内容，非常喜欢您最近这篇《[文章标题]》，想申请转载到我们的公众号。
> 会按您的要求在文末标明"作者 + 原文公众号 + 阅读原文链接"，全文不篡改。请问是否方便授权？谢谢！

- 对方可能反问"你有多少粉丝""转载来源怎么写",如实回答即可;谈妥的署名、是否可改、转载平台范围都记下来,避免日后扯皮。

**第二步：按对方要求处理署名。**
- 转载通常要求在文末显著位置标注:**原文作者、原公众号名、原文链接"阅读原文"**。
- 若对方要求"署名本人公众号",照做;若要求"带来源转载""加白名单",按其要求。
- 未经同意不得擅自改署名、去掉作者名、把"转载"写成"原创"。

**第三步：按平台流程开白/转载.**
- 若你的两个账号互相关注且来源账号开通了"白名单转载",可在后台走"转载"流程:从来源文章点"转载"使用,平台自动带来源信息。
- 若手动转载(直接复制正文),必须同步做"署名+来源+阅读原文"处理。

### 2. 被转载时的白名单管理

当你的文章被别人转载,你要管理"谁可以转、怎么转":

- **白名单是什么**：你在公众号后台可给特定账号开通转载白名单,授权转载时平台自动带来源与阅读原文,保护你的署名权。
- **建白名单的三种权限（按你意愿授权）**：
  - **可被转载(不修改)**：允许对方转载并自动署名,但不能改动正文。
  - **可被转载(可修改)**：允许对方转载并能修改内容(适合希望对方定制场景)。
  - **可转载(可修改+可用自己的名字)**：最宽松,允许对方改标题、换署名、用于其名义。
- **管理建议**：给长期合作、你信得过的账号开"可转载+自动署名"；给不熟悉的账号限制到"不修改"档。发现未授权转载,可通过后台投诉/举证,或联系对方补授权。

**被转载后的监测与维权四步：**

1. **发现**：定期搜自己的典型标题/摘要,或看后台"转载授权"申请记录,留意是否有人未授权搬运。
2. **定性**：判断对方是"白名单内授权""未授权搬运"还是"轻微引用"。授权内没问题;未授权需处理。
3. **联系**：先礼貌私信对方补授权/署名/删除,多数非恶意账号会配合。
4. **升级**：对方不配合可走平台"投诉/举证",甚至考虑是否采取进一步措施。**全程保留证据（截图/时间）。**

**对方对转载请求的几种常见回复与自己怎么接：**

| 对方回复 | 你怎么接 |
|---|---|
| 同意,但只能"不修改" | 照做,不擅自改正文 |
| 同意,可修改并可改署名 | 按其要求,明确转载范围 |
| 要求付费/合作 | 评估成本,超预算就放弃 |
| 婉拒 | 尊重,不硬搬（改用他文不=抄他文） |
| 要求先加白名单 | 按流程开白名单转载 |

### 3. 转载内容的合规注意（不涉及版权风险）

- **不转载的底线**:未经授权原文照搬、去作者名冒充原创、批量搬运 = 版权风险高,别做。
- **标注来源**:凡非原创,正文/文末一标明来源。转引用/引用片段也要注明出处。
- **避免误解**:转载文章不得标注"原创",蹭原文当自己原创会被投诉并影响账号信用。
- **数量克制**:一个账号内容主体应是原创,转载只作少量补充,避免变成"搬运号"损害定位。

**转载的"边界问题"速解：**

| 疑问 | 一般做法 |
|---|---|
| 能不能改标题？ | 看授权档位：没授权"可修改"就不可改,保持原标题 |
| 能不能删掉一段？ | 同理,只有"可修改"档才可动正文,否则原文照发 |
| 加了表情/排版算改吗？ | 视为微调,但最好在授权时向对方说明会排版美化 |
| 转载能挂广告吗？ | 视双方约定与平台规则,谨慎处理（以平台为准） |

拿不准时,宁可"少动"或先问对方,也别擅自改后埋下被投诉的雷。

## 二、可操作工具

**"转载他人"入库前检查清单：**

- [ ] 已获得作者授权(有沟通记录)?
- [ ] 已按对方要求处理署名(作者/原号/阅读原文)?
- [ ] 文章是否涉及"敏感/争议"内容需谨慎?
- [ ] 转载比例是否克制,不改"原创主、转载次"的结构?

**"被转载"版权说明文案（可放文末）：**

> 本文为 [公众号名] 原创。如需转载,请通过后台联系开通白名单,未经授权不得转载。联系邮箱：[____]

**白名单分档速记：**

| 档位 | 对方能做什么 | 什么时候开 |
|---|---|---|
| 不修改 | 自动署名,不得改正文 | 一般授权给不熟账号 |
| 可修改 | 可改动正文 | 信任合作账号 |
| 可修改+改名义 | 可改标题署名 | 极少,仅在强合作时 |

**"授权管理"记录（建议每次申请都留一行）：**

```
日期 | 对方账号 | 转载哪篇 | 授权档位 | 署名要求 | 沟通记录
____ | ____     | ____     | ____     | ____     | ____
```

把每笔授权记下来，日后有人问"可不可以转"你就知道以前给他开过什么档、他有没有遵守。一旦发现某账号总是不守约定，下次就给更严的档位或不再开。

## 三、示例

场景一（转载他文）：我们账号想做一篇睡眠科普,看到某医学号的文章很好。

- 请求:私信说明账号定位与转载用途,得到对方同意(截图留存)。
- 署名:文末标"原文作者:XX ,原文公众号:XX,阅读原文链接",正文不改动。
- 合规:内容为科普,转载一篇即可,主体仍是原创。

场景二（管理自己的白名单）：有人申请转载我们《谈薪攻略》,走流程:

- 判断:该账号是同类职场号、有长期合作 → 开"可转载(不修改)"档,自动署名来源。
- 次日对方转发了且正确显示来源与阅读原文 → 授权有效。
- 另发现某号未授权搬运 → 通过平台后台投诉/举证处理,或先联系补授权。

场景三（被婉拒的再处理）：想转载某医学号文章,对方婉拒。我们没有硬搬,而是把对方文章当成"参考研究方向",用自己的医学资料与语言原创了一篇《睡眠科普自查》,并在文末注明"部分观点参考 XX 号"作致谢。既没侵权,又保住了内容自主。**被拒绝不代表不能写,而是提醒你别抄。**

**转载合规红黑榜（速记）：**

| 红（别做） | 黑（可做） |
|---|---|
| 未授权全文搬运 | 先拿授权再转 |
| 去作者名冒充原创 | 照实署名 + 来源 + 阅读原文 |
| 给转载内容标"原创" | 明确标"转载/来源" |
| 批量把账号做成"搬运号" | 原创为主,转载少量 |
| 被拒绝仍偷搬 | 尊重拒绝,改原创或另找授权

## 四、常见错误

- **错误 1：不授权就转载。** 直接复制搬运、去掉作者名,踩版权雷,可能被投诉下架。正解:先拿授权、注明来源、必要时走白名单流程。
- **错误 2：转载却不署名或改作者名。** 冒名原创,既失信用又被举报。正解:照原要求署名,文末标"作者+原号+阅读原文"。
- **错误 3：给所有申请都开最宽白名单。** 可修改+可改署名的档,对方可篡改你的内容与你名义。正解:按信任分档,"不修改"是安全默认档。
- **错误 4：从不管理白名单,被转载也放任。** 失去对署名与使用边界控制。正解:定期查看转载申请,按档位授权,发现未授权及时处理。
- **错误 5：账号主体变"搬运号"。** 天天转载他人内容,既稀释原创定位,还可能触发平台对低原创内容的规则。正解:转载只作少量补充,维护"原创为主"。

## 五、个性化空间

- **白名单开档尺度**：合作紧密可放宽到"可修改";对外广而泛之的开"不修改"。判断依据:你对对方账号的信任度与合作深度。
- **是否主动开放转载**：有些账号欢迎白名单转载扩大传播,有些要控渠道、只求订阅。判断依据:你的增长目标——要量还是控独家。
- **要不要写版权声明话术**：在意署名权的账号可在文末固定版权声明;轻运营账号可不加,发现侵权再处理。判断依据:你的被转载频率与维权意愿。
- **转载内容的态度**：有的号几乎不转载他人(强原创),有的定期精选好文补充。判断依据:你的原创产能与账号定位对"内容纯净度"的要求。平台版权与转载规则**以平台最新规则为准**。
