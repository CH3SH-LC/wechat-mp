# 发布流程（pub-workflow）

> 定位：把一篇改好的推文从"正文"走成"已发到读者眼前"的完整操作链路，读清每一环怎么做、别漏哪步，并了解账号类型对发布权限的影响。本条目给完整链路（编辑完稿 → 预览检查 → 草稿保存 → 定时/立即群发 → 发布确认）、每步做法与注意，加发布前最后检查项。
> 调用时机：**首次发布或流程不熟时必读**。每篇正式发布前走一遍本流程防漏；接手新账号、不确定能用哪些发布功能时先看"发布权限说明"。与《最佳时段》（定时间）、《原创声明与合集》（发布前设置）、《多平台同步》（判断要不要多发）配套。

---

## 一、核心方法

标准发布链路五步：

**编辑完稿 → 预览检查 → 草稿保存 → 定时/立即群发 → 发布确认**

### 第一步：编辑完稿

在公众号后台「图文编辑」里把正文、标题、封面、摘要、作者、话题标签都填好。

- 标题：见《标题写法》,信息流一眼看清,20–30 字为宜。
- 摘要：**务必手填**(≤120 字)。不填时系统默认取正文前 54 字,容易截断成不明所以的句子(见 legacy/09 平台事实)。
- 封面：必须为已上传的永久素材(media_id),建议同时配 2.35:1 与 1:1 两种比例,适配不同展示位;封面 ≤10MB,jpg/png/gif/bmp。
- 正文：符合《00 主索引》的间距与排版规范;图片须来自平台已上传素材。

### 第二步：预览检查

- **发送"群发预览"到手机**：在编辑页点"预览",把预览消息发到自己的微信号(手机端查看效果,正文、图片、超链接、排版都过一遍)。
- **重点查**：首屏与封面在手机上的样子、标题与摘要是否正确截断、图片是否加载全、底部是否漏结语、链接是否能点、话题标签是否已挂上。
- **换一部手机或让同事预览一遍**：不同型号屏幕显示有差异,重要稿件多验证一次。

### 第三步：草稿保存

- 确认无误后点击「保存为草稿」,进入公众号的「草稿箱」。
- 草稿是可回退状态,群发前发现错误还有改的机会;正式"发布"就较难撤销(见发布时间点说明于第五步)。
- 多个版本可保留比对;发布前取最终版保存。

### 第四步：定时/立即群发

- **立即群发**：保存草稿后点「群发」,按提示选择群发范围(全部/标签分组),确认后即发。
- **定时群发**：想在未来某个时间点发,选「定时发送」设定具体时间,到点系统自动发(详见《最佳时段》的定时使用)。
- **注意**：群发是重量级动作,不同账号类型权限不同(见下方"发布权限说明")。

### 第五步：发布确认

- 群发不是"点了就完"——平台会提示"发布任务进行中"或要求确认(部分账号类型需管理员确认)。
- 确认发布后,可在「群发记录」查看任务状态,成功后再把文章转进「合集/话题」(见《原创声明与合集》)并做后续数据记录(见《数据复盘》维度)。
- 发布是异步任务,系统会自动查询状态(不断轮询,最长等一阵),等它返回成功再宣布发布完成。

### 每步常见卡点与即时解法

| 步骤 | 常见卡点 | 即时解法 |
|---|---|---|
| 完稿 | 封面没上传/传错规格 | 上传为永久素材,配 2.35:1 与 1:1 |
| 完稿 | 摘要忘了手填 | 回到编辑页补填 ≤120 字 |
| 预览 | 手机没收到预览 | 核对收件微信是否正确、是否发送预览 |
| 草稿 | 点错版本、多版混乱 | 先存"最终版"标记,发错删稿重存 |
| 群发 | 按钮灰着不能点 | 核对账号类型与认证等级,不硬点 |
| 确认 | 长时间"进行中" | 等系统查询,勿重复提交导致重复发布 |

发布前若遇接口/平台报错，可对照 legacy/09 错误码速查（如"未授权""需管理员确认"等常见码），判断是账号权限还是操作问题——**均以平台实际提示为准**。

### 发布权限说明（参考平台事实,以最新规则为准）

不同账号类型能用的发布能力不一样,发布前先确认你手上账号的类型能做什么(来源见 legacy/09):

| 能力 | 订阅号 | 服务号 | 认证账号 |
|---|---|---|---|
| 保存草稿 / 入库管理 | 可用 | 可用 | 可用 |
| 群发/发布 | 部分受限 | 部分受限 | 视认证与配置 |
| 定时发布/正式公开推送 | 视认证 | 视认证 | 认证后更完整（部分仍需管理员确认） |
| 接第三方接口自动化发布 | 需开发者模式 + 凭据 | 需开发者模式 + 凭据 | 需开发者模式 + 凭据 |

> 请以微信公众平台对你账号显示的**实际可用按钮**为准——按钮灰没灰、功能栏里有没有,直接说明你账号能不能做。若遇接口相关报错(如"未授权""需管理员确认"),见 legacy/09 错误码速查。

### 发布前最后检查项（必过清单）

- [ ] 标题:20–30 字、无夸张违禁词、与正文一致(见《标题写法》《标题党红线》)
- [ ] 摘要:已手填、≤120 字、与标题衔接不重复
- [ ] 封面:已上传、比例 2.35:1 与 1:1 双配、文件合规(≤10MB)
- [ ] 正文:排版间距合规、图片来自平台素材、无错别字
- [ ] 底部:结语/关注引导/合集归集已加
- [ ] 话题标签/合集已挂上(见《原创声明与合集》)
- [ ] 手机预览已过,首屏/图片/链接没问题
- [ ] 账号类型允许"群发/发布"(以平台实际按钮为准)
- [ ] 定时时间已核对(选定时时),避免发在错误日期

## 二、可操作工具

**发布流程步骤表（可贴墙/放后台旁）：**

| 步骤 | 动作 | 时长建议 | 卡点检查 |
|---|---|---|---|
| 1 完稿 | 填标题/摘要/封面/正文/作者/话题 | — | 摘要手填,封面双比例 |
| 2 预览 | 发手机预览 + 换机复核 | 5–10 分钟 | 首屏/图片/链接/截断 |
| 3 存草稿 | 保存为草稿 | 1 分钟 | 确认最终版本 |
| 4 群发 | 立即/定时 + 选范围 | 2 分钟 | 定时时间、群发范围 |
| 5 确认 | 查看发布任务+确认 | 按平台提示 | 账号是否需管理员确认 |

**发布前检查清单**（见上节,可复制成单页）——发布前逐项打勾。

**"首次发布"新手对照单（给第一次接触后台的人）：**

| 顺序 | 你要找的入口 | 做什么 |
|---|---|---|
| 1 | 后台"内容管理/图文" | 新建图文 |
| 2 | 正文编辑区 | 粘贴排版好的正文 |
| 3 | 标题栏 | 填标题（20–30 字） |
| 4 | 摘要栏 | 手填 ≤120 字摘要 |
| 5 | 封面上传 | 上传永久素材并选双比例 |
| 6 | 话题/合集 | 挂话题、入合集 |
| 7 | 保存草稿 | 存进"草稿箱" |
| 8 | 群发预览 | 发到手机验一遍 |
| 9 | 群发/定时 | 选"立即"或"定时" |
| 10 | 发布确认 | 等状态变"发布成功" |

**发布≠结束的后续三件事**：1把系列文加入合集归集（见《原创声明与合集》）；2记录发布数据供复盘（见《数据复盘》维度）；3若需多发平台,按《多平台同步》适配再发。**以平台实际界面与最新规则为准**。

## 三、示例

场景:职场号编辑完成一篇《求职突围3谈薪篇》,按流程发布。

- 完稿:标题《谈薪时,这三句话千万别先说》、摘要手填"跳槽谈薪的三个关键句,照着避开大坑"、上传封面(2.35:1 主图 + 1:1 小图)、正文填好、挂"求职""谈薪"话题。
- 预览:点"群发预览"发到手机,发现首屏一张配图加载慢 → 换成压缩过的图,再发一次预览确认。
- 存草稿:确认无误保存为草稿。
- 定时:账号是认证订阅号,支持定时,设周四 18:30(见《最佳时段》晚间档),范围选"全部门窗用户"。
- 发布确认:到点系统自动发出,后台见"发布成功",再把文章加进"求职系列"合集,更新《数据复盘》记录。

## 四、常见错误

- **错误 1：忘了手填摘要。** 不填默认取正文前 54 字,摘要语无伦次、丢失钩子。正解:每次必手填 ≤120 字的摘要,与标题衔接。
- **错误 2：不预览就发。** 手机端才发现排版错位、图片裂、链接失效,为时已晚。正解:先发手机预览,重要稿换机再验一遍。
- **错误 3：没确认账号发布权限就乱点。** 订阅号/服务号/认证号能力不同,点了发现按钮是灰的。正解:发布前确认账号类型与该按钮是否可用(以平台实际为准)。
- **错误 4：点"发布"当作点"定时"。** 想定时却误选立即,瞬间全量推送。正解:定时与立即是不同选项,提交前再核对一遍时间与范围。
- **错误 5：发布后不归集、不记录。** 系列文散落,无法回看,复盘无数据。正解:发布成功即加进合集,并记录到《数据复盘》,形成闭环。

## 五、个性化空间

- **预览遍数**：普通文章预览一遍即可,高重要度(品牌/首次/大型活动)文章可多换设备预览两遍。判断依据:稿件的重大程度与出错成本。
- **是否用定时**：内容风格稳定的账号适合"提前定时铺排";爱在最后一刻改稿的账号建议"现改现发"减少定时改稿。判断依据:你的工作习惯与团队审核节奏。
- **群发范围**：首次或谨慎账号可先用"标签分组"小范围试发,稳定后再全量。判断依据:对内容把握度与拉粉/稳粉的目标。
- **是否接自动化接口**：量大、流程固定的账号可考虑用平台接口批量发布(需开发者模式 + 凭据);小号手动操作更省心。判断依据:发布频率与是否具备配置条件。接口相关事项**以平台最新规则为准**。
