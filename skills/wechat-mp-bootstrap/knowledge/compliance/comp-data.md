# comp-data · 数据引用与来源标注

> 定位：解决"推文里引用统计数据时怎么保证可信、怎么标来源、怎么避免曲解"。数据引用出问题，轻则被读者、同行打脸，重则被认定虚假宣传或洗稿侵权。本条目给出数据可信度判断、必须标注来源的场景、标注格式与避免曲解的方法。
> 调用时机：**正文引用了任何统计数字、报告、榜单、数据分析结论、他人调研时**（百分比、人数、金额、年份趋势、排名等）。

## 一、核心规则

### 1.1 引用数据的可信度判断三维度
判断一个数字能不能直接引用，先问三件事，三者都说清楚才引用：

**1. 来源机构是谁**
- 优先国家级权威机构：国家统计局、央行、教育部、国家卫健委、市场监管总局、国家税务总局等；
- 以及正规大学/科研机构、学术期刊、头部咨询公司与研究机构的公开报告；
- 对**自媒体、小众网站、来路不明的"XX 网统计"** 要打问号，不能直接当依据；
- 来源机构的行业背书也很重要——医疗数据要以医疗权威机构为准，而不是某家卖保健品的公司；
- 能提供检索链接/报告全文的优先引用，只有一个孤零零的"XX 说了"没有出处文件的要警惕。

**2. 样本量与口径**
- 样本太小、只覆盖某一人群/某一地区/某一时段的数据，不能推广成"全行业/全国"的结论；
- 写之前搞清楚"这个数统计的是谁、用的什么口径"——是营收还是利润，是注册人数还是活跃人数，是整年数据还是某季度数据；
- 口径不对外公开时，宁可少写，也不要自行脑补。

**3. 时效**
- 数据有年份、期号才有意义；过期 2-3 年的"最新数据"会误导读者；
- 引用时写清统计年月，不把旧数据当当前事实；
- 找数据尽量找贴近发布时的最新版本；找不到最新数字就明说"最新公开数据为 XX 年"。

### 1.2 必须标注来源的场景
出现下列任一情况，就必须把来源标出来：

- 引用任何**具体数字**（百分比、金额、人数、增长率、排名）；
- 引用**研究报告结论、榜单、调研发现、专家观点、政策条文**；
- 使用了**别人的图表、截图、报告页**；
- 写了"数据显示""研究表明""80% 的人认为"这类带统计性的表述。

> 反过来说：**只要没有出处，就别写具体数字**。没有依据的"XX% 的人都觉得"是违规也误导读者。

### 1.3 标注格式（来源 + 时间）
标准格式是：**机构名 + 报告/文件名称 + 年份/期号**。示例：
- （据国家统计局《2023 年国民经济和社会发展统计公报》，2024）
- （数据来源：XX 咨询《2024 中国白领消费报告》，2024）
- （来源：教育部官网 2024 年政策问答）
在正文引用处就地用小括号/小字标注，文末可放完整出处列表（与「免责声明与风险提示写法」条目的"就地溯源 + 文末完整列表"配套），方便读者核验。

### 1.4 不可编造数据
- **绝对禁止**凭空捏造数字、报告、机构名、专家姓名；
- 自己记不清出处的一律不写具体数字，改写成"据公开信息整理"并给出可信来源指向；
- 没有来源支撑的"XX% 的人都觉得"**不能写**。

### 1.5 什么算"曲解"：判断标准
一句话引用先问四个"是不是"：
- 是不是**只取了对我有利的数字**，删掉了限定条件？（如报告写"仅华东受访者中 60%"，你却写成"全国 60%"）
- 是不是**年代、地区、人群口径被偷换**了？
- 是不是把"相关"说成了"因果"、把"调查局限"说成"普遍事实"？
- 是不是把抽样百分比**放大了绝对量级**（如把"60% 受访者"说成"全国八成人"）？
只要四者中有一个"是"，就是曲解，发布前要改回来。

> **一句话底线**：宁可把数据写淡、写保守，也不要为了"看起来专业"去夸大或省略边界——数据的价值在于可信，可查才可引。

## 二、对照表/清单

### 2.1 数据可信度分级速查
| 数据来源 | 可信度 | 使用建议 |
|---|---|---|
| 国家统计局/央行/教育部/卫健委等官方 | 高 | 可直接引用，标全来源 |
| 知名高校、学术期刊、正规学术机构 | 高 | 可直接引用 |
| 头部咨询/研究机构公开报告 | 中高 | 引用时注明报告名与年份 |
| 正规行业协会、行业白皮书 | 中 | 标注该机构与统计口径 |
| 主流媒体证实过的公开数据 | 中 | 转述时给原始来源 |
| 自媒体、小众网站、直播口播 | 低 | 不作为"数据依据"，只能当线索去核实 |
| 凭空数字/无法溯源 | 极低 | 一律不用，杜绝编造 |

### 2.2 必须标注来源的场景清单
- [ ] 出现具体数字（%、人数、金额、年份趋势、排名）
- [ ] 引用了报告、榜单、调研、专家观点、政策条文
- [ ] 使用了他人图表、截图、报告页
- [ ] 写了"数据显示、研究表明、XX% 的人认为"
满足任一，即必须标注来源。

### 2.3 "规范引用" vs "踩线引用"对照
把常见的现象摆在一起，一眼分得清该这么做：

| 场景 | 踩线做法 | 规范做法 |
|---|---|---|
| 引用某报告数据 | 只写"报告显示 70%…"不给出处 | "据 XX 机构《XX报告》2024，70%…（见文末出处）" |
| 引用一个百分比 | "八成人都…"无样本说明 | "某调查中 80% 的受访者…（样本为 XX 地区 XX 人）" |
| 引用旧报告 | 不提年份，读者当最新 | "据 XX 2021 年报告（最新公开数据）" |
| 引用行业数据 | 把一家公司营收当全行业 | "该公司营收 XX（据其年报），行业总规模见 XX 统计" |
| 引用图表 | 直接贴图不标来源 | "图表来源：XX 报告 XX 页" |

## 三、合规做法（怎么引、怎么标）

1. **先证后引**：引用一个数字前先确认四要素——谁统计的？多少样本？什么口径？什么时间？四者都说清楚再写进正文，写不齐就要么补齐要么不写。
2. **就地标注**：数字出现处随手加"（来源：机构《报告》年份）"，不让读者到处猜出处；同一来源多次引用，第一次标全，后面写"同上/同前"即可。
3. **文末列完整出处**：报告、文章引用多的，文末按编号列"某机构《某报告》某年，检索方式/链接"，方便读者核验与账号免责。
4. **转述 + 自己的话**：引用结论时用自己的话转述观点并注明出处，避免整段照抄（也与「版权风险」条目呼应，防洗稿认定）。
5. **旧数据注明"截至某年"**：写"截至 2023 年第一季度，XX"而不是假装是 2025 年最新；找不到更新数字就明说"最新公开数据为 XX 年"。
6. **不确定就降级表述**：只记得大概、拿不准精确数字时，写"据公开资料，规模在 XX 量级""近年呈上升趋势，具体以官方最新数据为准"，不硬给一个没头没尾的精确数。

### 3.1 规范呈现示例（好的写法 vs 踩线的写法）
给两段对照，一眼看懂"带来源 + 忠口径"长什么样：

**踩线写法（反例）：**
"最新数据显示，90% 的年轻人都存在睡眠问题，熬夜已成为这一代人的常态。"

**规范写法（正例）：**
"据《中国睡眠研究报告（2023）》（中国睡眠研究会），2022 年某抽样调查中受访成年人普遍存在入睡偏晚的情况，我把完整口径列在文末——需要说明的是，这是抽样调查而非全部人群，数值仅供参考。"

对比要点：
- 踩线版：无来源、无样本、无口径、无时间，"90%"成了无法核验的口号；
- 规范版：机构 + 报告名 + 年份 + "抽样而非全量"的边界说明 + 文末完整出处，读者能自己核验。

### 3.2 引用数据的四步落地动作
1. **查证**：在权威来源官网或报告原文找到原始数字与口径，别用二手的转述数字；
2. **核对**：确认这个数不是被媒体/自媒体夸大过的二次传播（找到原始报告最好）；
3. **标注**：正文就地写"（来源：机构《报告》年份）"，文末给完整出处；
4. **边界**：用一句话交代样本范围与统计时间，别让读者误以为覆盖全国/全行业。

## 四、常见错误（反例 + 正解）

1. **编造数据**——反例："调查显示 90% 的年轻人都熬夜到凌晨两点"（无任何出处）。正解：删掉具体数字，改写"熬夜在年轻人中很常见（据 XX 研究，详见文末来源；或无把握就先写'据公开资料'）"。**数字必须有出处。**
2. **引用不分口径**——反例：把"某集团 2023 年营收"说成"整个行业规模"。正解：写清"某集团营收 XX（据该集团年报），不代表全行业"，再列行业权威总量数据。
3. **旧数据当新**——反例：引用 2021 年报告却不标年份，读者当最新数据。正解：改成"据 XX 2021 年报告，截至 2021 年……"，并尽量找更新数据或注明"最新公开为 2021 年"。
4. **不标来源白用报告**——反例：整段引用某咨询报告结论却不出处。正解：就地标"来源：XX 咨询《XX报告》2024"，文末给完整链接，既避免曲解也防侵权质疑。
5. **断章取义/夸大换算**——反例：报告写"60% 受访者曾因失眠就医"，改写"全国八成人失眠"。正解：忠于原口径——"该调查中 60% 的受访者曾因失眠就医（来源 XX，样本为 XX 地区 XX 人）"，不扩大适用范围。

## 五、自查要点（发布前勾选）

- [ ] 每个具体数字都有出处（机构 + 报告名 + 年份/期号）？
- [ ] 出处机构是否可信、统计口径是否与我的说法一致、时效是否够新？
- [ ] 引用的图表、截图是否标注了原报告来源？
- [ ] 有没有凭空编造或"XX% 的人认为"这类无出处数字？
- [ ] 数据改写是否忠于原意、没有断章取义、没有夸大换算？
- [ ] 无法给出精确出处的数据，是否已降级为"据公开资料/具体以官方为准"？
- [ ] 涉及健康/投资等敏感行业的数据，是否就地补了风险提示（见「免责声明与风险提示」）？
- [ ] 文末完整出处列表是否齐全、读者能否据此找到报告原文？
- [ ] 是否保留了引用的来源链接/截图（留证备查，也方便同类文章复用）？
- [ ] 数据表述是否为"忠于原意"，没有删限定条件、没放大口径、没张冠李戴？

### 5.1 建立账号"权威来源清单"（长期投入）
数据靠谱的第一步是有一份可信来源池，运营者可以逐步沉淀：
- 列一份"常用权威机构清单"：国家统计局、央行、教育部、卫健委、学术期刊、头部咨询机构官网等；
- 定期关注这些机构的新报告，标题或摘要记下来备用；
- 建立"好用报告库"：按主题（消费、教育、健康、就业）分门别类放报告名与检索链接；
- 之后写文需要数据时，先在清单里找，找不到再去搜——既省时又安全。

## 六、注意

- **法规与平台规则会更新**：广告法禁止虚假宣传，统计数据的引用也受此约束；平台对无依据的绝对数据与编造数据有专项处置。**实际以最新法规与平台最新规则为准**；涉及医疗、金融等行业的数据，还要叠加「特殊行业红线」条目的合规要求。
- **个性化空间**：可按账号定位微调——资讯、科普类账号对来源与时效要求最高（建议逐步建立一份"权威来源清单"）；健康、投资类内容引用数据要更保守并配风险提示；生活、情感类账号引用数据较少，但**只要用了数字就必须标注**，不因内容轻就随手引。
- 来源标注条的具体排版与位置见「免责声明与风险提示写法」及 module 维度下的 module-disclaimer 条目；图片版权确认见「版权风险」条目；违规后果见「违规后果与申诉」条目。
