# comp-industry · 特殊行业红线：医疗/金融/教育/食品/化妆品/保健品

> 定位：六类强监管行业（医疗健康、金融理财、教育培训、食品、化妆品、保健品）各自的红线。这类内容触及读者健康与真金白银，平台审查最严，写错一条可能整篇删除、封号甚至吃执法罚单。每个行业给出：禁止事项 ＋ 合规表达方式 ＋ 典型违规示例与改写。
> 调用时机：**正文涉及上述任一行业的产品、服务、功效、政策、建议时，写之前读一遍**；不确定是否涉及也建议扫一眼。

## 一、核心规则（六行业逐条红线）

> **通用总原则（六行业全部适用）**：越影响读者健康或金钱的宣称，举证的难度就越高。**可验证的事实（国家批准、注册号、专业资质）才能写；效果类、收益类、升学类承诺一律不写。** 广告法绝对化用语的判定见「广告法违禁词」条目，本条目专注"行业专属"红线。

### 1.1 医疗与健康：疗效承诺是死线
医疗健康是监管最严、处罚最重的领域之一，因为直接关系生命健康，平台对"神医""偏方""治百病"零容忍。

**禁止事项：**
- 宣称能"治疗、治愈、根治"某种疾病，或"包治百病""药到病除""根治癌症/糖尿病/高血压"；
- 使用医药疗效用语（如"消炎""止痛""抗病毒""降血压""治感冒"）来描述普通食品或保健品；
- "神医"式内容：虚构"XX 老中医""祖传秘方""XX 专家坐诊"为特定产品背书，制造虚假权威；
- 以"偏方""祖传方""宫廷秘方"诱导患者放弃正规治疗、自行用药；
- 发布未获批准、无医疗资质的"特效药""进口神药""保健品能替代药品"。

**合规表达方式：**
只做**科普与提示**，可以写：
- 疾病预防知识、常见误区辨析、就医建议、生活习惯科普；
- "该去什么科室就诊""体检该查什么项目"这类就医指引（注意不给具体诊疗方案替医生做主）；
- 涉及产品只讲"无明显证据表明其能治疗，请咨询医生"，绝不给产品开"疗效药方"。

**典型违规 vs 改写：**
- 违规："这款茶一星期治愈我的糖尿病！" → 改写："我查资料整理了一些糖尿病人的日常注意点（数据参考 XX 医院科普号），具体用药请务必遵医嘱。"
- 违规："百年祖传秘方，亲测根治胃病" → 改写（不写病症治疗功效）："家人多年的养胃日常护理经验分享，仅供交流，不构成医疗建议，不舒服请就医。"

### 1.2 金融理财：收益承诺与保本宣传是死线
金融涉读者真金白银，监管与平台对"保证收益""保本"的宣传风险极高，误导读者的代价很大。

**禁止事项：**
- 承诺收益："保证年化 X%""稳赚不赔""躺赚""只涨不跌""闭眼赚"；
- 保本宣传："零风险""保本保息""银行同款保底""稳阵"；
- 诱导不理性投资："不投后悔""错过再等一年""现在不上车就亏了"；
- 宣传违规产品：无牌照理财、非法集资形式、传销式"拉人头"推荐。

**合规表达方式：**
只做**投资者教育**，可以写：
- 理财常识、风险类型介绍（R1-R5 风险等级的读法）、看懂产品说明书的步骤；
- 如何识别非法集资、投资骗局的技巧；
- 凡提及收益必强调"过往收益不代表未来"，提示"市场有风险，入市需谨慎""理财非存款，产品有风险"。

**典型违规 vs 改写：**
- 违规："这款基金稳赚，年化保底 8%" → 改写："本期内容教你如何看懂一只基金的业绩基准与风险等级（理财非保本，过往收益不代表未来）。"
- 违规："银行理财零风险，放心买" → 改写："2022 年起资管新规后，银行理财产品已不再保本保息，选购时先看产品标注的风险等级 R1-R5 再做决定。"

### 1.3 教育培训：升学与"保过"承诺是死线
教育培训关乎家长的钱与学生的前途，平台对"包过、保过、逆袭名校"类宣传查处很严。

**禁止事项：**
- 升学承诺："保证考上 985""签约保过""包过不退费""达到录取线才算过"；
- 任何形式的"包过"变体："签约不过退费""协议班包过";
- 虚假"名师"头衔："北大清华名师""高考命题组出题人""状元导师"，若无真实、可查的资质证明；
- 贩卖焦虑并以"一步到位、逆袭"诱导高额付费。

**合规表达方式：**
可以写：
- 学习方法分享、知识点讲解、备考心态调整、志愿填报思路的科普；
- 机构自身可查证的资质与规模："教学团队毕业于 XX 院校、平均教龄 X 年""历年开班规模 X 期、在读学员 X 名"；
- 绝不做任何"多少人考上""保送""保过"的承诺性表述。

**典型违规 vs 改写：**
- 违规："名师带你 3 个月逆袭 985" → 改写："分享一套我自己用过的备考时间管理方法（适合高二、高三同学参考），学习效果因人而异。"
- 违规："保过班，不过全额退费" → 改写："开班信息：XX 课程，周期 X 周，含 X 次阶段测评；效果请结合自身情况判断，报名前可先试听体验。"

### 1.4 食品：功效宣传需谨慎标识
食品宣传的坑在于"食物不能治病"，把食疗夸张成疗效是常见违规。

**禁止事项：**
- 把普通食品写成有治疗功效（"能降三高""补脑益智""抗癌""减肥神药"）——食物不能宣称治疗作用；
- **保健食品**未标注国家要求的警示语"保健食品不是药物，不能代替药物治疗疾病"；
- 用医疗术语形容普通食品（"消炎""抗过敏""降血脂"）；
- 虚构"纯天然无任何副作用"（纯天然不等于安全，且这种"无副作用"表述本身夸大）。

**合规表达方式：**
可以写：
- 营养成分与普通食用价值（"富含膳食纤维""蛋白质含量高"需有配料表或检测依据）；
- 涉及保健食品必须有"蓝帽子"标识与批准文号，且带警示语；
- **一律不写"治病功效"**；食疗只能说"作为日常饮食的一部分，有帮助均衡营养"这类有据的话。

**典型违规 vs 改写：**
- 违规："这款燕麦降脂又减肥" → 改写："燕麦是常见的粗粮，含较多膳食纤维（配料表标注每 100 克含 X 克），作为早餐替代精制主食是不错的选择。"
- 违规（保健食品）："吃这个胶囊，睡眠改善，疗程后根治失眠" → 改写："本品为国家批准保健食品（批准文号 XX，包装带蓝帽子标识），**保健食品不是药物、不能代替药物治疗疾病，不用于治疗失眠**；如有失眠请及时就医。"

### 1.5 化妆品：禁用医疗用语与功效夸大
化妆品行业监管近年来趋严，国家实行功效宣称与备案管理，"药妆"在国内本就无此概念。

**禁止事项：**
- 用医疗术语描述化妆品："治疗痘痘""消炎杀菌""抗过敏""促进伤口愈合""抑菌"；
- 功效夸大且无检测依据："三天美白""永久祛斑""彻底去皱""一夜填充"；
- 宣称"医用""药妆"（国内无"药妆"概念，化妆品不得宣称医疗作用）；
- 虚假成分/效果："媲美医美""打针一样的效果"。

**合规表达方式：**
可以写：
- 成分、质地、使用感受、备案/注册信息（化妆品有国妆备字/国妆特字等备案，宣传应匹配备案功效）；
- "美白""防晒"等功效类应有相应检测报告或符合功效宣称规则，措辞用"帮助改善""有一定 XX 效果"等有据表达；
- 明确"具体效果因人而异，敏感肌请先做局部测试"。

**典型违规 vs 改写：**
- 违规："这款面霜三天祛痘消炎" → 改写："成分表含 X（如壬二酸/水杨酸），对油痘肌常见问题有一定帮助，效果因人而异，敏感肌先做局部测试。"
- 违规："药妆，永久去皱" → 改写："备案功效为保湿（备案号可在国家药监局官网查询），坚持使用帮助改善干纹，不具医美效果。"

### 1.6 保健品：治疗疾病用语是死线
保健品与食品红线相近，但**监管更严**，又与医疗宣传高度相关，单列强调。

**禁止事项：**
- 宣传保健品能治疗/治愈疾病（"调理糖尿病""抗肿瘤""增强性功能""治腰酸腿痛"）；
- 漏标或淡化"保健食品不是药物，不能代替药物治疗疾病"警示语；
- 使用"治疗、根治、康复、药效"等词语；
- 冒充药品（把保健品说成能替代降压药、降糖药，诱导停药就医麻烦）。

**合规表达方式：**
- 只讲可在该保健食品批准文号对应的功能声称名单里的内容（如"有助于增强免疫力"是部分批准的功能声称）；
- 讲"用于特定人群补充某些营养素""作为日常保健"；
- 反复强调"不能替代药品、不能治疗疾病"。

**典型违规 vs 改写：**
- 违规："这款保健品治腰酸腿痛，两个月痊愈" → 改写："本品批准功能为'有助于增强免疫力'（文号见包装，可在药监局官网核实），**是保健食品不是药物、不能治疗疾病**；腰酸腿痛请就医检查，不要自行停药。"

## 二、对照表：六行业"禁止 vs 合规"速查

| 行业 | 绝对禁止（说一次即红） | 合规可写（有据才写） | 必须带的提示 |
|---|---|---|---|
| 医疗/健康 | 治疗/治愈/根治/包治百病/偏方治 X | 疾病科普、就医建议、预防知识 | 不能替代医嘱 |
| 金融/理财 | 保证收益/稳赚/保本/零风险/躺赚 | 投资教育、风险类型介绍、说明书读法 | 市场有风险、过往不代表未来 |

## 三、合规做法（写强监管内容的具体方法）

1. **能引用文件就引用**：批准文号、备案号、专利号、官方公告链接——有没有编号/出处，是"事实"和"宣传"的分水岭。写"XX 机构""XX 资质"时，把证书号、文件号放在文末，读者可自行核验。
2. **只描述"是什么、怎么用、有哪些营养或参数"**，不替读者做健康、金钱、升学判断：让读者带着判断去找专业机构（医生、持牌顾问、学校招生办），账号只做信息整理者而不是"裁判"。
3. **提示语固定套路（可整句复用）**：
   - 医疗健康："本文旨在科普，不能替代面对面诊疗，如有不适请及时就医。"
   - 金融理财："市场有风险，入市需谨慎；过往收益不代表未来表现。"
   - 教育培训："学习效果因人而异，请结合自身情况判断。"
   - 保健食品/食品："保健食品不是药物，不能代替药物治疗疾病。"
   - 化妆品："备案功效可在国家药监局官网查询，效果因人而异。"
4. **遇到拿不准的说法一律降级**：把"治疗"换"改善建议"、把"保证收益"换"过往数据"、把"保过"直接删掉。**多读两遍，宁可写淡不要写险。** 写一句之前先问：这句话我能不能当场拿出文件证明？拿不出就改。

## 四、常见错误（反例 + 正解）

1. **把科普写成带货功效**——反例："分享一款对失眠特别有效的茶"。正解："失眠的常见原因科普 + 就医建议"；即使提到产品也只写"无明显证据表明能治疗，请就医"。**科普与功效一定要分开。**
2. **保健食品漏标警示语**——反例：只夸"蓝帽子，增强免疫力，改善睡眠"却漏了"不能代替药物"。正解：凡出现保健食品功效表述处，必带"保健食品不是药物，不能代替药物治疗疾病"警示语。
3. **金融只用收益率不配风险提示**——反例："近一年收益 X%"却不写"不代表未来、有风险"。正解：任何收益数字旁就地标注风险提示，并给出数据口径与来源（见「数据引用与来源标注」条目）。
4. **教育写"保过"与无凭据"名师"**——反例："状元导师亲授"却拿不出导师真实履历。正解：改成可查证的团队资历介绍，且不承诺任何升学结果。
5. **化妆品用"药妆"/医疗词**——反例："药妆，消炎祛痘"。正解：国内没有"药妆"概念，改成成分 + 备案功效；去掉"消炎"等医疗词，功效措辞用"帮助改善""因人而异"。

## 六、注意

- **法规与平台规则会更新**：医疗、金融、教育、食品、化妆品、保健品均有专门监管法规与公众平台专项审查口径，各行业批准/备案机制在持续调整。**实际以最新法规与平台最新规则为准**；发布前可去国家药监局、国家市场监管总局或平台官方规则页核对最新口径。
- **个性化空间**：可按账号行业微调——若号主没有相应资质（不是医生、持牌顾问、机构官方），措辞要比白名单口径**更保守**（多用"据 XX 官方发布""请以官方为准"）；涉及具体产品推广时，把这张"禁止项清单"当发布前的最小检查表逐条划勾。
- 免责声明与风险提示的具体句式见「免责声明与风险提示写法」；绝对化用语见「广告法违禁词」；数据与来源标注见「数据引用与来源标注」；违规后果见「违规后果与申诉」。
