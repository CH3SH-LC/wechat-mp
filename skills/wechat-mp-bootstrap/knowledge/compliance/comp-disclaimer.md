# comp-disclaimer · 免责声明与风险提示写法

> 定位：告诉运营者在哪些内容上必须放免责声明、放哪里、怎么写，并给出一套可直接套用的标准句式。免责声明不是装饰，是强合规内容的必做动作，也是账号保护自己的一道缓冲。
> 调用时机：**医疗、投资、法律、转载内容、用户投稿等场景必用**；生活、情感类内容轻量处理。与 module 维度下的 module-disclaimer（免责/溯源条模块）配套使用——本条目讲"写什么"，模块条目讲"怎么排版"。

## 一、核心规则

### 1.1 免责声明解决什么问题
免责声明把"这是参考、建议、经验，不是结论、承诺"讲清楚，提醒读者正确理解内容，从而：
- **降低被误读为就医、投资、法律建议的风险**，保护读者不被误导；
- **为账号留出免责空间**，减少被投诉、被追责的可能；
- 是强监管行业（医疗、金融、法律）内容的**必做动作**，不是可选装饰。

> 什么时候要格外注意：凡是读者可能照着"照做"的内容——吃、买、投、就医、维权——都要想"如果读者误信出问题了，我怎么交代"。免责声明就是把这句交代提前写清楚。

> 要注意退路：免责声明主要在"建议与观点层面"起保护作用，**兜不了违法违规的绝对化用语和行业承诺**（见「广告法违禁词」「特殊行业红线」条目）——违禁词本身就不能出现。它和"从源头不违规"是两件事，都要做才安全。

### 1.2 适用场景（哪些内容必放）
- **医疗/健康**：涉及疾病科普、用药建议、饮食调理——必放，强调"不能替代医嘱"；
- **投资/金融**：涉及基金、股票、理财、保险——必放，提示"市场有风险、不代表建议"；
- **法律**：法律科普、维权建议——必放，强调"不构成法律意见"；
- **转载内容**：转载他人文章、素材——必放，注明作者与出处、声明转载性质（见「版权风险」）；
- **用户投稿/留言引用**：引用了读者投稿、评论、案例——必放，说明属个人经历、不具普遍性；
- **食品/保健品**：若涉及功效表述，附"保健食品不是药物"等提示（见「特殊行业红线」）。

**何时可以省略/弱化免责：**
- 纯个人随笔、生活琐事、情感分享、读书心得——风险极低，可弱化为一句轻量免责，或不放（但引用了别人数据仍须就地标注）；
- 阅读量低的强合规内容也不可省——**医疗/投资/法律即使粉丝少也要放**，合规不是"火起来才做"；
- 判断标准一句话：**内容越影响读者真金白银或身体健康，提示条越靠前、越醒目。**

### 1.3 免责声明的位置与样式
**位置规则：**
- **文首（开头首屏内）**：医疗、投资、法律等强合规内容，必须在开头第一屏就放提示条——不能让读者读完整篇干货才看到提示，那样提示就失效了；
- **文末/页脚**：通用免责声明收尾，低调不喧宾夺主；
- **就地**：高风险数据或观点处就近加一句提示（如收益处、用药处、升学处），让把提示放在最容易被误读的位置。

**样式规则：**
- 浅底色 + 细边框的小字条最稳妥（微信兼容好）；
- 字号 12-14px、行高 1.6-1.75，不加粗不花哨；
- **清楚、负责任优先，好看其次**——合规条子不必华丽；
- 自媒体/宣传类可用 `> [!WARN]` 等轻度警示色，但以克制为准，别做成刺眼广告；
- 具体尺寸与间距硬规范见 module-disclaimer 条目。

### 1.4 免责声明"管得到"和"管不到"的边界
搞清免责的边界，才不会被"写了免责就万事大吉"的错觉坑到：
- **管得到**：提醒读者信息仅供参考、不构成建议；为"观点/分享层面"留出缓冲；说明转载/投稿性质。
- **管不到**：不能掩盖广告法绝对化用语、不能豁免行业疗效/收益承诺、不能替代版权授权（见「广告法违禁词」「特殊行业红线」「版权风险」）。
**一句话**：免责声明是"降低被误解为建议的风险"，不是"违规的护身符"——它和"根本不违规"是两回事，两者都做才安全。

## 二、对照表/清单

### 2.1 场景 → 免责声明要点
| 场景 | 免责内容要点 | 位置 |
|---|---|---|
| 医疗/健康 | 不能替代医嘱、请就医 | 文首 |
| 投资/金融 | 市场有风险、不构成建议、过往不代表未来 | 文首 + 就地 |
| 法律 | 不构成法律意见、请咨询律师 | 文首 |
| 转载内容 | 注明作者出处、声明转载性质 | 文末/篇头 |
| 用户投稿/案例 | 属个人经历、不具普遍性、效果因人而异 | 就地或文末 |
| 食品/保健品 | 保健食品不是药物、不用于治病 | 文首/就地 |

### 2.2 是否需要免责声明的判断清单
- [ ] 涉及医疗、投资、法律等强合规领域？（是 → 必放文首）
- [ ] 引用了他人数据、观点、案例？（是 → 就地来源标注 + 文末免责）
- [ ] 属于转载或用户投稿？（是 → 注明作者出处 + 免责）
- [ ] 涉及具体效果、收益、升学、功效？（是 → 强调"因人而异/不保证"）
- [ ] 读者可能照着"照做"的吃/买/投/用药/维权内容？（是 → 哪怕内容轻也要有风险提示）

## 三、合规做法（标准句式与写法）

### 3.1 标准句式库（"本文仅为…不构成…"类，5-8 句可直接套用）
1. **通用免责**："本文仅为信息分享与个人观点整理，不构成任何专业建议或承诺。"
2. **医疗**："本文为健康科普，仅供信息参考，不构成医疗建议；如有身体不适，请及时咨询专业医生并就医。"
3. **投资**："本文内容仅供参考，不构成任何投资建议。市场有风险，入市需谨慎，过往收益不代表未来表现。"
4. **法律**："本文为法律知识科普，不构成法律意见；涉及具体纠纷，请咨询执业律师。"
5. **转载**："本篇为〔转载/整理〕内容，原文作者为〔作者名〕，来源〔公众号/平台〕；侵删请联系后台。"
6. **用户投稿/案例**："本文引用的案例、投稿属个人经历分享，不具普遍性，效果因人而异，仅供参考。"
7. **教育/学习**："文中所涉方法与经验仅供参考，学习效果因人而异，请结合自身情况判断。"
8. **食品/保健品**："保健食品不是药物，不能代替药物治疗疾病。文中信息不作为购买或疗效承诺。"

> **填空思路**：把上面句子里的"〔…〕"和领域词换成你的账号实际场景；不确定选哪句时，按"通用 ≤ 具体"取更具体的那句——"不能替代面对面诊疗"比"仅供参考"更有保护力。

### 3.2 "内容仅供参考，以官方为准"类提示
这类句式用来交代"信息会变化、以权威口径为准"，特别适合资讯、政策、数据类内容：
- "以上信息整理自公开资料，具体政策、规则以官方最新发布为准。"
- "数据来源已标注，请以原始报告与官方发布为准。"
- "各平台规则可能调整，请以各平台最新官方说明为准。"
- "涉及具体产品、服务的细节，请以官方客服或官网发布为准。"

> 上两类句式的区别：3.1 是第一人称的"自我声明"（我提供的是参考），3.2 是"信息可能变、请以官方最新为准"（正本清源）。强合规内容建议各自取 1 句搭配使用。

### 3.3 写法要点
- **措辞要具体**："不能替代面对面诊疗"比一句"仅供参考"更有保护力，也更显负责；
- **语气平稳负责**：不吓读者、也不打包票；既不轻描淡写也不制造恐慌；
- **免责声明自身不能违规**：句子里绝不出现"保证、根治、稳赚、最"等词；
- **一次放够但别堆砌**：开头 1 条风险条 + 文末 1 条免责，特殊情况关键段落再就地加 1 条，总数控制在 3-4 处以内（符合 module-disclaimer 的密度规则），别让一整屏免责条文把正文挤没了。

### 3.4 组合应用示例（三段实战示范）
把"开头风险条 + 就地溯源 + 文末免责"拼起来，就是一篇强合规内容的完整合规层：

**示例 A（投资类）**
- 开头风险条："本文为理财知识科普，仅供参考，不构成任何投资建议。市场有风险，入市需谨慎，过往收益不代表未来表现。"
- 就地溯源："（数据来源：XX 报告 2024，收益率口径见文末）"
- 文末免责："本账号观点仅代表个人，不构成投资建议；据此操作风险自担，请以专业机构与官方公告为准。"

**示例 B（健康类）**
- 开头风险条："本文为健康科普，仅供信息参考，不构成医疗建议；如有身体不适，请及时就医。"
- 就地溯源："（据 XX 医院科普号，2024）"
- 文末免责："内容整理自公开资料，具体诊疗请遵医嘱，请看诊医生判断。"

**示例 C（转载类）**
- 篇头注明："本文为转载，原文作者〔作者名〕，来源〔公众号〕，已获授权。"
- 文末免责："转载内容版权归原作者所有，如涉及侵权请联系后台；本文观点仅代表原作者。"

### 3.5 免责声明常见疑问（FAQ）
- **免责声明能完全免责吗？** 不能做到绝对免责，它只是降低"被理解为建议并向你追责"的风险；真正避免违规靠的是不写违禁词、不写承诺（见「广告法违禁词」「特殊行业红线」）。
- **内容不涉及敏感行业，要放吗？** 至少一句「仅供参考」的轻量免责成本低、风险小，建议都放；涉及医疗/投资/法律则必须放，且放文首。
- **免责放文末就够了吗？** 强合规内容不够——必须在开头首屏放风险条，让读者在最易误读的地方就看到；文末免责是收尾，不能替代文首提示。
- **我可以直接抄别人的免责声明吗？** 可以参考句式，但要改成贴合自己账号与内容的具体表达，别照搬（尤其别把别家固定模板的行业/人名套进来，反而显得不负责）。
- **免责放得越多越安全吗？** 不是。整屏免责不增加实际保护，还会吓跑读者、稀释重点；强合规内容抓好"文首风险条 + 就地溯源 + 文末免责"三处即可，弱合规一篇一句「仅供参考」就够。
- **免责和来源标注是一回事吗？** 不是。来源标注回答"数据凭什么"，免责回答"内容仅供参考、不构成建议"；强合规内容两者都做（见「数据引用与来源标注」）。

## 四、常见错误（反例 + 正解）

1. **免责声明放太靠后**——反例：理财干货全文讲完，结尾才补"市场有风险"。正解：投资、医疗类必须在开头首屏放提示条，再以文末收尾。
2. **用免责声明包裹违规词**——反例："本产品效果最棒，仅供欣赏，不构成建议"。正解：违禁词本身就不能出现，免责只在"建议/观点"层面起作用，不能给"最、治愈、保本"兜底。
3. **免责声明里自己违规**——反例："绝对安全，请放心（仅供娱乐）"。正解：声明里也禁用"绝对、保证、根治"等违禁词，写明也要合规。
4. **转载不写作者出处**——反例：转了文章只写"图文来自网络"。正解：注明具体作者与来源，必要走授权流程（见「版权风险」的转载 3 步）。
5. **风险条堆砌吓走读者**——反例：开头一整屏都是法律条文式免责。正解：只抓关键风险，用几条简洁清楚的提示，文末再低调收尾，不喧宾夺主。
6. **只放免责不放风险条**——反例：文末写了免责，却漏了文首风险提示。正解：强合规内容两者都要——文首风险条解决"怎么读"，文末免责收尾；只其一不完全。

## 五、自查要点（发布前勾选）

> 逐项照实勾选，别为"看起来有免责"而走形式——措辞是否具体、位置是否靠前，比有没有这句话更重要。

- [ ] 涉及医疗/投资/法律等强合规内容，开头首屏有风险提示条？
- [ ] 引用了他人数据、观点、案例的地方写清了出处的来源标注？
- [ ] 转载、用户投稿内容注明作者出处并声明了转载性质？
- [ ] 文末有免责声明（至少一句"仅供参考/不构成建议"）？
- [ ] 免责声明的措辞是否具体（如"不能替代医嘱"而非空泛"仅供参考"）？
- [ ] 免责声明的用词本身没有"保证、根治、稳赚、最"等违禁词？
- [ ] 提示条总数控制住了（风险条 1-2 条、免责 1 处），没有堆砌一整屏？
- [ ] 免责是否放在最容易被误读的位置（高风险数据就就地加一句）？
- [ ] 强合规内容的声明没有替代"先自查违禁词/行业承诺"这道真正防线？

## 六、注意

- **法规与平台规则会更新**：广告法、平台规范对各行业"应尽提示义务"的要求在调整，不同行业、内容形态触发义务不同。**实际以最新法规与平台最新规则为准**；涉及医疗、金融等强监管行业的，以「特殊行业红线」与官方规则为准。
- **个性化空间**：可按账号领域微调——健康、理财类账号把提示条做成固定开场模板逐步套用；生活、情感类账号弱化为一句轻量免责；有投诉史或曾踩线的账号免责写完整些；常带货的账号在免责里加"本内容为自己体验分享（如含合作会注明）"更能取信读者。
- 排版样式与间距硬规范详见 module 维度下的 module-disclaimer 条目；行业红线见「特殊行业红线」；违禁词见「广告法违禁词」；违规后果见「违规后果与申诉」。
