# comp-copyright · 版权风险：图片/字体/音乐/洗稿/转载

> 定位：解答"我用的图、字体、音乐、文字会不会侵权"——这是公众号最容易被投诉、起诉、封号的三类风险之一（素材版权）。本条目讲清五类素材的侵权边界与规避做法，以及图片版权确认流程的摘要。
> 调用时机：**使用任何非自制素材时**（网络搜图、图库图、字体、音乐、搬运文字、转载他人文章）。自制原创图片可跳过图片部分，但仍需注意字体版权。

## 一、核心规则（五类素材边界）

> **总原则**：别人创作的图、文、字、曲，默认受版权保护，没有授权就不能商用——而公众号推文公开传播，属于**商用场景**。"我注明了出处"不等于不侵权，**署名不能替代授权**。这一条想通了，后面所有细节都好理解。

> **判断一句话是否安全的快速问题**：写"这张图我要放进公众号/封面/海报带货"时，问自己——1 授权是否白纸黑字覆盖了"公开传播 + 商业用途"？2 素材里是否叠加了人物/品牌/商标，需要额外授权？3 我能当场拿出授权截图吗？三个问题只要能明确回答"是/有/能"，才算真的可用。

### 1.1 图片：最常见的雷区
图片是所有公众号侵权里最高发的类型，几乎每个号都至少在"搜图"上下过手。

**网络搜索图**
- 从百度、必应、微信搜索直接下载的图片，**绝大部分有版权所有人**；
- 直接用于商业公众号属侵权，与"是不是免费下载"无关——"能下载"不等于"能商用"；
- 搜索引擎显示"免费""无版权"也只是第三方站点标注，不代表作者授权你商用。

**图库授权类型（认准这些标签再来用）**
- **公有领域（Public Domain）/ CC0**：可商用、可修改、无须署名——最安全；但要在图源确认**真是 CC0**，而不是作者随便发的"免费"图。
- **CC BY**：可商用，但**必须署名**——能用，记得署名。
- **CC BY-SA**：可商用，须署名，且**重新加工后的作品也要以相同方式授权**——再加工需注意。
- **CC BY-NC**：**仅限非商业用途**——公众号推广/带货算商业用途，**不能用**。
- **免费图库（Unsplash / Pexels / Pixabay 等）**：多数允许商用，但带品牌、人物、建筑、商标的图可能叠加商誉权/肖像权/商标权，商用仍要留意；且各家最新授权条款不一，用前看该站说明。
- **付费图库（视觉中国、站酷海洛等）**：买了授权才能商用；注意授权范围——是个人稿还是商用、有效期、可否用于第三方平台发布。
- **"免费下载但没标可商用"的**：**默认不可商用**，切勿侥幸。

**自制图**
- 自己拍、自己画的原创图最安全，也能规避他人素材风险，尽量多用；
- 但自制图里**嵌入的字体、拼接的他人图片、底图**也要各自合规（字体见 1.2，拼接图片回到本节判断）；
- 自制图用于带货时，如果画面里出现了他人的 IP 形象、知名人物、可识别品牌商标，仍要额外确认，不能因为"图是我做的"就全免责。

### 1.2 字体：商用版权正在收紧
字体是近几年维权热点，很多运营者栽在这上面而不自知。

**免费可商用字体清单（推荐，用前到官网确认真实授权）**
- 思源黑体、思源宋体（Adobe 开源）、阿里巴巴普惠体、站酷系列（站酷快乐体、站酷庆科黄油体等）、得意黑、霞鹜文楷、庞门正道（部分版本）等；
- **前提**：都在字体官方声明"可商用"的范围内，且用最新版本。

**版权字体风险**
- 微软雅黑、Windows 自带的部分黑体，以及大量"设计字库字体"（某些企业的字体包）**仅限系统/个人使用，商用需授权**；
- 网上"破解字体包"切勿使用——来源不明的授权情况更危险，且下载盗版本身就有合规问题；
- **判定漏洞**：把版权字体做成图片、导出成 PNG、转换成轮廓，仍可能被字体厂商维权；正文字体、封面字体、图片内嵌字体都要留意。

**规避做法**
- 封面与正文统一用"免费商用字体白名单"里的字体；
- 封面需要"设计感字体"时，用免费商用替代字体，或用原创手写、图形装饰代替他人字库。

### 1.3 音乐/音频
配乐、BGM 往往受著作权、录音者权、表演者权多重保护，是容易被忽略的雷区。

- 后台"音乐库"或平台明确标注"可商用"的音乐素材才安全；
- 网上标注"免费"的音乐需逐一确认授权——**个人使用 free ≠ 商用 free**；
- 规避做法：优先用公众号后台音乐库或各平台的"可用配乐素材库"；用明确标注可商用且有授权页的声音库；**避免直接搬运他人的成品配乐或剪辑音频**。

### 1.4 洗稿：搬运、变着改也是侵权
洗稿是运营者容易"以为安全"但其实很危险的一类。

**洗稿认定**
- 把他人文章**换词、调序、重排**，但不改实质内容、观点与结构，仍属转述其独创表达，可能被认定侵权或抄袭；
- 平台对"近似度高、结构一致"的文章有洗稿识别机制，累计多次会被降低权重甚至处置。

**搬运**
- 整篇复制他人文章发布，即使注出处，未经授权也属侵权（授权转载除外）。

**规避做法**
- **以自己的写作**为原则：引用他人观点、数据、金句时**注明出处 + 用自己的话转述**，并做"来源标注"（见「数据引用与来源标注」条目）；
- 大量直接引用则必须走"转载授权流程"（见 1.5）。

### 1.5 转载：授权流程必须完整
转载他人文章是合规的常见姿势，但流程不完整照样侵权。

**授权流程（3 步，缺一不可）**
1. 取得作者或版权方的**书面同意**——截图聊天记录、授权邮件、白名单开通记录；仅口头同意不可靠，一定要留下可查证据；
2. 声明转载、**注明作者与原始出处**（原文标题 + 原公众号名）；
3. 保留原文版权信息，**不删改原文实质内容**（如需删改，须再获授权）。

**平台生态内转载**
- 开启"转载"权限的文章可走平台白名单转载规则；白名单之外，必须私下向作者取授权并按以上 3 步操作。

### 1.6 图片版权确认流程摘要（详细版见「配图素材」维度的 image/img-copyright 条目，本处仅摘要）
拿到任何一张"非自制图片"之前，按下面 5 步过一遍：
1. **先问来源**：图是不是原创？是，跳过；不是，往下走；
2. **判授权**：看平台/图库明示的授权（CC0/CC BY/商业授权/平台自带库），确认是否覆盖"公众号公开传播"这个商用场景；
3. **查叠加权**：图里有人物、品牌、建筑、商标的，额外确认肖像权、商标权——尤其用于带货推广时；
4. **留证**：记录来源站点、授权链接/截图、下载时间——出事时有据可查；
5. **拿不准就换**：任何一环不确定，直接换免费可商用图库或自制图，别赌。

## 二、对照表/清单

### 2.1 图片授权类型速查
| 授权 | 可否商用 | 是否须署名 | 公众号是否可用 |
|---|---|---|---|
| 公有领域 / CC0 | 可商用 | 不必署名 | 可用且最安全 |
| CC BY | 可商用 | 必署名 | 可用，记得署名 |
| CC BY-SA | 可商用 | 必署名，且衍生需同授权 | 可用，再加工注意 |
| CC BY-NC | 仅非商业 | — | 不可用于推广带货 |
| 免费图库（明示可商用） | 可（看条款） | 看条款 | 可用，注意人物/品牌叠加权 |
| 未标可商用 | 默认不可 | — | 勿用 |
| 付费图库 | 视所购授权 | 视条款 | 可用，须买对商用授权 |

### 2.2 免费可商用字体清单速查
- 思源黑体、思源宋体、阿里巴巴普惠体、站酷快乐体、站酷庆科黄油体、得意黑、霞鹜文楷、庞门正道（部分版本）
- 用前到字体官网确认当前授权条款与"可商用"版本；**不要用破解版或网盘随意打包的字库**。

## 三、合规做法（规避的具体方法）

### 3.1 素材选择优先级（从最安全到最小心）
给运营者一张"能用哪类素材"的优先级排序，遇到选择时不纠结：
1. **自制原创**（自拍、手绘、原创排版图）——最安全，优先用；
2. **公有领域/CC0** 与平台自带可商用素材库——安全度高，直接用；
3. **免费图库明示可商用的**——可用，但要先看授权页、避开人物/品牌叠加权；
4. **CC BY 等需署名素材**——可用，但记得署名、核对衍生授权条款；
5. **付费图库**——可商用，但须买到"商用授权"且按授权范围使用；
6. **网络搜图、未标可商用、破解字体资源**——一律不用，风险最高。
原则：**排序越靠前越优先选**；拿不准时用本文开头那段"判断一句话是否安全的快速问题（三个问题）"再过一遍。

### 3.2 建立"素材台账"的具体做法
一次性把台账做透，后续每篇都用得上:
- 每张图记录：来源站点、授权类型、授权链接/截图、下载日期、用途；
- 每种字体记录：字体名、官网授权页截图、是否为"可商用"版本；
- 每段音乐记录：来源库、授权说明、用途；
- 台账形式不限（表格、云文档、文件夹里的 README），关键是**出事时有据可查**；
- 定稿前抽查台账：凡台账里查不到授权记录的素材，一律换掉再做下一步。

### 3.4 常见版权问题（FAQ，逐条回答高频疑问）

**Q1：我在文章里注明了图片来自 XX 图库，就安全了吗？**
不一定。标注来源+署名解决的是"是否尊重作者"，但**能否商用取决于图库/作者的授权条款**——很多"免费下载"的图库并不授权商用转载。正确做法是看授权页，不是看"是否标了出处"。

**Q2：我用的是平台自带的图片库，还会侵权吗？**
平台自带"可商用图片库"一般已经解决著作权，相对安全；但仍要留意图片里的人物肖像、品牌商标（尤其带货场景），这些是图片库授权未必覆盖的。

**Q3：我自己画了个封面，但字体是别人字库，安全吗？**
自画只解决了图形版权，**内嵌字体版权仍须单独确认**。封面如果用了版权字体，也一样可能被字体厂商维权。所以要确认封面用字在"免费可商用白名单"里。

**Q4：从网上下载的音乐能当 BGM 吗？**
绝大多数不能直接商用。优先用平台授权音乐库或明确"可商用"且有授权页的声音库；"免费下载"不等于"免费商用"。

**Q5：我一篇文改了好几个词，算是原创了吗？**
不算。形式上的换词、调序，如果结构、论点、独创表达都照搬，仍可能被认定洗稿。真正安全的是自己组织结构、用自己的话表达，再对引用部分做来源标注。

### 3.3 日常写作中的规避动作汇总
把上面几条整理成发布前顺手可做的动作清单：
1. **图片走官方免费商用图库**：从 Unsplash、Pexels、Pixabay 或平台自带图库选图。养成"看授权页"的习惯；带人物、品牌、建筑、商标的图商用尤其谨慎。
2. **字体统一用可商用白名单**：维护一份账号的"可用字体清单"，封面与正文只从清单里选，杜绝随手用系统自带版权字库。
3. **音乐只用平台授权素材**：后台音乐库或明确可商用且有授权页的素材；避免搬运他人成品配乐。
4. **写作自为主**：需要引用时，"出处标注 + 用自己的话转述"，不做整段复制；确需全文引用走"转载授权 3 步"流程。
5. **建立"素材台账"**：每次用图、字体、音乐记一笔来源与授权链接，定稿前抽查；被投诉时有据可证、能快速下架整改，也方便复盘。

## 四、常见错误（反例 + 正解）

1. **"网络图免费就能用"**——反例：从百度直接下张产品图放进推文当封面。正解：下载不等于授权，换用 CC0/免费可商用图库或自制图；确实要用就线下取作者授权并署名。
2. **"注了出处就没侵权"**——反例：整段贴别人金句或长文，末尾写"来源：XX"。正解：注明出处≠获得授权，长引用必须走转载授权流程，短引用也要用自己的话转述并标注出处。
3. **用系统版权字体做封面**——反例：用 Windows 自带某种版权黑体设计封面。正解：设计封面统一走免费商用字体白名单，做图前确认所用字体可商用。
4. **把 CC BY-NC 素材用于带货推文**——反例：图库标"仅限非商业"的图用在商品推广图里。正解：非商业授权不能用于推广，换商业授权图或原创图。
5. **洗稿以为安全**——反例：把热门文"换个说法"整篇发出来。正解：结构、观点、独创表达照搬即可能被认定洗稿；自己组织内容 + 转述 + 出处标注才最稳妥。

## 五、自查要点（发布前勾选）

- [ ] 用了图片：是原创？非原创的所有图都确认来源与授权覆盖了"公众号公开传播"场景？
- [ ] 图里有人物/品牌/建筑/商标，且用于带货？——肖像权/商标权另行确认
- [ ] 用了字体：封面与正文都来自"免费可商用字体白名单"，没有版权字体或被破解字库？
- [ ] 用了音乐/BGM：来自平台授权库或明确可商用的素材？
- [ ] 正文有整段引用/长引用？——走了"转载授权 3 步流程"或改成"转述 + 出处标注"？
- [ ] 每份非自制素材都有来源/授权记录（可留证的台账）？

## 六、注意

- **法规与平台规则会更新**：著作权法修订、各图库/字库授权条款、平台版权保护机制都在变化，**实际以最新著作权法规与平台最新版权规则为准**；免费字体、图库的"可商用"条款也请以官方最新说明为准。
- **个性化空间**：可按账号内容形态微调——图文测评号对图片版权要求高（多图带货尤其严），思维导图/教程号对字体版权敏感（文字输出多），纯情感/观点号对洗稿、整段引用要重点防。无论哪种，**自制原创素材始终是版权风险最低的底牌**。
- 图片确认流程的完整版在「配图素材」维度（image/img-copyright、image/img-sources）；来源标注写法见「数据引用与来源标注」「免责声明与风险提示写法」条目。
