# 配图素材维度索引（index-image）

> 定位：解决「图片从哪来、怎么确认能用、怎么处理」。与 module-image（排版布局）互补：本维度管素材本身。
> 用法：找图前读 img-sources；用非自制素材读 img-copyright（与 comp-copyright 分工：本条目讲操作流程，合规条目讲法律边界）；处理图片读 img-processing。
> 交叉：版权红线见 compliance/comp-copyright；图片排版布局见 module/module-image。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| img-sources.md | 图片来源：免费图库清单/自制图/截图/读者投稿的适用规范 | 找图前 |
| img-copyright.md | 版权确认流程：授权类型识别、免版权核实、记录留证 | 使用任何非自制素材时 |
| img-processing.md | 图片处理规范：尺寸/压缩/格式/水印/滤镜统一 | 图片定稿前 |
| img-alternatives.md | 无图替代方案：纯色块/图表/美术资产/排版图形 | 没有合适图片时 |

## 使用顺序

1. 找图（img-sources）→ 2. 确认版权（img-copyright）→ 3. 处理统一（img-processing）→ 4. 排版插入（module/module-image）；无图时用 img-alternatives。
