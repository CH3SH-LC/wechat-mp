# 封面与首屏维度索引（index-cover）

> 定位：解决「读者点进来之前和点进来的第一屏」——封面决定点开率，首屏决定留存。
> 用法：发布前必读 cover-spec（尺寸规范）与 cover-firstscreen（组合拳）；有摘要填写环节必读 cover-summary。
> 交叉：封面风格呼应正文（style/）；封面文字排版可用排版工具生成（见使用指南）。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| cover-spec.md | 封面图规范：2.35:1 大图 + 1:1 方图、安全区、尺寸与格式 | 制作封面时必读 |
| cover-text.md | 封面文字排版：标题压图的位置/字号/对比度/留白 | 封面上要写字时 |
| cover-summary.md | 摘要写法：摘要=第二标题，≤120 字，承接标题制造点开冲动 | 发布填写摘要时 |
| cover-firstscreen.md | 首屏组合拳：标题→摘要→首图→引导关注→正文第一屏的整体排布 | 每篇发布前检查首屏 |
| cover-consistency.md | 封面与正文风格呼应：色调/字体/元素一致性 | 封面与正文分开制作时 |

## 使用顺序

1. 先定标题与摘要（copy-title + cover-summary）；
2. 按 cover-spec 做封面图（需要压字读 cover-text）；
3. 发布前用 cover-firstscreen 检查首屏整体；
4. 用 cover-consistency 核对封面与正文观感一致。
