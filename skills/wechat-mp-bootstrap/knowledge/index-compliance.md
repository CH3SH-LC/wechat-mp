# 内容合规维度索引（index-compliance）

> 定位：解决「这篇文章会不会踩红线」。合规是内容安全底线——违禁词、行业规则、版权、数据引用。
> 用法：**发布前必读**：先扫 comp-banned（违禁词），涉敏感行业读 comp-industry，用图/字体/音乐读 comp-copyright，引用数据读 comp-data。
> 交叉：正文里的免责声明/来源标注模块见 module/module-disclaimer；图片来源确认流程见 image/img-copyright。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| comp-banned.md | 广告法违禁词：绝对化用语清单、变体规避与改写方法 | 每篇发布前必读 |
| comp-industry.md | 特殊行业红线：医疗/金融/教育/食品/化妆品/保健品各自的平台规则 | 内容涉及上述行业时 |
| comp-copyright.md | 版权风险：图片/字体/音乐/洗稿/转载的侵权边界 | 使用任何非自制素材时 |
| comp-data.md | 数据引用与来源标注：数据可信度与标注规范 | 正文引用统计数据时 |
| comp-penalty.md | 违规后果与申诉：删除/限流/封号机制与申诉路径 | 了解风险与补救时 |
| comp-disclaimer.md | 免责声明与风险提示写法：适用场景与标准句式 | 强合规行业内容必备 |

## 使用顺序

1. 写作前：涉行业红线先读 comp-industry；
2. 写作中：引用数据读 comp-data，用素材读 comp-copyright；
3. 定稿前：comp-banned 全文扫违禁词；
4. 发布前：确认是否需要 comp-disclaimer，了解 comp-penalty 的后果。
