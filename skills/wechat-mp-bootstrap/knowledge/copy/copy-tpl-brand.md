# 品牌故事模板（copy-tpl-brand）

> **定位**：
> 用一个不断坚持、有细节、有转折的真实历程，
> 把品牌「为什么存在、相信什么、坚持什么」讲透。
> 让读者记住的不是产品，而是「这家店是什么立场、跟你一条心」。
>
> **调用时机**：
> 写「品牌理念与历程 / 品牌宣言 / 周年回顾 / 品牌进阶」时用。
> 典型场景——一家坚守十年的老店、一个从车库起步的创始人故事、
> 一次品牌升级的初心回顾、一句品牌口号的深层解释。
> 它区别于「产品软文」重在推产品——这里重在立品牌；
> 也区别于「人物故事」聚焦一个具体人物——品牌故事可以写一群人、一个理念。
> 判断依据见「内容类型」维度判断流程。

## 一、结构与写法

品牌故事不靠「自夸」立起来，靠「读者信服你的坚持」。
所以核心，是用真实历程证明你的价值观，而不是宣称你的价值观。
结构：价值观切入 → 品牌历程故事（转折 / 坚持 / 细节）→ 品牌宣言收尾。

### 阶段一：价值观切入（约占 15%）

**写作目标**：
第一段就让读者清楚「这个品牌站在哪、为什么存在」，并接住读者的心里话。

**写法要点**：
- 从一个具体的洞察或立场切入，
  可以是行业的痛点、被忽视的需求、一个普遍的困惑。
  例：「我们总在担心孩子输在起跑线，
  却忘了问一句：他自己想学什么？」
- 把品牌存在的理由讲成「就是因为这个，所以我们才做这件事」，
  而不仅仅是「我们很专业」。
- 立场要真实、要和品牌实际做的事吻合——
  喊出来却做不到，读者一眼识破。

**判断立场真不真**：
问一句：这个立场，品牌一路走来真的有在践行吗。
如果说起来自己都心虚，改成真实现状的立场。

**时长/篇幅建议**：
首段 ≤3 行，约 100-150 字。
帮读者确认「这是一家有观点的店」，建立立场上的共鸣。

### 阶段二：品牌历程故事（正文主体，约占 65%）

**写作目标**：
用真实的经历、转折、细节，证明前面那句价值观不是说着玩的，
是品牌一路走出来的。

**写法要点**：
- 讲一个有转折的历程，别写流水账。
  挑 1-3 个关键节点：
  从一个小小的决定开始 → 遇到一个具体困难 / 转折 →
  靠某个坚持撑过来。转折是让故事有起伏的关键。
- 用细节代替吹嘘。
  说自己「注重品质」，不如写「为了一个包装盒的厚度，我们返工了三次」；
  说自己「坚持匠心」，不如写「查了二十份资料才定下这个配方」。
- 克制表达：
  讲失败、讲犹豫、讲不那么光鲜的坚持，反而比一路高歌更可信。
  承认「差点放弃」，比反复喊「我们最强」有力得多。
- 起承转合里要有「人」：
  创始人的一念、一位员工的坚持、一位顾客的反馈，让品牌故事有人味。

**转折的三要素**：
转折前是什么状态、遇到了什么、靠什么信念挺过来。
三样缺一，转折就不成立、故事就平。

**时长/篇幅建议**：
这是全文主体，约 55-65%，500-900 字。
故事要具体、有画面，可配「时间线」呈现历程脉络。

### 阶段三：品牌宣言收尾（约占 20%）

**写作目标**：
把前面讲的故事收摄成一句清晰、笃定的品牌主张，
回应开头的价值观，完成情感闭环。

**写法要点**：
- 宣言是一句立场鲜明、符合品牌一贯行动、能记住的话，
  不是空喊口号。
  例：老书店写「有些店，坚持不卖畅销书，
  也想陪你把一本好书读完」。
- 宣言要「做得到」：
  读者会拿品牌过去的故事来验证这句话。
  故事里做了的事，才能成为宣言的底气。
- 常配合「金句 / 大字号引用」把宣言立成整篇的高光句，
  也让读者可以单拎转发。
- 收尾可以在宣言后给一个克制、温暖的向往，但不跪舔、不催买。

**宣言能不能被验证**：
读一遍宣言，再回看故事里有没有对应的行动。
如果找不到，宣言就是空的，要改。

**时长/篇幅建议**：
100-200 字。
宣言要短、要有力，越朴素越容易被记住和转发。

## 二、完整骨架（可套用，标出的地方是替换处）

```
【标题】
〔标题走「立场/执着/守护」情绪路，别像广告语。
  例「这家书店，十年不卖畅销书」「为什么要为一个包装盒返工三次」〕

【开头 · 价值观切入】
〔一个具体洞察/立场/被忽视的需求，1-3 行〕
〔点出「就是因为这个，我们才做这件事」〕

【正文 · 品牌历程故事】
○ 起点：一个小的决定/一刹那的念头（带具体细节）
○ 转折：遇到一个具体困难/选择/动摇（这是起伏的关键）
○ 坚持：靠哪个信念/动作撑过来（用细节证明，别喊口号）
〔可再补 1 个节点：一次升级/一个顾客反馈/一个团队故事〕
〔用什么立场 → 就配什么行动，让读者自己读出一致性〕

【结尾 · 品牌宣言】
〔一句简短、笃定、有立场的宣言，回应开头〕
〔可再补一句克制的向往/感谢〕

【行动号召（可选）】
〔品牌号涨粉/关注/留言引导；纯品牌文可不放硬 CTA〕
```

### 骨架用法说明

- 骨架是「填空题」，〔方括号〕处换成品牌自己的真实素材。
- 历程部分按「起点 → 转折 → 坚持」组织，别写成产品编年史。
- 宣言可作全文高亮，用「金句 / 大字号引用」立起来，方便读者转发。

## 三、示例（生活 / 商业场景，标注结构）

> 主题：一家开在老街十年的文具店

**【价值观切入】**
小时候上学，最怕老师说「拿一本新本子」。
因为新本子意味着，过去的错别字都被翻过去了，
要从第一页重新工工整整地写起。
长大后才懂，一本好本子，不是纸多厚，
而是它愿意陪你从第一页，写到最后一页。
老街这家文具店，就是为了「陪人写到底」这件事，开了十年。

**【品牌历程 · 转折 / 坚持 / 细节】**
十年前开店，我们只做一件事：不卖那种翻几页就脱页的本子。
起初听的人笑我们傻——同样的纸，进价贵三成，学生又不识货。
可我们较真，坚持挑厚实的纸张、加固的装订，
就因为想对得起「陪你写到底」这句话。

第二年遇到大转机，也差点栽了跟头。
那年纸张成本暴涨，同一条街的店都换了薄纸压成本，
我们咬着一箱箱贵的纸没松口。账本上那个月是亏损的，
好几个店员劝我「再这样下去店要关了」。
那天下班，一个常来买本子的小姑娘说：
「阿姨，你这本子，我写完一整个学期都不散页，
我爸妈都说好。」就这一句话，我告诉自己，这个「亏」我还要吃下去。

后来我们慢慢养成了习惯：每批货进店，先自己抽出一本，
写满一整本，看看会不会脱页、会不会洇墨。
这十年，我们真这么一本一本试过。
有位写作的老师，后来成了常客，每次来都买一打，
说在这买的纸，钢笔写上去不洇——他写了三本书，用的都是我们家的本子。
这些顾客没说话，但他们的回头，就是店最大的底气。

**【品牌宣言】**
有人说，一间文具店能有什么价值观？
但我觉得，门店的立场就在每一件货里。
我们可以不卖最便宜的本子，
但我们坚持，卖给你的每一本，都要能陪你写到最后一页。
这十年如此，以后也如此。
谢谢你，愿意在自己的新本子上，写下我们的名字。

## 四、语气与禁忌

**语气要求**：
克制、笃定、有温情的底气。
不喊口号、不自我吹嘘，用故事里的选择和细节说话。
「我们当时其实是犹豫的」「那个月我们亏了」这类坦然的承认，
比「我们是行业第一」更让读者信服。
整篇像一位老店主跟你聊这些年的坚持，而不是一份企业宣传册。

**具体落地**：
- 用「那一单我们亏了」替代「我们从不计较成本」。
- 用「查了二十份资料」替代「我们精益求精」。
- 用「差点放弃，但……」替代「我们从未动摇」。

**禁忌**：
1. 自我吹嘘。
   通篇「我们最专业」「品质卓越」「行业领先」「深受喜爱」——
   形容词轰炸零可信度（也涉广告法绝对化用语）。
2. 喊空洞口号。
   理念、宣言只悬在半空落不下来，故事里却找不到对应的做法。
   理念必须能找到「品牌路上真实做过的一件小事」来落地。
3. 报喜不报忧、一路高歌。
   全篇顺风顺水，没有转折、没有犹豫，读者会觉得是编的。
   要有低谷、有动摇、有坚持下来的细节。
4. 过度煽情、说教。
   强行讴歌品牌多伟大、硬灌输价值观，
   变成感动的说教。故事里的事实比煽情有力。
5. 与品牌实际言行不符。
   宣言说得漂亮、实际做的是另一回事，
   一旦被读者发现，信任反噬最大。价值观必须和行为一致。

## 五、与排版配合

品牌故事重「叙事张力 + 情感沉淀」，排版要帮故事呼吸、帮宣言立住。
- **开篇**：
  用「开头页眉」做有质感的首屏；
  立场明确的账号可配「装饰标题」增强品牌调性。
- **历程**：
  用「时间线」呈现从起点到现在的节点脉络，
  读者一眼看清「坚持了多久、经历了什么」；节点间用「分割线」过渡。
- **细节 / 证言**：
  顾客的一句话、一个故事，可用「重点气泡」或「用户证言 / 口碑卡」嵌入，
  补充第三方温度。
- **宣言**：
  用「金句 / 大字号引用」把品牌宣言立成整篇高光，方便读者单独转发；
  关键数字（十年、三次返工）用「徽章 / 高亮」点缀。
- **结尾**：
  用「结尾行动号召」「页脚区」收束；
  连载 / 周年可加「往期回顾 / 下期预告」。

> 具体模块语法与样式见「模块」维度各条目，这里只给组合建议。

## 六、个性化空间

模板是起点不是终点，以下环节需**结合账号调性与读者改写**。
- **价值观的落点**：
  这篇文章强调的价值观，
  要选「最能打脸品牌当下最需要的那一个」。一家刚爆出质量争议的店，
  就讲「坚持质量」的旧故事；一家想吸引年轻人的老店，
  就讲「打破陈规」的转折。
  没有放之四海皆准的价值观，看你账号当下的处境定位。
- **故事的取材**：
  骨架里的「返工」「亏损」「顾客一句话」都是真实素材的典型写法，
  务必换成你们品牌真实的经历——没有一次真实的转折和抵抗，故事撑不起来。
- **转折的深浅**：
  有的品牌历程波澜壮阔，有的只是一件小事坚持了十年。
  不强行制造大转折，把真实的微小坚持写透，同样动人。
  判断依据：你们真实历程里最纠结、最难忘的那一关是哪一关。
- **宣言的力度**：
  年轻新品牌宣言可以更锋利、更有网络感；
  有历史底蕴的老品牌宣言更沉稳。宣言要和品牌调性与读者年龄层匹配。
- **软硬程度**：
  周年回顾、纯品牌文可以不放硬 CTA；
  若品牌文兼有引流 / 上新诉求，宣言后可自然地加一个轻量号召。
  别为加广告破坏品牌文的纯粹感。
