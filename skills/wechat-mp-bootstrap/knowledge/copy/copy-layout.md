# 文案与排版配合（copy-layout）

> 定位：写文案时就要"预留排版位"，让文案在进入排版工具/模块之前就标好哪里配图、哪里设小标题、哪里给列表/分割线/行动按钮。本条目给文案里的排版位标记法、文案长度与模块数量的匹配，以及把文案翻译成模块结构的步骤。
> 调用时机：文案完稿、准备转成实际排版（选模块、加配图、调间距）时调用。配合《模块》维度（36 个排版模块）一起用：本条目负责"文案怎么为排版铺路"，《模块》提供"有哪些模块可选"。

---

## 一、核心规则

**规则 1：写文案时先想排版，后写正文更省事。**
在动笔前/起稿时，就大致想好这段要配图还是用列表、要小标题还是分点。先定"图文结构骨架"，再填文字，比写完一大段再来拆排版高效，也避免文字长得塞不进现有模块。

**规则 2：用一套简单的"排版位标记"写进文案草稿。**
在文案里用约定符号标出模块类型，排版时照着填即可。示例标记：
- `【图】` 表示这里放一张配图；
- `【小标题】` 表示这里起一个分点小标题；
- `【列表】` 表示这里是并列清单；
- `【分割】` 表示这里放一条分割线做呼吸；
- `【按钮】` 表示这里是行动按钮/卡片 CTA（点在看、关注、下单等）。
（具体符号可按账号习惯自定，只要团队/排版工具一致。）

**规则 3：文案长度要与模块数量匹配——"疏密有度"。**
太长的文配太少模块会显得一坨；太短的文配上大量卡片气泡又显得空。经验值：
- 800–1200 字短篇：开头钩子 + 4–6 个正文模块 + 结尾；
- 1500–2500 字中篇：开头 + 小标题分层 3–4 层 + 每层 1–2 个模块 + 配图 1–2 张 + 结尾；
- 3000 字+ 长篇：多小标题 + 细分点 + 配图/表格穿插 + 适度分割，避免整屏文字。
（参考《文案长度与阅读时长》，按读完率反推。）

**规则 4：每个排版位要"有存在意义"。**
配图不是凑数的、分割线不是乱加的。每处模块都应服务阅读：配图帮理解/换呼吸，小标题帮分节，列表帮扫描，按钮帮行动。为凑模块而加会显得空洞。

**规则 5：从"段落文字"到"模块结构"是可逆翻译，不丢信息。**
把一段连续文字拆成模块时，信息不丢、顺序不变、因果不乱。模块只是"换种呈现"，核心观点和衔接关系要保持原样（衔接问题参考《段落过渡》）。

## 二、模块数量与文案长度匹配参考

| 文案长度 | 建议模块规模 | 模块搭配示例 |
|---|---|---|
| ≤800 字（短篇） | 3–5 个模块 | 标题 + 开头 + 3 个分点/列表 + 结尾按钮 |
| 800–1500 字 | 5–8 个 | 标题 + 开头 + 小标题分层(2–3) + 每层 1 个模块 + 配图 1–2 + 结尾 |
| 1500–3000 字 | 8–14 个 | 标题 + 开头 + 小标题(3–4) + 每层要点/表格/图 + 中间分割 + 结尾 + 行动按钮 |
| 3000 字+（长篇） | 14+ 个 | 多小标题 + 细分点 + 表格/图片穿插 + 多处分割 + 章节式结尾 |

> 经验：**每屏（约 350–500 字）至少让读者"换一次眼"**——小标题、列表、图片、分割线任一。整屏连续正文无任何模块，就是可读性不合格（更多规范见《可读性》维度）。

## 三、把文案翻译成模块结构的步骤

1. **通读一遍文案**，标出"一个完整独立语义"的单位——每处稍作停顿就能读的就是一个潜在的模块边界。
2. **按语义归类**：这段是"解释"→ 普通段落；是"几个平级结论"→ 列表/卡片；是"顺序操作"→ 步骤；是"对比"→ 表格两栏；是"讲一个人"→ 独立段落/图卡；是"情绪或金句"→ 气泡/高亮。
3. **标出"需要换气/分隔"处**：段与段若相邻太长或跳跃大，插入分割线或图片做停留。
4. **补"排版位标记"**：按上面规则 2 的符号，在每个落点标上 `【小标题】/【列表】/【图】/【分割】/【按钮】`。
5. **校验信息完整性**：对照原文，确认每一步翻译没有遗漏要点、没有打乱逻辑顺序（对照《段落过渡》，小标题间需要时补过渡句）。
6. **送入排版工具**，按 `00-GUIDE` 的间距硬规范填充（块间距 16px、行距 1.75、标题上 28 下 12 等），再检查可读性。

## 四、示例

**把一段"连续文字"翻译成模块结构的完整示例，主题：给打工人的快手早餐。**

原文（一段 300 字）：
"打工人早上最缺的是时间和动手欲。隔夜燕麦提前一晚泡好，早上装杯就能走，很省事；微波炉厚蛋烧 5 分钟就能熟，配吐司就是完整一餐；还有即食全麦面包加鸡蛋，夹一夹 2 分钟搞定。这三样都不超过 15 分钟，一周可以轮着吃，不重样。坚持一个月你会发现，好好吃早餐真的能让你上午更有精神，也不容易到快中午就胃空。"

翻译成模块结构：
```
【开头段落】打工人早上最缺的是时间和动手欲。

【小标题】三款 15 分钟内能上桌的早餐
【列表】
- 隔夜燕麦：提前一晚泡好，早上装杯就能走。
- 微波炉厚蛋烧：5 分钟熟，配吐司就是一餐。
- 全麦三明治：夹一夹 2 分钟，边走边吃不设限。

【分割】——————————————————

【结尾段落 + 按钮】这三样不超 15 分钟，一周轮着吃，不重样。坚持一个月你会发现，好好吃早餐能让你下午更精神，也不易吃太快到中午就饿。→【按钮：点个在看，把这份清单分享给常饿着出门的朋友】
```
要点：一个 300 字长段被拆成"开头 + 小标题 + 列表 + 分割 + 结尾 + 按钮"，信息零丢失、原有"省事/快手/营养"的要点一个不少，且更易扫描。

**第二个更小规模示例（对比类内容的模块翻译），主题：进大厂 vs 小公司。**
原文一句话较长，翻译成"列表 + 表格 + 结论"：
```
【小标题】进大厂还是留小公司，先看这 3 个维度
【表格】
| 维度 | 大厂 | 小公司 |
|------|------|--------|
| 薪资 | 起点高、涨幅慢 | 起点低、看业绩 |
| 成长 | 细分专精 | 全能复合 |
| 节奏 | 流程规范 | 快而自由 |
【结尾段落 + 按钮】没有绝对好坏，关键看你现阶段更想要"稳定"还是"成长"。→【按钮：评论区聊聊你的选择】
```
要点：一段话被重排成"表格"，对比信息一眼可见，比堆在大段文字里清楚得多；结尾照常收束 + 互动。

### 排版位标记扩展（常见标记约定，可按需取用）

- `【图】` 正文配图（插在语义停顿处，上 12px/下 12px）。
- `【小标题】` 分点小标题（上层 28px / 下层 12px，具体见间距规范）。
- `【列表】` 并列清单（`-` 无序列表或 `::: cols`）。
- `【步骤】` 步骤流程（`::: steps`，动词开头、每步 ≤15 字）。
- `【表格】` 对比/参数（维度对齐）。
- `【分割】` 分割线（上下 24px，做"换气口"）。
- `【气泡】` 强调/金句/提示（`[!NOTE|TIP|WARN|DANGER]`，一屏 ≤1）。
- `【按钮】` 行动号召（点在看/关注/下单的卡片式 CTA）。
- `【时间线】` 历程/复盘节点（`::: timeline`）。
- `【高亮】` 句内强调（`==高亮==`，一屏 ≤1）。
- `【封面/首屏】` 文章最前的引导位（参考《封面与首屏》）。

选定符号后，同一账号内字面统一，排版与写作人员照此唯一标准执行。

## 五、常见错误

- **错误 1：文章写成一整坨，没有任何模块。**
  反例：上千字没有小标题、没有列表、没有配图，读者面对整屏文字直接划走。
  正解：按"每屏换一次眼"补模块。

- **错误 2：为凑模块乱加，模块与内容无关。**
  反例：内容没讲几件事，硬塞一堆卡片和配图，显空、显假。
  正解：模块服务语义，每个模块都有存在意义。

- **错误 3：翻译模块时丢信息或打乱顺序。**
  反例：原文有 3 个方法，拆成列表时漏掉第 2 个；或把"前置条件"放到了"操作步骤"之后。
  正解：翻译后对照原文逐条核对，信息与顺序原样保留。

- **错误 4：只做列表/只做段落，不考虑"换气"。**
  反例：通篇都是列表（左边一排字），或通篇都是段落，都缺少节奏变化。
  正解：段落/列表/图片/分割按阅读节奏搭配，疏密有度。

- **错误 5：标记符号各人各用，团队/排版不统一。**
  反例：有人用"图"，有人用"{图}"，有人直接贴一张占位图进去，排版时对不上。
  正解：定一套统一标记，写入账号写作规范，排版照着唯一标准执行。

## 六、自查要点

- [ ] 写文案时已按"每屏换一次眼"给长文留了模块位
- [ ] 文案草稿里标好了排版位（图/小标题/列表/分割/按钮）
- [ ] 模块数量与文案长度匹配（短篇 5–8、中篇 8–14、长篇 14+）
- [ ] 每个模块都有存在意义（服务理解/扫描/行动）
- [ ] 从段落文字到模块结构，信息不丢、顺序不乱
- [ ] 排版位标记在同一账号内统一、字面一致
- [ ] 翻译后对照原文完成信息完整性校验

## 七、个性化空间

- **模块风格的浓度**：插画/活泼向账号爱用卡片、气泡、低饱和纯色块+细边框；极简/商务向账号偏爱朴素段落、少装饰。判断依据：账号视觉风格（参考《风格》维度），模块密集度要与视觉调性一致。
- **配图的风格与频率**：生活方式/美食向可高频配图；干货/资讯向以图表/截图为主，频率更低。判断依据：内容认知维度——视觉内容型读者吃图，逻辑型读者吃结构和图表情报。
- **行动按钮的样式与位置**：促销向用醒目的 CTA 卡片大按钮；陪伴型用轻量"在看"引导。判断依据：营销浓度与你想营造的氛围。
- **分割线的使用偏好**：日系/温柔向可多用波浪分割线做呼吸感；极简向可少用靠留白。判断依据：视觉节奏与账号的"留白美学"。
