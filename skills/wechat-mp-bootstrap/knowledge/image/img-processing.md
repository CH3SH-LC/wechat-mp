# 图片处理规范（尺寸 / 压缩 / 格式 / 统一 / 水印 / 裁剪）

> 定位：图片定稿前怎么处理——尺寸与比例、jpg/png 选择与压缩（≤1MB 平台限制）、清晰度权衡、同一篇风格统一、加水印的做法与注意、裁剪原则。它管"素材本身"，排版布局另看"图片排版布局"条目（legacy/05 图 排模板）。
> 调用时机：图片下载/自制完成后、上传微信前处理定稿。

## 一、尺寸与比例

**正文图宽度：**
- 微信正文内容区手工约 677px 宽（手机约视图宽 - 120px）。
- **原始上传图建议 ≥1080px 宽（推荐 1080–1200px）**：手机 DPR 2–3，这样才能在微信把超宽图压到约 677px 后仍清晰锐利（见 legacy/05 第 6 条）。
- **重要内容（文字/LOGO）不要贴边**，留安全边距，避免被微信裁切或缩小时糊。

**比例建议：**
| 用途 | 建议比例 | 说明 |
|---|---|---|
| 正文通栏图 | 4:3 或 3:2（横向） | 常见舒服比 |
| 章节大横幅图 | 3:1 ~ 16:9（偏宽） | 制造氛围停顿 |
| 双图并排/三图 | 同比例（如都 4:3） | 网格对齐才不歪 |
| 封面图 | 2.35:1 + 1:1 双比例，见 cover/ | 封面另有规范 |

**长图约束（重要）：** 微信对超高长图会自动压到约 1500px 内并整图等比缩小，长图上的细字会发糊且无法局部放大。**信息长图宜切成 ≤1500px 高的多段**拼接，或正文用小图 + 查看原图引导。

**比例换算成"长宽像素"（给没有网格习惯的号参考，正文通栏）：**
- 4:3 → 如 1080×810 或 1200×900；
- 3:2 → 如 1080×720 或 1200×800；
- 16:9 → 如 1080×608；
- 做横幅 → 如 1080×360 / 1200×400。
- 只要保证"宽 ≥1080 + 高度别超过长图上限 + 比例统一"三个条件，具体像素可自由。

## 二、压缩与格式（jpg / png 选择 + ≤1MB）

**平台限制：** 微信 uploadimg 仅接受 **jpg / png，且 ≤1MB**（legacy/09 平台事实）；超过会被拒（错误码 40009 图片太大）。

**格式选择：**
- **JPG**：照片、复杂色彩图。压缩损失可接受。
- **PNG**：含文字、图表、透明底、LOGO 示意。色彩少的图片 PNG 反而更省体积。
- **不要用**：BMP/TIFF 太大，GIF 不适合静态正文；WEBP 需按格式转换（微信 uploadimg 收 jpg/png）。

**压缩方法：**
- 上传前在"设计工具/压缩工具/图片处理软件"里压缩到 **≤1MB**；
- 长图/大图优先压到 700KB 上下更稳（低于 1MB 余量，避免临界失败）；
- JPG 压缩时权衡：压缩率太高会糊、太低体积超限；肉眼在真机上核对一次不糊即可。
- 原始高清图保留一份，正文只传压缩后的可发布版（原始版用于重制/变换备份）。

**清晰度权衡口诀：** 先保证"内容（文字、数据）清晰可辨"，再谈体积；反过来因为压太小糊了，等于白做。

**压不下去怎么办（可操作顺序）：**
1. 先换格式（照片强行从 PNG 转 JPG 常能大幅降体积）；
2. 再降 JPG 质量档（从 90 → 75 → 60 逐步试，每次真机看一眼文字是否仍清楚）；
3. 还超就**降分辨率**（但正文图别低于 750px 宽）；
4. 最后看有没有"确实不用这么清楚"的图可再压。
- 别一上来就把质量拉到底——多数糊图是"一步到位压 20%"造成的，逐档试更可控。

## 三、统一性（同篇滤镜 / 圆角 / 边框一致）

一篇文章里的图要整体一致，否则显乱：

- **滤镜/色调**：同一篇里所有照片套同一套调色（亮度/对比/饱和度大致一致），不要有的图很亮有的很暗、有的偏暖有的偏冷。可保存一个统一的"预设"一次套用。
- **圆角**：同篇统一圆角（正文基础 8px，卡片图 8–10px），不要这张 8px 那张 20px。
- **描边/边框**：要加就统一加（全部套细描边或全部不加），"有的有框有的没框"视觉杂。
- **留白/间距**：统一图片上下留白，别一半贴边一半空敞；**阴影一律不用**，用细边框加留白形成边界。
- **比例**：并列/网格图用同比例，见上文。

**统一是"成套感"的来源**：处理时先定一套参数（滤镜+圆角+边框+比例），对整批图统一套用，而不是逐张随手调。

**落地做法（可操作）：** 处理一批图前，先拿 1 张做"标准样"（套好滤镜+圆角+边框+压到 ≤1MB+确认比例），其余逐张对着这个标准套，不做每张自由发挥。这样哪怕不是设计出身，也能保证一排图看过去是成套的。

## 四、加水印的做法与注意

**做法：**
- 水印用于标记版权的号名/Logo，放在**不遮主体**的位置：角落、图像边缘的安全区。
- 半透明（约 20–40% 透明度），字号/Logo 大小以"看得见、不抢内容"为度。
- 批量加水印，位置、大小、透明度整批统一。

**注意：**
1. **水印不遮主体**：遮住关键内容会让读者看不清图，也显得不专业。
2. **不要只写在角落当摆设**：真正的防搬运水印放中央大图但透明度极低（如 4–6%）或交叉排铺；若号不追求防搬运，角落小水印足够。
3. **不要压到文字/人脸/数据** 上。
4. **既加水印又想把图当素材分享** 的矛盾：保留一份无水印源文件，正文只放水印版。

**判断依据：** 是否加水印看账号对"被搬运"的在意程度与素材的独家性。纯图库图加号名水印意义有限；自制/独家素材值得加。

**水印"位置 × 透明度 × 字大小"速查：**
| 目的 | 位置 | 透明度 | 字号/大小 | 说明 |
|---|---|---|---|---|
| 纯号名露出 | 角落安全区 | 20–40% | 中 | 看得见、不抢内容 |
| 轻度防搬运 | 中央贯穿 | 10–20% | 大 | 遮挡少、仍看得到 |
| 强防搬运 | 交叉斜排多枚 | 4–6% | 中 | 隐形于图，转载难以裁掉 |
| 正文小图 | 右下角 | 30% | 小 | 别遮主要信息 |

**"遮没遮住"自检：** 加水印后把图缩到手机阅读大小再看一眼——那枚水印在不影响读图的前提下还"看得见"吗？看得见、又不碍事，就对了；完全看不见（太淡/太小）就白加了，明显碍事就调透明度/位置。

## 五、裁剪原则

- **主体居中、不截意**：裁切时保持被摄物主体在画面中间或视觉重心区，不把人物头/关键数据栏截掉一半。
- **构图原则**：裁掉多余背景、突出重点；人物照避免切耳朵/下巴，产品照避免切产品边角。
- **微信的二次缩放**：正文上传后微信还会压缩宽度，裁剪时要保证"微信缩到的宽度下主体仍可辨"。
- **比例对齐**：网格/并排图按统一比例裁，见上文。

**人物/产品照"别切哪"速查：**
- 人物：别切头发顶 / 耳朵 / 下巴 / 指关节；通常在"肩膀以上随意"。
- 产品：别切产品的关键边角 / 文字部分 / 明显特征。
- 数据/表格：别把表格边框、表头、关键行切掉，宁可多留一点空白。

**"先裁后调还是先调后裁"（给顺序）：** 建议**先统一比例做主要裁切，再套滤镜调色，最后压缩体积**。若反过来先调色再裁，裁掉的部分往往带着调好的色，重裁时色就乱了。简单记忆：比例 → 色彩 → 体积。

**没把握会不会切坏时：** 用"裁图前先看全图、裁完立刻缩到手机大小真机看一眼"的兜底——手机上能一眼看清主体、没切断关键部位，就过了；看不清就回退多留点边。

## 六、示例

**合规：** 下载 1200px 宽照片 → 在工具里裁成 4:3、套统一暖色滤镜、加 8px 圆角、角落放 30% 透明度号名水印 → 压到 800KB 的 JPG → 上传正文，微信压到约 677px 仍锐利。

**不合规反例：** 直接用缩略图（600px）上传 → 微信压到 677px 下方放大糊；同篇一张 4:3 圆角图 + 一张 16:9 直角无框爆炸图 → 视觉杂乱。

**压不动的处理示范：** 一张 1.4MB 的 PNG 长图 → 先转 JPG 压到 900KB → 转后轻微糊、文字仍清楚 → 定稿上传；原始 PNG 保留备份。另一种：一张 1.6MB 图转 JPG 仍有 1.2MB → 质量降到 75 → 900KB，达标。

## 七、常见错误

1. **用缩略图/低分辨率当正文图** —— 反例：放大糊。正解：取 ≥1080px 原图上传。
2. **超长信息图整张传** —— 反例：微信压到 1500px 内细字糊。正解：切成 ≤1500px 高的多段。
3. **压缩压过头、文字发糊** —— 反例：体积小了但内容不可辨。正解：以"图文可辨"为优先，压缩到 ≤1MB 且核不糊。
4. **同篇图风格不统一** —— 反例：滤镜/圆角/边框各不同。正解：整批套同一套参数。
5. **水印压住主体** —— 反例：遮了产品/人脸/数据。正解：放角落安全区、低透明度、不遮关键内容。
6. **一上来就把 JPG 质量压到最低** —— 反例：一步到位压 20%，文字直接糊。正解：逐档降级 + 每档真机看一次。
7. **不分用途用同一种格式** —— 反例：照片硬存 PNG 体积爆炸、文字图表硬转 JPG 有噪点。正解：照片 JPG、带文字/透明 PNG。
8. **长图不切、整张硬传** —— 反例：信息长图一张传到底，微信压到 1500px 内细字糊成一片。正解：按内容切段、每段 ≤1500px 高，各自独立可读。
9. **导出后不真机检查就上传** —— 反例：在电脑看着清楚，手机上放大才发现文字发糊。正解：上传前用真机预览看一次"满屏放大是否仍可读"。

## 八、自查要点（可勾选）

- [ ] 每张图 ≥1080px 宽（长图已切段 ≤1500px 高）
- [ ] 格式为 jpg/png，且 ≤1MB（尽量 800KB 上下）
- [ ] 上传后真机看**不糊、文字数据清晰**
- [ ] 同篇滤镜/圆角/边框/比例统一
- [ ] 水印在角落、低透明、不遮主体（如需）
- [ ] 裁剪主体居中、无关键部位被截
- [ ] 重要内容不贴边（防微信裁切）
- [ ] 保留一份无水印/原始高清备份（如需重制）
- [ ] 压不下去时已按"换格式 → 降质量 → 降分辨率"顺序尝试

## 九、个性化空间

- **统一风格的方向**：温暖生活方式号可用暖色滤镜+大圆角；极简科技号可用冷色+直角或极细边框。判断依据：品牌视觉调性（见 style/）。
- **圆角/边框的强度**：卡片感强、亲和的内容圆角大（12px）；严肃数据、资讯类圆角小（4–8px）甚至直角。判断依据：内容的正式度与观感诉求。
- **水印的策略**：独家干货/原创图坚持水印；图库素材加不加都不影响版权归属（版权在图库），水印只是"号名露出"。判断依据：素材的独家性 vs 打广告感。
- **优化目标取舍**：推荐图（横幅氛围）可把体积放宽到接近 1MB 换质感；列表里的九宫格小图可压缩更狠省流量。判断依据：每张图的信息量 vs 加载成本。
- **压缩档位的激进程度**：追求极致体积可把非关键装饰图压到 400KB 上下；承载文字/数据的图保守压到 700–900KB。判断依据：图是否承载关键信息。
