# 图片来源（免费图库 / 自制 / 读者投稿）

> 定位：配图从哪来——免费可商用图库、自己用手机/截图/设计工具做、读者投稿，各自的适用规范与授权注意；以及怎么把"来源 + 授权信息"留档。
> 调用时机：找图前先读本篇；用非自制素材前接"版权确认流程"条目做授权核实。

## 一、免费可商用图库（Pexels / Unsplash / Pixabay 等）

**可用清单（常见免费图库）：**
- **Pexels**、**Unsplash**、**Pixabay**：综合图库，量大、质量高，最常用。
- **Pixabay / Pexels** 支持中文搜索。
- 国内可达性好的还可考虑 **pxhere**、**摄图网（部分免费）**、**千图（付费为主）** 的免费通道，但授权条款需逐站看。
- 冷门门类（如医学、工业设备、本地风物）图库可能欠缺，可转"自制/读者投稿"或用替代方案（见"无图替代方案"），别在一棵树上找。

**使用注意（核心）：**
1. **每个图库的授权条款不同且会更新**，用之前到该站"授权 / License"页面确认。多数"免费"站对商用有附加限制，例如：
   - 作品不能商用后"转售"或做明显的衍生销售；
   - 含有人物/建筑/品牌的照片，体现上可能有知情同意、商标、肖像权问题，不能想当然；
   - 某些站要求按 CC 或站内规则署名，使用时要写明来源。
2. **站内标明 CC0 / 可商用 + 个人自用商用免署名的，才放心的自由用；带限制的，阅读条款后判断是否适合你的场景。**
3. 免费不等于免版权、免知情同意——**从搜索引擎整图抓的图默认没授权**（见"无明确授权时不可用"）。

**取图规范：**
- 优先取**原图/高分辨率**（网站有多个尺寸），不取缩略图，否则"图片处理规范"里放大就糊。
- 下载时**顺手保存来源页链接 + 作者 + 授权状态**（见"来源记录方法"）。
- 图库检索用关键词 + 拍风格（如"办公、俯拍、明亮"），选和账号调性一致的。
- **提示词习惯**（若图库支持扩展搜索）：按"内容 + 拍摄角度 + 光线/色调 + 场景"组合关键词（如"会议室 俯拍 明亮 无人物"），能更快命中风格统一的图；加"无人物/无商标"可避开肖像与商标顾虑。

**一个选图自检句（取图时默念）：** 这张图够不够清晰、色调和本篇统不统一、版权能不能覆盖我的公开传播——三问都对，才放进素材夹。

**关键词组参考（把"模糊的找图需求"翻译成图库能懂的词）：**
| 你要的感觉 | 例：正文/横幅图的关键词组合 |
|---|---|
| 干净办公感 | "办公室 桌面 俯拍 明亮的" |
| 生活日常感 | "咖啡 餐桌 侧光 暖色调 无人物" |
| 科技/极简 | "电路板 特写 冷色调 深色背景" |
| 国潮/传统 | "灯笼 红色 特写 纹理" |
| 无人物稳妥 | 结尾加"无人物 / no people"避免肖像顾虑 |

> 加"无人物/无商标"是省心选择：既是搜索技巧，也顺手避开了肖像权与商标的两类坑。

**为什么"免费"不等于"随便用"（一条总原则）：** 判断某张图能不能用，看的是"授权是否覆盖你的公开传播 + 商业/非商业场景"，一句话可以在取图时默念：**"没写明可商用，就当不可商用；要写明了，还得看有没有附加限制（署名/不可衍生）。"**

## 二、自制图（手机拍摄 / 截图 / 设计工具）

**手机拍摄**适用范围：产品实拍、场景记录、人物/事件。规范：
- 光线足够（室内开窗/补光），对焦清晰；
- 拍完在手机里调一次亮度和对比，避免太暗/太灰；
- 竖版或横版按版式需要拍，拍横屏照片时留安全边距（见"图片处理规范"）。
- 额外：批量拍"同场景多角度"再多选，比一张张硬凑更能选出色调一致的组图；同一期要凑多张就一次性拍"同一环境光"的一组。

**截图**适用范围：软件界面、数据后台、聊天记录、资料引证。规范：
- 界面截图要注意**敏感信息**（手机号、账号、密码打码）；真实读者互动截图征得对方同意；
- 截图在"设计工具"里加框/圆角统一风格（见"图片处理规范"的统一性）。
- 额外：手机端截图优先用系统长截图（若不需要长图，普通单屏即可）；截图别拖到上传前才处理，下载/截完立刻做一次裁剪与打码，避免反工。

**设计工具**（PPT/Canva/稿定/PS 等）做图规范：
- 预设好画布尺寸（正文图 ~750px 宽，见"图片处理规范"），避免做出来超出上传上限；
- 用工具模板做统一风格的一套（字号/配色一致）比逐张手拼更稳；
- 导出格式按用途选（照片 JPG、含文字示意图 PNG），控制 ≤1MB（详见"图片处理规范"）。
- 额外：设计图导出前先看"导出设置"里的尺寸（至少做到 ≥1080px 宽再导出，别默认 750px 就交卷），并用"几张预览一起看"确认成套。

**自制图的注意（共通）：** 自制不等于免所有风险——自制**照片里出现真人**仍涉及肖像权（需对方同意），**拍到品牌 LOGO / 商标**仍受商标约束。自制解决的是"版权"，不代表"肖像/商标"也自动豁免。

**怎么判断"自制能不能用"（可操作三连问）：**
1. 图里有没有**能认出的人脸**？有 → 需肖像同意（家人朋友拍的也最好打个招呼）。
2. 图里有没有**明显的品牌 LOGO / 店招 / 商标**？有 → 说明性引用可斟酌，别做营销暗示。
3. 有没有**可定位的个人敏感信息**（门牌号、工牌、车票）？有 → 打码或裁掉。

**多图成套的通用选法（无论图库还是自制）：**
- 同批图要么统一"色调 + 角度 + 场景"，要么统一"比例 + 圆角 + 滤镜"，二选一至少满足一个，视觉才成套（详见"图片处理规范"的统一性）。
- 图库取多张时，按**同一个关键词组合 + 同一风格**取，别东取一张西取一张。

## 三、读者投稿图的使用授权

读者投稿（照片、截图、留言、作品）是真实素材，但**版权归作者本人**，使用前必须：
1. **征得投稿者同意**，明确"会被用于公众号推文、可能被公开传播"；
2. **保留授权记录**（聊天记录/邮件/私信截图）；
3. 有肖像的投稿，尤其涉及个人信息的，征得同意时说明用途；
4. 评论区截图若涉及隐私，打码后再用，且一般不用于商业推广引用。

**投稿节奏建议：** 若想稳定获得投稿，可在每篇推文结尾放一句"欢迎投稿 / 分享你的 XX"征集语，搭配一张示例图告知"用什么格式、发到哪"。收到后统一走一次上面 4 步（同意→留证→可打码→标注来源），别临时一个招呼就发了。

## 四、来源记录方法（保存来源与授权信息）

**原则：能用但必须可追溯。** 记录一份"来源清单"（表格或文档）随素材保存，字段：
- 素材文件名（对应正文里的图）；
- 来源（图库名 + 原图页面 URL / 自制 / 读者投稿）；
- 作者（图库名可填站内作者名）；
- 授权类型（如 CC0 / CC BY / 站内可商用 / 自制 / 授权读者）；
- 授权链接（授权条款页面 URL）；
- 使用日期、是否已在正文署名。

**建议做法：** 每批素材开一个文档（如"素材来源备忘.md"），配图时就登记，发布后这个备忘就等于"留证"。需要补证时（如作者随时更新条款），凭链接能找回。
- 登记时机：**下载/取图那一刻就登记**，别等排版完再补——越晚越容易漏。
- 登记粒度：一张一行，别整批"一锅烩"，否则哪张对应哪个来源会对不上。
- 长文多图时，可在正文图注旁边同步标"图 1：来源 xxx"，与清单一一对应，最稳。

**一张图的"取图到定稿"完整流程（可逐张/逐批套用）：**
1. 定需求：这张图要传达什么（场景/数据/氛围）、放哪个版位（通栏/横幅/并排）；
2. 去取图：图库原图，或自制/截图，或读者投稿（先征得同意）；
3. 核授权：读对该场景的授权条款，判断能否商用/修改/是否需署名（见"版权确认流程"）；
4. 登记来源：把这张图的"文件名 + 来源 URL + 作者 + 授权类型 + 授权链接"写进清单；
5. 处理定稿：按"图片处理规范"裁比例、统一风格、压缩到 ≤1MB；
6. 上传与排版：插入正文对应版位，图注可标来源；
7. 留证归档：发布后清单文件保留，即成为日后自证凭据。

## 五、示例

**合规：** 用 Pexels 搜"办公室 俯拍"，下载原图，登记来源页链接 + 作者 + "站标可商用自用免署名"，正文直插。
**合规：** 自制一张 750×500px 的产品对比海报（设计工具），登记"自制"，无需授权。
**合规：** 读者私聊投稿一张照片，对方回"可以用",留存截图，正文注明"图源读者投稿"。
**合规批量：** 一篇内容取 5 张 Unsplash 组图，一次性登记到一个备忘：5 行（各自文件名 + URL + 作者 + 授权链接），正文配 5 处图注，发布后凭证齐。

**不合规反例：** 从百度图片直接右存一张"看起来是配图"的照片，不加来源、不核授权，直接插进正文——几乎必定踩版权（见"版权确认流程"条目的风险自查）。

## 六、常见错误

1. **把"百度/google 图片"当图库** —— 反例：搜索引擎的图默认无授权。正解：从明确标注授权的图库/站点取，或自制。
2. **把所有免费图库当成"随便用"** —— 反例：没看该站条款，商用后被告知需署名/不可衍生。正解：逐站读授权页并记录。
3. **下载缩略图凑合用** —— 反例：放大后糊、失真。正解：取原图/高分辨率版本。
4. **读者投稿不问就发** —— 反例：版权归作者，未授权乱用埋雷。正解：先征得同意并留证。
5. **用完不记录来源** —— 反例：事后补证找不到出处、作者更新条款无法自证。正解：用一张记一行，清单留存。
6. **自制图忘了肖像/商标** —— 反例：自拍里有路人脸、拍到店招 LOGO。正解：自制同样要过肖像/商标，需同意或模糊处理。
7. **批量取图不拆登记** —— 反例：5 张图共用一个来源，哪张对应哪个出处对不上。正解：一图一行、图注与清单一一对应。
8. **不核版权就直接插正文** —— 反例：图看着合适就上，没走"查授权→判断可商用"这步。正解：先过"版权确认流程"再插，取图即核、插前复看。
9. **只认一个图库找不到就放弃配图** —— 反例：某个门类在一个站找不到，就改成留白或硬塞无关图。正解：换图库 / 转自制 / 或走"无图替代方案"，多一条路。

**自查补充：** 自查不打满也别忘了"图注与清单对得上"——发布时顺手核对一遍正文里每张图的来源，比事后补证省力。

## 七、自查要点（可勾选）

- [ ] 图片来源为明确授权的图库 / 自制 / 已授权读者投稿
- [ ] 非自制素材的授权条款已读并判断适用当前商用场景
- [ ] 取的都是原图/高分辨率，不是缩略图
- [ ] 截图/互动素材已做敏感信息打码、必要时征得同意
- [ ] 每张图都登记了来源 + 作者 + 授权类型 + 授权链接
- [ ] 读者投稿有授权记录
- [ ] 未使用任何"来源存疑"的图
- [ ] 自制图已同样复核肖像/商标/敏感信息
- [ ] 批量取图时一图一行登记，无混记

## 八、个性化空间

- **图库的偏好**：科技/商业类偏好 Unsplash 的干净极简；生活/情感类可多用 Pexels/Pixabay 的日常感。判断依据：品牌视觉调性（见 style/ 维度）。
- **自制 vs 图库的比例**：有专业设计能力的账号可 80% 自制形成强辨识；编辑人手紧的账号可 80% 图库 + 统一滤镜风格。判断依据：人力与品牌辨识度需求。
- **是否在正文署名图源**：合规**不强制**在正文署名（只要授权允许），但若所用素材授权要求署名，或你想展示"素材来自读者"，可在图注注明。判断依据：授权条款要求 + 号的人情味策略。
- **方言/地域素材**：本地号可用读者投稿建立"本地感"，但需平衡隐私与授权。判断依据：账号社区属性和亲和策略。
- **选图的统一度投入**：追求极致成套的账号可固定"图库 + 关键词组合 + 滤镜预设"三件套标准化选图；快速产出型账号保证"色调大致统一 + 原图清晰"即可。判断依据：品牌辨识度 vs 产频权重。
- **是否建"常用图库源清单"**：把试过好用、授权明确的图库和关键词记成一张速查表，下次取图直接照着搜，能省下反复试错时间。判断依据：账号取图频率与团队交接成本。
- **给读者投稿设置格式门槛**：可让投稿更"能直接用"——例如只收"横向、≥1080px、无敏感信息"的照片，太随意的投稿先沟通再收。判断依据：投稿的利用率与筛选成本。
