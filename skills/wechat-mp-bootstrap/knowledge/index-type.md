# 内容类型维度索引（index-type）

> 定位：解决「这篇推文是什么类型」。**拿到任务第一步先定类型**——类型决定结构骨架、风格倾向、模块组合与文案模板。
> 用法：读 type-catalog 看全谱对照，读 type-choose 走判断流程，确定后读对应类型条目；两类混搭时读 type-mix。
> 交叉：每类内容的文案模板见 copy/（copy-tpl-*）；模块组合见 module/module-guide-matrix。

## 一、类型速查（内容特征 → 类型）

| 内容特征 | 类型 | 一句话结构 |
|---|---|---|
| 教方法、给步骤、讲知识 | 干货教程 | 痛点 → 方法分点 → 案例 → 行动 |
| 新近发生的事实报道 | 新闻资讯 | 倒金字塔：结论 → 细节 → 背景 |
| 抒发感受、生活感悟 | 情感随笔 | 场景 → 共鸣 → 升华 |
| 推广产品但不硬广 | 产品软文 | 场景 → 卖点 → 证言 → 行动 |
| 活动/促销/优惠信息 | 活动促销 | 利益点 → 规则 → 紧迫感 → CTA |
| 讲品牌理念与历程 | 品牌故事 | 价值观 → 故事 → 宣言 |
| 写一个人/一群人的经历 | 人物故事 | 引入 → 转折 → 细节 → 启示 |
| 罗列推荐、资源、技巧 | 盘点清单 | 总览 → 逐条 → 总结 |
| 解释原理、验证说法 | 科普测评 | 疑问 → 原理 → 验证 → 结论 |
| 官方通知、规则声明 | 公告通知 | 事项 → 细节 → 联系方式 |
| 连续更新的固定栏目 | 连载栏目 | 栏目框架 + 每期变化点 |
