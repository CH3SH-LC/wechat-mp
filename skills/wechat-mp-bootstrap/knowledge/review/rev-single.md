# 单篇复盘（rev-single）

> 定位：发完一篇后，用一套固定框架把这篇讲清楚——数据好不好、好在哪、差在哪、下一篇改什么。复盘的目的不是给数据贴标签，是逼出"下一篇能直接用的改进点"。
> 调用时机：每篇发布后第 2 天数据稳定时做一次，一次 15–20 分钟。可以不写"复盘报告"那么正式，但至少要在脑内把框架走一遍，并落一条改进动作。

---

## 一、核心方法：四步复盘框架

把单篇复盘固定成四步，按顺序走，别跳步（跳步最容易得出"这篇不行/这篇很行"这种没用的粗结论）。

### 第 1 步：数据回顾——先看事实，不做评断

把这篇的关键指标抄下来，先只"记数"，不急着找原因。记以下 8 项（数值来源见「核心指标解读」）：

| 指标 | 这篇 | 近 10 篇均值 | 趋势（↑持平↓） |
|---|---|---|---|
| 阅读量 | __ | __ | __ |
| 打开率 | __ | __ | __ |
| 在看 | __ | __ | __ |
| 转发率 | __ | __ | __ |
| 收藏率 | __ | __ | __ |
| 完读率（估） | __ | __ | __ |
| 新增关注 | __ | __ | __ |
| 评论数 | __ | __ | __ |

> 抄完先停一下，只回答一句话：**这篇整体是好、是差、还是平平？** （对比近 10 篇均值）先有这个总判断，再进第 2 步。

### 第 2 步：内容拆解——拿放大镜看每一个环节

数据是"结果"，内容才是"原因"。把一篇拆成 4 个环节，每个环节做对的和差的都记下来：

| 环节 | 做对了什么 | 差在哪 | 下次要不要改 |
|---|---|---|---|
| 标题 + 封面 | __ | __ | __ |
| 开头（前 3 行） | __ | __ | __ |
| 正文结构与节奏 | __ | __ | __ |
| 结尾与引导 | __ | __ | __ |

拆解时每个环节都问两个问题："它有没有做对？"、"如果有问题，问题具体在哪？"——**问题要能落到下一个动作**，否则不算找到问题。例如"开头差"没用，"开头前 3 行没给读者非读不可的理由，讲了 2 行背景才进正题"才有用（这个动作：把首段压到 3 行内、直接抛钩子，见「开头钩子」条目）。

### 第 3 步：读者反馈——数据之外的真实声音

数据会骗人（比如刷量），读者的反馈不会。收集三处：
- **评论区**：读者在叫什么痛、在认可什么、在反驳什么——这些都是下一篇的真实选题。
- **后台私信/关键词回复**：有没有读者主动问细节、要模板。
- **转发时的配文**：你分享到朋友圈/群里时看读者怎么回应（尤其是真实转发，说明这一处戳中了）。

把最有价值的一条反馈记下来，标注"这根可做进下一篇".

### 第 4 步：改进点——每一项都落到"下一篇的一个可执行动作"

把第 2、3 步的问题转化为**3–5 条具体改进动作**，格式固定为「哪个环节 + 改成什么 + 在哪里验证」。

后面专门给「复盘记录格式」表。

## 二、可操作工具：复盘提问清单 + 复盘记录表

### 复盘提问清单（发完自问，逐项打勾）

**关于标题/封面：**
- [ ] 标题有没有说清"读者能得到什么"？还是只写了名词没写诱惑点？
- [ ] 标题有没有用上具体数字/具体场景/反常识？（比抽象更好）
- [ ] 封面第一眼能不能明白这篇文章讲什么？还是只放了个装饰图？
- [ ] 如果我是路人刷到，会点进去吗？

**关于开头：**
- [ ] 前 3 行有没有直接进正题？（还是 3 行后还在铺背景）
- [ ] 开头有没有"接住"标题的钩子？（读者是冲着标题点进来的）
- [ ] 有没有让读者觉得"这说的就是我"？还是通用开场白？

**关于正文结构：**
- [ ] 小标题/分段能不能让人 30 秒扫出全篇要点？
- [ ] 每段是不是太长读着累？（手机上 3–4 行为宜）
- [ ] 有没有"读者最想要的那一步/那个结论"？有没有被埋得太深？
- [ ] 干货部分有没有给出"具体怎么做"的步骤，而不是空讲道理？

**关于结尾：**
- [ ] 结尾有没有点题、给个收获总结？（让读者觉得没白读）
- [ ] 有没有埋一两个"值得转给朋友/值得点在看"的金句？
- [ ] 有没有引导关注、引导评论？引导得自然不自然？

**关于整体：**
- [ ] 这篇最想让读者记住的一个点是什么？我有没有在标题/开头/结尾反复强调它？
- [ ] 这篇我做得最好的一个环节是？（下次保持）
- [ ] 下一篇我只改一个地方，会改哪？

### 复盘记录格式（可直接填）

> 建议每篇存一行到你的复盘表/文档，月末汇总进「月度复盘」。

```
【日期】2026-XX-XX ｜ 标题：《____》
【类型】干货/观点/资讯/故事/……
【数据】阅读__ 打开__% 在看__ 转发__% 收藏__% 新增关注__ 评论__
【总判断】□好 □平平 □差
【做对】1____ 2____ 3____
【做差】1____ 2____
【读者反馈】________
【下篇改进动作】1.____ 2.____ 3.____
【这篇最值得复制的点】____
```

### 复盘快速口诀（记不住框架时靠这句）

> **一记数、二拆环节、三听反馈、四落动作**——数据回顾→内容拆解→读者反馈→改进点。任何一篇都能套这句走完，尤其适合日更账号的"简易版复盘"。

### 单篇复盘 vs 月度复盘的分工

| 维度 | 单篇复盘（本文） | 月度复盘（见「月度复盘」） |
|---|---|---|
| 范围 | 只这一篇 | 看整月/多篇 |
| 目标 | 找出一篇的具体改法 | 找出一个月的趋势和栏目成败 |
| 频率 | 每篇发完 | 每月一次 |
| 给下篇 | 1 条可执行改进 | 一整份选题和策略计划 |

单篇做扎实了，月度才有素材——两者是"积少成多"的关系，别用月度复盘替代单篇复盘。

## 三、示例（均为虚构数字）

**示例一：一篇"平平"的干货文，怎么挖出改进点。**

某账号发《新手如何三个月上手数据运营》，次日数据：阅读 1200（近 10 篇均 1500）、打开率 2%、在看 8、转发率 1.5%、收藏率 6%、新增关注 10。

复盘走四步：
- 数据回顾：阅读偏低、打开偏低，但收藏率 6% 高于平均（干货价值有），整体"平平偏下"。
- 内容拆解：标题《新手如何三个月上手数据运营》太通用，没给"三个月能做到什么"的诱惑点；开头写了 2 行背景才进正题；正文干货扎实但某关键的"实操命令"埋在很靠后的段落，读者很可能没读到。
- 读者反馈：评论 1 条"第三步那里能不能讲细一点"——印证正文那一步是最想要的。
- 改进动作：
  1. 标题改成带结果的写法：《三个月从零到上岗：新手数据运营实操清单》；
  2. 开头首段直抛结论"照着这份清单，三个月能独立做日报周报"；
  3. 把读者最想要的那一步提前到正文前 1/3，并配步骤表。

**示例二：一篇"阅读好但互动差"的观点文，问题在结尾。**

某观点文《加班到底有没有意义》阅读 9000（爆了），但转发率 0.8%、在看 5、评论 2。

复盘：
- 数据回顾：阅读远超均值但传播互动极低——典型"看过就算了，不敢分享/没有分享理由"。
- 内容拆解：标题钩子强、观点压得准，正文节奏也不错；但结尾只是淡淡一句"你怎么看"，没有给一个能"转发到朋友圈"的金句或立场结论，读者看完没有"替我说了"的爽感。
- 改进动作：结尾补一个斩钉截铁的立场句（如"与其问加班有没有意义，不如问这份班值不值得加"）+ 一句"认同的话点个在看，让老板看看"，给读者转发和点看的理由。

## 四、常见错误

- **错误 1：复盘出"这篇不错/这篇不行"就结束，没有改进动作。** 复盘没落到"下篇改哪里"，等于白复盘。每条结论必须能变成一句"下次我把 X 改成 Y"。
- **错误 2：只盯阅读量，其它数据不看。** 会漏掉"内容其实很好只是标题不行"或"标题党但内容空"这类关键区别（看数据组合见「核心指标解读」）。
- **错误 3：问题描述得太抽象。** "开头不行""结构太乱""结尾没力度"都是没用的结论。要具体到"开头第 3 行才进正题""第三个小标题读者要滑两屏才看到"。抽象原因给不出可执行的改法。
- **错误 4：把一次数据当规律。** 单篇波动大（可能撞上热点/节假/推送时间），一次低不代表方向错了。至少要 3 篇同类内容再下"这类内容不行"的结论（详见「月度复盘」）。
- **错误 5：完全不看本篇，凭感觉改。** 想一出是一出地"下次换个更抓眼的标题"，没有对照数据验证到底哪一环出问题。数据是你改方向的依据，不是摆设。

## 五、个性化空间

- **账号阶段不同，复盘重点不同**：新手账号刚起步，数据基数小、波动大，先重点复盘"内容一致性"（这篇像不像这个号该发的），别急着为阅读量焦虑；成长账号重点复盘"涨粉入口"（是哪类/哪篇在带来关注）；成熟账号重点复盘"完读率与取关"这类精细化指标。
- **内容类型不同，复盘侧重不同**：干货文重"读者实操部分有没有给到位、收藏率高不高"；观点文重"立场够不够鲜明、能不能引发转发和评论"；资讯热点重"时效够不够快、标题够不够抓人"；情感故事重"完读率和在看的共鸣，结尾有没有共情爆点"。判断依据：你写的类型天然决定了读者"最看重、最容易做"的动作，复盘就盯那个方向。
- **复盘频率可调**：日更型账号可以只对"数据有明显异常（超常好或超常差）"的篇做完整复盘，正常篇只记一行；周更型账号每篇都要过一遍框架。判断依据：你有多少精力分给复盘——宁可每篇都简单过，不要攒一个月的量。
- **复盘记录的载体可调**：可放表格、Notion、备忘录、甚至微信收藏夹一条笔记。重要的是"可回溯"——月末要能用它做「月度复盘」，所以务必标好日期、标题、关键数字和那条改进动作。
