# 选题维度索引（index-topic）

> 定位：解决「今天/下周写什么」。选题决定内容价值，是推文生产的上游。
> 用法：常规找选题读 topic-sources；规划长期内容读 topic-library 与 topic-serial；追热点读 topic-calendar；筛选题读 topic-criteria。
> 交叉：选题定稿后进入类型判断（index-type）；系列化选题与栏目体系配合（positioning/pos-columns）。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| topic-sources.md | 选题来源：热点/痛点/系列/读者提问/竞品/数据的挖掘方法 | 常规找选题时 |
| topic-library.md | 选题库管理：选题登记/分类/优先级/排期机制 | 建立长期选题池时 |
| topic-calendar.md | 热点日历：节日/行业节点/可预期热点的日历化规划 | 追热点与提前规划时 |
| topic-criteria.md | 选题判断标准：与定位相关度/读者价值/可行性评估 | 筛选候选选题时 |
| topic-serial.md | 系列化规划：把一个主题拆成多期的方法 | 规划系列内容时 |

## 使用顺序

1. 挖掘候选（topic-sources + topic-calendar）→ 2. 入库登记（topic-library）→ 3. 筛选定稿（topic-criteria）→ 4. 可系列化则规划（topic-serial）。
