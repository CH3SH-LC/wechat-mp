# 可读性与无障碍维度索引（index-readable）

> 定位：解决「读者读得舒不舒服、任何环境下都能读」。深色模式、对比度、字号行距、长文节奏。
> 用法：排版完成后用 read-check 终检；深色模式适配读 read-darkmode；配色时读 read-contrast。
> 交叉：字号行距的硬数值同时受间距规范约束（00-GUIDE 第三节）；配色对比度与 style/ 各风格色板配合。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| read-darkmode.md | 深色模式：微信暗黑下的背景/文字/边框反色表现与对策 | 发布前检查深色模式 |
| read-contrast.md | 对比度与色弱：正文 ≥4.5:1 底线、色弱友好配色 | 设计配色时 |
| read-typography.md | 字号行距舒适区：正文/标题/引用的字号行高建议 | 排版设定时 |
| read-rhythm.md | 长文阅读节奏：每屏信息密度、段落长度上限、视觉锚点 | 长文排版时 |
| read-check.md | 手机单栏阅读检查项：发布前逐项核对清单 | 每篇发布前 |

## 使用顺序

1. 排版时：read-typography 设定字号行距，read-contrast 检查配色；
2. 长文：read-rhythm 规划节奏；
3. 发布前：read-darkmode + read-check 终检。
