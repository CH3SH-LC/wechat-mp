# 模块 · 时间线

> 定位：用一条纵向的时间轴把"过去发生的一连串事情"按先后串起来，每个节点给出"时间 + 事件 + 结果"，让读者看到一段历程的推进脉络。时间线是**叙事**，不是指令——它讲"曾经怎样一步步走过来"，不是"你现在该怎么做"。
> 调用时机：发展历程、品牌故事、项目复盘、人物故事、阶段性成果汇报、大事记——当正文在"讲故事/回顾"而非"教操作"时。**时间线 vs 步骤要分清**：时间线讲"经历/历程/怎么做成的"，用「模块 · 步骤」才讲"读者现在照做的操作"。凡是讲经历、讲变化、讲复盘就用时间线；凡是"第一步…第二步…照着做"就用步骤条（见「模块 · 步骤」）。

## 一、可用写法与语法

写作语法用容器：`:timeline` 包住若干 `:node`。时间线在正文渲染为"竖向时间轴 + 时间标签 + 事件说明"。

**节点写作结构（每个节点固定三件套，缺一不可）**：
1. **时间标记**：节点开头的"时间/阶段名"（年份、月份、里程碑名），一眼就能把读者锚定在时间轴上。
2. **事件**：这个节点发生了什么（一句话，动词或现象开头，讲清"做了什么/出现了什么"）。
3. **结果**：因此带来什么变化、影响（补一行，常用"由此""这之后""随之"引出具体成果）。

**写法要点**：时间轴是按时间顺序排布的，但它真正隐含的是**因果关系**——读者要能在相邻节点之间看到"因为 A，所以 B"。如果节点太跳跃、彼此没有因果，整条时间线就退化成了流水账，读起来只是"一堆时间的罗列"。写完后从头过一遍：能不能在每个节点间填上"因此"？填不上的，说明节点选得不对。

**文字类默认写法**：
```markdown
:timeline
:node 2019 | 成立，定位短视频工具 | 由此确立了'简单好用'的产品路线
:node 2021 | 用户突破 1000 万 | 验证了工具路线是正确的
```

## 二、双模式表现（文字类/宣传类）

**文字类（文字排版优先）**：时间轴用**细线 + 小圆点节点**，时间标签用品牌单色，配色克制。圆点 10px、竖线细淡，节点内容直接落排、不套卡。适合复盘、报道、人物故事，读者感受到的是"一路走来的踏实感"——重点是脉络，不是装饰。文字类的核心是"让人看清先后与因果"，颜色只作最轻的标注，真正靠时间标签的加粗来分行。

**宣传类（视觉优先）**：时间轴**竖线贯穿 + 节点浅色小卡**，时间标签用主色加粗，节点圆点可放大或用纯色强调。适合品牌历程、发展里程碑、企业大事记，更有仪式感与"成果感"。宣传类的核心是"让这段历程显得有分量"，竖线 + 卡片把每个节点从正文里分出来，读者看到的是"一步步做成"的成果序列。

**两个模式在同一篇里只选其一**：文字类全文细线圆点、宣传类全文竖线卡片，不要前半篇圆点后半篇卡片——混用等于让读者以为"圆点和卡片是两种不同时间线"，严重破坏一致性（见模块组合铁律）。判断依据：这篇是"梳理脉络给人读"（文字类），还是"展示成果给人看"（宣传类）。

## 三、样式变体（4 种常用，具体参数）

以下 4 个变体覆盖常用场景。**所有时间线统一节点间 16px、块内容行高 1.75、整组底部 16px**。

**变体 A｜细线 + 圆点时间轴（文字类最稳·讲历程）**：
```html
<section style="padding:0;margin:0 0 16px;">
  <section style="display:flex;align-items:flex-start;margin:0 0 16px;">
    <section style="width:16px;flex-shrink:0;text-align:center;">
      <p style="width:10px;height:10px;border-radius:50%;background:#00b8a9;margin:6px auto 0;"></p>
    </section>
    <section style="flex:1;padding-left:12px;">
      <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#00b8a9;">2019</p>
      <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">成立，定位短视频工具。</p>
      <p style="margin:0;line-height:1.75;font-size:13px;color:#888;">由此确立了'简单好用'的产品路线。</p>
    </section>
  </section>
  <section style="display:flex;align-items:flex-start;margin:0;">
    <section style="width:16px;flex-shrink:0;text-align:center;">
      <p style="width:10px;height:10px;border-radius:50%;background:#00b8a9;margin:6px auto 0;"></p>
    </section>
    <section style="flex:1;padding-left:12px;">
      <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#00b8a9;">2021</p>
      <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">用户突破 1000 万。</p>
      <p style="margin:0;line-height:1.75;font-size:13px;color:#888;">验证了工具路线是正确的。</p>
    </section>
  </section>
</section>
```
- 参数：左列 16px 放 10×10px 圆点（`border-radius:50%`、色 `#00b8a9`、顶部 `margin:6px auto 0` 与首行对齐）；右侧内容 `padding-left:12px`；时间标签 13px 加粗主色；事件 14px `#333`；结果 13px 灰，三件套行高 1.75。节点间 `margin:0 0 16px`，最后一个节点 `margin:0`。

**变体 B｜左竖线贯穿 + 节点卡（宣传类·展示成果）**：用一整条竖线把所有节点串起来，每个节点收进一张浅色卡：
```html
<section style="margin:0 0 16px;padding-left:20px;border-left:2px solid #ffd9c8;">
  <section style="margin:0 0 16px;padding-left:0;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#ff6b35;">2020</p>
    <div style="background:#fff7f2;border-radius:8px;padding:10px 14px;">
      <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">完成首轮融资，技术团队扩张到 30 人。</p>
      <p style="margin:0;line-height:1.75;font-size:13px;color:#8a5a45;">由此开始全国扩张的序幕。</p>
    </div>
  </section>
  <section style="margin:0;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#ff6b35;">2022</p>
    <div style="background:#fff7f2;border-radius:8px;padding:10px 14px;">
      <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">直营门店开到 300 家。</p>
      <p style="margin:0;line-height:1.75;font-size:13px;color:#8a5a45;">刷新了行业的配速记录，验证可复制。</p>
    </div>
  </section>
</section>
```
- 参数：外层 `padding-left:20px;border-left:2px solid <淡化主色>`（本例 `#ffd9c8`）做整条竖线；每个节点时间标签 13px 加粗主色 `#ff6b35`，内容收进浅色卡（圆角 8px、padding `10px 14px`）；事件 14px、结果 13px 暖灰。节点间 16px，最后一节 `margin:0`。竖线是"贯穿"的横向锁定，各卡宽度自然撑满正文。

**变体 C｜"阶段名"式时间轴（项目复盘/成长）**：时间标签用"阶段名"而非年份，适合项目复盘与人物成长，只讲阶段不讲精确时点：
```html
<section style="margin:0 0 16px;padding-left:20px;border-left:2px solid #cdeee9;">
  <section style="margin:0 0 16px;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#00b8a9;">阶段一 · 冷启动</p>
    <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">先做最核心的 3 个功能，小范围邀请 200 人内测。</p>
    <p style="margin:0;line-height:1.75;font-size:13px;color:#666;">由此验证了需求真实性，留存 40%。</p>
  </section>
  <section style="margin:0;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#00b8a9;">阶段二 · 放大</p>
    <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">开放注册并投放获客，补齐推荐算法。</p>
    <p style="margin:0;line-height:1.75;font-size:13px;color:#666;">由此进入快速增长期，月活翻倍。</p>
  </section>
</section>
```
- 参数：阶段名 13px 加粗主色，写在竖线右侧；事件 14px `#333`、结果 13px 灰 `#666`；整条竖线 `2px solid #cdeee9`。节点间 16px，最后一节 `margin:0`。阶段名式不给精确时间，反而更适合"想讲做了什么、结果如何"的复盘。

**变体 D｜月份精确到日期的"发布节点"轴（资讯/版本/记录）**：时间标签用"年月+日"、节点做成小方块，适合发布记录、版本日志、周期通报：
```html
<section style="margin:0 0 16px;padding-left:20px;border-left:2px solid #b8d0ff;">
  <section style="margin:0 0 16px;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#2777ff;">2024 · 03 · 12</p>
    <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">上线一键排版，支持 12 个常用模块。</p>
    <p style="margin:0;line-height:1.75;font-size:13px;color:#666;">由此单篇排版耗时从 40 分钟降到 3 分钟。</p>
  </section>
  <section style="margin:0;">
    <p style="margin:0 0 4px;line-height:1.5;font-size:13px;font-weight:bold;color:#2777ff;">2024 · 09 · 08</p>
    <p style="margin:0 0 4px;line-height:1.75;font-size:14px;color:#333;">上线多平台一键分发。</p>
    <p style="margin:0;line-height:1.75;font-size:13px;color:#666;">由此实现了当天全网覆盖，同步率达 100%。</p>
  </section>
</section>
```
- 参数：时间标签 "年 · 月 · 日"（用 ` · ` 分隔，13px 加粗主色 `#2777ff`）；竖线冷蓝 `#b8d0ff`（淡化的主色）；三件套字号同上。日期精确的好处是"给到证据感"，适合读者要"看到具体哪天做了什么"的发布/版本/记录文；缺点是不可太多，精确到日只适合少数关键节点。

## 四、使用时机与位置

- **品牌/公司历程**：大事记式时间线，展示发展成果，增强信任——"我们不是一夜成名，是一步步做成"。
- **项目复盘**：阶段式时间线（变体 C），讲清"每个阶段做了什么、结果如何"，最有说服力。
- **人物/成长故事**：个人经历的时间线，让读者感同身受看到"成长脉络"。
- **发布/记录文**：按时间推进的报道、产品版本、时间节点通报（变体 D）。
- **位置**：通常放在正文中段或偏后，作为"佐证/背景"给前面的论述补充时间维度；应置于观点或行动号召之前——先讲清"怎么来的"，再顺势引出"所以现在该怎样/为什么值得关注"。不要一开局就甩时间线，读者还没进入"回顾"的心境。

## 五、风格适配（3-4 个例子）

- **极简/商务**：变体 A 细线圆点，主色墨黑 `#333`，时间标签 13px 深灰，全黑白，事件与结果都用灰阶，靠时间的疏密出节奏。
- **国潮/品牌史**：整条竖线朱砂红 `#c0392b`、节点圆点金色 `#d4af37`，时间标签加粗，像"史册/家谱"，厚重可信，适合老字号讲故事。
- **科技/数码**：竖线冷蓝 `#0a84ff`、节点做成小方块（`border-radius:4px` 而非圆），时间标签用等宽感写法，像版本发布日志，适合产品/技术号讲迭代。
- **教育/故事**：阶段名式变体 C，暖色调浅底卡，时间标签前用花草植物图案点缀（`![小草](art://sprig-grass)`），轻松叙述成长，适合亲子/成长/个人号。

**风格统一原则**：时间线的颜色与样式要和整篇其他模块（卡片、气泡、步骤、标题）保持一致——卡片是浅底圆角，时间线的节点卡也用同色系浅底；标题是国潮红金，时间线竖线也用朱砂红。风格是"全篇穿的一套衣服"，时间线不能单独换风格。

## 六、间距与尺寸（遵守硬规范）

- **整组与前后块**：时间线整组底部 `margin:0 0 16px`（块距基线 16px），作为独立一个"块"参与正文排版，不要贴死上一段。
- **节点间距**：节点与节点 16px（块距），最后一个节点 `margin:0`，避免末尾多余空白。
- **圆点/竖线**：圆点直径 10px（变体 A）、竖线宽 2px（变体 B/C/D）。竖线粗不要超过 2px，太粗会喧宾夺主。
- **节点卡内边距**：节点卡 `padding:10px 14px`、圆角 8px（内容到卡边距满足硬规范 ≥12px 的近似，取 10px 更贴合小卡）。
- **内容字号**：时间标签 13px 加粗、事件 14px、结果 13px；行高正文与块内统一 1.75，仅时间标签可用 1.5（它是一行）。
- **整组不做左右内边距**：圆点式左列占 16px；竖线贯穿式用 `padding-left:20px + border-left:2px`（这 20px 是内部留给竖线与文字的空间，不算正文页边距）。
- **时间标签上下**：事件前 `margin:0 0 4px`，与事件保持 4px 呼吸；结果与事件也 4px。

## 七、配色配合（与全篇色盘协同）

- **竖线 = 主色的淡化档**：竖线颜色通常用主色的浅一档（如主色 `#00b8a9` 用 `#cdeee9`、主色 `#ff6b35` 用 `#ffd9c8`），时间标签才用主色实色——"线是底色、标签是强调"，一浓一淡才成层次。
- **节点卡与浅底系同源**：宣传类节点卡的浅底，要与全篇卡片、气泡的浅底同色系（都是同一主色的极浅档），别出现"卡片是青、时间线卡是红"的割裂。
- **结果用灰、事件用正文黑**：结果统一灰 `#888/#666`、事件用正文黑 `#333`，让时间轴"脉络感"退后、事件与结果由深到浅分层，不抢正文注意力。
- **避免五颜六色一个节点一个色**：全篇时间线 + 若干节点，只用一个主色一个灰，最多加一个警示色；彩虹时间线会让因果被彩色冲散。主色 ≤2 个最佳。
- **与正文关系**：时间标签的文字色要与所在底色对比度 ≥4.5:1（见「可读性」维度），浅底配深主色字最稳，勿用浅黄字配白底。

## 八、微信兼容注意

写时间线时的"可用子集"与"要绕开的坑"（微信富文本编辑器）：

- **可用**：`display:flex`（可做"左列圆点 + 右侧内容"的横向排列）、`border-left`（做竖线最稳，不依赖定位）、`border-radius`（8/4/50%）、`background` 纯色、`padding/margin/font-size`、`line-height:1.75`。
- **尽量别用**：`position:absolute` 做时间轴上的角标/装饰（旧端会飞逸）；伪元素 `::before/::after`（编辑器多剥除，竖线/圆点别用它去画）；竖线只需要纯色 `border-left`，无需背景渐变。
- **圆点画法**：圆点用"独立的空 `<p>` 配 `width:10px;height:10px;border-radius:50%`"最稳，不要指望用文字符号字形对齐，也不要依赖定位堆叠。
- **竖线做法**：外层用 `padding-left:20px;border-left:2px solid <色>` 一次性完成"预留空间 + 贯穿线"，比手动在每节点中间插一截线可靠得多。
- **通用兜底原则**：时间轴最关键的信息（时间、事件、结果）都要靠"文字"承载，竖线、圆点、浅卡都只是装饰——装饰失效后，读者仍能从文字读懂时间顺序，才算合格。

## 九、密度限制（重要）

- **节点 ≤8 个**：时间轴超过 8 个就滑得太长，读者记不住前后。精选"转折点"节点，砍掉流水账——不是所有年份都要上，只有"改变了走向"的才值得留。
- **一屏 2-3 个节点**：让每个节点有独立呼吸空间，别三四个挤满一屏；读者要能逐条读完整片才滑下一屏。
- **每个节点结果 1 行**：结果别写两行以上，时间轴要"脉络感"不是"详细报告"；结果太长就提进事件里或另起一个节点。
- **三件套齐全**：每个节点都是"时间 + 事件 + 结果"缺一不可，缺结果的节点是半成品，宁可不放；三个都全，节点之间的因果才能被读出来。

## 十、常见错误（反例 + 正解）

- **反例**："2021 → 做了改版。2022 → 又改了一次。"（只有时间+事件没有结果，也没有因果）→ **正解**："2021 上线新版界面，由此用户停留时长提升 20%。 2022 优化冷启动，由此次日留存翻倍。"每个节点补上"结果"，因果就立住了。
- **反例**：把 12 个节点全堆上去，从 2015 一路铺到 2025，每屏五个 → **正解**：只留 4-6 个转折点，每个都是"改变了走向"的关键节点，一屏 2-3 个。
- **反例**：用步骤条写历程——"步骤一 成立、步骤二 融资、步骤三 上市" → **正解**：讲"经历/如何做成"用时间线模块；「模块 · 步骤」只服务"让读者照着做"的可执行动作。历程是回顾，"步骤一/二/三"是命令。
- **反例**：时间标签和大段事件全用 16px 正文，读者分不清哪是时间哪是事件 → **正解**：时间标签 13px 加粗主色、事件 14px、结果 13px 灰——三层分明，一眼分层。
- **反例**：一个节点塞 5 行满溢，结果写三行还带补充 → **正解**：每节点事件 1-2 行、结果 1 行，保持"脉络"轻快；内容太重就拆成两个节点。
- **反例**：竖线用 `position:absolute` 或伪元素去画，发布后错位/丢失 → **正解**：竖线用外层 `border-left:2px`，最稳且永不跑位。

## 十一、示例（可用骨架，标注可替换处）

```markdown
:timeline
:node 2019 | 成立，定位短视频工具 | 由此确立了'简单好用'的产品路线
:node 2021 | 用户突破 1000 万 | 验证了工具路线是正确的
```

## 十二、个性化空间（可调参数与判断依据）

- **时间标签形式**：年份 / 月份 / 阶段名 / 年 · 月 · 日。判断依据：项目复盘、人物成长→阶段名更有"复盘感"；纯历史→年份更直白；发布/版本记录→精确到日给足证据感。阶段名 > 年份 > 精确日期，看你想强调"里程碑"还是"精确时点"。
- **节点样式**：圆点（轻） / 节点卡（重，宣传类） / 小方块（硬核科技）。判断依据：情怀叙事用圆点，成果展示用节点卡，版本日志用小方块。
- **竖线颜色**：主色淡化档（柔）/ 主色实线（强）。判断依据：时间轴是不是本段视觉主角——是就实线加粗、不是就淡化。
- **节点数量与疏密**：少而疏（每节点独立成块，适合复盘强调节点）/ 密（连续脉络，适合一口气看完的大事记）。判断依据：读者需要"单个节点聚焦"还是"整条脉络一气呵成"，叙事张力决定。
- **结果颜色梯度**：统一灰 `#888`（克制）或随主色加深一档（更强调成果）。判断依据：成果展示可让结果用主色深档，情怀叙事保持灰更沉稳。
- **时间标签是否带装饰**：轻松账号可在阶段名前用花草图案（`![小草](art://sprig-grass)`），严肃商务号不加。判断依据：账号语气——活泼用植物图案点缀，专业保持纯文字。
