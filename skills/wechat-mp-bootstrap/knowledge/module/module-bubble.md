# 模块 · 重点气泡

> 定位：用一块带色底的"气泡"把某段话从正文里拎出来，让读者一眼抓住"这里重要/要小心/能学到东西"。五种语义（说明、技巧、注意、警示、重点）各有一个专属颜色与 CSS 形状标记。
> 调用时机：正文有关键信息需要单独强调时——一句核心结论、一条操作小技巧、一处易踩的坑、必须禁止的事、全文最重要的那句话。**每个手机屏（约 6-8 行正文）最多 ≤2 个**，气泡是"压舱石"，不是铺路砖。轻量提示用普通高亮或列表，别动不动上气泡。

## 一、可用写法与语法

写作语法用引用符号 `>` 加语义标记：`> [!NOTE]`、`> [!TIP]`、`> [!WARN]`、`> [!DANGER]`、`> [!KEY]`。五个语义对应五种情绪："做标记"一律用 1 2 3 序号文字、CSS 圆点/方块/菱形，或 art:// 植物图案（`![小草](art://sprig-grass)` 等），不用 emoji 与图标字符。

| 标记 | 中文名 | 形状标记（CSS） | 表达的情绪 | 一句话区分 |
|---|---|---|---|---|
| `> [!NOTE]` | 说明 | 空心圆 16px + 细边框 2px + 中性色 | 中性补充 | 只是"顺带告诉你"，不紧急 |
| `> [!TIP]` | 技巧 | 实心圆 10px + 主色 | 可学干货 | "这么做更好"，想让他记方法 |
| `> [!WARN]` | 注意 | 旋转 45deg 方块 10px + 警示橙 | 转折/易错 | "这里别走岔"，提醒但不致命 |
| `> [!DANGER]` | 警示 | 方形细边框 16px + 红 | 强阻断 | "千万别这么干/会出大事"，最重 |
| `> [!KEY]` | 重点 | 实心菱形 10px + 主紫 | 结论/金句 | "整段最核心一句话"，压轴 |

**语义选择速查**：不确定用哪个时，问一句"这句话出问题会怎样"——完全没事用 NOTE，做错只是浪费用 TIP/WARN，会造成损失/违规则用 DANGER，是全文要让人带走的那句用 KEY。五种语义优先级从轻到重：`NOTE < TIP < WARN < DANGER`，`KEY` 是另一个维度（结论维度），不与轻重冲突。

**写法铁律**：
- 每个气泡只装一个意思。文字控制在 **1-3 行**（约 20-50 字），装不下就拆成两句或改用普通段落 + 卡片归纳。
- 首句是"标题"式短句（放在形状标记后），如"提示：""进阶方法"，后面才是内容。没有标题句的气泡像没领子的衬衫，松垮。
- 使用 `> [!语义]` 时，编辑器会自动套用该语义的默认样式（左竖条浅底）。需要更强的视觉（宣传类实色块）时，改用"内联样式手写版本"（见下），两者的内容写法一致。
- **全文语义一致**：一旦选定某个语义表达某件事，全篇这类信息都用同一种语义（别这次"缺货"用 WARN 下次用 NOTE），读者才能建立"形状即情绪"的默契。

## 二、双模式表现（文字类/宣传类）

**文字类（文字排版优先）**：细边浅底、左竖条，色轻、不喧宾夺主。底色用主色的极浅色（如 `#f4f0ff`），左边一条 3-4px 实色竖条，文字用同色的深一档（如 `#4a1f8a`）。形状标记用小号 CSS 圆点/方块。适合观点文、干货文、资讯文——强调但不打断阅读。文字类的核心是"提醒有这段"，颜色只是最轻的暗示，真正靠的是左竖条与浅底的"分块"。

**宣传类（视觉优先）**：整块实色底或深底、白字、圆角。底色用低饱和纯色（如 `#6b4fc4`），白字加粗，形状标记放大号、更醒目。适合促销、活动、新品发布、运营号——强调就该"跳出来"。宣传类的核心是"这段就得亮出来"，纯色底 + 白字 + 细边框把信息从正文里"顶"出来。

**两个模式在同一篇里只选其一**：文字类全文浅底左竖条，宣传类全文实色底，不要一半浅底一半实色——混用等于让读者以为"浅底和实色是两种不同语义"，严重破坏一致性（见模块组合铁律）。

## 三、样式变体（5 种常用，具体参数）

五语义 x 双模式 = 至少 10 种可组合，以下给最常用的 5 种模板。**所有气泡统一 `padding:14px 16px`、行高 1.75、`border-radius` 右侧用 8px（左竖条）或整块 10px（无竖条）**。

**变体 A｜左边条淡底（文字类·最常用）**——适用：中性说明、小技巧、普通重点：
```html
<div style="background:#eef6ff;border-left:3px solid #0ba89b;padding:14px 16px;border-radius:0 8px 8px 0;">
  <p style="margin:0;line-height:1.75;font-size:14px;color:#1a4a66;"><span style="display:inline-block;width:8px;height:8px;border-radius:50%;background:#0ba89b;vertical-align:1px;margin-right:6px;"></span>提示：每周留半天慢读，比每天刷一小时更有效。</p>
</div>
```
- 参数：`border-left:3px`；`border-radius:0 8px 8px 0`（右圆左直）；文字 14px；色 `#1a4a66`。底色 `#eef6ff` 是青色系极浅，五个语义换底色即可（TIP 橙系 `#fff8e8`、WARN 红系 `#fdf2f2`、KEY 紫系 `#f4f0ff`）。

**变体 B｜整块实色底（宣传类·TIP/KEY）**——适用：核心干货、进阶方法、行动号召：
```html
<div style="background:#e56b2f;padding:14px 16px;border-radius:10px;">
  <p style="margin:0;line-height:1.75;font-size:15px;color:#fff;font-weight:600;"><span style="display:inline-block;width:9px;height:9px;transform:rotate(45deg);background:#fff;vertical-align:1px;margin-right:6px;"></span>进阶方法</p>
  <p style="margin:6px 0 0;line-height:1.75;font-size:14px;color:#fff7f0;">把复杂流程拆成 3 步，每步一个动词开头，读者才愿意照着做。</p>
</div>
```
- 参数：实色底 `#e56b2f`；标题 15px 白字加粗，正文 14px 米白（`#fff7f0`）；标题与正文间距 6px。实色方向与字号统一稳定，别乱换底色深浅。

**变体 C｜带细边装饰 / 右上角标**——适用：想更活泼、或点名"这是新品/限时"：
```html
<div style="position:relative;background:#f4f0ff;border:1px solid #e2d9f5;border-radius:12px;padding:16px 18px;">
  <div style="position:absolute;top:0;right:0;background:#6b4fc4;color:#fff;font-size:12px;border-radius:0 10px 0 8px;padding:2px 10px;">NEW</div>
  <p style="margin:0;line-height:1.75;font-size:14px;color:#4a1f8a;"><span style="display:inline-block;width:10px;height:10px;transform:rotate(45deg);background:#6b4fc4;vertical-align:1px;margin-right:6px;"></span>重点：新增了自动排版功能，一次性满足全年封面需求。</p>
</div>
```
- 参数：整块淡紫底圆角 12px、`border:1px solid` 细边、内部 padding `16px 18px`（比默认大，给角标留空间）；角标用 `position:absolute` **必须父容器带 `position:relative`**，圆角 `0 10px 0 8px` 贴合顶角。
- **风险注意**：绝对定位在部分旧客户端会飞逸，稳妥备选是把角标改写为行内 `<span style="background:#6b4fc4;color:#fff;border-radius:5px;padding:2px 8px;margin-right:6px;">NEW</span>` 放在标题前，不依赖定位、永不跑飞。

**变体 D｜警示边框强阻断**——适用：合规红线、必须立即停止：
```html
<div style="background:#fff2f2;border:1px solid #d33;padding:14px 16px;border-radius:10px;">
  <p style="margin:0;line-height:1.75;font-size:14px;color:#a11;font-weight:600;"><span style="display:inline-block;width:14px;height:14px;border:2px solid #d33;vertical-align:-2px;margin-right:6px;"></span>警示：医疗功效类词汇不得出现在正文，发布前自查。</p>
</div>
```
- 参数：边框 `1px solid #d33`、整块圆角 10px、文字加粗、色 `#a11`，整篇气泡里视觉权重最高。较文字类其他语义在"左竖条"基础上再叠加了整圈边框，相当于"双重强调"。

**变体 E｜同色系深浅双行（KEY 结论式）**——适用：全文收尾、核心价值陈述：
```html
<div style="background:#6b4fc4;border:1px solid #5a3caa;padding:14px 16px;border-radius:10px;">
  <p style="margin:0;line-height:1.75;font-size:16px;color:#fff;font-weight:700;"><span style="display:inline-block;width:10px;height:10px;transform:rotate(45deg);background:#fff;vertical-align:1px;margin-right:6px;"></span>一句话记住本文</p>
  <p style="margin:6px 0 0;line-height:1.75;font-size:14px;color:#f4efff;">真正拉开差距的，是每天愿意多读 20 分钟正文的那批人。</p>
</div>
```
- 参数：首句 16px 白字、副句 14px 淡紫；`border:1px solid` 同色深一档描边增强"压轴"感。KEY 是唯一允许上 16px 的气泡（它是结论、是题眼，值得最重的字号）。

**变体 F｜品牌单色系「一张卡五档深浅」**——适用：品牌克制风，不想用多彩实色：
```html
<div style="background:#f0f5ff;border-left:3px solid #2f6fed;padding:14px 16px;border-radius:0 8px 8px 0;">
  <p style="margin:0;line-height:1.75;font-size:14px;color:#1b3a66;font-weight:600;"><span style="display:inline-block;width:9px;height:9px;transform:rotate(45deg);background:#2f6fed;vertical-align:1px;margin-right:6px;"></span>重点：品牌蓝单色系，五语义全用一套蓝，只改深浅与边框粗细。</p>
</div>
```
- 参数：单品牌色 `#2f6fed`，五档深浅靠背景透明度改写（极浅 `#f0f5ff` → 浅 `#dbe7ff` → 中 `#b8d0ff` → 实色 `#2f6fed`）；`border-left` 3px（重语义 4px）+ 文字加深一档表达轻重。判断依据：品牌色够不够撑起"从轻到重"的梯度——能就用，最专业。

**变体 G｜提示 vs 成品对照双气泡**——适用：教学「错误示范 + 正确示范」：
```html
<div style="background:#fff2f2;border-left:3px solid #9a281f;padding:14px 16px;border-radius:0 8px 8px 0;margin:0 0 16px;">
  <p style="margin:0;line-height:1.75;font-size:14px;color:#8a2418;"><span style="display:inline-block;width:14px;height:14px;border:2px solid #9a281f;vertical-align:-2px;margin-right:6px;"></span>反例：标题堆满关键词，读起来像报菜名。</p>
</div>
<div style="background:#eef6ff;border-left:3px solid #0ba89b;padding:14px 16px;border-radius:0 8px 8px 0;margin:0 0 16px;">
  <p style="margin:0;line-height:1.75;font-size:14px;color:#1a4a66;"><span style="display:inline-block;width:8px;height:8px;border-radius:50%;background:#0ba89b;vertical-align:1px;margin-right:6px;"></span>正例：一个情绪钩子 + 一个关键词，标题就立住了。</p>
</div>
```
- 参数：反例用红系左条 + 方形细边框标记、正例用青系左条 + 实心圆标记，一上一下成对；底部各留 16px 块距。判断依据：「反例/正例」并列时，用一红一青两个气泡比单气泡更强，且同屏仍 ≤2 个。反例语义选 `WARN/DANGER`，正例选 `TIP/KEY`。

## 四、使用时机与位置

- **开篇**：核心卖点/一句结论，紧跟钩子段之后（宣传类首选，制造"第一印象冲击"）。文字类慎用，连续两屏出现气泡会显拥挤。
- **正文中部**：每一段干货的小结、易错点警告（`WARN`/`TIP` 密集区）。
- **结尾**：`DANGER`（合规警示）放文末提示风险；`KEY` 收尾一句话点题，深化记忆。
- **位置顺序**：`TIP` 跟在"做法"段落后面，`WARN` 跟在"易错点讲解"后面，别把警示挂在毫无铺垫的地方——读者不知道你为何突然紧张。
- **位置与节奏**：气泡出现在"读者最需要被拉回注意力"的位置。长文每 300-500 字的自然段落切换前，可用一个气泡做小结锚点；短章两三个气泡足矣。
- **不要气泡开场且不要气泡结尾连排**：开篇气泡要"一击即中"，结尾 KEY 只留一个"压轴"，避免全篇开头中段结尾都亮，失去层级。
- **按"读者此刻的心理"排布**：开篇读者好奇→给 KEY 一句结论吊胃口；中段读者想学→给 TIP/方法；中后段读者有顾虑→给 WARN/注意；结尾读者要决策→给 DANGER（红线）或 KEY（点题）。让气泡出现的位置正好接住读者当下的情绪，而不是机械地在每节末尾各挂一个。
- **气泡是"锚点"不是"段落"**：气泡之后最好紧跟一段正常正文把它展开；气泡+大段正文+气泡的节奏比"连续几个气泡夹一行字"健康得多。气泡负责"拎出来"，正文负责"讲透"。

## 五、风格适配（3-4 个例子）

- **极简/科技风**：只用变体 A，左竖条换成细线 `border-left:2px solid #333`，底色 `#fafafa`、文字 `#444`，形状标记去掉，靠字号与字重（16px 加粗）表达重点。克制到极致。
- **国潮风**：底色用米白 `#fff7ef`、左竖条用朱砂红 `#9a281f`、文字 `#5a3520`，形状标记换水墨风方块（旋转 45deg 方块 span）；营造"印章"感。
- **港风/复古**：用变体 D 的粗边框思路，边框 `2px dashed #b23a48`、底色 `#fff4e6`，文字 `#4a1a1a`，"告示"感强，适合讲规矩/避坑。
- **童趣/活泼**：变体 C 角标 + 大圆角 14px、底色 `#fff3e0`、左竖条 `#ff8a3d`，形状标记用 CSS 圆点 + art:// 植物图案（`![花枝](art://blossom-branch)`），文字 14px 米棕，适合教育号/亲子号。

**风格统一原则**：气泡的风格要与整篇其他模块（卡片、列表、标题）保持一致——如果卡片用的浅底圆角，气泡也用浅底左竖条的同色系；如果标题是实色块，气泡也跟随实色块。风格是"全篇穿的一套衣服"，气泡不能单独换风格。

## 六、间距与尺寸（遵守硬规范）

- **气泡与前后块距离**：底部 `margin:0 0 16px`（块距基线 16px）。不要用一个挨一个；气泡后若紧跟另一个气泡，中间仍是 16px。
- **行高**：气泡内文字统一 `line-height:1.75`（与正文一致，保证扫读节奏不乱）。
- **内边距**：气泡 `padding:14px 16px`（硬规范）；实色/带角标的气泡可放宽到 `16px 18px 14px`。
- **圆角**：有左竖条用 `0 8px 8px 0`（右侧柔和）；无竖条整块用 10px；圆角不能超过内容高度一半。
- **标题内距**：气泡内首句与副句间距 6px；气泡本身不计入标题上下留白规范（它是"整体块"）。
- **标记与文字距离**：形状标记（CSS 圆点/方块）后加一个半角空格即可，不必用 margin。

## 七、配色配合（与全篇色盘协同）

气泡不是独立元素，它的颜色必须从全篇色盘里"取"。推荐的做法是：**一篇正文只用 1 个主强调色贯穿所有强调点**（卡片、气泡、列表符号、高亮共用同一个主色）。

- **单主色用法**：整篇气泡统一用一个主色（如青），五语义靠"深浅与边框强弱"而非换色来分轻重——浅青 `#eef6ff` 是 NOTE、实色青块是 TIP/KEY、上加红边框是 WARN/DANGER。这样最克制、也最容易维护。
- **双主色用法**：一个主色 + 一个警示色（如"主色青 + 警示红"）。强调重点用青，警告/合规用红。情感对比较强，适合宣传类，但红色只能是少数点。
- **品牌色替换**：把五个语义的默认色整体替换成品牌主色体系（一套品牌色对应五档明度深浅）。判断依据：品牌色能否连贯地表达"从轻到重"的梯度，若只能挤出一个色就退回单主色+灰色。
- **避免**：五种语义五颜六色地全换上（青橙红紫蓝开会），读者分不清轻重，也显得"彩虹排版"。全篇气泡颜色 ≤2 个主色最佳。
- **与正文关系**：气泡底/边色要与正文文字 `#333`、正文灰 `#555` 区分度足够（可读性角度，气泡文字与底色对比度 ≥4.5:1，见「可读性」维度）。浅底配深字最稳，深底实色配白字也稳定。

## 八、微信兼容注意

写气泡时的"可用子集"与"要绕开的坑"（微信富文本编辑器）：

- **可用**：`background`（纯色）、`border` 1px 实线/虚线、`border-radius`（4/8/10/12/14)、`padding/margin/line-height:1.75/font-size`、`display:inline-block`、简单 `display:flex`（卡内居中）。本规范统一纯色 + 细边框，微信端渲染最稳。
- **尽量别用**：`backdrop-filter`（基本不生效、可能整块变白）、`border-image`/`outline`（定位不稳）、伪元素 `::before/::after`（编辑器多剥除）。本规范禁投影——要"浮起/强调"一律用细边框 + 留白 + 圆角达成，不写投影样式。
- **位置定位风险**：`position:absolute` 做角标必须在父级 `position:relative` 内，且旧客户端可能飞逸——稳妥备选用行内 `<span>` 角标。
- **纯色兜底**：本规范不推荐渐变、不推荐投影，统一纯色底 + 细边框。若沿用旧样稿仍有渐变兜底说明，一律按"纯色 + 细边框"改写为准。
- **通用兜底原则**：任何一种装饰"锦上添花"时，优先保留"纯色底 + 实线边框 + 圆角"组合——装饰失效后内容仍然可读、仍成块。

## 九、密度限制（重要）

- **每屏 ≤2 个气泡**：一个手机屏（约 6-8 行正文）内最多 2 个气泡，否则满屏色块=失去重点。全文一篇通常 3-5 个足矣。
- **同屏两个气泡需分工**：一个 `KEY`/`TIP`（亮）+ 一个 `WARN`/`NOTE`（收敛），不要连放两个实色亮块（两个实色亮块会同归于尽，读者分不出谁更重要）。
- **气泡不与其他强装饰叠加同一屏**：这一屏已有花纹色带 + 大字号标题，就别再放第二个气泡了（见模块组合铁律：气泡 ≤2、徽章 ≤3）。
- **能用列表/高亮装下的并列小点，不上气泡**：气泡是"单体强调"，列表是"并列罗列"。气泡数量失控会稀释所有重点。
- **五种语义不必都用**：一篇通常只用 2-3 种语义（如 TIP + KEY + 一次 WARN）。五种全上会像交通信号灯开会，读者情绪被拉得忽上忽下。

## 十、常见错误（反例 + 正解）

- **反例**："提示：水果含糖，吃多了会胖，而且维生素C在烹饪中可能流失，所以建议每天吃，但是也要适量。"（一个气泡塞了 4 个意思）→ **正解**：一气泡一个点，拆成"每天吃 200g 水果即可"与"别再问吃水果会不会胖——适量都不会"两个气泡。
- **反例**：全文放了 9 个气泡，滑到第三屏满屏底色 → **正解**：保留 ≤2 屏最关键的 3-5 个，其余改成普通加粗或列表。
- **反例**：宣传类气泡写"注意：本活动最终解释权归我方所有"用实色大色块 → **正解**：免责声明用 `NOTE` 浅底小字，别用最强的实色视觉表达最弱的免责信息。
- **反例**：气泡文字 28px 大红加粗满溢 → **正解**：气泡最重字体 ≤16px，靠颜色+底色+边框三个通道表达（强调必须 ≥2 通道：颜色 + 字重/底色）。
- **反例**：把图片、整个段落都塞进气泡 → **正解**：气泡只装 1-3 行句，长素材交给卡片（见「模块 · 卡片」），大图交给图片模块。
- **反例**：同一篇里 NOTE 用"浅蓝条 + 青"，WARN 也画得浅淡没差异，读者分不清哪个更紧急 → **正解**：让 DANGER/WARN 视觉明显重于 NOTE：加重边框、加粗、或挂方形细边框标记，轻重分级要能被一眼读出。

## 十一、示例（可用骨架，标注可替换处）

```markdown
> [!NOTE]
> 提示：本方法对新手尤其友好，配合文末清单使用效果更佳。
```
（文字类默认样式：浅底左竖条。**可替换**：语义标记 `NOTE`、正文文字。语义可从 NOTE/TIP/WARN/DANGER/KEY 更换，每个自动配不同默认配色。）

```html
<!-- 较强的重点强调（"核心干货"场景适用）：可替换语义/颜色 -->
<div style="background:#0ba89b;border:1px solid #09877d;padding:14px 16px;border-radius:10px;margin:0 0 16px;">
  <p style="margin:0;line-height:1.75;font-size:15px;color:#fff;font-weight:600;"><span style="display:inline-block;width:9px;height:9px;transform:rotate(45deg);background:#fff;vertical-align:1px;margin-right:6px;"></span>新知速递</p>
  <p style="margin:6px 0 0;line-height:1.75;font-size:14px;color:#ffffff;">这里放一句最想让读者记住的新信息。</p>
</div>
```
**可替换处**：实色 `#0ba89b`（描边 `#09877d`）；首句 15px/末句 14px；圆角 10px。判断依据：是不是"整段唯一想让他带走的那句"——是才值得用实色亮块；如果是中性补充，降级为变体 A 浅底。

**五种语义组合示例（一篇的稳妥用法）**：开篇一个 `KEY` 结论 → 中段一个 `TIP` 干货 → 收尾一个 `WARN` 避坑（或 `DANGER` 合规）。三个气泡三种情绪，正好覆盖"结论 / 方法 / 雷区"，密度也在 1 屏 ≤2 的规则内。

**选语义速查（不确定用哪个时念一遍）**：
```markdown
> [!NOTE]  说明：只是顺带告诉你，不紧急
> [!TIP]   技巧：这么做更好，想让你记住方法
> [!WARN]  注意：这里别走岔，提醒但不致命
> [!DANGER] 警示：千万别这么干，最重
> [!KEY]   重点：整段最核心一句，压轴
```
**可替换处**：五个语义标签及各自一句话。判断依据：选不定时把这五句依次读一遍，看哪句最贴当前想强调的信息，再把那句改成真实内容。

## 十二、个性化空间（可调参数与判断依据）

- **五种语义颜色**：默认 青 `#0ba89b`/橙 `#e56b2f`/红 `#e0532a`/深红 `#9a281f`/紫 `#6b4fc4`。**可调**：换成品牌主色（如你的账号是绿色品牌，TIP 实色块改绿）。判断依据：品牌色能区分情绪层次就换，全篇都用同色就失去"警告/重点"的分级，不推荐。
- **左竖条宽度**：文字类 3-4px；极简风 2px。判断依据：越粗越有仪式感，但也越重，普通 NOTE 用 3px 即可。
- **圆角大小**：文字类右侧 8px；活泼/童趣可用 14px。判断依据：营造的风格越软圆角越大，商务/极简收小。
- **形状标记选择**：同一语义形状标记全篇固定（别一会儿实心圆一会儿菱形）。判断依据：账号语气轻松可用 art:// 植物图案（`![花枝](art://blossom-branch)`），严肃号可去掉标记只留字。
- **气泡文字密度**：1-3 行。判断依据：内容越关键越可以放 2-3 行完整表达，琐碎提示压到 1 行。
- **角标/装饰有无**：需要"点名某某事"才加 `NEW`/`限时` 角标。判断依据：角标是额外信息通道，普通气泡不加，保持气泡本身的干净。
- **是否加标记**：形状标记有"暖场"作用但也占视觉。判断依据：正文已很多装饰就少给气泡配标记，反之可加。
- **左竖条 vs 整框**：只有一句用左竖条（轻），要装"标题+正文"两行的用整框。判断依据：内容层级决定——单层用条，双层用框。
