# 模块·资料领取 / 福利入口

> 定位：用"回复关键词领资料/优惠券/模板"给读者一个关注后的即时回馈，是干货号、知识付费最常用的涨粉与留存钩子。
> 调用时机：知识付费、干货号、教程号；当想用一份低成本福利换取"关注 + 私信 + 转发"时。

## 一、可用写法与语法

资料领取块的机制是"**引导话术 + 关键词 + 自动回复配合**"：读者在公众号对话框输入约定关键词，后台自动回复资料的获取方式。

**引导话术三要素**（缺一不可，否则没人照做）：
1. **福利名 + 值不值**：一句话说清是什么、为什么值得领（"打包了 20 个可复用模板""打印就能用"）。
2. **明确动作**："在公众号对话框回复 **「模板」**"——动作词 + 关键词要用高亮/粗体/徽章标出。
3. **获取方式**：回复后"自动回复里点链接/加微信领取"，给出线索别让读者卡住。

**福利名 / 钩子的写法差异**：
- 干货号："回复【模板】拿 20 个开箱即用的排版模板"（给数量 + 用途）。
- 知识付费："回复【优惠券】领 ¥30 新课程券，限量 200 张"（给金额 + 稀缺）。
- 教程号："回复【代码】下载这期的可运行示例"（给具体交付物）。
钩子要具体到"你领的是什么东西"，而不是"很值的一份资料"。

**关键词设计**：
- 简短好记：一个词 2–4 字（"模板""手册""清单"），别用长句或有歧义难敲的。
- 与内容对应：本文讲排版就配"排版模板"，别给个无关关键词。
- 大小写/全半角可能踩坑：引导文案用中文词最稳，避免需要切换输入法的词。

**关键词回复的「引导三件套」写法**（照这个结构补全，读者不会卡）：
1. **价值句**：一句话说清福利是什么、值在哪（"20 个开箱即用的模板"）。
2. **动作句**：明确指出去哪、敲什么（"在公众号对话框回复 **模板**"）。
3. **线索句**：回复后会得到什么、若卡住怎么办（"自动弹出网盘链接，失效留言我补发"）。
三句齐，读者才能 10 秒内真的去操作，而不是看完就划走。

**自动回复配合**（后台配置）：设"被关注自动回复"先抛福利引导，再配合**关键词自动回复**出资料；福利入口也可放自定义菜单。资料本身走"自动回复给链接/二维码"分发。

**发放链路设计（先想清楚再发文）**：
1. 关键词 → 自动回复现成的资料链接/二维码。
2. 想要私域 → 自动回复里引导"加我微信领取，备注关键词"，沉淀到个人号/企业微信。
3. 想促关注 → 把福利设为"被关注自动回复"的一部分，新粉进门就发第一份。
4. 想筛有效粉 → 给每条资料配专属关键词，看哪个关键词被敲得多来判断需求。
链路定好，再把关键词写进正文，才不出现"引导了却发不出"的尴尬。

**福利类型**：
- **资料包**：PDF/模板/清单/图表合集（干货号最常用）。
- **优惠券**：付费课程/商品折扣码（知识付费、电商）。
- **模板**：可复用文档/设计稿/代码模板（教程号）。

**按账号目标选福利（别什么都给）**：
| 目标 | 合适福利 | 理由 |
|---|---|---|
| 简单涨粉/留存 | 一份好领的清单/模板 | 门槛低，人人领得到 |
| 筛精准粉 | 垂直领域深度资料 | 领的人基本是目标读者 |
| 沉淀私域 | 优惠券/加微信才能领 | 把"领资料"引到私域 |
| 铺垫付费 | 样品/低价券 | 为后续课程商品铺路 |
福利和本期内容挂钩最好：本篇讲了什么，就送相关的，转化最顺。

**适用场景**：干货分享文结尾、系列教程、涨粉活动、付费转化前的价值铺垫。

**合规**：福利内容真实可发放、不虚标（"价值 999"别瞎标）；优惠券规则真实（能用、不过期即失效）；不诱导过度转发分享获取（微信规则）。

## 二、双模式表现（文字类 / 宣传类）

- **文字类**（干货号，弱推销）：一条克制引导条，"回复 xx，送整理好的资料"；福利是"本篇的附赠"。
- **宣传类**（知识付费/促销）：醒目福利条 + 涨价倒计时/限量 + 引导转发（但别踩转发诱导红线）。

## 四、使用时机与位置

- **首选位置**：干货/教程正文结尾，内容给足价值后顺势"想要完整版，回复即送"。
- **也可**：文中流程讲完时插一条（"需要现成模板见文末领取"）。
- **配合**：关注自动回复已设福利 → 新粉进来就拿到第一份礼物；文末福利页 + 关键词自动回复承接。
- **不适合**：正文章节密集处频繁插福利条，打断阅读。

## 五、风格适配（4 个例子）

- **干货/工具号**：淡橙引导条 + 关键词胶囊，克制专业。
- **知识付费**：橙纯色优惠券卡 + 限时，转化感强。
- **教程号**：三合一工具箱卡，一份资料一个关键词，清爽。
- **日系清新**：淡青/米白卡、圆角 14px，关键词只用加粗不套色底。

**福利价值的诚实写法（可信 vs 画饼）**：
- 可信："20 个可复用的 .docx 模板""12 条发布前自查清单"——说清楚种类、数量、格式。
- 画饼："史上最全资料包，价值 999 免费送"——数量含糊、标价虚高，既不可信又踩合规。
判断标准：读者收到后会不会觉得"值回我这次回复"。会，就写；不会，别硬吹。

## 六、间距与尺寸（遵守硬规范）

- 福利块与前后内容：`margin:0 0 16px`。
- 单条引导条 `padding:14px 16px`；整卡优惠券款 `padding:16px`。
- 卡内文字行距 1.7–1.75；标题 14px 加粗、正文 13px、关键词胶囊 `padding:2px 8px`。
- 金额可放大（优惠券 24–28px）；三合一卡文案 12px（窄卡极限）。
- 关键词胶囊圆角 6px（融入文字）或按钮 14–18px（整按钮）。

## 七、密度限制

- 一篇福利入口 **1–2 处**（中段 + 文末）；主打文末一条即可。
- 关键词一次给 1 个最清晰；三合一给 3 个已到上限。
- 卡内引导文字 ≤3 行；福利价值一句话讲清，别写成长名单。

## 八、常见错误（反例 + 正解）

1. **关键词引导不清，读者找不到去哪回复**。
  错：`"想要的可以在后台领取"（没说回复什么词、在哪回）`
  对：`"在公众号对话框回复 **模板**"，动作+关键词+位置都写明。`
2. **关键词难敲或有歧义**。
  错：`"回复 haohaoxuexi-bang"，读者懒得敲、还容易错。`
  对：`用 2–4 字中文常用词（"模板""清单"），好记好敲。`
3. **自动回复没配置 / 和正文对不上**。
  错：`引导写回复"模板"，后台没设这位词，读者石沉大海。`
  对：`发布前先配好关键词自动回复，稿子里每个关键词都自测一次能收到。`
4. **虚标福利价值**。
  错：`"价值 999 的资料包，免费送"（就是几页随便找的）`
  对：`内容真、标价诚实，别把随便整理的当"史上最全"。`
5. **诱导转发领取触红线**。
  错：`"转发到 3 个群才给资料"`
  对：`用"关注 + 私信"低门槛获取，不用"转发群"设卡（涉诱导分享）；想促分享就光明正大说"觉得有用欢迎转发"。`
6. **领失败无兜底、读者流失**。
  错：`自动回复链接失效也没人管，读者领不到就取关。`
  对：`正文写明"失效留言我补发"，并可定期后台检查关键词回复是否正常。`

**发布前关键词自测清单**：
- [ ] 每个关键词在后台都设了自动回复并测过一遍。
- [ ] 文档/链接/二维码能正常打开，非失效状态。
- [ ] 关键词与正文完全一致（含大小写、全半角）。
- [ ] 兜底文案（"失效留言补发"）已写在正文与自动回复里。

## 十、个性化空间（可调参数与判断依据）

- **一份福利 vs 三合一**：主打一份重量级福利 → 单条；多份轻福利炒热 → 三合一。判断依据：福利是"一个精品"还是"多个小件"。
- **发放形式**（自动回复链接/加微信/网盘）：要自动化低维护 → 关键词自动回复 + 网盘链接；要建私域 → 引导加微信领取。判断依据：你是否想沉淀私域。
- **关键词命名**：用与内容/账号强相关的词（本文主题词），好记且不混淆。判断依据：账号内容主题。
- **福利价值文案**：诚实标值（"20 个模板"比"价值 999"可信）。判断依据：真实性与合规。
- **色盘**：干货橙 / 知识付费橙纯色 / 工具青。判断依据：内容类型与转化强度。
