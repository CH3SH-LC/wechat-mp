# 模块 · 步骤（数字圆步骤条）

> 定位：把"读者要照着做"的操作流程拆成一、二、三步，用数字圆编号 + 连线串起来，让读者明确知道"做完第 1 步才开始第 2 步"。步骤是**操作指令**，不是叙事。
> 调用时机：教程、新手引导、操作流程、上手引导——当读者要真正"动手执行"一篇连续动作时。**步骤条与时间线要分清**：步骤是"该这样做"（指令），时间线是"曾经这样发生"（叙事，见「模块 · 时间线」）。

## 一、可用写法与语法

写作语法用容器：`:steps` 包住若干 `:step`。步骤条在正文渲染为"数字圆 + 连线 + 说明"的纵向流程，读者从头往下读就是执行顺序。

**步骤写法铁律**：
1. **动词开头**：每步第一词是动作（打开/填写/上传/配置），让读者知道"要做什么"。别用名词或形容词开头。
2. **每步 ≤15 字**：一步一句、指令清晰，超过 15 字就拆成"第 1 步……然后第 2 步"。
3. **≤5 步**：5 步以上连读者和编辑自己都记不住，果断合并或拆成两组"流程 A/流程 B"。真正要很多步的，考虑分章节讲。

**哪些话是步骤、哪些不是**：只有"读者照做就能达成结果"的连续动作才进步骤条；解释、背景、注意事项是铺垫，放在步骤的前后，不要塞进某一步。步骤条是一串"请按顺序做"的命令，不是"我告诉你事情怎么回事"的叙述。

## 二、双模式表现（文字类/宣传类）

**文字类（文字排版优先）**：数字圆用单色（如品牌青 `#00b8a9`）圆底白字，连线细而浅（同色淡化），整体简洁利落。适合教程原文、操作文、干货文——像一个"清单式指引"，强调但不打断阅读。文字类的核心是"照着做就行"，颜色只是最轻的分块暗示，真正靠的是编号的顺序感。

**宣传类（视觉优先）**：数字圆用纯色底（橙系或品牌主色纯色），连线用主色实线，每步文字可收进浅色文字小卡。视觉更强、圆更大、"步骤感"更明显，适合营销活动流程、注册引导、报名指引——引导读者"一步步把它拿下"。宣传类的核心是"这条流程值得你走完"，纯色圆 + 浅色小卡 + 细边框把每步从正文里分出来。

**两个模式在同一篇里只选其一**：文字类全文单色圆，宣传类全文纯色圆，不要一半单色一半纯色——混用等于让读者以为"单色和纯色是两种不同环节"，严重破坏一致性（见模块组合铁律）。

## 三、样式变体（4 种常用，具体参数）

**所有步骤条统一行高 1.75、说明文字 14px、数字圆 `border-radius:50%`、圆与文字间距 12px**。圆直径 28px（紧凑文字类）或 32px（宣传类更醒目）；连线占位 16px。以下给 4 种常用模板。

**变体 A｜单色数字圆（文字类·最稳）**——适用：教程、新手指引、中性操作流程：
```html
<section style="padding:0;margin:0 0 16px;">
  <section style="display:flex;align-items:flex-start;margin:0 0 12px;">
    <p style="width:28px;height:28px;border-radius:50%;background:#00b8a9;color:#fff;font-size:14px;font-weight:bold;text-align:center;line-height:28px;flex-shrink:0;margin:0;">1</p>
    <p style="margin:4px 0 0 12px;line-height:1.75;font-size:14px;color:#333;">打开应用并登录账号</p>
  </section>
</section>
```
- 参数：数字圆 28×28px、`border-radius:50%`、底色青 `#00b8a9`、白字 14px 加粗、`line-height:28px` 垂直居中；圆与文字间距 12px；步与步间距 12px；说明文字 14px 色 `#333`。**每步说明首字即动词**。

**变体 B｜带竖线贯穿的纵向步骤**——适用：强调"严格先后"的流程（填表→提交→等待），圆形 → 竖线 → 圆形串成一条竖向轨道：
```html
<section style="display:flex;align-items:flex-start;margin:0 0 16px;">
  <section style="width:28px;flex-shrink:0;text-align:center;">
    <p style="width:28px;height:28px;border-radius:50%;background:#ff6b35;color:#fff;font-size:14px;font-weight:bold;line-height:28px;margin:0;">1</p>
    <p style="height:16px;margin:0;border-left:2px solid #ffd9c8;line-height:1px;font-size:1px;">&nbsp;</p>
  </section>
  <p style="margin:4px 0 0 12px;line-height:1.75;font-size:14px;color:#333;">上传你的资料</p>
</section>
```
- 参数：左列固定 28px 居中；圆下方加 `height:16px` 的 `border-left:2px solid <淡化主色>` 占位段当"竖线"；连线用 `line-height:1px;font-size:1px` 防默认行高把竖线撑高；**末尾一步不画竖线**（收尾）。竖线色取主色的浅一档，别用黑线抢了圆的视觉。

**变体 C｜纯色数字圆 + 文字卡（宣传类·最醒目）**——适用：营销活动、注册引导、报名流程：
```html
<section style="display:flex;align-items:flex-start;margin:0 0 12px;">
  <p style="width:32px;height:32px;border-radius:50%;background:#e56b2f;color:#fff;font-size:15px;font-weight:bold;text-align:center;line-height:32px;flex-shrink:0;margin:0;">
  <div style="flex:1;background:#fff7f2;border-radius:8px;padding:10px 14px;margin-left:12px;">
    <p style="margin:0;line-height:1.75;font-size:14px;color:#5a4a3a;">注册并完成邮箱验证</p>
  </div>
</section>
```
- 参数：纯色数字圆 32×32px（纯色主色如 `#e56b2f`）、细边框 `border:1px solid`（可略）= 无阴影，靠纯色底 + 白字分层；右边文字收进浅橙底小卡（圆角 8px、`padding:10px 14px`、与圆间隔 12px）。这是宣传类"步骤感"最重的一种。

**变体 D｜带"准备前提"行的步骤组**——适用：流程开始前需要先备齐东西（注册账号、准备资料、开通会员）：
```html
<section style="padding:12px 16px;background:#eef6ff;border-left:3px solid #00b8a9;border-radius:0 8px 8px 0;margin:0 0 12px;">
  <p style="margin:0;line-height:1.75;font-size:13px;color:#1a4a66;">准备：注册账号 / 准备一张图 / 手机连网</p>
</section>
<section style="display:flex;align-items:flex-start;margin:0 0 12px;">
  <p style="width:28px;height:28px;border-radius:50%;background:#00b8a9;color:#fff;font-size:14px;font-weight:bold;text-align:center;line-height:28px;flex-shrink:0;margin:0;">1</p>
  <p style="margin:4px 0 0 12px;line-height:1.75;font-size:14px;color:#333;">登录并进入个人中心</p>
</section>
```
- 参数：前提行是一块浅青左竖条（复用「模块 · 气泡」的说明底），`padding:12px 16px`、文字 13px；它提醒"开工前先备好什么"，正式步骤从"1"开始编号。前提行与步骤间距仍 12px，整组底部 16px。

## 四、使用时机与位置

- **新手指引**：产品/课程的新手起步流程，最适合做步骤条——读者照着走一遍就入门。
- **操作流程**：凡是"按顺序做完这几步就能达成 X"，用步骤条替代平铺段落，读者照做不迷路。
- **流程前置前提**：步骤条前先用一句话（或变体 D 前提行）说明"开始前需准备什么"，步骤内不再赘述。
- **位置**：紧跟"为什么这样做"的动机段之后——先给理由再给步骤，读者更有耐心照做；把"做完的好处/结果"放在步骤条之后作收尾。
- **不要步骤条开场**：全篇第一屏别直接甩步骤条（读者还没被说服为什么该做）；先动机铺垫，再进流程。
- **别在步骤里跑偏**：步骤条是单一线性流程，中间不要再岔开讲别的知识点；有分支说明放步骤外。

## 五、风格适配（4 个例子）

- **极简/商务**：变体 A，数字圆改深灰 `#333` 圆底白字、连线省略，说明文字 14px 深灰，利落克制，像一张 checklist，适合职教/服务条款类。
- **电商/营销**：变体 C 纯色圆 + 浅色小卡，主推橙 `#e56b2f`，宣传语气，引导"注册/下单/领取"动作，圆加大到 32px。
- **教育/生活**：数字圆用暖色黄/橙，说明文字更口语，每步后可加一句"效果/为什么要这步"的小注（13px 灰），营造手把手陪跑感。
- **科技/数码**：数字圆用冷蓝 `#0a84ff`，连线用浅蓝，说明 14px 左对齐，像一份安装向导，冷静可靠。

**风格统一原则**：步骤条的数字圆颜色要与全篇其他模块（卡片、气泡、列表符号）一致——如果卡片用青系，数字圆也用同一青；如果标题是纯色块，宣传类步骤圆跟随纯色。风格是"全篇穿的一套衣服"，步骤条不能单独换风格。

## 六、间距与尺寸（遵守硬规范）

- **步骤条与前后块**：整组底部 `margin:0 0 16px`（块距基线 16px）；组内步与步 12px（比块距紧，因为是一体的）。
- **行高**：圈内文字与说明文字统一 `line-height:1.75`（与正文一致，保证扫读节奏不乱）。
- **数字圆直径**：28px（紧凑文字类）/ 32px（宣传类更醒目），`border-radius:50%`、字号 14-15px、数字单字居中。
- **连线占位**：16px（两步之间）；末尾一步不画线。连线用 `border-left:2px` + 主色浅一档。
- **圆与文字**：间距 12px；文字 14px、色 `#333`（正文灰 `#555` 亦可）；整组宽度不自设左右边距（随正文视口）。
- **文字卡**：`padding:10px 14px`、圆角 8px、与圆间隔 12px；前提行 `padding:12px 16px`。

## 七、配色配合（与全篇色盘协同）

步骤条不是独立元素，数字圆的颜色必须从全篇色盘里"取"。**一篇正文只用 1 个主强调色贯穿所有强调点**（卡片、气泡、列表符号、步骤圆共用同一个主色）。

- **单主色用法**：数字圆统一用一个主色（如青 `#00b8a9`），连线取其浅一档（如 `#bfeae5`），文字卡用同色极浅底（如 `#eef6ff`）。最克制、最易维护，教程文首选。
- **主色 + 动作色**：强调数字圆用主色，关键的"最后一步/提交动作"可用一个进步色（如橙）单独点亮——只突出决定性一步，别整条都换色。
- **品牌色替换**：把数字圆整体换成品牌主色体系（品牌色加深一档做圆底、浅一档做连线底）。判断依据：品牌色能否撑起"圆 + 连线 + 卡底"三档梯度，能就以品牌单色贯穿，最专业。
- **避免**：每一步一个颜色（第一颗红第二颗蓝第三颗黄），读者分不清顺序优先级，显得"彩虹步骤"；步骤条颜色 ≤2 档最佳。
- **与正文关系**：说明文字与底色 14px 色对比度 ≥4.5:1（见「可读性」维度）；白字圆底要够饱和，浅色圆配白字会糊。

## 八、微信兼容注意

写步骤条时的"可用子集"与"要绕开的坑"（微信富文本编辑器）：

- **可用**：`background` 纯色、`border-left/border-radius`、细边框 `border:1px solid`、`padding/margin/line-height:1.75/font-size`、`display:flex` 做横向排布（卡内圆+文字左右对齐）。**本规范不推荐渐变与投影**，一律纯色 + 细边框。
- **尽量别用**：伪元素 `::before/::after`（编辑器多剥除，连线的占位别用伪元素画）、`outline`/`border-image`（定位不稳）。
- **连线画法**：竖线用「一段 `border-left` 的占位 `<p>`」而非伪元素；占位段设 `line-height:1px;font-size:1px` 防默认行高把竖线高度撑爆。
- **纯色兜底**：数字圆统一用纯色底 + 白字，装饰不会失效，始终是可读的实心圆，无需兜底冗余。
- **通用兜底原则**：任何一种装饰"锦上添花"时，优先保留"纯色圆底 + 实线 + 圆角"组合——装饰失效后数字编号与顺序仍然清楚。

## 九、密度限制（重要）

- **≤5 步**：超过 5 步读者就数不清了。6 步以上拆成两组步骤（流程 A/流程 B），或按章节拆。
- **一屏一组步骤**：一组步骤（含所有步）尽量控制在一屏能看完，别跨两三屏让读者滑到头忘了第 1 步。
- **每步 ≤15 字**：一步只讲一个动作，带前提的用括号补充（"上传（≤5MB 的图）"），别写整句长句。
- **不嵌其他强调块**：步骤条内不要再嵌气泡/卡片等其它强调块，步骤本身就是干净流程；前提行算作步骤条的"帽"，不算额外强调块。
- **别把平铺要点硬掰成步骤**：只是并列列举若干要点（"优点：A、B、C"）用列表（见「模块 · 列表」），步骤条只留给真正的先后执行顺序。

## 十、常见错误（反例 + 正解）

- **反例**："第一步：这个功能的设置，需要你登录之后，找到个人中心里的高级选项，点开后……"（不是动词开头 + 超长）→ **正解**："1 登录账号并打开个人中心"。
- **反例**：报 8 步，第 4 步和第 5 步其实是同一件事拆两半 → **正解**：合并成 5 步以内，保证每步真正不同、真正顺序执行。
- **反例**：把时间线当步骤用——"2019 年上线、2021 年改版、2023 年获奖"放进步骤条 → **正解**：这是叙事，用「模块 · 时间线」，步骤只用于"该怎么做"。
- **反例**：步骤之间没有竖线也没有编号逻辑，读者不知道先做谁 → **正解**：务必用数字圆编号 + 明确顺序，或至少按 1-2-3 编号；需要强先后再画竖线。
- **反例**：第 1 步前没有前提说明，读者一上来就"上传文件"结果没有文件 → **正解**：步骤条前一句话（或前提行）交代"准备：注册账号 / 准备一张图"，把前置条件外提。
- **反例**：圆形数字用大红字满屏堆加粗，满溢占半屏 → **正解**：圆内数字 ≤15px，靠圆底 + 白字 + 圆角表达步骤感，别靠超大字号。

## 十二、个性化空间（可调参数与判断依据）

- **数字圆直径/颜色**：28-32px；纯色，可加深一档或浅一档。判断依据：风格软硬与"步骤感"需求——硬核教程用单色 28px，营销引导用纯色 32px。
- **连线有无与颜色**：需要"强先后顺序"就画竖线，并列分支不画。判断依据：步骤有无严格的先后依赖（填表→提交→等待）——有则连线更清楚。
- **每步是否配小注**：需要解释"为什么这步重要"时可加 13px 灰小注。判断依据：读者会质疑或需要动机的步骤才加，别每步都加（冗长）。
- **前提行有无**：开工前要备东西就加"准备"帽，没有前置条件就不加，让步骤直接从"1"开始。
- **步数**：3-5。判断依据：流程本身复杂性——能 3 步说清绝不上 5 步；真到 6 步拆成两组流程，别硬塞一条。
- **步序号表达**：一律阿拉伯数字（1/2/3），别用"第一步/第二步/第三步"文字堆叠（数字更省字、更好扫读）。
