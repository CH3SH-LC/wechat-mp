# 页脚区（module-footer）

> 定位：文章最末尾的一条「信息带 + 引导带」，承载作者署名、版权声明、往期推荐、二维码、关注引导，既是收尾也是承接长期运营的最后触点。
> 调用时机：**所有类型都用**；连载 / 系列 / 栏目号尤其需要（放往期回顾与下期预告），新读者靠它找到入口。

## 一、可用写法与语法

页脚是多信息组合，排版语法用卡片 / 分割线 / 列表拼接，内联样式可做更规整的「信息带」。

**排版语法（交给排版工具）**：

```markdown
---
**撰文**：编辑署名（可换）　·　**栏目**：读书札记

::: card 往期回顾
- 《高效阅读（一）：带着问题读》
- 《高效阅读（二）：三遍阅读法》
:::

喜欢请点关注，不错过下期。
```

**排版语法（分块拼页脚）**：

```markdown
---
**作者**：编辑署名　|　**栏目**：读书札记

::: card 下期预告
下期聊聊怎么选书。
:::

关注我，别错过下期。
```

**内联样式——文末信息带（作者 + 版权 + 引导，推荐）**：

```html
<section style="background:#f8f8f8;border:1px solid #e0e0e0;border-radius:10px;padding:16px 18px;margin:24px 0 0;">
  <p style="font-size:14px;color:#555;line-height:1.9;margin:0;">撰文 · 编辑署名　|　栏目 · 读书札记</p>
  <p style="font-size:13px;color:#999;line-height:1.9;margin:8px 0 0;border-top:1px solid #eee;padding-top:8px;">
    本文原创，转载请联系授权。　© 2026 账号名</p>
  <p style="font-size:14px;color:#2f6fed;font-weight:bold;margin:10px 0 0;">
    <span style="display:inline-block;width:8px;height:8px;border-radius:50%;background:#2f6fed;margin-right:6px;"></span>喜欢请点关注，不错过下期</p>
</section>
```

**元素的承载**：

- **作者署名**：正文段落 / flex 排布均可。
- **往期推荐**：`::: card` 列表 / 内联列表。
- **二维码**：必须用微信 `uploadimg` URL 图片，`width:120px` 居中；未上传 / 无权限则省略。
- **关注引导**：纯文字加粗或胶囊钮（复用「首屏引导关注条」的钮样式，但轻量）。

## 二、双模式表现

| 维度 | 文字类 | 宣传类 |
|---|---|---|
| 信息带底 | 浅灰 `#f8f8f8`、细边框 | 纯色顶条 / 白卡 + 加粗引导 |
| 引导按钮 | 纯文字加粗「关注」 | 实底纯色胶囊钮「关注」 |
| 二维码 | 灰度黑白即可 | 可做主色描边装饰 |
| 往期推荐 | 简单列表 | 可带序号 / 封面小图 |
| 版权行 | 灰字 `#999` 低调 | 同样低调，版权不清越 |

页脚「信息归属」与「行动引导」两段可分开：归属段低调用灰，引导段才用品牌色强调。

## 三、样式变体（≥3 种）

**变体 A｜文末信息带（组合齐全，推荐）**——作者 / 版权 / 往期 / 关注引导一体。
参数：`background:#f8f8f8;border:1px solid #e0e0e0;border-radius:10px;padding:16px 18px;margin:24px 0 0`；作者行 14px `#555`；版权行 13px `#999`、上边 `border-top:1px solid #eee;padding-top:8px`；引导行 14px 主色加粗、前缀一个主色圆点 span。组合最全、通用最好。

**变体 B｜精简一行（短文 / 极简）**——只放一句署名 + 关注引导。
参数：`text-align:center;font-size:13px;color:#999;letter-spacing:1px;margin:24px 0 0`；内容如「撰文 / 编辑署名 · 关注不错过下期」。零色块，极简 / 黑白账号收敛答案。

**变体 C｜「往期回顾」卡 + 下期预告（连载标配）**——先往期卡片，再下期预告，最后引导。
参数：`::: card 往期回顾` 列表（条目 14px `#444` 行高 1.8）+ `::: card 下期预告`（14px 主色）+ 末尾一句引导；每卡 `margin:0 0 16px`，`border-radius:10px`、`padding:14px 16px`。连载号必配双承接。

**变体 D｜品牌页脚（机构 / 公众号主视觉）**——顶部纯色分隔条 + 居中署名 + 二维码 + slogan。
参数：顶部 `border-top:3px solid #2f6fed` 主色实线条；居中作者 14px、slogan 12px 灰；二维码图片（`uploadimg` URL）居中 `width:120px`、下方 `12px` 间距；`padding:20px 0`、`margin:28px 0 0`。机构号主视觉收尾。

**变体 E｜信息带 + 小图往期（图文号）**——往期推荐带小封面缩略图。
参数：`::: imgcard` 或每条 `display:flex`（左图 `width:56px;height:56px;border-radius:6px` + 右标题 14px）；条目间 `border-top:1px dashed #eee`；白卡底（细边框）。适合图片内容占比高的账号。

## 四、使用时机与位置

- **位置**：CTA 行动号召之后、全文最末尾。顺序建议：正文收尾 → 收束句 → CTA → **页脚区**（作为真正的『全篇句号』）。
- **组合顺序（推荐）**：1 署名 / 作者栏 → 2 版权声明（转载/原创标记）→ 3 往期回顾 / 下期预告（连载）→ 4 二维码（可选）→ 5 关注引导（收尾）。
- **适用场景**：所有类型收尾；**连载尤其需要**——页脚里放往期回顾 + 下期预告，是新读者进入系列的唯一入口，务必给齐。
- 二维码需要配 `uploadimg` URL 图片，微信正文只认微信素材；无二维码权限 / 未上传就省略该项，不与文字硬凑。
- **与「结尾行动号召」分工**：CTA 驱动「这期最后一个行动」，页脚承接「长期入口」；连载把往期/下期放在页脚而非 CTA 里。

## 五、风格适配

- **国潮红金墨**：页脚信息带浅米底 `#faf3e7`、作者墨色；版权金 `#a5765a`；可选择加一枚主色方形章印 span（`display:inline-block;width:16px;height:16px;transform:rotate(45deg);border:1px solid #a5765a`）或金线分隔。
- **科技蓝紫**：变体 C + 顶部细蓝实线条；往期条目带编号；二维码带主色圆角描边；版权 12px 灰蓝。
- **校园青春**：变体 A 用浅青底 `#eafaf7` + 主色引导钮；往期条目可带小草 art:// 图案、语气口语。
- **极简黑白**：变体 B 纯文字；只放署名 + 关注引导，二维码黑白；版权行最小号灰字。
- **商务 / 机构**：变体 D 品牌页脚，顶部主色条 + 居中 Slogan + 二维码，署名规范完整。

## 六、间距与尺寸（遵守硬规范）

- 页脚与上方 CTA：`margin:24px 0 0`（进页脚留大段）。
- 信息带 padding：`16px 18px`；`border-radius:10px`；行高 **1.9**。
- 组内分段用 `border-top:1px solid #eee;padding-top:8px` 或 8–10px 间距，不用大空段。
- 作者行 14px、版权行 13px、引导行 14px；正文 `line-height:1.75`。
- 二维码图片：`width:120px` 居中，下方留 12px（图片上下间距规范 ≥12px）。
- 页脚是全文最后，无需再往下 `margin-bottom`；它是结尾点。

## 七、密度限制

- **一篇文章只有 1 个页脚**，置于最末；不在中段重复「往期回顾」卡片（中段的系列衔接交给「往期回顾 / 下期预告」模块，页脚别重复一套）。
- 页脚内的往期条目 2–5 条，不把整站历史都列上；版权声明一行为主。
- 「关注引导」已在首屏关注条出现时，页脚引导用更轻的纯文字，避免重复大钮。
- 二维码一次即可，不铺满；二维码与关注条、CTA 别在结尾三连轰炸。
- 页脚整体作为一个块，不在其中塞气泡、表格等其它大模块。

## 八、常见错误

- **反例**：只放一句「本文到此结束」没有署名 / 版权 / 任何引导，收尾又空又没入口。**正解**：信息带补齐署名 + 版权 + 至少一个引导或未来承接。
- **反例**：版权声明写长段法律条文压住整页脚。**正解**：一行带过（「本文原创，转载需授权」），合规点在「合规与信息」区条目里处理。
- **反例**：往期回顾列 10 条把页脚撑成长清单。**正解**：精选 2–5 条最相关。
- **反例**：页脚信息带 `margin-top:0` 或配色过重，把结尾搞成另一块广告。**正解**：进页脚 `margin-top:24px`，归属段低调用灰，引导段才强调。
- **反例**：连载页脚不放下期预告、也不对照往期，读者看完这期不知道下一期在哪。**正解**：连载必配「往期回顾 + 下期预告」双承接。
- **反例**：二维码用本地/外链图片，微信端不显示。**正解**：二维码走微信素材上传取 `uploadimg` 永久链接，`width:100%/120px` 居中都行，但务必是微信素材 URL。

## 十、个性化空间

- **署名呈现**：真名 / 笔名 / 栏目名 / 团队名；判断依据是 IP 或机构定位，个人 IP 用真名笔名，机构用栏目名。
- **往期条数 & 排序**：精选 2–5 条最相关；判断依据是读者此刻最可能点的（同系列 / 最新章节 / 高赞文），连载按顺序给前一级 + 最新几期。
- **是否放二维码**：判断依据是账号是否主推私域 / 公众号矩阵；放时应配主视觉与描边风格统一。
- **版权语句 & 转载门槛**：按合规条目定，可声明「转载需授权」或更强声明；判断依据内容原创程度与转载诉求。
- **引导句强度**：从「圆点饰头 · 点关注」到「关注我，不错过下期」到 silent 仅署名；判断依据是账号涨粉诉求——成长型强化引导，成熟型克制。
- **slogan / 座右铭**（品牌页脚可选一行）：判断依据账号是否有一句可长期复用的品牌语，重复使用能沉淀记忆。
- **是否统一样式**：页脚建议成为账号固定「模板」，每期复用同一排版与措辞；判断依据是账号辨识度诉求——固定页脚让老读者每期都认得出。
