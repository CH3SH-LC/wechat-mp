# 方法论·模块×内容类型矩阵（module-guide-matrix）

> 定位：一张"内容类型 × 常用模块"的完整总表，按 **推荐 / 可选 / 不用** 三档标出每种内容该用什么模块。调用方从内容类型出发，直接在表里抄模块清单。
> 调用时机：定好内容类型后、动手排版前。矩阵给出"哪些模块是这类的主心骨、哪些可加、哪些别放"，配合《典型模块组合模式》用。

## 一、矩阵使用法（三步）

1. 先确定这篇属于哪个**内容类型**（见类型维度）——它是决定模块组合的顶。
2. 在矩阵里找到那列，抄下"推荐"档的模块即为主结构；"可选"档按需要补。
3. "不用"档的模块**一般情况下不放**，除非有强理由（见常见错误）。

三档含义：
- **推荐**：这类内容的主力，几乎每篇都用。
- **可选**：视篇幅、素材、运营目标可选加，有助更丰满但非必需。
- **不用**：通常与这类内容气质冲突或冗余，默认不放。

另一个先想清楚的问题：**这篇是给谁看、想让读者干嘛**。同样一篇干货，涨粉号要的是"内容够用想收藏"，变现号要的是"看完想下单"，复利号要的是"愿意持续追更"。运营目标不同，同一列的档位会跟着动（见第九节）。

## 三、11 类内容逐项解读（每类的模块搭配理由）

### 干货教程
- 主结构：标题 → 痛点 WARN → 核心观点 → 步骤 steps → 清单 checklist → 案例 case → 延伸阅读 → CTA。
- **推荐理由**：实操价值是命根，步骤+清单是"学得走"的关键；案例是"真有用"的证明。
- **不放**：贩卖感重的价格/证言，除非走"教程顺便带货"的软转路（此时降为可选）。
- **不同运营目标怎么调**：涨粉时把案例放大、开头痛点戳得更准，让人先收藏；变现时可在文末软转价格卡（见第十节）；复利时固定"这期是什么、下期预告什么"，让人往回看系列。

### 新闻资讯
- 主结构：标题 → 导语摘要 → 正文 → 图+引用 → 延伸。
- **推荐理由**：快讯重在"快、准、全"，模块克制，靠标题和导语抓人。
- **不放**：促销/证言/互动投票，破坏新闻的客观性。
- **不同运营目标怎么调**：涨粉靠标题和导语多做"钩子"，把话说全；变现与新闻天然冲突，一般不动；复利时多接"延伸阅读"，把读者从这一条导到栏目或历史同题文章。

### 情感随笔
- 主结构：标题 → 金句/叙事 → 段落 → 一句收束 → 留言/关注。
- **推荐理由**：情绪比模块重要，模块极简，靠文字张力与留白。
- **不放**：步骤/清单/价格——把情绪文写成教程是错位。
- **不同运营目标怎么调**：涨粉靠共鸣感和转发点，结尾引导"转给那个TA"；变现基本不做硬转，顶多角落软植入；复利靠"固定的情绪栏目感"，让人期待下期同款情绪。

### 产品软文
- 主结构：标题横幅 → KEY 卖点 → 优点列表 → 价格/参数卡 → 证言 → CTA。
- **推荐理由**：先说服"值"，再让"放心买"，转化是目标。
- **可选**：使用步骤（体验类产品加）、互动（不冲突可加）。
- **不放**：与产品无关的装饰性花纹堆砌。
- **不同运营目标怎么调**：变现是主场，价格/证言/CTA 拉满；涨粉时弱化硬销、多讲"这产品让人变好的场景"；复利靠"系列选品"和售后答疑栏目，让人觉得"关注你能一直买到好东西"。

### 活动促销
- 主结构：倒计时 → 核心卖点 → 报名步骤 → 价格/特权卡 → 证言 → CTA。
- **推荐理由**：紧迫感 + 价值 + 路径 + 信任 + 行动五连，压力驱动下单。
- **必放**：倒计时（若是限时）；**不放**：跟活动无关的长篇科普。
- **不同运营目标怎么调**：变现就是目的，行动按钮和倒计时一个不少；涨粉靠"拉新有礼/转发抽奖"这类互动引流；复利靠"每次活动都有记忆点"的固定流程，让读者下次活动直接来。

### 品牌故事
- 主结构：叙事 → 时间线/历程 → 理念金句 → 留言/关注。
- **推荐理由**：建立情感与信任，靠故事与认同留住读者，不打硬广。
- **不放**：价格表/证言墙——品牌故事的"卖"是隐性的。
- **不同运营目标怎么调**：涨粉靠故事传播性，结尾引导转发；变现走"认同后自然信任"，中间含蓄带出产品线与服务；复利靠"品牌叙事形成记忆锚点"，反复讲同一句理念。

### 人物故事
- 主结构：主角叙事 → 身份卡/时间线 → 金句 → 留言/关注。
- **推荐理由**：人物刻画靠叙事与留白，身份卡帮读者快速认识主角。
- **不放**：促销模块——除非像"人物带货"这种特殊场景。
- **不同运营目标怎么调**：涨粉靠人物经历共鸣，越具体越有传播力（具体到"深夜几点、在哪个店"）；变现靠"人物与产品的信任传导"；复利靠"人物系列"连载，把一个人物讲深讲透。

### 盘点清单
- 主结构：标题+目录 → 分组卡片（每项一卡）→ 收藏引导 → 延伸。
- **推荐理由**：清单的骨架是"分组 + 并列"，卡片是最佳容器；目录帮导航。
- **可选**：同类导购（盘点"好用的XX"时可软转）。
- **不放**：把每项写成长篇——清单价值在并列扫读。
- **不同运营目标怎么调**：涨粉靠"收藏+转发"数据，结尾明确引导；变现靠"同类导购"把其中一两项软转掉；复利靠"定期更新榜单"（如每月一版），养成固定期待。

### 科普测评
- 主结构：标题+目录 → 结论气泡(先给结论) → 参数表 → 对比图 → 测评总结 → 延伸。
- **推荐理由**：结论先行 + 数据支撑 + 对比可视化，是测评的可信来源。
- **不放**：无依据的证言墙——测评靠客观数据而非粉丝吹捧。
- **不同运营目标怎么调**：涨粉靠专业度和"敢下结论"，争议点反而出圈；变现靠"测评后导购"把好评项软转；复利靠"连续测评系列"建立"这个号测评靠谱"的标签。

### 公告通知
- 主结构：标题 → 注意 WARN → 关键信息卡 → 办理步骤 → 留言。
- **推荐理由**：通知类重信息明确，直接把关键点(时间/地点/对象)卡片化。
- **不放**：促销装饰——通知是正事，别花哨。
- **不同运营目标怎么调**：涨粉变现都不宜在公告里硬来，维持"信息干净"才显得专业；复利靠"通知即服务"，把通知做成能长期放着的索引。

### 连载栏目
- 主结构：标题 → 上期回顾 → 本期内容 → 下期预告 → 关注。
- **推荐理由**：连载靠"上一篇→这一篇→下一篇"的钩子留住追更读者，往期卡/预告条是核心。
- **不放**：跟主线无关的延伸堆砌。
- **不同运营目标怎么调**：涨粉靠"下集预告"吊胃口 + 转发抽奖；变现靠栏目广告位或"先免费几期再收费"；复利是连载的天然主场，把"追更"做成习惯，想沉淀长期读者的首选。

## 四、跨类型通用的"骨架模块"（每篇几乎都要）

无论哪种类型，下面这几个属于"骨架"，矩阵里可能标为"可选"但在多数文章里都在：
- **结尾 CTA**（行动号召）：每篇都有，动词明确（见《结尾行动号召》）。
- **页脚关注/作者/版权**：连载、品牌号必备（见《页脚区》）。
- **封面区**：每篇必配（见《封面与首屏维度》）。

骨架之外，还有一个**贯穿所有类型的节奏底线**：正文各模块之间保持统一的块距，常用 **16px 块距、1.75 行高**，让页面呼吸一致。叙事类靠留白，理性类靠分隔，但两块之间都别忽大忽小——节奏稳了，内容才显得专业。

## 五、矩阵背后的判断原则（遇到表中没有的情况）

表中是"默认建议"，真到具体文章可按三条原则微调：
1. **主心 vs 装饰**：该类型的"推荐"档是主心，是读者期待的内容核心；"可选"是让文章更丰满的装饰与佐证——主心一个不少，装饰克制。
2. **转化目标**：想引导成交的，往上"转化"列加档（证言/价格/CTA）；想沉淀关注/复利的，加"延伸/互动"。判断依据＝这篇的运营目的是卖货、涨粉还是做长期内容库。
3. **克制优先**：拿不准时往"低档"走——少放一个模块比多放一个更安全（见《避免模块堆砌》检查清单）。

## 六、常见错误

1. **类型与模块错配**：情感文堆步骤清单、通知文堆促销装饰——先定类型再用表。
2. **把所有可选都加上**：可选档全塞导致塞成拼盘，装饰超载。主心 + 2-3 个可选足够。
3. **把"不用"档硬放进去**：产品软文不放客观数据反而全凭吹捧；新闻里塞投票互动——多数"不用"是有原因的。
4. **标题误导类型**：正文是干货感、标题却带货腔，读者进来发现错位——标题与内容类型、模块一致。

## 七、个性化空间（可调参数与判断依据）

- **档位微调**：矩阵是"大部分账号的平均值"。你的账号有长期粉丝圈层、且已形成口碑时，可把某些"可用"升为"推荐"（如带货号把证言升级为主结构）。判断依据＝账号的实际运营数据与读者画像。
- **跨类型混合**：一篇文章可两个类型混合（如"干货 + 软转"），此时取两列模块的交集/并集，但**主心只能有一个**——别刚讲干货又忽转促销。
- **栏目固化**：连载/系列可把特定模块固化成标配（如每期固定的"上期回顾+下期预告"），形成栏目记忆点。判断依据＝栏目的稳定性。
- **间距即风格**：块距与行高可以算一种"模块外的风格参数"。叙事号喜欢更松的 **16px 块距、1.75 行高** 配大留白；导购号宁可紧一点让信息密度高。参数选一种，全文一致。

## 八、发布前用矩阵做一次快速复核

- [ ] 这篇内容类型确定，并对照矩阵核对了该列的推荐档模块？
- [ ] 用到该类型"推荐"档的每个主心模块？
- [ ] 可选档只加了必要 2-3 个，未塞成拼盘？
- [ ] 没有强行使用该类型"不用"档的模块？
- [ ] 结尾 CTA、页脚关注等骨架已补齐？
- [ ] 正文各模块块距/行高统一（如 **16px 块距、1.75 行高**）？

## 九、同一内容类型、三种运营目标下矩阵怎么动

运营目标一句话：**涨粉**＝让更多人看到并愿意转发关注；**变现**＝把流量换成订单；**复利**＝让读者反复回来看、形成长期沉淀。同一个内容类型，目标不同，档位要跟着调。

| 内容类型 | 涨粉优先 | 变现优先 | 复利优先 |
|---|---|---|---|
| 干货教程 | 案例放大、痛点戳准，加"收藏转发"引导 | 文末软转价格卡（见第十节） | 固定系列预告，让人往回追 |
| 新闻资讯 | 标题+导语做钩子，把话说全 | 一般不动（与新闻气质冲突） | 多接延伸阅读，导到历史同题 |
| 情感随笔 | 共鸣+转发点，结尾"转给那个TA" | 基本不做硬转，角落软植入 | 固定情绪栏目感，期待下期 |
| 产品软文 | 弱化硬销，多讲使用场景 | 价格/证言/CTA 拉满 | 选品系列+售后答疑栏目 |
| 活动促销 | 拉新有礼/转发抽奖引流 | 倒计时+行动按钮一个不少 | 固定活动流程，形成记忆点 |
| 品牌故事 | 故事传播性，引导转发 | 认同后自然信任，含蓄带产品 | 反复讲同一句理念，沉淀记忆锚点 |
| 人物故事 | 经历越具体越有传播力 | 人物与产品的信任传导 | 人物系列连载，讲深讲透 |
| 盘点清单 | 明确引导"收藏+转发" | "同类导购"软转一两项 | 定期更新榜单（每月一版）|
| 科普测评 | 专业度+"敢下结论"，争议出圈 | 测评后导购，好评项软转 | 连续测评系列，"测评靠谱"标签 |
| 公告通知 | 信息干净即是涨粉（专业感） | 不宜硬来 | 通知做成可长期放置的索引 |
| 连载栏目 | 下集预告吊胃口+转发抽奖 | 栏目广告位或先免后收 | 天然主场，把"追更"做成习惯 |

注意：多数账号不是"只做一个目标"，而是**一篇一个主目标**。主打"涨粉"的文章就别硬塞价格卡，主打"变现"的别指望读者主动转发。目标错位是矩阵失效最常见的来源。

## 十、跨类型混合写法（把两列拼出一列）

一篇文章可以"表面是 A 类型、实际上略带 B 类型的意图"，最常见两对组合：

### 干货 + 软转（教程顺手带货）
- **规则**：主心只能是干货（步骤/清单/案例是主角），转化只在**文末**用一个小价格卡/CTA 收尾，前面不打断节奏。
- **注意**：干货段与软转段之间用分隔（如 **16px 块距、1.75 行高** 的统一节奏 + 分割线）明确"讲完干货、进入卖货"，别让读者觉得被偷袭。
- **红线**：干货占比必须远大于软转，否则变成挂羊头卖狗肉，掉粉。
- 适用：测评导购、工具类教程、盘点榜单带同类商品。

### 资讯 + 延伸（新闻引出观点/栏目）
- **规则**：资讯正文保持客观克制，延伸部分明确用分隔块标成"我的看法/延伸阅读"，让"事实"和"观点"分开。
- **注意**：延伸可以带栏目钩子（"下期我拆解这个"），但不要 把评论混进资讯正文。
- **红线**：别让新闻被自己的观点带偏，失了"快准全"。

### 通用混合口诀
- 取两列模块的**交集**当主结构，**并集**按需补，但**一句话主心只能有一个**。
- 混合时优先保"更克制、信息更少"那一类的模块，另一类的模块明显降档。
- 两个类型若气质冲突（情绪文+促销、通知+硬广），**别硬混**，见第六节常见错误。

## 十一、叙事类 vs 理性类：对照看清各自该有什么

矩阵里的 11 类可以粗略归成两派：**叙事派**（情感随笔、品牌故事、人物故事、连载栏目）靠"情绪/故事/共鸣"留住人；**理性派**（干货教程、科普测评、盘点清单、新闻资讯、公告通知）靠"信息/逻辑/数据"说服人；**导购派**（产品软文、活动促销）是理性的变体，多带一个转化目标。

| 维度 | 叙事派（人物/品牌/情感） | 理性派（干货/测评/盘点/资讯） |
|---|---|---|
| 读者为何看 | 图情绪共鸣、图人设认同 | 图信息增量、图"学得会/信得过" |
| 主心模块 | 金句quote、叙事段落、时间线、身份卡 | 步骤、清单、参数表、对比图、结论气泡 |
| 转化怎么放 | 基本不放，或极柔软 | 可在文末/测评后软转 |
| 互动靠什么 | 留言倾诉、转发共鸣 | 收藏、延伸阅读、提问答疑 |
| 排版气质 | 松散留白，块距大一点（**16px 块距、1.75 行高**）| 结构分明，卡片/表格分隔清晰 |
| 常见误区 | 塞步骤清单，写成教程 | 堆情绪金句，丢了干货密度 |

一句话分法：**让读者"心里动一下"的走叙事派，让读者"脑子里记下东西"的走理性派**。先分派，再进矩阵选模块，方向就不会乱。

## 十二、从矩阵到成文的最小检核

排版前把矩阵过成一行"手术单"，照着填即可：

- [ ] 内容类型、主目标（涨粉/变现/复利）都定下来。
- [ ] 从第二节抄下该类型的推荐档模块清单。
- [ ] 确认主心只留一个（混合时见第十节）。
- [ ] 骨架四件（CTA、页脚、封面、统一节奏）已配齐。
- [ ] 全文块距/行高统一（**16px 块距、1.75 行高**），无忽大忽小。
- [ ] 发布前再跑一遍第八节复核清单。
