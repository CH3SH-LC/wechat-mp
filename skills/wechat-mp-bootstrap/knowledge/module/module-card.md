# 模块 · 卡片（归纳容器）

> 定位：把一段相互关联的并列信息"收进一个框里"，让读者把这一块当一个整体来看——字段有多项、彼此并列、需要一眼归为一类时最合适。卡片是"归纳容器"，负责把散乱的并列信息团成一块，**不是装饰**。框本身不抢戏，让里面的内容因为"有了框"而显得有序。
> 调用时机：**3 条以上并列项**、产品参数、对比、小标题下的多要点需要归拢成"一块"时。卡片里面装的是"一段有结构的内容"（标题 + 若干条要点），不是单个气泡一句话。**一篇只用一个卡片样式**（白卡/浅底/实色顶条/双线/分栏，选一个，别混），这是卡片模块的铁律。

## 一、可用写法与语法

写作语法：用容器语法 `::: card` 包住内容，正文里它会渲染成一整块带底、带边或带顶条的区域，里面的文字自然归为一个整体。

**什么时候该用卡片**（符合其中之一就用）：
- 内容有 **3 条以上并列项**，而且它们属于"同一主题"（如一个产品的屏幕、电池、防水三个参数）；
- 内容是 **小型结构**（一个标题 + 一两句说明 + 一组要点），需要内部有小层级；
- 需要与正文其他部分**明确区分**出来（如"注意事项""参数""对比"），框能替你做这种"区隔"。

**什么时候不要用卡片**：
- **只有一句话**——那是气泡（「模块 · 重点气泡」）的活，单体强调不需要框来归纳；
- **内容超过一屏且是一个大段落**——那是章节头 + 正文的活，硬塞进框会让读者对着一个大方块发怵。
卡片是"中号容器"：装得下"一组要点"，装不下一篇文章。

**写法铁律**：
- 卡内要有标题 + 至少 2-3 条内容才配叫"归纳容器"；只有一个标题下面空空的，是空架子。
- 卡内的并列项**性质要一致**——都是优点、或都是参数、或都是注意点，别把优点和注意事项混进同一张卡。
- `::: card` 是编辑器默认样式；想要实色顶条、双线、分栏这类更强的写法时，改建"内联样式手写版本"（见第三节），两者的内容写法一致。

## 二、双模式表现（文字类/宣传类）

**文字类（文字排版优先）**：白底细边框，或极浅底色，圆角适度，内文保持和正文一致的字号与行高（标题 15px、正文 14px、行高 1.75）。强调"信息归组"，视觉安静、不喧宾夺主。适合干货、教程、资讯文——这一类读者要的是"看清结构"，框够轻、结构够清就好。

**宣传类（视觉优先）**：可加实色顶条、主色点缀 + 细边框，在白卡上做"彩色抬头"来突出同类中的重点项（比如三选一里的"推荐项"）。视觉更"跳"，适合促销、产品页、活动——这一类读者的注意力需要用颜色"接住"。

**两个模式在同一篇里只选其一**：文字类全文白底细边框或浅底，宣传类全文实色顶条或彩色点缀，不要一半细边框、一半实色顶条——混用等于让读者以为"细框和顶条是两种不同语义"，严重破坏一致性（见「密度限制」一节与模块组合铁律）。

## 三、样式变体（5 种常用，具体参数）

五种最常用的卡片模板，**每种都给到色号、圆角、padding、字号、背景**。所有卡片遵循硬规范：外间距下方 `margin:0 0 16px`、内文行高 1.75、卡内文 padding `14px 16px 12px`。

**变体 A｜白卡细边框（最稳）**——适用：一切信息归纳，兼容性最好：
```html
<div style="background:#fff;border:1px solid #f0f0f0;border-radius:12px;
            padding:14px 16px 12px;margin:0 0 16px;">
  <p style="margin:0 0 10px;line-height:1.5;font-size:15px;font-weight:bold;color:#333;">核心参数</p>
  <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 屏幕：6.7 英寸</p>
  <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 电池：4500mAh</p>
  <p style="margin:0;line-height:1.75;font-size:14px;color:#555;">· 防水：IP68</p>
</div>
```
- 参数：白底 `#fff`、边框 `1px solid #f0f0f0`、圆角 12px、padding `14px 16px 12px`；卡标题 15px 加粗、正文条目 14px、行高 1.75。想更"立"可加细边框 `border:1px solid #e0e0e0` 加深描边，不靠投影。

**变体 B｜浅底圆角大卡（底色分区）**——适用：想让这块"有底色地浮起来"、不靠边框：
```html
<div style="background:#f7f9fc;border-radius:12px;padding:16px 16px 12px;
            margin:0 0 16px;">
  <p style="margin:0 0 10px;line-height:1.5;font-size:15px;font-weight:bold;color:#2c3e50;">为什么重要</p>
  <p style="margin:0;line-height:1.75;font-size:14px;color:#4a5a6a;">各类数据常用来支撑观点，卡片能把结论归拢成大块，读者扫一眼就抓住了要点。</p>
</div>
```
- 参数：底色 `#f7f9fc` 极浅灰蓝、圆角 12px、padding `16px 16px 12px`、无边框无投影，靠底色成块。底色越浅越安静，越接近主色越醒目（换色见「配色配合」）。

**变体 C｜实色顶条白卡（宣传类·推荐项突出）**——适用：三选一推荐、主推套餐：
```html
<div style="background:#fff;border:1px solid #f0f0f0;border-radius:12px;margin:0 0 16px;overflow:hidden;">
  <div style="background:#e56b2f;padding:10px 16px;">
    <p style="margin:0;line-height:1.5;font-size:15px;font-weight:bold;color:#fff;">推荐组合</p>
  </div>
  <div style="padding:14px 16px 12px;">
    <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 一年会员</p>
    <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 全年资料库</p>
    <p style="margin:0;line-height:1.75;font-size:14px;color:#555;">· 一对一定制</p>
  </div>
</div>
```
- 参数：外层白底 `border:1px solid #f0f0f0` 圆角 12px、`overflow:hidden`（让顶条圆角贴合）；顶部实色条 `background:#e56b2f`、白字 15px 加粗；内容区再 `padding:14px 16px 12px`。顶条是整张卡最醒目的"抬板"。

**变体 D｜双线角块（强调边界）**——适用：规则、注意事项、明细：
```html
<div style="border:1px solid #c8c8c8;border-radius:12px;padding:14px 16px 12px;
            margin:0 0 16px;">
  <p style="margin:0 0 8px;line-height:1.5;font-size:14px;font-weight:bold;color:#333;">注意事项</p>
  <p style="margin:0;line-height:1.75;font-size:13px;color:#666;">以上价格为含税价、不含运费，大宗采购可另议。</p>
</div>
```
- 参数：外边框 `1px solid #c8c8c8`（较深细边）+ 圆角 12px；标题 14px、说明 13px。双线边界不用内层描边阴影，改用"外边框 + 内留一条 `1px solid #f0f0f0` 细边 span"或直接加深外描边来宣告边界。

**变体 E｜分栏卡（并列两列/三列）**——适用：两两对比、横向并列特征：
```html
<table cellpadding="0" cellspacing="0" border="0"
       style="width:100%;border-collapse:collapse;margin:0 0 16px;">
  <tr>
    <td style="width:50%;vertical-align:top;box-sizing:border-box;">
      <div style="background:#f0fbff;border:1px solid #d9f0f5;border-radius:10px;padding:14px;margin:0 6px 0 0;">
        <p style="margin:0 0 6px;font-size:13px;font-weight:bold;color:#0ba89b;">优点</p>
        <p style="margin:0;font-size:13px;color:#4a6a63;line-height:1.7;">一键部署、持续更新</p>
      </div>
    </td>
    <td style="width:50%;vertical-align:top;box-sizing:border-box;">
      <div style="background:#fff7f2;border:1px solid #f7e0d3;border-radius:10px;padding:14px;margin:0 0 0 6px;">
        <p style="margin:0 0 6px;font-size:13px;font-weight:bold;color:#e56b2f;">注意</p>
        <p style="margin:0;font-size:13px;color:#8a5a45;line-height:1.7;">需要备案、有配额</p>
      </div>
    </td>
  </tr>
</table>
```
- 参数：`<table>` 两列各 50%（三列各 33%），卡内 padding 14px、圆角 10px，两卡中缝各 8px 凑成 16px（`margin:0 6px 0 0` 与 `0 0 0 6px`）。**所有并排卡必须 `box-sizing:border-box`**，防止 padding 把宽度撑破。

## 四、使用时机与位置

- **产品/参数正文**：用白卡或浅底卡收纳"参数表 / 特征清单"，比平铺成普通段落清晰得多（一屏 3-5 条最顺）。
- **对比段落**：用分栏卡做"前后 / 优劣 / 左右"对照（见变体 E），读者左右一眼比出差异。
- **章节内"注意事项 / 特别说明"**：用双线卡或浅底卡，把它和主体论述区隔开来，别让它淹没在正文里。
- **推荐 / 主推**：用实色顶条卡突出（宣传类首选），给"我要你选的那个"一个彩色抬头。
- **位置**：卡片通常出现在"该主题论述完之后"作为小结归纳，或并列项集中的地方。别把卡片当"正文分段工具"——正文普通段落负责叙述推进，卡片是给"并列 / 归纳"用的。一张卡结束后，可以紧跟一段正文把它讲透，形成"卡归拢 → 正文深化"的节奏。

## 五、风格适配（4 个例子）

- **极简/商务**：只用白卡细边框 + 无色的灰底 `#f5f6f7`，圆角收紧到 8px 显得利落，标题 14px 深灰加粗，整体黑白灰，靠结构不靠颜色。
- **国潮风**：白卡配朱砂红细边框 `1px solid #9a281f`、转角更圆润；标题左侧可加 `border-left:3px solid #9a281f` 模拟印章竖条，配米白底 `#fff7ef`。
- **科技/数码**：浅底卡用冷蓝 `#f0f5ff`、边框 `#d9e4ff`，标题青色 `#2f6fed`，圆角 8px，描边更硬朗，冷感强。
- **电商/促销**：实色顶条卡 + 主推项做 `border:2px solid #e56b2f` 高亮，其余同款式但弱化（无顶条、细边框），让"推荐的那个"一眼跳出来。

**风格统一原则**：卡的风格要与整篇其他模块（气泡、列表、标题）保持一致——如果气泡用浅底左竖条，卡也用同色系的浅底/细边框；如果标题是实色块的，卡也跟随实色顶条。风格是"全篇穿的一套衣服"，卡片不能单独换装。

## 六、间距与尺寸（遵守硬规范）

- **卡片与前后块**：`margin:0 0 16px`（块距基线 16px）。多张并列卡之间同样是 16px，别一个挨一个。
- **卡片内边距**：`14px 16px 12px`（硬规范「卡片内文 padding 14px 16px 12px」）；实色顶条卡的内容区同样 `14px 16px 12px`，分栏卡内 14px。
- **卡内层级间距**：标题与首条内容 10px；条目之间 6-8px；标题行高 1.5、正文 1.75。
- **圆角**：8 / 10 / 12 / 14px 由风格软硬决定，**同组统一**（别一张卡一个圆角）。圆角不超过内容高度的一半。
- **字号**：卡标题 15px（内容稍多时用 14px）、正文 14px、分栏/三栏精简到 13px。卡内不要出现 17px+ 的大字，卡片是归纳不是标题。
- **分栏宽度**：两列各 50%、三列各 33%；并排卡必带 `box-sizing:border-box`，padding 才不撑破宽度。

## 七、配色配合（与全篇色盘协同）

卡片不是独立的色块，它的颜色必须从全篇色盘里取。**一篇正文只用 1 个主强调色贯穿所有强调点**（卡片、气泡、列表符号、高亮共用同一个主色）。

- **单主色用法**：整篇卡片用同一个主色（如青）做细边框/浅底，靠"边框深浅"而非换色来分轻重——普通参数用灰边框，重点项用主色边框 + 加粗。最克制、最好维护。
- **双主色用法**：一个主色 + 一个警示色（如"主色青 + 警示红"）。主色用于普通归纳，警示用于"注意/改价/规则"。适合宣传类，但红色只能是少数点。
- **品牌色替换**：把默认的白/灰边框、浅底整体替换成品牌色体系（一套品牌色对应深浅档位）。判断依据：品牌色能否连贯地表达"普通 → 重点"的梯度，若只能挤出一个色就退回灰边框 + 主色点缀。
- **避免**：五种卡片样式五种颜色齐上（白卡、蓝底、紫实色块开会），读者分不清轻重。全篇卡片颜色 ≤2 个主色最佳。
- **与正文关系**：卡底色/边框要与正文文字 `#333`、正文灰 `#555` 区分度足够（卡内文字与底色对比度 ≥4.5:1，见「可读性」维度）。浅底配深字最稳，实色顶条配白字也稳定。

## 八、微信兼容注意

写卡片时的"可用子集"与"要绕开的坑"（微信富文本编辑器）：

- **可用**：`background`（纯色）、`border` 1px 实线、`border-radius`（8/10/12/14)、`padding/margin/line-height/font-size`、`overflow:hidden`、`display:inline-block`；分栏可用 `<table>` + `table-cell`（`td`）。本规范统一纯色 + 细边框，微信端渲染最稳。
- **尽量别用**：`backdrop-filter`（基本不生效、可能整块变白）、`border-image`/`outline`（定位不稳）、伪元素 `::before/::after`（编辑器多剥除）。本规范禁投影——要"浮起/强调"一律用细边框 + 留白 + 圆角达成，不写投影样式。
- **分栏安全写法**：并列卡用 `<table cellpadding="0" cellspacing="0" border="0">` + `<td style="box-sizing:border-box">`；别用 `float`（旧客户端换行错乱）、也别用 CSS grid（不识别）。
- **纯色兜底**：本规范不推荐渐变、不推荐投影，统一纯色 + 细边框。若沿用旧样稿仍有渐变顶条说明，一律改为实色顶条（如 `#e56b2f`）为准。
- **通用兜底原则**：任何装饰都是"锦上添花"，优先保留"白底/浅底 + 细边框 + 圆角"这个最稳组合——装饰失效后内容仍然可读、仍成块。

## 九、密度限制（重要）

- **一种样式到底**：同篇只用一个卡片样式（白卡/浅底/实色顶条/双线/分栏，选一）。三种混用 = 灾难（铁律）。
- **卡片数量**：一篇 **3-5 张**足够，别把全文都装进卡里——正文段落也要呼吸。超过 5 张卡，说明你在用卡代替正常叙述，要回头削减。
- **卡片不嵌套卡片**：一张卡里别再塞第二张卡。双层可以接受，三层以上在手机上挤到没法读。卡内并列点用圆点列表，别再造一张小卡。
- **卡片不叠加气泡**：这一屏已有重点气泡，就不再放实色顶条卡——两者都是"亮块"，同屏一个就好（见模块组合铁律：气泡 ≤2、卡片 ≤5）。
- **性质一致**：同一张卡内的并列项性质要统一（都是优点 or 都是参数 or 都是注意点），别把"优点 + 注意"塞进同一张卡让读者困惑。

## 十、常见错误（反例 + 正解）

- **反例**：同一篇用了实色顶条卡 + 白细边框卡 + 分栏卡三种 → **正解**：只选一种全篇统一；要突出重推项，可在同款式内用边框粗细/顶条做"程度"区分，不换样式。
- **反例**：卡片里只有一句话"本产品很好" → **正解**：一句话用重点气泡（「模块 · 重点气泡」）；卡片至少要有标题 + 2-3 条内容才算"归纳容器"。
- **反例**：分栏卡两栏高度差很大（左卡 8 行、右卡 2 行），table 自动等高后右卡下方一大块空白 → **正解**：左右内容保持行数接近，或改成上下两张卡，别强撑两栏。
- **反例**：卡片内装了整整 200 字的一段 + 一张大图 → **正解**：卡内内容控制在标题 + 3-5 条要点；长段落交给正文，大图交给「模块 · 图片」。
- **反例**：卡内文字缩到 13px 还塞了 8 条要点，字号太小、内容太多 → **正解**：卡内要点 ≤5 条，正文保持 14px，别排版排到反人类。
- **反例**：一张卡里既写"优点"又写"注意事项"，读者分不清到底在夸还是在提醒 → **正解**：一张卡一个主题，多主题就拆成两张卡（优点一张、注意一张）。

## 十一、示例（可用骨架，标注可替换处）

```markdown
::: card
**核心参数**  
· 屏幕：6.7 英寸  
· 电池：4500mAh  
· 防水：IP68
:::
```
（文字类默认卡样式：白底细边框。**可替换**：标题、条目内容、条数 ≤5。）

```html
<!-- 白卡细边框（信息归纳最通用）：可替换色号/圆角/标题前缀/内容 -->
<div style="background:#fff;border:1px solid #f0f0f0;border-radius:12px;
            padding:14px 16px 12px;margin:0 0 16px;">
  <p style="margin:0 0 10px;line-height:1.5;font-size:15px;font-weight:bold;color:#333;">为什么值得买</p>
  <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 参数一：具体值</p>
  <p style="margin:0 0 6px;line-height:1.75;font-size:14px;color:#555;">· 参数二：具体值</p>
  <p style="margin:0;line-height:1.75;font-size:14px;color:#555;">· 参数三：具体值</p>
</div>
```
**可替换处**：边框色 `#f0f0f0`、圆角 12px、条目（≤5 条）。判断依据：是不是"同一主题的并列信息"——是才用卡，且全篇同款式。

## 十二、个性化空间（可调参数与判断依据）

- **样式选择**：白卡（通用）/ 浅底（分区）/ 实色顶条（推荐）/ 双线（规则）/ 分栏（并列）。判断依据：内容的"语义"——并列对比用分栏、主推用实色顶条；但全篇锁定一种（主推项可在同款式内加粗/加框做程度高亮）。
- **边框 vs 底色**：边框 = 靠线成块的"正式"感；底色 = 靠色成块的"柔和"感。判断依据：行业与风格——金融/数码用边框，生活方式/教育用浅底。
- **圆角**：8（利落/商务）/ 12（通用）/ 14（柔软/童趣）。判断依据：风格软硬，同篇统一。
- **标题装饰**：CSS 方块/菱形 span 前缀，或左竖条 `border-left:3px`。判断依据：想让标题更"立"用左竖条，否则用 CSS 形状前缀即可（用 `display:inline-block` + `transform:rotate(45deg)` 拼菱形，不写字形字符）。
- **卡内密度**：3-5 条。判断依据：≥6 条拆成两张卡，或改用「模块 · 表格」做真正的大表格——卡片装得下要点，装不下数据表。
- **顶条有无**：只在"我要你选这个/这是主推"时加实色顶条。判断依据：顶条是额外强调通道，普通归纳不加，保持卡片本身的克制。
