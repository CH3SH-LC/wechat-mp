# 模块·免责 / 溯源条（风险提示 + 来源标注）

> 定位：给"有风险提示需要"或"引用了外部信息"的内容，在关键位置放**风险提示条**与**来源标注条**，既护读者也护账号。它不是点缀，是合规动作——强合规内容该放不放，出了事才麻烦。
> 调用时机：医疗、法律、投资、用药、保险等强合规内容要放风险条与免责声明；引用数据、报告、他人观点处要放来源标注条。
> 交叉：本条目聚焦"两种条子 + 免责声明"的写法与合规；具体表现与间距见《模块索引》与 00-GUIDE 间距硬规范；双模式表现见《双模式切换》。

## 一、一句话定位

在**强合规内容**开头放风险提示条，在**引用数据/结论**处放来源标注条，把"我说的是参考、不是结论/不是我的原创"讲清楚。两者共同目标：让读者知道这篇该怎么读、信息从哪来，降低误读风险，也为账号留出免责空间。

## 二、两种条子先分清楚

这是两件事，别混成一个组件：

| 条子 | 回答的问题 | 典型内容 |
|---|---|---|
| 风险提示条 | "我该怎么读这篇？" | 仅供参考 / 不构成建议 / 请遵医嘱 / 以官方为准 |
| 来源标注条 | "你凭什么这么说？" | 数据出自 XX 报告 / XX 机构 / 统计年月 |

**风险提示条**是"护栏"——告诉读者这篇不是正式意见/承诺，别照搬执行。
**来源标注条**是"凭证"——告诉读者这些数字和观点从哪来，让他能自行核验。

二者常配套使用，形成完整流程：
1. **开头**放风险提示，先立下"仅供参考"的基调；
2. **正文引用处**放来源标注，证明信息有出处；
3. **文末**放免责声明收尾，交代个人立场与授权。

三个位置各司其职，读者前后都能明白"我在读什么、这从哪来"。

## 三、适用场景与位置表

| 场景 | 用哪条 | 放哪 | 备注 |
|---|---|---|---|
| 医疗/健康建议 | 风险提示 | 开头第一屏内 | 健康号必用 |
| 法律/维权科普 | 风险提示 | 开头 | 强调"不构成法律意见" |
| 投资/理财/基金 | 风险提示 | 开头 + 关键段落 | 强合规必备 |
| 用药/保险 | 风险提示 | 开头 | 加"遵医嘱/读条款" |
| 引用统计局/机构数据 | 来源标注 | 引用处"就地"标注 | 紧跟数据 |
| 引用他人观点/调研 | 来源标注 | 引用处或文末 | 注明编号与出处 |
| 总结性结论/排行榜 | 来源标注 | 结论下方 | 标注依据来源 |

**判断依据（一句话规则）**：
- 内容**越影响读者真金白银或身体健康**，提示条就越靠前、越醒目。
- 医疗/金融/法律属强合规，提示条放开头且措辞完整。
- 生活技巧、读书心得、情感随笔影响面小，风险提示可省略或弱化。
- 但**只要引用了别人的数据，来源标注就不能省**——这是底线。

## 四、标准句式与填空模板

调用方把 `{…}` 换成具体内容即可。

### 风险提示条（按领域选一句或组合）

> [!NOTE] 本文内容为{科普/信息整理/个人经验分享}，仅供参考，不构成{医疗建议/法律意见/投资建议}。涉及具体决策，{请先咨询专业医生/请咨询专业律师/请以官方公告为准}。

> [!WARN] 健康/医疗：本文旨在帮助你理解相关概念，不能替代医院的面对面诊疗。如有身体不适，请及时就医。

> [!WARN] 投资/理财：市场有风险，入市需谨慎。文中观点仅代表个人，不构成任何投资建议，过往表现不代表未来收益。

> [!WARN] 法律/维权：本文为一般性知识科普，不构成法律意见。具体案件请咨询执业律师。

> [!NOTE] 用药/保险：请严格遵医嘱或按药品说明书使用；保险产品请仔细阅读保险合同与免责条款。

### 来源标注条

> [!TIP] 数据来源：{机构名}《{报告名}》{年份/期号}，完整出处见文末备注{编号}。

### 文末免责声明块

> 本账号发布的所有{科普/体验/观点}内容仅代表作者个人立场，与本平台无关。若引用内容不当或构成侵权，请联系后台删除。{本文不含商业推广，如含合作会在文首标注。}

### 改写技巧（把套路话变人话）

- 把空泛"仅供参考"改成具体——"本文仅帮助你理解概念，不能替代面对面诊疗"。
- 把"不构成建议"改成"如有疑问请先问专业人士"。
- 语气平稳、负责，既不让读者恐慌，也不轻描淡写地打包票。
- 避免"甩锅腔"——别把免责声明写得像在推卸责任，而像在认真提醒。

## 五、样式与双模式表现

- **文字类（克制冷静）**：用 `> [!NOTE]` / `> [!TIP]`，浅灰蓝底、细线条、字号 13–14px，不抢正文焦点。
- **宣传类（醒目但克制）**：风险条用 `> [!WARN]` 弱橙黄底提醒，来源条用细卡片。
- **合规条子不必华丽**——重点是清楚、负责任，不是好看。
- 位置规则：
  - 风险条＝开头首屏内；
  - 来源条＝就地紧跟数据；
  - 免责声明＝结尾页脚前。
- 位置固定，方便读者形成预期，每次发文都落在同一处。

## 六、样式变体（4 种，带骨架）

### 变体 A｜单行风险条（最短，轻量风险）

```html
<section style="background:#fff7e6;border-left:4px solid #ffb020;border-radius:0 8px 8px 0;padding:10px 14px;margin:0 0 16px;">
  <p style="font-size:13px;color:#8a6a30;line-height:1.7;margin:0;">本文仅为科普分享，不构成任何专业建议。</p>
</section>
```

### 变体 B｜风险 + 溯源双条卡（推荐，开头一张解决）

```html
<section style="background:#f7f7f7;border:1px solid #eee;border-radius:12px;padding:14px 16px;margin:0 0 16px;">
  <p style="font-size:14px;color:#666;line-height:1.75;margin:0 0 8px;">本文为信息整理，仅供参考，不构成投资建议。入市有风险，决策请谨慎。</p>
  <p style="background:#ddd;height:1px;margin:0 0 8px;line-height:1px;font-size:1px;">&nbsp;</p>
  <p style="font-size:12px;color:#999;line-height:1.7;margin:0;">数据均标注来源，可自行核验。</p>
</section>
```

### 变体 C｜文末免责声明块（低调收尾）

```html
<section style="background:#fafafa;border:1px solid #eee;border-radius:8px;padding:12px 14px;margin:24px 0 0;">
  <p style="font-size:12px;color:#999;line-height:1.6;margin:0;">本文仅代表作者个人观点，与本平台无关。引用数据均标注出处，若有侵权请联系删除。本文不含商业推广。</p>
</section>
```

### 变体 D｜就地溯源 + 文末完整列表（报告型文章）

正文引用处写法：
> 我国快递业务量突破 1800 亿件（据国家统计局 2023 年报，见文末 1）。

文末编号完整出处：
> 1 国家统计局《2023 年国民经济和社会发展统计公报》，2024-02
> 2 中国互联网络信息中心《第 53 次统计报告》，2024-01

## 七、合规重点（必读，这是命根子）

1. **别因粉丝少就省**：医疗/投资/法律内容即使阅读量低，风险提示条也是必要动作，不是可选装饰。
2. **引用了就标注**：凡用别人的数据、图表、报告、金句，都要标来源。
3. **记不清出处就写明**：不确定出处的，稳妥写"内容整理自公开信息"，绝不明造机构或报告名。
4. **风险条本身也得合规**：提示条里绝不出现"保证根治""稳赚不赔""绝对有效"等承诺性表达——提示条是降低风险，不是再造违规点。
5. **效果承诺闭环**：凡涉及"看完你就能……"，尽量在提示条加一句"效果因人而异"，讲清不确定性。
6. **行业红线叠加检查**：医疗/投资/教育类证言与效果话术，额外看各维度合规底线，不能只在提示条遮掩。

## 八、间距尺寸（遵守硬规范）

- 风险/来源条：块间距 16px、行高 1.75。
- 气泡内文：`padding:14px 16px`。
- 开头风险条与首段之间：块距 16px。
- 文末免责声明与前文之间：建议 24px（语义块切换）。
- 免责声明字号可降至 12px、行高 1.6，降低存在感。
- 页边距不自设（正文自带左右 16px）；条子不额外内缩，避免三层缩进。

## 九、密度限制

### 布局
- 风险提示条：全篇 **1 条**（开头），特殊多风险内容关键段可再加 1 条，总上线 **2 条**。
- 来源标注条：就地随引用处，数量随引用次数；但**同一来源重复引用只标一次**，后续用"同上"，别每次重复一段。
- 免责声明：**1 处**（文末）。整篇合规条数合计可控，别堆砌成一屏免责条文把正文挤没。

## 十、微信兼容注意

- 气泡/卡片语法在微信富文本可正常展示；粘贴外部模板后自查 16px 块距、1.75 行高。
- 来源链接若做不成可点击卡片，用**纯文字标注**（机构名+报告名+年份）即可——"信息齐全"优先于"可跳转"。
- 免责声明块用纯浅底 + 细边框即可，稳妥不依赖特殊渲染；本规范不推荐渐变，统一纯色 + 细边框。
- 若涉及外链数据源，写明"复制链接到浏览器查看"，别依赖端内直接跳转。

## 十一、常见错误（返工项）

1. **风险条放太靠后**：读者都读完干货才看到提示，提示失效。务必开头首屏。
2. **只标来源不标风险**：医疗内容只写"数据来自 XX"却没说"不构成建议"，仍有隐患。
3. **免责声明堆砌吓跑读者**：一整屏免责条文挤没正文。抓关键，控制篇幅。
4. **引用不标注**：最危险，涉及侵权与"洗稿"，红线中的红线。
5. **来源条出现编造出处**：不确定就写"公开信息整理"，绝不虚构机构或报告名。
6. **风险条本身违规**：提示条里出现"保证有效"——提示条是防护，不能是新的违规点。

## 十二、个性化空间（可调参数与判断依据）

- **提示强度按账号领域自定**：健康/金融号必须强警示（放开头 + 措辞完整）；生活/情感类弱化为一句话。依据＝内容影响面。
- **免责声明详略结合账号历史**：有投诉史或踩线史的写完整；运营稳定的新号可从简。依据＝账号合规风险敞口。
- **来源链接形式**（纯文字 vs 可点击卡）按排版工具能力自定，但**信息必须齐全**，这是唯一不可妥协的底线。
- **是否声明"不含商业推广"**按账号是否常带货自定：常带货的号在免责块加这句更能取信读者。
- **提示条语气**按账号人设：亲切号写"先别急着照做，听我把话说清楚"更自然；专业号用正式句式更可信。

## 十三、三段条子如何编排（健康/理财/法律文的合规骨架）

以一篇**理财/健康/法律类干货文**为例，把三条落到正文的具体位置：

1. **首屏内（标题下、钩子前）**：风险提示条——`> [!WARN] 本文为信息整理，仅供参考，不构成投资/医疗/法律建议`。
2. **正文每个关键数据处**：就地来源标注——`（数据：XX 研究院 2023，见文末 1）`；涉及强弱结论再补一句"仅作参考，方向以官方为准"。
3. **文末、CTA 之后**：免责声明块——整段收尾，交代个人立场、引用授权、是否含推广。

**顺序原则**：风险条永远在读者"付出信任"之前；来源标注永远在"信息被采信"的同一屏内；免责声明在"行动号召"之后，别让免责提示凉了 CTA 的热度——三条形成「事前提醒、事中溯源、事后声明」的链条，读者从头到尾都知道自己在读什么。

## 十四、与相邻模块的衔接

- **与开头页眉**：风险条紧跟标题与首屏，别放在第一章之后。可先用一句钩子，再落地风险条，顺序灵活但都要够靠前。
- **与重点气泡**：风险条用 NOTE/WARN，正文重点用 KEY——别把"风险提示"和"核心卖点"用同一个风格气泡，读者会分不清哪个是提醒、哪个是卖点。
- **与延伸阅读**：若文末有往期推荐，免责尽量放在延伸或页脚之间更靠后处，别夹在延伸列表中间打断阅读。
