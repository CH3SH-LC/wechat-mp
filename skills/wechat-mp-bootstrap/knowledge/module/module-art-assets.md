# 美术资产总目录（module-art-assets）

> 定位：全部 `art://` 图案资产的查询目录——按用途选资产、按规格引用、按铁律约束。正文禁止 emoji 与图标字符后，图案装饰的唯一来源就是本目录资产（或 CSS 几何形状）。
> 交叉：密度限制与各风格条目一致（每屏装饰 ≤1 处）；气泡角饰另有 `> [!KEY|grass]` 语法（见 module-bubble）；分割线花边用法见 module-divider。

## 一、核心规则（先读）

1. **资产是 PNG 图片，不是 CSS**：SVG 内允许渐变、明暗分层（客户端 canvas 渲染成 PNG 上传微信），**正文 CSS 平面化铁律（零渐变/零阴影/零 emoji/零图标字符）不受影响**——铁律管正文内联样式，不管图片内容。这是复杂插画资产（第二级）可以带光影层次的依据。
2. **图案必须植物/自然类**，绝不用图标/贴纸类图案（箭头、表情、电子图标一律禁止）。
3. **引用方式**：`![说明](art://资产名)`；使用前需在面板「渲染并上传」（`wechat_mp_art` 上传得到永久 URL 并缓存）；未上传的引用会被移除并产生警告。
4. **展示规格（系统自动处理，正文不用设尺寸）**：整行装饰图自动居中收窄至 ≤56%≈179px 宽、不进卡片；气泡角饰按 60px 显示；横幅/边框类资产按图自身比例缩放。
5. **密度铁律**：每屏装饰 ≤1 处，不铺满；气泡角饰一个气泡顶多加一处。

## 四、选择指引（按用途速查）

- **气泡角饰**：小图优先 `sprig-grass` / `leaf-corner`；想更丰富用 `corner-flourish`；语法角饰用 `> [!KEY|grass|blossom|leaf]`。
- **标题装饰**：一侧花枝用 `spring-branch` / `plum-branch` / `blossom-branch`；包围式用 `arch-garden` / `frame-gilt` / `vine-frame`（后者配 `[[title:文字|vine]]` 语法）。
- **章节开篇/收尾横幅**：`sunrise-panorama`（启程）、`moon-night`（夜思）、`bamboo-mist`（清雅）；内容类大图横幅也可用 `ribbon-sash` / `flower-band`。
- **里程碑/奖项/达成**：`seal-red`（官方/年节）、`laurel-badge`（荣誉/冲刺达成）。
- **分隔线**：隆重 `divider-ornate`；轻盈 `vine-divider` / `wavy-line` / `branch-line`。
- **情感点缀**：感谢 `rose-branch`；禅静 `lotus`；新年 `plum-branch`；贺寿 `pine-sprig`。

## 五、风格适配要点

- **国潮/敦煌**：`plum-branch`、`arch-garden`、`seal-red`、`divider-ornate` 优先（东方纹样感）；一级资产保持克制。
- **日系/治愈/森林**：`spring-branch`、`lotus`、`bamboo-mist`、`leaf-corner` 优先；可适度多一档植物点缀但密度铁律不变。
- **校园/插画/手账**：`flower-tiny`、`sun-flower`、`tulip`、`butterfly`、`corner-flourish` 较活泼；插画风可"放肆用植物"但仍每屏 ≤1 处。
- **商务/科技/极简**：仅 `sprig-grass` / `leaf-corner` 级小点缀，至多一处；复杂插画基本不用。
- **深色横幅注意**：`moon-night` 自带墨蓝底，放在白底正文即可，不要放进深色卡片里（图与卡撞色）。

## 六、常见错误

1. **把 art:// 当 emoji 用**（一处一句、一句一图）→ 每屏装饰 ≤1 处，位置只放标题旁/气泡角/分割线中央/章节开篇。
2. **引用未上传资产** → 面板「渲染并上传」后再引用；未上传引用会被移除并告警。
3. **用图标类图案**（箭头/勾叉/表情类）→ 资产必须是植物/自然类。
4. **在深色卡片内嵌深色横幅** → 横幅类资产自含背景，放白底/浅底即可。
5. **同一资产重复堆叠**（一篇里同一个角饰出现 5 次）→ 一种装饰全篇只出现 1-2 次。
6. **认为"图里有渐变=违规范"** → 资产是图片，渐变合法；铁律只管正文 CSS 内联样式。

## 七、可调参数

- 展示尺寸系统固定（装饰图 ≤179px、角饰 60px），正文不设尺寸；如需更大篇幅请改用本地图片而非 art://。
- 密度上限按风格条目（插画/手账可偏高，商务/极简至多 1 处）；同篇装饰 ≤2 种资产。
