# 方法论·文字/宣传双模式切换规则（module-guide-dualmode）

> 定位：同一个账号（甚至同一篇的变体）需要在"文字类"与"宣传类"两套视觉语言间整体切换时，讲清楚怎么切、切到哪、怎么保证不串味。这两套语言不是"风格不同"这么简单，是"克制冷静"与"生动热闹"两套不同的排版语法。
> 调用时机：1一个号要出两种内容的（资讯号偶尔做促销、品牌号既发干货又发广告）；2一篇内容想同时出文字版和宣传版（如"纯干货 + 带货变体"）；3模式切换前自查是否自洽。

## 一、两套模式的差异是什么

| 维度 | 文字类（克制冷静） | 宣传类（生动热闹） |
|---|---|---|
| 整体气质 | 像一本书/一篇文章，靠内容留人 | 像一份广告/海报，靠视觉抓人 |
| 主色 | 克制，1-2 个低饱和色，正文必黑白灰系 | 主色 ≤3（低饱和陶土橙/雾青/墨），多用主色，正文深灰 |
| 标题 | 极简左竖条 / 无装饰 | 纯色横幅 / box / vine 装饰标题 |
| 气泡 | NOTE/TIP 浅底细条 | KEY/TIP/WARN 纯色底 + 可选图案角饰（|grass 等） |
| 卡片 | 细边框/双线角/浅底栏 | 白卡纯色条 / 纯色双层 / 分栏卡 |
| 列表 | 常规圆点 / 灰圆点 | 纯色圆点标记 |
| 纯色块/细边框 | 基本不用或极淡 | 焦点纯色块 + 细边框 |
| 收尾 CTA | 克制号召 + 高亮 | 大字号召 + 限时徽章 |

### 逐模块双态对照（细表）

怕只靠上面一栏记不住"具体哪个模块怎么改"，下面把每个常用模块都拆成"文字态长什么样 → 宣传态长什么样"的两行小表。切换时对着这张表逐项替换即可。

| 模块 | 文字态（克制冷静） | 宣传态（生动热闹） |
|---|---|---|
| 大标题 | 极简左竖条，或干脆不加装饰，靠字号留白撑气场 | 纯色横幅 / box / vine 装饰标题吸引眼球，副标题可上主色 |
| 小节小标题 | 常规加粗或用浅色细线分隔 | 可上色带标题（::: band 斜纹/波点/条纹）或纯色条带出层次 |
| 重点气泡 | NOTE/TIP 浅底细条，`> [!NOTE]` 温柔提醒 | KEY/TIP/WARN 纯色底 + 可选图案角饰，`> [!KEY]` 直接强调卖点 |
| 分类卡片 | 细边框白卡、双线角、浅色底栏，安静收纳 | 白卡套纯色条、纯色双层、分栏卡，把关键词用彩色条托出来 |
| 列表 | 常规圆点 / 灰圆点，不抢正文 | 纯色圆形标记 / 彩色圆点打头，重点项可上色加粗 |
| 步骤序号 | 灰底数字圈，朴素排布 | 彩色圆底数字（::: steps），每步可有纯色圆点标记 |
| 分割线 | 极细中性灰线，低调分段 | 主色细分割线，或花纹色带，把"价格/限量"等段切得更醒目 |
| 徽章 | 少见，若用则浅灰低调 pending | 主色徽章挂顶部，限时/限量/秒杀等紧迫词做成彩底白字 |
| 图片与图注 | 图片端正放置，图注浅灰小字 | 图片可带彩色描边或装饰框，图注跟着主色走 |
| 金句/引语 | 浅底色块 + 中性 quote，安静立论 | 彩色 quote 或大字号金句卡，甚至做成全屏纯色块 slogan |
| 互动模块 | 浅色互动卡，温和引导留言/在看 | 彩底互动卡 + 醒目纯色圆点，直接喊"评论区聊聊/点在看" |
| CTA 收尾 | 克制号召 + 高亮关键词，含蓄 | 大字号召 + 限时徽章 + 价格/小程序卡，一路放大到极致 |

差异根源：文字类服务"读"，宣传类服务"卖"。前者让读者安心读下去，后者让读者快点行动。**两套语言各有各的主色上限、装饰强度、CTA 语气，切换不是"点一下换肤"，而是把上表每一行都换到同一套体系里。**

## 二、切换边界：哪些模块两模式差异大

**切换时重点改的"高差异模块"**（不改就穿帮）：
- 标题区：极简 ↔ 横幅/装饰标题（差异最大，开篇就定调）。
- 重点气泡：浅条 ↔ 纯色底 + 图案角饰。
- 卡片：细框白卡 ↔ 纯色/分栏卡。
- 列表、步骤序号、分割线、徽章：颜色与装饰语言整套更换。
- 图注、金句 quote：字号/配色跟着模式走。

**切换时可保留的"低差异模块"**（两者差距小，可少动）：
- 正文段落本身（都是黑白正文，行高 1.75 一致）。
- 块间距、页边距、行高等硬规范（两模式一致，不因切换改变）。
- 图片本身（配图不用换，只换图注/边框处理方式）。

判断依据：**凡是"外观语言"强（颜色、纯色块、图案角饰）的模块差异大要重点改；凡是"信息本身"（正文、间距、图）差异小可少动。**

## 三、切换规则：三选一，别骑墙

同一篇文章，视觉语言必须整体一致，杜绝"上半文字下半宣传"或"混着来"。三选一：

1. **整篇文字态**：开头到结尾全程文字类语法，哪怕内容含软转也不上纯色横幅/促销色。适合"以内容立号、偶尔带货也要含蓄"的运营。
2. **整篇宣传态**：全程宣传类语法，连说明性段落也用宣传色/卡片承载。适合促销、活动、新品发布，开篇即热闹。
3. **主内容态 + 收尾切换**：正文按内容类型的主态（多数是文字态），到结尾 CTA 段才切到宣传态（上价格/CTA 卡、促销色、限时徽章），形成"读得舒服、结尾来促成"的单一明确转弯。

**推荐默认**：多数账号用方案 3——正文保持阅读舒适，只在结尾转化处切换宣传态，既守住阅读体验又不浪费转化时机。**绝不允许**"通篇一会儿文字态一会儿宣传态"的骑墙式混排。

## 四、整体切换的操作流程（6 步）

从"决定要切模式"到"能发布"，按下面的顺序走一遍，越到后面越省事。前三步是"想清楚"，后三步是"动手 + 自查"。

1. **定主态**：先按内容类型定这篇文章的主态（干货/科普/情感 → 文字态；促销/活动/新品 → 宣传态），全程主态只有一个。拿不准时，先按"读者是来读还是来买"判断。
2. **定切点**：如果走"主态 + 收尾切换"，明确要在哪个位置切一次（多数在结尾 CTA 前一屏；要插卖点段就在那段开头切）。切点定了就别半路再改。
3. **预评高差异模块**：把文章里会出现的标题、气泡、卡片、列表、步骤、分割线、徽章列一遍，心里过一遍"这套换过去长什么样"，避免走着走着发现某模块两态都没想好。
4. **逐模块替换**：按第一节的细表，从标题开始一路把高差异模块换到目标态，低差异模块（正文/间距/图片）保持不动。一次只换一个类型，别跳着改。
5. **统一装饰语言**：检查宣传态里所有装饰（纯色块、徽章、圆点、图案角饰）是否全在同一个体系里，主色 ≤3、纯色只给焦点，去掉跳脱的个例。
6. **过一遍穿帮检查**：最后按第六节/第九节的检查清单逐项打勾，尤其看切点信号、间距行高、重点单通道这三项。

> 口吻提醒：不管切到宣传态多热闹，**块间距仍守 16px、行高仍守 1.75**。模式变的是"长相"，地基（间距、行高、页边距）一个字都不能动。

## 五、切换的具体做法（以"文字态正文 → 宣传态收尾"为例）

1. **正文阶段**：保持文字态——极简标题、浅色气泡、细框卡片、黑白正文。
2. **切点选定**：在进入结尾 CTA 前一屏处（约正文结束后），用一个"模式切换信号"（如一条分割线 或 一个色带标题"关于价格/关于限量"）明确告诉读者"下面进入推介段"。
3. **收尾阶段**：换上宣传态语法——CTA 大卡用主色纯色/徽章/价格表/小程序卡，把整段的颜色、装饰、号召全面提亮。
4. **收束**：CTA 之后回到浅色页脚（关注/版权），把热闹收敛回安静，文章在"提亮→回落"中干净收尾。

## 六、模式自洽检查（切换后必查）

- [ ] **通篇只有一个视觉主态**：除收尾 CTA 段外，正文全程一种模式，没有中间态骑墙。
- [ ] **切点清晰**：文字态→宣传态的切换处有一个明确信号（分割线/色带标题），不是突然变亮。
- [ ] **装饰语言一致**：宣传段内所有装饰（纯色块/徽章/圆点）同在宣传态体系，没有"一半文字一半宣传"的混搭。
- [ ] **间距/行高仍守硬规范**：切换模式不等于可以破坏 16px 块距 / 1.75 行高。
- [ ] **重点仍单通道**：宣传态再亮，重点也只有一个最强通道，不因"活泼"而叠加强调。
- [ ] **内容类型与方法论不冲突**：不要为了宣传态硬把干文章塞成卖货腔（见《模块×类型矩阵》）。

## 七、常见错误

1. **骑墙式混排**：一会儿文字态一会儿宣传态，读起来像两篇文章拼贴——三选一整体一致。
2. **只改标题不改正文**：标题用纯色横幅，正文却还在文字态细卡——开篇高调、正文掉链子，气场断裂。
3. **切点无信号**：正文还在温柔讲道理，突然一个促销大卡砸下来——加一个分割线/色带标题做过渡信号。
4. **切换全清空间距规范**：宣传段花哨但间距失守——模式可以变，地基不能变。
5. **为"看起来丰富"双模式都来**：同一屏又浅条气泡又纯色卡——装饰语言必须统一在一套体系内。
6. **把"切换宣传态"当成"全部高亮"**：进了宣传态就处处加粗、处处纯色，反而没了重点——主色 ≤3、纯色只给焦点、重点仍单通道，热闹里头要有主次。

## 八、跨篇管理模式：平时干货、大促促销

同一账号里"平时发干货、大促发促销"是最常见的跨篇切换场景，比单篇内切换更常见、也更好管理。关键是**把两套语言分别固定下来，而不是每次现编**。

- **建立"常态模板"**：为文字态和宣传态各存一套固定蒙版（标题、气泡、卡片、CTA 各自的排版写法）。平时发干货直接套文字态蒙版，大促发促销直接套宣传态蒙版，零成本即切即用。
- **主线账号定位不漂移**：一个号要有明确的"主线主态"——干货为主就日常全文字态，促销只在活动窗口整篇切宣传态，避免读者发现"这个号今天像卖货号、明天像读书号"。
- **促销前预告切点**：如果一个号平时很克制，偶尔整篇宣传态，建议在推文顶部或用一篇预告文先打个招呼（"本周五限时活动"），让主态切换有心理预期，不显得突兀。
- **存档复用而不重建**：每次活动结束后，把那条宣传态图文留档成模板素材，下次同类活动改改日期、价格、名额就能复用，别每次从零搭骨架。
- **跨篇终检同一套**：无论单篇切换还是跨篇切换，硬规范（16px 块距、1.75 行高）、主色 ≤3、重点单通道这几条地基始终一致，只有"外观语言"跟着场景走。

判断依据：**"平时干货、大促促销"这类跨篇切换，读者的容忍度高出很多——只要每次发文内部自洽、账号主线不漂移，切换本身不是问题；真正穿帮的是单篇内部骑墙。**

## 九、单篇内"正文文字态 + 收尾宣传态"完整骨架示例

下面是一段可直接对照的骨架（模块语法以 Markdown 符号示意），演示怎么在"读得舒服"的正文之后，通过一个明确信号切进宣传态。**正文阶段零促销色，切点来了才上颜色。**

## 方法一：先定对象
正文段落……（黑白正文，16px 块距，1.75 行高，浅色细框卡片收纳要点）

## 方法二：选题从评论区挖
正文段落……（圆点列表，不抢正文）

## 方法三：结尾给一个可执行的钩子
正文段落……（金句用浅色 quote）

--- （模式切换信号：一条清晰分割线，告诉读者"下面进入推介"）

> 现在下单立减 20 元，限量 300 份，售完即止。

:::

对照要点：开头到分割线前全是文字态（极简标题、浅色气泡、细框卡片、黑白正文）；分割线后切宣传态（色带标题、KEY 纯色气泡、价格卡、小程序卡、限时徽章）；最末回浅色页脚。**一次转弯，干净利落，没有骑墙。**

## 十、切换后最容易穿帮的点与检查项

切完之后，穿帮往往不在"切没切"，而在**切得不干净、切点没铺垫、地基被顺手破坏**。下面几处是重灾区，对应给出检查项。

| 穿帮点 | 为什么一眼穿帮 | 检查项 |
|---|---|---|
| 标题已上横幅，正文还是文字态细卡 | 开篇高调、正文掉链子，气场断裂 | 标题、小节标题是否已随主态整套换掉 |
| 切点没有信号 | 正文温柔讲道理，突然促销大卡砸下来，读者被"闪"到 | 文字态→宣传态之间是否有一条分割线/色带标题做过渡 |
| 装饰语言一半文字一半宣传 | 同一屏又浅条气泡又纯色卡，像拼贴 | 宣传段所有纯色块/徽章/圆点是否全在宣传态体系 |
| 进宣传态后间距被改松 | 为了"更好看"把块距拉开、行高加大 | 块距是否仍 16px、行高是否仍 1.75 |
| 主色超限、乱用纯色 | 橙青紫之外又加一堆色，纯色到处给 | 主色是否仍 ≤3、纯色是否只给焦点 |
| 宣传态里处处高亮 | 全都强调等于没强调，重点抓不住 | 是否仍保持一个最强通道、重点单通道 |
| 收尾没收住 | 宣传段一直热闹到结尾，没有回落 | CTA 之后是否回到浅色页脚把气氛收回来 |
| 切了宣传态但 CTA 语气没跟上 | 视觉很热闹，文案还在含蓄"可以看看" | 宣传段文字是否同步到"现在就买/抓紧"的号召语气 |

> 自查套路：发布前把文章从头到尾顺一遍，**在心里只在"切点"处允许一次"变亮"**，前后必须连得起来。凡是多出一处跳变、或地基被动了，就回第六节重查。

## 十一、个性化空间（可调参数与判断依据）

- **主态选哪套**：干货/科普/情感号几乎全文字态；促销/活动号全宣传态；两者兼顾选"正文文字态 + 收尾宣传态"。判断依据＝账号内容结构里"卖货"占比高不高。
- **切点位置**：多数在结尾 CTA 前；也可在中间插入一个专门卖点段（如"顺便推荐""限时活动"）从那里切换再切回或一路宣传到底。判断依据＝卖点出现在正文哪里。
- **宣传态兴奋度**：新品/大促可以拉满；日常软转可只升卡片+CTA 不全升横幅。判断依据＝活动力度与紧迫感。

## 十二、宣传态骨架色速查（模块渲染基础色）

排版语法模块在宣传态默认用骨架低饱和三主色：陶土橙 `#c96f4a`（焦点）/ 雾青 `#5f8d8a`（次焦点）/ 墨 `#2f3640`（横幅），沙金 `#d9a35f` 与暖灰 `#b08d8d` 仅作辅助点缀。正文一律深灰 `#4a4a52`，禁止正文用彩色文字（宣传态同样适用）。**注意：这是模块渲染的骨架色，不代表风格**——正式稿件的风格化配色须从风格维度条目（如校园风/国潮/日系色板）读取后，以模板 HTML 或内联样式显式落地（见《风格维度索引》与各风格条目「模块表现」一节）。切换时保证主色 ≤3、纯色只给焦点。本规范一律纯色 + 细边框，零渐变、零阴影、零 emoji/图标字符。

## 十三、双模式版本是否都要做

只有当**同一篇内容确需两版投放**（如一条纯干货想让它在活动和平时都能用）才出两版；多数情况一篇文章只用一个主态。判断依据＝是否有明确的"同一内容多场景复用"需求，且读者已经熟悉你的双模式会在不同发文里切换（如"平时干货、大促促销"），这种跨篇切换比单篇内切换更常见、也更容易管理。

> 补充：若确需同时出文字版和宣传版（纯干货 + 带货变体），**别在同一篇文章里做两版视觉**，而是各做一篇封面与标题风格一致、正文分别为文字态/宣传态的独立图文，用"同样内容两套投放"去匹配平时与大促两种场景。
