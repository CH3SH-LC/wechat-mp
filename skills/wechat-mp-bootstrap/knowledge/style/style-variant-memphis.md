# 孟菲斯（几何撞色、波浪线）

> 定位：插画风格的**子系变体**。插画风已经很活泼，孟菲斯把它再往「玩设计、玩几何」推一步——用不规则的几何图形、撞色、波浪线、黑白斜纹，营造设计感极强的潮流感。
> 适用对象：设计、潮流、文创、年轻向品牌、创意活动的内容。调用方：排版时多用几何装饰元素并把图形「错位、扭动、重复」成一组。

## 一、属于哪个顶层风格的子系

- **母风格：插画风格**（快消、母婴、娱乐、促销、文创）。本变体继承插画的高饱和撞色与圆润节奏，但把插画的「形象化插画（人物/动物/banner）」换成「几何化图形（圆、半圆、波浪、斜纹、不规则多边形）」。
- **一句话**：内容是「设计感、新潮、创意」时，插画的可爱让位给孟菲斯的玩味几何。

### 何时用本变体，而不是直接用插画母风格

| 内容状态 | 选择 | 理由 |
|---|---|---|
| 需要可爱角色/形象来带货、讲抓人眼球的故事 | 插画风格（母） | 形象化插画才有代入感，几何代替不了"人物讲故事" |
| 需要"设计感的潮、有想法的酷" | **孟菲斯（本变体）** | 不规则几何 + 撞色 + 斜纹才是潮流设计的语言 |
| 面向设计师/极客审美，越特别越好 | **孟菲斯（本变体）** | 玩味几何让内容显得有"想法"，不是糖水可爱 |
| 促销非常需要冲动买单的氛围 | 插画风格（母） | 活泼夸张的插画更能催冲动，孟菲斯偏"冷静的设计感" |

判断尺：**设计感 > 可爱感的时刻，从插画切到孟菲斯**；内容核心是"讲故事/带货"，仍留插画。

## 二、与母风格的差异点

| 对比维度 | 插画风格（母） | 孟菲斯（本变体） |
|---|---|---|
| 主要元素 | 人物/动物/产品插画 | **几何图形：圆、半圆、三角、波浪、扭曲方块** |
| 色板 | 高饱和撞色 + 奶油底 | **高饱和撞色 + 黑白斜纹点缀 + 大块纯色底** |
| 造型 | 圆润可爱 | **几何硬朗但有节奏地歪扭、错位、重复** |
| 边框/描边 | 粗描边白边 | **细黑描边（1.5px）常用于图形轮廓** |
| 标题 | 白字彩底圆角 banner | **大字纯色 + 几何图形夹衬；编号做几何徽章** |
| 气质 | 热闹、可爱、冲动 | **潮、设计感、玩味、先锋** |

- **节奏区别**：插画是"一张完整画面"，孟菲斯是"一组拼贴图形"——图形之间要有错位、重叠、互为衬托的节奏，而不是平铺。
- **收敛区别**：孟菲斯比插画更需要"黑白压场"——彩色越多越要靠黑色斜纹/描边收住，不要只堆彩色。

## 三、完整色板

> 孟菲斯的灵魂是「彩色随意地挤在一起 + 黑白压一压」。取 4 个高饱和亮色 + 黑白，别再多。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FCF7EE`（米白） | 常规版面底色；大标题/重点区可整块换纯色彩底 |
| 分区纯底色 | `#FFD447`（明黄）／`#FF7A59`（活力橙） | 大标题 banner、花纹色带、几何块底 |
| 主色1 | `#FF5A55`（橙红） | 主强调、几何图形主色 |
| 主色2 | `#2EC4B6`（青柠绿） | 辅助图形、次要强调 |
| 主色3 | `#3E64FF`（宝蓝） | 图形/文字强调，与橙互补撞色 |
| 辅助色 | `#8C7BF0`（葡萄紫） | 图形点缀、徽章 |
| 强调/压色 | `#111111`（近黑）+ `#FFFFFF`（白） | 黑白二色交替的纯色斜纹（平面条纹）、细描边、正文 |
| 正文文字 | `#2B2424`（暖黑） | 正文用色 |
| 次级文字 | `#8A7F7F`（暖灰） | 注释、图注 |

**每个色号一句话用法**：

- `#FCF7EE` 米白：常规版面底，给彩色一个"喘气"的纸面；大标题或重点区可整块换成纯彩色底形成反差。
- `#FFD447` 明黄：大标题/色带的首选纯色底，自带"醒"的感觉，别让它和橙红同时铺满。
- `#FF7A59` 活力橙：另一个彩色底选项，替代明黄做分区，暖而有劲。
- `#FF5A55` 橙红：主强调，几何图形与重点词的主力，孟菲斯的热度担当。
- `#2EC4B6` 青柠绿：与橙红互补的第二主色，常用在辅助图形与背景细节，让撞色有"呼吸"。
- `#3E64FF` 宝蓝：第三个主色，与橙形成经典互补撞色，常做文字强调或图形里的"冷锚点"。
- `#8C7BF0` 葡萄紫：图形点缀与徽章，补足"彩色挤在一起"的丰富感但一次只用一点。
- `#111111` 近黑：压住整版的锚，黑白斜纹、细描边主力；没有它彩色就会飘。
- `#FFFFFF` 白：与大块彩色对比、做纯色块间隔，也是正文里反白字体的用色。
- `#2B2424` 暖黑：正文主色，压住阅读的重心，别让彩底把正文带走。
- `#8A7F7F` 暖灰：注释与图注，弱化但可读。

**配色规律**：每屏主角 1 个亮色，其余亮色只在相邻几何块出场；黑白斜纹负责「收敛」，千万别每个图形都不同颜色而失控。主色的三色组合「橙红 + 青柠绿 + 宝蓝」是孟菲斯经典三角，可整体替换为「粉紫 + 黄 + 青」，保持互补撞色关系即可。

**深浅档切换**：白天/冷白米底排个性潮感；夜间或"演出/派对"氛围内容可切一段深色底（暖黑 `#221E1C` + 亮色 + 斜纹），**深档每篇 ≤2 处**，专放最"炫"的高潮段。深档必须保留黑白斜纹的明暗对比，否则收不住。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | 大号纯色字 + 左右各一个几何图形夹衬；或整块黄/橙色彩底白字 | `把设计玩出花`（宝蓝字，两旁黄圆+黑斜纹半圆夹衬） |
| 章节小标题 | 标题前加编号几何徽章（圆/三角/波浪里放数字） | `几何的节律`（行首一枚纯色圆徽章编号） |
| 重点句 | 橙红加粗 + 一块奶黄纯色底；或夹在两个几何方块间 | `撞色，是另一种秩序` |

- 字号：大标题 22-24px（可做大字），章节 18px，正文 15px，注释 13px。
- 标题字距 1-2px，正文 0.5px，行距 1.75。

**几何徽章的写法**：章标题前放一个 `<span style="display:inline-block;background:#FF5A55;color:#fff;border-radius:50%;width:26px;height:26px;line-height:26px;text-align:center;font-weight:900;">01</span>`，像章节目录的"几何序号"；三种几何形状（圆/三角/波浪）按章节轮换，制造"玩几何"的连续感。

## 五、模块表现

- **重点气泡**：奶黄或青柠绿整块底 + 黑细描边 + 圆角 12px；右上角放一个黑斜纹方块做「图钉」。内文 14px 暖黑。
- **卡片**：白底 + 2px 黑描边 + 圆角 8px（偏几何硬角）+ `padding:14px 16px`，靠粗描边与色块制造"贴纸按下去"的平面层次，不加投影。
- **分割线**：用一串重复的几何方块/三角（纯色交替排）或黑白斜纹长条；上下 24px。
- **花纹色带**：黑白二色交替的纯色斜纹（平面条纹，非平滑渐变）、波点或圆环；整篇 ≤2 条，用来衬标题或分区。
- **列表**：圆点换成小圆/三角图形；数字用几何徽章。
- **步骤**：步骤圈做成几何图形绕数字，如「圆里套数字」。
- **图片**：可把图片裁成圆/几何形，或压在几何底块上（斜切选框）。

**一个几何徽章编号步骤的骨架**：

```html
<div style="display:flex;align-items:center;gap:10px;margin:0 0 16px;">
  <span style="background:#3E64FF;color:#fff;width:30px;height:30px;border-radius:6px 6px 12px 2px;display:inline-flex;align-items:center;justify-content:center;font-weight:900;">01</span>
  <p style="margin:0;color:#2B2424;line-height:1.75;">步骤名：让几何图形"错位一点"再落进去。</p>
</div>
```

要点：编号盒子的圆角做成"一角偏圆、一角偏尖"的几何感（`border-radius:6px 6px 12px 2px`），比处处等圆更孟菲斯；正文仍留白底清晰可读。

## 六、图片处理与装饰

- 图片：几何裁切或加黑描边「图鉴感」；一组图片可错落摆放成拼贴画。
- 可用 `clip-path` 把图片裁成圆三角/斜切多边形，压在彩色底块上；别把重要信息裁掉。
- 装饰克制：图案/几何点缀每屏 ≤1 处，宁可留白。孟菲斯的视觉冲击靠几何图形，不靠图案字符；装饰只做价格/问答等功能的几何角标。图案资产只可用植物/自然类：如 `vine-frame` 藤蔓花框、`sprig-grass` 小草、`blossom-branch` 花枝、`leaf-corner` 叶角——在正文用 `![说明](art://资产名)` 引用，统一以纯色平面线条化呈现，不用图标类图案。
- 几何装饰密度：**每屏部署 ≤3 个几何图形**（可能已很满），宁少勿多，靠重复与节奏而非堆量。

## 七、禁忌与陷阱

1. **别让彩色失控**：超过 4 亮色 + 黑白的孟菲斯会从「设计感」变成「儿童乱涂」。锁死色板，图形颜色只能在色板里轮换。
2. **别省黑白压场**：完全不用黑描边/黑斜纹的孟菲斯会飘，黑色是让撞色「落定」的关键。
3. **别用阴影与柔光**：孟菲斯用纯色块 + 粗描边 + 留白撑层次，不用任何投影、硬阴影或大圆角软模糊，保持平面化。
4. **别做规整网格**：几何图形要素要「歪一点、错位一点」，排得太整齐反而失去孟菲斯的玩味。
5. **别高密度堆图形**：整篇图形 ≤8-10 个，花哨区域集中在标题与分区，正文段仍保持白底清晰可读。
6. **别把每个几何块都换一种颜色**：一屏只让 1 个主角亮色，其它图形用色板内重复的相近色，靠"重复"而非"每次都新鲜"营造节奏。
7. **别让文字屈服于彩底**：在纯彩底上放正文时，必须用白字或保证足够对比与描边，别用深字贴深底，否则读不清。

## 八、混搭方向

- **+ 极简**：明黄/黑白两个元素做点缀、大留白，可以给「极客审美向」内容加一层潮感。
- **+ 波普**：孟菲斯的黑白斜纹与波普的网点很配（见波普艺术条目），可混用但别同时上满。
- **+ 插画（母）**：孟菲斯几何做框架、个别形象化插画做主角，内容是"潮流插画"时用。
- **- 禁忌**：别混国潮（红金墨庄重冲突）、别混商务（克制专业冲突）、别混日系（纸感温柔冲突）、别混森系（自然清新冲突）。

## 九、封面与首屏建议

- 封面：几何图形密铺背景 + 居中大字标题，四角放黑白斜纹角标。
- 首屏：一排连续半圆/波浪当页眉，紧跟一个大号撞色标题。
- 配色呼应：米白 `#FCF7EE` 底 + 澄红/宝蓝大字 + 黑白斜纹点缀，封面与正文统一用同一套"色彩三角"，点进去衔接自然。

## 十、深色模式表现

- 深色下：米白底换暖黑 `#221E1C`，亮色彩底略微提亮；黑白斜纹保留但黑换深灰 `#2A2A2A`、白换暖白 `#F5EEE6`，保证斜纹的明暗对比仍在。
- 深浅层次在深底上用「加一圈浅色描边 `#FCF7EE` + 色块明度差」体现，不用硬阴影。
- 深色下彩色图形提亮一位（橙红 `#FF6B66`、青柠 `#3ED6C6`、宝蓝 `#4D72FF`），避免在深底发闷；正文换暖白 `#EDE6DB`。

## 十一、个性化留白（按账号自定）

- **主色三角**：橙红+青柠+宝蓝（经典热情型）／粉紫+黄+青（温柔潮流型）／黑白+单彩（极简孟菲斯）——读者偏潮流时尚选第一组，偏少女系选第二组，偏设计极客选第三组。
- **几何密度**：低（只印花纹带与标题）／中（每屏 1-2 图形）／高（拼贴画式）——结合账号「设计向」程度。
- **是否斜切标题**：不做（方正）／做（标题色块一端斜切）——看目标读者的年龄与审美。
- **斜纹 vs 波点**：斜纹更"工业潮流"，波点/圆环更"复古趣味"——看内容想表达潮酷还是童趣。
- 判断依据：读者年龄审美、内容是否本就「设计/创意向」、品牌年轻度。

**给调用方的复查三问**：一、一屏的亮色是否只有一两个主角、黑白斜纹有没有出来压下重量？二、几何图形是否"错位有节奏"，而不是平平整整排一脸？三、正文区是不是保持清晰可读，没有被几何装饰抢走视线？

**孟菲斯的"活"在哪**：同样的几何配方之下，孟菲斯比的是"谁把彩色与黑白放对了位置"——一屏的主角亮色、一处错位的图形、一条收住全局的斜纹，比满屏堆色彩更有设计感。玩几何，也要懂"留白与压色"。
