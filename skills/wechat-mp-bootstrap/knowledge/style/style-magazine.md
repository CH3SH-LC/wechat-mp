# 杂志编辑风（style-magazine）

> 定位：大字报、编辑感、强观点，像杂志的封面标题和一出戏剧的电影字幕，字号巨大、图形化文字、张力十足。

> 调用时机：时尚观点、深度人物、品牌宣言、编辑部企划、话题评论，以及一切要"有态度、有张力、引人注目"的观点向内容。

## 一、气质与适用内容

**气质关键词**：编辑感、大字报、强观点、张力、戏剧化、观点鲜明。超大字号 + 图形化文字是它的签名，敢表达是它的内核。它不像娓娓道来的故事，更像一本杂志摊开的封面——大字先扑过来，态度先站住，读者再进正文。

**适合的内容类型与行业**，逐个说为什么合拍：

- **时尚/文艺观点**（趋势评论、风格观察、审美主张）：这类内容自带审美立场，编辑味的大字正好把"我主张"放大成"封面头条"，让观点一上来就有分量。

- **深度人物**（人物专访、人物侧写、意见领袖画像）：人物内容需要戏剧性和拍摄感，杂志风的大字、反白块、编辑小标能把被访者塑造成"封面人物"，比平铺直叙更有人物张力。

- **品牌宣言**（态度宣言、周年主张、文化企划）：品牌要的是"宣示感"，大字报式的标题把立场喊出来，符合这种"郑重启事"的表达场景。

- **话题评论**（热点评论、行业观察、编辑部视角）：评论需要敢断言，杂志风的强烈视觉正好匹配"我们编辑部是有立场的"这种态度输出。

- **设计/潮流文化**（策展、杂志化表达、编辑特稿）：这类内容本身就是"视觉的表达游戏"，编辑风与它们天生气味相投，排版越讲究越好看。

**不适合的场合**，逐个说为什么是雷区：

- **高密度信息清单（表格、步骤轰炸）**：杂志风重表达、不重信息密度，通篇表格、密集步骤会跟超大字号打架，读者既抓不住要点，又失去编辑张力。

- **强调客观中立、需避开主观态度的严肃资讯聚合**：编辑风是"有立场"的，如果内容必须保持绝对中立，再用犀利的视觉就会显得表态失当。

- **需要极简安静、纯功能说明的场景**：杂志风的张力与"安静的说明书"相悖，功能教学用大字压场，读者会觉得"在看广告而不是在看说明"。

- **完全无观点、纯资料罗列的内容**：没有观点就给不出编辑的"主张"，硬上编辑视觉等于给一具空壳穿上戏服，言不符实。

**判断一句**：内容要"亮出态度的编辑部特稿、像封面头条"，杂志编辑风正中；要"冷静客观罗列信息"，就别用。核心是——你这一篇有没有一个"敢说出口的立场"。有，就适合；没有，硬套会显得空洞。

## 二、完整色板表

```text
背景类（有编辑版面感）
  #FFFFFF        纯白底：正文底色，干净承托大字
  #F4F1EC        米白：纸刊分区，编辑版面
  #111111        近黑（深档底）：压场/大字块
  #EAEAEA        浅灰：专题分区

主色类（锐利 + 态度）
  #C8102E        朱红：态度字/高亮，编辑力的红
  #111111        近黑：大字主标题，够重
  #2D5CF0        电光蓝：理性强调（可选第二主色）

辅助色类
  #4B4B4B        中灰：结构/说明
  #8A8A8A        次级灰：注释
  #B5B5B5        浅灰：细线

强调色类（全篇克制 ≤2）
  #FF5A00        活力橙：唯一点亮词/CTA
  #C8102E        朱红：重点态度词
  #2D5CF0        电光蓝：另一克制强调

文字色类
  #111111 / #1A1A1A   近黑：标题与大字
  #2B2B2B            正文主色（避免整段纯黑刺眼）
  #6B6B6B            次级灰、注释
```

**颜色怎么用，逐个说一次**：

- **#FFFFFF 纯白底**：正文底色，干净承托大字。白底让黑字、朱红、反白块有最大的对比，是编辑版的"画布"。

- **#F4F1EC 米白**：纸刊分区用。比纯白暖一点，做专题分区或引语卡底，制造"翻到某一页纸"的版面层次。

- **#111111 近黑**：深档底或大字块底。颜色够重，用来压场、做反白大字、做通栏。

- **#EAEAEA 浅灰**：专题分区底。很浅、不抢眼，用来划分专题区域。

- **#C8102E 朱红**：态度字/高亮，编辑力的红。很多大刊封面标题的用色，醒目且有"权威的激烈"。

- **#111111 近黑**：大字主标题。黑字够重，撑得起"大字报"的力道，是标题的底子。

- **#2D5CF0 电光蓝**：理性强调，可选第二主色。比朱红冷静，用于科技/理性向内容的强调。

- **#4B4B4B 中灰**：结构/说明。做次级结构文字，比正文浅一档。

- **#8A8A8A 次级灰**：注释。比中灰再浅，做脚注、来源、落款。

- **#B5B5B5 浅灰**：细线、细分隔。最浅的一档灰，做版面上的细线最合适。

- **#FF5A00 活力橙**：唯一点亮词/CTA。全篇最多用一到两处，做"动作钩子"，比如结尾引导语。

- **#2B2B2B 正文主色**：正文用深灰而不纯黑。避免整段纯黑刺眼，这个细节直接决定阅读舒适度。

- **#6B6B6B 次级灰、注释**：同工作为辅助文字。

**深浅两档怎么切换**：

- **浅档（默认）**：白/米白底 + 黑大字 + 朱红或电光蓝强调。这是杂志正文的常态——张力靠字号与留白撑起来，不靠颜色堆。切换方法：白底为主，大字用 #111111 近黑，把一支态度色（朱红或电光蓝）压在关键标题/高亮词上，灰阶做结构。
- **深档（压场专题）**：近黑 #111111 底 + 白大字 + 强调色。用于「封面式开头、观点强调屏、结尾宣言」这类要"重重压一下"的地方。全篇只用 2–3 处深档，制造"章节翻页"的截图感——用得越多，越失去反差的分量。切换方法：底换成 #111111，字换成米白/白，把态度色提亮一档保持对比。

## 三、标题与字号层级

**标题样式特征**：超大字号、图形化文字。标题本身就是视觉主体，字号大到撑版面，可配描边效果、色块反色、错位排版。这是"大字报型"的核心——标题不像标题，更像一张海报。

**装饰语法**，逐条说明：

- **反白大字**：`display:inline-block` + `background:#111111` + 白字 + 大字号，做成"反白字块"。像杂志标题的标签，深色块上面浮白字，冲击力最强。

- **朱红大字**：纯文字大标题用朱红 #C8102E 或近黑 #111111，字号拉大。不带底色的一个大字，靠字重和字号撑气势。

- **加粗描边感**：用描边做出"空心大字"的效果。注意：描边在微信里未必可靠，跑不通时就改用"大粗字重 + 对比色背景"来替代。

- **装饰小标**：大标题上方或旁配一行小字，如「封面故事 FEATURE」「专栏 COLUMN」。用 `letter-spacing:4px` 把字距拉宽，做成编辑标签。写到中文更通用：写作「特稿 / 专题 / 观点」。

- **倾斜/错位**：标题可 `transform:rotate(-2deg)` 一点错位，或分两行错开排。这种"不完美"反而更像手工排版的编辑部，更亲切、更有编辑味。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 封面级大标题 | 24–28px | 900/bold | 反白字块或朱红大字，撑满视觉 |
| 章节标题 | 18–20px | bold | 黑字/朱红，大而有力 |
| 编辑小标（FEATURE 式） | 12–13px | 600 | 大写/中文小标签，letter-spacing 拉宽 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 引语/金句 | 17–18px | 600 | 居中或左侧大字引语 |

> 间距硬规范：正文行高 1.75、字距 0.5px；正文色建议用 #2B2B2B 级别深灰，避免整段纯黑。

杂志风强调标题的"版面力"：标题上 30–36px、下 16–20px。这是唯一可以在硬规范基础上加大上留白的风格——给大字呼吸空间。封面级大字更要留足，让它"站得住"而不是被上下挤压。章节标题以下再用标准规范，标题上 28px、下 12px。

## 四、模块表现

每个模块怎么画，逐项给具体数值和可参考写法：

- **重点气泡**：无框大字引语。不用普通气泡，改做「引语卡」：米白底 + 左侧朱红或电光蓝竖条 + 大号引语字。可参考写法 `background:#F4F1EC;border-left:4px solid #C8102E;padding:14px 16px;`，引语字 17–18px、600 字重，padding 用硬规范 14px 16px。要"报纸式"更强，可换成反白大字块 `background:#111111` + 白字。

- **卡片**：白/米白底 + 1px 细边 + 直角偏方。可参考写法 `background:#FFFFFF;border:1px solid #E0E3EB;border-radius:4px;padding:14px 16px 12px;`。圆角 4px——编辑感讲究方、讲究利落，不用大圆角。卡片顶部可加一条 4px 的朱红或黑横条做"栏眉"。卡片之间间距 16px（硬规范）。

- **分割线**：粗黑线 / 通栏线。可参考写法 `border-top:3px solid #111111`，或 1px 细线 + 居中放一个 CSS 圆点/方块（`span` 拼，圆角 8px）。像杂志栏目之间的分隔，上下各留 24px。粗线稳重、细线精致，二选一，别混着滥用。

- **花纹**：极少或不用。杂志风靠字号与留白制造版面感，不靠花纹装饰。真要用，最多极浅米灰格做专题底（#F4F1EC 级别），全篇 ≤1 种，且绝不显眼。

- **列表**：短促条目。每条前用「— ・ 01」这类短粗符号，或反白序号块，行距保持 1.75（硬规范）。条目克制有力、不灌水——每一条都要像"编辑部下达的一句话指令"。

- **步骤**：编辑部步骤。序号用大反白字块「01/02/03」，可参考写法 `background:#111111;color:#FFFFFF;border-radius:4px;` 配短句，或用"大数字 + 标题 + 短说明"的三段式。步骤之间间距 16px（硬规范）。

- **翻转/通栏**：可做整行通栏，黑底白字铺满一行的"栏目带"，用来切分章节，编辑感直接拉满。

## 五、图片与装饰

- **图片处理**：圆角 4px 或直角。配高对比/编辑感裁剪——局部特写、强构图。可用黑白照或单色处理，塑造时尚态度，比彩色原图更有"杂志大片"质感。比例多取 4:3 或 1:1（人物特写）。

- **图文混排**：可用"大字压图"。深色细边/低饱和纯色衬底（`background:rgba(17,17,17,0.55)` + 细边框）托住白字叠在图片上做标题，杂志封面式。图片做底、大字做前景，一屏就完成"封面感"。

- **装饰克制**：近于零。杂志编辑风基本上不能用图标装饰，情绪用排版表达——用大字、反白、留白，而不是贴纸符号。要标记用 CSS 几何点/方块或「— / ·」这类文字符号。即使内容偏轻松，也宁可降一点热闹度，保住编辑风的"正式张力"。

## 六、文案调性

**语气关键词**：有态度、犀利、观点鲜明、编辑部口吻、敢断言、有分量。

**句式倾向**，逐条说明：

- 断言式、判断句开头，比如"这个时代……""我始终认为……"。开头即立论，不给读者"慢慢琢磨"的机会，先把立场钉住。

- 短句有力，可排比，可设问后自答。三四个短句连排，节奏感强，像编辑在签字定稿时的口吻。

- 适度使用"我不认同""更应该""真相是"等观点词。这些词是"立场的杠杆"，但要用得克制，用多了就成喊口号。

- 用编辑部视角拉读者进一场讨论，比如"我们做这篇……"。把"我"变成"我们"，读者感觉被邀请进一场编辑部会议，参与感更强。

**可直接套用的示例句**：

- "编辑按：我们决定，为这个时代做一期诚实的封面。"

- "真正的潮流，从来不是跟风。"

- "这篇，写给正在犹豫的每一位创作者。"

- "封面故事——审美，也是一种判断力。"

- "不表达立场，才是这个时代最大的保守。"

- "我们的答案很简单：只做对读者诚实的内容。"

## 七、禁忌与陷阱

每个坑给"反例 + 正解"两段，反例带具体色号/写法：

**坑1：大字过多、全屏轰炸。**
- 反例：整篇所有标题都 20px+ 满屏，每个段落都一个 24px 大字。读者一路被"喊"下来，累，找不到重点，像在听通篇喊口号。
- 正解：超大字号只给封面级 1–2 处，和章节主标题。正文仍保持 15px，字距 0.5px、行高 1.75（硬规范）。靠"大字 vs 正常"的落差做编辑张力——落差在，冲击才在。

**坑2：配色太花。**
- 反例：朱红 + 电光蓝 + 活力橙 + 多个灰阶同时当主色上阵。几个态度色互相打架，编辑感全碎，像满版广告纸。
- 正解：近黑 #111111 + 1 个态度色（朱红或电光蓝）+ 灰阶。彩色全篇 ≤2 个。克制是编辑风的高级所在——颜色越少，态度越清楚。

**坑3：态度混乱 / 无观点。**
- 反例：内容写成中性罗列、没有立场，却配了极其犀利的编辑视觉。言不符实，口号喊得响，内容却空，读者一眼看穿。
- 正解：先厘清观点，再配编辑视觉。观点是内核，排版是放大镜——《放大镜》只会放大已有的内容，不会凭空造出态度。

**坑4：装饰过度。**
- 反例：同一个标题同时叠反白块 + 加粗描边 + 倾斜 + 朱红 + 符号。一处塞满所有手段，视觉又乱又挤，反而把重点淹没。
- 正解：一个标题只选一个编辑手段——反白、或朱红大字、或倾斜。其余部分保留干净，让那一个手段成为焦点。

**坑5：忽略正文字高。**
- 反例：只顾着放大字，把正文行距压紧，字号缩小。大字越醒目，正文越挤，读起来费劲，头重脚轻。
- 正解：大字醒目不错，但正文仍保持行高 1.75、字距 0.5px（硬规范）。大小字之间落差要清晰又舒服——大字负责抓眼球，正文负责好读，两者不能互相牺牲。

## 八、混搭方向

按主辅搭配，杂志风做主风格时守大字编辑骨架：

- **杂志 × 极简（主 6 辅 4）**：时尚观点/品牌内容。杂志的大字图形 + 极简的克制留白，张力与高级兼得。这也与"极简 × 杂志"是同一个组合，主辅比例可反（参照「极简」条目）。
- **杂志 × 艺术画廊（主 6 辅 4）**：艺术/策展/设计内容。杂志大字 + 画廊的衬线与画幅卡，更艺术（参照「艺术画廊风」条目）。
- **杂志 × 港风（主 7 辅 3）**：人物/故事特稿。杂志大字 + 港风霓虹/旧纸，更强"大片人物"的感觉。
- **杂志 × 报纸（主 7 辅 3）**：编辑部企划/深度盘点。杂志大字 + 报纸分栏/徽章，更有"纸媒编辑部"的实感（参照「复古报纸风」条目）。

> 具体主辅怎么切、谁做版式骨架，参照「风格混搭与主辅法则」条目，别硬拼两套系统。

## 九、封面建议

- **构图**：封面式。超大标题占满上方 + 一张态度图/人物特写 + 编辑小标；或"大字压图"式。封面要像一本要翻开的最新刊，大字先占据视觉中心。

- **配色呼应**：白/米白底 + 近黑大字 + 朱红/电光蓝强调，或深档近黑底 + 白大字 + 态度色。封面配色和正文首屏保持同一套，别换体系。

- **字**：FEATURE 式小标 + 6–8 字大标题，像书刊封面。副标用一句引语，把读者"勾"进正文。标题字数一次说清，别用两行长句。

- **气质**：有态度、有张力，像要大声读出来。封面就要先让人"感觉这期有话要说"。

## 十、深色模式表现

杂志风的深档反白大字，在暗黑下更站得住。近黑底 + 白大字 + 朱红/电光蓝强调，暗黑里张力依旧，甚至更沉更稳。白/米白底在深色模式下改为近黑 #111111 底 + 米白字 #E8E8E8。浅灰字 #B5B5B5 在深底上不够亮，要提亮成更浅的米灰。朱红 #C8102E 在深底上略微提亮为 #E23B45。电光蓝 #2D5CF0 提亮为 #5B78FF，保持对比足够。大字反白块在深底上仍是"黑底白字"，和页面同调，注意给足对比。杂志风很适合暗黑，但别让荧光强调在暗底过闪。克制住态度色的使用密度——暗黑里一点高亮就很醒目，多了反而乱。

## 十一、个性化空间

以下留白是可按账号/读者自定的参数，每项给判断依据：

- **态度色**：可选朱红（热烈/传统编辑力）、电光蓝（理性/现代）、活力橙（流行/张扬）。判断依据：账号气质与读者偏好——时尚媒体杂志向多选朱红，年轻新锐向可选橙色或电光蓝。一旦选定，让它成为账号的"态度色"，贯穿每一篇。

- **大字强度**：态度强、话题硬的内容可把大字用到 28px + 反白。软性观点可降到大纲级（18px）但仍保留编辑感。判断依据：内容的"响亮程度"与读者的承受度——越硬越响用大字，越软越克制。

- **编辑小标语**：栏目名可用账号自己的栏目（如「主编手记」「趋势观察」）替代通用"特稿/专栏"。判断依据：账号的栏目体系。有小标体系就用小标，能形成稳定的栏目识别。

- **深浅档节奏**：话题热度高可多深档翻页，日常观点保持浅档。判断依据：内容想制造的"章节截图感"——越需要截图传播的内容，越适合深档制造反差。

- **是否用反白大字**：年轻向/社交传播向可用反白大字增强截图传播，老派严谨媒体则安静排版。判断依据：读者画像与传播诉求。

> 以上留白点为可调参数，调用方应结合账号定位落地，而非机械套表。
