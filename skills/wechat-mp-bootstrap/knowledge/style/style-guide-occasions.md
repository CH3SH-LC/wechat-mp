# 时令节日风格倾向（各时点的方向与节日化做法）

> 定位：跨风格通用方法论。一个账号平时有自己的「风格基线」，到节日/时点要过节味，但不能为了过节自乱阵脚。本条给出「各时点该偏哪个风格」与「如何在保住基线的前提下做节日化」的具体做法。
> 适用对象：所有需要应景的节日营销、节气、时点内容。调用方：先确认账号基线（见「账号风格基线」条目），再按下方做法做节日化。

## 一、核心原则：主风格保底，节日特征点缀

- **别整篇换风格**：除非账号本来就是节庆感风格（国潮号过节直接用国潮即可），否则只在「标题区 + 开头 + 结尾 + 一处花纹」四点上做节日化点缀，正文仍以账号基线为主。这叫「风格混搭的节日化应用」（详见「风格混搭与主辅法则」条目）。
- **节日化的三个抓手**：1 节日主色点缀（如春节金红透进标题区）；2 节日花纹透进分割线/纹样带；3 节日文案词替换（「团圆」「迎新」「告白」）。
- **判断依据**：账号「风格基线」结得越紧，节日化越要轻（只抓一两个特征点）；没有基线或本来就是活泼号的，可以大胆过节味。

## 二、时点 → 风格倾向与节日化做法表

| 时点 | 首选风格倾向 | 节日化怎么做（基于任何基线） | 提醒/别踩 |
|---|---|---|---|
| 春节 | 国潮 / 敦煌青绿 | 标题下加「墨金福纹」金线分割线；结尾改「祝阖家团圆」；透入红/金点缀 | 别把极简号整个变红金满版，只抓金线+一句吉言 |
| 元宵 | 国潮 / 报纸 | 「花灯/圆月」元素进标题；可用暖金色点缀 | 圆月意象好做，避免糊成春节同款 |
| 清明 | 报纸 / 极简 / 森系 | 用「纸鸢/山水」意象、克制留白，色调偏青灰；文案稳一些 | 别用喜庆撞色，清灵肃穆 |

| 元旦 | 极简 / 报纸 / 国潮 | 「新年」字、跨年倒数、留白感；可由报纸做年度回顾 | 新年前后可借「年度盘点」用报纸/极简 |
| 情人节 | 手账 / 治愈手绘 / 日系 | 粉/红点缀、爱心元素、情感文案 | 情感号用暖手帐系最自然；商务号则点一下即可 |
| 母亲节 | 治愈手绘 / 手账 / 插画 | 花朵+温暖色、亲子意象 | 温暖克制，别过度煽情 |
| 父亲节 | 商务 / 森系 / 报纸 | 稳重的黑/棕/绿、父辈器物意象 | 父亲节宜稳，别太粉太可爱 |
| 毕业季 | 校园 / 运动活力 | 蓝色学士帽、青春冲劲、回顾向 | 毕业生动态正盛，校园/运动最贴 |
| 开学季 | 校园 / 二次元 | 作业本/书包/社团意象、元气重启 | 学生受用校园/二次元 |
| 年末总结 | 极简 / 报纸 / 商务 / 国潮 | 年度数据、回顾时间线、庄重收束 | 报告式内容可用商务/极简；品牌周年用国潮 |
| 节气（二十四） | 森系 / 清水森系 / 国潮（冬） | 每个节气用对应植物/气候意象（立春嫩芽、谷雨、立冬暖） | 节气内容森系/清水森系最常驻，冬季可转国潮暖调 |

**节气（分到季度给意象）**：
- 春（立春/雨水/惊蛰/春分/清明/谷雨）：嫩芽绿、桃粉、春雨、纸鸢——森系 / 清水森系做主，色调清亮。
- 夏（立夏/小满/芒种/夏至/小暑/大暑）：荷叶、蝉鸣、荔枝、晚风——森系 / 日系，色调转到深绿 + 一点咬口的暖。
- 秋（立秋/处暑/白露/秋分/寒露/霜降）：稻穗金、桂花、红叶、明月——国潮 / 森系，色调转暖金黄 + 描金。
- 冬（立冬/小雪/大雪/冬至/小寒/大寒）：炭火、雪、汤圆、暖茶——国潮（墨金）/ 日系暖调，色调收敛暖棕。
> 节气内容森系 / 清水森系最常驻，随四季换绿→金→暖即可，别每个节气都换风格。

> 表格说明：首选倾向是「这类内容最顺的风格」，但不代表必须换。若账号基线明显另一个风格（比如常年极简），就按「保底 + 上面节日化做法」在极简上点缀，而不是强换国潮。

## 三、节日化的三步做法（任何基线通用）

1. **锁定节日特征三件套**：1 一个节日主色；2 一个节日意象（花纹/元素）；3 一句节日文案。三样就够了，别求全。
2. **落在四点上**：把这三样放到「标题区（主色/意象）/ 开头一句（文案）/ 结尾号召（文案/意象）/ 一处分割线或纹样带（花纹）」。正文其余部分保持不变。
3. **检查**：过「风格一致性」（见「风格一致性检查」条目），尤其颜色是否仍以基线色板为主，节日色是否只是点缀。

**节日的「三件套」从哪来（给调用方抄）**：
- 节日主色：取该节日的「标志色」并降一档饱和，让它能透进任何风格（春节=红/金、端午=粽叶青绿、中秋=月金、圣诞=冬青红绿、元旦=跨年金、情人节=粉/红）。
- 节日意象：选一个「一眼能认」的元素（春节=福字/灯笼、端午=粽叶/龙舟、中秋=圆月/桂花、毕业=学士帽/学士服）。
- 节日文案：一句应景话（春节「阖家团圆」、端午「安康」、中秋「人月两圆」、毕业「前程似锦」）。
> 三个原则：**色要降饱和、意象要单一、文案要应景不雷同**——每个节抓它「独一无二」的那个点，别所有节共用一套红金。

> 装饰图案限制：凡是作为图案 / 花纹落地的装饰，只能是植物 / 自然类——用 art:// 引用（sprig-grass 小草、vine-frame 藤蔓花框、blossom-branch 花枝、leaf-corner 叶角），绝不用图标 / 贴纸类图案。节日意象主要靠「纯色 + 纹样带 + 文案词」传达，不靠图标贴纸。

## 四、节日化与账号基线（不同基线的过法）

不同账号的「风格基线」决定节日化深浅，给四种典型基线的过法：

| 账号基线 | 节日化怎么做 | 深浅档 |
|---|---|---|
| 极简 / 商务 | 标题下加一条节日单色细线 + 一句吉言，其余不动 | 微过节 |
| 日系 / 森系 / 手账 | 透入节日主色 + 一个意象（如中秋月、圣诞松枝）做点缀 | 中度过节 |
| 国潮 / 敦煌青绿 | 直接整套过节（具身贴合），可做深度过节 | 深度过节 |
| 插画 / 运动 / 校园 | 节日元素当大色块 / 贴纸接入，热闹放得开 | 中 / 深度过节 |

> 判断依据：见「账号风格基线」条目——绑定越紧，档位越轻；灵活号可放手。

## 六、三个完整节日化示例（照着套）

**示例 A：极简号过「国庆」**
- 基线：极简（黑白灰 + 单强调色）。
- 三件套：主色=中国红 `#C8102E`（降饱和一点）、意象=红绸 / 五角星、文案=「山河同庆」。
- 落点：标题下一条中国红细线（微过节）、开头一句「山河同庆」、结尾「与国同行」。
- 检查：正文仍是黑白灰留白，红只做标题与分割线点缀。通过。

**示例 B：日系号过「中秋」**
- 基线：日系（米纸 + 暖棕）。
- 三件套：主色=月金 `#C9A24B`、意象=圆月、文案=「人月两圆」。
- 落点：标题下一个圆月小标 + 暖金分割线、开头一句「今晚月色真温柔」、结尾「愿人月两圆」。
- 检查：底色仍是米纸 `#FBF7F0`，气氛温柔不跳风格。通过。

**示例 C：插画号过「双11」**
- 基线：插画（高饱和撞色）。
- 三件套：主色=促销橙红、意象=倒计时 / 购物袋、文案=「手慢无」。
- 落点：大促主题整篇走插画 + 运动活力（斜切 / 倒计时），可深度过节。
- 检查：插画号本就是活泼基线，双11深度过节完全合理。通过。

## 八、节日化的 3 档深浅（按账号选）

| 档位 | 做法 | 适合账号 |
|---|---|---|
| 微过节 | 只换结语文案 + 标题主色微调，其余不动 | 风格绑定极紧的号（常年极简/商务） |
| 中度过节 | 标题区 + 分割线 + 结尾都透节日特征 | 有明确基线的多数账号 |
| 深度过节 | 节日应景主题整篇换该时点首选风格 | 无固定基线 / 灵活号 / 大促节点 |

> 深浅选择依据：账号节庆营销 KPI、读者对节日的参与预期、运营是否想借节日破圈。运营者可自定，本条目只给三档做法。

## 九、常见错误与修正

| 错误 | 现象 | 修正 |
|---|---|---|
| 过节就换风格 | 平时日系，中秋临时变国潮整篇 | 用「保底节日化」：基线日系 + 月亮意象点缀 |
| 所有节日同一套路 | 春节和端午都用红金 | 每个节抓住独一无二意象（端午=青绿粽叶水、中秋=月金桂花） |
| 情感过度的节日乱煽情 | 清明、哀悼类用喜庆撞色 | 该类用报纸/极简/森系，克制留白 |
| 节日元素堆满 | 标题/正文/结尾全是节日 | 三件套即可，其余收敛回基线 |
| 忘了账号品牌 | 节日色盖过品牌色 | 见「账号风格基线」的映射法，节日色当作点缀色替换品牌辅助色 |

## 十、FAQ（常见疑问）

**Q：账号是「节庆号」，平时就国潮，过节还要节日化吗？**
A：要，但方向是「换节不换风格」——守住国潮基线，把节日化集中在一个更贴的意象与文案上（中秋换成月与金桂、端午换成青绿龙舟水），别变成「每个节都像春节」。

**Q：时点表里「首选风格」和账号基线冲突怎么办？**
A：以账号基线为准（见「账号风格基线」）。时点表是「这类内容最顺的风格」，若基线是极简，就在极简上做对应节日化，不必强换国潮。

**Q：节日过了才发现做错了风格，能补救吗？**
A：节日推文时效性强，改风格的投入产出不划算。下次节前先看本条目「分季节奏表」预排，避免再翻车。

**Q：能不能同一节既做大促又走情感？**
A：可以，但要主次分明——主风格定一个，情感与大促各占所属位置，别混在同一屏。参考「风格混搭」的分节法。

## 十一、个性化留白（按账号自定）

- **节日化的深浅档**：按账号节庆力度自选（见上文八的三档），本条目只给做法不给强弱。
- **哪些节必做**：有的账号只做大促节，有的逢节必做——按账号 KPI 与读者习惯自定。
- **固定节日栏目**：是否设「节气/节日固定栏目」并长期绑定某风格变体，是账号运营规划。
