# 敦煌青绿（青绿山水、壁画纹样）

> 定位：国潮风格的**子系变体**。国潮的「红金墨」偏节庆喜庆，本变体换成敦煌青绿的「青+金+土」，往「文化、艺术、清雅、有底蕴」走——像一幅青绿山水画，也像敦煌壁画的一角。
> 适用对象：文化、非遗、传统美学、文旅、文创、高端礼赠、艺术向国货。调用方：排版时多用「青绿低饱和纯色 + 描金细边、云纹/卷草/飘带纹、对称留白」。

## 一、属于哪个顶层风格的子系

- **母风格：国潮风格**（节日营销、文化、国货、礼赠）。本变体继承国潮的「庄重、东方、仪式感」与「对称、金边、传统纹样」，但把红的占比换给青绿，气质从喜庆转为清雅。
- **一句话**：内容要「更艺术、更文化、不落俗套的大气」时，从国潮切到敦煌青绿。

### 何时用本变体，而不是直接用国潮母风格

| 内容状态 | 选择 | 理由 |
|---|---|---|
| 节庆营销、需要喜庆热闹的喜庆红金 | 国潮风格（母） | 红金墨才撑得起节庆的"欢喜"，青绿偏清冷不够热 |
| 强调文化、艺术、清雅、有底蕴的大气 | **敦煌青绿（本变体）** | 青绿山水与壁画纹样的"雅"才接得住文化厚重感 |
| 高端礼赠、非遗、文旅，要"有格调"的东方 | **敦煌青绿（本变体）** | 青+金+土的克制比红+金更显"品味"与"格调" |
| 日常国货促销需提振年味 | 国潮风格（母） | 促销要热闹，青绿的清雅节奏可能偏安静 |

判断尺：**内容在"文化/艺术/格调"还是在"节庆/热闹"**——前者走敦煌青绿，后者留国潮。

## 二、与母风格的差异点

| 对比维度 | 国潮风格（母） | 敦煌青绿（本变体） |
|---|---|---|
| 主导色 | 红 + 金 + 墨 | **青绿（石青/石绿）+ 金 + 土褐** |
| 气质 | 喜庆、庄重、节庆 | **清雅、艺术、文化底蕴、富丽而不艳** |
| 纹样 | 云纹、回纹、卷草（重装饰） | **山水纹、飘带/飞天纹、细描金边（克制的装饰）** |
| 底色 | 宣纸米、绢黄 | **米白 + 淡青色分区 + 窄幅青绿纯色块** |
| 标题 | 描金细边标题、对称结构 | **青绿纯色大标题字 + 描金细边；或「加框如画」** |
| 气质关键词 | 尊贵、仪式感 | **雅、远、大气、有年代的故事感** |

- **装饰区别**：国潮纹样偏"重装饰"（满铺云纹回纹），敦煌青绿纹样讲究"克制"——一屏只留一处重点纹样，其余用细描金边与留白。
- **对称区别**：两者都用对称，但国潮对称用来"撑场"，敦煌青绿对称用来"入画"——更像一幅能挂起来的山水，而非一张贺卡。

## 三、完整色板

> 核心是「三青三绿 + 金 + 土」，比国潮更素雅。

| 色位 | 色值 | 说明与具体用处 |
|---|---|---|
| 背景基色 | `#FBF7EE`（米白） | 全文底色，像宣纸 / 绢面 |
| 分区浅底 | `#EAF2EB`（淡青）／`#F4EDDC`（浅土） | 卡片/气泡底色，青与土轮换 |
| 主色1（石青） | `#2F8F8F`（青） | 主强调、标题底、山水线条主色 |
| 主色2（石绿） | `#7FB069`（绿） | 山水、飘带、辅助强调 |
| 辅助色1（金） | `#C9A24B`（描金） | 细描边、标题描金、纹样金线 |
| 辅助色2（土） | `#A98A6E`（土褐） | 分区底、图注点缀 |
| 强调色（墨） | `#3A342E`（暖墨） | 正文/标题字，庄重基底 |
| 正文文字 | `#4A453E`（暖灰褐） | 正文用色 |
| 次级文字 | `#8E8576`（浅褐灰） | 注释、图注 |

**每个色号一句话用法**：

- `#FBF7EE` 米白：全文底，像宣纸或绢面，决定整篇"纸绢"的温润，别换成冷白。
- `#EAF2EB` 淡青：卡片/气泡底色，让分区带一点山水之气，比纯纸色更"画境"。
- `#F4EDDC` 浅土：另一个分区底色，与淡青轮换制造"青绿与土褐"的山水土层感。
- `#2F8F8F` 石青：主强调与山水线条，敦煌青绿的名片般存在，标题底首选。
- `#7FB069` 石绿：与石青同系的辅助强调，画山水、飘带的次主色，搭配出"青绿"两色的层次。
- `#C9A24B` 描金：细描边、标题描金、纹样金线，克制的点睛，"细而不假"。
- `#A98A6E` 土褐：分区底与图注点缀，给整版一份"土地的沉稳"。
- `#3A342E` 暖墨：标题与正文的庄重基底，比纯黑暖、有"墨"的分量感。
- `#4A453E` 暖灰褐：正文主色，温、深、不刺眼。
- `#8E8576` 浅褐灰：注释、图注，可读底线。

**配色规律**：青 + 绿 + 金三主色，土与墨做基底。一屏主角是青或绿，金只做细描边与点缀（描金占比不宜超 15%），避免变成「满城尽带黄金甲」。全篇亮色 ≤3 个。

**深浅档切换**：白天/文档内容走浅档（米白底 + 青绿 + 细描金）；"夜游敦煌、洞窟氛围"的沉浸内容可切一段深档（墨青 `#223030` + 提亮青绿 + 降一档描金），**深档每篇 ≤2 处**，放在最有"入画"感的段落。深档必须保证描金线与青绿有明度差，否则细线融进深底。

## 四、标题与字号层级

| 层级 | 写法 | 示例 |
|---|---|---|
| 大标题（开头） | 墨字 + 下方一条**青绿纯色细线**（`border-bottom:2px solid #2F8F8F`），或加「描金细边」；对称居中 | `青绿之间，见千里江山` |
| 章节小标题 | 行首放一枚纯色菱形/莲花纹样 + 青字；或短横线 + 青字 | `山色如黛`（行首一枚青绿菱形徽章） |
| 重点句 | 墨字加粗 + 左右描金细线夹衬；或整句放在「画框」式卡里 | `一 卷 山 水，藏 半 部 文 昌` |

- 字号：大标题 21-23px，章节 18px，正文 15px，注释 13px。
- 标题字距 2-3px（古意可放宽到 4px），正文 0.5px，行距 1.9（舒展感）。

**青绿细线标题的写法**：标题下放一条 `border-bottom:2px solid #2F8F8F` 的青绿纯色细线，两端各留一点空；可选在线上叠一个极小的纯色莲花纹，像山水画的题字栏。标题对称居中，左右留白让它"端着"。

**章节小标的写法**：行首放一枚纯色 CSS 菱形/圆点徽章 `<span style="display:inline-block;width:8px;height:8px;background:#2F8F8F;transform:rotate(45deg);border-radius:2px;"></span>` 做莲花纹意象，再接青字短句；或一条 `border-bottom:1px solid #C9A24B` 的短描金线 + 青字。小标字距放宽到 2-3px，每章一个符号，别反复堆纹。

## 五、模块表现

- **重点气泡**：淡青底 + 1px 描金细边 + 左上角一朵莲花纹小型 + 圆角 6px；内文 14px 暖灰褐。
- **卡片**：白底/淡青底 + 描金细边 + 圆角 8px + 可选「微微土色角落」；忌厚阴影。
- **分割线**：一条细金线中间夹一个菱形/莲花纹；或一条青绿纯色细线（低饱和，不加渐变）；上下 24px。
- **花纹色带**：飘带/卷草/水纹浅档（透明度降到 30% 左右的纯色图案，或用底部细纹图片做极浅重复背景，避免平滑渐变）；整篇 ≤2 条。
- **列表**：圆点换成「水滴/叶形」纹样；编号放莲花徽章。
- **图片**：图片可加描金细边 + 白底留白，像揭开的画幅；或做成「装裱框」效果。

**一个"画框式"重点句骨架**：

```html
<div style="background:#EAF2EB;border:1px solid #C9A24B;border-radius:8px;padding:14px 16px;margin:0 0 16px;">
  <p style="margin:0;color:#3A342E;font-weight:600;line-height:1.75;">一 卷 山 水，藏 半 部 文 昌</p>
</div>
```

要点：重点句放"画框"式卡里，描金细边 1px 不要太粗；两侧若有描金细线夹衬更好，但一句话别框太多处，只留最要紧那一两句。

## 六、图片处理与装饰

- 图片：强烈建议「山水/器物/纹样」实拍配图，加描金细边与留白；次选把图压成青绿色调滤镜。
- 图片比例多取 3:4 竖构图（像立轴画），或裁成等宽横幅配土褐衬底；别放花里胡哨的现代促销图。
- 装饰克制：图案/纹样点缀每屏 ≤1 处，宁可留白。敦煌气质靠纹样与排版，不靠图案字符；如用，只选具象的莲花、山川、明月的**纯色几何意象**（CSS 或 art:// 图案），别用现代趣味图案。
- 纹样密度与图案：整篇纹样/描金点缀 ≤5 处，集中在标题、分割线、重点气泡，正文保持素净。图案资产只可用植物/自然类：如 `vine-frame` 藤蔓花框、`sprig-grass` 小草、`blossom-branch` 花枝、`leaf-corner` 叶角——在正文用 `![说明](art://资产名)` 引用，或用这些图案做气泡/标题装饰，一律低饱和纯色线条化。
- 图片加描金细边时，细边用 `1px solid #C9A24B`（透明度可降到 60%）并配白底留白，像揭开的画幅；实拍图压成青绿色调滤镜后，再叠极浅描金线手绘风更统一。
- 若只有可用的现代产品图，别硬凹西域味——可只用其中细节裁剪、配素净留白与描金细边，让"画意"靠排版而非图片本身撑起。

## 七、禁忌与陷阱

1. **别把红挤回来**：这是国潮子系最容易踩的坑——一想起传统文化就加红。敦煌青绿的特色就是「不用红」，忍住。
2. **别金到刺眼**：描金是「细线、点缀」，不是满版金底。金的占比 >15% 就俗气。
3. **别过度堆纹样**：云纹、卷草、飘带全上满就乱。纹样宁缺毋滥，一屏 ≤1 处重点纹样。
4. **别用现代趣味贴纸/emoji**：会破坏清雅古意。
5. **别忽略对比度**：青绿做文字时注意与底色对比，正文务必用暖墨/灰褐，不要整段青字。
6. **别把青绿做成"圣诞绿/荧光绿"**：`#00FF00` 这类高饱和绿会瞬间崩掉古意，石青石绿走低饱和、带灰调的"矿物绿"，才像壁画矿物颜料。
7. **别用大圆角现代气泡**：敦煌青绿讲"方圆有度"，圆角 6-8px 克制即可，别用大圆角或软糊阴影破坏骨感。

## 八、混搭方向

- **+ 国潮**：敦煌青绿做主体、在关键处（标题/收尾）加一抹国潮红/描金细边，适合节庆又想要艺术感的场景——把「国潮红金」当点缀而非主体。
- **+ 极简**：只留青绿纯色细线 + 大量留白，适合「新中式高端品牌」。
- **- 禁忌**：别混插画高饱和撞色、别混赛博朋克霓虹、别混日系卡哇伊——气质全冲。

## 九、封面与首屏建议

- 封面：青绿山水纯色背景 + 居中墨字标题 + 顶部一条描金细线 + 角落一枚印章式红方（一小点红反而是点睛），全平面、不加渐变。
- 首屏：对称结构的「画框」式开头——上描金线、中大标题、下青绿山水条。
- 配色呼应：米白 `#FBF7EE` 底 + 石青/石绿标题 + 描金细边，封面与正文同系"丹青"，点进去如展开一幅画，不跳戏。

## 十、深色模式表现

- 深色下：米白底换「墨青」`#223030`，分区淡青换 `#2B3A37`；青/绿提亮（青 `#4DB8B8`、绿 `#93C87A`），描金可降为 `#D8B25A` 保持柔和，正文用暖米白 `#EFE7D8`。
- 深色模式尤其要保证描金线与青绿的明度差，否则细线会「融」进背景。
- 原暖灰褐正文 `#4A453E` 在深底上提亮为暖米字，别沿用浅档的字被吞；描金线在深底上尽量保持可见但别亮到刺眼。

## 十一、个性化留白（按账号自定）

- **青绿比例**：青为主（清冷雅）／绿为主（温润自然）／青绿对半（经典山水）——按读者偏好与内容气质定。
- **描金用量**：克制（仅标题/分割线）／中式（重点气泡 + 卡片角）——结合内容「贵气」程度与品牌要传达的调性。
- **是否加印章红点**：加（点睛）／不加（纯青绿）——中式文创常加，要极克制则不加。
- **纹样取向**：山水纹（大气）／飘带飞天纹（灵动）／莲花卷草（温润）——按内容的意象与读者年龄取舍。
- 判断依据：读者对传统美学的接受度、内容文化艺术属性、品牌高端定位。

**给调用方的复查三问**：一、红有没有忍住不在主体出现、金有没有只做细描边而不是铺满？二、纹样是不是一屏只留一处重点、其余靠留白与细线？三、正文是不是用了暖墨/灰褐、没有整段青字压得人读不清？

**敦煌青绿的"活"在哪**：同样的青金土配方之下，比的不是谁堆的纹样多，而是谁守住了"雅"——一条青绿纯色细线、一条细描金、一片克制留白，比满版金边纹样更接近"千里江山"的气度。
