# 账号风格基线与品牌色映射

> 定位：跨风格通用方法论。一个号不是每篇随机换风格，而是有一个「长期锁定的主风格」成为账号辨识度；同时品牌若有专属色，要能把品牌色「种进」任意风格而不破坏风格气质。本条讲怎么『锁基线』和怎么『换品牌色』。
> 适用对象：长期运营的账号、有品牌色/VI 的品牌号、想做账号辨识度的号。调用方：先判断账号是否要锁基线，再按映射规则执行。

## 一、账号风格基线（长期锁定主风格）

### 什么是基线
- **基线 = 账号的「默认样式」**：读者看到一篇就知道「啊，是这家的文章」，靠的就是长期沿用同一主风格。一条顶多留 1 个主基线 + 允许少量节庆/品牌事件偏移（5% 场景）。

### 怎么定基线（四问判断）
1. 这个号的核心内容类型是什么？（按「风格选择」条目，主类型→首选风格）
2. 目标读者是谁？希望 TA 记住的「账号气质」是什么？
3. 品牌要传达的核心印象是紧张/信任/温度/潮流哪一种？
4. 竞品号大多是什么风格？想差异化还是随大流？

### 锁基线的具体操作
- **建「账号风格卡」**：把选定的风格（主色、辅助色、标题样式、花纹、文案调性）记成一张卡，作为之后每篇的「默认模板」。各风格条目里的「色板」可直接抓取。
- **默认用基线**：日常推文默认套「账号风格卡」，不做任何自由发挥。
- **预留偏移口**：只允许两类偏移——1 节日化（见「时令节日风格倾向」条目，按深浅档做）；2 品牌大事件（周年、联名、大促）可整篇换风格，但需按「风格混搭」法则处理好过渡，事后回归基线。

### 何时不锁基线
- 定位松散、每期主题跨度极大的多品类号（今天美食明天数码）：强行锁一个风格反而别扭，可允许「按内容类型选风格」，但要锁定「配色习惯 + 标题风格」这两个最小可辨识单元做底线统一。

## 二、品牌色 → 任意风格色板的映射规则

> 品牌有 VI 主色，但不能直接「把品牌色贴上去」——不同风格需要将品牌色「翻译」进对应色位，才能既认得出品牌又不破坏风格气质。

### 映射第一步：给品牌色定「角色」
品牌通常给 1-2 个主色 + 1-2 个辅助色。先按「明度 / 饱和度 / 冷暖」给它们定位到风格色板的某个色位：
- **品牌主色（通常明度适中、饱和高）** → 换「风格主色位」。
- **品牌辅助色（更浅/更中性）** → 换「风格辅助色位」或「强调色位」。
- **品牌中性色（灰/黑白）** → 换「次级文字色位」或「背景辅色位」（一般不换正文黑）。

### 映射第二步：按风格气质「调深调浅」
品牌色可能和风格气质不搭（如极简号遇大紫），不能硬贴，要**调节同系深浅**去适配：
| 风格的气质需要 | 品牌色的处理 |
|---|---|
| 庄重/克制的风格 | 把品牌主色调深一档、降饱和（如加同色相深色），去它的跳脱 |
| 活泼/潮流风格 | 把品牌主色调亮一档、提饱和，保持它的鲜 |
| 日系/森系/手账（低饱温暖） | 把品牌主色降低饱和、调向暖，保持纸感 |
| 极简/商务（高对比） | 用品牌主色做「单强调色」，其余全黑白灰，品牌色只当那个「唯一强调」 |

> 原理：风格气质的「定海神针」是底色 + 文字色 + 标题样式（这些别轻易动），品牌色替换的是「主色 / 辅助色」，替换后通过调明度/饱和度让品牌色「服帖」进该风格的气质。底色、正文文字色、标题样式一律保持风格原样。

### 替换的三步操作（以「森系」为例）
1. 取森系色板（见清水森系条目）：主色草绿 `#5B8C5A`、辅助木褐 `#9A7B5A`、背景米白等。
2. 假设品牌主色是「鲜橙 `#FF7A1A`」：按「日系/森系要低饱温暖」→调成低饱和暖橙 `#C9893A`，替换「主色位」。
3. 品牌辅助色若偏中性灰 → 替换「次级文字位」；把木褐这一类自然辅助色保留不要全盖。
4. 检查（见下文「映射后自检」）。

### 给品牌色定位的决策表（先定位再调色）

| 品牌色特征 | 归到哪个色位 | 处理说明 |
|---|---|---|
| 明度适中、饱和高的主色 | 主色位 | 大多数品牌主色的去处，需按风格气质调明/饱和 |
| 更浅、更柔的辅助色 | 辅助色位 | 承担植物图案（botanical）/ 图注 / 次级强调 |
| 偏中性（灰、黑白）、明度低 | 次级文字 / 背景辅色位 | 一般不动正文黑，只做底色与注释 |
| 很鲜亮但不适合当主字 | 强调色位 | 只做关键词 / 植物图案（botanical）点缀 |
| 品牌特别指定必用色 | 尊重品牌原样 | 当作「强调位」小范围出现，减少对风格的破坏 |

### 常见品牌色的跨风格映射示例（照着搬逻辑）

| 品牌主色 | 切进极简 | 切进森系 | 切进国潮/敦煌 | 切进插画 |
|---|---|---|---|---|
| 品牌蓝 `#2F6FED` | 直接做唯一强调蓝，其余黑白灰 | 调低饱和成雾蓝 `#8FA3C0` 做辅助 | 作为青味辅助，降低饱和配草木 | 原样提亮当撞色主角之一 |
| 品牌绿 `#3E8E5A` | 做唯一强调绿 | 接近草绿，微调饱和度 | 调向青绿当山水点缀 | 提亮成青柠绿撞色 |
| 品牌橙 `#FF7A1A` | 做唯一强调橙 | 降饱和成暖橙 `#C9893A` | 换作描金 / 辅助暖色 | 原样当撞色主角 |
| 品牌红 `#C8102E` | 降饱和作暖灰红强调 | 仅图注点缀 | 直接贴合国潮红金 | 降饱和避免刺眼 |

> 逻辑要点：**极简只当「唯一强调」、森系/日系必须降饱展暖、国潮借品牌色当辅助或描金、插画可提亮当撞角**。别把品牌色原封不动贴进所有风格。

## 三、映射后自检（4 项）

| 检查项 | 通过标准 |
|---|---|
| 气质是否仍在 | 换色后仍能认出是「哪个风格」（森系该清、极简该静、国潮该庄） |
| 品牌可辨认 | 品牌主色出现在全文至多 2 处明显位置，读者能认出「哦这是这家的」 |
| 配色克制 | 全文仍 ≤3 主色，品牌主色 + 原生辅助 ≤3，没变成「品牌色大全」 |
| 对比可读 | 换色后的标题/强调与底色对比仍够（不要在浅底上放浅品牌色） |

## 四、常见错误与修正

| 错误 | 现象 | 修正 |
|---|---|---|
| 品牌色硬贴 | 极简号贴了满版大紫大红 | 只留品牌主色做「唯一强调」，其余回黑白灰 |
| 品牌色当正文 | 正文用品牌主色，刺眼难读 | 正文锁原黑/深灰，品牌色只做标题强调 |
| 盖掉风格灵魂 | 把森系的木褐、日系的暖棕全换成品牌辅助色 | 风格关键天然色保留，只换「主色位」一个 |
| 忽视明度 | 浅底上放浅品牌色，字看不见 | 按「同系调深」规则调整，保证对比 |
| 每篇都重调 | 品牌色每篇深浅不一 | 把品牌色在该风格的「标准映射值」记进账号风格卡，一次定终身 |


## 六、系统性的换色流程（一条内容走到底）

拿到一篇要发的内容，把它「套上品牌 + 风格」的完整流程：

1. **取账号风格卡**：先拿出「账号风格卡」（见上），确认基线风格与品牌映射值。
2. **套基线色板**：先按该风格条目的「完整色板」把全文铺成标准版。
3. **替换品牌三点**：用账号风格卡里记好的品牌映射值，替换「主色位 / 辅助色位 / 强调色位」三处。
4. **守住三样**：底色、正文文字色、标题样式一律不改（这三样是风格骨架，见「映射第二步原理」）。
5. **自检四项**：过「映射后自检」——气质在不在、品牌可不可认、配色够不够克制、对比可不可读。
6. **发布前再过一遍「风格一致性」清单**。

> 这一步一档，别跳。跳了「替换」直接做自检，常会漏掉「品牌色越位」或「风格骨架被改」这两类翻车。

## 七、FAQ（常见疑问）

**Q：品牌主色和所选风格冲突太大（如极简号配万紫），还要用吗？**
A：用，但只在「唯一强调位」小范围出现，其余回黑白灰。若品牌 VI 强制满屏紫，需人工权衡「品牌优先 vs 风格优先」，本条目只给「尽量不破坏风格的通用法」。

**Q：账号风格卡要每篇都刷新吗？**
A：不。只有「换风格基线」或「品牌色变更」时才更新，日常直接读卡即可。频繁改卡会让读者认不出你。

**Q：一个号可以有多个风格卡吗？**
A：主风格一张即可（一条顶多一个主基线）。若真想多卡，请按「风格库维护」升格标准重新评审，别让多张卡稀释辨识度。

**Q：品牌辅助色要不要全替换进去？**
A：不。只换「主色位 + 一到两个辅助/强调」，风格自己的关键天然色（森系木褐、日系暖棕、国潮墨）该留就留。

**Q：节日色（如春节红）和品牌色（如品牌蓝）撞了，先顾谁？**
A：先保住品牌可辨识，节日只做点缀——把节日色当作「强调位」替换品牌辅助色，主色仍以品牌/基线的映射为主（见「时令节日风格倾向」条目）。

**Q：多账号矩阵，每个号一套卡，怎么管理？**
A：主品牌一张「母卡」（造品牌共通色与标题风格），各子号在母卡约束下微调主风格。避免各子号各自为政、读者认不出是同一集团。

**Q：换品牌色后，历史推文要不要回改？**
A：只回改「常驻栏目模板 / 账号风格卡」这类复用物，历史单篇推送不回改。保证「从现在往前」，读者看到的都是新品牌映射一致的样式即可。

**Q：想给品牌「建深色模式专用色」吗？**
A：若账号常被深色模式浏览，建议在风格卡里为每个主色记一个「深色提亮位」，否则深色下品牌色可能看不清（见各风格条目的「深色模式表现」）。

**Q：品牌主色和「账号基线」主色根本不同，先顾谁？**
A：先定基线（见「风格选择」），再用「品牌映射」把品牌色译进该基线的色位。基线是「风格」的决定者，品牌色是「品牌」的决定者，两者在「色位」层合并，而不是互踩。

## 八、个性化留白（按账号自定）

- **是否锁基线 & 锁哪个**：核心运营决策（见上「何时不锁」），本条目只给方法与判断依据，不替账号定死。
- **品牌色的映射深度**：有的品牌要求「主色必须原样」、有的允许调深调浅——以品牌 VI 规范的自定义为准，本条目给「不破坏风格的通用法」，若品牌硬性要求原色，需自行权衡「品牌优先 vs 风格优先」。
- **偏移频率**：一年仅大事件换风格 vs 每季换主题——按账号运营节奏自定。
