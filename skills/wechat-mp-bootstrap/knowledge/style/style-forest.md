# 清新森系自然风（style-forest）

> 定位：清新、自然、呼吸感，像清晨的林间、一捧绿植与透过叶缝的柔光，低饱和绿 + 柔光让内容"可呼吸"。
> 调用时机：植物鲜花、健康养生、度假旅行、自然生活、环保公益、净味好物，以及一切要"舒服、放松、贴近自然"的生活方式内容。

## 一、气质与适用内容

**气质关键词**：清新、自然、呼吸感、柔和、治愈、有生命感；低饱和绿 + 柔光是它的底色，留白与绿色是它的骨架。

**适合的内容类型与行业**：

- **植物鲜花**：绿植养护、花艺、多肉、香氛植萃。为什么合适：绿色本身就是植物的母语，森系的低饱和绿 + 柔光恰好呼应"养得活、有生命力"的安心感，读者看到就放松。
- **健康养生**：轻健身、天然饮食、养生作息、身心放松。为什么合适：养生的核心诉求是"慢和好"，森系的舒缓节奏天然契合"调理身心"的语境，不催不赶。
- **度假旅行**：自然风光、露营、民宿、户外足迹。为什么合适：户外与自然的画面用柔光合绿调呈现，能让人隔着屏幕就感到"山里的空气"，旅行感一下就起来了。
- **自然生活**：环保、节气自然、香薰、自然系好物。为什么合适：这些内容本身讲"人和自然的关系"，森系的画风让理念可视化，读起来更亲切不教条。
- **情感疗愈**：从自然视角的放松、慢生活（偏清爽版）。为什么合适：疗愈内容需要"轻、软、透气"，森系的呼吸感就是最好的安慰剂式底色。

**不适合的场合**：

- **硬核财经、严谨法律、医疗事故类**：为什么是雷区：这些场合要权威与结论，森系偏软、偏抒情，会稀释严肃感和可信度。
- **赛博朋克/街头潮流、高强度夜生活内容**：为什么是雷区：赛博与潮流的强对比、强霓虹与清新绿是两套相反语言，硬合会两边都不讨好。
- **大型严肃政经报道、密集数据轰炸**：为什么是雷区：森系要呼吸、要留白，塞满数据的场面会让它喘不过气，读者也看不出重点。
- **需要动感冲击、快速促销的内容**：为什么是雷区：促销要"赶紧的、错过了可惜"的紧张感，森系太舒缓，反而压住转化冲动。

**判断一句**：内容要"让人放松下来、呼吸一点清新、贴近自然"，森系正中；要"刺激、硬核、赶节奏"，就别用它。

## 二、完整色板表

```text
背景类（柔光浅底）
  #FFFFFF        纯白底：正文底色
  #F3F8F0        淡雾绿：分区卡，清晨绿光
  #F6FAF7        极淡薄荷：次级分区，更嫩
  #FFFDF6        米白：暖一点的柔和块（可选）

主色类（低饱和绿 1-2 个）
  #7A9E7E / #6B8E6E   鼠尾草绿/松绿：主标题、主线，森系定调
  #8FA8A0            雾青绿：另一主色/辅助，柔
  #5E8B66            森绿：深一档的绿（标题深档）

辅助色类
  #B9CBB8            浅绿灰：边框、辅助结构
  #A9BCAB            灰绿：分隔线
  #DCE8D8            淡叶绿：极浅分区线

强调色类（克制的暖点缀）
  #C89B6B            暖木棕：副标题/木质感点缀
  #D9A97A            奶茶暖：小面积暖调（阳光感）
  #B58A4D            琥珀棕：重点词/标签

文字色类
  #3D4A3E            深松绿灰：正文主色（绿调墨字，避免纯黑偏冷）
  #5B6B5D            中绿灰：次级文字
  #7A887B            浅绿灰：注释/辅助
```

**每个色号怎么用**：

- `#FFFFFF` 纯白底：正文底色，森系的"纸质感"。最干净，但别让颜色少的段落显得空，配绿字就好。
- `#F3F8F0` 淡雾绿：分区卡的地面，清晨绿光，是"块"和"底"的间隔色，柔和不抢。
- `#F6FAF7` 极淡薄荷：次级分区，更嫩更浅，放在淡雾绿上面做内层，层次要轻。
- `#FFFDF6` 米白：暖一点的柔和块，想带一点温度时用，适合居家/生活方式。
- `#7A9E7E / #6B8E6E` 鼠尾草绿/松绿：主标题、主线，森系定调色，低饱和温润，是封面的脸。
- `#8FA8A0` 雾青绿：另一主色或辅助，柔，带一点灰的青绿，可做章节下划线与次级标题。
- `#5E8B66` 森绿：深一档的绿，标题深档或强调用，比鼠尾草绿更确定、更沉。
- `#B9CBB8` 浅绿灰：边框、辅助结构，够浅，不会给画面添堵。
- `#A9BCAB` 灰绿：分隔线，中性不抢戏，比淡叶绿深一档。
- `#DCE8D8` 淡叶绿：极浅分区线，几乎隐形，只做淡淡的引导。
- `#C89B6B` 暖木棕：副标题/木质感点缀，是"暖"的主要来源，小面积用。
- `#D9A97A` 奶茶暖：小面积暖调，阳光感，做标签或关键词一角。
- `#B58A4D` 琥珀棕：重点词/标签，比暖木棕更醒目，但仍是暖棕不是红橙。
- `#3D4A3E` 深松绿灰：正文主色，绿调墨字，避免纯黑偏冷，大段正文都归它。
- `#5B6B5D` 中绿灰：次级文字，语气比正文轻一层。
- `#7A887B` 浅绿灰：注释/辅助，最轻的一档，别让它承载重要信息。

**选色原则一句话**：绿永远唱主角，暖木棕只负责"给一点温度"；一屏的绿要有深有浅有层次，别让某一种绿色独占全篇，也别一次塞进超过两种绿色做主打。

**深浅两档怎么用**：

- **浅档（默认）**：白/淡雾绿底 + 松绿字 + 暖木棕点缀。森系本体的清新生机，柔光呼吸。绝大多数森系内容都走这一档，明亮透气，像清晨推开窗。
- **深档（少，夜间感）**：深松绿底 `#223325` 或深木 `#2E4031` + 浅绿米白字，用于开篇氛围或结尾"晚安森林"，全篇 ≤2 处，保持"静谧森林"而非压抑。深档只做点缀式氛围，主体仍在浅档的清新里。

## 三、标题与字号层级

**标题样式特征**：**柔和的低饱和字 + 一点叶/枝符号**——标题色松绿、鼠尾草绿，配少量叶形或柔和符号，不尖不硬不荧光。

**装饰语法**：

- **叶片符号前缀**：标题前放一处 `![说明](art://leaf-corner)` 叶角或 `![说明](art://sprig-grass)` 小草做角饰（图案要淡、1 枚），点题又不吵。用它替代一切叶形图标字符。
- **下划线**：标题下 `border-bottom:2px solid #8FA8A0` 雾青绿细线，或双细线，柔和收边。
- **左竖条**：`border-left:4px solid #7A9E7E` + `padding-left:12px`，松绿，柔和做栏目标题。
- **小标签前缀**：`<span style="background:#7A9E7E;color:#fff;border-radius:8px;font-size:13px;padding:2px 10px;">自然手记</span>` 式松绿胶囊小标（圆角偏柔）。
- **琥珀强调**：暖木棕 `#C89B6B` 做小点缀（如节气、产地），给绿里添一点点温暖。

标题的装饰只挑其中 1-2 件用：要么叶片符号，要么下划线，要么左竖条；全上反而像过节挂满彩带。用一个符号 + 一种线条，是森系标题最稳的组合。

标题装饰都以"轻、柔、少"为度：一枚叶、一条细线就够，别在标题上又上叶又上色块，堆多了就失去清新。

**标题与正文的关系**：标题负责"点出清新与松绿"，正文负责"把话说清楚舒服"。标题用了松绿或鼠尾草绿，正文就老老实实用深松绿灰 `#3D4A3E`，让标题永远是画面里最有色彩的那一层，别让正文跟标题抢绿。

**字号字重建议**：

| 层级 | 字号 | 字重 | 用法 |
|---|---|---|---|
| 主标题 | 19–21px | 600–bold | 松绿 + 叶片符号 |
| 章节标题 | 16–17px | 600 | 鼠尾草绿 + 下划线/左竖条 |
| 小节/副标题 | 15px | 600 | 深松绿灰 |
| 正文 | 15px | normal | 行高 1.75，字距 0.5px（硬规范） |
| 注释/季节 | 13px | normal | 浅绿灰 |

> 标题上 28px 下 12px（硬规范）；松绿大标题可上 30px 下 14px 稍宽松，配低饱和留白。

正文保持行高 1.75、字距 0.5px，为的是"字与字之间留出呼吸"，这正是森系在字排上的秘密——不是字少，而是间距给够。

## 四、模块表现

- **重点气泡**：**淡雾绿低饱和气泡**——`background:#F3F8F0` + `border:1px solid #C9D8C8` 浅绿细边 + **圆角 14px**（柔）+ `padding:14px 16px`（硬规范）；左上角可放一处 `![说明](art://sprig-grass)` 淡绿小草角饰。不用阴影/光晕。
- **卡片**：白/淡雾绿底 + `1px solid #DCE8D8` 浅叶绿细边 + **圆角 12–14px** + `padding:14px 16px 12px`；顶部可放 4px 松绿横条或叶片符号。卡片间 16px。
- **分割线**：**细软的叶线**——`border-top:1px solid #DCE8D8`，或一段 `border-style:dashed` 浅绿虚线，配居中一个 CSS 圆点（`span`，松绿，圆角 50%）或 `~`（波浪感）；上下 24px。森系的分割线要轻、透气、不像街灯。
- **花纹**：可选**极浅叶形/树叶脉络底纹**（重复图案，明度近纸绿 #F3F8F0）、或者**极浅斜纹**做仿树轮；≤2 种且很浅柔和。
- **列表**：用 `·` 圆点或 CSS 鼠尾草绿圆点（`span`，圆角 50%）当项目符，行距 1.75；或每项前放一处淡 `![说明](art://sprig-grass)` 小草角饰。暖木小圆点也可。
- **步骤**：**自然生长流程**——"土壤→种子→萌芽→生长"式意象步骤，圆点用鼠尾草绿，或配 `sp1 / 2 / 3` 编号 + 一处淡绿小草角饰；步骤间 16px。可做"陪植物长大"的打卡式步骤。

模块整体守住"圆角柔、边线浅、底子亮、留白多"的统一句法：低饱和纯色 + 细边框只轻轻一笔，别让任何模块有"硬块"感。

## 五、图片与装饰

- **图片处理**：**圆角 14–16px**（柔和），配**低饱和绿色调滤镜**（提亮、降饱和、加一点绿或暖色），图片亮而透气不暗沉。
- **氛围**：植物、阳光、微风氛围图绝配；可叠极浅白/绿罩做柔和，让图融入森系底色。
- **比例**：多取 **3:4**（植物/细节竖版）或 **16:9**（自然风光）。
- **裁剪与构图**：植物特写可裁成竖幅突出叶片与晨光，林间大景用横幅拉出纵深感；画面里的光斑、露珠、逆光都是天然的森系装饰，留着它们能省一张素材的力气。
- **文字压图**：在图上叠标题时，给文字加一层极浅白或半透明罩（如 `background:rgba(255,255,255,0.55)`），保证压图字仍能读清，别让图和字互相吞。
- **装饰克制**：图案/几何点缀每屏 ≤1 处，宁可留白。要用装饰只放植物/自然类：`![说明](art://sprig-grass)` 小草角饰、`![说明](art://vine-frame)` 藤蔓花框做标题边框、`![说明](art://blossom-branch)` 花枝做装饰，避免电子/刺眼的图标印花堆叠。绝不用图标类图案。

图片记得修"亮一点、柔一点、绿一点"：森系图最怕暗沉发闷。选图优先有光有叶的逆光、晨光素材，别用大面积死绿或偏灰的片子。

图片上的元素也要"让位给文字"：森系图本身就美，别让它再抢标题的注意力。图里已经有了绿叶和光，那标题就只管把字说清，二者各司其职才清爽。

## 六、文案调性

**语气关键词**：清新、舒缓、自然、呼吸、治愈、贴近生活；像清晨深呼吸，慢而舒服。

**句式倾向**：

- 用"呼吸""慢下来""阳光""风""光合作用"等自然意象，让文字自带画面。
- 句子舒缓、有留白，多用感官描写（光、香、风、绿），唤起"看得到、闻得到"的身体感。
- 少催促、少夸张，营造"自然就好"的状态，不硬造紧迫。
- 适度科普自然知识（有理有据，不玄学），给"舒服"之外一点"长见识"的满足。

**示例句**：

- "把绿意搬进房间，日子也跟着水润起来。"
- "晨光落在叶子上，那一刻，时间慢得刚刚好。"
- "这盆多肉，陪了我三年，比日历还准时。"
- "周末去山里走一走，氧气和心情一起满格。"
- "浇水的时候，其实也是在给自己放慢一拍。"
- "风一吹，窗台那盆小绿，替我呼吸了一整天。"
- "有些事急不来，光合作用都知道。"
- "把窗打开，让屋里也长一片小森林。"

这些示例句的共同点是"慢、有画面、带一点呼吸感"：不急着讲道理，先把光、风、绿递给读者。真正的内容信息留给正文段落去展开，示例句负责让读者先"放松下来"，再顺着往下读。

## 七、禁忌与陷阱

1. **绿色过度饱和/荧光感**：用 `#00FF00` 或高饱和翠绿 → 变成"荧光草地"，森系崩。
   反例：标题用 `#2ECC40` 高饱和绿，整篇像荧光海报 → 清新感全失，刺眼。
   正解：绿色走**低饱和** `#7A9E7E / #6B8E6E`，压饱和度，才有清新不是刺眼。
2. **暖色抢戏、太花**：暖木棕 + 奶茶 + 琥珀全上 + 高饱和 → 森系变混搭大杂烩。
   反例：副标题暖木棕、正文琥珀棕、标签奶茶暖、图标全是棕 → 绿被挤成配角。
   正解：**绿是主体，暖色只是小点缀**（木棕给副标/标签，奶茶/琥珀各 1 处小用），绿色占主导，暖只负责"有点温度"。
3. **底噪花纹太浓**：绿叶脉络底纹画得太深 → 像水渍污点。
   反例：脉络底纹做到中明度，能看清纹路 → 满篇像贴了花布，干扰正文。
   正解：花纹明度压到近纸绿（#F3F8F0 级），几乎看不见，只做氛围。
4. **忽略可读性（浅字浅底）**：浅绿字放白底、白字放淡绿底 → 看不清。
   反例：正文用 `#7A887B` 浅绿灰放白底、标题白字放淡雾绿底 → 发虚费眼。
   正解：正文用深松绿灰 `#3D4A3E`，标题才用彩绿；浅底一律深字，彩绿只做标题/装饰而非正文。
5. **无层次、全是绿**：通篇同一绿色 → 单调发腻。
   反例：标题、正文、列表全用同一个 `#7A9E7E` → 一眼平，没有起伏。
   正解：用**深松绿（标题）→ 鼠尾草绿（副标）→ 浅绿灰（注释/边框）→ 白/淡雾绿（底）**的阶度，绿里有层次，配木棕做呼吸。

**总原则**：每一个坑的共同根源都是"度"——饱和度、暖色占比、花纹深浅、单一绿都有各自的边界，越界就从"清新"变成"刺眼、花、闷"。遇到任何模块，先问一句"它还能再淡一点吗"，能就再压一压。

## 八、混搭方向

- **森系 × 日系（主 7 : 辅 3）**：植物/生活方式内容，森系的绿 + 日系的米纸暖棕，更纸感治愈（与"日系 × 森系"互通）。
- **森系 × 手账（主 7 : 辅 3）**：植物手账/生活记录，加手账的虚线与打卡清单（见「手账风」），更"在记录自然"。
- **森系 × 极简（主 8 : 辅 2）**：自然生活观/慢生活品牌，加大留白、减装饰，走"极简森系"更高级。
- **森系 × 美式复古（主 8 : 辅 2）**：户外露营/田园复古，偶加一点奶油棕做点缀（见「美式复古」）。

参照「风格混搭与主辅法则」；森系做主风格守住低饱和绿 + 柔光。

## 九、封面建议

- **构图**：**大幅自然图 + 居中标题**——一捧绿叶/林间光/一扇窗绿景，标题叠在图的一侧或居中；留白呼吸。
- **配色呼应**：淡雾绿 `#F3F8F0` 底（或图片本身的自然绿）+ 松绿 `#7A9E7E` 标题 + 琥珀暖小点缀，与正文同色系连贯。
- **字**：标题 ≤6 字、松绿或白字（压图用白字 + 半透明深罩），副标一句，别堆字。
- **气质**：清新、舒爽、如清晨走进森林；封面就要让读者一眼"想深呼吸一下"。

封面是内容的分身：正文以松绿做主色，封面也让松绿当家；封面和正文主绿一致，读者才认得出"还是那篇森系"。

封面元素同样走"少而清"：一张好自然图 + 一句松绿标题就足够；堆太多字和色块，反而把清晨的呼吸感压没了。

## 十、深色模式表现

- 深色模式把淡雾绿底换成**深松绿/深木底**（`#1F2E22` / `#263428`）+ 浅绿米白字 `#DCE8D8`，保持绿调不刺眼。
- 松绿 `#7A9E7E` 在深底上保留或略提亮为 `#9FBE9F`；暖木棕 `#C89B6B` 提亮为 `#D9B084` 保对比。
- 深松绿灰正文 `#3D4A3E` 在深底上要提亮为浅绿灰，否则被吞，读不清。
- 浅叶绿边 `#DCE8D8` 在深底上改深绿灰 `#4A5C4A`，让边框仍然看得见又不刺眼。
- 森系本来就应避免阴影与光晕，深色模式下更别加任何柔光晕影，保持纯色平面与留白透气，别让暗底上再叠一层光雾。

深色模式下森系要做的不是"变赛博"，而是"换一套更安静的绿"：浅档的明快在暗底上不再适用，把整套色往上提亮、往下压饱和，保持"静谧森林"而不是"幽闭洞穴"，氛围就守住了。

## 十一、个性化空间

- **主绿选择**：账号可自定义绿色系——偏暖用黄绿/抹茶 `#8FA87E`，偏冷用松绿/蓝绿 `#5E8B66`。判断依据：品牌色与内容情绪（暖绿更治愈，冷绿更干净）。
- **暖木棕比重**：植物类可少暖色重绿；居家/生活方式可加一点木棕暖意。判断依据：内容是想"更鲜活"还是"更温暖"，前者重绿，后者添暖。
- **柔光与留白**：疗愈/慢生活向可更大留白 + 更柔；实用植物养护干货可稍密一点、多步骤卡。判断依据：读者是想"放松读"还是"拿笔记"，决定了要疏还是要实。
- **装饰密度**：治愈向可多一档植物图案点缀（`art://sprig-grass` / `art://blossom-branch`），偏干货养护向降一点。判断依据：读者年龄与内容松紧，越治愈越可多叶。但每屏 ≤1 处，宁可留白。
- **深浅倾向**：夜读向可用深松绿整篇，"清晨光合"向用浅档。判断依据：内容的阅读时段与氛围，深档只在想要"静谧之夜"时交出来。

这里列的都是可依据账号与读者自定的可调参数，调用方应结合品牌色、目标读者与内容语境落地，不做死模板。森系的价值就在于"可呼吸"，把决定权和留白一起交给读者就好。
