# 15 · 风格总览（八种风格详解与选择）

> 用途：拿到任务先定风格，再定模块与文案。风格决定**配色 + 标题样式 + 边框气质 + 花纹 + 文案调性**。
> 八种风格地位平等，均按同一套维度描述（气质 / 适用内容 / 主色 / 标题 / 气泡与边框 / 花纹 / 结构 / 文案调性 / 示例开头），按内容类型选择即可。
> 深度色板与模板：《风格与配色》（6 风格色板）+《内容与配色》；风格化配色从本文件各风格条目的色板读取后，以模板 HTML 或内联样式落地（排版系统不提供内置配色主题）。

## 一、风格选择速查（内容类型 → 推荐风格）

| 内容类型 | 推荐风格 | 设计模式 | 气质关键词 |
|---|---|---|---|
| 校园活动/社团招新/学习笔记 | 校园（活力清新） | promo | 青春、明快、元气 |
| 科技新品/技术干货/数码测评 | 科技（理性锐利） | promo/text | 专业、简洁、数据感 |
| 节日营销/文化/品牌国货 | 国潮（红金墨） | promo | 庄重、东方、仪式感 |
| 职场技能/金融/行业报告 | 商务（克制专业） | text/promo | 可信、高效、留白 |
| 生活方式/美食/旅行 | 日系（纸感温暖） | text | 治愈、手作、慢生活 |
| 情感/随笔/亲子 | 手账（柔和贴纸感） | text | 温柔、陪伴、小确幸 |
| 观点/品牌/极客审美 | 极简（高冷克制） | text | 高级、留白、单色 |
| 快消/母婴/娱乐 | 插画（高饱和撞色） | promo | 活泼、圆润、热闹 |

## 二、八种风格详解（统一结构，平等条目）

### 1. 校园风格
- 气质：青春活力、亲切元气、轻松有趣
- 适用内容：校园活动、社团招新、学习笔记、学生向内容
- 主色：天蓝 `#4A90E2` + 珊瑚粉 `#FF7E9D` + 明黄 `#FFC53D`（高饱和但明快）；可配马卡龙浅色点缀
- 标题：大圆角贴纸感——白字彩底胶囊、几何点缀
- 气泡与边框：浅彩底 + 大圆角 16px、植物图案角饰（art://sprig-grass）、彩色细边框
- 花纹：圆点、彩虹斜纹、格纹（浅档）
- 结构：卡片密集、纯色圆点列表、活泼步骤
- 文案调性：亲切元气（"一起""超实用"），感叹号克制、卖萌适度
- 示例开头："开学第一周，社团招新开始啦！3 个理由让你爱上摄影社——"

### 2. 科技风格
- 气质：理性专业、简洁锐利、未来感
- 适用内容：科技新品、技术干货、数码测评、数据向内容
- 主色：深蓝紫 `#2F6FED` / `#3B4FC0` + 青 `#00B8D9`（低饱和冷色）；单强调色 + 中性灰 `#667085`
- 标题：h1 荧光下划线或左竖条、h2 编号块，克制无装饰
- 气泡与边框：左竖条浅底，或深蓝纯色白字（焦点）
- 花纹：无花纹或极浅细斜纹/网格，宁缺毋滥
- 结构：分栏对比、时间线、数据图示、留白大
- 文案调性：数据说话、结论先行、无废话、术语准确
- 示例开头："3 组实测数据告诉你：新算法比旧方案快 42%。"

### 3. 国潮风格
- 气质：庄重、东方、仪式感
- 适用内容：节日营销、文化内容、品牌国货、礼赠主题
- 主色：红 `#C8102E` + 金 `#E6B422` + 墨 `#2B2118`
- 标题：box 纯色框标题、对称庄重结构
- 气泡与边框：朱砂红纯色气泡 + 金线细边、纯色双层边框
- 花纹：棋盘/斜纹浅档（云纹感）
- 结构：对称结构、横幅开篇、克制点缀
- 文案调性：庄重文雅（"礼遇""匠心""共此时"）
- 示例开头："中秋礼遇，明月共此时——一份东方美学的团圆心意。"

### 4. 商务风格
- 气质：可信、高效、克制专业
- 适用内容：职场技能、金融理财、行业报告、B 端内容
- 主色：深蓝 `#0F2A5E` 系 + 中性灰；忌彩色堆叠
- 标题：左竖条、细线标题，无花哨装饰
- 气泡与边框：细线边框卡、浅底气泡
- 花纹：忌花纹与花哨气泡，保持干净
- 结构：细线表格、对比块、图表化表达、留白大
- 文案调性：专业可信（"方案""效率""标准"）
- 示例开头："3 个判断标准，帮你选对方案。"

### 5. 日系风格
- 气质：治愈、手作、慢生活
- 适用内容：生活方式、美食、旅行、家居
- 主色：米纸底 `#FAF3E3` + 暖橙棕；文字为主
- 标题：居中带小符号装饰（细线 + 符号）
- 气泡与边框：暖色浅底气泡、细分割线
- 花纹：极浅暖调纹样，或不用
- 结构：文字为主，图片克制、留白充足
- 文案调性：温柔细腻（"慢慢""小确幸""陪伴"）
- 示例开头："下班回家，锅里的米饭还热着，这就够了。"

### 6. 手账风格
- 气质：温柔、陪伴、小确幸
- 适用内容：情感、随笔、亲子、日记体
- 主色：粉紫奶油色系；文字类专属
- 标题：贴纸感几何装饰标题、手账式清单标题
- 气泡与边框：虚线边框气泡、贴纸感圆角
- 花纹：细碎点缀纹样（浅档）
- 结构：手账式清单、分节卡片
- 文案调性：温柔细腻，第一人称叙事多
- 示例开头："把今天的小事，记进手账里。"

### 7. 极简风格
- 气质：高级、留白、单色
- 适用内容：观点、品牌宣言、极客审美、设计向内容
- 主色：黑白灰 + 单一强调色
- 标题：左竖条或纯文字标题，无装饰
- 气泡与边框：无边框卡片、细线分割
- 花纹：无花纹
- 结构：大留白、少即是多
- 文案调性：干脆笃定（"少即是多""只做一件事"）
- 示例开头："少即是多。这句话值得每个产品经理抄三遍。"

### 8. 插画风格
- 气质：活泼、圆润、热闹
- 适用内容：快消、母婴、娱乐、促销
- 主色：高饱和撞色（但 ≤3 主色）、大圆角
- 标题：大圆角 banner、白字彩底
- 气泡与边框：大圆角纯色气泡、圆润卡片
- 花纹：花朵纹、波点纹（art://flower-band）
- 结构：卡片网格、横幅开篇
- 文案调性：活泼热闹（"狂欢""抢先""限量"）
- 示例开头："夏日狂欢大促，全场 5 折起！限量 100 份，手慢无。"

> 已按 v10 规范：零 emoji/零图标字符、零渐变、零阴影、纯色平面化 + art:// 植物图案

## 三、风格选择三原则

1. **匹配读者**：先想读者是谁——学生群体、决策者、家庭用户、极客……读者画像直接决定风格。
2. **匹配情绪**：热闹促销、冷静科普、温情陪伴……内容的情绪基调与风格气质一致。
3. **克制执行**：风格是"主色 + 2-3 个特征元素"的组合；全篇 ≤3 主色、花纹 ≤2 种；风格是方向，不是堆料（活泼 ≠ 杂乱，专业 ≠ 冰冷）。

> 快速上手：先定风格（本文件）→ 取色板（《风格与配色》）→ 用排版语法组装（《模块总览》）→ 按《文案总览》写内容。
