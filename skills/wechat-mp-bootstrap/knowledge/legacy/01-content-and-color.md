## 1. 内容主题 → 色板映射

### 1.0 总原则

- 每个内容类型给 **2-3 个主色 + 1-2 个辅色 + 1 个文字色建议**。
- 色板中的"主色"用于强调、标题、按钮、"正文"色恒用深灰蓝 `#3d4257`（比纯黑 `#000` 更柔、护眼、高级）；正文字号基线 16px、行高 1.75、段距 16px。
- 辅色用于点缀、分支、次要标签，用量 ≤10%。
- 背景默认纯白 `#ffffff`；若用浅底色，请保持正文对比度 ≥4.5:1。

### 1.2 各类型的设计要点（一句话）

- **科技/数码**：蓝紫主调传递"理性、前沿、信赖"，可加一点电光橙作"亮点 CTA"；避免大面积高饱和青。
- **美食/餐饮**：暖红橙色最"开胃"，能刺激食欲；文字别用大红标题刺眼，用深棕。
- **健康养生**：低饱和青绿"舒缓可信"，橙色仅作警示性强调（如"注意/风险"），用量极小。
- **教育**：蓝紫色"专注、可靠"；可加黄"划重点"，但黄色只配深色文字，否则对比度不足。
- **金融理财**：藏蓝+金的"稳重高级"优于大红大绿；涨跌红绿仅用于涨跌标注，不作全文强调。
- **母婴**：低饱和粉/蜜桃"柔软温馨"，避免荧光高饱和伤眼；多用大段留白。
- **美妆时尚**：高饱和玫红/紫"时尚吸睛"，可用深色标题压住；底色调低饱和。
- **旅游**：青绿+沙黄"自由放松"；橙红做目的地亮点；避免全部高饱和造成"花"。
- **职场**：藏青+橙的"严谨又不失进取"；灰做层级区分；红仅在警示。
- **情感治愈**：紫粉棕"温柔治愈"，饱和度整体调低 15-30%，大量留白与浅底。

## 2. 配色方法论

### 2.1 60-30-10 法则

- **60% 主色（基底/环境色）**：微信正文=白底 + 大面积中性色（文字、段距、留白）。这里的"主色"其实是**中性基底**，不要理解为高饱和主色铺满。
- **30% 次色（与主色相邻）**：标题、章节分隔、次级强调块、表格表头。
- **10% 强调色（点睛）**：CTA、重点句高亮、图标、气泡框左框条。**全篇真正"彩"的只有这 10%**。

> 微信正文落地：底色白 60% + 中性深灰文字 30% + "强调色"点状使用 10%。**人眼记住的是一篇的"主色调"，不是每个色块。**

### 2.2 语义色与品牌色协调

语义色是"含义 = 颜色"的约定：
- 🔵 **信息/提示** info → 蓝；🟡 **警告/注意** warn → 橙黄；🟢 **成功/通过** → 绿；🔴 **危险/错误/风险** → 红；⭐ **重点/收藏** → 强调色。

协调三原则：
1. **语义色只出现在具有"那个语义"的内容上**——"成功"才用绿，"警告"才用黄橙，不当作装饰色乱用。
2. **当语义色 ⊆ 品牌色板时**最好（如科技账号的蓝既是品牌也是 info），此时语义色直接用品牌色系，全篇最统一。
3. **当语义色 ∉ 品牌色板时**（如粉紫账号要表达警告），放宽：警告态用一个"品牌色板中相邻、但更亮/更橙"的变体。**红线：语义色永远不与品牌强调色完全同款，否则读者无法区分"这是重点"还是"这是警告"。**一般规则：重点=品牌主强调色；警告=偏橙黄；错误=偏红。当品牌主色本身是红，则把"错误"降为更深红/带边框对比，区分层级。

### 2.3 避免"配色混乱"的 5 条硬规则

1. **数量上限：全篇不超过 3 种"活跃色"**（1 主强调 + 2 语义/辅），其余全部中性灰。底色、文字色不算"活跃色"。
2. **饱和度控制：主强调色饱和度适中（不要全用纯色 100% 饱和）**；大面积色避开最高饱和；越接近 10% 强调用量越可高饱和。
3. **对比度要求（硬指标）**：
   - 正文 vs 背景 ≥ **4.5:1**（WCAG AA，文字字号 <18px 必守）。
   - 大标题/大块文字（≥18pt 粗体）可放宽到 ≥3:1。
   - 主强调色若用作**小字号文字**，也需 ≥4.5:1。
   - 例：黄色 `#ffd43b` 配白底对比度仅约 1.4:1，**严禁黄底白字/白底黄小字**，须用深色压字。
   - 正文推荐 `#3d4257` 配白底，对比度约 ≈9:1，达标且不刺眼。
4. **层次用"明度+字号"而非"更多颜色"**：同级并列用同一色不同深浅，别引入新的颜色。
5. **每换一个内容板块，允许换一组强调色，但全局基调色/主色保持 1 个即可贯穿全篇。**

### 2.4 三个速查判断

- 打开一屏截图：**除白底/灰底/文字外，能数出的"彩色" ≤3 种** → 及格；>5 → 配色混乱，砍。
- 任意一句正文文字无法在背景上轻松阅读 → 对比度不足，用更深文字或更浅底色。
- 某颜色"既像重点又像警告又像装饰" → 职责不清，只保留一个定义。

## 3. 从文章主题/封面图提取色板（纯规则启发式，不用工具）

### 3.1 封面图取色法

不采样像素，用**视觉主体/环境**规则推：
1. **主色 = 封面上最大的一个"视觉主体物"颜色**（手机、食物、风景主角、人物服装）。
2. **辅色 = 主体周边的 1 个环境色/次要物颜色**（背景主色、装饰元素）。
3. **文字色/强调 = 与主色对比度最高、面积最小的那个色**（通常是"反差点缀"，如食物上的高光、CTA 按钮色）。
4. 输出 3 个色即可，其中第 3 个优先选饱和度较高的作为强调。

判断口诀：**"主体一个、环境一个、亮点一个"**——三色原则。

### 3.2 从主题关键词推（无封面时）

把主题映射到 1.1 的表：
- 命中共识情感/行业词 → 直接取该行色板（如"AI"→科技蓝）。
- 主题含**具体物体** → 物体固有色的行业代表色（"咖啡"→咖啡棕；"海洋"→海蓝；"花"→对应花色的低饱和版）。
- 主题含**情绪/氛围词** → 蓝色系(冷静沉稳)/暖色系(热情温暖)/紫色系(温柔神秘)。

### 3.3 落地三步法（从粗到细）

1. **粗取 3 色**（上两法）。
2. **降饱和/调明度**：把 100% 饱和的原色降到约 70-85% 作为主画布色；强调色保留高饱和但**缩小面积**。
3. **补中性文字色**：统一正文 `#3d4257`，标题用主色的深色版（主色明度降 40% 或直接混黑）。

### 3.4 反例提醒

- **别直接抄封面上几个大色块的原始色** → 会全部高饱和、花掉 → 必须降饱和。
- **别把封面里所有颜色都带进正文** → 最多 3 活跃色。

## 4. 内容类型 → 设计调性映射

### 4.1 调性气质表

| 内容类型 | 气质关键词 | 色系倾向 | 文本 vs 宣传 |
|---|---|---|---|
| 📄 干货/教程/清单 | 冷静、理性、可信、条理 | 蓝/青/藏青 + 一个强调 | **文字类**为主，强调色点缀关键结论 |
| 💨 资讯/快讯/周报 | 干净、高效、中性 | 灰蓝 + 少量强调 | **文字类**，弱化装饰突出信息密度 |
| ✒️ 随笔/散文/感悟 | 温柔、留白、治愈 | 低饱和紫/粉/棕 + 大量留白 | **文字类**，几乎无装饰，靠排版节奏 |
| 🎪 活动/发布会/沙龙 | 活力、热络、氛围 | 主色 + 渐变/圆角卡片 CTA | **宣传类**为主，需强视觉引导 |
| 🛒 促销/打折/新品 | 冲击、欲望、行动 | 高饱和主色 + 强 CTA 按钮 | **宣传类**，CTA 按钮最大、最亮 |
| 📢 公告/通知/规则 | 正式、克制、庄重 | 藏青/深灰 + 单色强调 | **文字类**，规范严肃，禁花哨 |
| ✨ 品牌新品发布(概念) | 高级感、克制、氛围 | 低饱和主色 + 大量留白 + 大标题 | **宣传类**但走"高级感"非"促销轰炸" |

### 4.2 文字类 vs 宣传类 选择建议（据现有设计基线）

- **文字类基线**：正文 16px/行高 1.75/段距 16px；强调色 **`#2f6fed`（蓝）**；适用干货、资讯、随笔、公告。
- **宣传类基线**：三主色 橙 `#ff6b35` / 青 `#00b8a9` / 紫 `#7a3cec`；适用活动、促销、新品。
- **判断标准**：
  - 目标 = **让人读完、理解信息** → 文字类。
  - 目标 = **让人点击、报名、下单、产生行动** → 宣传类。
  - 内容 **信息密度高、重阅读** → 文字类；**视觉情绪强、重氛围** → 宣传类。
  - 混排场景：长图文促销，可"正文段走文字类基调 + 关键 CTA 走宣传类强调"，但**全篇仍只保留 3 活跃色**。
