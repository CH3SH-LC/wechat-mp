## 开头（页眉）模块详解——三种开篇结构

> 开头与结尾是决定读者去留的关键位置，故展开详解；其余模块按上表使用即可。

1. **横幅开篇**（促销/活动/新品）：`# 大标题` + `[[banner:主标题|副标题]]` → 第一段钩子文案 → 首个 `> [!KEY]` 核心卖点。视觉焦点最强，宣传类首选。
2. **装饰标题开篇**（内容型/品牌）：`# 标题` + `[[title:副题|flower]]`（或 box）→ 引言段。仪式感适中，文字类/国潮/日系可用。
3. **极简开篇**（观点/干货/科技）：`# 标题` + 直接钩子段（结论先行）。无装饰，靠文字张力；科技/极简/商务首选。

页眉间距：标题上 28px 下 16px；banner 后正文块距 16px（系统自动处理）。

## 结尾模块——行动号召三式

1. **利益驱动**："点击下方小程序卡片，**立减 30 元**"（宣传类 + `[[badge:限时]]`）。
2. **情绪驱动**："如果这篇文章对你有用，点个在看，让更多人看到。"（文字类 + `==在看==` 高亮）。
3. **悬念驱动**："下期聊聊怎么选书，关注我，别错过。"（任何类型）。

## 模块组合铁律

- 同一模块**风格统一**：一篇里卡片只用一个样式（card 或 frame 或 cols，别混三种）。
- 装饰密度：气泡 ≤2、徽章 ≤3、花纹 ≤2 种、装饰标题 ≤2 处；其余靠留白与字号分层。
- 所有模块间距自动满足间距规范（16px 块距/1.75 行高），粘贴外部模板时自查。
