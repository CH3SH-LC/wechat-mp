## 二、间距规范（违反即返工——所有排版都必须遵守）

- **块间距**：段落/气泡/卡片/步骤/列表/代码块/图片 之间统一 **16px** 底部间距（`margin:0 0 16px`）。
- **行距**：正文与所有块内文字统一 **1.75**；代码块 1.6。
- **页边距**：微信端正文视口自带左右边距，正文内**不自设**左右 padding；卡片/气泡内容与边框 **≥12px**（气泡统一 `padding:14px 16px`，渐变气泡 `16px 18px 14px`，卡片内文 `14px 16px 12px`）。
- **标题层级**：标题上方 **28px**、下方 **12px**（h3 上 24px 下 10px）。
- **分割线**：上下 **24px**。
- **图片**：上下 **12px**。
- **字距**：正文 `letter-spacing:0.5px`；标题 1-6px 视风格。

## 三、工作流（写一篇推文）

1. 澄清主题/读者/字数/调性（最多 1 问）。
2. 定类型（文字/宣传）→ 按路由表打开对应知识文件。
3. 拟标题（《内容策略》公式）→ 定结构（钩子→分层→行动号召）。
4. 按《排版语法全表》语法写正文；需要装饰/布局/图文时，从对应知识文件**挑选模板并改用设计系统色板与间距规范**。
5. 用排版工具生成（可选自动/文字类/宣传类三种模式），检查输出与间距规范是否一致。
6. 交付：导出文件 → 写入草稿箱 → 发布/查询状态（按账号权限可用性）。

## 四、知识文件与排版系统的关系

- 排版系统内置：气泡/卡片/步骤/分割线/徽章/横幅/高亮 + art:// 资产，已全部符合间距规范。
- 知识文件提供**更丰富的设计模式**（复杂标题、分栏、图文混排等），用法二选一：
  a) **直接改 markdown 调用内置语法**（推荐，可校验）；
  b) **把模板 HTML 粘贴进 markdown 原文**（系统会原样通过，注意自行遵守间距规范与配色纪律）。
- 所有知识文件模板的色值需替换为设计系统色板（文字类单强调色 `#2f6fed`；宣传类 ≤3 主色 橙 `#ff6b35`/青 `#00b8a9`/紫 `#7a3cec`）。
