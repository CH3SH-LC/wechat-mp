# 06 · 排版语法全表

> 写正文时使用 Markdown + 以下语法，系统会自动生成微信可识别的排版样式。全部样式已符合间距规范（16px 块距/1.75 行高）。

## 模式选择

- 自动模式（默认）：正文含 `::: card/steps`、`> [!...]`、`[[banner`、`[[badge`、`art://`、`~~~` 任意一种 → 按宣传类排版；否则按文字类排版。
- 也可手动指定：文字类 / 宣传类。

## 语法表

| 语法 | 效果 | 文字类表现 | 宣传类表现 |
|---|---|---|---|
| `# 标题` ~ `###### 标题` | 标题 | h1/h2 左竖条（强调色），h3+ 纯色 | h1 下划线居中、h2 纯色序号自动编号、h3 左条 |
| `> [!NOTE] 标题` + `> 正文…` | 提示气泡 | 蓝左条+浅底 | 浅底卡片 |
| `> [!TIP]` | 技巧气泡 | 绿左条 | 青绿纯色气泡 |
| `> [!WARN]` | 注意气泡 | 琥珀左条 | 琥珀纯色气泡 |
| `> [!DANGER]` | 警示气泡 | 红左条 | 红纯色气泡 |
| `> [!KEY]` | 重点气泡 | 深蓝左条 | 橙纯色气泡 |
| `> [!KEY\|grass]` 等 | 气泡图案角饰 | grass 小草/vine 藤蔓/leaf 叶片/blossom 花朵（art:// 资产） | 同左 |
| `> 引用文字…` | 普通引用 | 蓝左条浅底 | 橙左条+引号 |
| `::: card 标题` … `:::` | 卡片 | 细边框+灰标题栏 | 白卡+顶部纯色条 |
| `::: steps` + `- 条目…` + `:::` | 编号步骤 | 蓝数字圆 | 纯色数字圆 |
| `---` | 分割线-细线 | 浅灰线 | 橙红纯色线 |
| `***` | 分割线-圆点 | `· · ·` | 三彩点 |
| `___` | 分割线-条 | 蓝纯色细条 | 双头细线+菱形 |
| `~~~` | 分割线-丝带 | 细线 | 三层纯色丝带 |
| `[[badge:文本]]` | 行内徽章 | 蓝底圆角签 | 橙纯色胶囊 |
| `[[banner:主标题\|副标题]]` | 整行横幅 | 居中标题+下划线 | 纯色横幅 |
| `==文字==` | 荧光笔高亮 | 淡黄底 | 琥珀底 |
| `[[title:文字]]` | 装饰标题（居中+两侧线+菱形） | 灰线蓝菱 | 纯色线橙菱 |
| `::: cols` + `- 项…` + `:::` | 分栏卡片（2 项 50% / 3 项 33.3%，白卡/浅底卡） | 浅底细边框 | 白卡+纯色顶条 |
| `::: imgrow` + `- ![说明](图)` + `:::` | 多图并排（2-3 张，50%/33.3% 各带 8px 间隙） | 同左 | 同左 |
| `::: imgcard` + `- ![图](路径)` + `- 说明…` + `:::` | 图卡（图 + 底部说明条 13px） | 白卡+浅底注 | 白卡+浅底注 |
| `::: timeline` + `- 节点…` + `:::` | 时间线（竖线+圆点节点+序号） | 蓝线蓝点 | 橙线纯色点 |
| `::: band` + `- 文字…` + `:::` | 花纹色带（图案底+文字） | 蓝系 | 橙系 |
| `::: band 斜纹/波点/棋盘/条纹/圆环` | 花纹种类选择（默认斜纹） | 蓝系图案 | 橙系图案 |
| `::: frame` + `- 内容…` + `:::` | 复杂边框容器：纯色双层（宣传）/双线+角块（文字） | 蓝双线角块 | 纯色双层 |
| 配色 | **无内置主题**：排版语法模块用基础色渲染骨架，风格化配色须从《风格维度索引》对应风格条目读取色板，以模板 HTML 或内联样式显式落地 | — | — |
| `[[lace]]` | 花边分隔线（纯 CSS 线+菱形，无字符图标） | 灰 | 橙 |
| `[[title:文字\|box]]` | 标题风格-box：纯色边框（宣传）/实线框（文字） | 实线框 | 纯色框 |
| `[[title:文字\|vine]]` | 标题风格-vine：藤蔓花枝图案边框（art://vine-frame） | 藤蔓 | 藤蔓 |
| `![说明](art://名称)` | 美术资产图片（sprig-grass/vine-frame/blossom-branch/leaf-corner/vine-divider/flower-band/bird-line/paper-frame） | 需先在面板上传图片后再插入 | 同左 |
| `![说明](本地路径)` | 本地图片 | 发布时自动上传 | 同左 |
| `**粗**` / `*斜*` / `` `代码` `` / `[链接](url)` | 行内 | 常规 | 常规 |
| 列表 / 表格 / ` ``` ` 代码块 | 块 | 常规 | 常规 |

> v10 铁律：零 emoji/零图标字符、零渐变（配色）、零阴影；band 花纹的 repeating-gradient 属图案纹理允许；图案装饰走 art:// 植物资产。

## 内联规则

- 段落自动合并连续行；块之间空一行。
- 表格在微信中显示支持有限，建议截图转图片后再插入。
- 未上传的 `art://` 图片不会显示，请先完成上传。

## 常用组合示例

### 宣传类

```markdown
# 夏日狂欢大促

[[banner:全场五折起|仅限 7 天]]

## 活动亮点

> [!KEY] 限时抢购
> 爆款直降 50%

::: steps
- 点击小程序卡片
- 领取优惠券
- 下单立享五折
:::

~~~ 

[[badge:爆款]] 数量有限，售完即止
```

### 文字类

```markdown
# 高效阅读的三个方法

## 方法一：带着问题读

开始前先写下一个问题，读书就有了方向。

> [!TIP] 三遍阅读法
> 第一遍翻目录，第二遍精读，第三遍只看笔记

::: card 输出方法
读完一章，用 3 句话复述给朋友听。
:::

==金句==：阅读是一座随身携带的避难所。
```

## 间距规范速查（已内置，粘贴外部模板时自行遵守）

块距 16px · 行高 1.75 · 气泡内边距 14px 16px · 标题上 28px 下 12px · 分割线 24px · 图片上下 12px · 卡片内文 14px 16px 12px。
