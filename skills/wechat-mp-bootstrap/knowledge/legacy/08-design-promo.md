# 08 · 宣传类设计规范（素材美观、配色生动、层次分明不凌乱）

> 适用：活动、促销、新品发布、品牌推广、周年庆。原则：**生动而有秩序**——主色 ≤3、渐变只给焦点、统一圆角与留白。

## 色板（固定三主色，可微调饱和度但不得增加色相）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 1 橙 | `#ff6b35` | 焦点：KEY 气泡/徽章/序号/表头 |
| 主色 2 青 | `#00b8a9` | 次焦点：TIP 气泡/点缀 |
| 主色 3 紫 | `#7a3cec` | 横幅/大标题装饰 |
| 辅助 琥珀 | `#ffb020` / `#ffd166` | 渐变过渡/高亮 `#ffe08a` |
| 辅助 粉 | `#ff6b9d` | 横幅渐变第二色 |
| 墨色标题 | `#2b2433` | 标题 |
| 正文 | `#4a4150` | 正文 |
| 浅底 | `#fff3ea` | 卡片底/引用底 |
| 边框 | `#ffd9c2` | 描边 |

## "生动不凌乱"三纪律

1. **主色 ≤3**：一篇推文只允许橙/青/紫三色出现（琥珀/粉仅作渐变过渡），正文一律 `#4a4150`。
2. **渐变只给焦点**：横幅、KEY/TIP 气泡、徽章、卡片顶部条、h2 序号块可用渐变；段落文字、列表、普通内容禁用渐变背景。
3. **统一节奏**：圆角统一 12-14px（气泡 14px、卡片 12px）；块间距 16px；装饰圆（半透明白）只出现在气泡/横幅角落，不铺满正文。

## 排版规范（间距规范同《排版语法全表》）

- h1：22px 居中 + 琥珀荧光下划线（`background:linear-gradient(180deg,transparent 60%,#ffe08a 60%)`）。
- h2：渐变序号块（橙→琥珀）自动编号 + 墨色标题 20px；上 28px 下 12px。
- h3：紫字 + 橙左竖条。
- 列表用 ▸ 橙箭头（自动生成）；步骤用渐变数字圆。
- 分割线：`~~~` 三层丝带 / `___` ✦ 渐变线 / `***` 三彩点（按章节氛围选一，全篇统一 ≤2 种）。

## 常见错误（返工项）

- 主色超过 3 个色相（如另加绿色/蓝色）→ 乱。
- 正文用彩色文字 → 阅读负担；正文永远 `#4a4150`。
- 渐变背景块连着出现 → 焦点失效；渐变块之间至少隔一个白底块。
- 装饰圆/星星铺满 → 只允许 2-3 处角落装饰。
