# 10 · 内容策略：标题 / 结构 / 文风

> 来源：公众号爆款内容方法论。

## 标题公式（先给 2-3 个方案再定稿）

1. **数字清单**：数字 + 具体收益（"7 个让你效率翻倍的阅读习惯"）。
2. **悬念缺口**：制造信息差（"为什么你读了很多书却记不住？"）。
3. **利益直给**：用户身份 + 结果（"给打工人的 3 个下班充电法"）。
4. **情绪共鸣**：戳中痛点/爽点（"30 岁后，我戒掉了无效社交"）。
5. 禁忌：标题党（与内容不符）、夸张词滥用（"震惊/必看"）、超过 30 字。

## 结构（3 秒钩子 → 分层 → 行动号召）

- 开头 3 秒钩子：结论先行 / 痛点共鸣 / 悬念提问（选一，一段内完成）。
- 中段：小标题分层（2-4 个），每层一个核心观点 + 论据 + 例子；段落短小（≤4 行）。
- 结尾行动号召：在看 / 转发 / 留言 / 关注（选 1-2 个，明确动词）。

## 文风（去 AI 味清单）

- 口语化短句；避免：夸大象征、三段式排比、过度连接词、否定式排比、AI 高频词（"赋能""闭环""值得注意的是"）。
- 数字具体化（"省 20 分钟"优于"节省时间"）。
- 重点用 `**加粗**` 或 `==高亮==`，一屏不超过 2 处。

## 配图建议

- 封面：2.35:1 大图 + 1:1 方图，主体居中、留边安全区。
- 正文：每 400-600 字一张图；图表/截图优先；手机阅读宽度 677px。
- 无图可用时用美术资产（wave-divider 等）做呼吸感，见使用指南的「美术资产」章节。
