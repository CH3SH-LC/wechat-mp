# 09 · 微信平台事实 / 限制 / 错误码

> 违反即失败。来源：微信公众平台官方文档与实操经验。

## 正文 HTML 限制

- <20000 字符、<1MB；会去除 JS。
- 只保留内联样式（无 `<style>`/`<script>`/外链字体/伪元素）。
- 图片 src 必须来自 `uploadimg` 接口（仅 jpg/png ≤1MB），外部图片 URL 被过滤。
- **SVG 策略**：正文内联 SVG 无官方承诺、编辑器粘贴会丢 → SVG 一律客户端渲染为 PNG 经 uploadimg 上传，以图片插入。
- 表格支持有限（建议截图转图）。

## 接口权限

| 接口 | 权限 |
|---|---|
| token / uploadimg / add_material | 公众号 + 服务号（需开发者模式 + IP 白名单） |
| draft/add（草稿箱） | 公众号 + 服务号均可 |
| freepublish/submit（发布） | 仅认证账号 |
| mass/sendall（群发） | 仅认证账号，且需管理员确认（89505） |

- 发布是异步任务（PUBLISHJOBFINISH 事件）；系统会自动查询状态（每 3 秒一次，最长等待 120 秒）。
- 摘要 ≤120 字；不填默认取正文前 54 字（务必手填）。
- 封面必须为永久素材 media_id（add_material，≤10MB，jpg/png/gif/bmp）；2.35:1 + 1:1 双比例。

## 错误码速查

| 码 | 含义 |
|---|---|
| 40001 | 无效 access_token（重新获取/检查凭据） |
| 40013 | 无效 appid |
| 48001 | 接口未授权（账号类型/认证不足） |
| 53503 | 草稿未通过发布检查 |
| 53504 | 需前往公众平台官网使用草稿 |
| 40009 | 图片太大 |
| 89505 | 群发需管理员确认 |

## 排版硬规则（与间距规范并列）

字号 15-16px · 行高 1.75 · 段距 16px · 段首不缩进 · 摘要=第二标题 · 不标题党。
