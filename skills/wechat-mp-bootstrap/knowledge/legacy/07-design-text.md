# 07 · 文字类设计规范（简洁明确、视觉清晰）

> 适用：资讯、干货教程、随笔、公告、行业观点。原则：**内容为主，装饰为辅**。

## 色板（固定，不要自创）

| 角色 | 色值 |
|---|---|
| 强调色（唯一） | `#2f6fed` 蓝 |
| 强调深色 | `#1f4fc4` |
| 标题色 | `#1f2d3d` 墨色 |
| 正文色 | `#3f3f3f` |
| 次要文字 | `#8a94a6` |
| 浅底/引用底 | `#f7f9fc` |
| 边框 | `#e3e8ef` |
| 语义：技巧 | 绿 `#0e9f6e` / 底 `#ecfaf3` |
| 语义：注意 | 琥珀 `#b26a00` / 底 `#fff7e6` |
| 语义：警示 | 红 `#c0392b` / 底 `#fdeeee` |
| 高亮 | `#fff3c4` |

## 排版规范（间距规范）

- 正文 16px / 行高 1.75 / 段距 16px / 字距 0.5px / 段首不缩进。
- 标题：h1 22px、h2 20px、h3 18px；h1/h2 左侧 4px 强调色竖条 + 左 padding 10px；上 28px 下 12px。
- 引用：左竖条 + 浅底；气泡/卡片/步骤/分割线/图片间距按《排版语法全表》。
- 全篇强调色只用 `#2f6fed` 一处；语义色仅用于对应语义块。

## 设计纪律

1. 装饰元件 ≤3 类（如：竖条标题 + 浅底引用 + 圆点分割线），不堆叠渐变/阴影。
2. 配色对比：正文 #3f3f3f 与白底对比度足够；不用浅色小字（≥13px 才允许 #8a94a6）。
3. 层次靠字号与留白，不靠颜色数量。
4. 图片：圆角 8px、上下 12px；长图可全宽。
5. 表格尽量少用（微信支持有限），数据多时建议转图。

## 常见错误（返工项）

- 用了多个强调色（红、绿、蓝同时出现）→ 文字类只保留一个强调色。
- 正文用彩色文字 → 正文永远 `#3f3f3f`，彩色只给标题与语义块。
- 装饰过度（渐变块、阴影卡堆叠）→ 文字类靠留白与字号分层。
- 浅色小字（<13px 的 #8a94a6）→ 无法阅读，放大或加深。
- 标题间距不统一 → 一律上 28px 下 12px。
