# 发布与分发维度索引（index-publish）

> 定位：解决「写好的推文怎么发出去、发到哪」。发布流程、定时时段、多平台同步、转载与原创管理。
> 用法：首次发布读 pub-workflow；选推送时间读 pub-timing；一稿多发读 pub-platform；涉及转载/白名单读 pub-reprint；原创/合集读 pub-original。
> 交叉：平台接口与错误码事实见 legacy/09；正文限制见 legacy/09 与 00-GUIDE 间距规范。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| pub-workflow.md | 发布流程：草稿→审核→定时/群发→发布确认的完整链路 | 首次发布或流程不熟时 |
| pub-timing.md | 最佳时段：各类型内容的推送时间规律与账号实测方法 | 选推送时间时 |
| pub-platform.md | 多平台同步：公众号/头条/知乎/小红书/百家号的差异与适配 | 一稿多发时 |
| pub-reprint.md | 转载与开白：转载规则、白名单、授权流程 | 转载他人或被转载时 |
| pub-original.md | 原创声明与合集：原创标记、合集归集、话题标签设置 | 发布设置时 |

## 使用顺序

发布前：pub-original（设置）→ pub-timing（时间）→ pub-workflow（流程）；多发：pub-platform；转载相关：pub-reprint。
