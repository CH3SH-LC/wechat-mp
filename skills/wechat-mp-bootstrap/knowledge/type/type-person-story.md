# 人物故事

> 定位：写一个人/一群人的真实经历，靠具体细节和转折让读者"看见"这个人，而不是听你夸他。
> 调用时机：人物专访、人物小传、告别文、"XX 人的一天"、写创始人/员工/老师/粉丝/同事。凡是"写的是一个人做了什么、怎么走到今天"的稿子，都是这一型。

## 一、类型定义与特征（详细）

**1. 先分清"人物介绍"和"人物故事"**

- 人物介绍在罗列信息：姓名、职务、获奖、荣誉，像档案表。读者看完记住的只有"他很厉害"，无感。
- 人物故事在还原过程：他遇到什么事、做了什么选择、卡在哪个坎、跨过去时是什么画面。读者看完会"代入他"。
- 一句话判断：你在给读者"看简历"，还是"看他的一段人生"？后者才是人物故事。
- 人物介绍记录"他是谁"，人物故事讲述"他怎么成为他"；一个是结果，一个是过程，读者想看的是过程。

**2. 三个核心特征**

特征一：特征是"发生出来的"，不是被贴上去的。

- 你写"他很有韧性"，读者只是点头；你写"他高考落榜后把错题本改了六遍"，韧性自己站出来了。
- 全文的目标，是把所有"形容词"翻译成"发生了什么事"。形容词是结论，故事是证据；读者信证据，不信结论。
- 常见误区：以为多用好词才够感人。正相反——词越多越假，事越具体越真。

特征二：必须有一个"坎"。

- 没有转折的人物故事叫"流水账"。这个坎可以是失败、犹豫、质疑、现实压力、自我怀疑。
- 它是全文的支点：读者替主人公悬着的那口气，就是从这里来的。
- 转折不必是惊天大事，一个深夜的纠结、一次坚持或放弃的选择都算。关键是"他发生了变化"。

特征三：结局不必是"成功逆袭"。

- 真实、可信比圆满重要。一个人没成事但明白了什么，同样成立——落点要从"他赢了"换成"他变了"。
- 给读者留下"一个变化 / 一个感受 / 一个念头"就够了。"他变了"型结尾常见三种落点：和自己和解了、想清楚一条道理、保住一件重要的东西。

**3. 适用场景确认**

- 你要写的人有一"段经历的先后变化"可以讲，哪怕只是"这周学会了一个新技能"。
- 如果对方只有一堆头衔、没有故事可讲，先采访把故事问出来再写，不要硬编。
- 人物故事的核心资源是"真实的经历细节"，素材不够就开不了工。
- 警惕"伪人物"素材：只有奖项照片、只有业绩数字、只有官方评语都不成故事；先转成"他为了这个奖熬了多久、那晚发生了什么"再写。

## 二、标准结构骨架（分阶段展开）

人物故事用五段式：**引入画面 → 背景 → 转折 → 细节 → 启示**。每段负责一个任务，后一段回答前一段留下的问题。

**阶段一：引入画面（第 1 段，1-3 行）**

- 用一个具体的瞬间开篇，让读者"眼前有画面"；不要写"今天介绍一位优秀班主任"，要写他此刻的一个动作。
- 好：办公室的灯关到一半，张老师又坐下来，把一张月考卷翻到反面。／差：他是我们学校最敬业的班主任。
- 画面感来自"动作 + 具体的事物"（灯、月考卷、反面），不是形容词。选"他正做一件与身份有反差的事"的瞬间，读者会好奇。

**阶段二：背景（2-3 段）**

- 补"他是谁、原本处什么状态"。用"状态"不用"标签"：好——在县城教了八年书／刚接手全校最乱的班；差——市优秀教师。
- "状态"有可进入的画面，读者能跟着往下走；"标签"只是盖章。
- 背景段还负责把读者拉到"他的起点"：起点越具体，后面转折的反差越大越有分量。

**阶段三：转折（全文最重，3-5 段）**

- 写那个"坎"——什么事件打破了他原来的状态，他的犹豫、挣扎、不得不做的选择。要有具体的时间、地点、对话、心理。
- 转折是全篇的推动力，篇幅可占全文 1/3 以上。成功的标志：读者在这里停下想"然后呢"。
- 小结构三环缺一不可：事情发生（时间地点）→ 他的反应（对话/动作/心理）→ 他做出的选择。
- 心理要用纠结具象化：写"那晚他翻来覆去，几次拿起手机又放下"，不写"他很纠结"。

**阶段四：细节（2-3 段）**

- 用两三个"特写镜头"撑起转折后的状态：他具体做了什么、重复了多少次、哪个小细节暴露了他的坚持或改变。
- 细节要"小"，越小越真——一句原话、一个习惯动作、一样随身物件都够。这段是人物的"血肉"。
- 选取标准：这个细节"只有他会有"吗？换个人也一样的没价值，只有他特有的才好用。

**阶段五：启示（1-2 段）**

- 把读者注意力从"他"拉回"我们"：这段经历对读者意味着什么。落点如"你也可以……""原来坚持是这个样子"。
- 一句话或一小段即可，避免喊口号。给两个方向，选一个：给一个"读者能带走的小改变"，或给一个"让人想再看一眼的干净收束"。

## 三、写作要点（配示例）

要点 1：用对话写人，不替人总结。

- 想看一个人"想给学生更好的生活"，别写心理活动，写一句他说出口的话，原话自带信息量和性格。
- 反例：他内心深处一直希望改善教室环境、把窗户换成能打开的，多年心愿。／正例：我就想着，等我教完这一届，也许能把教室窗户换成能打开的。
- 对话要"像这个人会说的"，别硬凹金句。写稿前把录音的关键句抄出来，挑"绕不开那句"的原话。

要点 2：用动作写状态。

- 描写情绪时让身体替你说话。反例：她非常紧张又忐忑地查看成绩。／正例：她把手机扣在桌上屏幕朝下，过了半分钟才翻过来看排名。
- 可参考的动作：手心出汗、反复看时间、声音变低、走路比平时快/慢、把水杯放得特别远——都能替代情绪形容词。

要点 3：用具体细节替代形容词堆砌。

- "认真""执着""温暖"这类词要逐个过一遍，问自己：他做了什么让我知道他认真？把那个动作写出来。
- 反例：他批改作业非常认真仔细、一丝不苟。／正例：他批改从不用红笔，用铅笔，这样学生拿到卷面还能再订正一遍。一个"用铅笔"的细节胜过十个"认真"。
- 自查法：把全文形容词圈出来，逐个问"读者能凭这个词画出画面吗"，画不出就补一个细节。

要点 4：转折要"具体到一件事"。

- 不要写"后来他遇到很多困难"，要写哪一件事成了转折点，时间地点越实越好。
- 反例：创业路上困难重重，但她咬牙坚持了下来。／正例：资金断裂那天，她退掉出租屋，搬进办公室的沙发上睡了一周。
- "哪一天、在哪儿、发生了什么"，哪怕一句带过，可信度就上一个台阶。

要点 5：保留一点"不完美"。

- 敢写他的犹豫、退缩、甚至一次没做好，人物才可信，全程高光反而假。读者能在"他也会犹豫"里看到自己才被打动。
- 程度：不完美是"一点"不是"一坨"——写一次犹豫、一句抱怨就够，别把他写成"又怂又没能力"。

要点 6：让读者"看见"而不只"知道"。

- 多用"看得到的画面 + 听得到的原话"，少用"我知道他很努力"这种间接转述。把心理状态外化成读者能观察到的表现。
- 验证法：把稿子读给不认识主人公的陌生人听，问"你脑子里有没有画面"，有画面就对了。

## 四、风格与模块建议

风格优先考虑四类，按情感浓度和正式度挑：

1. 日系风——想给读者温柔、治愈、慢一拍的感觉时用，适合生活方式、教育、温情向。
2. 手账风——写亲子、朋友、生活化人物，带日记体和陪伴感，翻起来像私人日记。
3. 杂志编辑风——想做有编辑感、大字号、有态度的专访时用，人物显分量。
4. 极简风——账号偏硬朗或企业向时用，压住情感浓度，让克制感说话。

模块上搭配使用：

- 开头钩子模块：承接"引入画面"，把那个瞬间立在最前。
- 引言金句模块：提炼主人公一句最有分量的话，放背景段或结尾。
- 气泡模块：承载对话，让"有人在说话"从排版上立起来。
- 图片模块：放主人公真实照片或场景照，增强真实感（人物故事尤其靠这个）。
- 行动号召模块：结尾引导"点赞 / 在看 / 留言他"。

注意事项：全文只出现 1-2 处高亮或加粗（主人公那句话、启示句）；别把情绪标点用满（"！！！""~~~"），克制比用力更有力量；对话用引号且独立成段。

## 五、常见错误（反例 + 正解）

错误 1：人物介绍当故事写。

- 反例：他是区优秀教师，多次获得教学比赛一等奖，深受学生喜爱。
- 正解：把获奖背后的事写出来——为了那节课怎么熬夜改课件、推翻了几版。
- 判断：一串"是…是…是…"的简历句，都换成"为了…他…"的过程句。

错误 2：形容词堆砌，没有画面。

- 反例：她是个坚韧、乐观、富有爱心的人。／正解：她连续三年给班里留守儿童过生日。
- 判断："温暖、坚持、优秀"超过两三个就逐个换成画面。

错误 3：转折浮在空中。

- 反例：创业路上困难重重，但她咬牙坚持了下来。／正解：资金断裂那天她退掉出租屋，住在办公室沙发上。
- 判断：转折段有没有"哪一天、在哪、发生了什么"？没有就是浮在空中。

错误 4：结尾喊口号。

- 反例：让我们向伟大的 XX 学习，他的精神永远激励我们！／正解：落到读者的小事——"你也可以从今晚给父母打个电话开始。"
- 判断：结尾在"呼吁大家"就喊口号了；要落在"读者自己能做的一件事"。

错误 5：全程高光、失真。

- 反例：他从没动摇过，从不抱怨，默默付出了一切。／正解：承认他摇摆过、抱怨过一两次，最后又站起来。
- 判断：一个毫无缺点的人，读者只会觉得是编的。

错误 6：全篇"听说 / 据说"。

- 反例：我听说他从小就特别努力，据说连续几年没请过假。／正解：用采访一手细节——他办公室挂着一张 2019 年考勤表，下面用铅笔写着"全勤"。
- 判断：把"听说 / 据说 / 大家都说"圈出来，逐个补成"我看到 / 他亲口讲"。

## 六、示例骨架（可套用大纲）

"人物故事 · 手账风"骨架，可填空套用：

- 标题：这个班主任，三年来只做对了一件事
- 引入画面：晚自习下课后，老赵没有回办公室，而是坐在最后一排，把卷子摊开。
- 背景：老赵带的是全校成绩最差的一个班，被叫"放牛班"三年。他教数学，板书总写得很慢。
- 转折：高二期中班里垫底，年级主任暗示"别太较真"。当晚他失眠。转折点是第二天，一个辍学两周的学生回来拿东西，他拉住对方说了十分钟。
- 细节：他每天提前二十分钟把错题重抄上黑板；谁请假他拍照发笔记；寒假布置"每日一题"逐条批改，三年没断过。
- 启示：老赵没带出清北生，但让这个班 92% 的人读完了高中。落点句："成长不是轰轰烈烈的逆袭，是一个人对一群人不放手。"
- 结尾：问一句"你遇到过这样的老师吗？"引导留言。

套用时可替换：把"班主任 / 放牛班"换成你的人物与处境；把"高二期中 / 辍学学生"换成真实转折事件；把"每日一题 / 提前二十分钟"换成他真实的日常动作；把"92%"换成具体数字；把互动问题换成贴着你读者的问法。

另一版更偏"平凡日常"的变体（无大事件，靠细节撑）：

- 引入：她每天 6 点 40 分准时开门，钥匙插进锁孔要压一下才开。／背景：开了十二年包子铺，周围店换了一茬又一茬。／转折：有一年房租涨三成，她想关门，最后咬咬牙续租。
- 细节：她记得每个熟客的忌口，谁不要葱、谁豆浆少糖，不用问直接做好。／启示：平凡日子里有人把它过成了仪式，这本身就是不平凡。
- 说明：人物故事不必非有大事件，"日复一日的细节"照样撑得起一篇。

## 七、个性化空间（按账号自定，附判断依据）

1. 篇幅松紧：专访型可写 1500-2500 字铺足细节；生活号压缩到 800 字内只留"背景→转折→启示"。判断：读者看"一个人"还是"一件事"——看人铺得足，看事收得紧。
2. 口吻亲疏：亲子号可第一人称"我"；企业号多第三人称。判断：人物和读者关系越近越可用第一人称，远则第三人称更客观。
3. 启示浓度：教育 / 成长号把启示写明显；品牌号要克制点到价值观。判断：账号调性是"给方法"还是"给情绪"——给方法少升华，给情绪可抒情。
4. 结构松紧：人物曲折可把转折拆成"小转折 → 大转折"；人物平凡把重心移到"细节"段。判断：有没有足够强的后段事件——强则重转折，弱则重细节。
5. 情感浓度：可往深情 / 治愈写满，也可往克制 / 冷静收敛。判断：读者来"被治愈"还是"看真实"——治愈往浓写，看真实往淡写。
6. 素材来源交代：人物真事的企业 / 专访交代"细节从哪来"更严谨；纯文学化随笔可淡化来源。
