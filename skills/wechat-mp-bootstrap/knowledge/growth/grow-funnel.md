# 导流路径（grow-funnel）

> 定位：把已经关注你的读者和潜在读者，引导到"更深一层"的阵地——从单篇到公众号本身、再到社群/个人号/私域、再到视频号与其他平台。导流是做"转化漏斗"：一步一步把陌生人变成铁杆。
> 调用时机：想系统搭建"从内容到转化"的路径时；想把公众号读者沉淀进私域/社群时；想打通公众号与视频号多平台时；发现"读者只看了这篇就走、没留下任何路径"时。

## 一、核心方法

### 步骤 1：公众号内的导流点——菜单、自动回复、文末、名片

先把"免费、第一层"的公众号内导流点用起来：

| 导流点 | 怎么做 | 作用 |
|---|---|---|
| 菜单栏 | 把"核心内容/合集/引流入口"放进账号自定义菜单 | 把感兴趣读者引到最重要内容/入口 |
| 自动回复 | 关键词自动回复（如"资料""入群""合集"），把想要的人引到对应资源 | 低成本承接，把"有明确诉求"的读者精准分流 |
| 文末引导 | 每篇结尾放导流动作（关注/合集/关键词/下期），配合固定元素 | 把单篇读者引向"继续关注"或"进下一步" |
| 名片/关注入口 | 用好默认的关注、名片转发，配合首屏关注条（见 module-followbar） | 把路人转关注 |

> 原则：**公众号内导流点是最低门槛、最高性价比的"漏斗第一层"。** 先把"关注/合集/关键词"这些做对，再谈向公众号外（私域/平台）导流。

### 步骤 2：向私域导流——社群、个人号的正确做法与平台限制

私域（社群、个人号）是更高黏性的一层，但受平台规则约束，必须"巧引导、勿硬导"：

- **社群导流**：在文末/关键词放"进群方式"，前提是群里有持续价值（资料、答疑、专属）而非纯广告。注意：强制"必须加客服才能领资料"要合规，别踩诱导。
- **个人号导流**：把"产品/课程/咨询/资料包"承接在个人号，读者有更深诉求时引过去；用"一句话利益点"（见步骤 5）说明为什么值得加。
- **平台限制（以官方规则为准）**：微信对"诱导添加个人微信/强制加群/外链跳转"有限制，文案勿用"必须关注+加微信才给你""点链接跳某网页"等诱导强导。导流要"提供价值→自然愿意过去"，而不是"设置障碍逼你过去"。

> 一句心法：**私域导流是"顺水推舟"不是"强拉硬拽"。** 读者本来就有更深诉求，你用价值承接，他自然愿意加；用规则逼，则踩红线又遭反感。

### 步骤 3：视频号互推——公众号与视频号打通

公众号和视频号的账号互通（同一主体/绑定后），可以做双向导流：

- **公众号→视频号**：文内/文末放视频号同一主题的短视频，评论区/内容里引导"进视频号看完整版/直播"，把深阅读读者引向动态内容。
- **视频号→公众号**：视频号内容中引导"完整图文见公众号"，把被短视频吸引的人引到公众号沉淀。
- **互推做法**：同主题在两端各做一版（图文 vs 视频），互相留口;也可以是"预告/延伸"型互洽。
- 微信对公众号与视频号关联互导的入口与规则，以官方后台当前设置与最新规则为准。

### 步骤 4：多平台互相导流——微信生态内外

- **微信生态内**：公众号、视频号、小程序、企业微信可以在合规前提下做联动（如同一资料的多个承接位）。
- **微信生态外**（其他平台）：在各平台简介/内容里留"微信公众号/视频号"的统一入口，把外部流量向公众号聚拢;同时公众号也可做"外部渠道的延伸引导"。
- 注意跨平台规则差异：各平台对外链、导流有自己的规范，到哪个平台遵守哪个平台的规则，别用微信内规则套到别处，或反着来。

> 原则：**导流是"多点聚合、内容一致"**——各平台放同一个"公众号/私域入口"，别让读者在每个平台认识的是"不同的你"。

### 步骤 5：导流文案的写法——一句话利益点

导流文案的关键，是给读者一个"为什么现在就该过去"的一句话理由。套这个模板：

> 「想[得到什么]吗？→ [去这里]，因为[给你一个具体好处]。」

**示例：**
- 进群："想每周收到 3 个可直接用的职场模板？进「职场资料群」，每周四更新。"（一句话利益点：每周实用模板）
- 加个人号："想让我帮你看一眼你的简历？加我微信，发你一份修改版。"（一句话利益点：最想要的诊断）
- 关注："想持续看这类 30 分钟快手菜？点关注，每周四更，绝不断更。"（一句话利益点：稳定续更）

> 写好一句话利益点的标准：**读者一眼就知道"过去能得到什么、值不值"**。说不清能给什么好处，就别放那个导流点。

### 步骤 6：导流效果追踪

导流不是放了就完，要能衡量"从哪来、有没有效果"：

- **用关键词/专属引导区分来源**：不同导流点给不同关键词或不同的领取口令，看哪个入口带来的关注/加群最多。
- **看数据漏斗**：单篇阅读 → 关注 → 进群/加个人号的各环节转化，找出"卡在哪一步"。
- **按入口复盘**：菜单/自动回复/文末/视频号互推各自贡献多少新关注 / 私域新增，砍掉无效口、优化高效口。
- 数据口径以公众号后台实际可看指标为准（关注来源、关键词回复数、菜单点击等），公众号外的私域数据在各自后台看。

## 二、可操作工具

**工具 1：导流点铺设清单（先检查公众号内这四块）**

```
□ 菜单栏：是否有"核心内容/合集/导流入口"三项及以上
□ 自动回复：是否设了关键词回复（资料/入群/合集），有对应资源承接
□ 文末引导：每篇是否放了"关注/合集/关键词/下一步"
□ 名片/关注入口：首屏关注条与默认关注是否利用到位
```

**工具 2：私域导流文案模板**

```
进群："想[得到什么]？进[群名]，因为[具体好处]。"
加个人号："想[得到什么]？加我微信，因为[具体好处/我能帮你]。"
关注："想[持续得到什么]？点关注，因为[稳定承诺]。"
（写出来前自查：好处是否具体？值不值？是否含"诱导/强制"措辞？）
```

**工具 3：导流漏斗追踪表**

```
来源（菜单/自动回复/文末/视频号/外部）：____
单篇阅读：____ → 关注新增：____ → 私域新增（群/个人号）：____
各环节转化率：____   卡点环节：____
本月调整：____（砍掉/优化哪个入口）
```

**工具 4：合规自查（导流动作发布前）**

- [ ] 文案无"强制必须关注/加微信才能 X"式诱导措辞
- [ ] 无违规外链跳转 / 违禁导流
- [ ] 各平台遵守各自导流规则
- [ ] 私域/群里有真实持续价值，非纯广告
- [ ] 已按微信官方当前规则与最新产品功能核对

## 三、示例（虚构账号）

**示例 1：「妈妈厨房周记」的导流链路（虚构）**

- 公众号内：菜单放「快手菜合集」「进菜谱群」;自动回复设关键词"资料"回一份「30 分钟备菜表」。
- 文末引导："想每周多几道 30 分钟上桌的菜？点关注，每周四更，绝不断更。"（一句话利益点：稳定续更）
- 私域：文末/关键词给"进菜谱群"，群每周发 3 份快手菜清单 + 答疑;文案"想每周收 3 份快手菜清单？进「妈妈菜谱群」，每周四更新。"
- 视频号互推：同一个快手菜做成短视频，视频号说"完整图文步骤见公众号「妈妈厨房周记」"。

**示例 2：「Echo 的职场说明书」的导流链路（虚构）**

- 公众号内：菜单放「周会工具箱合集」「一对一答疑」;自动回复"话术"回「5 个汇报话术模板」。
- 私域：设个人号承接一对一诊断/课件领取，"想让我帮你看一眼汇报要改哪？加我微信，发你一份调整思路。"（一句话利益点：最想要的诊断）
- 视频号：录 1 分钟讲一个汇报技巧，"想看完整案例拆解进公众号本周三的「周会工具箱」"。
- 追踪：用不同关键词区分"资料"（公众号内）、"简历"（个人号一对一）来源，复盘哪个入口带来的私域粉更对味。

## 四、常见错误

- **错误 1：只做内容不做导流，读者看完就走、没留下路径。**
  反例：文章很好，但没菜单入口、没文末引导、没合集，读者看完就散。
  正解：先把公众号内的导流点铺齐（菜单/自动回复/文末），把单篇流量沉淀成关注与私域。
- **错误 2：用"强制必须加才能领"式诱导导流，踩红线又遭反感。**
  反例："必须关注并加微信号，否则不算参与/不给资料"——强制诱导、惹反感且可能违反平台规范。
  正解：提供价值→自然引导，"想得资料进群"而非"不关注就不给"，并核对平台导流规则。
- **错误 3：导流文案没有具体利益点，只说"欢迎关注我们"。**
  反例："感谢阅读，欢迎关注我们的公众号，了解更多内容。"——没有"为什么现在关注"的理由。
  正解：给一句话利益点（"想每周收 3 份模板？点关注周更"），读者一眼知价值。
- **错误 4：私域里除了广告就是发奖，没有持续价值。**
  反例：读者加群后天天收到打折促销，没有真正内容/答疑，粉很快流失。
  正解：私域里给真实价值（资料、答疑、专属），让加进来的人愿意留下。
- **错误 5：导流不做追踪，不知道哪个入口有效。**
  反例：同时放了菜单/文末/视频号一堆入口，从不看数据，无法取舍。
  正解：用关键词/口令区分来源，按入口复盘砍无效口、优化高效口（工具 3）。

## 五、个性化空间

- **导流的深浅**：判断依据是账号诉求与粉丝规模——只做品牌/科普的号轻导流（到关注即可）；有产品/课程/咨询的号要深导流（到私域/个人号）。看你要"结个果"还是"做转化"。
- **主阵地是社群还是个人号**：判断依据是承接形态——高频答疑/资料群用社群；一对一咨询/高客单用个人号。按"你要提供的是群发价值还是一对一价值"来选。
- **是否做视频号互推**：判断依据是内容形态与人力——你本身有短视频产能就做双向互推；只有图文就别硬凑视频，先把公众号内漏斗做扎实。看你有多少精力能稳定做。
- **多平台铺开的范围**：判断依据是账号阶段——起步期先聚焦公众号+1 个外部口；成熟期再铺多平台，且各平台放同一个统一入口。避免"哪里都占、哪里都浅"。
