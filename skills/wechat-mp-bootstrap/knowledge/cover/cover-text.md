# 封面文字排版（cover-text）

> 定位：解决「封面压字」的全部细节——字号、位置、对比度、字数上限、字体选择、文字与主体的位置关系、深浅底色上的配色规则。封面要写字时读它。
> 调用时机：封面确定要压字（把标题关键词做进图里）时必读；也作为 cover-spec 封面图规范、cover-consistency 一致性 的配套条目跳读。

## 一、核心规范

封面压字有七条硬规则：字号、位置、对比度、字数上限、字体、与主体的位置关系、深浅底色配色。逐条拆开，全是能直接照抄的数值。先记住一句话总纲：**封面字要「粗、大、纯色、强对比、少而清」，一切细节都围绕这五个词展开。** 这一部分写得最细，因为你真正要动笔时，90% 的决策都来自这里。

**先补一层认知：为什么要压字（而不是全靠系统标题）**：读者面对信息流里的封面，每张停留常常只有零点几秒；系统标题虽会叠加，但字体位置都不可控，且在很小的缩略尺寸里，读者往往先看图再看字。压上去的大字是给封面「贴上一个钩子」，让读者在扫过的瞬间被那个关键词单独拽住——**压字不是把标题抄一遍，而是给封面加一个比系统标题更醒目、更聚焦的心锚**（这套「图内大字一眼看懂、系统标题负责完整句」的分工详见 cover-spec）。

### 1. 字号：大字有多大

封面压字最核心的问题就是「字要够大」。手机订阅号列表会把封面缩到约 1/5 大小，所以字号小了等于没写——这是无数人第一次做封面都会踩的坑，先把它钉死在前面。

**主标题（主卖点关键词）**：建议 **60–100px**（以 900px 宽画布为基准）。这是画面里最该被看到的一句话，字号往大里走，宁大勿小。别舍不得放大，缩略之后它没有你想的那么大。

**副字（栏目名 / 期数 / 金句）**：做主标题的 **1/2 到 1/3**，约 **28–40px**。副字是衬托，大小要和主标题拉开明显差别，受众一眼分得出「哪个是重点」。

为什么强调 60px 起：订阅号列表把封面压缩到 1/5 尺寸时，字号低于 40px 的字基本退化成一条淡淡的线。可以说，「字够大」比「字好看」重要得多，这是整个封面排版的**第一优先级**，先于一切审美判断。

衡量标准要可执行：把封面缩小到手机列表宽度（约 1/5 尺寸），能一眼认出主标题在说什么，这字号就对；认不出就继续加大，直到「扫一眼就懂」为止。这个测试如果用电脑就把窗口缩窄，或者直接手机预览，效果最真实。

再看字号和行数的关系：一个字能讲清就用一行，讲不清拆两行，最多两到三行。绝不因为「字多」把字号往下压——正确思路恰好相反，**「字少了，才能大」**。宁可删字，不要缩字，这条在字数上限里还会再强调。

**什么情况下可以放松字号**：如果封面走「氛围大片」路线（主体不是文字而是视觉画面，比如宣传片风格、高端品牌感），可以允许主标题降到一个"点缀"尺寸或干脆不放字。但这属于"反常规"路线，前提是你的封面画面本身有足够强烈、不依赖文字来表达吸引力；否则对绝大多数账号，放大的字仍是安全且有效的默认。

### 2. 位置：放哪里最稳

文字位置决定了它会不会被裁、被叠、被忽略，是仅次于字号的第二条生命线。位置错了，再大的字也可能白搭。

**主标题优先放中上部或正中，靠上 1/3 处**：这是读者读图时视线最先落下的位置，也是最不容易被微信其他界面元素挤压的位置，天然安全。

**千万不要放的位置**：画面正底部、左右边缘、四角。底部中央是「系统叠加标题」最容易跑来的区域（机制见 cover-spec 第 4 节），边缘和四角则是最容易被缩略裁掉的地方。凡是「边界」和「底边」，都尽量远离。

文字整体要落在 cover-spec 所说的 **≥8% 安全区以内**，不贴边、不顶头、不压角。安全区是给「不同设备、不同取景」兜底的，文字一旦越界，就没人敢保证它在某个手机上还完整。

排布建议：一行能放下就一行，两行为宜；不要排成四五行的细小文字。四五行小字缩略后像一群蚂蚁，既难看又难读，信息层级也整个糊掉。

一句话记忆：**文字优先往上、往中放；往下放要非常谨慎。** 如果实在要往下放，也要放在安全区的下半部分，且对应区域不要是叠字高发区。

位置判断给一个可操作的办法：把封面缩到最小能看清的状态，看文字是否仍在明显、完整、不被遮。「一缩就消失」或「一缩就被挡」的，说明位置或对比度有问题，需要回炉。

**和底部安全的关系补充**：底部中央是最容易「中招」的位置，所以在 cover-spec 里我们反复强调「字不要压底部中央」。如果你实在想把字放在画面下半部（比如给上部留大片的视觉画面），那请保证 1 这部分不落进底部 8% 安全区外的越界区，2 做好被系统标题遮挡的预案（少放满行字、留出余量）。默认仍建议「中上部最省心」。

**不同内容放哪个位置的常见习惯**（供快速参考）：

| 位置 | 适合放什么 | 原因 |
|---|---|---|
| 中上部偏上 | 主标题、品牌 slogan | 视线最先落、最安全 |
| 中央偏下 | 副字、期数、金句 | 与主标题形成上下层级 |
| 四角 | 角落 logo、水印 | 属于「环境信息」不抢戏 |
| 正底部中央 | 尽量避免 | 系统标题叠加高发区 |
| 左右边缘内 | 竖排小字（少用） | 容易在缩略时被裁 |

这组习惯不是死规矩，但它帮你快速定位「哪类信息放哪」，减少每次从零决策的时间。真正拿不准的例外，再回到「安全区 + 避底部 + 避边缘」这三条底线上去判断。

### 3. 对比度：文字必须「压得住」背景

对比度是压字的**第一生命线**，专门解决「字在图上看不清」这个头号痛点。它在七条里优先级最高——字形还可以商量，看不清就是硬伤。

所谓对比度，就是文字和它背后那块底之间「明暗差」的大小：明暗差越大，字越清楚；明暗差越小，字越糊。这里的关键是**明暗（亮度）差，不是「颜色搭不搭」**。很多人以为「都是红色系所以搭」，结果两个红色的亮度几乎一样，字硬生生被底色吃掉——这是对「对比度」最常见的误解。

可量化的标准：文字颜色与背景底色在明暗上拉开明显差距——深底配白字、浅底配深字。尤其在影像背景上，要保证文字所在的那片底足够干净或足够暗，字才托得住。

如果背景是实景图，处理手法是：**先在压字区域铺一层半透明罩（黑或白），或把图整体压暗 20–40%，让放字的那块底层变干净，再打字。** 这是影压图里最常用、也最有效的一招，比一味的加粗、加亮更管用——底干净了，字自然就出来了。

补充一个小技巧：给文字加一条**细描边**，或干脆把字放亮字区留足底色明暗差，能再拉开文字边缘和底的分离感。但它是「锦上添花」，不能用来代替本来就该够的对比度——对比度本身足够，才算真正过关，描边永远只是辅助。

**对比度的检查顺序**：先检查「底色明暗」再检查「字色明暗」最后看「是否加了罩」。任何一步发现字和底亮度太近，都要回到前一步修正。不要跳过逻辑直接调透明度——调透明度会同时改变字色和它盖住的地方，容易顾此失彼。一个稳定的判断流程是：底色定了之后，先问「这块底是深还是浅」，再据此直接选「白字还是黑字」，90% 的情况这一步就解决了。

### 4. 字数上限：主标题 ≤10 字

图内文字的字数，直接决定可读性。数字给得越死，越不容易出错，所以直接给上限。

**主标题（主卖点关键词）控制在 ≤10 字**，最好落在 **4–8 字**。超过 10 字就浓缩，或拆成两行，或只放最关键的部分；完整意思交给系统标题去承载。

为什么限字数：图内字越少越大、越大越清晰；一句话塞满封面，只会让每个字都变小、可读性崩塌。把「一句话」和「几个扎心的字」放在一起比，前者在缩略后一定是后者赢。

副字 / 金句可以稍长（约 ≤15–20 字），但同样要控制在一两行内，且字号明显小于主标题。副字承担的是「补充语境」，不是「抢主标题的戏」。

这里要破除一个常见误区：很多人以为「封面字 = 把标题搬上去」。真实逻辑是——**封面字是把标题里「最扎心的那几个字」放大**。剩下的信息由系统标题 + 摘要 + 正文一步步补齐（这套分工再对照 cover-spec 第 4 节、cover-summary 摘要写法一起看，会更清楚）。

字数上限还能带来一个附加好处：字少了，封面就有了喘息和留白，反而比塞满显得更高级、更聚焦。「留白是高级感」在这件事上是成立的，而前提恰恰是「先把字删到够少」。

**什么时候可以超过 10 字**：招牌栏目名（如一个专有的栏目名）本身超过 10 字时，可放行一次；或者封面走「一句话宣言」风格、且那句话说得很短很押韵时（比如 12 字以内的金句），也可以适量放宽。除此之外一律按 ≤10 字执行——判断的关键是：这句放大后，缩略到列表还认不认得清、突不突出重点。

萃取封面大字的建议位置：通常取自标题里最「痛点 / 卖点 / 好奇点」的那一段，比如「为什么你读了很多书却记不住」里点题的是「读了很多书却记不住」，顺着「让读者最想点开的那几个字」去萃取，比机械截取前几个字有效得多（这个思路和标题写作同源，参考 copy 维度标题条目）。

### 5. 字体选择：系统字体即可，粗体优先

字体这条最省心——因为它几乎不需要你做什么专业操作。给运营者的结论可以先给：**别为字体纠结，直接上系统默认 + 粗体。**

不需要下载、不需要依赖任何特殊字体，直接用系统自带的中文字体、加粗即可。封面字追求的是「清晰可读」，不是「字体特别」；在缩略图这个场景里，任何花哨字体的加成都会被「看不清」抵消。

**粗体优先**：正文和标题的文字都优先选「粗体 / 重」字重。细体在缩略后容易「断线」、字笔画被吃掉，所以除非需要极简故意的细字（通常要在放大场景用），否则一律粗体更稳。

英文配中文时选统一字族，避免中西文字体风格打架；一张封面上不要堆 3 种以上字体——1 到 2 种就够，多则乱、乱则廉价。

一句话把这条钉死：**封面字体不追求「特别」，追求「清晰」。粗、大、纯色、强对比，就是好封面字。** 如果你的账号有既定的品牌字体，可以用它做出「品牌感」，但即便没有，系统默认字体也完全及格，绝不影响发布。

**字体兼容的一个提醒**：在封面上用非系统字体（比如手写体、艺术体）时，要注意「换到别人的手机上会不会显示成默认字体」。封面是做进图片里的，字体被「拍」进去了，所以不存在"对方手机没有这个字体就变样"的问题——这正是封面相对正文 html 的一个优势（正文里的自定义字体反而可能被过滤）。所以你可以更大胆地用一个有风格的字体，只要它和账号调性一致、且粗重到缩略后还清晰。

**字号与字重的一个提醒**：一条有用的经验是「宁可字重粗、也不要字多大」。同样信息量下，加粗能显著提升小尺寸下的辨识度，而一味放大到撑满画面反而让观感局促。所以当你纠结「再放大一点」还是「先加粗」——通常先加粗，问题常已解决大半。

### 6. 文字与主体元素的位置关系（避让安全区）

如果封面上还有非文字的主体元素（人物、产品、图标），文字和它们的位置关系要专门处理——「字和主体撞在一起」是继对比度之外最常见的观感翻车。

文字与主体**不要重叠打架**，两者要有独立的留白。重叠不是绝对的禁区，但如果叠得脏、叠得乱，观感会非常廉价。

常见的安全排法有两种：主体在画面中下方、主标题在主体上方的留白区；或者主体在左、文字在右，各自占一块，互不遮挡。优先用这两种里的任一种，就基本不会出错。

文字要避开「缩略后会被其他元素遮住」的位置；如果确实必须叠（比如画面就这么大），先判断是哪条路更合理——通常先把主体那块压暗，再把字放在暗区上，字反而更清楚。

量化的间距：文字边缘与画面四边保持 ≥8% 安全距；与主体元素之间、以及字与字之间，留 **≥15–20px** 的呼吸空隙。这个空隙不是随便留的，是为了缩略后「字和主体还能分清谁是重点」。

判断方法同样简单：把封面缩到最小能看清的状态，看文字和主体有没有「黏在一起」。黏在一起，说明空隙不够，需要再拉开，直到两者清晰可分。

**「谁更靠前」也值得想一下**：当文字和主体都必须出现时，通常让「主标题」因为承担卖点而更靠前、更大，主体元素作为辅助氛围。但如果你这篇的性质是「主角是产品或人物」（比如探店、明星、产品测评），则可以反过来让主体元素更突出，文字退到辅助位、且更小。这条没有唯一答案，判断依据一句话：**哪个更能帮读者立刻做出「点不点」的决定，就让它更醒目。**

判断「主体该大还是字该大」的中间方法：把封面做到一半，分别导出「主体醒目版」和「文字醒目版」两个版本，并排缩到手机列表宽度扫一眼，看哪个更容易让你在零点几秒内做出点击判断。让几个旁人盲选一次，得来的直觉往往最接近真实读者的反应。这条同理适用于 cover-spec 里的方图与大图比对。

### 7. 深浅底色上的文字配色规则

这是最容易被忽视、但最好记的一条——**按底色明暗，决定文字深浅**。底越深、字越浅；底越浅、字越深。整条就这一句话。

| 底色类型 | 文字颜色 | 典型搭配 |
|---|---|---|
| 深色底（深蓝 / 墨绿 / 黑 / 深灰） | 用**浅色 / 白色**字 | 深蓝纯色底 + 纯白大字 |
| 浅色底（白 / 米色 / 浅灰 / 大亮色） | 用**深色 / 黑色**字 | 白色底 + 深黑大字 |
| 中间亮度底 / 实景图 | 先把罩再归入上两类 | 半透明罩 + 白字或深字 |

**铁律：深底白字、浅底深字**，明确避开「浅底浅字」或「深底深字」这两种明暗相近的搭配。它们颜色可能「都很好看」，但亮度太近，字会直接化进底里。

如果你的账号有品牌色，可以让文字带一点品牌色，但前提是把明暗差拉开；拿不准时，「黑色或白色」永远最稳，永远不会出错。

实景图还给你一个傻瓜判断法：**拖一张灰色的蒙版盖在图片上，看文字被盖成灰之后，还能不能从底里「浮」出来**——能浮出来，说明深浅对比足够；浮不出来，说明字色和底色的亮度太接近，需要调整。这个办法不需要任何设计功底，人人都能做。

**常用字色组合速查**（直接可抄，作为底色问题兜底）：

| 底色 | 推荐字色 | 容易踩的雷 |
|---|---|---|
| 深蓝 / 墨绿 | 纯白、米白 | 深蓝字（亮度太近会糊） |
| 黑 / 深灰 | 纯白 | 银灰字（缩略后看不清） |
| 白 / 米色 | 纯黑、深墨色 | 浅黄字（浅底浅字） |
| 亮橙 / 亮黄 | 纯黑、深墨色 | 橙字 / 黄字（会化进底） |
| 实景图（已压暗） | 纯白 | 不压暗直接上白字 |

这组「推荐 / 雷区」覆盖了九成底色场景。拿不准时，就从「推荐」列里选；如果你的主题色板不在表里，就用「黑或白」兜底，永远安全。

**七条规范的合力**：字号管「够不够大」，位置管「放不放得稳」，对比度管「看得清不清」，字数管「显不显得出重点」，字体管「是否清晰统一」，与主体关系管「是否干净不打架」，底色配色管「是否遵循明暗规律」。七条不是孤立的，它们共同服务一个目标：**让封面在 1/5 缩略尺寸下，依然「一眼有重点、信息不打架、层次清晰」。** 检查时不必七条都完美，但至少要保证它们「互不冲突」——比如最大最强的对比度，要配最小最聚焦的字数，才能立住重点。

## 二、可执行步骤（压字流程）

1. **先从标题提炼主卖点关键词（≤8 字）**：把系统标题里最核心的 4–8 个字挑出来作图上大字；这句话与系统标题「互补不重复」。
2. **决定底色**：用主题纯色就一步到位；用实景图就先在压字区域铺半透明罩或压暗 20–40%，把底层做干净。
3. **放主标题**：字号 60–100px、粗体，放画面中上部或正中，居中对齐，左右距安全区 ≥8%。
4. **补副字（可选）**：字号 28–40px，放主标题下方，与主标题保持约 20px 以上间距，形成明确层级。
5. **核对对比度**：确认文字颜色与底层明暗差足够（深底浅字 / 浅底深字）；不够就换文字颜色或加深罩色。
6. **模拟缩略检查**：把封面缩到手机列表宽度，确认主标题一眼可读、没被边缘裁掉。
7. **转成 cover-spec 的两个版本**（2.35:1 大图 + 1:1 方图），两版都要复核一遍可读性。
8. **最终放上封面**：回到 cover-spec 的自查清单，连同封面尺寸、格式、大小一起过一遍。

> 这套流程的关键不是"会不会用软件"，而是"先后顺序对不对"。先定字、再定底、再定位置、最后检查——顺序不乱，出来的封面基本不会翻车。顺序一旦乱（比如先堆了好看的花字再去想内容），往往会做无用功、得返工。

> 如果你今天只有 5 分钟时间做一张封面，就把精力集中在三件事上：**1. 提炼 ≤8 字的关键词；2 字号给足到 60px+；3 深底浅字 / 浅底深字把对比度拉开。** 做完这三步的封面，已经稳定超过很多随手做的封面；剩下的细节（字体、间距、罩色浓淡）是在这三件事拼齐之后再谈的打磨。

## 三、示例

这里给两个可直接照搬的完整示例。每个示例都是一套「从选底到放字到核对比度」的完整决策，跟着做就能出图。示例里标注的数值（颜色、字号、透明度）都是可直接使用的起点，按你的账号稍作修正即可，不必每处都精确到像素。

**示例一：纯色底 + 居中大字（干货文「效率翻倍」）**

一套完整决策：先选深蓝 `#1F3A5F`（深色底→文字取浅色），再从标题「7 个让你效率翻倍的阅读习惯」提炼「效率翻倍」四个字作主标题，放白字、粗体、约 90px 居中在上部，副标题「7 个阅读习惯」用半透明白、约 36px 放其下；深底白字明暗差大，无需加罩。

```
底色：  #1F3A5F（深蓝，「深色底」）
主标题：「效率翻倍」——白字 #FFFFFF，粗体，约 90px，居中放中上部
副标题：「7 个阅读习惯」——白字（约 85% 透明度），约 36px，主标题正下方
原则： 深底白字，明暗拉开，主大副小。
```

（可替换处：底色换成你的主题色；主标题换成当期最扎心的关键词；副标题字号可按画面比例微调。）

**示例二：实景压字封面（生活方式类推文「戒掉无效社交」）**

一套完整决策：街景实图先压暗约 30% 或中间铺半透明深色罩（先做暗底层），再放白字、粗体、约 72px 主标题于中上部，副字「小城生活日记」约 28px 放其下一行；主标题避开画面底部中央（系统标题叠加高发区）。

```
背景:  街景实图 → 整图压暗约 30%，或中间铺半透明深色罩
主标题:「戒掉无效社交」——白字，粗体，约 72px，放在暗罩上
副字:  「小城生活日记」——白色略偏灰，约 28px，主标题下方
关键:  先做暗底层、再放白字；别在一个很亮的底上直接打白字
```

（可替换处：实景图每次换；罩色深浅按图片明暗调；主标题换成当期主卖点。）

**用这两个示例做模板的建议**：示例一适合把图文做成「信息明确、靠关键词打钩子」的类型；示例二适合「氛围感更强、靠画面情绪吸引」的类型。先想清楚你这篇属于哪一类，再选对应的示例做基底，改改字色和背景就能出图。两个示例都建立在 cover-spec 的尺寸与安全区之上，别忘了同步核对比例。

## 四、常见错误

| 错误反例 | 问题出在哪 | 正确做法 |
|---|---|---|
| 图上打满一句话，字号只剩 30px | 字多又小，缩略后根本看不清 | 图内只放 ≤8 字关键词，字号提到 60px+ |
| 白底打白字 / 深底打深字 | 明暗相近，字糊进底色里 | 深底浅字 / 浅底深字，拉开明暗差 |
| 字放画面正底部 | 最容易被系统标题叠加遮挡 | 移到中上部，避开底部中央 |
| 在实景图上直接打字、不打罩 | 底太花，字被背景吃掉 | 先压暗 / 铺半透明罩，再放字 |
| 一张封面堆 4 种字体 | 杂乱，违背「清晰优先」 | 用 1–2 种系统字体 + 粗体即可 |
| 主标题和主体元素叠死 | 字被压、主体被挡 | 文字与主体错开留白，或把主体压暗再叠 |
| 图内重放了和系统标题一字不差的句子 | 信息重复、视觉打架 | 图内放浓缩关键词，完整句交给系统标题 |
| 为了「好看」把字号压到 40px 以下 | 缩略后基本看不见 | 坚持 60px+，可读性永远优先于美观 |

**错误的共同根源**：把这些错误放在一起看，会发现它们大多不是因为"不会设计"，而是因为"把美观放在了可读性之前"。字号、对比度、位置、字号上限这几条，本质都是在跟「缩略后的可读性」作斗争。只要你在动手前先问一遍「这张封面缩到 1/5 还清不清楚」，上面绝大多数坑都能提前绕开。记住：封面不是给你自己放大看的，是给读者在列表里"一扫而过"看的。

## 五、自查要点

> 做「自查」不是走个过场。压下这八条，最稳妥的办法是：**自己先在手机 / 电脑上把封面缩到最小确认一遍，再发给另一位同事让他看一眼是否认得出主标题**。两个人两个视角，比一个人反复看更容易发现「看不清」「被挡」「重复」这三类高频问题。

> 如果自查时任何一项「拿不准」，原则是「偏向保守」：字号再大一点、对比度再拉开一点、字再删掉一两个、位置再往中间收一点——这四个"再"几乎总是能让封面往更稳的方向走。宁可朴素，不要冒险看不清。

- [ ] 主标题 ≤8 字（上限 10 字），是从标题提炼的关键词而非完整句
- [ ] 主标题字号 60–100px、粗体，缩略到列表宽度后仍一眼可读
- [ ] 文字位置在安全区内，优先中上部，不贴边、不压底部中央
- [ ] 对比度达标：深底浅字或浅底深字；实景图先打罩再放字
- [ ] 字体 1–2 种、粗体优先，无 3 种以上堆叠
- [ ] 文字与主体元素之间留 ≥15–20px 呼吸空隙或互不遮挡
- [ ] 大图（2.35:1）+ 方图（1:1）两版都复核过可读性
- [ ] 图上文字与系统标题、摘要互补，不是同一句话三处重复（可配 cover-summary 检查）

## 六、个性化空间

- **字号幅度可按风格调**：极简大字报风格可冲到 100px+ 更大；文艺 / 内敛风格可稍降到 56–64px，但缩略后主线仍要可读。判断依据：账号整体是不是走「大字冲击」的路线。
- **配色不只是黑白**：深底不一定是黑，可用「深墨绿 + 米白字」「深橙底 + 黑字」等；关键是明暗拉开，而不是颜色多显眼。判断依据：账号主题色板（见 cover-consistency 一致性条目）。
- **是否放副字看层级需要**：要有栏目名 / 期数 / 金句的定位就放副字形成层级；极简路线可以只留一个主标题。判断依据：画面信息需要分几层表达。
- **文字位置偏好可调**：有人喜欢居中大字、有人喜欢上部横排——只要都在安全区内、避开底部叠字区，都是合法选项。判断依据：你的模板式封面的固定版式。
- **字距 / 行高可微调**：追求「留白高级感」可加字距（letter-spacing），追求「紧凑冲击」可不加；但永远不要为好看牺牲可读性。判断依据：账号整体的排版风格。
- **是否加描边 / 留白衬底**：对比度够时完全不用；想特别强调时可加细描边，但别依赖它兜底。判断依据：图片底是否足够干净，以及主标题在缩略后是否还足够清晰。

**一条通用判断底线**：无论你怎么个性化，最后都要回到那句最朴素的标准——**「这张封面缩到列表 1/5，主标题还认不认得清」。** 所有个性化都是在「保证这条底线」的前提下做文章；越靠近底线，越要保守。宁可稍微朴素一点，也不要为了特别而牺牲辨识度。这条底线同时服务于封面文案与正文的一致性，详见 cover-consistency。

**和相邻条目的关系**：压字做好的前提是封面尺寸和安全区「先对」（见 cover-spec），压字内容是否提炼为关键词要和系统标题、摘要配合好（见 cover-summary）；整篇首屏布局里压字所在的首图放第几屏见 cover-firstscreen；封面文字颜色和正文色板要不要统一，看 cover-consistency。压字本身只解决「图上的字」，但「整篇的表达」要靠这几个条目一起撑起来——本文是其中的一块拼图。

**一句话收束**：封面文字排版的所有努力，都汇成一句读者视角的自检——**他把列表滑到时，能不能在半秒内看清你要说什么，并因此想点开。** 能做到，压字就成功了；其余都是锦上添花。
