# 账号定位维度索引（index-positioning）

> 定位：解决「这个账号是做什么的、给谁看、怎么长期保持一致」。定位是内容选择的北极星。
> 用法：建号或转型时读 pos-define；规划栏目读 pos-columns；统一长期观感读 pos-baseline；定更新节奏读 pos-rhythm。
> 交叉：长期风格基线落到 style/style-guide-brand；栏目内容进入选题（topic/）；系列栏目见 type/type-serial。

## 条目清单

| 条目文件 | 一句话定位 | 调用时机 |
|---|---|---|
| pos-define.md | 定位与读者画像：一句话定位法、读者特征/需求/场景画像 | 建号、转型、内容跑偏时 |
| pos-columns.md | 栏目体系：固定栏目设计、更新频率与栏目间搭配 | 规划长期内容结构时 |
| pos-baseline.md | 长期风格基线：账号级视觉/文风一致性标准 | 账号观感不统一时 |
| pos-rhythm.md | 更新节奏：频率选择的依据与可持续性 | 定更新计划时 |

## 使用顺序

建号：pos-define 定定位 → pos-columns 立栏目 → pos-rhythm 定节奏 → pos-baseline 立基线；日常跑偏时回到 pos-define 校正。
