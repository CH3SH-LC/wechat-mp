# 首战告捷！十连捧回沙场争锋旗

[[banner:首战告捷|军训首日 · 全营积分第一]]

哨声响起的时候，晨光刚从训练场边的树梢漏下来。上海交通大学新生军训团十连的同学们整装列队——这一天，他们以全营第一的总积分，捧回了「沙场争锋旗」。

## 战报速览

沙场争锋旗是营部评比的最高荣誉：每天按队列、内务、纪律三项综合打分，当日总分最高的连队获得旗帜。首日的积分榜上，十连的名字排在第一。

::: cols
- **队列会操**：动作整齐、口号响亮，单项评分居全营首位
- **内务卫生**：宿舍床铺、物品摆放全连达标，零扣分项
- **纪律作风**：集合迅速、军容严整，全天无违纪记录
:::

![花枝](art://blossom-branch)

## 这一天的背后

荣誉不是天上掉下来的。首日亮眼的表现，靠的是开训前两周的集体准备，和训练场上一遍遍的较真：

- 开训前集体学习内务标准，被子的棱角、桌面的摆放，每个细节提前抠到位
- 训练间隙加练队列，一遍不行就再来一遍
- 排长带头示范，谁的动作不到位就一起陪练
- 「十连十连，勇往直前」的口号，在训练场上喊了一遍又一遍

::: band 斜纹
- 十连十连，勇往直前——口号不是喊出来的，是练出来的。
:::
