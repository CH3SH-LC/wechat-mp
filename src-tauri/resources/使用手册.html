安装与认识界面

本次发布提供 Windows x64 安装包。准备一台可联网的 Windows 电脑和一个浏览器，用于登录模型服务商网站。

  1. 下载安装包。

    打开 智序 GitHub Releases 下载页，找到 1.0.0，展开 Assets。下载 zhixu-1.0.0-windows-x64-setup.exe，不要选 Source code 源码压缩包。手册附件为 zhixu-1.0.0-user-guide.html 和 zhixu-1.0.0-user-guide.pdf。

  2. 双击安装，按向导完成。

    可使用向导给出的默认安装位置，也可选择你需要的位置。安装过程中保持联网。若缺少 WebView2，安装程序会联网下载安装；它是让智序显示界面的微软组件。

  3. 从开始菜单打开「智序」。

    如果你拿到的是软件提供者已经准备好的项目目录，可双击其中的 启动智序.cmd。不要单独移动程序文件或手册。

Windows 弹出保护提示时：先确认文件确实来自上述发布页，且文件名与版本一致。确认来源可信后，才按系统提供的「更多信息 → 仍要运行」继续；不确定来源时，回发布页重新下载，无需关闭系统安全防护。

第一次配置模型

API Key 可以理解为模型服务的专用钥匙。它让智序使用你自己的 DeepSeek 开放平台账号。能登录 DeepSeek 网页聊天，不代表开放平台已有可用余额；智序不会随安装赠送模型额度。

  1. 登录 DeepSeek 开放平台。

    点击 DeepSeek 开放平台，按页面提示注册或登录，完成平台要求的账号步骤。

  2. 查看余额和收费方式。

    进入 余额与充值页面，按自己的需要充值。模型费由 DeepSeek 收取，按输入、输出等用量计算，不是按文章固定收费；价格、最低充值金额和赠送额度以平台当时页面为准。参见 官方模型与价格说明。

  3. 创建自己的 API Key。

    进入 API Keys 管理页，选择创建密钥，名称可写「智序」。复制平台生成的完整密钥，并按平台提示妥善保管。不要复制登录密码，也不要使用别人发来的共享密钥。

  4. 回到智序，打开右上角「设置」。

    把密钥粘贴到 API Key（DeepSeek）。接口地址 保持为 https://api.deepseek.com；主模型显示 deepseek-flash，当前版本固定使用它，置灰是正常的。

  5. 点「保存」，等成功提示，再点「关闭」。

    看到「已保存，下次发送消息时生效」后，下一条消息就会使用这份设置，无需重启。可以先在对话中发一句「你好，请简单介绍你能怎样帮我做公众号推文」，确认能收到回复。

密钥只填设置框，不要贴进聊天。不要把它发给同学、放进截图或上传到问题反馈。若不小心公开，立即在 API Keys 管理页删除或停用这把密钥，再创建新的。

「开启视觉复核」要不要勾选？

第一次使用可保持默认关闭。它用于额外复核排版与插图，会增加模型调用。它与成稿过程中的一次文案复核不同：文案复核会随创作流程执行，不需要勾选这个选项。

哪些操作会产生模型费用？对话、起草、文案复核、改稿、制作或重试 AI 素材，以及开启后的视觉复核，都可能调用模型。反复重试也可能收费；停止请求不代表已经产生的用量会退回。打开已存文档、普通预览和导出本身不需要新生成内容。

平台入口可能要求先登录。上面的密钥与充值地址来自 DeepSeek 官方说明；页面菜单变化时，可回开放平台首页寻找「API Keys」和余额相关入口。

准备底稿与导入原图

已有完整底稿：优先这样做

从 Word、记事本等地方复制正文，粘贴到输入框，再补一句想要的风格。需要原文不动，就写：「正文逐字保留，只调整排版。」

只有需求：也能开始

说清主题、给谁看、希望读者做什么，并提供已知事实。可以让 AI 安排结构和配图，不必先规划每一段、每一种装饰。

先给事实，再让 AI 发挥

校园活动常用材料包括：主办方、活动名称、时间地点、面向对象、报名方式、截止时间和已有成果。没有确认的数字、嘉宾、奖项或联系方式，不要让 AI 自己补成事实。可以直说「这项未定，请先问我」或「暂时不要写这一项」。

例如：「这篇给本校大一同学看；原稿已审定，正文不要删改；整体明亮一些，分成报名、活动安排、注意事项三个部分。」这一两句话已经足够指导方向。

把真实活动照片放进文章

  1. 先把照片保存到电脑。

    在对话输入框旁点 图片，选择本地文件。也可以把图片文件拖入对话区，或在输入框中粘贴剪贴板里的图片。

  2. 等缩略图出现，再补一句说明。

    看到「正在保存原图…」时先等待。写明图片用途，例如：「第一张是现场全景，放在开头；第二张是签到台，放在活动安排后。请使用这两张原图，不要重画。」选错了可以在发送前点缩略图上的 移除。

  3. 与底稿或修改要求一起发送。

    每条消息最多 8 张，单张小于 32MB；支持 PNG、JPEG、WebP、GIF、BMP。仅附图还不能发送，需要同时输入文字说明。后续补图时，继续在同一会话里发送即可。

软件会保存所选原图，并用独立的识别副本帮助模型理解图片。HTML 导出保留原图数据；导出整篇 PNG 时，图片会随文章一起渲染。输入图片的完整本地路径也可读取，但第一次用「图片」按钮更直观。
插画与现场照片要分清。AI 可以制作主题插画和装饰，不能凭空补出真实活动记录。如果照片稍后提供，明确说「照片稍后补」；看到照片占位提示，说明照片还没补齐，导出前要用原图替换。不要把 AI 插画标成现场实拍。

三个可复制的输入示例

点「复制示例」后，粘贴到智序输入框。下面的社团、时间和地点都是演示材料，请替换成你自己的事实后再发送。按 Enter 发送，Shift + Enter 换行，也可点 发送。

例 1 · 已有底稿，只想做好排版

请把下面的完整底稿排成公众号推文，正文逐字保留，不删减，也不拆成零碎短句。给本校同学看，做成明亮的秋日花笺风，标题和章节有层次，配少量书本主题插画。按“活动介绍”和“参与方式”分成两节，其余排版你来安排。 秋日交换书会 一本读过的书，也许正是另一位同学想读的。拾页读书社将在10月25日15:00—17:00，于图书馆一楼共享空间举办交换书会，邀请本校同学带着书和阅读故事见面。 参加者可携带一至三本保存完好的书，在现场登记后自由交换。活动免费，无需提前报名。请勿携带教材、盗版书或明显破损的书籍；未换出的书请在活动结束前自行带回。

例 2 · 只有事实，请 AI 起草

帮青禾摄影社写一篇招新推文，主要给大一同学看，语气亲切自然。我们每周六下午组织校园拍摄，每月有一次作品交流，新手可以参加，手机也能拍。报名方式是9月20日17:00—19:00到大学生活动中心一楼服务台现场登记。不要添加获奖经历、名额或费用信息，缺少必要事实就问我。视觉上明亮活泼，像校园票笺，配与摄影有关的插画；篇幅和结构你来安排。

例 3 · 实践记录，配自己的现场照片

请根据下面材料写一篇社区实践回顾，给学院师生看，语气平实，不夸大成果。10月12日下午，书页同行实践小组在青禾社区阅读室，协助整理归还图书、检查书架标签，并记录需要补充的图书类别。参与者共12名，后续会把需求记录交给阅读室负责人。没有开展捐赠，也没有统计服务人数，请不要补写。整体用蓝金色书页风，章节清晰。我通过“图片”按钮附了两张现场照片，第一张是整理书架，第二张是记录表，请使用原图，放在相关内容附近，不要改画成插画。

使用例 3 前，请先添加自己的两张照片；没有照片就删掉示例最后两句。若手册的复制按钮不可用，选中示例文字，右键复制即可。

风格、等待与手机预览

用一句话给风格方向

风格不是必填表格，也没有必须先选好的模板。你可以只说「适合大学生，清楚好读」，也可以给更明确的感觉：

想要的感觉可以直接这样说
花笺、轻松温暖米白纸面，配花枝和精致角饰，明亮一点，正文保留足够留白。
票笺、校园活力像校园活动票券，标题有变化，章节之间用票笺元素呼应。
书页、蓝金缎带蓝金色书页风，窄缎带做章节标题，正式一些，但别太沉重。
清爽极简以文字为主，装饰少一点，标题清晰，不要太多色块。

章节指导也可以很短：「按活动介绍、参与方式、注意事项来排。」不必规定每个框、每条线和每张插画的位置；不喜欢某处，看到预览后再指出来。

发送以后，等它完成这一轮

左侧会显示工作阶段和已用时间。过程可能包括读取资料、撰写、一次文案复核、制作素材、排版检查与保存。先出现文字或预览，不代表这一轮已经结束。

最近六份完整底稿样稿的实际生成等待约为 108—282 秒，可先按几分钟安排。它不是时限保证；篇幅、配图、修改内容、网络和服务繁忙程度都会影响等待。单个步骤也可能超时。

等待时不要连续重复发送。若不想继续，可点 停止。停止或复核失败时，本轮不一定成为新成品；以右侧状态提示为准，不能把聊天里出现的初稿当作已经保存的最终版本。

在右侧，像读手机文章一样检查

推文预览 · 375px 指的是手机阅读宽度。鼠标放进预览内上下滚动，点上方的百分比按钮可切换缩放。它是电脑里的手机尺寸预览，不是已经发布到你的手机。

  • 先看事实：人名、日期、地点、数字、报名方式是否正确。
  • 再读正文：有没有遗漏原稿、无依据的新说法、重复或不自然的句子。
  • 再看图和版式：原图是否放对位置，插画是否贴题，文字是否清晰，有没有遮挡。
  • 看完最后一屏：结尾、联系方式和照片占位是否处理好。

「质量检查 · 通过」是软件检查结果，不等于事实正确或审美已经合你心意。公众号后台的手机预览仍需在发布前再看一次。

修改、保存与重新打开

第一稿只是起点。在同一会话继续说哪里要改，每轮先解决最在意的一两件事。可以在预览里点一下段落或图片，把对应位置带进输入框，再补上要求；点选本身不会直接修改文章。

改文案

“开头太空泛，请直接说明活动内容。语气亲切些，保留完整句子，不要拆成一句一行；时间、地点和报名方式不要改。”

保护已经审定的底稿

“这轮只调整标题层级和段间距。正文逐字保留，不删减、不概括，也不把首句改成另一段小标题。”

改配图

“第二节插画和摄影主题不太相关，改成拿着相机观察校园的插画，颜色与全文一致。两张真实活动照片保留原图。”

改风格

“现在每一段的框太像了。保留米白和绿色，用花笺、细框和少量角饰做出章节变化；正文留白多一点，不要增加装饰数量来填满页面。”

如果 AI 理解错了，引用原句、指出具体图片或小节，比只说「不好看」「再高级一点」更容易改准。每次改完都再看一次；一直不满意时，可把范围缩小，先定正文，再定排版和配图。

怎样确认这篇已经存好？

  1. 等待这一轮结束。

    右侧出现 成品已验收并保存，才表示本轮已保存。如果显示「写入文档库尚未确认」或保存失败，不要马上关闭软件；先尝试导出 HTML 留一份，再按提示处理。

  2. 点顶部「文档库」，找标题并打开。

    打开文档会回到关联会话，继续发修改要求即可。同一篇文章的修改会更新原文档，不会每轮都在库里多出一篇。

  3. 重要文章再做一次重开核对。

    确认保存后正常关闭智序，再打开，在文档库找到该稿；核对末段、原图和最近改动。准备开始另一篇时，展开会话栏，点 新建。

不要用「清空」开始下一篇。「清空」会清空当前会话并删除其文档；会话栏和文档库的「删除」也会连带删除关联内容，界面会要求确认。这些操作不能当作撤销改稿或关闭预览使用。

若出现「已恢复上一版成品」，本轮新稿没有替换旧成品；「草稿未通过」则仍需处理问题。先看状态和具体原因，再继续修改。

导出与公众号手动使用

确认预览是你要的版本、图片齐全，并已保存后，再使用右侧上方的导出按钮。智序不替你登录公众号、保存后台草稿或群发。

方式一：导出图片，保留整体视觉

  1. 点 导出图片，等待「转图中…」结束。一次会生成一张长图和一组分页 PNG，图片宽度为 750 像素。
  2. 导出完成后会打开图片所在文件夹。文件名带「长图」的是整篇；末尾为 -01.png、-02.png… 的是分页，按数字顺序使用。
  3. 双击打开图片检查清晰度、页与页的衔接及结尾。需要整篇转发或留存，可选长图；需要分段上传时，可用分页图片。不要把长图和分页重复放进同一篇。
图片里的文字已经成为画面，读者不能像普通正文那样选中文字，里面的链接也不能点击。报名链接、联系方式等需要点击或复制的内容，应在公众号后台另外填写为可用的文字或链接。

方式二：导出 HTML，留存一份可打开的文章

点 导出 HTML，按屏幕显示的保存路径找到文件，双击后用浏览器查看。HTML 是一种网页文件，你不需要编辑其中的代码。文件保存到作品目录下的 exports 文件夹；此按钮不会自动打开文件夹。

复制 HTML 复制的是源文本，不是公众号可直接粘贴的富文本。不要把它粘进公众号正文。当前没有「一键导入公众号排版」；如果需要可选择的正文，请在后台整理文字、上传图片并重新检查版式。普通复制粘贴也不能保证完整保留样式。

放到公众号：这一步由你操作

  1. 在浏览器打开 微信公众平台，用有权限的账号登录，进入图文内容编辑页面。
  2. 填写文章标题、作者、摘要和封面。采用图片方案时，将导出的分页图按顺序插入正文；标题和封面需要另行设置，正文长图不会自动成为后台封面。

按钮上有「草稿」时先停一下。「导出草稿 HTML」或「导出图片（草稿）」用于取回未通过检查的内容，并不表示适合发布。先处理未完成素材、缺照片或排版问题，再导出最终稿。

素材工坊与本机备份

可选：做一套自己的常用插画

第一次写稿可以先跳过素材工坊，直接在对话中提出配图要求。需要经常使用同一套素材时，再进入顶部 素材工坊。

  1. 选择分类，例如 开篇横幅、小节装饰 或 宽幅插图，用文字描述内容和配色，然后点 制作并入库。
  2. 打开素材后，可在 连续修改 中写「花心改成金黄，绿色再淡一点」，点 生成新版。看过前后预览，满意再点 采纳为新版本；不满意可点 放弃。
  3. 之后写推文时，可在对话中说明要复用哪个素材。旧文档保留保存时的素材副本；库里更新素材不会自动替换所有旧稿，需要时再用 用新版更新 并检查结果。

工坊制作的是插画与装饰。真实照片请从对话输入框的「图片」导入。工坊里的「SVG 源」「替换源」属于进阶操作，新手无需使用。

作品到底保存在电脑哪里？

打开 Windows 文件资源管理器，在上方地址栏粘贴下面这一行，按回车即可。这是文件夹地址，不是要运行的命令。

%USERPROFILE%\Documents\wechat-mp-workspace

通常对应「C:\Users\你的用户名\Documents\wechat-mp-workspace」。即使 Windows 的“文档”被移动到 OneDrive 或别的盘，当前版本仍使用上述用户目录下的 Documents。

最省心的备份方法

确认已保存并关闭智序，复制整个 wechat-mp-workspace 文件夹到自己的移动硬盘或受保护的备份位置，加上日期。仅备份 exports 只能留住导出文件，不能完整恢复会话续改。

整份备份包含密钥和对话，请勿发到公开群或作为反馈附件。恢复旧备份前，先把当前文件夹再备一份；覆盖可能丢掉较新的作品。不会处理时先保留两份，请软件提供者协助。
本地保存不等于离线创作。创作、复核与改稿时，相关对话、文章和选定图片的识别副本会发送给配置的模型服务；密钥也会用于向该接口认证。只输入和选择适合交给该服务处理的材料，避免身份证号、密码和未获授权的个人信息。

遇到问题这样处理

发送后报密钥错误、余额不足，或一直连接不上

401 / 认证失败：重新核对 API Key 是否完整，以及接口地址是否仍为官方地址，保存后再发。402 / 余额不足：去开放平台查余额。429 / 请求过多、500 / 503：稍后重试，别连续点发送。网络错误先确认电脑能打开官方平台网页。官方解释见 DeepSeek 错误码说明。

提示模型不存在、不可用或没有权限

当前版本固定使用 deepseek-flash，不能在设置中自行切换模型。即使已填密钥、已有余额，也不代表你的账号一定能调用该模型。请记录错误文字并联系软件维护者，核对服务支持情况；不要因此反复充值或尝试陌生接口。

等待很久、提示超时，或停在某个阶段

生成带图文章可能需要几分钟。若已明确报超时，先读错误原因，检查网络后在原会话重试；可以先要求少量配图。若长期没有进展，可点 停止，等工作状态结束。不要把等待中的一轮当作已保存，也不要连续重新发送同一请求。

打开后白屏、黑屏，或窗口无响应

先等片刻；若出现界面恢复提示，按提示处理。仍异常时，正常关闭后重开，并从文档库检查已存稿。若持续无法显示，可从 微软 WebView2 官方下载页安装或修复对应的 Evergreen Runtime，再重开。不要为此删除作品文件夹。未发送的输入或未保存内容可能无法恢复。

素材没出来，或文章里还有「待补照片」

看预览上方的「仍有…个素材未完成」及原因；对生成失败的素材可点旁边 重试，会再次调用模型。待补照片需要你从 图片 导入真实原图，不是点重试就能得到现场照片。补齐以后再检查、保存和导出。

明明出现了新稿，预览却还是旧的

若显示「已恢复上一版成品」或文案复核未完成，本轮未替换正式成品。看提示列出的原因，在同一会话继续要求修正；必要时用明确标注的草稿导出入口留存候选。不要以聊天里“完成了”的文字代替右侧状态。

设置、文档库读取失败，或保存失败

先点界面提供的 重新读取 / 重试。保存失败时先导出当前稿留存，检查磁盘空间和文件夹是否可写。「恢复默认」会清空本机 API Key；设置损坏时会替换旧配置，先备份再处理，不要把重置当作常规修复步骤。

内容不满意，或费用比预想多

引用具体段落或图片，说明希望保留什么、改掉什么；已审定的底稿写明“正文逐字保留”。费用去平台查看实际用量；可以减少反复重试和不必要的配图，保持视觉复核关闭。软件不能保证每篇固定价格，也不能保证一次生成就满意。

需要反馈给软件提供者：记录智序版本、出错时间、刚才点了什么，以及完整错误文字。可到 项目问题反馈页提交。发截图前遮住密钥、个人信息和未公开材料；不要上传 settings.json 或整份作品目录。
