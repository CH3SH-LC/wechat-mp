1这个软件是做什么的

智序（本软件，全称"公众号推文助手"）是一个安装在电脑上的桌面软件。你像聊天一样告诉它想写什么，它会帮你起草一篇排版好的微信公众号推文，并在右侧的「手机屏幕」里实时给你看效果。

  • 对话创作：自然语言提出需求，它会先澄清细节再成稿，也支持后续修改。
  • 专业排版：内置公众号排版知识库与排版引擎，标题、小标题、提示气泡、分隔线、插画等自动成套，成品接近人工排版效果。
  • 实时预览：右侧按 375 像素的手机宽度渲染，所见即所得。
  • 插画素材库：内置「素材工坊」，让 AI 专门制作小插画并入库，后续推文直接复用，风格统一。
  • 自动保存：每篇完成的推文自动存入「文档库」，随时打开继续改。
  • 导出发布：一键导出高清长图或分页图片，手动上传到公众号后台即可发布。
需要说明：创作过程需要联网——你的对话内容会发送给 DeepSeek（AI 服务商）处理，请勿输入个人敏感信息（身份证号、密码等）。软件本身不收集任何统计信息，详见 第 11 节。

2安装与启动

  1. 拿到安装包：文件名为 wechat-mp-desktop-x.x.x-setup.exe（一个以 -setup 结尾的文件）。
  2. 双击安装包开始安装。若 Windows 弹出蓝色提示「已保护你的电脑」（SmartScreen），是因为该软件由个人开发者制作、尚未购买微软签名证书——点击「更多信息」，再点「仍要运行」即可继续。
  3. 按提示选择安装位置（默认即可），等待安装完成，勾选「运行公众号推文助手」启动软件。
  4. 安装后桌面和开始菜单会出现「公众号推文助手」图标，以后从这里双击打开。
卸载：打开 Windows「设置 → 应用 → 已安装的应用」，搜索「公众号推文助手」，点击卸载即可。卸载不会删除你的作品文档（见 第 11 节）。
更新：拿到新版本安装包后直接双击安装（覆盖安装），你之前保存的文档、素材、设置都会保留。

3第一次使用：填入 API 密钥

本软件不提供 AI 服务，它调用的是 DeepSeek 的人工智能接口。要使用，需要先有一个自己的 DeepSeek「钥匙」（API 密钥）。这个过程只做一次，约需 5 分钟。

  1. 打开 DeepSeek 开放平台网站：platform.deepseek.com，注册账号并登录。
  2. 在「API Keys（API 密钥）」页面点击「创建 API Key」，给钥匙起个名字（如 home），复制生成的密钥。它长得像一串 sk- 开头的字母数字，例如 sk-xxxxxxxx…。密钥只显示这一次，请妥善保存。
  3. 回到本软件，点右上角「设置」，在「AI 模型设置」里把密钥粘贴到「API 密钥」一栏，然后点「保存」。
  4. 保存成功后，直接开始对话即可（密钥立即生效，无需重启）。
关于费用：DeepSeek 平台按用量计费，新账号通常有赠送额度；用量很少时费用极低。若提示余额不足或鉴权失败，请到平台「用量/充值」页面查看。
密钥安全：密钥只保存在你自己的电脑上（具体位置见 第 11 节），本软件不会把它上传到任何地方，也不会随软件源码公开。不要把密钥文件发给别人。

4创作你的第一篇推文

  1. 打开软件后，在左下角输入框用平常说话的方式提出需求。例如：
    「帮我写一篇公众号推文，主题是咖啡店新品桂花拿铁，面向年轻上班族，口语一点，要配插画」
  2. 按 Enter 发送（Shift + Enter 换行）。右上角状态会显示「思考中…」/「生成中…」——AI 在构思和撰写，请稍等。
  3. 如果需求还不够清楚，AI 会先用文字问你几个问题（比如文章多长、要不要放真实照片），你逐条回答，它会自动接着写。
  4. 成稿后，右侧「手机屏幕」会立刻显示排版效果。满意就保存（会自动保存，见 第 7 节）；不满意就直接在输入框里说，例如「第二段再口语一点」「加一个小标题」「插画换成卡通风格」，它会修改给你看。

怎么提需求更高效

  • 说清主题 + 读者 + 想要的感觉，效果最好：「给新手妈妈写奶粉选购避坑指南，温暖、有条理，1200 字」。
  • 要不要真实照片请提前说：AI 会给照片留好位置并配装饰插画；没照片时会全部用生成的插画。
  • 风格不限：你可以指定「小红书风」「国潮」「简约商务」，AI 会按内容选择并统一渲染。
内容提示：AI 是写作帮手，不是事实核查员。发布前请人工核对数字、政策、价格等关键信息，医疗、金融等内容请遵守平台规则。

5右侧预览与质量提示

右侧就是成品效果：一个手机屏幕样式的 375px 宽预览，顶上一行小按钮：

按钮作用
百分比（如 100%）放大 / 缩小预览（循环切换）
复制 HTML把排版后的网页代码复制到剪贴板（供进阶使用）
导出图片把全文转成高清长图 + 分页图片，并自动打开所在文件夹——推荐用它发布（见 第 9 节）
导出 HTML把排版后的页面保存成单个 .html 文件
清空删除当前对话与其自动保存的文档（需确认）

生成过程中，软件会自动做质量检查：发现"组件太少、没有插画、气泡缺角饰"等可修问题时，会自己把问题清单喂给 AI 重写一次（最多两轮），直到合格为止。底部提示条含义：

  • 绿色「质量检查通过」：可以放心导出。
  • 黄色提示：剩余是一些软性建议（如文章偏短、风格名称未收录），可改可不改。

想看文字源码：在左侧对话气泡上点「查看 HTML 源码」即可展开收起。

注意「清空」按钮：它会把当前这篇对话连同文档库里的成品一起删除，且不可恢复。想留底稿请先「导出图片」或把内容复制出来。

6素材工坊：你的插画素材库

公众号排版好看的秘密，是各种小插画：气泡上的角饰、分隔线、小图标、横幅、题图插画…… 素材工坊让 AI 单独制作这些小素材并存进你的素材库，以后每篇推文都能复用，越用越顺手。

  1. 点顶栏「素材工坊」进入工坊界面。
  2. 先选一个分类（气泡角饰、分割线、装饰花边、横幅、小标题图、文章插图、宽幅插图、照片相框），然后在描述框里尽量说清素材长什么样，例如：「右下角一朵粉色小花的气泡角饰，扁平插画风，留白多」。描述越具体，成品越贴近想象。
  3. 点「制作入库」。AI 绘制完成后素材会出现在素材列表里，可以给它起名、写描述方便日后检索。
  4. 创作推文时不用管素材：AI 会自动从素材库检索复用你的素材；库里的不够用时，它才会现场委托制作并自动入库。

维护素材的小知识

  • 检索：列表上方可输入关键词，按语义查找（如搜"小花"能命中描述里写了小花的素材）。
  • 替换源（重新制作）：对某个素材不满意，可以用新描述重做。它会先扫描「哪些历史推文引用了这个素材」，由你逐篇选择是否用新版更新——旧文档不会被悄悄改动。
  • 删除：删除素材不会破坏已发布的推文（推文里保存的是当时素材的固化副本）。

7文档库：作品自动保存

  • 每篇成稿的推文会自动保存成一份文档，标题用你的第一句话自动命名。你什么都不用做，顶栏会提示「已自动保存」。
  • 点顶栏「文档库」可以看到所有作品。点某篇文档，会回到它原来的对话，预览同步恢复，你可以继续修改——修改后文档就地刷新，不会出现"两版并存"。
  • 删掉某篇文档（连同它的对话）用文档库里的删除按钮；清空操作见 第 5 节。
文档存在哪：作品文件位于电脑「文档」文件夹下的 wechat-mp-workspace 目录（详见 第 11 节），重装系统前请先备份这个文件夹。

8多任务会话管理

  • 左侧「会话栏」每一条对话就是一个独立会话：写咖啡推广、写公司通知、写节日祝福……互不干扰，各自自动保存。
  • 顶栏「展开会话栏 / 收起会话栏」控制侧栏显示；「新建」开新对话；点某条会话可随时切回继续写；删除会话会连同它的文档一起删除（有确认）。
  • 软件关闭、重启后，所有会话和文档都还在，从会话栏直接点开即可。

9导出成品并发布到公众号

本软件不代发文章（公众号的发布必须由你自己的账号在官方后台操作）。推荐流程如下，全程约 2-3 分钟：

方式一（推荐）：导出图片后上传

  1. 在预览区点「导出图片」。软件把全文转成图片并自动打开所在文件夹。文件夹里是一张超长图（手机 375 宽、2 倍高清输出，约 750 宽）以及按屏拆好的若干张分页图。
  2. 浏览器打开 mp.weixin.qq.com 并登录你的公众号。
  3. 左侧菜单进「草稿箱 → 新建图文」（或「图文消息 → 新建」），填写标题等。
  4. 在正文编辑区点工具栏的「图片」图标，选择「从图片库」或「从本地上传」，把刚才的图片按顺序全部选中上传（想用超长图就传长图一张；手机端阅读长图体验更好时传长图，追求图文穿插则逐张传分页图，每张之间可点回车补一段说明文字）。
  5. 检查排版无误后保存为草稿或直接群发。封面可在后台单独设置（建议用 900x383 比例的图片做封面）。

方式二：导出 HTML（进阶）

  1. 点「导出 HTML」，得到一个 .html 文件，双击可用浏览器打开查看。
  2. 把 HTML 内容复制到公众号编辑器，或交给懂技术的同事进一步处理。
提醒：微信公众号编辑器会自动过滤大部分自定义样式，直接粘贴 HTML 会丢失排版——这也是推荐用图片方式发布的原因。图片方式所见即所得，任何公众号都能用。

10常见问题（FAQ）

发消息后一直没反应 / 提示网络错误

创作需要联网访问 DeepSeek。请检查电脑网络是否正常，必要时关闭代理软件再试。公司内网如有防火墙限制也可能导致失败。

提示鉴权失败 / 401 / 403

多半是密钥问题：打开「设置」确认密钥是完整的一整串（以 sk- 开头，无多余空格）；再到 DeepSeek 平台确认账号有余额、密钥未被删除。

AI 先问我一堆问题，能不能直接写？

它是在确认需求，保证不写偏。你可以回答「你看着办，直接写」，它会按合理默认直接成稿。

生成的内容不满意怎么办？

直接提修改意见即可：「太长/太短」「再活泼一点」「换个角度重写」。也可以换一批更具体的素材再生成。AI 写作偶有起伏，多试几次通常就有满意版本。

我想换别的模型或服务商

「设置 → AI 模型设置」可以改接口地址与模型名。默认配置已调好，非进阶用户请勿改动。

改了设置后为什么没生效？

设置对「新开始的对话」生效。当前进行中的对话请新建会话后使用。

软件更新/重装后我的东西还在吗？

作品、素材、密钥都在「文档」文件夹的 wechat-mp-workspace 里，覆盖安装或重装不会动它。若手动删除了该文件夹则无法找回。

11数据存放在哪里（隐私说明）

数据存放位置说明
对话记录 / 会话文档 → wechat-mp-workspace/sessions本机明文文件
推文文档wechat-mp-workspace/documents含源码与渲染快照
素材库wechat-mp-workspace/assets你制作的插画素材
导出图片 / HTMLwechat-mp-workspace/exports导出即自动打开该文件夹
API 密钥与模型设置wechat-mp-workspace/settings.json明文文件，仅本机
隐私承诺：以上数据全部保存在你自己的电脑上。软件不联网上传你的作品与素材，不收集使用统计；唯一的外部通信是创作时把「对话内容」发送给 DeepSeek 接口用于生成（以你在 DeepSeek 平台同意的条款为准）。请勿在对话中输入敏感个人信息。密钥只在本机使用，本软件的源码库中不含任何真实密钥。

建议：重要作品请定期到 wechat-mp-workspace 文件夹手动备份；该文件夹不随软件卸载而删除。
