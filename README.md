# 智序 · 公众号推文助手

智序是 Windows 上的公众号创作工作台：通过 AI 对话完成写作和修改，在右侧手机预览中查看排版，复用个人素材，将成稿本地保存并导出后手动发布。

**项目目标和完成标准见 [GOAL.md](GOAL.md)**；完整文档入口见 [文档导航](docs/README.md)。

## 能做什么

- 自然对话创作，按需取用内置知识库，支持多轮修改。
- 375px 手机版式预览、组件化排版和自动质量提示。
- 个人素材库与素材工坊：检索复用、缺料补做、版本和引用快照。
- 文档自动保存、回源会话续改、多会话管理。
- 导出 HTML、750px 宽高清长图及分页 PNG，供用户手动上传公众号。

上述能力有源码实现；本轮仅核对文档与代码入口。历史发布验收见 [发布说明](RELEASE-NOTES.md)，当前缺口见 [需求与待办](REQUIREMENTS.md)。

## 使用与开发

用户安装与操作见随安装包提供的 [使用手册](src-tauri/resources/使用手册.html)。0.1.0 安装包名称和历史发布信息见 [发布说明](RELEASE-NOTES.md)；本轮未联网确认下载资产状态。

技术栈为 Tauri 2、React 19、TypeScript、Vite 与 Rust。运行 pnpm install 安装依赖；pnpm dev 启动浏览器模拟模式；pnpm tauri dev 启动真实桌面模式。配置、验证和打包说明统一见 [开发指南](docs/DEVELOPMENT.md)。

## 数据与服务

桌面实现使用用户主目录下的 Documents/wechat-mp-workspace/ 保存会话、文稿、素材、导出和设置；目前通过拼接路径定位，不保证跟随 Windows 文档目录重定向。浏览器模拟模式使用 localStorage，与桌面数据分开。

AI 请求发往所配置的模型服务（默认 DeepSeek），请求内容包含对话及所取用的知识/素材描述。API Key 从本机配置读取，不应提交。旧微信发布模块仍在后端注册，当前界面没有发布入口；不能据此宣称整个程序只有一种外部通信。历史密钥扫描结果见发布说明，本轮没有重新进行全历史安全审计。

本项目独立于旧 DSH 公众号插件预设运行；知识语料来源和维护方式见 [协作规则](CLAUDE.md)。仓库未附开源许可证；使用、分发或商用请联系作者。
